# Blacksmith 예술성 비상한 수치형 능력치 설계

- 설계 승인: `2026-08-05`
- Decision ID: `BS-CRAFT-20260805-01`
- 정제 대상: 기존 `예술성 1~10`, `예술성 7/10`, `예술성 10 = 최고치` 해석
- 배치: `R2_BATCH_004 / 2_OF_10`
- 제품 구현: `BLOCKED`
- 상태: `USER_APPROVED_DESIGN / SPEC_REVIEW_REQUIRED`

## 1. 문제

기존 정본은 예술성을 무기·작품 능력치로 분리했지만 `1~10`, `7/10` 표기를 사용해 예술성 10을 고정 최대치처럼 보이게 했다. 이는 공격력·내구도·조작성처럼 성장하는 일반 능력치로 사용하려는 사용자 의도와 충돌한다.

## 2. 승인 설계

예술성은 다음 도메인을 사용하는 일반 무기·작품 능력치다.

```text
ARTISTRY: integer >= 0
fixed maximum: none
named tiers: none
```

표시 예시:

```text
공격력  42
내구도  31
조작성  18
예술성  27
```

- `0`을 허용한다.
- 정수만 사용하며 소수점은 사용하지 않는다.
- 고정 최대치는 없다.
- `/10`, `/100`, 별점, 백분율로 표시하지 않는다.
- 예술성 단계명이나 희귀도명을 붙이지 않는다.
- 공격력·내구도·조작성과 같은 능력치 영역에 원수치로 표시한다.

## 3. 의미

예술성은 작품의 다음 요소가 누적된 결과를 표현한다.

- 조형 완성도
- 표면 마감과 세공
- 장식 구성과 조화
- 작품으로서의 인상
- 감정·전시·수집 가치에 기여하는 미적 완성

`예술성 0`은 미완성품을 뜻하지 않는다. 기능과 안전 기준은 충족하지만 장식·세공·미적 의도가 거의 없는 순수 기능품을 뜻한다.

## 4. 다른 축과의 경계

```text
제작 등급 = 최초 단조의 기술적 완성도
예술성 = 누적 가능한 미적·작품 능력치
촉매 수식어 = 정밀강화와 촉매 계보
연대기 수식어 = 실제 작품 생애
```

따라서 다음 조합이 모두 가능하다.

```text
[전설] 운철 전투도끼 / 예술성 3
[보통] 은제 의장검 / 예술성 87
```

- 제작 등급은 예술성의 고정 상한을 만들지 않는다.
- `[전설]`이 높은 예술성을 보장하지 않는다.
- `[보통]`도 높은 예술성을 가질 수 있다.
- 예술성은 네 번째 수식어 슬롯이 아니다.

## 5. 생성과 변화

예술성은 승인된 제작·강화 행위로 증감할 수 있다.

- 최초 제작 결과
- `ARTISTIC_FINISH` 정밀강화 방식
- 예술성 관련 촉매·수식어 효과
- 세공·마감 콘텐츠
- 손상과 복원 중 미적 상태 변화

강화 레벨만으로 자동 증가하지 않는다. 동일 행동의 반복으로 무한 효율을 얻는 구조도 허용하지 않는다. 구체적인 증감값·비용·성공률은 `BASELINE_TEST_PRESET / USER_PLAYTEST_REQUIRED`다.

## 6. 경제·수요 사용

고정 최대치가 없더라도 예술성이 모든 경제와 고객 판정을 선형으로 지배해서는 안 된다.

권장 처리:

- 화면에는 원수치를 그대로 표시한다.
- 판매 가치·감정 가치·고객 선호 계산에서는 콘텐츠별 기대 범위와 점감 함수를 사용할 수 있다.
- 고객과 일정은 절대 최대치가 아니라 최소 요구치·선호 구간·다른 능력치와의 조합을 사용한다.
- 높은 예술성이 모든 고객과 모든 상황의 최적해가 되지 않게 한다.

정확한 점감 함수와 기대 범위는 구현 전 별도 승인 대상으로 둔다.

## 7. 전투 경계

예술성은 전투 성능을 기본적으로 올리지 않는다.

금지:

- 공격력·방어력·내구도·조작성의 범용 증가
- 모든 수식어 수치의 일괄 증폭
- 예술성을 종합 전투력으로 자동 환산
- 높은 예술성만으로 모든 장비 선택을 지배

특정 전투 효과가 필요하면 촉매 수식어·강화 방식·고객 또는 사건 조건이 별도로 책임진다.

## 8. 벤치마킹 판정

### 채택

- 공격력·내구도와 같은 원수치 능력치 표시
- 이름이 붙는 제작 등급과 숫자형 능력치의 분리
- 제작 품질·장식·재료가 가치에 서로 다른 원인으로 기여하는 구조

### 수정 채택

- 고정 상한 없는 성장 수치를 사용하되 경제·수요 계산에는 기대 범위와 점감을 적용 가능

### 비채택

- 예술성 숫자가 모든 속성을 일괄 강화하는 범용 품질 배율
- 제작 등급·예술성·촉매·연대기를 하나의 총품질 점수로 합산
- 예술성 10을 최고치로 고정

### Blacksmith 차별점

같은 작품 UID의 출생 등급, 제작자의 미적 투자, 촉매 선택, 실제 생애를 서로 독립적으로 설명한다.

## 11. TDD 인수 조건

정본 변경 전에 실패 계약을 먼저 추가한다.

RED에서 다음을 요구한다.

1. Registry의 예술성 도메인이 `NON_NEGATIVE_INTEGER_NO_FIXED_MAXIMUM`이다.
2. 현재 권위 문서에 `/10`, `1~10`, `예술성 10 = 최고치`가 남아 있지 않다.
3. `0` 허용과 고정 최대치 없음이 명시된다.
4. 예술성 단계명과 범용 전투력 배율이 금지된다.
5. 과거 `1~10` 계약은 `[대체됨]` 역사로만 남는다.
6. 제품 구현은 `BLOCKED`다.

GREEN은 최소 정본·Registry·라우터·Sheet 변경으로 만든다. 이후 중복·구형 참조를 정리하고 exact-head CI를 다시 실행한다.
