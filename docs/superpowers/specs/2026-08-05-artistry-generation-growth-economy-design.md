## 1. 목적

고정 설계 최대치가 없는 예술성 원수치가 다음 질문에 일관되게 답하도록 한다.

1. 새 작품의 예술성은 어디서 생기는가?
2. 제작 후 어떤 행동만 예술성을 높일 수 있는가?
3. 무한 성장 가능한 원수치가 가격 경제를 어떻게 파괴하지 않는가?
4. 고객마다 예술성을 어떻게 다르게 평가하는가?
5. 같은 원인을 가격·수식어·연대기에 중복 계산하지 않는가?

이 설계는 구조와 책임만 확정한다. 정확한 수치·확률·구간은 `BASELINE_TEST_PRESET / USER_PLAYTEST_REQUIRED`로 남긴다.

## 2. 현재 불변 계약

```text
예술성 = 0 이상의 정수
고정 설계 최대치 = 없음
표시 = 예술성 27
```

- 분모·별점·백분율·단계명 없음
- 제작 등급과 별도 축
- 전투 성능을 기본적으로 올리지 않음
- 범용 전투력·수식어 배율이 아님
- 제작 등급은 예술성 최소값·상한을 정하지 않음
- `[전설] / 예술성 3`, `[보통] / 예술성 87` 모두 가능

## 3. 벤치마킹·현업 비교

### Diablo IV

최근 아이템화는 아이템의 기본 위력, affix, Tempering, Masterworking/Quality를 구분하고, 성장 비용을 품질에 따라 크게 증가시키는 구조를 사용한다.

- **채택:** 기본 성능·선택형 성장·품질성 수치를 서로 다른 책임으로 분리
- **수정 채택:** 높은 수치의 추가 성장을 점점 비싸고 어려워지게 만드는 비용 구조
- **비채택:** 예술성에 고정 최대치를 두는 방식
- **비채택:** 예술성 수치가 모든 기본 성능과 affix를 일괄 증폭하는 방식
- **이유:** Blacksmith의 예술성은 전투 품질이 아니라 작품 가치와 특정 수요의 축이다.

제작 품질과 장식 품질은 서로 독립될 수 있고, 장식은 낮은 제작 품질의 물건에도 별도로 높은 가치를 더할 수 있다. 반면 재료·품질·장식 배율이 중첩되면 가치가 매우 빠르게 커질 수 있다.

- **채택:** 제작 완성도와 장식·미적 가치를 독립적으로 생성
- **채택:** 낮은 제작 등급에도 높은 예술성이 가능
- **수정 채택:** 장식·세공의 기여를 출처별로 기록
- **비채택:** 제작 등급·재료·예술성을 전체 가격에 연속 곱셈하는 구조
- **이유:** 곱셈 중첩은 희귀 재료와 고등급이 예술성까지 독점하게 만든다.

- Dwarf Fortress Wiki, `Item value`

- **채택:** 동일한 저비용 행동 반복에서 예술성·가치가 무한 생성되지 않도록 출처별 반복 제한
- **수정 채택:** 정상 플레이 전체를 벌주는 전역 점감이 아니라, 악용 가능한 동일 출처에만 제한 적용

참고:

- Guild Wars 2 Wiki, `Diminishing returns`

## 4. 검토한 접근법

### A. 원수치 누적 + 허용 출처 제한 + 평가 단계의 구간별 점감 — 권장

- 예술성은 원수치로 계속 누적된다.
- 허용된 제작·정밀강화·세공 행동만 수치를 변경한다.
- 가격과 고객 평가는 별도의 구간별 점감 함수로 원수치를 해석한다.
- 제작 등급·촉매·연대기는 각자 별도 가치 항목으로 한 번만 계산한다.

장점:

- 플레이어가 작품 자체의 성장량을 그대로 이해할 수 있다.
- 고정 최대치 없이 장기 성장을 지원한다.
- 경제 밸런스를 원수치와 분리해 조정할 수 있다.
- UID 작품의 변화 원인을 설명하기 쉽다.

위험:

- 출처와 중복 계산 규칙을 엄격히 관리해야 한다.
- 가격 계산은 내부적으로 한 단계 더 복잡하다.

### B. 원수치 선형 가격 변환

```text
가격 기여 = 예술성 × 고정 계수
```

장점은 단순함이다. 그러나 고정 상한이 없는 수치와 결합하면 후반 가격이 무한 팽창하고, 예술성만 올리는 전략이 모든 경제 선택을 지배할 가능성이 높아 비채택한다.

### C. 예술성·명성·연대기를 하나의 작품 가치 점수로 통합

장점은 UI 항목이 적다는 것이다. 그러나 제작자의 미적 선택, 작품이 겪은 역사, 사회적 인지도를 구분할 수 없고 같은 사건이 여러 가치에 중복 반영될 위험이 커 비채택한다.

## 5. 권장 구조

### 5.1 원수치와 평가값 분리

```text
artistry = 작품 자체의 미적 완성 원수치
artistry_value = 시장·감정에서 해석한 점감 가치
customer_artistry_fit = 특정 고객의 예술성 적합도
```

- 화면에는 `artistry` 원수치만 표시한다.
- `artistry_value`와 `customer_artistry_fit`은 맥락별 계산 결과다.
- 계산 결과를 새로운 영구 능력치로 저장하거나 작품명에 붙이지 않는다.

### 5.2 최초 제작 예술성

모든 직접 제작 작품은 `artistry` 필드를 가지며 0도 정상 결과다.

허용 가능한 최초 생성 원천:

1. **기본 작품 설계의 미적 성향**
   - 의장검·의식용 무기처럼 조형을 중시하는 설계는 미적 기여 가능
   - 전투용 기본 설계도 예술성 0 이상을 가질 수 있음
2. **재료의 시각·가공 특성과 설계의 적합성**
   - 희귀도나 가격 자체가 아니라 색·결·광택·가공성·조합 적합성이 책임짐
   - 비싼 재료라고 자동으로 높은 예술성이 되지 않음
3. **직접 단조 결과 중 미적 완성 부분**
   - 제작 등급과 같은 판정을 복사하지 않음
   - 동일 제작 결과가 두 축에 영향을 줄 수 있어도, 제작 등급을 예술성 보너스표로 직접 변환하지 않음

현재 추가하지 않는 것:

- 별도 보조재료 슬롯
- 별도 장식 재료 슬롯
- 승인되지 않은 대장장이 숙련 능력치
- 재료 희귀도 × 제작 등급의 자동 예술성 배율

정확한 초기 분포와 기여량은 별도 테스트 프리셋에서 결정한다.

### 5.3 제작 후 성장 원천

예술성을 증가시킬 수 있는 원천은 명시적으로 예술성 책임을 가진 행동으로 제한한다.

#### 허용

- `ARTISTIC_FINISH` 정밀강화 방식
- 예술성 계열 촉매의 명시된 수치 효과
- 승인된 세공·마감·장식 콘텐츠
- 작품 설계를 미적으로 재작업하는 별도 의미 있는 공정

#### 자동 증가 금지

- 일반 강화 레벨 상승
- 고객에게 판매·증여
- 전시 횟수
- 감정 횟수
- 소유권 이전
- 명성 증가
- 연대기 사건 발생
- 동일 저비용 행동 반복

연대기와 명성은 작품의 맥락·사회적 가치에 영향을 줄 수 있지만 `artistry` 원수치를 직접 바꾸지 않는다.

### 5.4 촉매·수식어 중복 계산 방지

하나의 촉매 사용 결과가 다음 두 효과를 무제한 중복해서 만들면 안 된다.

```text
즉시 예술성 대폭 증가
+ 같은 예술성 값을 다시 배율로 증폭하는 촉매 수식어
```

원칙:

- 한 사건의 직접 예술성 증가는 한 번만 기록한다.
- 촉매 수식어는 미래 성장 경향, 조건부 고객 적합도, 특정 세공 효율 중 하나를 책임질 수 있다.
- 같은 원수치를 즉시 증가시키고 다시 전체 가격에 곱하는 이중 계산은 금지한다.
- `GRADE_AFFIX / CATALYST_AFFIX / CHRONICLE_AFFIX`는 예술성 원수치와 별도 필드·별도 원인을 유지한다.

### 5.5 손상·복원 경계

손상은 작품의 보이는 상태를 악화시킬 수 있으나, 영구 예술성 원수치 삭제 여부는 손상 시스템 Decision에서 확정한다.

현재 보호 계약:

- 단순 수리 반복으로 예술성 순증가 금지
- 복원만 수행했다면 손상 전 기록값을 초과하는 순증가 금지
- 손상 전 값을 넘는 증가에는 별도 예술적 재작업 비용과 결과가 필요
- 손상·복원 기록은 작품 UID에 남김

### 5.6 가격·감정 가치

권장 가격 구성:

```text
최종 가치
= 기능 가치
+ 제작 등급 가치
+ 예술성 점감 가치
+ 촉매 수식어 가치
+ 연대기 가치
+ 고객·시장 수요 보정
```

금지:

```text
전체 기본 가격 × 제작 등급 × 재료 × 예술성 × 연대기
```

예술성 점감 가치 규칙:

- 예술성이 증가하면 가치 기여는 감소하지 않는다.
- 추가 1점의 한계 가치는 높은 구간일수록 작아진다.
- 원수치 자체는 점감·압축하지 않는다.
- 구간 경계와 계수는 data 기반 테스트 프리셋으로 관리한다.
- 로그·제곱근을 코드에 직접 고정하기보다 **구간별 한계 가치 테이블**을 우선한다.

구간별 테이블 권장 이유:

- 디자이너가 이해·조정하기 쉽다.
- 모바일 UI에서 예상 가격 변화를 설명하기 쉽다.
- 회귀 테스트가 명확하다.
- 특정 콘텐츠 단계만 정밀하게 조절할 수 있다.

### 5.7 고객 선호

각 고객·일정은 다음 예술성 관심 유형 중 하나를 가진다.

```text
IGNORE      예술성을 성공·가격 판단에 사용하지 않음
SECONDARY   다른 핵심 능력치를 충족한 뒤 보조 가치로 사용
PRIMARY     주요 요구 능력치 중 하나
REQUIREMENT 최소 요구치 또는 선호 구간을 충족해야 함
```

초기 고객 권장 방향:

| 고객 | 기본 관심 유형 | 의미 |
|---|---|---|
| 검투사 | `SECONDARY` 또는 `IGNORE` | 성능·조작성 우선, 미적 가치는 제한적 보너스 |
| 모험가 | `IGNORE` 또는 `SECONDARY` | 환경 대응·내구·무게 우선 |
| 군인 | `IGNORE` | 표준화·안정성·비용 우선 |
| 귀족 | `PRIMARY` | 예술성·상징성·희소성을 주요 판단에 사용 |
| 후원자 | `PRIMARY` 또는 `REQUIREMENT` | 작가성·독창성·예술적 완성 요구 |
| 수집가 | `PRIMARY` | 예술성과 연대기를 서로 별도 평가 |
| 의식·행사 | `REQUIREMENT` | 최소 예술성뿐 아니라 재료·형식·상징 태그 요구 |

보호 조건:

- 높은 예술성이 검투사·군인 임무 성공률을 자동 상승시키지 않음
- 관심이 낮은 고객은 높은 예술성에 추가 비용을 지불하지 않을 수 있음
- 예술성 초과분 자체에 패널티를 주기보다 **지불 의사 한계**로 처리
- 모든 고객이 같은 예술성 구간을 선호하지 않음
- 고객 선호는 연대기 선호·촉매 선호와 별도로 계산

### 5.8 플레이어 정보 공개

작품 상세:

```text
예술성 27
```

예술성 변화 행동의 사전 정보:

- 결정적 결과: `예술성 +4`
- 확률적 결과: `예술성 +2~5 예상`
- 영향을 주지 않음: `예술성 변화 없음`

고객·시장 정보:

- `예술성 중요도: 높음`
- `현재 작품: 요구 충족`
- `초과 예술성의 추가 보상: 낮음`

정확한 내부 가격 공식을 모두 공개하지 않더라도, 플레이어가 선택 방향과 결과 원인을 설명할 수 있어야 한다.

## 6. 악용 방지 계약

1. 같은 정밀강화 이정표에서 예술성 결과 무한 재추첨 금지
2. 동일 저비용 세공 반복으로 무한 상승 금지
3. 수리·손상 반복으로 순증가 금지
4. 전시·감정·판매·증여 반복으로 원수치 증가 금지
5. 비싼 재료만으로 높은 예술성 보장 금지
6. 제작 등급이 예술성 최소값·상한·배율을 직접 결정하지 않음
7. 촉매의 즉시 증가와 수식어 배율 이중 계산 금지
8. 연대기 가치와 예술성 가치를 같은 사건으로 중복 합산 금지
9. 높은 예술성이 모든 고객·상황의 최적해가 되지 않음
10. 고수치 구간의 비용과 한계 가치가 모두 선형으로 유지되지 않음

```text
→ artistry 원수치 저장

예술성 책임 행동
→ 허용 출처·중복 여부 검사
→ 변화량 판정
→ artistry 갱신
→ UID에 기계적 변화 원인 기록

판매·감정·고객 판정
→ artistry 원수치 읽기
→ 예술성 점감 가치 계산
→ 고객 관심 유형·요구 구간 계산
→ 다른 가치 축과 한 번씩 합산
```

예술성 변화 원인 기록은 연대기 수식어를 자동 생성하지 않는다. 연대기는 의미 있는 실제 생애 사건 기준을 별도로 따른다.

## 8. 향후 TDD 승인 기준

구현 계획에서는 최소 다음 계약을 RED로 먼저 고정한다.

1. 예술성 0은 유효한 정상 작품이다.
2. 고정 설계 최대치가 존재하지 않는다.
3. 제작 등급이 예술성 최소값·최대값을 정하지 않는다.
4. 일반 강화만으로 예술성이 증가하지 않는다.
5. 허용된 예술성 책임 행동만 수치를 변경한다.
6. 같은 행동 결과가 예술성·촉매·가격에 이중 계산되지 않는다.
7. 예술성 가치 함수는 단조 증가하고 한계 가치는 구간이 높아질수록 감소한다.
8. 같은 예술성 작품도 고객 관심 유형에 따라 지불 의사와 적합도가 달라진다.
9. 감정·전시·판매·증여·연대기 발생은 예술성 원수치를 변경하지 않는다.
10. 복원만으로 손상 전 기록값을 초과하지 않는다.
11. 정확한 구간·계수는 승인 전 제품값으로 고정하지 않는다.
12. 제품 구현은 계속 `BLOCKED`다.

## 9. 별도 Decision으로 남기는 정확한 값

이 설계 승인만으로 다음 수치를 확정하지 않는다.

- 최초 제작 예술성 분포
- 작품 종류별 초기 기여 범위
- 재료 적합성 태그와 기여량
- `ARTISTIC_FINISH` 증가 범위·비용·성공률
- 촉매별 예술성 변화량
- 가격 점감 구간과 한계 가치 계수
- 고객별 최소 요구치와 선호 구간
- 손상 상태의 표시·유효 예술성 계산
- 저장 자료형과 overflow 보호

각 값은 테스트 프리셋과 사람 플레이 결과를 근거로 후속 승인한다.

## 10. 적대적 검토 결과

### 위험 1 — 예술성 메타 독점

높은 예술성이 가격과 모든 고객 판정에 동시에 강하면 실용 무기가 열등해진다.

대응:

- 고객 관심 유형 분리
- 기능 가치와 예술성 가치 분리
- 점감 가치와 지불 의사 한계

### 위험 2 — 희귀 재료·고등급의 삼중 배율

재료·등급·예술성을 전체 가격에 곱하면 희귀 재료만 정답이 된다.

대응:

- 출처별 가치 항목을 한 번씩 합산
- 희귀도가 아니라 미적 적합성 사용
- 제작 등급은 예술성 상한·자동 보너스가 아님

### 위험 3 — 연대기와 예술성 혼합

역사적 작품이 자동으로 미적으로 아름다워지면 제작 선택의 책임이 약해진다.

대응:

- 연대기는 별도 가치와 수식어
- 사건 발생만으로 예술성 원수치 변경 금지

### 위험 4 — 무한 반복 파밍

고정 상한이 없으므로 저비용 행동이 반복 가능하면 경제가 붕괴한다.

대응:

- 허용 출처 제한
- 이정표당 한 번
- 수리·전시·감정 루프 차단
- 높은 구간 비용 증가와 한계 가치 점감

### 위험 5 — 수식이 불투명해짐

점감 함수가 숨겨지면 플레이어가 결과를 이해하지 못한다.

대응:

- 원수치 항상 공개
- 변화량 또는 예상 범위 공개
- 고객 중요도·요구 충족·초과 보상 수준 공개

## 11. 완료 판정

이 설계는 다음을 만족할 때 승인 가능하다.

- 예술성 원수치와 가격·고객 평가값의 책임이 분리됨
- 최초 생성과 후천 성장의 허용 출처가 명확함
- 제작 등급·촉매·연대기와 중복 계산되지 않음
- 고정 상한 없이도 경제 인플레이션과 반복 파밍을 제어함
- 정확한 수치를 성급하게 제품값으로 확정하지 않음
- 후속 TDD 계약이 기계 판독 가능함
- 제품 구현 `BLOCKED` 유지
