# Blacksmith 내구도 0% 파괴 — 5회 적대적 검토

- 대상: `BS-ENHANCE-20260820-05`, `BS-ENHANCE-20260820-06`
- 상태: `PLAN_REVIEW_EVIDENCE`
- 기준 main: `e714b864ebbdbd73c0b0714f93296044dcf619ee`
- Human/Player evidence: `NOT_RUN`

## Loop 1 — 파괴 공포가 강화 자체를 막는가

전체 공격:
- 작품 UID·고객 생애가 애착을 키울수록 0% 영구 파괴는 플레이어가 좋은 작품에 강화 버튼을 누르지 못하게 만들 수 있다.
- 긴장감이 아니라 회피 행동만 강화될 위험이 있다.

검증:
- 현재 강화 코어는 `멈춤 vs 추가 도전`이므로 파괴 가능성 자체는 적합하다.
- 문제는 파괴 여부가 예측 불가능하거나 초기부터 빈번할 때다.

개선:
- `LEARN` 구간에는 파괴 위험 없음.
- 파괴 가능 구간은 사전 경고.
- 현재 내구도 %, 이번 시도 손상/파괴 가능성을 공개.
- 체크포인트로 이미 확보한 강화 진전은 단계 하락으로 전부 회수하지 않음.

재검사:
- 파괴는 선택 압박으로 남고, 기본 진행을 막는 랜덤 즉사로 사용하지 않는다.

## Loop 2 — 내구도가 반복 유지비 세금이 되는가

전체 공격:
- 내구도가 모든 하루/고객 일정/성공 강화에서 자동 감소하면 플레이어는 작품 생애보다 수리비를 관리하게 된다.
- 보조 시스템이 강화 코어보다 더 많은 클릭과 비용을 요구할 수 있다.

검증:
- 기존 Toren canon도 `모든 여정 자동 마모`를 금지한다.

개선:
- 성공 강화의 기본 내구도 감소 = 없음.
- 단순 날짜 진행/소유권 이전/전시 = 감소 없음.
- 강화 실패와 실제 인과가 있는 세계 사건만 내구도 감소.

재검사:
- 내구도는 긴장/사건 상태이지 일일 세금이 아니다.

## Loop 3 — 수리가 0% 파괴를 무의미하게 만드는가

전체 공격:
- 언제든 값싸게 100% 수리할 수 있으면 저내구도 위험이 형식적이다.
- 0%에서도 복원 가능하면 사용자 최신 `0% 파괴` 결정이 약해진다.

검증:
- FFXIV는 0%에서도 수리가 가능하지만 이것은 Blacksmith가 원하는 영구 파괴 긴장과 다르다.

개선:
- 1~99%에서만 일반 수리/복원 가능.
- 0%는 `DESTROYED` 고정.
- 수리 비용·작업량은 강화와 경쟁하는 기회비용.
- 현장 수리는 제한 회복만 허용.

재검사:
- 저내구도 판단의 실질적 의미 유지.

## Loop 4 — 영구 파괴가 작품 생애 정체성을 삭제하는가

전체 공격:
- 물리 아이템을 삭제하면서 UID·연대기까지 삭제하면 Blacksmith의 보조 차별점인 작품 기억이 가장 큰 실패 순간에 사라진다.

검증:
- 현재 코어 계층은 UID 생애를 강화 결과의 기억 증폭 장치로 유지한다.

개선:
- 0%에서 장비 사용/강화/일반 수리만 종료.
- UID·이름·최고 강화·소유·사건·파괴 원인·Chronicle provenance는 기록 보존.
- 미래 successor/relic 시스템이 생겨도 새 UID를 사용하고 이전 성장 수치를 복사하지 않음.

재검사:
- 물리적 상실은 강하지만 역사적 의미는 오히려 강화된다.

## Loop 5 — 정보 과잉 또는 숨은 파괴가 생기는가

전체 공격:
- 정확한 수치를 모두 펼치면 모바일 강화 화면이 계산기가 된다.
- 반대로 내구도 손실 범위나 파괴 가능성을 숨기면 불공정하다.

검증:
- 기존 UX는 핵심 이유 2~4개 progressive disclosure를 사용한다.

개선:
- P0 화면: 현재 단계/체크포인트/내구도 %/성공률/비용/주요 실패 결과/파괴 가능성/회복 진전/다음 체크포인트.
- 상세 수학·원인 계수는 Detail.
- 색상만으로 저내구도를 전달하지 않음.

재검사:
- 긴장 판단에 필요한 정보는 전면, 계산 상세는 후면.

## Better Alternative Search

### A. 내구도 0% = 사용 불가, 언제든 수리
- 접근성은 높지만 파괴 긴장이 약하다.
- 사용자 최신 결정을 충족하지 않는다.
- `REJECT`.

### B. 0~100% + 0% 물리 영구 파괴 + UID 기록 보존
- 강화 긴장과 작품 생애를 동시에 유지한다.
- `ADOPT`.

### C. 최대 내구도 자체가 영구 감소하고 0에서 파괴
- 장기 애착과 수리 결정을 만들지만 현재 단계에서 상태 변수가 하나 더 늘고 수리/복원 설계가 복잡해진다.
- `DEFER`.

### D. 파괴 시 완전 데이터 삭제
- 손실은 강하지만 Blacksmith의 UID 생애 차별점을 파괴한다.
- `REJECT`.

## 장기 적합성

현재 최선:

`VISIBLE_0_TO_100_DURABILITY + CAUSAL_DAMAGE_ONLY + REPAIR_WHILE_ABOVE_ZERO + DESTROY_AT_ZERO + UID_HISTORY_PRESERVED`

재검토 조건:
- 플레이어가 저내구도에서 항상 멈춰 고위험 강화가 사실상 사용되지 않음.
- 수리 때문에 강화보다 유지보수 시간이 길어짐.
- 파괴 경험이 긴장보다 세션 종료/이탈을 더 강하게 유발함.
- UID 기록 보존이 파괴 감정을 희석해 상실감이 사라짐.
- 파괴된 작품 수가 누적되어 UI/저장/콘텐츠 관리 부담을 만듦.
