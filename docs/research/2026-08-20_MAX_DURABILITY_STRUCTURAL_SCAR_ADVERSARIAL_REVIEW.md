# Blacksmith 최대 내구도 구조 손상 — 5회 적대적 검토

- 대상: `BS-ENHANCE-20260820-07~08`
- 상태: `PLAN_REVIEW_EVIDENCE`
- Human/Player evidence: `NOT_RUN`

## Loop 1 — 수리로 리스크가 사라지는가

공격:
- CURRENT만 수리할 수 있고 MAX가 그대로라면 수리는 완전 리셋이 아니다.
- 그러나 MAX가 강화에 아무 영향도 주지 않으면 결국 수리만 하면 동일한 강화가 가능해 사용자의 목표를 달성하지 못한다.

개선:
- MAX 상태가 강화 성공 기대에 직접 페널티를 준다.
- 심각 구조 손상에서는 미래 강화 성장량도 감소한다.

재검사:
- CURRENT 수리는 즉사 위험을 낮추지만 누적 구조 리스크는 제거하지 못한다.

## Loop 2 — 죽음의 나선인가

공격:
- MAX가 낮아질수록 성공률↓, 기존 공격력↓, 파괴 위험↑를 동시에 적용하면 한 번 손상된 작품은 회복할 이유가 없다.

개선:
- 기존 획득 성능은 소급 삭감하지 않는다.
- 성공률 페널티를 먼저 적용하고, MAX 60% 이하부터 신규 강화 성장량만 감소한다.
- MAX 감소 자체로 파괴 확률을 자동 추가 상승시키지 않는다.

재검사:
- 손상은 의미 있지만 작품의 과거 가치가 즉시 증발하지 않는다.

## Loop 3 — MAX 손상이 유지비 세금이 되는가

공격:
- 일반 실패마다 MAX가 깎이면 장기적으로 모든 작품이 반드시 파괴되는 단순 소모품이 된다.

개선:
- `FAIL_HOLD / FAIL_DOWNGRADE / FAIL_DAMAGE`는 MAX 기본 유지.
- `FAIL_CRITICAL_DAMAGE`와 명시적인 구조 손상 사건만 MAX를 감소시킨다.
- 성공 강화와 단순 시간 경과는 MAX를 깎지 않는다.

재검사:
- MAX 손상은 고위험 선택의 흉터이지 일상 유지비가 아니다.

## Loop 4 — 수리가 무의미해지는가

공격:
- MAX 페널티가 모든 리스크를 지배하면 CURRENT 수리는 장식 행동이 된다.

개선:
- CURRENT 0%는 즉시 물리 파괴이므로 수리는 여전히 직접적인 생존 선택이다.
- 수리하면 CURRENT를 MAX까지 올려 다음 심각 손상에 대한 버퍼를 확보한다.
- MAX는 장기 리스크, CURRENT는 단기 생존 리스크로 역할을 분리한다.

재검사:
- `수리할까 / 그대로 한 번 더 갈까` 선택은 살아 있고, 수리가 장기 구조 리스크를 삭제하지는 않는다.

## Loop 5 — 모바일에서 계산표가 되는가

공격:
- CURRENT, MAX, 성공률, 구조 페널티, 실패 누적 회복, 효과 배율을 모두 숫자로 펼치면 핵심 DDD 리듬이 깨진다.

개선:
- 기본 화면은 `CURRENT / MAX`, 구조 상태 이름, 최종 성공 기대, 주요 손실, 신규 강화 효과 배율만 전면 표시한다.
- 상세 보기에서만 기본 성공률→회복→구조 페널티 계산을 설명한다.
- 원인은 2~4개로 제한한다.

재검사:
- 플레이어는 `왜 불리한지`를 이해하면서도 한 화면에서 판단 가능하다.

## Better Alternative Search

### A. MAX가 성공률만 감소
- 단순하지만 확률표 게임으로 수렴하기 쉽다.

### B. MAX가 현재 작품 성능을 직접 감소
- 손상 체감은 강하지만 애착 작품 폐기 압력이 과도하다.

### C. 성공률 페널티 우선 + 심각 손상 시 미래 강화 효과 감소
- 현재 가치 보존과 장기 흉터를 동시에 만족한다.
- 사용자 요구인 `수리로 강화 리스크 제거 불가`를 가장 직접적으로 해결한다.

최종 권장: **C**.
