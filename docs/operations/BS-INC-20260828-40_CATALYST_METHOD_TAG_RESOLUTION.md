## 교정

```text
TAG_KEYWORD_SOURCE = CATALYST_LINEAGE_AND_PRECISION_METHOD
TAG_KEYWORD_RESOLUTION = CATALYST_LINEAGE_AND_PRECISION_METHOD_GOVERN_TAG_IDENTITY
PRECISION_METHOD_EFFECT_SCOPE = WEAPON_STATS_DURABILITY_AND_TAG_RESOLUTION_CONTEXT
PRECISION_METHOD_TAG_ROLE = TAG_IDENTITY_RESOLUTION
PRECISION_METHOD_CANNOT_AFFECT_GRADE_OR_EVENT_KEYWORD = TRUE
EMPTY_CATALYST_LINEAGE_BEHAVIOR = UNDECIDED / BLOCKS_TAG_WRITE_IMPLEMENTATION
```

`+9 -> +10` 성공은 계속 기존 `CATALYST_AFFIX`에 정확히 하나의 weapon-owned
Tag keyword만 기록한다. 촉매 계보는 후보 가족·계보 범위를, 강화 방식은 그
범위 안의 Tag identity 해석 문맥을 함께 제공한다. 방식은 무기 능력치와
내구도에도 영향을 줄 수 있으나 Grade/Event keyword, player title, 네 번째
affix slot, function-rework, 예술성 또는 환경 기능을 만들지 않는다.

## 영향과 미결정

- `WEAPON_KEYWORD_CONTENT_ID`, 표시 문구, 촉매 계보·방식의 실제 조합표는
  `UNDECIDED / USER_CONTENT_DECISION_REQUIRED`다.
- 빈 촉매 계보의 `+10` 선택·기본값·차단 흐름은 `UNDECIDED`다.
- 따라서 Tag write/presentation과 임시 placeholder 노출은 여전히 구현
  범위 밖이다. 이 교정은 production code, data, Scene, Resource, asset,
  probability, cost, durability curve, 또는 `+20` Precision을 변경하지 않는다.

## Lesson

한 입력이 item identity와 수치 양쪽에 영향을 줄 때, **어떤 결과를 결정하는지**와
**결정하지 않는 결과가 무엇인지**를 같은 owner에 명시해야 한다. 그러나 이 사례의
세 affix slot, +10 cadence, 촉매·방식 조합은 Blacksmith 고유 제품 의미이므로
Base 승격 대상이 아니다.
