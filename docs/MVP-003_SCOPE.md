## 1. MVP-003 당시 목표

플레이어가 자신이 만든 철검을 기억하고, `+5`에서 납품할지 `+10`까지 더 도전할지 판단하며, 그 선택이 검투사의 지연된 결과와 장비 이력에 영향을 줬다고 이해하는지 탐색했다.

당시 플레이 흐름:

```text
검투사 의뢰 확인
→ 철검 제작
→ 정밀 결과와 영구 완성도 결정
→ +5 기본 납품 조건
→ 납품 또는 +10 추가 도전
→ 납품
→ 수동 하루 종료
→ 지연 경기 결과
→ 장비 이력·명성·관계 갱신
→ 같은 검투사 재방문
```

이 흐름은 현재 첫 코어 버티컬 슬라이스가 아니다.

## 5. 최신 정본과의 차이

현재 승인된 첫 코어 증명:

```text
플레이어가 선택한 작품 한 점 제작
→ +10/+20/+30/+40/+50 정밀 이정표
→ 방문 고객 납품
→ 즉시 인과 결과
→ 피로도·날짜·세계일정
→ 같은 UID 재방문
→ 손상·복원·재강화·후속 판단
→ 작품 생애가 다음 강화 이유로 환류
```

주요 변경점:

- `+5/+10`은 역사 PoC 체크포인트이며 현재 데모 종료 구조가 아니다.
- 현재 검증 상한은 `+50`; 최종 장기 상한은 `DEFERRED`다.
- 일반 수식어는 A·B 두 개다.
- 세계일정 성질은 활성 사건·연대기 수식어 한 개의 진화 계보다.
- 손상·대파는 UID·연대기를 유지하고 수식어를 삭제하지 않으며 잠금·복원할 수 있다.
- 일반 실패의 즉시 영구 파괴는 현재 규칙이 아니다.
- 코어 통과는 행동 증거와 회상 인터뷰가 일치해야 한다.
