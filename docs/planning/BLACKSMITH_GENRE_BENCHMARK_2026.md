> 상태: `PLANNING_IN_PROGRESS`
>

>
> 목적: 현재 확정된 블랙스미스 구조를 유지한 채, 대장간·상점 운영 게임과 고강화 RPG의 설계 사례를 비교해 추가·개선 후보를 식별한다.

> 효력: 이 문서의 신규 제안은 모두 `PROPOSED_ONLY`다. 기존 책임 문서의 확정 규칙을 자동으로 변경하지 않는다.

## 1. 벤치마크 기준

비교 대상을 두 축으로 나눈다.

1. 대장간·상점 운영 축
   - 제작과 판매의 반복 동기
   - 고객 관계와 주문
   - 제작법·도감·명성
   - 운영 피로도와 자동화
2. 고강화 RPG 축
   - 실패 손실과 보호
   - 누적 실패 보정
   - 수식어 선택권
   - 저단계 반복 완화
   - 장비 교체 시 진행 보존

블랙스미스의 비교 기준은 다음과 같다.

- 강화 클릭 루프를 약화시키지 않는가
- 고객 생애주기와 장비 이력을 강화하는가
- POC에서 실제로 체험·검증할 수 있는가
- 새 재화·새 게이지·새 관리 화면을 불필요하게 늘리지 않는가
- 실패가 무의미한 시간 손실이 되지 않는가

## 2. 대장간·상점 운영 게임 비교

### 2.1 Shop Titans

관찰 요소:

- 장비 제작, 상점 판매, 영웅 장비 지급, 영웅 파견, 재료 회수의 순환
- 제작 반복에 따른 설계도 숙련·가치 상승
- 원소·정령 효과를 통한 조합형 장비 성장
- 영웅·챔피언·길드·세계 시장으로 장기 목표 확장
- 2026년 로드맵에서도 컬렉션·상위 성장·신규 티어를 지속 확장

블랙스미스에 유효한 교훈:

- 제작법 친숙도와 도감은 반복 제작의 장기 동기가 될 수 있다.
- 장비를 고객에게 제공한 뒤 그 고객이 다시 재료·기록·이야기를 가져오는 순환은 강하다.
- 다만 글로벌 시장, 길드, 끝없는 신규 티어는 현재 POC 범위를 과도하게 넓힌다.

판정:

- 제작법 친숙도, 고객 장비 회수, 도감·전시 구조는 현재 기획을 유지한다.
- 글로벌 플레이어 시장과 길드 시스템은 POC 및 초기 출시 범위에서 제외한다.

### 2.2 Holy Potatoes! A Weapon Shop?!

관찰 요소:

- 대장장이 인력을 관리해 무기를 제작하고 모험가에게 판매
- 고객 충성도를 통해 고객 이야기를 추가로 확인
- 재료·유물·마법 부여 탐색
- 무작위 사건과 지역 확장

블랙스미스에 유효한 교훈:

- 반복 방문 고객의 관계 성장이 단순 가격 보너스보다 강한 장기 보상이 된다.
- 제작 결과가 고객 이야기와 다음 주문으로 연결되어야 장비가 소모품에 머물지 않는다.

판정:

- 고객 생애주기, 재방문, 장비 이력은 블랙스미스의 핵심 차별점으로 더 선명하게 노출해야 한다.
- 직원 다수 관리와 지역별 생산망은 현재 클릭 중심 코어와 충돌하므로 도입하지 않는다.

### 2.3 Potion Craft

관찰 요소:

- 고객 문제에 맞는 상품을 판단해 판매
- 잘못된 상품 판매가 관계와 세계에 결과를 남김
- 조합 실험과 제작법 발견
- 여행 상인과의 선택형 흥정
- 제작품 이름·외형·진열을 통한 소유감 강화

블랙스미스에 유효한 교훈:

- 고객 적합도는 수치보다 이유와 결과가 중요하다.
- 모든 거래를 흥정 미니게임으로 만들지 않고, 특별 거래에만 집중하는 편이 흐름을 보호한다.
- 등록된 제작법은 반복 실험을 줄이고 숙련감을 제공해야 한다.

판정:

- 일반 공개시장은 즉시 고정 매입가를 유지한다.
- 고객·수집가·중개인 등 특별 거래에만 짧은 흥정을 유지한다.
- 정밀강화 등록 조합은 성공 시 수식어 정체성과 계보를 보장하는 현재 방향을 유지한다.

### 2.4 Anvil Saga

관찰 요소:

- 주문 수락과 거절이 상충하는 세력 관계에 영향을 줌
- 명성과 고유 주문이 상위 고객을 유치
- 선택의 결과가 세계와 서사에 누적
- 직원·시설·공간 운영 비중이 큼

블랙스미스에 유효한 교훈:

- 군사 보급, 밀수, 국가 영향력은 독립 미니게임보다 하나의 세계 갈등으로 읽혀야 한다.
- 계약 수락 전에 어느 세력·수치가 움직이는지 예측 가능해야 한다.

판정:

- 군사·밀수·국가 선택의 예상 방향을 사전 카드로 표시하는 개선 후보가 필요하다.
- 직원 숙소·급여·행복도 관리는 POC에 추가하지 않는다.

### 2.5 Blacksmith Master / Forge Industry

관찰 요소:

- 원료 채굴부터 제련·가공·판매까지 생산 체인 전체 관리
- 공간 배치와 처리량 최적화
- 주문으로 신규 능력·시장·생산품 해금
- 자동화·직원 위임을 통한 대규모 생산

블랙스미스에 유효한 교훈:

- 자동화는 반복 저위험 작업의 피로를 줄이는 용도로 제한해야 한다.
- 생산망 전체를 관리하게 만들면 강화 한 점의 위험·판매 판단이 희석될 수 있다.

판정:

- 저위험 반복의 후반 편의는 검토한다.
- 채굴·운송·직원 배치·공장 처리량을 코어 시스템으로 확장하지 않는다.

### 2.6 Merchant / Moonlighter 계열

관찰 요소:

- 모험 또는 파견으로 재료·상품을 확보하고 상점 판매로 재투자
- 비동기·세컨드 스크린 운영에 적합한 짧은 확인 루프
- Moonlighter 계열은 상품 가격 반응과 일일 수익 목표로 상점 운영 긴장을 형성
- 반복 흥정과 다수의 동시 비용 목표는 피로·불안 요소가 될 수 있음

블랙스미스에 유효한 교훈:

- 하루에 하나의 명확한 운영 목표가 있으면 여러 시스템이 한 세션으로 묶인다.
- 반대로 모든 거래에 수동 가격 설정과 흥정을 요구하면 강화 흐름이 끊긴다.

판정:

- 선택형 `오늘의 대장간 목표` 후보를 검토한다.
- 일반 상품의 수동 가격 설정은 도입하지 않는다.

## 3. 고강화 RPG 비교

### 3.1 Lost Ark

관찰 요소:

- 장비 이전으로 기존 강화 진행을 새 장비에 옮겨 교체 손실을 줄임
- 고급 강화는 정해진 경험 증가와 누적 보정 효과를 병행
- 2026년 진행 개편에서 낮은 구간의 강화 제거, 비용 감소, 일괄 강화와 결과 애니메이션 단축을 적용

블랙스미스에 유효한 교훈:

- 플레이어가 이미 충분히 학습한 저위험 반복은 후반에 압축할 수 있다.
- 실패가 반복될 때 최소한 다음 시도에 의미 있는 누적이 남아야 한다.
- 장비 교체 손실 완화는 필요하지만, 블랙스미스에서는 장비 자체의 생애와 판매 결정을 훼손하지 않아야 한다.

판정:

- 수동 체험 완료 후 저위험 구간만 제한적으로 묶는 `연속 강화` 후보를 검토한다.
- 전체 강화 이전은 도입하지 않는다. 대신 기존 장비의 판매·교환·전시·복원 가치를 유지한다.

### 3.2 Black Desert

관찰 요소:

- 실패 시 Agris Essence가 누적되고, 일정량에 도달하면 Ancient Anvil로 100% 성공
- 누적 실패 기록은 일부 장비군에서 동일 강화 단계 간 공유·보존
- Cron Stone은 파괴·하락 위험을 줄이는 별도 보호 수단

블랙스미스에 유효한 교훈:

- 긴 실패 구간에는 명확한 최악 상한이 필요하다.
- 보호 수단과 성공 보장 수단은 역할을 분리해야 한다.
- 누적 보정 비용이 결과물 시장가보다 과도하게 커지면 보장 장치가 오히려 함정이 될 수 있다.

판정:

- 보호석은 파괴 방지, 회복석은 복구라는 현재 역할 분리를 유지한다.
- 별도의 무한 실패 스택을 추가하기보다 기존 강화 특수 타격 충전·실패 기여를 하나의 최악 상한 구조로 정리하는 후보를 검토한다.

### 3.3 Diablo IV

관찰 요소:

- 2026년 아이템 여정 개편에서 Tempering은 원하는 수식어를 직접 선택하는 방향으로 변경
- 수식어는 한 개로 줄이고 충전 복구를 허용해 아이템 폐기 압력을 완화
- Masterworking은 품질 상승의 선형 경로와 마지막 특수 보상으로 역할을 분리
- 이전 개편에서도 비이정표 애니메이션 제거, 결과 수치·범위 표시, 실패 제거 등 반복 마찰을 줄임

블랙스미스에 유효한 교훈:

- 수식어 정체성과 수치 변동을 동시에 무작위화하면 장비가 쉽게 폐기 대상으로 변한다.
- 등록된 조합에서는 수식어 정체성을 확정하고, 변동성은 성공 여부와 세부 강도에 남기는 편이 낫다.
- 비핵심 반복 연출은 숙련 이후 축약할 수 있다.

판정:

- 정밀강화의 `등록 조합 = 수식어 정체성·계보 보장`을 유지한다.
- 미등록 조합도 완전 무작위보다 후보 계열을 명확히 예고해야 한다.
- 정밀강화 결과 화면에는 결과 수치와 가능한 범위를 함께 표시하는 후보를 채택 검토한다.

## 4. 현재 구조의 경쟁 우위

벤치마크 결과, 다음은 구조 변경보다 더 강하게 노출해야 할 차별점이다.

1. 장비 한 점의 생애
   - 제작자, 고객, 사건, 손상, 복구, 전시, 판매 이력이 하나의 기록으로 이어짐
2. 고객의 자율성
   - 플레이어 조언은 확률과 성향을 바꾸지만 고객을 직접 조종하지 않음
3. 강화 메인 빌드
   - 고강화 한계와 안정·성능·효율 분기가 같은 메인 포인트를 경쟁
4. 정밀강화의 작은 상태 공간
   - 정밀 등급 1개와 수식어 2개로 읽기 쉬움
5. 판매 채널 책임 분리
   - 공개시장 즉시 매입과 특별 거래의 흥정을 분리
6. 세계 반응
   - 군사 보급, 밀수, 국가 사건, 수집가가 동일 장비 이력에 반응

## 5. POC 필수 보강 후보

다음 네 항목은 새로운 장기 시스템이 아니라, 이미 기획한 요소를 실제로 체험·이해시키기 위한 보강이다.

### P1. POC 시나리오 런처와 체험 패스

상태: `PROPOSED_ONLY / HIGH_PRIORITY`

목적:

- 긴 자연 성장 없이 파괴·보호·회복·고위 정밀강화·고객 재방문·국가·밀수를 모두 검증
- 결정적 seed와 자원 프리셋으로 동일 장면 재현

구성:

- 핵심 루프 시작
- 정밀강화 실패
- 보호석 파괴 방지
- 고객 장비 손상·복구
- 검투사 재방문
- 군사 보급과 국가 사건
- 밀수 적발
- 역사 장비·전시·수집가

이 기능은 POC·QA 도구이며 출시 플레이 메뉴에 그대로 노출하지 않는다.

### P2. 장비 연대기 요약 카드

상태: `PROPOSED_ONLY / HIGH_PRIORITY`

장비 상세와 결과 보고에서 다음을 한 화면에 요약한다.

- 제작일과 제작 완성도
- 10강 이정표별 정밀강화 결과
- 주요 강화 실패·손상·복구
- 고객 소유와 활동 기록
- 군사·국가·밀수 사건
- 판매·교환·전시 상태

목적:

- 블랙스미스만의 핵심 차별점을 플레이어가 실제로 인식하게 함
- 외부 테스트에서 장비 기억률을 측정할 수 있게 함

### P3. 위험·결과 사전 카드

상태: `PROPOSED_ONLY / HIGH_PRIORITY`

강화·계약·밀수·국가 선택 전에 다음을 표시한다.

- 가능한 최악 결과
- 보호석 사용 시 달라지는 부분
- 영향을 받는 세계 수치 방향
- 확정 손실과 확률 손실 구분
- 결과가 언제 판정되는지

정확한 숨은 확률은 공개하지 않고 `매우 낮음~매우 높음`과 이유를 유지한다.

### P4. 오늘의 대장간 목표

상태: `PROPOSED_ONLY / MEDIUM_PRIORITY`

- 하루에 선택 가능한 목표 1개
- 예: 특정 장비 +30 달성, 고객 약속 이행, 군사 납품, 역사 장비 복원
- 목표 미선택·실패에 불이익 없음
- 보상은 작은 명성·기록·도감 진척 중심
- 메인 강화 수익을 대체하지 않음

목적:

- 여러 시스템을 한 세션의 의도로 묶음
- 체크리스트형 일일 숙제로 변질되는 것을 방지

---

## 6. POC 이후 검토 후보

### P5. 숙련 후 저위험 연속 강화

상태: `PROPOSED_ONLY / POST_POC`

- 해당 구간을 수동으로 충분히 체험한 뒤 해금
- 개별 판정·재료 소모·기록은 유지
- 위험 단계 진입, 실패, 재료 부족, 10강 이정표에서 자동 정지
- 고위험 구간과 정밀강화는 항상 수동

### P6. 기존 특수 타격 충전의 최악 상한화

상태: `PROPOSED_ONLY / POST_POC`

- 새 실패 스택을 만들지 않음
- 기존 강화 기여도·특수 타격 충전에 실패 기여를 명확히 포함
- 장기 실패 후 선택 가능한 강한 안전 행동을 제공
- 100% 성공보다 파괴 방지·하락 제한·재료 절약 중 하나를 선택하는 방향 우선

### P7. 등록 조합의 선택권 강화

상태: `PROPOSED_ONLY / POST_POC`

- 등록 조합은 수식어 정체성과 계보 확정
- 실패 여부와 세부 강도만 변동
- 미등록 조합은 후보 계열·호환도·불가능 결과를 사전 표시

### P8. 경제 목표와 비용 우선순위 안내

상태: `PROPOSED_ONLY / POST_POC`

- 다음 한계 돌파, 시설, 회복, 재료 구매를 동시에 강제하지 않도록 비용 곡선 분산
- UI에 `다음 의미 있는 투자`와 현재 보유 재화 대비 부족량 표시
- 자동 추천은 참고 정보이며 플레이어 결정을 대신하지 않음

## 7. 도입하지 않을 요소

현재 코어와 충돌하거나 범위를 과도하게 넓히므로 다음은 권장하지 않는다.

- 글로벌 플레이어 시장
- 길드·협동 도시 투자
- 직원 급여·숙소·행복도 관리
- 채굴·운송·공장 배치 중심 생산망
- 모든 거래의 수동 가격 설정
- 모든 고객과의 반복 흥정
- 장비 강화 전체 이전
- 수식어 정체성과 수치의 완전 이중 무작위
- 고위험 강화의 완전 자동화
- 보상 때문에 강제되는 다수의 일일 임무

## 8. 우선순위 결론

벤치마크로 확인된 가장 큰 누락은 신규 장기 시스템이 아니다.

현재 기획한 장비 생애·강화 위험·세계 반응을 플레이어가 한눈에 이해하고, POC에서 반복 재현할 수 있는 표현·검증 장치가 부족하다.

권장 우선순위:

```text
POC 시나리오 런처
→ 장비 연대기 요약 카드
→ 위험·결과 사전 카드
→ 오늘의 대장간 목표
→ POC 검증
→ 저위험 연속 강화 및 실패 상한 검토
```
