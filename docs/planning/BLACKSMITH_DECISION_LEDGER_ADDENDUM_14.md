# 블랙스미스 결정 원장 추가 기록 14

> 상태: `PLANNING_IN_PROGRESS`
>
> 기준일: 2026-07-26
>
> 주제: 실패 완충 타격과 보호석의 최종 상호작용

---

## 1. 사용자 승인

사용자는 다음 권장안을 승인했다.

- 보호석 없이 실패 완충 타격을 사용한 하락 1은 `유지`로 완화한다.
- 보호석 없이 실패 완충 타격을 사용한 하락 2는 `하락 1`로 완화한다.
- 보호석 없이 파괴가 나오면 실패 완충 타격을 사용했어도 장비는 즉시 영구 소멸한다.
- 보호석 사용 시 자연 하락 1·2는 기존 규칙대로 `유지`가 된다.
- 보호석과 실패 완충 타격을 함께 사용하고 파괴가 나오면 보호 파괴 하락량을 2단계 줄인다.
- 완충된 보호 파괴의 최소 하락량은 3단계다.

---

## 2. 승인된 공식

```text
기본 보호 파괴 하락량
= MAX(3, FLOOR(시도 직전 현재 강화 단계 ÷ 10))
```

```text
완충 병용 보호 파괴 하락량
= MAX(3, 기본 보호 파괴 하락량 - 2)
```

대표 예시:

| 시도 직전 단계 | 기본 보호 파괴 | 완충 병용 결과 |
|---:|---:|---:|
| +51 | -5 → +46 | -3 → +48 |
| +60 | -6 → +54 | -4 → +56 |
| +80 | -8 → +72 | -6 → +74 |
| +99 | -9 → +90 | -7 → +92 |

---

## 3. 시스템 역할

- 보호석은 영구 소멸을 막는 유일한 일반 강화 보호 수단이다.
- 실패 완충 타격은 비파괴 실패를 완화하고, 보호석과 병용했을 때 보호 파괴의 진행 손실을 줄인다.
- 실패 완충 타격은 보호석을 대체하지 않는다.
- 두 수단을 선택한 유효 시도가 시작되면 성공·실패와 관계없이 보호석과 충전값을 모두 소비한다.
- 보호 파괴 후 장비는 별도 손상 상태나 수리 없이 즉시 사용 가능하다.

---

## 4. 충돌 해결

기존 `안정 타격: 실패 완충 사용 시 하락 2를 하락 1로 완화`는 새 기본 실패 완충 효과와 중복된다.

결정:

- 기존 안정 타격 추가 효과: `SUPERSEDED`
- 안정 타격 전문화 자체: 유지
- 안정 타격 대체 효과: `REVIEW_REQUIRED`
- 대체 효과 승인 전 추가 보너스: 없음

이는 단순 수치 조정이 아니라 전문화의 역할과 빌드 정체성을 바꾸는 문제이므로 후속 중요 기획으로 분리한다.
