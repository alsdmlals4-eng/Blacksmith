## 2. 설계 질문

1. 단조 손맛을 짧은 모바일 입력으로 어떻게 전달할 것인가?

## 4. 채택

### 제작 과정이 주 입력

결과 화면만 보는 구조 대신 망치 입력과 즉시 금속 반응이 제작 감각을 담당한다.

### 고객은 작품의 다음 삶

고객은 최고가 버튼이 아니라 장비가 어떤 인물·사건·기록으로 이어질지 선택하는 채널이다.

### 판매 후 장비 환류

판매한 장비는 삭제되지 않고 소유권이 이전되며, 결정적 장면·관계·장비 연대기로 돌아온다.

### 작품은 여러 축으로 비교

단일 전투력 대신 다음을 함께 사용한다.

- 강화 단계
- 제작 등급
- 계보 수식어
- 보조 수식어
- +50 진화 형태
- 장비 연대기

## 5. Blacksmith에 맞게 변형

| 벤치마크 원리 | Blacksmith 적용 |
|---|---|
| 긴 제작 공정 | 30~90초 안에 첫 제작 반응·강화 진입 |
| 다수 고객·파벌 | 카시아 대표 흐름 + 에르사 별도 증명 세트 |
| 영웅 모험 환류 | 전투 전체가 아닌 결정적 장면·기여 원인·연대기 |
| 폭넓은 생산 체인 | 단조·강화·판매·세계 환류만 Vertical Slice 코어 |
| 온라인 시장 | 미래 명작 전당만 계획, 핵심 플레이는 오프라인 |
| 많은 속성·스킬 | 계보 1개 + 보조 최대 2개 |

## 7. 정합화된 P1 기본안

### 불씨 정령 모닥

- 비성장형 상징 동반자
- `BS-MODAK-20260731-01`: C안의 차분한 표정과 밝은 노랑·주황 불꽃 몸체
- 숯 껍질 몸체는 사용하지 않음
- 어두운 디테일은 손·발·목 장식 등에만 제한
- 한 번에 한 문장의 짧은 안내
- 확률·정답·결과 예측 금지
- 성장·재화·능력 보정 없음

대표 대사:

- `불이 올랐어. 지금 쳐.`
- `비용과 위험을 먼저 봐.`
- `여기서 완성해도 좋아.`
- `어떤 작품으로 남길래?`
- `이 작품의 기록은 남길게.`

### 대표 검투사 카시아 벨란

- 중견 검투사, 상위 투기장 진출 목표
- 무기 범주 요청
- 성능·명성·계보·경기 이력을 공개 가치 방향으로 사용
- 판매 후 대표 선택은 `경기 전 조율 지원`
- 배팅은 선택적 변형이며 대표 흐름·합격 조건에서 제외

### 수집가 에르사 로엔

- 이동 전시회를 운영하는 수집가 겸 감정인
- 방어구 범주 요청
- 제작 등급·희소성·계보·연대기를 평가
- 대표 픽스처 `별철 의식 방패`는 고객의 특정 아이템 요구가 아님
- 검투사와 같은 요청·판매·소유권·저장 구조 재사용

## 8. +50 대표 진화

| 후보 | 방향 | 가치 분포 |
|---|---|---|
| 성벽파쇄 | 파쇄·중량·결정적 충격 | 경기 직접 기여 중심 |
| 용광의 심장 | 잔화·연속 압박·화로 정체성 | 경기·제작 정체성 균형 |
| 투기장의 맹세 | 명예·안정·기록 | 관계·명성·수집 가치 중심 |

세 후보는 총가치 예산을 유사하게 유지하고 전투·관계·시장·연대기 분포만 다르게 한다. 어느 후보도 모든 축에서 우월하지 않는다.

## 10. 첫 5분 UX

```text
0~30초: 망치 입력과 즉시 반응
30~60초: 제작 등급 확인과 첫 강화 진입
1~3분: 단계·성공률·비용·위험 학습
3~5분: +5 완성 또는 +10 도전 비교
```

금지:

- 연속 모달
- 긴 세계관 설명
- 정답 버튼 강조
- 첫 5분 안의 고객·세계·서버 설명
- 모닥 대사로 확률·비용 대체

첫 5분은 Vertical Slice UX 목표이며 출시 경제 속도 확정값이 아니다.

## 11. 모바일 정보 위계

### 장비 카드

```text
이름
→ 제작 등급 + 강화 단계
→ 계보
→ 보조 최대 2개
→ 진화 형태
→ 소유자·운명 상태
→ 최근 연대기
```

### 고객 비교

```text
요청 범주·남은 영업일
→ 고객 가치 방향
→ 공개 적합 이유
→ 가격
→ 예상 관계·후속 방향
→ 최종 확인
```

### 입력

- 주요 터치 대상 최소 48dp
- 비가역 버튼은 하단 고정 영역
- 같은 위치에 위험도가 다른 행동을 빠르게 교체하지 않음
- 기능 아이콘에 고유 접근성 설명 제공
