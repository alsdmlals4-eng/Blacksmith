## 1. 설계 질문

이번 벤치마킹은 다음 질문에 답하기 위해 수행했다.

1. 단조 손맛을 짧은 모바일 입력으로 어떻게 전달할 것인가?
2. 고객이 장비를 사는 행위를 단순 가격 비교가 아니라 작품 선택으로 만들 수 있는가?

## 3. 채택·변형·제외

### 3.1 채택

1. **제작 과정 자체가 주 입력이어야 한다.**
   - Potion Craft의 물리적 도구 상호작용처럼, 결과 화면만 보는 것이 아니라 망치 입력이 제작 감각을 담당한다.
2. **고객은 작품의 다음 삶을 결정하는 선택지다.**
   - Anvil Saga처럼 의뢰와 관계가 결과에 영향을 주되, 대규모 파벌 정치까지 확장하지 않는다.
3. **판매 후 장비가 다시 돌아와야 한다.**
   - Shop Titans의 영웅 환류 원리를 장비 연대기와 결정적 장면으로 변형한다.
4. **제작물은 세계 연결 도구다.**
   - While the Iron's Hot처럼 제작 결과가 다른 인물과 사건을 변화시키게 한다.
5. **작품의 정체성은 단일 전투력보다 여러 축으로 읽힌다.**
   - 제작 등급, 강화 단계, 계보·보조 수식어, 진화, 연대기를 함께 보여준다.

### 3.2 Blacksmith에 맞게 변형

| 벤치마크 원리 | Blacksmith 변형 |
|---|---|
| 긴 제작 공정 | 30~90초 안에 첫 작품과 첫 강화에 진입하는 짧은 세로형 조작 |
| 다수 고객·파벌 | 대표 검투사 1명 + 별도 수집가 증명 세트 |
| 영웅 모험 환류 | 자동 경기의 결정적 장면 + 장비 기여 원인 + 연대기 |
| 폭넓은 생산 체인 | 단조·강화·판매·세계 환류만 Vertical Slice 코어로 유지 |
| 온라인 시장 | 미래 명작 전당만 계획하고 핵심 플레이는 오프라인 유지 |
| 많은 속성·스킬 | 계보 1개 + 보조 2개로 모바일 정보량 제한 |

### 3.3 제외

- 직원 고용·임금·시설 방 확장
- 채굴·벌목·농장 등 전체 자원 생산 체인
- 실시간 탐험·전투·자동전투
- 길드·오픈마켓·필수 로그인
- 수백 개 제작법을 Vertical Slice에 선행 구축
- 한 화면에서 많은 스킬과 수식어를 무제한 조합
- 단일 종합 점수만으로 모든 작품을 줄 세우는 랭킹

## 4. 불씨 정령

### 4.1 이름

**모닥**

- `모닥불`에서 가져온 짧고 기억하기 쉬운 이름이다.
- 지나치게 유아적이지 않으면서 따뜻한 대장간 인상을 준다.
- 기능명·재화명·장비명과 충돌하지 않는다.

### 4.2 역할

- 대장간의 비성장형 상징 동반자
- 첫 조작과 주요 이정표의 짧은 안내
- 결과에 대한 감정 반응
- 다음 행동 방향을 한 문장으로 알려주는 보조자

모닥은 확률, 정답, 최적 장비, 경기 결과를 예측하지 않는다.

### 4.3 성격

- 호기심이 많지만 말이 짧다.
- 성공을 과장해 플레이어를 부추기지 않는다.
- 실패·하락·파괴를 조롱하지 않는다.
- 장인의 선택을 존중한다.
- 장비보다 앞에 나서지 않는다.

### 4.4 말투

- 한 번에 한 문장
- 18자 안팎을 기본 목표로 사용
- 아기 말투·과도한 감탄사·인터넷 밈 사용 금지
- 수치는 UI가 담당하고 모닥은 행동 방향만 말한다.

예시:

| 상황 | 대사 후보 |
|---|---|
| 첫 망치 | `불이 올랐어. 지금 쳐.` |
| 첫 강화 | `비용과 위험을 먼저 봐.` |
| +5 도달 | `여기서 완성해도 좋아.` |
| +50 후보 | `어떤 작품으로 남길래?` |
| 단계 하락 | `결과는 남았어. 다시 보자.` |
| 영구 파괴 | `이 작품의 기록은 남길게.` |
| 고객 도착 | `작품을 찾는 사람이 왔어.` |

### 4.5 외형

- 주먹보다 작은 불씨 정령
- 검은 숯 껍질 안쪽에 주황빛 핵
- 머리 위에 한 갈래의 짧은 불꽃
- 금속 가루가 박힌 작은 표면
- 눈과 자세로 감정을 표현하고 색상만으로 상태를 구분하지 않음
- 기본 위치는 모루 뒤 또는 작업대 측면

### 4.6 반응 단계

1. 유휴: 낮게 호흡하는 불꽃
2. 타격 기대: 몸을 낮추고 불꽃이 앞으로 기울어짐
3. 성공: 짧은 상승과 금속 가루 반짝임
4. 하락: 불꽃이 낮아지고 몸이 움츠러듦
5. 파괴: 즉시 사라지지 않고 잠깐 정지한 뒤 잔불만 남음
6. 복구 오류: 장식 움직임을 멈추고 별도 경고 UI를 가리키는 자세

## 5. 대표 검투사

### 5.1 인물

**카시아 벨란**

- 역할: 중견 검투사, 다음 경기에서 상위 투기장 진출을 노림
- 성격: 담백하고 직설적이며 장비의 출처와 제작자를 존중함
- 핵심 욕망: 한 번의 화려한 승리보다 자신의 이름과 함께 기억될 무기를 얻는 것
- 약점: 과거 장비가 경기 중 부러진 경험 때문에 지나치게 화려하지만 불안정한 작품을 경계함

### 5.2 방문 요청

```text
요청 범주: 무기
기한: 2영업일
공개 가치 방향:
- 성능
- 명성
- 계보 수식어
- 경기 이력
```

모든 무기 범주 작품은 거래 가능하다. 적합 신호는 가격·관계·경기 장면과 연대기 결과를 바꾸지만 판매 자격을 막지 않는다.

### 5.3 공개 비교 문구

| 적합 요소 | 표시 예시 |
|---|---|
| 높은 강화 | `강한 충격을 버틸 수 있는 단계` |
| 파쇄 계보 | `중장갑 상대에게 가치가 높음` |
| 명예 계보 | `투기장 기록과 이름값을 중시함` |
| 전투 흔적 | `이미 실전에서 쓰인 이력을 높게 평가함` |
| 낮은 제작 등급 | `가격은 낮지만 현재 경기에는 사용 가능` |

### 5.4 후속 선택

판매 후 하나만 선택한다.

1. **경기 전 조율 지원**
   - 추가 비용을 사용해 장비 특징이 경기 장면에서 더 명확히 드러나게 함
   - 승리를 보장하지 않음
2. **공식 배팅**
   - 내부 골드만 사용
   - 배당과 최대 손실을 사전에 공개
   - 실제 결제·현금성 재화와 연결 금지

Vertical Slice의 기본 추천 경로는 `경기 전 조율 지원`이며, 배팅은 선택 가능한 대안으로 둔다.

### 5.5 경기 결과 표현

전체 전투를 구현하지 않는다.

```text
경기 시작 요약
→ 결정적 장면 1개
→ 장비 기여 원인 1~2개 공개
→ 승패 확정
→ 관계·명성·연대기 갱신
```

장비 기여 예시:

- 파쇄 계보가 상대 방패를 무너뜨림
- 견고 보조 수식어가 강한 충돌 뒤 형태를 유지함
- 명예 계보와 높은 제작 등급이 관중 평가와 명성을 높임

패배 시에도 장비가 무의미했다고 처리하지 않는다. 장비의 기여와 패배 원인을 분리한다.

## 6. +50 대표 진화 후보

대표 무기 픽스처는 임시명 `오래 벼린 검`을 사용한다. 최종 작품명은 진화 선택 후 결정한다.

### 6.1 성벽파쇄

```text
방향: 파쇄·중량·결정적 충격
대표 계보 승격: 파쇄 → 성벽파쇄
시각: 두꺼운 칼등, 균열 같은 각인, 무게 중심이 앞쪽
적합 고객: 검투사·군인
```

- 강한 한 번의 장면을 만들기 쉽다.
- 단순 공격력 최고안이 아니라 파쇄 정체성으로 표현한다.

### 6.2 용광의 심장

```text
방향: 잔화·연속 압박·열의 축적
대표 계보 승격: 잔화 → 용광의 심장
시각: 칼날 중심의 붉은 금속선, 타격 후 남는 잔열
적합 고객: 검투사·모험가
```

- 불꽃 이펙트만 화려한 안이 아니라 제작 과정의 열을 작품 정체성으로 연결한다.
- 무음·모션 감소에서도 각인과 문구로 식별한다.

### 6.3 투기장의 맹세

```text
방향: 명예·안정·기록
대표 계보 승격: 명예 → 투기장의 맹세
시각: 손잡이와 칼등의 경기 기록 각인, 균형 잡힌 실루엣
적합 고객: 검투사·수집가
```

- 순수 전투 성능 외에 명성·연대기·소유자 관계를 강화한다.
- 카시아 대표 흐름의 서사형 선택지다.

### 6.4 후보 공통 원칙

- 세 후보 모두 +50 성공을 보장한다.
- 후보는 우열이 아니라 다른 작품 방향이다.
- 정확한 수치 효과는 후속 밸런스 단계에서 결정한다.
- 선택 전 외형·계보 승격·고객 적합 방향·세계 결과 예시를 함께 보여준다.

## 7. 초기 수식어 풀

### 7.1 계보 수식어 6종

| 계보 | 작품 정체성 | 대표 적합 방향 |
|---|---|---|
| 예리 | 정밀·약점 공략·깔끔한 마감 | 검투사·수집가 |
| 파쇄 | 중량·충격·장갑 대응 | 검투사·군인 |
| 수호 | 안정·방어·사용자 보호 | 모험가·군인 |
| 기민 | 경량·조작성·빠른 대응 | 모험가·검투사 |
| 잔화 | 열·지속 압박·화로의 흔적 | 검투사·수집가 |
| 명예 | 명성·의식·기록·소유자 관계 | 검투사·수집가 |

계보는 장비 종류에 따라 표현이 달라지지만 데이터 축은 공통으로 유지한다.

### 7.2 보조 수식어 10종

| 수식어 | 의미 |
|---|---|
| 균형 잡힌 | 조작성과 안정의 중간값 |
| 가벼운 | 빠른 반응과 휴대성 |
| 묵직한 | 충격과 존재감 |
| 정교한 | 세밀한 마감과 정확성 |
| 견고한 | 충돌 후 형태 유지 |
| 열을 품은 | 잔열과 화로 계열 반응 |
| 울림 있는 | 타격·공명·상징성 |
| 흠없는 | 높은 제작 완성도와 전시 가치 |
| 흔적을 새긴 | 전투·소유·사건 기록과 상호작용 |
| 실용적인 | 가격 대비 안정성과 일반 고객 선호 |

### 7.3 조합 규칙

- 계보와 보조 수식어가 같은 의미를 중복할 경우 하나는 후보에서 제외한다.
- 보조 수식어 두 개가 상충해도 자동 금지하지 않고, 실제 의미가 모순이면 데이터 검증에서 차단한다.
- 고객 적합도는 수식어 이름만이 아니라 계보·등급·연대기 전체를 사용한다.
- 수식어 효과를 숨은 등급 점수로 축약해 표시하지 않는다.

## 8. 수집가 제작 파이프라인 증명 세트

### 8.1 인물

**에르사 로엔**

- 역할: 이동 전시회를 운영하는 수집가 겸 감정인
- 가치관: 전투 성능보다 제작 등급, 희소성, 계보의 명확성, 소유 이력을 중시
- 성격: 차분하고 근거를 구체적으로 설명함

### 8.2 요청

```text
요청 범주: 방어구
대표 작품: 별철 의식 방패
기한: 2영업일
공개 가치 방향:
- 제작 등급
- 명예·수호 계보
- 흠없는·울림 있는 보조 수식어
- 제작자·소유자·사건 기록
```

### 8.3 결과

```text
제품 비교
→ 직접 선택·판매
→ 짧은 감정 장면
→ 전시 방식 선택
→ 전시 결과
→ 가치·관계·연대기 갱신
```

전시 방식:

1. 제작 기술 중심 전시
2. 소유·사건 기록 중심 전시

두 선택은 같은 작품의 다른 의미를 강조한다. 새 핵심 시스템이나 별도 저장 엔진을 만들지 않는다.

### 8.4 검증 목적

- 검투사의 전투 가치와 다른 고객 가치 축이 작동하는지
- 장비 카드가 성능 이외의 등급·계보·연대기를 전달하는지
- 공통 요청·선택·판매·소유권·저장 구조를 재사용하는지
- 수집가 이름 하드코딩 없이 데이터로 구성되는지

## 9. 첫 5분 튜토리얼

### 0:00~0:30 — 망치 입력

- 완성 직전 장비를 중앙에 표시
- 타격 가능한 위치를 한 번만 강조
- 모닥: `불이 올랐어. 지금 쳐.`
- 세 번의 입력 안에 제작 반응을 확실히 보여준다.

### 0:30~1:00 — 제작 결과

- 장비 이름·제작 등급·기본 가치만 먼저 표시
- 긴 연대기와 상세 수치는 접힌 상태
- `[강화해 보기]`를 다음 행동으로 제시

### 1:00~3:00 — 첫 강화

정보 순서:

1. 현재 단계와 목표 단계
2. 성공률
3. 비용
4. 최대 하락·파괴 여부
5. 보호 효과
6. 실행 버튼

첫 저위험 구간에서는 파괴가 없다는 사실을 명확히 표시한다.

### 3:00~5:00 — +5 판단

```text
현재 완성 가치
vs
+10 도전 시 얻을 수 있는 계보 수식어
+ 추가 비용·위험
```

버튼:

- `[이 작품을 완성]`
- `[+10까지 도전]`
- `[자세히 보기]`

모닥: `여기서 완성해도 좋아.`

### 튜토리얼 금지

- 연속 모달 창
- 긴 세계관 설명
- 정답 버튼을 빛내는 자동 추천
- 첫 5분 안의 고객·세계·서버 기능 설명
- 모닥의 대사로 확률과 비용을 대신 설명

## 10. 화면 정보 위계

### 10.1 장비 카드

첫 화면:

1. 장비 이름
2. 제작 등급 + 강화 단계
3. 계보 수식어
4. 보조 수식어 최대 2개
5. 현재 소유자·운명 상태

상세 펼치기:

- 진화 형태
- 가격과 가치 변화
- 최근 연대기 3개
- 전체 소유자·사건 기록

### 10.2 고객 비교

1. 요청 범주와 남은 영업일
2. 고객이 중요하게 보는 가치
3. 작품별 공개 적합 이유
4. 매입 가격
5. 예상 관계·후속 방향
6. 최종 판매 확인

### 10.3 장비 연대기

- 가장 최근 사건을 상단에 표시
- 결과 원인과 결과를 한 묶음으로 표시
- 오래된 기록은 접힌 타임라인
- 파괴된 작품도 기록에서 삭제하지 않음

### 10.4 모바일 입력

- 주요 터치 대상 최소 48dp
- 강화·판매 같은 비가역 버튼은 화면 하단 고정 영역
- 같은 위치에 서로 다른 위험도의 행동을 빠르게 교체하지 않음
- 아이콘에는 목적과 결과를 설명하는 고유 접근성 라벨 제공

## 12. 일반 판매와 방문 상인

### 일반 판매

- 언제나 사용 가능
- 가격 변동이 작음
- 즉시 현금화
- 관계·세계 사건 없음
- 재기 경제의 안전망

### 방문 상인

- 영업일 시작에 제한적으로 발생
- 2영업일 기한
- 무기·방어구 범주 요청
- 시장성·회전 가치·거래 이력을 공개 적합 신호로 평가
- 일반 판매보다 높은 가격 가능성이 있지만 항상 최고가를 보장하지 않음
- 장기 관계나 전용 세계 사건을 만들지 않음

### 이름 있는 고객

- 검투사·수집가처럼 관계·후속 사건·연대기를 제공
- 단순 현금화보다 작품의 다음 삶을 결정하는 선택

## 13. 미래 명작 전당 정책

> 상태: `FUTURE_SERVER_PLANNING / NOT_IMPLEMENTED`

### 13.1 등록 자격

- +50 이상
- 완성 처리된 작품
- 사용자가 명시적으로 등록
- 서버 검증 통과
- 금지 이름·신고 정책 통과

### 13.2 비교 화면

기본 정렬:

1. 강화 단계
2. 제작 등급
3. 서버 검증 등록 시각

필터:

- 장비 범주·종류
- 계보 수식어
- 제작 등급
- 진화 형태
- 시즌·역대

표시:

- 작품명
- 강화 단계
- 제작 등급
- 계보·보조 수식어
- 진화 형태
- 공개 연대기 요약
- 공개 제작자명

단일 종합 전투력 점수는 사용하지 않는다.

### 13.3 시즌

- 기본 시즌 후보: 12주
- 시즌 전당과 역대 전당 분리
- 시즌 종료 후 작품을 삭제하지 않고 역대 기록으로 보존
- 보상은 칭호·프레임·전시 표식 같은 비성능 명예 보상만 사용

### 13.4 공개 제작자명

- 기본값: 비공개 또는 자동 생성 별칭
- 사용자가 직접 공개 동의한 별칭만 표시
- 실명 요구 금지
- 별칭 변경 시 과거 등록 작품에도 최신 공개 이름을 적용하거나 `이전 제작자명`을 노출하지 않는 방향을 기본값으로 사용

### 13.5 삭제·신고

- 사용자는 언제든 공개 등록을 해제할 수 있음
- 공개 목록에서는 즉시 제거
- 중복·부정 등록 방지를 위한 최소 감사 식별자는 비공개 보관 가능
- 작품명·제작자명 신고 기능 필요
- 신고는 로컬 장비 삭제나 싱글플레이 제재로 자동 연결하지 않음

### 13.6 파괴·분실 작품

- 등록 후 영구 파괴된 작품은 `역사적 기록` 상태로 남길 수 있음
- 현재 사용 가능한 작품 랭킹에서는 제외
- 파괴 전 등록 기록과 연대기는 유지
- 분실 상태는 공개하되 소유권과 현재 위치를 구분

### 13.7 검증 경계

Google Play Games 리더보드는 숫자 점수 중심이므로 장비 등급·수식어·진화·연대기 메타데이터를 정본으로 보관하기에 충분하지 않다.

따라서 미래 명작 전당은 다음 중 하나가 필요하다.

1. 자체 서버의 검증된 작품 레코드
2. 자체 서버 + Play Games 숫자 리더보드의 보조 사용

핵심 원칙:

- 클라이언트가 보낸 강화 단계·등급·수식어를 그대로 신뢰하지 않음
- 서버 기능 출시 이후 검증 흐름에 참여한 작품만 `검증 랭킹`에 등록
- 서버 출시 이전의 기존 오프라인 작품은 `레거시 전시`로 표시할 수 있으나 검증 순위에는 포함하지 않음
- 온라인 실패가 로컬 저장·장비·강화 결과를 변경하지 않음
- 중복 안전 등록 식별자 사용
- 제출 값 상한과 변조 탐지 사용

## 14. 플레이테스트 판정 기준

### 차단 결함

- 첫 강화에 도달하지 못함
- 위험·비용·파괴 여부를 잘못 이해한 채 비가역 행동 실행
- 한 입력이 두 번 판정·저장됨
- 판매 후 장비·보상·소유권이 불일치
- 앱 재실행으로 결과가 재추첨됨
- 핵심 버튼이 화면·제스처 영역에 가려짐

### 대표 흐름 추천 목표

- 6명 중 최소 5명이 관찰자 개입 없이 첫 강화 완료
- 첫 강화 중앙값 60초 이내
- 6명 중 최소 5명이 +5 완성과 +10 도전의 차이를 자신의 말로 설명
- 6명 전원이 판매한 작품이 사라진 것이 아니라 소유권이 이전됐음을 이해
- 잘못 누른 비가역 행동 0건
- 검투사 결과 후 최소 5명이 장비 기여 원인을 하나 이상 회상
- 수집가 세트가 별도 핵심 코드 없이 동일 데이터 구조로 완료

이 수치는 초기 기획 합격 후보이며 실제 첫 테스트 결과에 따라 재조정할 수 있다.
