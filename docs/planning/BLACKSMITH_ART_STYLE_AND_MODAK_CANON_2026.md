## 1. 승인 결정

### BS-ART-20260731-01 — 스타일라이즈드 다크 포지

Blacksmith의 프로젝트 공통 그림체는 **스타일라이즈드 다크 포지**로 고정한다.

핵심 문장:

> 어두운 대장간의 무게감, 선명한 장비 표현, 따뜻하고 감성적인 불빛을 결합한 모바일 세로형 스타일라이즈드 2D 비주얼.

### 시각 구성

- 배경: 어두운 대장간, 숯·철·목재·가죽의 낮은 채도 질감
- 조명: 화로와 금속 열기에서 발생하는 주황·황금빛 국부 조명
- 장비: 화면의 시각적 주인공이며 실루엣·재질·강화 흔적을 명확히 표현
- 캐릭터: 반실사보다 단순화된 게임 일러스트 비율
- UI: 철·황동을 암시하되 실제 금속 텍스처를 과도하게 사용하지 않음
- 정보: 확률·비용·위험·결과는 장식보다 높은 가독성을 유지
- 연대기: 가죽·양피지 질감을 제한적으로 사용해 작업 화면과 구분

### 렌더링 강도

- 완전 반실사 금지
- 밝은 캐주얼 공방풍 금지
- SD 캐릭터 중심 게임처럼 보이는 구성 금지
- 배경과 장비에는 충분한 물성·명암을 부여
- 고객과 대장장이는 모바일에서 읽히도록 형태와 얼굴 정보를 단순화
- 장비·핵심 행동·결과가 캐릭터 일러스트보다 우선

### 금지 요소

- 일반적인 밝은 모바일 판타지 RPG UI
- 보라색·무지개색 희귀도 효과의 전면 사용
- 장비를 가리는 과도한 캐릭터·불꽃·파티클
- 화면마다 다른 렌더링 방식
- 확률·위험을 장식 아래 숨기는 레이아웃

---

### BS-MODAK-20260731-01 — 밝은 불 정령 모닥

모닥은 **C안의 차분하고 감정적인 표정 구조를 유지하면서, 숯 몸체를 제거한 밝은 불 정령**으로 고정한다.

핵심 문장:

> 작고 밝은 불꽃 몸체와 차분하고 풍부한 표정을 가진, 대장간의 선택을 지켜보는 비성장형 불 정령 동반자.

## 2. 모닥 기본 디자인

### 몸과 실루엣

- 몸의 주재질은 밝은 노랑·주황 불꽃
- 머리가 크고 몸이 작은 2등신 이하 실루엣
- 머리 위 불꽃은 비대칭으로 휘어져 고유 실루엣을 형성
- 몸통도 불빛이 살아 있는 형태이며 숯 껍질로 덮지 않음
- 검은색·숯색은 손·발·목 장식·작은 테두리에만 제한적으로 사용
- 가슴의 작은 황금 또는 주황 핵 장식은 허용
- 장비·버튼·확률표보다 밝기와 크기가 앞서지 않도록 화면 배치에서 축소

### 얼굴과 표정

표정 방향은 C안의 차분한 정령형을 기준으로 한다.

- 기본: 온화하고 조용한 미소
- 호기심: 눈을 약간 크게 뜨고 손을 모으며 작은 물음표 반응
- 걱정: 불꽃이 낮아지고 눈썹·입이 작게 처짐
- 기쁨: 눈이 반달형이 되고 몸의 밝기가 올라감
- 놀람: 불꽃 끝이 순간적으로 퍼지고 작은 `o`형 입
- 슬픔: 과장된 울음보다 작은 눈물·낮아진 불빛 사용
- 집중: 장비를 바라보며 입을 다문 진지한 표정

항상 활짝 웃는 표정으로 고정하지 않는다. 강화 실패·영구 파괴·작품 인계 장면에서는 상황의 감정을 존중한다.

### 색상 비율

- 밝은 노랑·황금 중심부: 약 50%
- 주황 불꽃 외곽: 약 35%
- 적갈색·숯색 보조 디테일: 약 15% 이하
- 기본 형태에서 파랑·보라 불꽃 사용 금지

### 성격·기능 경계

- 호기심이 많고 작품에 애착을 보임
- 플레이어의 선택을 대신하지 않음
- 성공 확률이나 결과를 예측하지 않음
- 정답 행동을 강조하지 않음
- 성장·레벨·재화·버프 시스템을 갖지 않음
- 한 번에 한 문장의 짧은 안내만 사용
- 작업대·장비·위험 정보·행동 버튼을 가리지 않음

## 3. 기존안 처리

다음 기존 표현은 폐기한다.

- `숯 껍질·주황빛 핵·짧은 불꽃`을 기본 외형으로 사용하는 안
- 몸 전체가 검은 돌이나 숯으로 보이는 안
- 밝은 불꽃보다 어두운 갑각이 시각적 주재질이 되는 안
- 과도하게 유아적인 젤리형 불꽃 마스코트

허용되는 어두운 요소는 손·발·목 장식·작은 보석 테두리처럼 전체 실루엣을 지배하지 않는 보조 디테일뿐이다.

## 4. 화면 적용 규칙

- 허브: 화로 또는 모루 옆에 작게 배치
- 단조: 첫 타격·열기 변화에 짧게 반응하되 타격 지점 비가림
- 강화: 확률·비용·위험표 바깥에서 감정 반응만 제공
- +50 경로: 일반·고위 경로 중 하나를 추천하거나 가리키지 않음
- 고객 거래: 작품 인계 감정을 보조하되 고객과 장비보다 작은 비중
- 결과·연대기: 성공·부분 성공·실패·파괴에 맞는 표정 사용
