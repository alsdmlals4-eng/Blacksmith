## 1. 최종 결정

Blacksmith의 제작 등급은 다음 네 단계로 고정한다.

```text
보통 → 우수 → 명품 → 걸작
```

`양질` 등급은 현행 제작 등급에서 제거한다.

## 2. 등급의 역할

제작 등급은 단조가 완료될 때 확정되는 **작품의 영구 제작 품질 정보**다.

- 강화 단계와 분리한다.
- 계보 수식어·보조 수식어와 분리한다.
- +50 일반·고위 정밀강화 경로와 분리한다.
- 장비 운명 상태와 분리한다.
- 판매 뒤에도 장비 연대기에 보존한다.

```text
제작 등급 ≠ 강화 단계
제작 등급 ≠ 수식어 희귀도
제작 등급 ≠ +50 진화 형태
제작 등급 ≠ 전설 등급
```

## 3. 네 단계의 의미

| 순서 | 표시명 | 기획 의미 |
|---:|---|---|
| 1 | 보통 | 요구 기준을 충족한 정상 완성품 |
| 2 | 우수 | 마감·균형·완성도가 뚜렷하게 좋은 작품 |
| 3 | 명품 | 고객과 세계가 높은 가치를 인정할 수준의 작품 |
| 4 | 걸작 | 제작 과정 자체가 작품의 대표 정체성이 되는 최상위 제작 결과 |

정확한 확률·공격력 배율·가치 배율은 밸런스 조정값이며 이번 결정에서 고정하지 않는다.

## 4. 불변 규칙

- 네 등급 모두 유효한 완성품이다.
- 보통 등급도 강화·보관·일반 판매·고객 판매가 가능하다.
- 낮은 제작 등급을 숨은 실패나 사용 불가 상태로 만들지 않는다.
- 제작 등급은 단조 완료 이후 일반 강화로 상승하거나 하락하지 않는다.
- 고객 적합도는 제작 등급 하나만으로 결정하지 않고 계보·보조·진화·연대기와 함께 공개 평가한다.
- `전설`은 제작 등급으로 사용하지 않는다.
- `양질`은 현행 UI·데이터·문서의 현재 등급 값으로 사용하지 않는다.

## 5. 기존 결정 처리

`BS-V9-20260731-01`의 다음 5단계 결정은 이력으로 보존하되 현행 정본으로 사용하지 않는다.

```text
보통 → 양질 → 우수 → 명품 → 걸작
```

상태:

```text
BS-V9-20260731-01: SUPERSEDED
SUPERSEDED_BY: BS-GRADE-20260801-01
```

## 6. 실제 main과의 충돌

현재 main의 런타임 데이터는 다음 구형 5개 ID와 표시명을 사용한다.

```text
APPRENTICE  / 미숙한
STANDARD    / 평범한
REFINED     / 정교한
MASTERWORK  / 명품
PERFECT     / 완벽한
```

이는 승인된 네 단계와 직접 충돌한다.

이번 결정은 **목표 등급 구조만 확정**한다. 다음 항목은 P0-2 마이그레이션 설계에서 별도 승인한다.

- 신규 런타임 ID 4개
- 구형 ID 5개에서 신규 ID 4개로의 변환표
- 기존 저장 데이터의 등급 보존 규칙
- 분포·공격력·가치 배율
- 고객 적합도 점수 변환
- fixture·validator·회귀 테스트 변환

## 7. 마이그레이션 안전 원칙

아직 세부 변환표는 확정하지 않았지만 다음 원칙은 고정한다.

- 기존 작품의 등급을 난수로 다시 추첨하지 않는다.
- 저장된 장비 ID·제작자·소유권·강화 단계·연대기를 유지한다.
- 같은 저장 파일을 여러 번 변환해도 결과가 달라지지 않아야 한다.
- 변환 실패 시 원본 저장을 덮어쓰지 않는다.
- 표시명만 바꾸고 고객 점수·테스트를 구형 ID에 남겨두는 부분 마이그레이션을 금지한다.
