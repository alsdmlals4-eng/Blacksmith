## 알림·배지 우선순위

알림과 탭 배지는 **필수 확인 → 기한·행동 → 일반 소식**의 3단계 행동 우선순위를 사용한다.

단순히 읽지 않은 항목 수를 누적하지 않는다. 플레이어가 지금 처리해야 하는 상태의 중요도와 남은 영업일을 우선 표시한다.

| 우선순위 | 대상 | 기본 표시 |
|---|---|---|
| 1. 필수 확인 | 미확인 원자적 결과, 저장 복구, 세계 진행 결과 | `확인 필요` |
| 2. 기한·행동 | 고객 제안, 약속, 사건 지원, 경기 준비 | 남은 영업일·마감 문구 |
| 3. 일반 소식 | 구독 소식, 게시판 뉴스, 장비 연대기 갱신 | 작은 새 소식 표시 |

```text
필수 확인
→ 상태 정합성을 위해 일반 조작보다 먼저 정리

기한·행동
→ 오늘 마감 / 1영업일 남음 / 준비 가능 표시

일반 소식
→ 묶어서 표시
→ 강화와 고위험 선택을 중단시키지 않음
```

## 필수 확인

필수 확인은 이미 저장된 결과를 플레이어가 아직 확인하지 않았거나, 정상 진행을 위해 오류·복구 상태를 먼저 정리해야 하는 경우다.

대상:

- 미확인 강화·정밀강화·고위 정밀강화 결과
- 미확인 거래·판매·소유권 이전 결과
- 영업 종료 후 저장된 세계 진행 결과 묶음
- 영구 파괴·장비 분실 등 비가역 장비 결과 요약
- 저장 손상 또는 버전 마이그레이션 복구 화면
- 상태 무결성 오류 안내

원칙:

- 필수 확인은 원시 알림 개수 대신 `확인 필요` 상태로 표시한다.
- 동일 결과를 여러 탭에서 중복 필수 항목으로 만들지 않는다.
- 이미 저장된 결과를 확인하는 과정에서 판정·보상·관계를 다시 적용하지 않는다.
- 강화 연출 도중 발생한 일반 소식보다 우선하지만, 아직 확정되지 않은 강화 입력을 강제로 실행하거나 취소하지 않는다.
- 복귀 시 미확인 필수 결과가 있으면 일반 작업대 조작보다 먼저 결과 요약을 정리한다.

## 기한·행동 알림

기한·행동 알림은 플레이어가 선택적으로 개입할 수 있고, 영업일이 지나면 기회 또는 조건이 변경되는 항목이다.

대상:

- 방문 고객 제안 마감
- 수락한 약속의 제공 기한
- 세계 사건 지원 기한
- 검투사 경기 준비·배팅 마감
- 장비 수리·회수·후계 장비 관련 선택 기한
- 영업 종료 전에 처리 가능한 중요한 자원 결정

표시 원칙:

- `오늘 마감`, `1영업일 남음`, `2영업일 남음`처럼 게임 시간 단위를 직접 표시한다.
- 실제 마감이 없는 항목에 긴급 문구를 사용하지 않는다.
- 기한이 가장 가까운 행동을 해당 탭의 대표 배지로 올린다.
- 같은 우선순위라면 약속·고객·사건 등 플레이어가 이미 책임을 수락한 항목을 먼저 표시한다.
- 기한이 지나 자동 해결된 항목은 행동 배지에서 제거하고 결과 소식으로 전환한다.
- 기한 알림은 행동을 안내하지만 해당 화면으로 강제 이동시키지 않는다.

## 일반 소식

일반 소식은 즉시 행동하지 않아도 진행 무결성이 깨지지 않는 정보 갱신이다.

대상:

- 구독한 인물의 새 소식
- 세계 게시판 일반 뉴스
- 장비 연대기 갱신
- 관계 변화 기록
- 고객의 비긴급 재방문 예고
- 이미 종료된 사건의 상세 기사

원칙:

- 일반 소식은 무제한 숫자 카운트로 쌓지 않는다.
- 탭에는 작은 점·아이콘·`새 소식` 문구 중 하나로 묶어서 표시한다.
- 플레이어가 해당 탭을 열거나 영업 종료 결과 묶음을 확인할 때 정리한다.
- 강화 실행, 길게 누르기, 정밀강화 후보 선택과 결과 연출을 팝업으로 중단시키지 않는다.
- 일반 소식을 보지 않았다는 이유로 보상·관계·기한을 불리하게 변경하지 않는다.

## 탭별 대표 상태

각 탭은 원시 알림 개수가 아니라 **현재 가장 높은 우선순위 상태 하나**를 대표 표시한다.

| 탭 | 우선 표시 예시 |
|---|---|
| `[대장간]` | 미확인 강화 결과 → 파괴 위험 장비 → 수리 필요 → 재료 부족 |
| `[방문 고객]` | 약속 오늘 마감 → 고객 제안 1영업일 → 새 방문 고객 → 일반 재방문 소식 |
| `[세계]` | 미확인 세계 진행 결과 → 사건 오늘 마감 → 경기 1영업일 → 새 구독 소식 |

- 탭 하나에 여러 숫자 배지를 동시에 붙이지 않는다.
- 상세 화면에 들어가면 같은 등급의 여러 항목을 목록으로 확인할 수 있다.
- 같은 사건·고객·장비 상태를 여러 탭의 숫자에 중복 집계하지 않는다.
- 다른 탭과 연결되는 항목은 실제 책임 영역 탭에만 대표 배지를 두고, 관련 화면에는 링크만 제공한다.

## 표시 언어와 접근성

- 색상만으로 우선순위를 구분하지 않는다.
- 아이콘, 문구, 남은 영업일을 함께 사용한다.
- `빨간 점`만 표시하고 의미를 설명하지 않는 구조를 사용하지 않는다.
- 스크린 리더 또는 대체 텍스트에서는 우선순위와 남은 영업일을 읽을 수 있어야 한다.
- 점멸·강한 애니메이션을 긴급도 표현의 기본 수단으로 사용하지 않는다.
- 모션 감소 설정에서도 동일한 우선순위 정보를 제공한다.

## 처리 완료와 제거

배지는 원인이 해소되면 즉시 갱신한다.

- 미확인 결과를 확인하면 필수 확인 상태 제거
- 약속·지원·배팅을 확정하면 해당 행동 알림 갱신
- 기한이 지나면 행동 알림 제거 후 결과 소식으로 전환
- 고객 제안이 판매·거절·만료되면 제안 배지 제거
- 일반 소식을 확인하면 해당 묶음의 새 소식 표시 제거

알림을 닫았다는 이유만으로 실제 기한·약속 상태를 삭제하지 않는다. 표시 상태와 게임 상태는 분리한다.

## 버티컬 슬라이스 검증

15~25분 버티컬 슬라이스에서 다음을 검증한다.

- 미확인 강화 결과가 일반 조작보다 먼저 정리되는지
- 고객 제안·약속·사건의 남은 영업일을 오해하지 않는지
- 가장 가까운 마감이 탭 대표 상태로 올라오는지
- 일반 구독 소식이 강화 흐름을 방해하지 않는지
- 같은 사건이 여러 탭에 중복 집계되지 않는지
- 처리 완료·만료 직후 배지가 제거 또는 결과 소식으로 전환되는지
- 색상·사운드 없이도 우선순위와 기한을 이해할 수 있는지
