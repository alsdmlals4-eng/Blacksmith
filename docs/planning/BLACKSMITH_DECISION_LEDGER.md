## 2. 최신 정밀강화 규칙 요약

1. 모든 10강 이정표에서 정밀강화가 필수다.
2. +10~+40은 일반 정밀강화만 사용한다.
3. +50부터 일반 정밀강화 또는 특수 재료를 넣은 고위 정밀강화를 선택한다.
4. 이정표당 결과 확정은 1회다.
5. 정밀강화를 완료해야 다음 강화 단계로 진입한다.
6. 보조재료와 촉매가 수식어 후보군과 가중치를 결정한다.
7. 등록된 특정 조합은 수식어 정체성을 확정한다.
8. 특수 재료를 추가한 등록 조합은 초희귀 수식어를 확정할 수 있다.
9. 고정 조합도 정밀강화 성공은 보장하지 않는다.
10. 특수 재료 실패 학습은 장비가 아니라 대장장이 도감의 재료별 숙련에 저장한다.
11. 조합식은 단서를 얻고 발견한 뒤 도감에 영구 등록한다.

## 3. 병합 전 필수 충돌 검사

- 기존 코어 문서가 생애주기를 메인으로 설명하는가
- 기존 적합도 UI가 정확한 점수·예상 결과를 선공개하는가
- 기존 파손 상태가 `BROKEN_OR_LOST`로 장비 삭제를 전제하는가
- 기존 강화 규칙이 +10 안전, +11 하락, +30 파괴 등 과거 수치표를 확정값으로 취급하는가
- 기존 정밀강화가 후보 선택 방식으로 남아 있는가
- 기존 특수 재료가 모든 고강화 시도의 필수 입장권으로 남아 있는가
- 보호석이 강화 하락이나 손상까지 막는다고 적혀 있는가
- 회복석이 모든 손실을 되돌리는가
- 화술·제작·강화 성장 축이 누락되었는가
- 국가·밀수·전시·수집가·보관소가 서로 다른 책임 문서에서 모순되는가

## 4. 남은 미결정

- 분야별 기술 돌파와 고위 정밀강화의 특수 재료 공유 여부
- 돌파 기준 단계와 10강 정밀강화 단계의 관계
- 일반·고위 정밀강화 실패 결과의 정확한 장비 손실
- 수식어 슬롯 수, 교체·누적·진화 규칙
- 고정 조합의 세부 수치 변동 범위
- 재료 숙련 획득량과 상한
- 모든 정확한 밸런스 수치
