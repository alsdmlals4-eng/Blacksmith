## 2. POC 우선순위 최신 순서

```text
POC 시나리오 런처
→ 장비 연대기 요약 카드
→ 위험·결과 사전 카드
→ 저위험 연속 강화
→ 특수 타격 실패 상한
→ 경제·성장 수치 조정
→ 통합 E2E·자동 검증
→ Android·접근성·성능·외부 플레이 검증
```

`BLACKSMITH_GENRE_BENCHMARK_2026.md`의 이전 권장 순서에서 `오늘의 대장간 목표`가 사람 검증 전에 위치한 내용과, 연속 강화·실패 상한이 POC 이후로 배치된 내용은 `SUPERSEDED`다.

## 3. 시나리오 런처 결정

- POC·QA 전용 진입점이며 출시 일반 메뉴와 분리한다.
- 총 12개 대표 시나리오를 제공한다.
- 결정적 seed, 시작 스냅샷, 자원 프리셋, 기대 종료 상태를 가진다.
- 기대 상태 재현 성공은 `PASSED`, 재미 승인과 구분한다.
- 시나리오별 원클릭 초기화를 제공한다.

정확한 시나리오 ID와 임시 자원은 다음 책임 파일을 따른다.

- `docs/planning/BLACKSMITH_POC_PRIORITY_BASELINE_2026.md`
- `docs/planning/data/blacksmith_poc_priority_seed_2026.json`

## 4. 장비 연대기 카드 결정

- 상단에서 활동 가치, 거래 가치, 역사 가치를 분리한다.
- 제작·강화·정밀강화·손상·복구·고객 활동·국가·밀수·전시·판매를 시간순으로 기록한다.
- 저위험 연속 강화는 카드에서 한 묶음으로 표시하되 개별 판정 로그를 삭제하지 않는다.
- 대표 사건 6개와 최근 타임라인 12개는 `POC_TUNABLE`이다.

---

## 5. 위험·결과 사전 카드 결정

- 위험 표시는 `매우 낮음 / 낮음 / 보통 / 높음 / 매우 높음` 5단계를 사용한다.
- 내부 위험 점수는 POC에서 0~100 구간을 사용하지만 플레이어에게 숫자를 공개하지 않는다.
- 확정 소비, 최악 결과, 보호 수단의 변화, 세계 수치 방향, 판정 시점과 회복 가능성을 표시한다.
- `높음` 이상과 영구 결과 가능 행동은 명시 확인을 요구한다.

---

## 6. 저위험 연속 강화 결정

- 수동 강화 15회 뒤 해금한다.
- POC 런처는 즉시 해금 프리셋을 제공한다.
- +1~+20과 `매우 낮음 / 낮음` 위험에서만 사용할 수 있다.
- 요청 최대치는 10회다.
- 첫 실패, 자원 부족, 목표 도달, 정밀강화 대기, 보통 이상 위험, 장비 손상, 수동 보호 선택에서 즉시 정지한다.
- 각 시도는 독립 판정·비용·이력·telemetry를 유지한다.
- 고위험 자동 강화와 정밀강화 자동 처리는 `REJECTED` 상태를 유지한다.

---

## 7. 기존 특수 타격을 이용한 실패 상한 결정

- 별도 실패 스택·보장 재화를 추가하지 않는다.
- 기존 특수 타격 충전 최대치 100을 POC에서 사용한다.
- 위험도에 따라 실패 기여량을 차등 적용한다.
- 충전 완료 후 선택형 `실패 완충 타격`을 사용할 수 있다.
- 성공률은 증가하지 않으며 사용 시 충전을 모두 소모한다.
- 영구 파괴는 최대 `DAMAGED`, `DAMAGED`는 최대 2단계 하락, 3단계 이상 하락은 최대 1단계 하락으로 제한한다.
- 보호석과 함께 쓰면 보호석 처리 뒤 완충 상한을 적용한다.
- 전문화별 추가 효과는 `POC_TUNABLE`이다.

이 결정은 보호석의 상점 구매형 파괴 방지 책임을 대체하지 않는다. 실패 완충은 충분한 강화 활동 뒤 제한적으로 얻는 1회 행동이다.

## 8. 경제·성장 임시 데이터 결정

다음 값은 POC 구현·시뮬레이션용이며 출시 확정값이 아니다.

- 자연 진행 시작 골드 20,000
- 대표 철검 제작비 골드 500, 재료 20
- +1~+60 강화 비용 6개 밴드
- 대표 공개시장가 +0 1,000에서 +60 275,000
- 방문 고객 +10~25%, 군사 +15%, 밀수 +35%, 수집가 +20~80%
- 강화 메인 포인트 총 8점
- +50 한계 돌파 2점, +60 한계 돌파 3점
- 동일 구간 강화 2회분 이하 잔액 경고

모든 상세값은 `docs/planning/data/blacksmith_poc_priority_seed_2026.json`을 책임 원본으로 한다.
