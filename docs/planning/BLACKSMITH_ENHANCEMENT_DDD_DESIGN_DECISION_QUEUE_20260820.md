# Blacksmith 강화 DDD Decision Queue — 2026-08-20

- Parent: `BS-CORE-20260820-01`
- 상태: `PROPOSED_ONLY`
- 목적: 강화가 메인이라는 사용자 최신 결정 아래에서 다음 Grill Me 승인 항목을 최소화한다.

## Decision 02 — 실패·회복 골격

후보:
- A `PURE_RISK_LADDER`: 실패는 비용/손실만 남기고 다음 시도 확률은 독립적
- B `RISK_PLUS_RECOVERY_PROGRESS`: 실패가 비용/손실과 함께 공개된 누적 회복/보정도 남김
- C `PER_ATTEMPT_RISK_MODE`: 강화마다 안정/표준/강행을 선택

권장:
- **B를 기본으로 하고 C는 이정표·고위험 구간에만 흡수**

이유:
- 일반 강화의 반복 리듬을 빠르게 유지한다.
- 실패 연속이 무의미해지는 피로를 제한한다.
- 중요한 구간에만 별도 선택을 두어 긴장과 플레이어 표현을 강화한다.

## Decision 03 — 작품 파괴 경계

후보:
- A `NO_DESTRUCTION`: 실패는 유지/손상/수리만
- B `CRITICAL_BREAK_UID_PRESERVED`: 고위험 구간에서 사용불가 파손 가능, UID/역사 보존, 복원 가능
- C `TRUE_DESTRUCTION`: 고위험 실패에서 작품 UID 자체 영구 소실

권장:
- **B**. 기본 실패에서 영구 삭제는 제외하고, 높은 위험을 명시적으로 선택한 구간에만 심각한 파손을 둔다.

## Decision 04 — 실패 누적 정보 공개

후보:
- A 정확한 수치 공개
- B 단계형 게이지/상태만 공개
- C 숨김

권장:
- **A 또는 A에 가까운 B**. 성공률·비용·실패 결과는 정확히 공개하고, 회복 누적이 확률에 직접 가산되면 수치도 공개한다. 긴장감을 위해 핵심 확률을 숨기지 않는다.

## Decision 05 — 첫 세션 강화 사다리

권장 구조:

```text
1. 높은 성공 체감의 안전 강화
2. 한 번 더 빠른 성공/작은 보상
3. 처음으로 멈춤이 합리적인 확보점
4. 첫 실질 위험 강화
5. 성공/실패와 관계없이 다음 행동이 생김
6. 짧은 고객/세계 payoff로 이전 강화 선택 회상
```

정확한 단계·확률은 Balance Budget에서 조정한다.

## Decision 06 — 정밀강화 역할

정밀강화는 별도 메인 미니게임이 아니라 **일반 강화 사다리의 이정표 선택**으로 둔다.

- 일반 강화: 빠른 DDD 반복
- 정밀강화: 이정표에서 성장 방향/촉매/위험 프로필을 바꾸는 큰 선택
- 정밀강화가 일반 강화보다 자주 등장하거나 시간이 길어지면 축소
