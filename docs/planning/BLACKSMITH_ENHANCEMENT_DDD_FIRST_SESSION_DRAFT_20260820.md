## 대표 경험

첫 세션은 작품 생애 전체보다 **강화가 왜 재미있는지**를 먼저 증명한다.

```text
짧은 의뢰/목표
→ 기본 작품 확보
→ 안전 강화 1
→ 즉시 성공 피드백
→ 안전 강화 2 또는 작은 선택
→ 첫 '이 정도면 충분함' 확보점
→ 성공 기대·비용·실패 결과 공개
→ 첫 위험 강화: 멈춤 / 도전
→ 즉시 결과
→ 실패면 회복 진전 또는 작품 손상 등 다음 판단 발생
→ 성공이면 다음 이정표 기대
→ 짧은 고객/세계 결과
→ 과거 강화 선택이 같은 UID 작품에 남았음을 확인
→ 다음 강화 질문
```

## 첫 세션에서 아직 넣지 않는 것

- 여러 고객 동시 관리
- 긴 고객 생애주기
- 복잡한 정밀제작 레시피
- 대량 주문
- 다수 재료 경제
- 장기 명성/관계 최적화
- 최고 단계 강화

## 성공 질문

첫 세션 후 플레이어가 다음을 말할 수 있어야 한다.

1. 강화할 때 왜 긴장했는가?
2. 왜 그 시점에 멈추거나 더 도전했는가?
3. 성공/실패로 무엇이 바뀌었는가?
4. 다시 강화하고 싶은 이유가 무엇인가?
5. 자신의 첫 작품을 무엇 때문에 기억하는가?

실제 사람 검증 전 결과는 `HYPOTHESIS`다.
