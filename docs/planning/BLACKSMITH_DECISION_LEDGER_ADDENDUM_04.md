## 2. 최신 구조

```text
강화 성장 화면
├─ 메인 전문화: 안정형·성능형·효율형 역할 분기
├─ 강화 한계 돌파: 같은 메인 포인트를 쓰는 고강화 순차 트리
└─ 보조 영구 강화: 작은 누적 성능·정보·편의
```

```text
기본 활성 최대 +40
→ 강화 한계 돌파 I 투자: 활성 최대 +50
→ 강화 한계 돌파 II 투자: 활성 최대 +60
→ 강화 한계 돌파 III 투자: 활성 최대 +70
→ ...
```

고강화 빌드는 한계 돌파에 메인 포인트를 사용하므로 같은 날 안정·성능·효율 분기의 깊이를 일부 포기한다.

## 3. 투자·회수와 장비 처리

- 투자와 회수는 영업 전 준비 단계에서만 가능하다.
- 가게 오픈 후에는 그날의 한계 돌파 상태가 잠긴다.
- 하위 노드 회수 시 상위 노드도 연쇄 회수한다.
- 포인트 반환과 취소 미리보기는 기존 메인 트리 규칙을 따른다.
- 현재 장비가 새 활성 한계보다 높아져도 강화 단계는 내려가지 않는다.
- 해당 장비는 사용·판매·납품·전시할 수 있으나 추가 강화는 제한된다.
- 필요한 한계 노드를 다시 투자하면 추가 강화가 가능하다.

## 4. 정밀강화 순서

- 모든 10강 이정표의 정밀강화 규칙은 유지한다.
- 상한 단계의 정밀강화를 먼저 완료한다.
- 다음 한계 돌파 노드가 현재 메인 빌드에 투자되어 있어야 다음 강화 단계가 열린다.
- `+50` 이후 고위 정밀강화 결과와 한계 돌파 노드 상태는 독립이다.
- 한계 돌파 노드는 확률·실패·연구 시간을 사용하지 않는다.

## 5. 폐기 문서 해석

성장 시스템 추가 결정 03의 `주요 돌파 / 일반 돌파` 보상 분류는 최신 기획에서 사용하지 않는다.

성장 시스템 추가 결정 04의 이전 `영구·회수 불가 한계 트리`와 `포인트 풀 미결정` 문구는 이번 결정으로 대체한다.

## 6. 남은 미결정

- 한계 돌파 노드별 메인 포인트 비용 곡선
- 노드별 강화 숙련·공통 등급 선행 조건
- 공통 보너스 포인트의 한계 돌파 기여 상한
- 최종 메인 포인트 기준 한계 돌파와 역할 분기의 목표 점유 비율
- 최종 강화 한계
- 한계 노드 취소 비용을 일반 메인 노드와 동일하게 적용할지 여부

모든 미결정 수치는 `PROPOSED_ONLY`다.
