# 블랙스미스 기획 결정 원장 추가 기록 04

> 상태: `PLANNING_IN_PROGRESS`
>
> 기준일: 2026-07-26
>
> 범위: 돌파 명칭·책임 위치·포인트형 별도 트리 전환

## 1. 결정 추적표

| 영역 | 결정 | 상태 | 최신 규칙 | 병합 조치 |
|---|---|---|---|---|
| 돌파 명칭 | 분야별 기술 돌파 | `SUPERSEDED` | `[강화 한계 돌파]` | 모든 최신 문서·UI 명칭 교체 |
| 돌파 보상 분류 | 주요 돌파·일반 돌파 | `REJECTED` | 보상 등급 구분 없음 | 추가 결정 03의 구분 폐기 |
| 시스템 위치 | 장비 분야별 기술 트리 | `SUPERSEDED` | 강화 성장축 내부 별도 영구 트리 | 강화 화면 세 번째 영역으로 이동 |
| 투자 방식 | 골드·재료·연구 자원으로 즉시 돌파 | `SUPERSEDED` | 강화 포인트로 순차 노드 투자 | 포인트형 성장으로 교체 |
| 구조 | 돌파마다 기능 보상 배치 | `REJECTED` | 최대 강화치 개방이 노드의 핵심 책임 | 기능 팽창 방지 |
| 최초 한계 | +40 이전 돌파 | `REJECTED` | 기본 한계 +40, 첫 투자로 +50 개방 | 시작 경계 고정 |
| 반복 간격 | 가변 간격 | `REJECTED` | +40 이후 10강 단위 | +50, +60, +70 순차 개방 |
| 노드 관계 | 자유 분기 | `REJECTED` | 이전 한계 노드를 요구하는 순차 트리 | 우회 투자 금지 |
| 적용 범위 | 현재 장비만 | `REJECTED` | 계정 전체 강화 한계 영구 개방 | 기존·신규 장비 공통 적용 |
| 회수 | 초기화·재분배 가능 | `REJECTED` | 한계 돌파 노드는 영구, 회수 불가 | 최대 강화치 역행 방지 |
| 포인트 출처 | 공통·장비 분야 포인트 사용 | `REJECTED` | 강화 성장축 포인트 사용 | 타 성장축과 책임 분리 |
| 포인트 풀 | 메인·보조·한계 트리 공용 여부 | `UNRESOLVED` | 공용 또는 한계 전용 중 별도 결정 | 임의 확정 금지 |
| 투자 시점 | 한계 도달 전 선투자 가능 여부 | `UNRESOLVED` | 별도 결정 | 다음 기획 질문 |

## 2. 최신 구조

```text
강화 성장 화면
├─ 메인 전문화: 당일 빌드, 준비 단계에서 회수·재투자
├─ 보조 영구 강화: 작은 누적 성능·정보·편의
└─ 강화 한계 돌파: 강화 포인트를 쓰는 영구 순차 트리
```

```text
기본 최대 +40
→ 강화 한계 돌파 I 투자: 최대 +50
→ 강화 한계 돌파 II 투자: 최대 +60
→ 강화 한계 돌파 III 투자: 최대 +70
→ ...
```

## 3. 정밀강화 순서

- 모든 10강 이정표의 정밀강화 규칙은 유지한다.
- 상한 단계의 정밀강화를 먼저 완료한다.
- 다음 한계 돌파 노드가 투자되어 있어야 다음 강화 단계가 열린다.
- `+50` 이후 고위 정밀강화 결과와 한계 돌파는 독립 판정이다.
- 한계 돌파 노드는 확률·실패·연구 시간을 사용하지 않는다.

## 4. 폐기 문서 해석

성장 시스템 추가 결정 03의 `주요 돌파 / 일반 돌파` 보상 분류는 최신 기획에서 사용하지 않는다.

해당 문서는 의사결정 이력을 위해 남기되 상태는 `SUPERSEDED`로 취급한다. 구현·밸런스·UI 사양은 추가 결정 04를 기준으로 한다.

## 5. 남은 미결정

- 강화 포인트 공용 풀과 한계 돌파 전용 풀 중 선택
- 해당 강화 한계 도달을 노드 투자 조건으로 요구할지 여부
- 영업 전 준비 단계에서만 투자할지 여부
- 노드별 포인트 비용 곡선
- 최종 강화 한계

모든 미결정 수치는 `PROPOSED_ONLY`다.
