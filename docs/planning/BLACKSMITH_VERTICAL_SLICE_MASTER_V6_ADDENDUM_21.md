## 보관함 명칭과 일반 영업·방문 고객 구조 정정

플레이어가 제작·강화·보유한 제품을 모아 두는 기능의 사용자 노출 명칭은 **`보관함`**으로 확정한다.

기존 기획에서 사용한 `재고`는 경제·상태를 설명하는 일반 용어로만 이해하며, 실제 화면·버튼·탭·안내 문구에서는 `보관함`을 기준 명칭으로 사용한다.

또한 가게 오픈 후의 일반 제작·강화·판매와 `[방문 고객]`을 분리한다.

```text
가게 오픈
→ 별도 고객 없이 제작 클릭
→ 별도 고객 없이 강화 클릭
→ 별도 고객 없이 일반 판매 클릭

별도 이벤트
→ 방문 고객 발생
→ 특정 종류 장비 요청
→ 요청에 대응할 제품 선택·준비
→ 방문 고객 거래 및 후속 결과
```

## 사용자 노출 용어

### 확정 명칭

- `보관함`: 플레이어가 현재 보유한 작업 중 제품·완제품·정비 필요 제품을 확인하는 곳
- `방문 고객`: 특정 종류의 장비를 요청하는 별도 고객 이벤트
- `일반 판매`: 방문 고객 이벤트 없이 보관함 제품을 클릭해 판매하는 기본 영업 행동

### 사용하지 않는 사용자 노출 표현

- 재고 탭
- 고객용 전용 장비
- 검투사 전용 재고
- 모험가 전용 완제품
- 고객 수에 맞춰 자동 생성된 판매 제품

내부 구현 변수나 데이터 구조에서 `inventory`와 같은 기술 명칭을 사용할지는 구현 계획의 문제다. 사용자에게 보이는 정식 명칭은 `보관함`이다.

## 보관함 계약

보관함은 세션마다 초기화되는 목록이 아니라 캠페인 동안 지속되는 제품 보유 상태다.

```text
재료 확보
→ 제작 시작
→ 작업 중 제품
→ 제작 완료
→ 보관함 등록
→ 강화·수리·정비
→ 일반 판매 또는 보유
→ 방문 고객 요청에 제안 가능
```

보관함의 제품은 고객과 독립적으로 존재한다.

- 고객이 방문하지 않아도 제품을 제작할 수 있다.
- 고객이 방문하지 않아도 제품을 강화할 수 있다.
- 고객이 방문하지 않아도 제품을 일반 판매할 수 있다.
- 미판매 제품은 보관함에 남는다.
- 고객 방문으로 제품이 자동 생성되지 않는다.
- 특정 고객에게 판매하기 전까지 미래 소유자가 고정되지 않는다.
- 같은 제품을 일반 판매와 방문 고객 거래에 동시에 확정할 수 없다.

## 가게 오픈 후 일반 영업

가게 오픈 후 기본 영업은 이름 있는 고객이나 고객 이벤트를 요구하지 않는다.

플레이어는 현재 자원과 보관함 상태를 기준으로 다음 행동을 직접 클릭해 진행한다.

### 제작

- 제작 가능한 제품 종류를 선택한다.
- 필요한 재료와 비용을 확인한다.
- 제작 결과가 보관함에 등록된다.
- 제작 완료와 재료 소비는 하나의 확정 상태로 저장한다.
- 제작 결과를 특정 방문 고객에게 자동 예약하지 않는다.

### 강화

- 보관함에서 제품을 선택한다.
- 성공률·비용·하락·파괴·보호 정보를 확인한다.
- 일반 강화·정밀강화·고위 정밀강화 계약을 그대로 사용한다.
- 강화 결과는 고객의 존재와 무관하게 제품 자체에 적용된다.
- 강화 후에도 제품은 플레이어가 판매하기 전까지 보관함에 남는다.

### 일반 판매

- 보관함의 판매 가능한 제품에서 `[판매]`를 선택한다.
- 별도의 이름 있는 고객 화면을 거치지 않는다.
- 일반 판매 가격과 획득 자원을 확인한 뒤 확정한다.
- 판매 보상과 제품의 보관함 제외 상태를 원자적으로 저장한다.
- 일반 판매는 방문 고객 관계·약속·지원·구독·세계 사건을 자동 생성하지 않는다.
- 일반 판매된 제품을 방문 고객에게 다시 판매할 수 없다.

일반 판매의 정확한 가격 계산, 익명 구매자 또는 시장 소유권의 표시 방식, 일반 판매 제품의 연대기 유지 범위는 후속 경제·장비 생애주기 결정에서 확정한다.

## 방문 고객 이벤트

`[방문 고객]`은 일반 판매 화면의 구매자 목록이 아니다. 특정 시점에 별도로 발생하는 **요청 이벤트**다.

방문 고객은 특정 장비 또는 장비 종류를 요청한다.

요청 예시의 구조:

```text
방문 고객 발생
→ 요청 장비 종류 공개
→ 최소 조건·선호·야망 공개
→ 보상·기한·후속 가능성 공개
→ 보관함에서 대응 제품 확인
→ 판매 또는 거절·보류
→ 관계·약속·세계 후속 결과
```

### 방문 고객 요청 정보

최소한 다음 정보를 명시한다.

- 요청 장비 종류 또는 범주
- 최소 요구 조건
- 선호 강화·수식어·내구·역사 가치 방향
- 고객의 야망 또는 사용 목적
- 제안 가격과 즉시 보상
- 응답 기한 또는 남은 영업일
- 거래 후 발생할 수 있는 후속 활동 방향

특정 종류 요청은 고객 전용 장비 타입을 의미하지 않는다.

예를 들어 고객이 `장검`을 요청해도:

- 장검은 일반 제작·판매 가능한 제품 종류다.
- 해당 고객만 장검을 구매할 수 있는 것이 아니다.
- 방문 전에 제작해 보관함에 둔 장검을 제안할 수 있다.
- 방문 후 새로 제작하거나 강화할 수 있는지는 이벤트 기한과 일반 영업 규칙에 따른다.
- 요청 조건에 맞지 않는 장검도 보관함에는 정상적으로 존재한다.

## 일반 판매와 방문 고객 거래의 차이

| 구분 | 일반 판매 | 방문 고객 거래 |
|---|---|---|
| 고객 이벤트 필요 | 없음 | 필요 |
| 시작 방식 | 보관함 제품의 판매 클릭 | 방문 고객 요청 발생 |
| 요구 장비 종류 | 없음 또는 시장 일반 조건 | 특정 종류·조건 요청 |
| 이름 있는 고객 | 없음 | 있음 또는 식별 가능한 이벤트 고객 |
| 가격 구조 | 기본 판매 가치 | 요청 적합도와 보상 반영 |
| 관계·약속 | 생성하지 않음 | 생성 가능 |
| 세계 후속 결과 | 자동 생성하지 않음 | 고객 유형에 따라 발생 가능 |
| 장비 선택 | 플레이어가 판매 제품 선택 | 요청에 맞는 보관함 제품 중 선택 |

두 판매 경로는 같은 제품 소유권과 중복 판매 방지 규칙을 공유하지만, 콘텐츠 목적과 보상 구조는 분리한다.

## 기존 네 고객 세션 결정 정정

추가 결정 17~18에서 정한 다음 전제는 이번 결정과 충돌하므로 그대로 유지하지 않는다.

- 모든 세션에서 수집가·모험가·검투사·병사 네 명이 동시에 방문
- 네 고객 모두에게 제품을 반드시 판매해야 영업 종료 가능
- 한 번의 영업 종료에서 네 고객 세계 결과를 항상 함께 판정
- 네 고객 판매를 위해 최소 네 제품 확보를 강제
- 일반 영업 전체가 고객 비교·배정 과정으로 구성

위 전제는 **`SUPERSEDED_BY_ADDENDUM_21`**로 처리한다.

네 고객 유형 자체와 고객별 후속 콘텐츠 방향은 폐기하지 않는다. 다만 이들은 매 세션 고정 구매자 네 명이 아니라, 각각 발생 가능한 방문 고객 이벤트 유형 또는 이름 있는 고객 콘텐츠로 재배치한다.

```text
수집가
모험가
검투사
병사
→ 모두 방문 고객 이벤트 후보
→ 발생 시 특정 종류 장비 요청
→ 보관함 제품으로 대응
→ 거래 성립 시 각자 후속 세계 활동 가능
```

각 고객의 등장 빈도, 동시 활성 수, 요청 종류, 기한과 재방문 규칙은 후속 결정에서 확정한다.

## 내비게이션 영향

기존 3영역 구조는 유지하되 의미를 다음처럼 정정한다.

### `[대장간]`

- 제작
- 강화·정밀강화
- 수리·정비
- 보관함 확인
- 일반 판매
- 가게 오픈·영업 종료

### `[방문 고객]`

- 현재 발생한 방문 고객 요청
- 요청 장비 종류와 조건
- 기한·보상·후속 가치
- 보관함 제품 제안
- 거래·거절·보류
- 약속·지원·관계·재방문

### `[세계]`

- 방문 고객 거래 이후 활동
- 검투사 경기
- 모험가 원정
- 수집가 전시·감정
- 병사 임무·부대 활동
- 장비 연대기와 결과

일반 판매를 위해 `[방문 고객]`로 이동하도록 강제하지 않는다.

## 저장·무결성 계약

- 제작 완료 시 재료 소비와 보관함 제품 생성을 원자적으로 저장한다.
- 강화 시 비용과 제품 상태를 원자적으로 저장한다.
- 일반 판매 시 보상과 보관함 제외를 원자적으로 저장한다.
- 방문 고객 거래 시 보상·소유권·관계·약속을 하나의 확정 상태로 저장한다.
- 일반 판매와 방문 고객 판매가 같은 제품에 중복 적용되지 않게 한다.
- 앱 재실행으로 판매 경로가 바뀌거나 제품이 복구·복제되지 않게 한다.
- 고객 요청이 만료돼도 보관함 제품 자체가 사라지지 않는다.
- 고객 요청을 거절하거나 놓쳐도 일반 제작·강화·판매는 계속 가능하다.
