## 1. 슬롯

```text
GRADE_AFFIX / CATALYST_AFFIX / CHRONICLE_AFFIX
```

정확히 세 슬롯이며 생성 원인·시점·변경 조건이 서로 다르다. 일반 수식어 A·B 구조는 `[대체됨]`이다.

## 2. 이름 조합

```text
[등급 수식어] 촉매 수식어 기본 작품명 - 연대기 수식어
```

```text
[명품] 예리한 강철 장검 - 투기장의 승자
```

- 등급 수식어는 대괄호
- 촉매 수식어는 기본 작품명 앞
- 연대기 수식어는 하이픈 뒤
- 빈 촉매·연대기 부분은 자연스럽게 생략
- 데이터는 세 독립 UID 필드

## 3. GRADE_AFFIX

현재 제작 등급:

```text
CRAFT_NORMAL / 보통
CRAFT_SUPERIOR / 우수
CRAFT_FINE / 명품
CRAFT_MASTERWORK / 걸작
CRAFT_LEGENDARY / 전설
```

- 최초 직접 단조 완료 시 즉시 생성
- 동일 UID에서 영구 고정
- 제작 후 승격·강등 없음
- `전설`은 최초 제작에서만 극희귀하게 발생
- 강화·촉매·연대기·감정·명성·복원·상속으로 변경되지 않음
- 등급 수식어가 제작 등급 효과를 다시 더하는 이중 배율이 되지 않음

이전 4단계 `[보통] → [우수] → [걸작] → [전설]`과 과거 구현 `STANDARD / GOOD / PERFECT`는 현재 제품 모델이 아니다.

## 4. CATALYST_AFFIX

```text
EMPTY → SEED → DEVELOPED → EVOLVED → MASTERED
```

- 최초 제작 시 `EMPTY`
- 정밀강화의 현재·누적 촉매 이력으로 확률적 생성·성장·분기·변형
- 같은 계보 반복은 성장 가능성을 높임
- 호환 계보 전환은 분기 가능성을 높임
- 무관한 계보로 무작위 교체 금지
- 연대기와 제작 등급이 직접 변경하지 않음

## 5. CHRONICLE_AFFIX

- 최초 제작 시 `EMPTY`
- 고객·사건·사용·손상·복원·전시·증여·상속 등 의미 있는 실제 기록으로 생성·진화
- 낮은 위험 반복 파밍 금지
- 촉매와 제작 등급이 직접 변경하지 않음
- 현재 이름에는 현재 연대기 하나만 표시하고 과거 계보는 UID 상세에 보존

## 6. 예술성과의 경계

```text
예술성 7/10
```

예술성은 수식어 슬롯이 아니라 숫자형 무기·작품 능력치다.

- 단계명 없음
- 제작 등급과 별도
- 촉매·연대기 슬롯을 점유하지 않음
- 전투 성능을 기본적으로 올리지 않음
- 판매 가치와 특정 고객·전시·감정 수요에 기여 가능

작품 종류 + 주재료 + 직접 단조
→ 기본 작품명·기본 성능·제작 등급
