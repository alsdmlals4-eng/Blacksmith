## 1. 결정 요약

모든 작품은 다음 세 수식어 슬롯을 서로 독립적으로 가진다.

```text
1. 등급 수식어 / GRADE_AFFIX
2. 촉매 수식어 / CATALYST_AFFIX
3. 연대기 수식어 / CHRONICLE_AFFIX
```

세 슬롯은 생성 원인, 생성 시점, 변경 조건, 고정 여부가 다르다. 한 슬롯의 원인이 다른 슬롯을 직접 생성·교체·성장시키지 않는다.

기존 `일반 수식어 A·B + 별도 사건 수식어` 구조는 현재 정본이 아니다. 최신 구조는 `등급 1 + 촉매 1 + 연대기 1`의 정확히 세 슬롯이다.

## 2. 작품 이름과 수식어 표시

작품의 기본 이름은 계속 주재료와 작품 종류가 결정한다.

```text
주재료 + 작품 종류
예: 철검 / 강철 방패 / 은합금 의장검
```

수식어는 기본 작품명과 별도 데이터로 저장한다.

```text
기본 작품명: 강철검
등급 수식어: [제작 등급 표식]
촉매 수식어: [촉매 계보 표식 또는 비어 있음]
연대기 수식어: [연대기 표식 또는 비어 있음]
```

등급 수식어를 기본 작품명 앞에 축약 표시할 수는 있지만 저장 구조와 상세 화면에서는 세 슬롯을 분리한다. 세 수식어를 모두 긴 접두사로 연결해 작품 이름을 읽기 어렵게 만들지 않는다.

## 3. 등급 수식어

### 3.1 생성

- 직접 단조가 끝나고 제작 등급이 확정되는 순간 한 개가 생성된다.
- 초기 제작 품질 기준선은 기존 구현의 `STANDARD / GOOD / PERFECT`를 사용한다.
- 정확한 한국어 표시명은 후속 콘텐츠·현지화 Gate에서 정한다.

### 3.2 역할

- 작품이 어떤 제작 등급으로 태어났는지 영구적으로 표시한다.
- 제작 등급이 이미 제공하는 기본 성능·가치 차이를 설명한다.
- 등급 수식어 자체가 같은 제작 등급 효과를 다시 더하는 두 번째 배율이 되어서는 안 된다.

### 3.3 고정 규칙

- 강화 성공·실패·대파·단계 하락으로 변경되지 않는다.
- 촉매, 강화 방식, 작품 사용, 사건, 손상, 복원, 감정, 전시, 상속으로 변경되지 않는다.
- 같은 UID 작품을 복원하거나 재강화해도 유지한다.
- 완전히 새로운 UID로 다시 제작한 경우에만 새 제작 등급을 판정한다.

## 4. 촉매 수식어

### 4.1 생성

- 최초 제작 시에는 비어 있다.
- 정밀강화 이정표에서 사용한 촉매가 후보 계보와 확률을 설정한다.
- 성공 시 후보 계보 안에서 씨앗이 생성되거나 기존 촉매 수식어가 성장·분기·변형될 수 있다.
- 촉매는 정확한 결과와 강화 성공을 보장하지 않는다.

### 4.2 영향 원인

촉매 수식어에 직접 영향을 주는 것은 다음이다.

- 현재 정밀강화에서 사용한 촉매
- 작품 UID에 누적된 촉매 사용 순서와 반복·혼합 이력
- 현재 촉매 수식어의 계보와 단계
- 촉매와 주재료·강화 방식의 호환 여부
- 정밀강화 이정표가 허용하는 성장 상한

작품 연대기와 제작 등급은 촉매 수식어의 계보를 직접 생성·교체·진화시키지 않는다.

### 4.3 생애주기

```text
EMPTY
→ SEED / 씨앗
→ DEVELOPED / 성장
→ EVOLVED / 진화
→ MASTERED / 완성
```

- 같은 촉매 계열 반복: 같은 계보 성장 가능성 상승
- 호환 촉매 전환: 분기 가능성 상승
- 희귀 호환 촉매 이력: 혼합 변형 후보 추가
- 비호환 촉매 이력: 변형 가능성 저하 또는 위험·비용 증가 가능
- 기존 계보와 무관한 완전 무작위 교체 금지

강화 단계는 다음 기회와 상한을 열 뿐이며, 촉매를 사용하지 않은 일반 강화만으로 촉매 수식어가 자동 성장하지 않는다.

## 5. 연대기 수식어

### 5.1 생성

- 최초 제작 시에는 비어 있다.
- 작품이 실제 고객·사건·사용·소유 이력에서 의미 있는 기록을 얻었을 때 생성될 수 있다.
- 단순 판매, 낮은 위험 반복 작업, 같은 사건의 반복만으로 자동 생성하지 않는다.

### 5.2 영향 원인

연대기 수식어에 직접 영향을 주는 것은 다음이다.

- 검투 경기·전쟁·원정·사냥·구조·의례·전시 결과
- 고객의 생존·패배·명성·재방문
- 작품의 큰 손상·상실·회수·복원
- 가문 증여·상속·소유권 변화
- 감정·수상·왕실 또는 세력 기록
- 사건 중요도·고유성·반복 감쇠

촉매와 제작 등급은 연대기 수식어의 이름·계보·진화 결과를 직접 결정하지 않는다.

### 5.3 성장·진화

- 연대기 수식어는 실제 작품 일대기가 누적될 때 강화·분기·변형된다.
- 서로 관련된 기록이 이어지면 기존 연대기 정체성이 깊어진다.
- 의미가 크게 전환되는 사건은 호환되는 새 분기를 만들 수 있다.
- 무관한 사건 하나가 기존 연대기 수식어를 임의로 교체하지 않는다.
- 모든 변화는 작품 UID의 연대기 기록과 연결한다.

정확한 단계명·임계값·사건 점수는 `BASELINE_TEST_PRESET`이다.
