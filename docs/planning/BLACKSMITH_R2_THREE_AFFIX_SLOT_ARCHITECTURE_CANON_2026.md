## 1. 결정 요약

모든 작품은 다음 세 수식어 슬롯을 서로 독립적으로 가진다.

```text
1. 등급 수식어 / GRADE_AFFIX
2. 촉매 수식어 / CATALYST_AFFIX
3. 연대기 수식어 / CHRONICLE_AFFIX
```

세 슬롯은 생성 원인, 생성 시점, 변경 조건, 고정 여부가 다르다. 한 슬롯의 원인이 다른 슬롯을 직접 생성·교체·성장시키지 않는다.

기존 `일반 수식어 A·B + 별도 사건 수식어` 구조는 현재 정본이 아니다. 최신 구조는 `등급 1 + 촉매 1 + 연대기 1`의 정확히 세 슬롯이다.

## 2. 작품 이름과 수식어 표시

작품의 기본 이름은 계속 주재료와 작품 종류가 결정한다.

```text
주재료 + 작품 종류
예: 철검 / 강철 방패 / 은합금 의장검
```

수식어는 기본 작품명과 별도 데이터로 저장하지만 장비명에서는 다음 순서로 조합한다.

```text
[등급 수식어] 촉매 수식어 기본 작품명 - 연대기 수식어
```

대표 예시:

```text
[걸작] 예리한 강철 장검 - 투기장의 승자
```

슬롯이 비어 있으면 해당 부분을 자연스럽게 생략한다.

```text
[걸작] 강철 장검
[걸작] 예리한 강철 장검
[걸작] 강철 장검 - 투기장의 승자
[걸작] 예리한 강철 장검 - 투기장의 승자
```

- 등급 수식어는 대괄호로 구분한다.
- 촉매 수식어는 기본 작품명 앞에 붙인다.
- 연대기 수식어는 하이픈 뒤에 붙인다.
- 연대기 수식어가 없으면 하이픈도 함께 생략한다.
- 장비명에는 현재 연대기 수식어 하나만 표시한다.
- 저장 구조와 상세 화면에서는 세 슬롯을 계속 분리한다.
- 기존 임시 제작 등급 라벨 `[명품]`은 사용하지 않는다.

## 3. 등급 수식어

### 3.1 생성

- 직접 단조가 끝나고 제작 등급이 확정되는 순간 한 개가 생성된다.
- 현재 제품 기획은 `BS-CRAFT-20260804-07`의 네 단계다.

```text
CRAFT_NORMAL / 보통
CRAFT_SUPERIOR / 우수
CRAFT_MASTERWORK / 걸작
CRAFT_LEGENDARY / 전설
```

- `전설`은 최초 제작 판정에서만 극희귀하게 발생한다.
- 과거 구현의 `STANDARD / GOOD / PERFECT`는 `REFERENCE_IMPLEMENTATION / HISTORICAL_IMPLEMENTED_VALUE`로만 보존한다.

### 3.2 역할

- 작품이 어떤 제작 완성도로 태어났는지 영구적으로 표시한다.
- 제작 등급이 이미 제공하는 기본 성능·가치 차이를 설명한다.
- 등급 수식어 자체가 같은 제작 등급 효과를 다시 더하는 두 번째 배율이 되어서는 안 된다.
- 제작 등급은 기술적 완성도이며 예술성·촉매 계보·작품 연대기·명성과 별도다.

### 3.3 고정 규칙

- 강화 성공·실패·대파·단계 하락으로 변경되지 않는다.
- 촉매, 강화 방식, 작품 사용, 사건, 손상, 복원, 감정, 전시, 명성, 상속으로 변경되지 않는다.
- 같은 UID 작품을 복원하거나 재강화해도 유지한다.
- 제작 후 `걸작 → 전설` 승격은 없다.
- 완전히 새로운 UID로 다시 제작한 경우에만 새 제작 등급을 판정한다.

## 4. 촉매 수식어

### 4.1 생성

- 최초 제작 시에는 비어 있다.
- 정밀강화 이정표에서 사용한 촉매가 후보 계보와 확률을 설정한다.
- 성공 시 후보 계보 안에서 씨앗이 생성되거나 기존 촉매 수식어가 성장·분기·변형될 수 있다.
- 촉매는 정확한 결과와 강화 성공을 보장하지 않는다.

### 4.2 영향 원인

촉매 수식어에 직접 영향을 주는 것은 다음이다.

- 현재 정밀강화에서 사용한 촉매
- 작품 UID에 누적된 촉매 사용 순서와 반복·혼합 이력
- 현재 촉매 수식어의 계보와 단계
- 촉매와 주재료·강화 방식의 호환 여부
- 정밀강화 이정표가 허용하는 성장 상한

작품 연대기와 제작 등급은 촉매 수식어의 계보를 직접 생성·교체·진화시키지 않는다.

### 4.3 생애주기

```text
EMPTY
→ SEED / 씨앗
→ DEVELOPED / 성장
→ EVOLVED / 진화
→ MASTERED / 완성
```

- 같은 촉매 계열 반복: 같은 계보 성장 가능성 상승
- 호환 촉매 전환: 분기 가능성 상승
- 희귀 호환 촉매 이력: 혼합 변형 후보 추가
- 비호환 촉매 이력: 변형 가능성 저하 또는 위험·비용 증가 가능
- 기존 계보와 무관한 완전 무작위 교체 금지

강화 단계는 다음 기회와 상한을 열 뿐이며, 촉매를 사용하지 않은 일반 강화만으로 촉매 수식어가 자동 성장하지 않는다.

## 5. 연대기 수식어

### 5.1 생성

- 최초 제작 시에는 비어 있다.
- 작품이 실제 고객·사건·사용·소유 이력에서 의미 있는 기록을 얻었을 때 생성될 수 있다.
- 단순 판매, 낮은 위험 반복 작업, 같은 사건의 반복만으로 자동 생성하지 않는다.

### 5.2 영향 원인

연대기 수식어에 직접 영향을 주는 것은 다음이다.

- 검투 경기·전쟁·원정·사냥·구조·의례·전시 결과
- 고객의 생존·패배·명성·재방문
- 작품의 큰 손상·상실·회수·복원
- 가문 증여·상속·소유권 변화
- 감정·수상·왕실 또는 세력 기록
- 사건 중요도·고유성·반복 감쇠

촉매와 제작 등급은 연대기 수식어의 이름·계보·진화 결과를 직접 결정하지 않는다.

### 5.3 성장·진화

- 연대기 수식어는 실제 작품 일대기가 누적될 때 강화·분기·변형된다.
- 서로 관련된 기록이 이어지면 기존 연대기 정체성이 깊어진다.
- 의미가 크게 전환되는 사건은 호환되는 새 분기를 만들 수 있다.
- 무관한 사건 하나가 기존 연대기 수식어를 임의로 교체하지 않는다.
- 모든 변화는 작품 UID의 연대기 기록과 연결한다.

정확한 단계명·임계값·사건 점수는 `BASELINE_TEST_PRESET`이다.

## 6. 최초 제작 결과 교정

```text
작품 종류 + 주재료 + 직접 단조
→ 기본 작품명·기본 성능·제작 등급 확정
→ 등급 수식어 1개 즉시 부여
→ 촉매 수식어는 EMPTY
→ 연대기 수식어는 EMPTY
```

따라서 최초 제작품은 모든 수식어가 없는 작품이 아니다. `촉매 수식어와 연대기 수식어가 아직 없는 작품`이다.

## 7. 슬롯 독립성 계약

| 슬롯 | 생성 원인 | 최초 제작 상태 | 변경 가능성 |
|---|---|---|---|
| 등급 수식어 | 최초 제작 등급 | 즉시 생성 | 동일 UID에서 고정 |
| 촉매 수식어 | 정밀강화 촉매 이력 | 비어 있음 | 정밀강화 촉매 이력으로 성장·분기·변형 |
| 연대기 수식어 | 실제 작품 일대기 | 비어 있음 | 중요한 연대기로 생성·성장·분기·변형 |

다음 교차 영향은 금지한다.

- 촉매로 등급 수식어 변경
- 사건·연대기로 등급 수식어 변경
- 연대기로 촉매 수식어 진화
- 촉매로 연대기 수식어 구매·생성
- 제작 등급만으로 촉매·연대기 수식어 자동 생성
- 한 슬롯 결과가 다른 슬롯을 삭제하거나 덮어쓰기

## 8. 능력치와 수식어 관계

- 주재료: 기본 이름과 기본 성능 범위
- 제작 등급: 출생 품질과 고정 등급 수식어
- 강화 방식: 정밀강화의 세부 수치 변화
- 촉매 수식어: 촉매 계보에서 파생되는 특수 효과와 정체성
- 연대기 수식어: 작품이 실제로 겪은 역사에서 파생되는 조건부 효과와 의미
- 예술성: 별도 단일 가치 수치

제작 등급이 높아도 예술성이 자동 최고가 되지 않으며, 예술성이 높아도 제작 등급 수식어가 바뀌지 않는다. 예술성 최종 한국어 단계명은 후속 Decision에서 정하며 `보통 / 우수 / 걸작 / 전설`을 재사용하지 않는다.

## 9. 표시·상호작용 계약

작품 상세 화면은 다음을 구분해 표시한다.

```text
[등급] 촉매 수식어 기본 작품명 - 연대기 수식어
제작 등급과 등급 수식어
촉매 수식어와 촉매 계보·단계
연대기 수식어와 관련 핵심 기록
강화 단계와 세부 능력치
예술성
```

연대기 수식어가 존재하면 장비명 뒤의 연대기 수식어 부분을 누를 수 있다.

```text
[걸작] 예리한 강철 장검 - 투기장의 승자 ›
                         └ 연대기 상세 열기
```

누르면 현재 장비 상세 맥락을 유지하는 하단 상세 패널을 열고 다음을 보여준다.

- 현재 연대기 수식어와 짧은 설명
- 최초 형성 사건
- 주요 연대기 타임라인
- 과거 수식어에서 현재 수식어까지의 진화 계보
- 현재 조건부 효과·위신·감정 가치
- 소유자·고객·사건 결과와 손상·복원·상속 기록

일반 반복 로그는 제외하고 수식어 형성과 변화에 영향을 준 핵심 기록만 표시한다. 모든 상세 항목은 작품 UID 기록에 근거해야 한다. 구체 계약은 `BS-UX-20260804-01`을 따른다.

## 10. 적대적 보호 조건

- 세 슬롯을 다시 `일반 수식어 A·B`로 통합하는 구조 금지
- 등급 수식어가 제작 등급 효과를 중복 가산하는 구조 금지
- 강화·복원·촉매·연대기·감정·명성으로 등급 수식어 변경 금지
- 제작 후 `걸작 → 전설` 승격 금지
- `전설`이 예술성·촉매·연대기·최강 성능을 자동 보장하는 구조 금지
- 연대기가 촉매 수식어를 직접 성장·진화시키는 구조 금지
- 촉매가 연대기 수식어를 직접 생성·구매하게 하는 구조 금지
- 한 슬롯이 다른 슬롯을 삭제·교체하는 구조 금지
- 제작 등급과 예술성 시각 단계를 동일시하는 구조 금지
- 현재·과거 연대기 수식어를 장비명에 모두 나열하는 구조 금지
- 실제 UID 기록에 없는 연대기를 확정 역사처럼 표시하는 구조 금지
- 연대기 상세에 원본 로그를 필터 없이 전부 덤프하는 구조 금지
- 연대기 누르기가 게임 판정·보상·수식어 진화를 발생시키는 구조 금지
- 낮은 위험 반복으로 연대기 수식어를 무한 파밍하는 구조 금지
- 과거 3단계 구현 PASS를 현재 4단계 제품 구현 PASS로 해석 금지
