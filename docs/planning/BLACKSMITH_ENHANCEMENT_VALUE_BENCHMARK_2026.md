# 블랙스미스 강화 확률·판매가 벤치마크 — 2026

> 상태: `PLANNING_IN_PROGRESS`
>
> 기준일: 2026-07-26
>
> 목적: 강화형 게임의 성공 확률·실패 보호·거래 가격 사례와 현재 블랙스미스 POC 수치를 비교해 공개시장 판매가 곡선의 수정안을 제안한다.
>
> 효력: 시나리오 런처 배포 범위는 사용자 승인에 따라 `POC_CONFIRMED`다. 아래 신규 판매가 곡선은 사용자 승인 전까지 `PROPOSED_ONLY`이며 기존 POC 데이터 값을 자동으로 대체하지 않는다.

## 1. 확정: 시나리오 런처 배포 범위

POC 시나리오 런처는 개발·POC 빌드 전용으로 제공한다.

- 개발 또는 POC 빌드 플래그가 활성화된 경우에만 진입 가능
- 일반 출시 빌드에서는 메뉴와 진입 경로를 노출하지 않음
- POC 전용 저장 프로필을 사용
- 일반 플레이 저장 데이터에 자원·장비·진행도를 기록하지 않음
- 시나리오별 초기화는 POC 프로필 안에서만 수행

상태: `POC_CONFIRMED`

## 2. 외부 벤치마크

### 2.1 Black Desert — Godr-Ayed

공식 문서 기준 대표 성공률:

| 구간 | 성공률 |
|---|---:|
| +0 → PRI | 9.90% |
| PRI → DUO | 7.00% |
| DUO → TRI | 6.00% |
| TRI → TET | 4.50% |
| TET → PEN | 3.15% |

개발사는 Godr-Ayed의 전체 강화 비용이 PEN Blackstar 획득 비용과 유사하도록 설계했고, 최종 장비 가치를 유지하기 위해 중앙시장 최대 가격을 올렸다고 설명한다. 또한 각 강화 단계 장비를 시장에서 거래할 수 있다.

설계 교훈:

- 거래 가능한 강화 장비의 가격은 단일 성공 시도 비용이 아니라 해당 단계까지의 누적 기대 비용을 반영해야 함
- 낮은 성공률을 작은 단계로 분할하더라도 최종 장비 가치가 누적 비용보다 낮아지면 제작·강화 동기가 붕괴함

출처:

- https://www.naeu.playblackdesert.com/en-US/Adventure/history?_groupmasterno=3307

### 2.2 Black Desert — Preonne

공식 문서 기준 고정 성공률은 25%에서 시작해 최종 단계에서 7.5%까지 낮아진다. 실패 시 단계 하락이 존재하고, 단계별 Agris Essence 보장선은 6회에서 20회다.

설계 교훈:

- 보장선은 최악의 경험을 제한할 뿐, 판매 가격을 낮게 책정해도 된다는 의미가 아님

공식 가이드에서 강화 단계가 높아질수록 성공률이 낮아지고, 15성 이상에서는 실패 시 파괴가 발생할 수 있다고 설명한다. 파괴 방지는 추가 메소를 요구하며, 하락 방지 구간과 찬스타임이 존재한다.

## 3. 현재 블랙스미스 수치 비교

현재 런타임 강화 계약의 목표 단계별 기본 성공률은 다음 방향이다.

| 목표 단계 | 기본 성공률 |
|---|---:|
| +10 | 68.0% |
| +20 | 65.5% |
| +30 | 63.0% |
| +40 | 60.5% |
| +50 | 58.0% |
| +60 | 55.5% |

추가 규칙:

- 실패 1회당 성공 보정 +4%p
- 누적 보정 상한 +24%p
- 중·고강화에서 단계 하락
- +30 이후 파괴 가능
- 보호석·회복석·실패 완충 타격으로 손실 완화 가능

Black Desert의 3.15~25% 구간보다 기본 성공률은 높지만, 블랙스미스는 60회의 순차 성공과 하락·파괴 복구를 요구한다. 따라서 최종 장비 가격은 성공률 숫자만 비교해서 낮게 잡을 수 없다.

## 4. POC 비용 모델

### 4.1 모델 가정

- 현재 POC 강화 골드·재료 비용 사용
- 현재 성공률 패턴과 실패 누적 보정 사용
- 현재 단계 하락·파괴 비율 사용
- 균형 단조 기준
- 보호석·회복석·특수 타격 미사용
- 파괴 시 대표 장비를 다시 제작
- 강화 재료 1개를 POC 내부 그림자 가격 50골드로 환산
- 5,000회 모의 시행의 평균값을 비교 기준으로 사용

이 값은 출시 경제 예측이 아니라 POC 가격곡선의 상대적 적정성을 확인하기 위한 내부 모델이다.

### 4.2 대표 누적 비용

| 목표 단계 | 평균 골드 환산 비용 | 현재 공개시장가 | 현재가/평균비용 |
|---|---:|---:|---:|
| +10 | 약 3,900 | 2,500 | 약 0.64배 |
| +20 | 약 9,100 | 6,500 | 약 0.71배 |
| +30 | 약 23,700 | 16,000 | 약 0.68배 |
| +40 | 약 60,600 | 40,000 | 약 0.66배 |
| +50 | 약 159,000 | 105,000 | 약 0.66배 |
| +60 | 약 565,000 | 275,000 | 약 0.49배 |

판정:

- 현재 공개시장가는 대표 제작비보다 전 구간에서 낮음
- 특히 +60은 평균 비용의 절반 수준이라 고강화 후 즉시 판매 루프가 손해 행동이 될 가능성이 큼
- 고객·군사·밀수·수집가 배율이 있어도 공개시장 자체가 손해 기준이면 채널 선택이 아니라 특수 거래 강제가 됨

## 6. 권장안의 채널 처리

권장 가격곡선을 적용하더라도 첫 POC에서는 거래 채널 배율을 변경하지 않는다.

- 방문 고객: +10~25%
- 군사 보급: +15%
- 밀수: +35%
- 수집가: +20~80%
- 전시: 직접 골드 없음

이유:

- 기본 공개시장가와 특수 채널 배율을 동시에 올리면 원인을 분리해 검증하기 어려움
- 먼저 공개시장 기준가를 조정하고, 특수 거래 선택률과 통화량을 측정한 뒤 배율을 조정하는 편이 안전함

권장 +60 예시:

| 채널 | 대표 가격 |
|---|---:|
| 공개시장 | 1,000,000 |
| 방문 고객 | 1,100,000~1,250,000 |
| 군사 보급 | 1,150,000 + 세계 보상 |
| 밀수 | 1,350,000 + 적발 위험 |
| 수집가 | 1,200,000~1,800,000 |

## 7. 검증 지표

가격곡선을 변경하면 다음을 기록한다.

- 단계별 평균·중앙값·75백분위 누적 제작비
- +10 단위 판매율
- +40 이상 도전율
- 공개시장·고객·군사·밀수·수집가 선택 비중
- 한 번 판매 후 다음 동일 단계 재도달 시간
- 골드 부족으로 제작·강화를 전혀 못 하는 소프트락 비율
- 보호석·회복석 구매 비중
- +60 판매 후 보유 골드가 다음 장비 +30 도달 비용을 과도하게 초과하는지

목표 방향:

- 공개시장은 즉시성과 확실성의 기준 채널
- 특수 채널은 추가 조건·위험·대기 대가로 더 높은 수익 제공
- 공개시장 판매가 구조적으로 손해가 되지 않음
- +60 한 번으로 이후 POC 경제가 무의미해지지 않음

## 8. 현재 판정

- 개발·POC 빌드 전용 시나리오 런처: `POC_CONFIRMED`
