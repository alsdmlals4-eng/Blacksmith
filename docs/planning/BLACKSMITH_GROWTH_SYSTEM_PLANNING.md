> 상태: `PLANNING_IN_PROGRESS`
>
> 기준일: 2026-07-25
>
> 목적: 대화에서 승인된 플레이어 성장축, 전문 분야 트리, 분야별 기술 돌파, 화술, 명예 단계와 정보 공개 규칙을 누락 없이 통합한다.
>
> 효력: 이 문서는 `BLACKSMITH_MASTER_GAME_DESIGN_PLANNING.md`의 기존 화술·제작·강화 성장 및 분야별 돌파 설명 중 충돌하는 구형 규칙을 대체한다. 사용자의 정확한 명령 `기획 완료` 전까지 검수 단계로 전환하지 않는다. 정확한 수치·단계 수·확률·비용·상한은 별도 승인 전까지 `PROPOSED_ONLY`다.

## 1. 성장 시스템의 설계 목표

블랙스미스의 성장은 강화 중심 클리커 루프를 보조해야 하며, 성장 화면 관리가 강화 클릭의 템포를 대체해서는 안 된다.

성장 시스템은 다음 네 원칙을 따른다.

1. **행동과 성장의 인과성**: 제작 경험은 제작과 해당 장비 분야를, 강화 경험은 강화와 해당 장비 분야를 성장시킨다.
2. **현재 빌드와 영구 성장을 분리**: 메인 전문 분야는 제한된 당일 전략이고, 보조 전문 분야는 누적되는 영구 기반이다.
3. **확정 수치와 결과 불확실성을 분리**: 플레이어가 투자한 고정 효과는 정확히 공개하되, 최종 결과 확률은 단계와 원인으로 요약한다.
4. **코어 경제 보호**: 성장·명예·관계·국가 시스템이 공개시장 고정 매입가나 메인 강화 수익을 무제한 증폭하지 않는다.

## 2. 통합 성장축

### 2.1 플레이어 직접 성장

1. 공통 대장장이 등급
2. 제작 숙련과 제작 메인 전문 분야
3. 강화 숙련과 강화 메인 전문 분야
4. 무기 분야 숙련·기술 돌파·전문 분야
5. 방어구 분야 숙련·기술 돌파·전문 분야
6. 보조 장비 분야 숙련·기술 돌파·전문 분야
7. 장신구 분야 숙련·기술 돌파·전문 분야
8. 공통 화술 숙련과 화술 메인 전문 분야

### 2.2 계정 지식 성장

1. 대표 제작법 친숙도
2. 재료·촉매 조합 도감
3. 특수 재료별 숙련
4. 역사 장비 도감

### 2.3 대장간 성장

1. 제작 시설
2. 강화 시설
3. 복구 시설
4. 보관 시설
5. 전시 시설
6. 관리·자동화 편의
7. 대장간 명성

### 2.4 세계 성장

1. 고객별 신뢰·생애주기
2. 국가 군사력
3. 국가 영향력
4. 외국·중개인·수집가 네트워크

## 3. 공통 대장장이 등급

공통 대장장이 등급은 전체 진행도와 콘텐츠 해금을 담당한다.

### 3.1 주요 역할

- 신규 시설과 시설 단계 해금
- 장비 분야별 기술 돌파의 선행 조건
- 상위 고객·군사 계약·국가 콘텐츠 개방
- 신규 장비 분야와 관리 기능 해금
- 제작법·복구·전시·자동화 기능 접근 조건
- 계정 전체 성장도 표시

### 3.2 허용되는 소규모 편의 보정

- 제작·강화 결과 정보 표시 개선
- 일괄 제작·판매·필터 기능 확장
- 즐겨찾기·비교·최근 빌드 기록 기능
- 반복 작업 입력 간소화
- 거래·고객·국가 알림 정리
- 일부 연출 단축

### 3.3 직접 제공하지 않는 성능

- 강화 성공률의 큰 직접 보정
- 제작 품질의 큰 직접 보정
- 공개시장 판매가 상승
- 상점 할인율·흥정률 상승
- 고객 신뢰 자동 증가
- 특수 재료 성공률 상승

이 수치들은 각각 제작, 강화, 분야 기술, 화술, 관계, 특수 재료 숙련이 담당한다.

## 4. 성장 경험치 획득

모든 성장축은 `행동 경험 + 의미도 보정 + 최초 기록 보너스`를 사용한다.

### 4.1 공통 규칙

- 정상적인 제작·강화·거래·대화에서도 관련 경험을 얻는다.
- 현재 숙련에 비해 지나치게 쉬운 행동은 경험 효율이 감소한다.
- 신규 강화 구간, 신규 제작법, 최초 고품질 결과에는 큰 보너스를 준다.
- 고객에게 실제로 유용한 장비 제공, 계약 완수 등 결과가 있는 행동에 추가 보정을 준다.
- 실패도 새로운 위험 구간, 손상, 복구 경험이라면 일부 성장을 제공한다.
- 자동 판매와 무의미한 반복 클릭은 핵심 경험 공급원이 되지 않는다.
- 각 성장축은 직접 관련된 행동에서만 경험을 얻는다.

### 4.2 행동별 예시

| 행동 | 성장하는 축 |
|---|---|
| 무기 제작 | 제작 숙련, 무기 분야 숙련, 제작법 친숙도 |
| 무기 고강화 | 강화 숙련, 무기 분야 숙련 |
| 손상 장비 복원 | 제작·강화 숙련, 복원 관련 성장 |
| 고객에게 적합한 장비 제공 | 관련 제작·분야 숙련, 관계·화술 성과 |
| 수집가 흥정 | 화술 숙련, 관련 화술 전문 분야 경험 |
| 특수 재료 고위 정밀강화 | 강화 숙련, 해당 특수 재료 숙련 |
| 군사 계약 완수 | 관련 장비 분야 숙련, 공통 진행도 |
| 단순 공개시장 판매 | 숙련 경험을 거의 또는 전혀 제공하지 않음 |

### 4.3 반복 감쇠 기준

- 현재 숙련 대비 난도
- 강화 단계와 위험도
- 제작 결과 품질
- 신규성
- 고객·계약 요구와의 적합성
- 소비한 자원과 실제 손실 가능성
- 동일 행동의 최근 반복 횟수

정확한 경험 공식은 `PROPOSED_ONLY`다.

## 5. 성장 보상의 두 층

각 성장축의 전문 분야는 `메인 전문 분야 트리`와 `보조 전문 분야 트리`로 나뉜다.

| 구분 | 메인 전문 분야 | 보조 전문 분야 |
|---|---|---|
| 목적 | 현재 운영 빌드 결정 | 계정 기반 영구 성장 |
| 효과 강도 | 강함 | 작고 누적형 |
| 포인트 | 제한됨 | 장기적으로 전부 획득 가능 |
| 회수 | 영업 전 준비 단계에서 가능 | 불가능 |
| 적용 | 현재 투자한 노드 | 해금한 모든 노드 상시 적용 |
| 최상위 고유 기능 | 있음 | 없음 |
| 프리셋 | 사용하지 않음 | 변경 개념 없음 |

기존의 활성 숙련 특성 슬롯, 작업별 통합 프리셋, 프리셋 자동 변형, 작업 세션 단위 특성 장착 규칙은 폐기한다.

## 6. 영업 전 준비 단계와 당일 잠금

전문 분야 트리 투자는 가게 오픈 전 준비 단계에서만 가능하다.

```text
새 게임 날짜 시작
→ 영업 전 준비
→ 메인 투자·회수·초기화 및 보조 영구 투자
→ 가게 오픈
→ 모든 전문 분야 투자 상태 잠금
→ 영업 종료
→ 다음 날짜 준비 단계에서 다시 변경 가능
```

### 6.1 준비 단계에서 가능한 조작

- 메인 신규 특성 투자
- 메인 개별 특성 취소
- 반환 포인트 재투자
- 메인 전체 초기화
- 공통 보너스 포인트 재배치
- 보조 전문 노드 영구 투자
- 현재 빌드와 예상 효과 확인

### 6.2 영업 중 규칙

- 제작·강화·화술·장비 분야 메인 트리 변경 불가
- 보조 전문 분야 신규 투자 불가
- 영업 중 얻은 포인트와 해금 조건은 즉시 기록
- 실제 투자는 다음 준비 단계부터 가능
- 전문 분야 화면은 읽기 전용
- 같은 날짜에 가게를 닫았다 다시 열어도 잠금 유지
- 저장 후 재접속하거나 영업이 강제 중단되어도 당일 구성 유지

모든 작업 결과는 가게를 열었을 때 확정된 당일 메인 구성을 사용한다.

## 7. 메인 전문 분야 트리

### 7.1 기본 구조

모든 메인 트리는 같은 시각 문법을 사용한다.

```text
자동 해금되는 기본 기능
+ 선택형 범용 노드
+ 안정형 분기
+ 성능형 분기
+ 효율형 분기
```

### 7.2 자동 해금 기본 기능

숙련 조건을 충족하면 포인트 없이 개방한다.

- 트리와 역할 분기 접근
- 기본 정보 표시
- 작업 결과 비교
- 위험·비용·예상 범위 확인
- 성장축의 기본 조작 기능

기본 사용성을 의무 포인트 비용으로 만들지 않는다.

### 7.3 선택형 범용 노드

- 역할 분기와 무관한 소수의 정보·편의 노드
- 역할별 분기의 필수 선행 조건으로 사용하지 않음
- 범용 노드 없이 역할 분기로 바로 진입 가능
- 강한 결과 보정과 고유 기능은 역할 분기에 배치
- 범용 노드 투자는 역할 분기 누적 투자량에 포함하지 않음

### 7.4 역할별 분기

| 역할 | 설계 목적 |
|---|---|
| 안정형 | 실패 손실, 하락, 손상, 흥정 철회, 관계 악화 등 위험 관리 |
| 성능형 | 품질, 수식어 성장, 강화 보상, 거래 성과 극대화 |
| 효율형 | 재료·골드·촉매·수수료·복구 비용 절감 |

다른 역할 분기로 교차 투자해도 추가 비용은 없다. 여러 분기의 초급 노드를 조합할 수 있으나, 각 분기의 중·상위 노드는 그 분기 내부 누적 투자량을 별도로 요구한다.

### 7.5 노드 투자 단계

| 노드 유형 | 투자 단계 | 역할 |
|---|---:|---|
| 기본 정보·기능 | 숙련 자동 해금 | 기본 사용성 |
| 범용 선택 기능 | 1회 | 공통 편의 |
| 분기 고유 기능 | 1회 | 빌드 차별화 |
| 핵심 수치 보정 | 일부만 2~3단계 | 분기 심화 |
| 최상위 고유 특성 | 1회 | 전문화 정체성 |

- 기능 노드는 한 번 투자하면 완전한 기능을 제공한다.
- 핵심 수치 노드는 단계마다 체감 가능한 변화가 있어야 한다.
- 단순 미세 수치 상승을 위해 모든 노드를 다단계화하지 않는다.
- 다단계 노드 회수는 마지막 단계부터 역순으로 처리한다.

### 7.6 상위 노드 개방 조건

중·상위 노드는 다음을 함께 요구한다.

1. 기능적으로 연결된 핵심 선행 노드
2. 해당 역할 분기의 누적 투자량
3. 필요한 숙련도·공통 등급
4. 최상위 특성이라면 사용할 수 있는 최상위 슬롯

공통 범용 노드와 다른 역할 분기의 투자량은 해당 분기의 깊이 조건에 포함하지 않는다.

### 7.7 최상위 고유 특성

- 성장축별 주 최상위 특성 최대 1개
- 후반의 높은 숙련·공통 등급 조건으로 보조 최상위 슬롯 최대 1개 해금
- 보조 최상위는 주 최상위와 다른 역할 분기에서만 선택
- 보조 최상위는 원래 효과보다 약하게 적용
- 세 역할의 최상위 동시 확보 금지
- 같은 분기의 최상위 중복 금지

### 7.8 메인 포인트 상한

- 숙련 이정표에 따라 메인 전용 포인트가 증가한다.
- 공통 대장장이 등급의 주요 이정표에서 소량의 공통 보너스 포인트를 얻는다.
- 후반에는 영구적인 최종 포인트 상한에 도달한다.
- 최종 상한으로도 메인 트리 전체를 동시에 완성할 수 없다.
- 목표 구성은 `주력 분기 최상위 + 다른 분기 일부 혼합`이다.
- 보조 영구 강화 트리는 장기적으로 전부 완성할 수 있다.

정확한 포인트 수와 트리 점유 가능 비율은 `PROPOSED_ONLY`다.

## 8. 메인 포인트 종류와 사용

### 8.1 전용 포인트

- 제작 숙련 이정표: 제작 전용 포인트
- 강화 숙련 이정표: 강화 전용 포인트
- 화술 숙련 이정표: 화술 전용 포인트
- 장비 분야 숙련 이정표: 해당 분야 전용 포인트

한 분야의 반복 플레이만으로 다른 분야를 완성할 수 없다.

### 8.2 공통 보너스 포인트

- 공통 대장장이 등급 주요 이정표에서 소량 지급
- 제작·강화·화술 메인 트리에 자유 투자 가능
- 장비 분야 트리는 원칙적으로 분야 전용 포인트 중심
- 공통 포인트만으로 특정 트리를 완성할 수 없도록 성장축별 사용 상한 적용

### 8.3 투자 순서와 반환

1. 해당 성장축의 전용 포인트를 먼저 사용한다.
2. 부족분만 공통 보너스 포인트로 자동 보충한다.
3. 투자 확인 화면에서 포인트 출처를 구분한다.
4. 플레이어는 `공통 포인트 사용 금지`를 선택할 수 있다.
5. 노드 회수 시 실제 사용한 종류 그대로 반환한다.

## 9. 메인 트리 회수와 초기화

### 9.1 개별 특성 취소

- 영업 전 준비 단계에서만 가능
- 취소 포인트 즉시 반환
- 작고 고정된 골드 비용
- 반복 취소에 점증 비용 없음
- 선행 조건이 깨지는 하위 노드는 함께 회수
- 실행 전에 연쇄 회수 노드, 반환 포인트, 비용, 사라지는 효과를 표시

### 9.2 전체 초기화

- 해당 성장축 메인 트리의 모든 투자를 회수
- 개별 취소보다 큰 골드 또는 재훈련 자원 필요
- 반복 초기화 점증 비용 없음
- 초기화 후 즉시 재투자 가능
- 제작·강화·화술·각 장비 분야 트리는 별도로 초기화

### 9.3 초반 보호

- 전문 분야 최초 해금 뒤 일정 횟수까지 무료 변경
- 신규 특성 최초 해금 직후 제한적인 무료 시험 기회
- 무료 기회의 잔여 횟수와 종료 시점을 명확히 표시

정확한 무료 횟수와 비용은 `PROPOSED_ONLY`다.

## 10. 보조 전문 분야 트리

### 10.1 기초 자동 해금

숙련 구간에 따라 다음 기초 효과를 자동으로 해금한다.

- 제작·강화 결과 정보 개선
- 위험도와 예상 손실 표시
- 재료·촉매 호환성 정보
- 반복 제작·강화 조작 편의
- 고객 예산·반응 범위 표시
- 일괄 처리와 필터 기능

### 10.2 특수 보조 노드 영구 투자

- 보조 전문 포인트 사용
- 한 번 투자하면 영구 적용
- 회수·초기화 불가
- 활성 슬롯 없음
- 해금한 모든 노드가 상시 적용
- 최종적으로 모든 실질 성능 노드를 획득 가능
- 메인 전문 분야의 강한 고유 기능을 복제하지 않음
- 영구 투자 전 효과·비용·선행 조건과 회수 불가 경고 표시
- 실제 투자는 영업 전 준비 단계에서만 가능

### 10.3 단계별 선택 순서

```text
1단계에서 원하는 노드부터 투자
→ 단계 최소 투자량 충족
→ 2단계 개방
→ 같은 방식으로 상위 단계 진행
→ 장기적으로 이전 단계 미선택 노드까지 전부 획득
```

- 같은 단계 안에서는 투자 순서를 자유롭게 선택한다.
- 다음 단계에는 현재 단계 최소 투자량이 필요하다.
- 기능적으로 필요한 경우에만 명시적 선행 노드를 둔다.
- 초기 선택은 성장 순서를 바꾸지만 최종 성능 손해를 만들지 않는다.
- 후반 보조 노드도 메인 최상위 특성보다 약하게 유지한다.

### 10.4 보조 포인트 획득

- 숙련 주요 이정표에서 기본 지급
- 관련 최초 기록·주요 성취에서 추가 지급
- 제작 포인트는 제작 성과, 화술 포인트는 관계·협상 성과에서만 획득
- 같은 성취는 반복 지급하지 않음
- 단순 반복으로 무한 획득 불가
- 특정 일회성 콘텐츠를 놓쳐도 대체 성취·높은 숙련 보상으로 완성 가능

### 10.5 성취와 완성 보장

- 성취는 조기 접근과 빠른 완성을 제공한다.
- 성취를 놓쳐도 높은 숙련에서 대체 포인트·대체 조건을 제공한다.
- 특정 성취 전용 요소는 명칭·외형·칭호·도감·연출 등 기념 요소로 제한한다.
- 실질 성능 노드는 어떤 경로에서도 장기적으로 전부 획득 가능하다.
- 완성 이후 남는 포인트를 골드·재료·특수 재료·메인 포인트로 교환하지 않는다.

## 11. 제작 성장축

### 11.1 제작 숙련

주요 성장 행동:

- 신규 제작법 최초 제작
- 고품질 장비 제작
- 희귀 재료 사용
- 고객에게 적합한 장비 제작
- 군사 대량 계약 수행
- 손상·역사 장비 복원
- 직업이 바뀐 고객의 장비 개조
- 의미 있는 제작 실패 분석

주요 자동 성장 효과:

- 품질 하한과 결과 편차 개선
- 재료 손실 완화
- 수식어 후보 정보 개선
- 재가공·복원·개조 기능 개방
- 상위 제작법 접근
- 강화 성공률에 작은 공통 보정

### 11.2 제작 메인 전문 분야 예시

- 정밀 제작
- 대량 생산
- 복원 기술
- 특수 가공

이들은 제작 트리의 안정·성능·효율 역할 분기에 맞게 재구성한다. 전문화하지 않은 공정도 사용할 수 있으며, 전문화는 독점 권한이 아니라 강한 우위다.

### 11.3 제작법 친숙도

- 장검·창·활·중갑 등 대표 제작법별 소규모 숙련
- 실제 사용으로 성장
- 신규 제작법 사용을 막지 않음
- 품질 안정성, 반복 편의, 작은 강화 준비 보정, 후보 정보 개선
- 거대한 제작법별 별도 스킬 트리는 만들지 않음

## 12. 강화 성장축

### 12.1 강화 숙련의 역할

- 연속 강화와 조작 편의
- 위험·결과 정보 개선
- 실패 시 재료 손실 완화
- 손상 후 복구 효율
- 회복석 효율
- 특수 타격 충전과 운용
- 성공률 직접 보정은 제한적

제작 숙련이 강화 성공률의 주요 숙련 보정을 담당하고, 강화 숙련은 실패 이후의 손실과 복구를 주로 담당한다.

### 12.2 강화 메인 전문 분야 예시

- 안정 타격
- 승부사의 망치
- 회복 단조
- 효율 정련

기존의 `주 전문화 1개 + 보조 기술 1~2개` 고정 구조는 폐기한다. 제한된 메인 포인트를 공통 줄기와 역할 분기에 투자하는 방식으로 대체한다.

### 12.3 특수 타격

- 메인 전문 분야의 고유 기능 노드로 해금
- 상시 지속 효과와 조건 충족형 1회 사용 효과
- 별도 미니게임 없이 기존 강화 버튼에 통합
- 일반 강화도 계속 가능
- 확정 성공이 아니라 위험·피해·보상 구조를 변형
- 계정 공통 충전과 대상 장비 최근 기여도를 함께 사용
- 저위험 반복 충전 감쇠

정확한 충전량과 효과는 `PROPOSED_ONLY`다.

## 13. 장비 분야 숙련과 기술 돌파

대상 분야:

1. 무기
2. 방어구
3. 보조 장비
4. 장신구

### 13.1 분야 숙련

해당 분야의 제작·개조·복원·강화·계약 수행으로 자연 성장한다.

주요 효과:

- 해당 분야 제작 품질 안정
- 강화 성공률의 주요 분야 숙련 보정
- 재료 손실 완화
- 수식어 후보 정보 개선
- 반복 작업 편의
- 분야별 기술 돌파 조건 충족

분야 숙련은 포인트 배분이 아니라 실제 사용 경험으로 성장한다.

### 13.2 분야별 기술 돌파의 역할

분야 숙련이 경험 성장이라면, 기술 돌파는 자원과 조건을 충족해 상위 강화 구간과 분야 기술을 영구 개방하는 계정 성장이다.

- 고위 정밀강화와 독립
- 이벤트 `[특수 재료]`와 독립
- 실패 확률 없음
- 연구 시간 없음
- 연구 슬롯 없음
- 조건 충족 후 버튼을 누르면 즉시 완료
- 해당 분야의 기존·신규 장비에 계정 단위 영구 적용

### 13.3 돌파 절차

```text
해당 분야 숙련·공통 등급·선행 기술 충족
→ 골드·일반 재료·연구 자원 확인
→ 돌파 버튼 선택
→ 자원 즉시 소모
→ 상위 강화 구간과 분야 기술 즉시 영구 해금
```

골드만으로 선행 조건을 건너뛸 수 없다.

### 13.4 다단계 돌파

- 분야별 순차적 다단계 구조
- 단계마다 상위 강화 구간과 분야 보조 기술 일부 해금
- 주요 단계에서는 분야 메인 전문 분야의 핵심 노드·분기 접근 조건을 해금할 수 있음
- 정확한 단계 수, 강화 경계, 비용은 `PROPOSED_ONLY`

### 13.5 분야 역할군

공통 역할명은 유지하되 실제 효과는 분야별로 다르다.

| 분야 | 안정형 | 성능형 | 효율형 |
|---|---|---|---|
| 무기 | 강화 하락·손실 관리 | 공격·기록 수식어 성장 | 제작 재료 효율 |
| 방어구 | 손상·품질 손실 관리 | 방어·생존 수식어 성장 | 복구 비용 효율 |
| 보조 장비 | 불리한 조건 손실 관리 | 상황 대응 수식어 성장 | 촉매 소비 효율 |
| 장신구 | 희귀 효과 보존 | 특수 조건·명예 수식어 성장 | 특수 가공 효율 |

### 13.6 폐기된 구형 돌파 규칙

다음 규칙은 `REJECTED` 또는 `SUPERSEDED`다.

- 최초 분야 돌파에 이벤트 특수 재료 필수
- 돌파 성공·실패 확률
- 돌파 실패 시 파편 반환
- 돌파 이해도 누적
- 실패 횟수 보장선
- 돌파 연구 기간
- 연구 슬롯과 동시 연구 제한
- 최초 고위 정밀강화가 분야 돌파를 겸함

## 14. 정밀강화와 특수 재료 성장

### 14.1 일반 정밀강화

- 모든 10강 이정표에서 필수
- 일반 보조재료와 촉매 사용
- 일반 수식어 획득·성장·진화
- 특수 재료 없이 진행 가능
- 완료해야 다음 강화 구간 개방

### 14.2 고위 정밀강화

고위 정밀강화는 일반적인 분야 돌파가 아니라 **특수 수식어 장비를 만드는 특수 제작 경험**이다.

- `+50` 이후 10강 이정표에서만 가능
- 호환되는 `[특수 재료]`를 보유하고 등록해야 선택지 활성화
- 특수 재료가 없으면 시도 불가
- 특수 재료가 없어도 일반 정밀강화로 다음 구간 진행 가능
- 일반 정밀강화를 확정하면 해당 이정표의 고위 기회 소멸
- 성공 시 특수·초희귀 수식어 계보 획득 또는 진화 가능
- 분야별 기술 돌파와 무관

### 14.3 특수 재료 숙련

- 실제 고위 정밀강화에서 사용한 특수 재료별 독립 숙련
- 장비가 아니라 계정 도감에 저장
- 실패 시 추가 분석 숙련 가능
- 같은 특수 재료의 이후 시도에 제한적인 성공 보정
- 다른 특수 재료에는 적용하지 않음
- 전문 분야 초기화·장비 판매·파괴 뒤에도 유지
- 숙련만으로 성공률 100% 불가
- 일반 정밀강화는 특수 재료 숙련을 제공하지 않음

## 15. 화술 성장축

화술은 사람과 관계를 맺고 거래 조건을 개선하는 계정 공통 성장축이다. 장비 성능이나 강화 성공률을 직접 올리지 않는다.

### 15.1 영향 범위

#### 대인관계

- 고객 첫인상과 대화 반응
- 조언 수용 가능성
- 선물·지원 의도의 해석
- 약속 실패·장비 손상·사고 설명
- 낮은 신뢰에서 관계 회복 기회
- 수집가·중개인·귀족·군 관계자의 특수 대화

화술만으로 신뢰를 자동 획득하거나 고객 의사를 강제할 수 없다.

#### 할인

- 일반 상점의 작은 상시 할인
- 일부 시설·복구·재훈련 비용 절감
- 희귀 상인·외국 상인의 조건 개선
- 중개인 수수료·계약 비용 완화

#### 흥정

- 수집가 매입 제안
- 방문 고객 추가 거래 조건
- 군사·귀족·외국 계약 보너스
- 중개인 보상·운송 조건
- 조사·처벌 상황의 벌금·압류 기간 협상

### 15.2 가격 적용 규칙

| 거래 | 화술 효과 |
|---|---|
| 일반 상점 구매 | 작은 상시 할인 |
| 공개시장 판매 | 적용하지 않음 |
| 방문 고객 거래 | 흥정·설명·추가 조건 |
| 수집가 거래 | 매입가 흥정 |
| 중개인 거래 | 보상·수수료·운송 조건 |
| 군사·귀족 계약 | 제한적 보너스 조건 |
| 시설·복구·재훈련 | 일부 비용 할인 |
| 밀수 적발 확률 | 직접 영향 없음 |
| 조사·처벌 협상 | 벌금·압류 기간 등에 제한적 영향 |

거래 종류별 할인·추가 보상 상한을 별도로 두고, 같은 거래에서 할인과 흥정이 겹치면 통합 상한을 적용한다.

### 15.3 화술의 절대 한계

- 고객 실제 예산
- 수집가 최고 매입 한도
- 장비의 실제 가치·역사·희귀성
- 고객과 거래 상대의 자율성
- 심각한 장비 부적합
- 밀수 적발 판정
- 공개시장 고정 매입가

### 15.4 화술 전문 분야 예시

- 상인 감각
- 신뢰 화법
- 은밀 교섭
- 궁정 예법

이들은 화술 메인 트리의 안정·성능·효율 역할에 맞춰 배치한다. 소규모 예산 범위 표시, 반응 예측, 상점 할인 등은 보조 영구 강화로 누적할 수 있다.

## 16. 성장축 간 중첩 규칙

- 제작 전문 분야는 `어떻게 제작하는가`를 결정한다.
- 강화 전문 분야는 `어떻게 위험을 감수하는가`를 결정한다.
- 장비 분야 전문 분야는 `어떤 장비를 잘 다루는가`를 결정한다.
- 화술은 `사람과 어떻게 거래하고 관계를 형성하는가`를 결정한다.
- 세 작업 성장 효과는 함께 적용할 수 있다.
- 같은 수치에 여러 효과가 겹치면 총합 상한과 체감 감소를 적용한다.
- 분야 기술이 제작·강화 전문 분야의 특수 타격이나 고유 기능을 복제하지 않는다.
- 화술은 장비 성능·강화 성공률을 직접 높이지 않는다.
- 명성·영향력·명예 단계는 공개시장 고정 매입가를 직접 올리지 않는다.

## 17. 숙련 상한 이후 명예 단계

메인 포인트가 최종 상한에 도달한 뒤에도 숙련 경험은 성장축별 명예 단계로 계속 기록한다.

### 17.1 제공 가능한 보상

- 성장축별 칭호
- 트리 외형과 테두리
- 제작·강화·흥정 연출
- 기록실 통계 장식
- 장비 설명·역사 기록의 특별 문구
- 작업 완료 도장·아이콘
- 최근 빌드 기록과 비교 기능
- 분야별 최고·누적 기록 표시

`최근 빌드 기록`은 자동 적용 프리셋이 아니라 참고용 기록이다.

### 17.2 세계의 인정

- 고숙련 고객·수집가·국가 인물의 전용 대사
- 칭호·소개 문구·기록 전시 해금
- 명예 단계 기념 의뢰·도전 과제
- 과거 최고 기록과 대표 업적 언급

### 17.3 제공하지 않는 실질 보정

- 방문 확률
- 구매 할인·판매가·흥정 한도
- 강화 성공률·제작 품질
- 고객 신뢰 획득량
- 계약 보상
- 희귀 재료 획득률
- 반복 골드·재료·전문화 포인트

실질 콘텐츠 해금은 공통 등급, 대장간 명성, 국가 영향력, 고객 신뢰 등 기존 담당 성장축을 사용한다.

## 18. 성장 수치 공개 방식

### 18.1 정확히 공개하는 정보

- 숙련 레벨과 경험치 진행도
- 보유·사용 전문 포인트
- 노드의 고정 효과와 비용
- 분야별 기술 돌파 조건과 소모 자원
- 확정적으로 적용되는 할인율·재료 절감률·비용 감소율
- 특수 재료 숙련 단계와 다음 성장 조건
- 메인 포인트 출처와 회수 시 반환 종류

### 18.2 단계·범위로 표시하는 결과 정보

- 최종 강화 성공 가능성
- 고객의 조언 수용 가능성
- 흥정 철회 가능성
- 국가 사건 성공 전망
- 특수 수식어 세부 결과 확률
- 밀수 적발 위험

표시 단계 예시:

- 매우 낮음
- 낮음
- 보통
- 높음
- 매우 높음

단계와 함께 주요 상승·하락 원인을 제공한다. 플레이어가 투자 효과는 판단할 수 있지만 모든 결과를 정확한 계산으로 확정하지는 못하게 한다.

## 19. 화면 구성

성장축별로 하나의 화면을 제공하고 상단 탭으로 구분한다.

- `메인 전문화`
- `보조 영구 강화`

대상 화면:

- 제작
- 강화
- 화술
- 무기
- 방어구
- 보조 장비
- 장신구

### 19.1 공통 헤더

- 현재 숙련도와 다음 숙련 단계
- 메인 전용 포인트
- 공통 보너스 포인트 사용 현황
- 보조 전문 포인트
- 다음 노드·단계 해금 조건
- 현재 영업 상태
- 다음 투자 가능 시점

### 19.2 메인 탭

- 자동 해금 기능, 범용 노드, 안정·성능·효율 분기 표시
- 전용·공통 포인트 출처 표시
- 주·보조 최상위 상태 표시
- 회수 시 연쇄 해제 노드 미리 표시
- 영업 중 읽기 전용

### 19.3 보조 탭

- 단계별 진행도
- 현재 단계 투자 가능 노드
- 다음 단계 최소 투자량
- 영구 적용·회수 불가 표식
- 장기적으로 실질 성능 완성 가능 안내
- 영업 중 투자 버튼 비활성화

상태는 색상만이 아니라 아이콘·문구·테두리로 함께 구분한다.

## 20. 폐기·대체 결정 요약

다음 구형 구조는 최신 기획에서 사용하지 않는다.

- 화술의 게임 날짜를 소비하는 별도 재훈련 대기
- 강화의 `주 전문화 1개 + 보조 기술 1~2개` 고정 구조
- 분야별 돌파의 특수 재료·확률·이해도·보장선
- 분야별 돌파 연구 시간과 연구 슬롯
- 고위 정밀강화가 분야 돌파를 겸하는 구조
- 모든 전문 효과를 제한 없이 독립 누적하는 구조
- 숙련 특성 활성 슬롯
- 작업별 통합 프리셋과 분야별 자동 변형
- 작업 세션마다 특성을 교체하는 구조
- 영업 중 전문 분야 투자·회수
- 메인 트리 전체 완성 가능 구조
- 명예 단계의 직접 경제·성능 보정
- 모든 결과 확률의 정확한 수치 공개

## 21. 현재 미결정 사항

- 각 성장축의 정확한 숙련 단계 수와 경험 곡선
- 메인·보조 포인트 지급량과 최종 상한
- 공통 보너스 포인트의 성장축별 사용 상한
- 메인 트리 노드 수, 분기 깊이, 다단계 수치
- 주·보조 최상위 해금 조건과 약화 비율
- 개별 취소·전체 초기화 비용과 초반 무료 횟수
- 보조 트리 단계 수와 최소 투자량
- 분야별 기술 돌파 단계·강화 경계·소모 자원
- 화술 거래별 할인·흥정 상한
- 확률 요약 단계의 내부 구간
- 특수 재료 숙련 획득량·상한
- 정밀강화의 수식어 슬롯·교체·진화 세부 규칙

모든 항목은 `PROPOSED_ONLY`다.

## 22. 문서 유지 규칙

기획 누락을 방지하기 위해 다음 운영 규칙을 사용한다.

1. 사용자가 하나의 기획 묶음을 승인하면 관련 책임 문서와 결정 원장을 갱신한다.
2. 구형 규칙은 삭제만 하지 않고 `REJECTED` 또는 `SUPERSEDED`로 원장에 남긴다.
3. 정확한 수치가 승인되지 않은 경우 문서에서 임의 확정하지 않고 `PROPOSED_ONLY`로 표시한다.
4. GitHub 갱신은 구현 코드와 분리된 기획 브랜치·PR 단위로 진행한다.
5. PoC 수동 검증 Issue는 실제 플레이·플랫폼 증거가 채워질 때까지 별도로 유지한다.
6. `기획 완료` 명령 전에는 상태를 `PLANNING_IN_PROGRESS`로 유지한다.
