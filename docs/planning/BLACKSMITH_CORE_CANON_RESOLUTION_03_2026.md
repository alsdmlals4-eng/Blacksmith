## 결정 — 활성 사건·연대기 수식어 1개와 진화형 생애 계보

사용자 승인:

- `권장안대로 진행`

### 확정 내용

1. 하나의 작품 UID가 동시에 활성화할 수 있는 `사건·연대기 수식어`는 원칙적으로 1개다.
2. 최초의 결정적 세계일정에서 작품의 실제 사용·기여·결과가 확인되면 사건 수식어 계보가 생성될 수 있다.
3. 후속 세계일정은 사건 수식어를 무제한 추가하지 않고 기존 계보를 강화·변형·잠금·복원 또는 대체한다.
4. 현재 활성 사건 수식어는 해당 작품의 현재 세계적 정체성을 대표한다.
5. 이전 사건 수식어의 이름·상태·효과·변경 원인과 시점은 작품 연대기에 영구 보존한다.
6. 사건 수식어가 대체되더라도 이전 세계일정과 실제 기여 기록은 삭제하지 않는다.
7. 일반 정밀강화 수식어 A·B와 사건 수식어는 별도 계층이며 서로의 슬롯을 점유하거나 덮어쓰지 않는다.
8. 같은 일정·같은 결과·같은 고객을 반복해 사건 수식어를 무한 성장시키는 방식은 허용하지 않는다.
9. 후속 변화에는 이전 사건과 새 사건 사이의 인과 관계 또는 작품 상태의 실질적 변화가 필요하다.
10. 하나의 사건 수식어가 모든 상황에서 항상 강한 범용 최적해가 되지 않도록 성능·상황 적합성·서사·선택지 효과를 분리한다.
11. 사건 수식어의 정확한 단계 수, 효과 폭, 대체 허용 조건, 플레이어 개입 범위와 UI 표현은 후속 `RECOMMENDED_DEFAULT / TEST_VALUE`로 남긴다.

### 표준 흐름

```text
방문 고객 납품
→ 작품 생애 활성화
→ 결정적 세계일정에서 실제 기여
→ 사건 수식어 계보 생성
→ 후속 세계일정
  ├─ 강화
  ├─ 변형
  ├─ 잠금
  ├─ 복원
  └─ 대체
→ 현재 활성 형태 1개 유지
→ 이전 형태와 변경 이유는 연대기에 보존
```

### 예시

```text
[왕도를 지켜낸]
→ 대파 후 복원
→ [부서졌으나 다시 왕도를 지켜낸]
→ 소유자 계승 후 재출전
→ [두 세대에 걸쳐 왕도를 지켜낸]
```

예시는 방향 설명용이며 실제 명칭·효과·단계는 확정값이 아니다.

### 보호 조건

- 사건 수식어를 여러 개 쌓아 오래된 작품이 자동으로 최강이 되게 하지 않는다.
- 이전 형태를 삭제하고 현재 보너스만 남기지 않는다.
- 단순 현장 존재나 반복 횟수만으로 강화하지 않는다.
- 사건 수식어 변경이 일반 수식어 A·B의 성장 선택을 무효화하지 않는다.
- 작품의 생애보다 최적 사건 조합 수집이 주목적이 되지 않게 한다.
- 잠금·약화·대체가 발생해도 UID와 연대기는 유지한다.

### 정본 우선순위

본 결정은 다음 미확정 표현보다 우선한다.

- 사건 수식어를 작품당 무제한 누적할 수 있다는 해석
- 활성 사건 수식어를 2~3개 이상 기본 제공한다는 해석
- 후속 세계일정마다 별도 보너스를 새 슬롯으로 추가한다는 해석

정리 후 표준 문구:

> 작품당 활성 사건·연대기 수식어는 1개다. 후속 세계일정은 이를 무한 추가하지 않고 강화·변형·잠금·복원·대체하며, 모든 이전 형태와 변경 인과는 작품 연대기에 보존한다.

### 벤치마킹 적용 요약

- 제한된 기본 성장 슬롯과 후속 성장 계층을 분리하는 현업 구조는 정보량과 밸런스 폭증을 줄이는 데 유리하다.
- 사건과 선택이 대상의 현재 정체성을 변화시키고 과거 기록으로 남는 구조는 Blacksmith의 작품 생애 환류와 더 잘 맞는다.
- 따라서 경쟁작의 슬롯 수나 수치를 복제하지 않고 `현재 활성 정체성 1개 + 전체 변화 이력` 구조만 채택한다.
