## 1. 복원한 기존 결정

### 고객 구조

PR #61의 v6 요구사항 이력에서 고객은 **4명의 고정 고객**이 아니라 다음 **4개 고객 유형**으로 정의돼 있었다.

```text
수집가
모험가
검투사
군인
```

각 유형은 서로 다른 이름·성격·직업·야망을 가진 복수의 방문 고객을 수용하며, 유형은 공통 세계 환류 파이프라인을 제공한다.

### +49 → +50 구조

기존 결정은 +49에서 다음 두 경로를 구분했다.

```text
일반 정밀강화
고위 정밀강화
```

- 일반 정밀강화는 해당 구간의 기존 성공·유지·하락·파괴·보호 규칙을 사용한다.
- 고위 정밀강화는 특수재료와 고액 보조재료를 투입해 +50 도달, 진화, 대표 특수 수식어를 확정하는 고비용 경로다.
- +50 도달 뒤 별도 행동을 실행하는 것이 아니라 `+49 → +50` 시도 자체가 두 경로 중 하나다.

## 3. Decision `BS-CUST-20260731-01`

### 3.1 고객 유형은 정확히 4개

| Type ID | 유형 | 고유 세계 환류 | 대표 가치 축 |
|---|---|---|---|
| `COLLECTOR` | 수집가 | 감정·전시·거래망·유물화·소유권 이력 | 희소성·제작 등급·계보·연대기 |
| `ADVENTURER` | 모험가 | 탐험·발견·생환·분실·회수·특수재료 | 적응성·생존·환경 적합·발견 |
| `GLADIATOR` | 검투사 | 경기·관중·명성·승패·장비 기여 | 성능·조작성·명예·경기 이력 |
| `SOLDIER` | 군인 | 부대 배치·보급·임무·공적·전선 변화 | 신뢰성·표준화·임무 적합·세력 영향 |

### 3.2 유형별 고객은 복수다

- 각 유형은 **최소 2명의 이름 있는 고객 프로필**을 가져야 한다.
- 본제작 승인 전 권장 목표는 유형별 3명 이상이다.
- 카시아 벨란은 검투사 유형의 대표 고객이다.
- 에르사 로엔은 수집가 유형의 대표 고객이다.
- 모험가·군인 대표와 각 유형의 추가 고객 이름은 별도 콘텐츠 승인 대상으로 남긴다.
- 한 명의 고객을 유형 전체와 동일시하지 않는다.

### 3.3 유형과 개인의 책임 분리

```text
CustomerType
- 공통 결과 파이프라인
- 허용 준비 선택
- 세계 상태 변화 종류
- 공통 적합 평가 축

NamedCustomer
- 이름·외형·성격
- 개인 목표·야망
- 위험 성향·예산
- 선호 장비 범주와 가치 가중치
- 관계 단계·재방문 사건
- 개인 대사·연대기 템플릿
```

모든 이름 고객은 다음 공통 파이프라인을 사용한다.

```text
방문·요청
→ 보관함 장비 비교
→ 판매·소유권 이전
→ 고객 유형에 맞는 준비 선택
→ 세계 활동 결과
→ 장비 기여 원인
→ 관계·세계 상태·장비 연대기
→ 재방문
```

### 3.4 유형은 장비 종류가 아니다

- 검투사라고 항상 검만 요구하지 않는다.
- 군인이라고 군용 표준품만 요구하지 않는다.
- 수집가도 무기·방어구·의식품을 요청할 수 있다.
- 모험가도 환경과 목적에 따라 무기·방어구·도구를 요청할 수 있다.
- `customer_type_id`는 후속 세계 활동을 결정하고, `request_category`는 현재 거래 자격을 결정한다.

### 3.5 Vertical Slice 범위

- 4유형은 기획·데이터 계약에 모두 존재한다.
- 유형별 최소 2개 이름 고객 슬롯을 정의한다.
- 한 15~25분 세션에 4유형·8명을 동시에 완주시키지 않는다.
- 동시 활성 요청은 최대 2개를 유지한다.
- 대표 세션은 카시아를 깊게 검증한다.
- 에르사·모험가 대표·군인 대표는 **분리된 결정론적 검증 시나리오**로 공통 파이프라인 재사용을 검증한다.
- 추가 고객은 같은 유형 내 변주가 고객명 하드코딩 없이 작동하는지 검증한다.

## 4. Decision `BS-ENH-20260731-01`

### 4.1 +49 → +50은 두 경로다

| 경로 | 특수재료 | 성공·실패 | +50 결과 |
|---|---|---|---|
| 일반 정밀강화 | 사용하지 않음 | +40대 기존 정밀강화 위험 적용 | +50 도달, 일반 정밀강화 결과, 특수 수식어 없음 |
| 고위 정밀강화 | 촉매 또는 특수 보조재료로 사용 | 확정 성공 | +50 도달, 진화·대표 특수 수식어 확정 |

### 4.2 일반 정밀강화

```text
+49 장비
+ 일반 강화 재료
+ 선택적 보호
→ 성공·유지·하락·파괴 확률 공개
→ 1회 판정
```

- 성공하면 +50에 도달한다.
- 기존 정밀강화 결과를 적용한다.
- 진화와 대표 특수 수식어는 붙지 않는다.
- 실패는 +40대 정밀강화 규칙을 사용한다.
- 보호는 기존 계약대로 영구 파괴 결과만 변환한다.
- 일반 +50 장비도 완성품이며 +51 이상 강화와 명작 전당 등록 자격을 가진다.

### 4.3 고위 정밀강화

고위 정밀강화는 등록된 `[특수재료]`를 **촉매 또는 특수 보조재료**로 사용하는 +49→+50 시도다.

```text
+49 장비
+ 기존 계보·보조 수식어
+ 특수재료 1개 이상
  - 촉매 슬롯 또는
  - 특수 보조재료 슬롯
+ 고위 정밀강화 비용
→ 유효 후보 2~3개 공개
→ 후보 하나 선택
→ 확정 성공
→ +50
→ 진화 또는 특수 형태
→ 대표 특수 수식어 1개 확정
```

보장:

- +50 단계 상승
- 실패·유지·하락·파괴 없음
- 선택 결과 적용
- 대표 특수 수식어 정확히 1개 이상
- 기존 계보·장비 정체성 보존 또는 승격
- 특수재료만 소실되고 무변화인 결과 없음

### 4.4 특수재료 역할

#### 촉매로 사용

- 진화 계열과 대표 특수 수식어 계열을 우선 결정한다.
- 해당 촉매가 허용하는 후보 2~3개를 공개한다.
- 장비 계보와 충돌하는 후보는 제외한다.

#### 특수 보조재료로 사용

- 장비의 기존 계보가 기본 진화 방향을 제공한다.
- 특수 보조재료는 후보를 추가·제한하거나 대표 특수 수식어의 표현·부가 방향을 결정한다.
- 촉매와 함께 사용하면 촉매가 주계열, 특수 보조재료가 변주를 담당한다.

공통:

- 슬롯 역할은 실행 전에 명시한다.
- 같은 특수재료가 촉매와 보조재료 역할을 모두 지원하는지는 재료 데이터에 선언한다.
- 역할에 따라 결과가 달라지면 후보 비교 화면에 차이를 표시한다.

### 4.5 일반 +50을 열등안으로 만들지 않는 가드레일

- 고위 정밀강화는 모든 전투·시장·관계 축에서 일반 +50보다 우월하지 않는다.
- 일반 경로의 장점은 낮은 비용, 즉시성, 재료 보존, +51 이상 성장 유연성이다.
- 고위 경로의 장점은 확정 성공, 작품 정체성, 특수 수식어, 특정 고객·세계 사건의 새로운 선택지다.
- 명작 전당은 두 경로를 모두 표시하며 `일반 정밀`과 `고위 정밀` 배지를 구분한다.
- 단일 종합 전투력 점수로 두 경로를 서열화하지 않는다.

### 4.6 저장 데이터

```text
enhancement_route_at_50

- material_id
```

+50이라는 단계만 보고 경로·특수 수식어를 추론하지 않는다.

## 5. 특수재료 획득 연결

특수재료는 한 고객 유형을 강제 통과하는 단일 병목이 아니다.

- 수집가 거래망 구매·교환
- 모험가 탐험·발견·생환 보상
- 제한된 고가 상점 재고
- 군사·투기장·세계 사건의 고유 보상

고객 유형별 획득 성격은 다르지만 동일 특수재료의 유일 공급자를 한 고객 한 명으로 고정하지 않는다.

## 6. 적대적 검토 루프

### Loop A — 4유형이 다시 4명 동시 완주로 변질되는가

위험: 15~25분에 4개 후속 세계 활동을 강제해 강화 코어가 사라진다.

판정: `REJECT`

대응: 유형은 전체 콘텐츠 분류이며, 세션 동시 요청은 최대 2개다. 유형별 검증은 분리 시나리오로 수행한다.

### Loop B — 같은 유형 고객이 이름만 다른 복제품인가

위험: 복수 고객이 대사와 초상화만 바뀌고 같은 요청·예산·결과를 반복한다.

대응: 같은 유형 내에서도 최소 3개 축이 달라야 한다.

- 야망
- 위험 성향
- 예산·보상 구조
- 선호 장비 범주
- 가치 가중치
- 재방문 사건
- 세계 세력 연결

### Loop C — 유형 간 역할이 겹치는가

- 수집가: 소유·희소·전시·거래망
- 모험가: 미지·발견·생환·회수
- 검투사: 공개 경기·명성·개인 기량
- 군인: 집단 임무·보급·전선·세력 영향

두 유형이 같은 결과 축만 사용하면 콘텐츠 설계 오류다.

### Loop D — 고객별 전용 엔진이 늘어나는가

위험: 고객이 늘 때마다 저장·관계·결과 코드를 새로 만든다.

판정: `FORBIDDEN`

대응: 유형 파이프라인과 데이터 템플릿을 공유하고, 이름 고객은 프로필·가중치·사건 데이터만 추가한다.

### Loop E — 고위 정밀강화가 일반 정밀강화를 무효화하는가

위험: 고위 경로가 비용 외 모든 면에서 우월하면 일반 경로는 함정 버튼이 된다.

대응: 일반은 저비용·유연성, 고위는 확정성과 정체성으로 책임을 분리한다. 보상 예산은 고객·시장·전투·연대기 축에 분산한다.

### Loop F — 촉매·보조재료 의미가 숨겨지는가

위험: 같은 재료를 다른 슬롯에 넣었을 때 결과가 달라지지만 UI가 설명하지 않는다.

대응: 슬롯 역할, 후보 변화, 소비량, 확정 결과를 실행 전에 비교한다. 유효 후보가 2개 미만이면 실행을 차단한다.

### Loop G — 특수재료 공급이 순환 잠금되는가

위험: 고위 정밀강화를 해야만 만날 수 있는 고객이 고위 정밀강화 재료의 유일 공급자가 된다.

대응: 최소 2개 독립 획득 경로를 유지하고, Vertical Slice에는 확정 테스트 픽스처를 제공한다.

### Loop H — 저장·랭킹에서 경로를 구분할 수 있는가

위험: 모든 +50이 같은 것으로 저장돼 특수 수식어·재료 이력·랭킹 표시가 손실된다.

대응: +50 경로, 특수재료 역할, 특수 수식어, 진화 ID를 명시적으로 저장한다.

## 7. 검증 기준

### 고객 구조

- 4개 `CustomerType`이 존재한다.
- 각 유형에 이름 고객 프로필이 최소 2개 존재한다.
- 한 고객을 추가할 때 고객 전용 핵심 엔진 변경이 없다.
- 같은 유형 두 고객의 변주 축이 최소 3개 다르다.
- 한 세션 동시 활성 요청이 2개를 넘지 않는다.

### +50 경로

- 일반 정밀강화와 고위 정밀강화가 별도 선택으로 표시된다.
- 일반 경로에는 특수 수식어가 생성되지 않는다.
- 고위 경로는 촉매·특수 보조재료 역할을 표시한다.
- 고위 경로는 유효 후보 2~3개와 특수 수식어를 실행 전에 공개한다.
- 고위 경로에서 실패·하락·파괴·무변화가 발생하지 않는다.
- 저장·복귀 후 경로와 특수재료 역할이 동일하다.
