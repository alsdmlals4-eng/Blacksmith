## 강화 결과 연출 구조

강화 결과 연출은 **결과 등급별 차등 연출 + 반복 시 단축·건너뛰기** 구조를 사용한다.

저위험 반복 강화는 빠른 입력과 즉시성을 우선한다. 일반 정밀강화, 단계 하락, 영구 파괴와 고위 정밀강화는 결과의 의미와 손실을 명확하게 전달하는 별도 연출을 사용한다.

```text
저위험 일반 강화
→ 짧은 타격·숫자 변화
→ 즉시 다음 입력 가능

일반 실패·단계 하락
→ 손실 방향이 읽히는 짧은 연출
→ 하락 단계와 소비 재료 표시

일반 정밀강화
→ 10단위 진입 전용 연출
→ 단계 상승과 정밀강화 결과 공개

영구 파괴
→ 입력 잠금
→ 파괴 결과 명확히 연출
→ 손실·연대기 처리 후 작업대로 복귀

고위 정밀강화
→ 진화 후보 선택
→ 전용 진화 연출
→ 외형·이름·대표 특수 수식어 공개
```

## 결과별 연출 계약

### 저위험 일반 강화 성공

- 짧은 망치 타격과 단계 숫자 변화를 사용한다.
- 강화 결과를 인식할 수 있는 최소한의 시각·음향·진동 피드백을 제공한다.
- 결과 연출 때문에 다음 강화 입력을 불필요하게 오래 막지 않는다.
- 반복 강화의 기본 템포를 담당한다.

### 일반 실패와 단계 유지

- 실패 여부, 소비된 재료와 현재 단계를 즉시 확인할 수 있어야 한다.
- 성공과 구분되지 않는 모호한 연출을 사용하지 않는다.
- 단계 유지가 무효 입력처럼 보이지 않도록 재료 소비와 실패 결과를 표시한다.

### 단계 하락

- 하락 전 단계와 하락 후 단계를 모두 읽을 수 있게 한다.
- 숫자만 순간적으로 바뀌어 손실을 놓치게 하지 않는다.
- 최대 하락이 발생한 경우 일반 실패보다 강한 손실 피드백을 적용한다.
- 하락 직후 현재 위험과 다음 시도의 비용을 다시 판단할 수 있도록 작업대 정보를 갱신한다.

### 일반 정밀강화

- `+9 → +10`, `+19 → +20` 등 10단위 진입 시도임을 전용 연출로 구분한다.
- 성공 시 강화 단계 상승과 정밀강화 결과를 하나의 연속된 결과로 공개한다.
- 실패 시 해당 구간의 일반 실패 위험이 적용됐음을 명확히 표시한다.
- 처음 보는 정밀강화 결과 연출은 완전 재생한다.
- 이미 확인한 동일 계열 연출은 단축하거나 건너뛸 수 있다.

### 영구 파괴

- 영구 파괴 판정 후에는 추가 입력을 잠시 잠근다.
- 장비가 실제로 소멸했다는 사실, 장비 이름·강화 단계·주요 수식어와 손실 자원을 명확히 표시한다.
- 파괴 결과가 단순한 짧은 숫자 변화로 처리되지 않게 한다.
- 장비 연대기 또는 파괴 기록이 존재하는 경우 기록 반영을 보여준다.
- 확인 후 같은 강화 작업대로 돌아오되, 파괴된 장비는 선택 상태에 남겨 두지 않는다.

### 고위 정밀강화

- 진화 후보 선택 완료 후 길게 누르기 또는 접근성 대체 입력으로 실행한다.
- `+49 → +50` 확정 성공을 전제로 전용 진화 연출을 사용한다.
- 다음 결과를 순차적으로 공개한다.
  1. +50 도달
  2. 장비 외형·유형·이름 변화
  3. 선택한 진화 후보 확정
  4. 대표 특수 수식어 획득
  5. 부가 등급·수치·보조 효과
  6. 적합 고객과 세계 사건 방향 변화
- 최초 고위 정밀강화 연출은 완전 재생한다.
- 이후 동일 계열 연출은 단축 가능하지만, 진화 결과 요약은 생략하지 않는다.

## 반복 재생과 건너뛰기

- 처음 보는 일반 정밀강화와 고위 정밀강화 연출은 완전 재생한다.
- 이미 본 반복 연출은 플레이어 설정에 따라 단축하거나 건너뛸 수 있다.
- 저위험 일반 강화는 기본적으로 짧은 연출을 사용한다.
- 영구 파괴처럼 비가역적 결과는 건너뛰더라도 결과 확인 화면과 손실 요약을 생략하지 않는다.
- 건너뛰기 설정은 성공률, 판정 결과, 비용과 보상에 영향을 주지 않는다.
- 연출 생략 중에도 텍스트·아이콘·숫자로 결과를 완전히 전달한다.

## 접근성·피드백 설정

### 모션 감소

- 화면 흔들림, 급격한 확대·축소, 강한 섬광과 반복 파티클을 줄인다.
- 제거된 연출 정보는 단계 변화, 결과 아이콘, 텍스트와 진행 상태 표시로 대체한다.
- 모션 감소 설정에서도 성공·실패·하락·파괴·진화를 서로 구분할 수 있어야 한다.

### 사운드와 진동

- 사운드와 진동은 각각 별도로 끌 수 있다.
- 사운드 또는 진동을 끄더라도 결과 정보가 누락되지 않는다.
- 중요한 결과를 특정 감각 하나에만 의존해 전달하지 않는다.

### 입력 재개

- 저위험 강화는 결과를 읽을 수 있는 최소 시간만 확보한 뒤 다음 입력을 허용한다.
- 단계 하락과 정밀강화는 결과 요약을 확인할 수 있게 하되 과도한 입력 잠금을 두지 않는다.
- 영구 파괴와 고위 정밀강화는 결과 확인이 끝나기 전 추가 강화 입력을 허용하지 않는다.

## 플레이테스트 조정 대상

정확한 연출 시간은 기획 확정값이 아니라 플레이테스트 조정 대상이다.

- 저위험 강화 타격 시간
- 다음 입력 허용 시점
- 실패·하락 결과 표시 시간
- 정밀강화 완전 연출과 단축 연출 시간
- 영구 파괴 입력 잠금과 결과 확인 시간
- 고위 정밀강화 진화 공개 순서별 시간
- 건너뛰기 가능 시점
- 화면 흔들림·섬광·진동 강도

수치 조정 시 다음 안전 경계를 지킨다.

- 저위험 반복 강화가 연출 대기 게임으로 변하지 않아야 한다.
- 중요한 손실이 인식 불가능할 정도로 짧아서는 안 된다.
- 고위 정밀강화가 일반 강화와 같은 무게로 보이면 안 된다.
- 모션 감소와 무음·무진동 설정에서도 모든 결과를 이해할 수 있어야 한다.

```text
ENHANCEMENT_RESULT_PRESENTATION: OUTCOME_TIERED
LOW_RISK_PRESENTATION: SHORT_AND_IMMEDIATE
PRECISION_PRESENTATION: MILESTONE_SPECIFIC
DESTRUCTION_PRESENTATION: NON_SKIPPABLE_LOSS_SUMMARY
HIGH_PRECISION_PRESENTATION: DEDICATED_EVOLUTION_REVEAL
FIRST_TIME_MILESTONE_PRESENTATION: FULL_PLAYBACK
REPEAT_PRESENTATION: SHORTENABLE_OR_SKIPPABLE
REDUCED_MOTION_ALTERNATIVE: REQUIRED
SOUND_AND_HAPTICS: INDEPENDENTLY_TOGGLEABLE
EXACT_PRESENTATION_DURATION: PLAYTEST_TUNABLE
```
