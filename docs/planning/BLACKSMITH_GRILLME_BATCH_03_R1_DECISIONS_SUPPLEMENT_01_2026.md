## `BS-HOF-20260802-03` — 한국 표준시 자정 기준 현실 일일 등록권 초기화

- 승인 시각: `2026-08-02 20:20 KST`
- 상태: `CONFIRMED_BY_LATEST_USER_DIRECTION / APPROVED_KST_MIDNIGHT_RESET`

### 이전 결정 상세화

- `BS-HOF-20260802-02`에서 후속으로 남긴 현실 날짜의 기준 시간대와 초기화 시각을 본 결정이 확정한다.
- 명예의 전당 신규 등록과 기존 작품 갱신은 계속 하나의 현실 일일 등록 행동 한도를 공유한다.
- 현재 상태는 성공한 등록·갱신 행동에서만 반영되며 자동·실시간 갱신하지 않는다.

### 확정 내용

1. 명예의 전당의 현실 일일 등록권은 한국 표준시 `KST (UTC+09:00)`를 공통 기준으로 사용한다.
2. 일일 등록권은 매일 한국 시간 `00:00`에 초기화한다.
3. 사용자가 표현한 `한국 시간 24시`는 해당 날짜의 끝과 다음 날짜의 시작인 `KST 00:00` 경계를 뜻한다.
4. 하나의 현실 일일 구간은 `KST 00:00 이상`부터 `다음 날 KST 00:00 미만`까지다.
5. 같은 KST 날짜 구간 안에서 플레이어 계정은 신규 작품 등록 또는 기존 작품 현재 상태 갱신 중 하나만 1회 성공시킬 수 있다.
6. 등록·갱신에 성공하면 해당 KST 날짜의 일일 등록권을 사용한 상태가 된다.
7. 다음 KST 자정이 도달하면 사용 상태가 초기화되고 새로운 현실 일일 등록권 1회를 사용할 수 있다.
8. 모든 지역의 플레이어에게 동일한 KST 자정 경계를 적용하며, 계정·기기·접속 지역의 현지 시간대로 초기화 시각을 변경하지 않는다.
9. 게임 내 날짜, 피로도, 날짜 넘기기, 저장 불러오기, 재접속으로 현실 일일 등록권을 복구할 수 없다.
10. 기기 로컬 시계나 사용자가 변경 가능한 시간대 설정을 권위 시간으로 사용하지 않는다.
11. 등록 화면은 `오늘 등록권 사용 여부`, `마지막 성공 시각`, `다음 초기화 시각: KST 00:00`, `남은 시간`을 명확히 표시한다.
12. KST 자정 이전에 등록권을 사용했다면 자정 이후 새 일일 구간에서 다시 1회를 사용할 수 있다. 이는 정확히 24시간을 기다리는 쿨다운 방식이 아니다.
13. 자정 경계 직전·직후 동시 요청, 중복 요청과 다중 기기의 판정은 서버 또는 동등한 권위 시간과 원자적 기록을 사용해야 한다.
14. 등록 요청 실패·취소·통신 오류가 일일 권한을 소비하는 정확한 시점은 후속 기술 설계에서 확정한다. 현재 확정된 기본 의미는 `성공한 등록 행동 1회`다.
15. 외부 작품의 운영자·시스템 등록 주기는 플레이어 계정의 현실 일일 등록권과 분리할 수 있으며, 본 결정은 플레이어가 실행하는 신규 등록·갱신 행동의 초기화 경계를 확정한다.

1. 플레이어의 현실 일일 등록권은 서버 또는 동등한 권위 시스템에서 등록 성공이 확정된 경우에만 소모한다.
2. `등록 성공`은 다음 결과가 하나의 원자적 작업으로 모두 저장된 상태를 뜻한다.
   - 등록 대상과 자격 검증 완료
   - 최초 등록이면 입성 스냅샷 생성
   - 신규 등록·갱신 공통으로 현재 상태 스냅샷 반영
   - 마지막 성공 시각과 KST 날짜 키 기록
   - 해당 KST 날짜의 일일 등록권 사용 기록
3. 등록 확인 화면에서 플레이어가 취소하거나 최종 확정을 하지 않은 경우 일일 횟수를 소모하지 않는다.

6. 서버 내부 오류, 저장 실패 또는 트랜잭션 롤백으로 명예의 전당 결과가 만들어지지 않은 경우 일일 횟수를 소모하지 않는다.
7. 등록 결과와 일일 사용 기록 중 하나만 저장되는 부분 성공을 허용하지 않는다. 어느 한쪽이라도 실패하면 전체 작업을 롤백한다.

10. 등록 요청은 계정·KST 날짜·요청 식별자 또는 동등한 멱등 키로 중복 실행을 방지한다.
11. 자정 경계의 동시 요청과 다중 기기 요청은 권위 시간 기준으로 직렬화하거나 원자적으로 경쟁을 해결하여 하나의 성공만 허용한다.

```text
  세트 아이템 자격 보유
)
AND
특수 연대기 보유
```

### 확정 내용

1. 플레이어 제작 작품의 명예의 전당 등록 기본 강화 문턱은 `+50 이상`이다.
2. `+50 이상`만으로는 등록할 수 없으며 희소성 자격과 특수 연대기 자격을 함께 충족해야 한다.
3. 희소성 자격은 다음 두 경로 중 하나 이상을 충족하면 된다.
   - `[특수 재료]`를 사용한 제작·강화 결과로 해당 작품에 귀속된 `[특수 수식어]`를 보유
   - 정식 `[세트 아이템]` 자격을 보유
4. 특수 수식어 경로와 세트 아이템 경로를 모두 동시에 요구하지 않는다. 둘 중 하나를 충족하면 희소성 분기를 통과한다.
5. 희소성 분기를 통과한 작품도 반드시 `[특수 연대기]`를 보유해야 한다.
6. 특수 연대기는 단순 소유 시간, 단순 강화 횟수, 재료 희귀도 또는 자동 생성 문구가 아니라 작품이 실제 세계 사건·고객 사용·성공·부분 성공·실패·손상·복원·계승 등에서 쌓은 의미 있는 생애 기록을 기반으로 한다.
7. 단순히 특수 재료를 투입했다는 사실만으로 특수 수식어 자격을 부여하지 않는다. 작품에 유효한 특수 수식어 결과가 실제로 귀속돼 있어야 한다.
8. 일반 수식어, 높은 수치만 가진 일반 작품 또는 단순 보유 세트 재료는 희소성 분기를 충족하지 않는다.
9. 세트 아이템은 선행 `BS-SET-*` 결정의 사건 연대기 기반 세트 원칙을 따르며, 단순히 같은 이름·외형·재료를 모았다는 이유로 등록 자격을 얻지 않는다.
10. 세트의 모든 구성품이 자동으로 등록 자격을 얻는지, 기여한 개별 구성품만 얻는지, 세트 전체를 하나의 출품 단위로 다루는지는 후속 결정으로 남긴다.
11. `[특수 연대기]`의 최소 사건 수, 필수 태그, 희소도, 독창성 또는 검증 점수는 후속 설계에서 확정한다.
12. 이미 명예의 전당에 등록된 작품의 현재 상태 갱신도 갱신 시점의 자격 검증을 거친다. 손상·변화로 현재 자격을 일시적으로 잃었을 때의 갱신·표시·순위 처리 방식은 후속 결정이다.
13. 외부 작품은 플레이어 작품과 동일하게 명예의 전당 자격 검증을 받아야 하지만, 외부 작품의 역사 체계에 `+50`, 특수 수식어 또는 세트 데이터가 동일한 형태로 존재하지 않는 경우 사용할 동등 자격 표준은 후속 결정으로 남긴다.
14. 외부 작품의 동등 표준은 플레이어 작품보다 느슨한 우회 조건이 되어서는 안 되며, 강화·희소성·특수 연대기라는 세 축의 의미를 보존해야 한다.
15. 등록 화면은 `강화 문턱`, `희소성 분기`, `특수 연대기` 세 축의 충족 여부와 부족한 조건을 각각 보여준다.

### 자격 판정 흐름

```text
작품 선택
→ 강화 문턱 확인
  ├─ +50 미만 → 등록 불가
  └─ +50 이상
     → 희소성 분기 확인
       ├─ 특수 재료 기반 특수 수식어 보유
       ├─ 또는 정식 세트 아이템 자격
       └─ 둘 다 없음 → 등록 불가
     → 특수 연대기 확인
       ├─ 있음 → 등록 요청 가능
       └─ 없음 → 등록 불가
→ 최종 등록 요청
→ BS-HOF-20260802-04의 원자적 성공 처리
```

### 보호 조건

- 단순 고강화 수치만으로 명예의 전당을 채우지 않는다.
- 희귀 재료를 소비했다는 사실만으로 등록 자격을 판매하거나 보장하지 않는다.
- 특수 수식어와 세트 자격을 모두 강제해 하나의 정답 제작법만 남기지 않는다.
- 반대로 특수 연대기를 선택 조건으로 낮춰 수치·재료 중심 랭킹으로 변질시키지 않는다.
- 짧고 반복 가능한 동일 사건을 파밍해 특수 연대기 자격을 대량 생성하지 않는다.
- 세트가 아닌 개별 특수 작품과 특수 수식어가 없는 사건 연대기 세트 모두 진입 경로를 가질 수 있게 한다.
- 외부 작품을 수집가 상점·플레이어 재고·재매입 대상으로 전환하지 않는다.
- 등록 자격 미달은 `BS-HOF-20260802-04`에 따라 일일 등록권을 소모하지 않는다.
