## `BS-HOF-20260802-03` — 한국 표준시 자정 기준 현실 일일 등록권 초기화

- 승인 시각: `2026-08-02 20:20 KST`
- 상태: `CONFIRMED_BY_LATEST_USER_DIRECTION / APPROVED_KST_MIDNIGHT_RESET`
- 사용자 근거:
  - `권장안대로 진행 (한국 시간 24시 기준으로 초기화)`

### 이전 결정 상세화

- `BS-HOF-20260802-02`에서 후속으로 남긴 현실 날짜의 기준 시간대와 초기화 시각을 본 결정이 확정한다.
- 명예의 전당 신규 등록과 기존 작품 갱신은 계속 하나의 현실 일일 등록 행동 한도를 공유한다.
- 현재 상태는 성공한 등록·갱신 행동에서만 반영되며 자동·실시간 갱신하지 않는다.

### 확정 내용

1. 명예의 전당의 현실 일일 등록권은 한국 표준시 `KST (UTC+09:00)`를 공통 기준으로 사용한다.
2. 일일 등록권은 매일 한국 시간 `00:00`에 초기화한다.
3. 사용자가 표현한 `한국 시간 24시`는 해당 날짜의 끝과 다음 날짜의 시작인 `KST 00:00` 경계를 뜻한다.
4. 하나의 현실 일일 구간은 `KST 00:00 이상`부터 `다음 날 KST 00:00 미만`까지다.
5. 같은 KST 날짜 구간 안에서 플레이어 계정은 신규 작품 등록 또는 기존 작품 현재 상태 갱신 중 하나만 1회 성공시킬 수 있다.
6. 등록·갱신에 성공하면 해당 KST 날짜의 일일 등록권을 사용한 상태가 된다.
7. 다음 KST 자정이 도달하면 사용 상태가 초기화되고 새로운 현실 일일 등록권 1회를 사용할 수 있다.
8. 모든 지역의 플레이어에게 동일한 KST 자정 경계를 적용하며, 계정·기기·접속 지역의 현지 시간대로 초기화 시각을 변경하지 않는다.
9. 게임 내 날짜, 피로도, 날짜 넘기기, 저장 불러오기, 재접속으로 현실 일일 등록권을 복구할 수 없다.
10. 기기 로컬 시계나 사용자가 변경 가능한 시간대 설정을 권위 시간으로 사용하지 않는다.
11. 등록 화면은 `오늘 등록권 사용 여부`, `마지막 성공 시각`, `다음 초기화 시각: KST 00:00`, `남은 시간`을 명확히 표시한다.
12. KST 자정 이전에 등록권을 사용했다면 자정 이후 새 일일 구간에서 다시 1회를 사용할 수 있다. 이는 정확히 24시간을 기다리는 쿨다운 방식이 아니다.
13. 자정 경계 직전·직후 동시 요청, 중복 요청과 다중 기기의 판정은 서버 또는 동등한 권위 시간과 원자적 기록을 사용해야 한다.
14. 등록 요청 실패·취소·통신 오류가 일일 권한을 소비하는 정확한 시점은 후속 기술 설계에서 확정한다. 현재 확정된 기본 의미는 `성공한 등록 행동 1회`다.
15. 외부 작품의 운영자·시스템 등록 주기는 플레이어 계정의 현실 일일 등록권과 분리할 수 있으며, 본 결정은 플레이어가 실행하는 신규 등록·갱신 행동의 초기화 경계를 확정한다.

### 시간 경계

```text
KST 2026-08-02 00:00
→ 2026-08-02 일일 등록권 시작
→ 신규 등록 또는 기존 작품 갱신 중 1회 성공 가능

KST 2026-08-03 00:00
→ 이전 날짜 사용 상태 종료
→ 2026-08-03 일일 등록권 1회 시작
```

### 등록·갱신 흐름

```text
플레이어 등록·갱신 요청
→ 권위 시간의 KST 날짜 확인
→ 해당 KST 날짜 사용 여부 확인
→ 자격·데이터 검증
→ 성공 시 작품 스냅샷 반영과 일일 사용 기록을 원자적으로 저장
→ 최초 등록이면 입성 스냅샷 생성
→ 기존 작품 갱신이면 입성 스냅샷 유지 + 현재 상태만 교체
→ 다음 사용 가능 시각은 다음 KST 00:00
```

### 보호 조건

- 마지막 성공 시점부터 정확히 24시간을 요구해 등록 시간이 매일 밀리는 구조를 사용하지 않는다.
- 계정 지역이나 기기 시간대를 바꿔 일일 초기화를 여러 번 받게 하지 않는다.
- 게임 내 날짜 변경으로 현실 일일 한도를 우회하지 않는다.
- 신규 등록과 갱신에 각각 별도 일일 횟수를 제공하지 않는다.
- 자정 경계에서 중복 요청이 모두 성공해 하루 한도를 초과하지 않게 한다.
- 단순 조회·정렬·상세 열람은 등록 행동으로 취급하지 않는다.
- 등록권을 유료 결제·광고 시청·희귀 재화로 반복 충전하는 구조를 기본 설계로 두지 않는다.
- 한국 외 지역 플레이어에게 KST 기준임을 숨기지 않고 현지 시간 환산과 남은 시간을 함께 제공할 수 있게 한다.

## `BS-HOF-20260802-04` — 등록 성공 확정 시에만 현실 일일 횟수 소모

- 승인 시각: `2026-08-02 20:58 KST`
- 상태: `CONFIRMED_BY_LATEST_USER_DIRECTION / APPROVED_SUCCESS_ONLY_DAILY_CONSUMPTION`
- 사용자 근거:
  - `권장안대로 진행`

### 이전 결정 상세화

- `BS-HOF-20260802-03`에서 후속으로 남긴 실패·취소·통신 오류 시 일일 한도 소비 시점을 본 결정이 확정한다.
- 현실 일일 등록권은 계속 매일 `KST 00:00`에 초기화하고, 신규 등록과 기존 작품 갱신이 같은 1회 한도를 공유한다.

### 확정 내용

1. 플레이어의 현실 일일 등록권은 서버 또는 동등한 권위 시스템에서 등록 성공이 확정된 경우에만 소모한다.
2. `등록 성공`은 다음 결과가 하나의 원자적 작업으로 모두 저장된 상태를 뜻한다.
   - 등록 대상과 자격 검증 완료
   - 최초 등록이면 입성 스냅샷 생성
   - 신규 등록·갱신 공통으로 현재 상태 스냅샷 반영
   - 마지막 성공 시각과 KST 날짜 키 기록
   - 해당 KST 날짜의 일일 등록권 사용 기록
3. 등록 확인 화면에서 플레이어가 취소하거나 최종 확정을 하지 않은 경우 일일 횟수를 소모하지 않는다.
4. 최소 `+50`, 특수 수식어·세트·연대기 등 현재 또는 후속 자격 검증을 통과하지 못한 경우 일일 횟수를 소모하지 않는다.
5. 이미 해당 KST 날짜의 등록권을 사용했거나, 대상 작품이 존재하지 않거나, 데이터가 유효하지 않은 요청은 저장하지 않고 횟수도 추가 소모하지 않는다.
6. 서버 내부 오류, 저장 실패 또는 트랜잭션 롤백으로 명예의 전당 결과가 만들어지지 않은 경우 일일 횟수를 소모하지 않는다.
7. 등록 결과와 일일 사용 기록 중 하나만 저장되는 부분 성공을 허용하지 않는다. 어느 한쪽이라도 실패하면 전체 작업을 롤백한다.
8. 명예의 전당 결과가 권위 저장소에 성공적으로 기록됐으나 플레이어에게 성공 응답만 전달되지 않은 경우에는 이미 성공한 등록으로 처리하고 해당 일일 횟수도 소모된 상태를 유지한다.
9. 위 응답 유실 상황에서 같은 요청을 다시 보내면 기존 성공 결과를 반환하고, 작품을 중복 등록하거나 현재 상태를 중복 갱신하거나 일일 횟수를 추가 소모하지 않는다.
10. 등록 요청은 계정·KST 날짜·요청 식별자 또는 동등한 멱등 키로 중복 실행을 방지한다.
11. 자정 경계의 동시 요청과 다중 기기 요청은 권위 시간 기준으로 직렬화하거나 원자적으로 경쟁을 해결하여 하나의 성공만 허용한다.
12. 등록 화면은 요청 결과를 `성공`, `검증 실패`, `오늘 사용 완료`, `취소`, `처리 실패·재시도 가능`, `이미 처리된 성공 요청` 등으로 구분해 표시한다.
13. 검증 실패 이유는 플레이어가 수정할 수 있도록 부족한 자격과 충족 조건을 보여준다.
14. 기술 오류를 반복 유도해 등록권을 보존한 채 결과만 복제하거나 순위를 조작할 수 없도록, 성공 결과와 일일 사용 기록의 원자성·멱등성을 우선한다.
15. 외부 작품을 운영자가 등록하는 시스템 작업에는 플레이어 계정의 일일 등록권 소비 규칙을 자동 적용하지 않는다.

### 원자적 등록 흐름

```text
등록·갱신 요청
→ 권위 KST 날짜와 오늘 사용 여부 확인

  ├─ 취소·자격 미달·유효성 실패
  │  → 저장 없음
  │  → 일일 등록권 유지
  └─ 검증 통과
     → 하나의 원자적 작업 시작

       - 마지막 성공 시각 저장
       - KST 날짜 사용 기록 저장
     → 전체 성공
       - 일일 등록권 소모
       - 성공 결과 반환
     → 일부라도 실패
       - 전체 롤백
       - 일일 등록권 유지
```

### 보호 조건

- 등록 버튼을 누른 시점에 선차감하지 않는다.
- 자격 미달·취소·단순 입력 오류·저장되지 않은 서버 실패에 일일 횟수를 소모하지 않는다.
- 등록 결과 없이 일일 사용 기록만 남겨 플레이어의 기회를 잃게 하지 않는다.
- 일일 사용 기록 없이 등록 결과만 남겨 같은 날 반복 등록할 수 있게 하지 않는다.
- 응답 유실을 실패로 오인해 동일 작품·스냅샷·순위 항목을 중복 생성하지 않는다.
- 재시도할 때 일일 횟수를 두 번 소모하지 않는다.
- 자정 직전 요청을 자정 이후 요청으로 중복 처리해 두 날짜의 등록권을 동시에 부당하게 소모하지 않는다.
- 클라이언트가 성공 여부나 일일 사용 상태를 단독 결정하지 않는다.
