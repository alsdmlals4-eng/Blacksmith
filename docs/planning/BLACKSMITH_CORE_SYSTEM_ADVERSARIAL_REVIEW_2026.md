## 1. 현재 프로젝트의 핵심 약속

> 한 명의 대장장이가 제한된 하루 작업량 안에서 작품 한 점을 직접 만들고, 강화 위험 앞에서 멈춤과 추가 도전을 선택하며, 작품을 고객에게 보낸 뒤 그 작품이 세계에서 만든 결과와 역사를 다음 제작 동기로 돌려받는 게임.

차별화의 중심은 `강화 자체의 긴장`과 `강화한 작품이 세계에서 살아남아 역사를 만드는 환류`의 결합이다.

## 2. 시스템 위계

### 2.1 핵심 시스템

1. **직접 제작**
   - 작품의 출생 차이와 최초 정체성을 만든다.
   - 주재료, 완성도, 작품 종류가 시작 조건을 결정한다.

2. **강화와 멈춤 판단**
   - 가장 자주 반복하는 주 행동이다.
   - 성공·실패 결과보다 `지금 멈출지, 더 투자할지`가 핵심 판단이다.
   - +10 단위 정밀강화·수식어 이정표가 작품의 성질을 만든다.

3. **피로도와 날짜 진행**
   - 무제한 반복을 막는 단순 스태미나가 아니라 하루의 작업 우선순위를 만드는 핵심 시간 자원이다.
   - 날짜는 의뢰·고객 재방문·세계 사건·시장 변화의 공통 시간축이다.

4. **작품 생애와 세계 환류**
   - 방문 고객에게 실제 납품된 작품이 UID·소유자·사건·손상·복원·계승 이력을 유지한다.
   - 즉시 결과와 지연 결과가 작품의 기여를 설명하고 다음 의뢰·재료·명성·제작 목표를 만든다.

### 2.2 핵심을 직접 보강하는 1차 보조 시스템

- 방문 고객과 의뢰 목적
- 작품군별 역할과 세트 연결
- 재료·보조재료·촉매 공유 자원
- 작품 연대기와 결과 설명
- 수집가 재회·재매입
- 제한된 자동화와 저위험 연속 강화
- 명성·관계·새 제작법·새로운 작품군 해금

### 2.3 후속 콘텐츠로 분리할 2차 보조 시스템

- 명예의 전당 전체 UI·테마 운영·검색·필터
- 외부 역사 작품 운영
- 전쟁·토너먼트·관전·베팅
- 광범위한 시장·세력·국가 시뮬레이션
- 대표작·선택형 복원 고도화
- 다수 작품군의 대규모 세트 콘텐츠

명예의 전당은 `FUTURE_CONTENT_HOLD`이며 핵심 루프 완성 조건으로 사용하지 않는다.

## 3. 핵심 재미

### 즉각적 재미

- 터치·제작 반응
- 강화 성공의 즉시 피드백
- 실패 위험을 읽고 멈춤 또는 추가 도전을 선택하는 긴장
- +10 이정표에서 작품의 성질을 직접 결정하는 소유감

### 세션 재미

- 제한된 피로도 안에서 어떤 작품과 의뢰에 오늘을 쓸지 정하는 우선순위
- 작품을 어디까지 강화하고 누구에게 보낼지 판단
- 납품 후 짧은 이벤트를 보며 강화 반복에서 호흡을 바꾸는 리듬

### 장기 재미

- 내가 만든 작품이 다른 사람의 손에서 성공·실패·손상·복원·계승을 겪는 역사
- 과거 작품의 결과가 고객 재방문과 새로운 작품 요구로 돌아오는 연속성
- 단순히 더 높은 숫자가 아니라 `더 강하고, 더 적합하고, 더 많은 이야기를 가진 작품`을 만드는 포트폴리오 성장

## 4. 플레이어 목표

### 단기 목표

- 오늘의 의뢰와 세계 상황을 보고 제작 대상을 선택한다.
- 제한된 피로도 안에서 목표 강화 이정표까지 도달한다.
- 현재 작품을 멈출지 더 도전할지 결정한다.

### 중기 목표

- 특정 고객·사건에 맞는 작품 또는 세트를 완성한다.
- 납품 결과와 재방문을 통해 관계·재료·새 의뢰를 연다.
- 손상되거나 실패한 작품을 복원·재강화해 생애를 이어간다.

### 장기 목표

- 다양한 작품군과 강화 경로를 숙달한다.
- 세계에 남은 작품들의 연대기와 연결된 제작자 명성을 만든다.
- 자신의 대표적인 작품군과 제작 철학을 형성한다.

`최고 강화 수치 달성`은 장기 목표의 한 축일 뿐 전체 최종 목표가 아니다.

## 5. 적대적 검토 결과

### P0 — 현재 발견 없음

제품 코드를 즉시 중단하거나 승인 결정을 무효화할 수준의 치명 충돌은 확인하지 못했다.

### P1 — 정본 충돌·모호성

#### `P1-01` Game Bible의 강화 규칙이 최신 승인과 불일치

- Game Bible은 +5 납품 PoC, +30 파괴, 최대 3개 수식어, +100 제품 목표를 현행 설명에 함께 둔다.
- 최신 승인은 데모에서 플레이어 선택 작품이 +50까지 실제 진행하고, +10마다 정밀 이정표를 거치며, 손상·대파 시 단계 하락과 수식어 잠금·복원을 사용한다.
- 완전 파괴는 명시적이고 충분히 고지된 선택에만 허용하며, 숨은 난수로 임의 소멸시키지 않는다.

**조치 후보:** Game Bible의 강화·손상·데모 범위를 최신 승인 정본에 맞춰 재작성하고, 구형 PoC 규칙은 `LEGACY_POC`로 분리한다.

#### `P1-02` POC 기준선의 영구 파괴 계약이 최신 작품 생애 보호와 충돌

- POC 기준선은 무보호 파괴의 즉시 영구 소멸과 보호 파괴를 핵심 시나리오로 둔다.
- 최신 승인에서는 일반적인 손상·대파가 작품 UID·생애·수식어 기록을 유지하고, 완전 파괴는 명시적 선택으로 제한된다.

**조치 후보:** 기존 파괴 시나리오를 `LEGACY / REQUIRES_REAPPROVAL`로 내리고 `DAMAGE_RESTORE`, `CATASTROPHIC_SCAR`, `EXPLICIT_DESTRUCTION` 시나리오로 교체한다.

#### `P1-03` 멀티플레이·서버 제외와 현실 일일 등록 권위 시간의 잠재 충돌

- Game Bible은 서버를 프로젝트 제외로 적는다.
- 명예의 전당은 KST 자정, 계정별 일일 등록권, 기기 시계 우회 방지, 원자적 등록을 요구한다.

**판정:** 명예의 전당이 후속 콘텐츠 보류이므로 현재 차단은 아니다. 다만 구현 재개 전 `서버 없는 권위 시간` 또는 `서버 최소 서비스 허용` 중 하나를 재승인해야 한다.

#### `P1-04` 핵심 목표의 성공 판정이 문서에 없다

시스템 구성은 상세하지만 실제 핵심 재미가 성공했는지 판단할 행동 지표가 부족하다.

**권장 검증 기준:**
- 플레이어가 최근 작품 하나의 강화 선택과 역사를 자발적으로 설명할 수 있는가.
- 플레이어가 다음 날 무엇을 만들지 작품·고객 결과를 근거로 결정하는가.
- 피로도가 단순 차단이 아니라 우선순위 선택으로 인식되는가.
- 강화 중 멈춤 판단이 실제 고민을 만들며, 자동화가 이를 대체하지 않는가.
- 고객 이벤트가 강화보다 길지 않으면서 다음 제작 욕구를 만드는가.

### P2 — 구조 개선 권고

#### `P2-01` 핵심 루프 문장을 더 짧게 고정

권장 표현:

> `오늘 만들 작품을 고른다 → 어디까지 강화할지 결정한다 → 고객에게 보낸다 → 작품이 만든 역사를 보고 내일의 작품을 정한다.`

모든 보조 시스템은 이 네 단계 중 하나를 강화해야 한다. 직접 연결되지 않는 시스템은 후속 콘텐츠로 보낸다.

#### `P2-02` 강화 숫자 경쟁과 작품 역사 사이의 우선순위 명시

- 강화는 가장 빈번한 주 행동이다.
- 작품 역사는 강화 행동을 장기적으로 의미 있게 만드는 환류다.
- 어느 한쪽도 독립 메인 게임이 아니다.

권장 설계 비율은 세션 체감 기준 `강화·제작 70~80%`, `고객·결과·연대기 20~30%`이며 정확한 비율은 플레이 테스트 값이다.

#### `P2-03` 콘텐츠 생산 비용 제한

고객·세계 사건·세트·연대기를 모두 수작업 서사로 확장하면 콘텐츠 비용이 코어 검증보다 빨리 폭증한다.

권장 순서:
1. 고객 1명과 작품 1점의 완전한 왕복
2. 서로 다른 목적의 고객 3명
3. 무기·방어구·장신구 각 1종
4. 실패·손상·복원·계승의 대표 생애 패턴
5. 세트·수집가
6. 명예의 전당·세계 대형 콘텐츠

#### `P2-04` 일일 루프 종료 만족도 보강

피로도 소진만으로 하루가 끝나면 강제 정지처럼 느껴질 수 있다.

권장 방향:
- 하루 종료 전 `오늘 완성한 것`, `보낸 작품`, `내일 확인할 결과`를 짧게 정리한다.
- 보너스 체크리스트나 일일 미션은 추가하지 않는다.
- 다음 날 기대를 만드는 예약된 세계 결과만 보여준다.

## 8. 결론

현재 핵심 재미와 시스템 구성은 서로 맞는다. 가장 강한 차별점은 `강화의 멈춤·도전 판단`과 `작품 생애의 세계 환류`가 피로도·날짜로 연결된다는 점이다.

문제는 새로운 시스템 부족이 아니라 최신 결정이 과거 Game Bible·POC 문서에 완전히 흡수되지 않았고, 핵심 재미의 행동 성공 기준이 아직 명문화되지 않았다는 것이다.

따라서 다음 최적 행동은 콘텐츠 확장이 아니라 `정본 정합화 → 핵심 재미 플레이 검증 → 결과에 따른 최소 조정`이다.
