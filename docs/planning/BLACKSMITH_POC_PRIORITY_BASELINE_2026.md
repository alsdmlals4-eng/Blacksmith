> 상태: `PLANNING_IN_PROGRESS`
>
> 기준일: 2026-07-26
>
> 효력: 이 문서는 `BLACKSMITH_GENRE_BENCHMARK_2026.md`의 제안 우선순위를 사용자 승인에 따라 대체한다. 아래 6개 항목은 후속 통합 POC 구현의 선행 범위다. 사람 플레이 검증은 이 6개 항목과 자동 검증이 완료된 뒤 진행한다.

1. POC 시나리오 런처

## 2. P1 — POC 시나리오 런처

### 2.1 책임

- 긴 자연 성장 없이 핵심 시스템을 직접 재현한다.
- 모든 시나리오는 결정적 seed, 시작 스냅샷, 자원 프리셋, 기대 종료 상태를 가진다.
- 시나리오 종료 또는 재시작 시 해당 시나리오 시작 스냅샷으로 되돌릴 수 있다.
- 출시 플레이 메뉴와 분리된 POC·QA 진입점으로 취급한다.

### 2.2 시나리오 목록 — `POC_CONFIRMED`

| ID | 시나리오 | 핵심 확인 |
|---|---|---|
| `CORE_LOOP` | 제작→강화→판매→재투자 | 코어 경제 순환 |
| `PRECISION_GRADE` | 등급 결정·등급 강화 | 정밀 등급 1개 구조 |
| `PRECISION_AFFIX` | 수식어 추가·강화 | 수식어 슬롯 2개 구조 |
| `LIMIT_BUILD` | +40→+50→+60 한계 빌드 | 메인 포인트 경쟁 |
| `PROTECTION_DAMAGE` | 파괴→보호석→DAMAGED | 보호석 책임 |
| `RECOVERY_WINDOW` | 회복석·3일 기한·보관 | 회복 기록 책임 |
| `LOW_RISK_BATCH` | 저위험 연속 강화 | 개별 판정·정지 조건 |
| `FAILURE_BOUND` | 연속 실패→특수 타격 | 실패 최악 상한 |
| `LIFECYCLE_GLADIATOR` | 검투사 장비 생애 | 조언·경기·재방문 |
| `MILITARY_NATION` | 보급→군사력→국가 사건 | 세계 영향 |
| `SMUGGLING` | 밀수 성공·적발 | 고수익·위험 |
| `HISTORY_COLLECTOR` | 역사 장비→전시→수집가 | 역사 가치·거래 |

### 2.3 공통 프리셋 — `POC_TUNABLE`

- 기본 seed: `20260726`
- 시나리오별 seed: `2026072601`부터 순차 부여
- 기본 시작 골드: `120,000`
- 일반 강화 재료: `600`
- 일반 촉매: `80`
- 보호석: `8`
- 회복석: `8`
- 대표 특수 재료: `6`
- 강화 메인 포인트: `8`
- 시나리오 런처에서는 부족 자원으로 핵심 장면이 막히지 않도록 프리셋을 우선한다.

### 2.4 완료 조건

각 시나리오는 다음 상태를 가진다.

- `NOT_STARTED`
- `IN_PROGRESS`
- `PASSED`
- `FAILED_EXPECTATION`

`PASSED`는 사람이 재미를 승인했다는 뜻이 아니라, 시나리오의 기대 상태와 계약이 재현됐다는 뜻이다.

## 3. P2 — 장비 연대기 요약 카드

### 3.1 카드 구성 — `POC_CONFIRMED`

상단 요약:

1. 전투·활동 가치
   - 현재 강화 단계
   - 제작 완성도
   - 정밀 등급
   - 수식어 2개
2. 거래 가치
   - 공개시장가
   - 적합 고객 등급
   - 특별 거래 예상 범위
3. 역사 가치
   - 대표 소유자
   - 대표 사건
   - 손상·복구 흔적
   - 전시·수집가 상태

### 3.2 타임라인 이벤트

- `CRAFTED`
- `ENHANCEMENT_RUN`
- `MILESTONE_REACHED`
- `PRECISION_RESULT`
- `FAILURE_MAJOR`
- `DAMAGED`
- `RECOVERED`
- `OWNER_CHANGED`
- `CUSTOMER_ACTIVITY`
- `MILITARY_EVENT`
- `SMUGGLING_EVENT`
- `NATION_EVENT`
- `EXHIBITED`
- `SOLD`

저위험 연속 강화의 개별 성공은 타임라인을 오염시키지 않도록 한 건의 `ENHANCEMENT_RUN`으로 묶되, 상세 로그에서는 개별 판정을 보존한다.

### 3.3 표시 수치 — `POC_TUNABLE`

- 요약 카드 대표 사건: 최대 `6개`
- 기본 펼침 타임라인: 최근 `12개`
- 전체 타임라인: 중요 사건 전체
- 같은 유형의 저중요도 사건은 `3개 이상`부터 묶음 표시
- 장비 이름은 플레이어가 한 번 변경할 수 있고, 이후 다시 변경하려면 소액 골드를 사용한다.

### 3.4 검증 목표

외부 테스트에서 플레이어가 다음을 설명할 수 있어야 한다.

- 이 장비가 누구에게 사용됐는지
- 어느 실패나 복구를 겪었는지
- 왜 일반 장비보다 역사 가치가 높은지

## 4. P3 — 위험·결과 사전 카드

### 4.1 적용 대상 — `POC_CONFIRMED`

- 일반 강화
- 정밀강화
- 보호석·회복석 사용
- 군사 보급 계약
- 국가 사건 선택
- 밀수 계약
- 수집가 위험 흥정

### 4.2 표시 필드

- 위험 단계
- 확정 소비
- 가능한 결과
- 가능한 최악 결과
- 보호·완화 수단이 바꾸는 결과
- 영향을 받는 세계 수치 방향
- 결과 판정 시점
- 회복 가능 여부

### 4.3 위험 단계 내부 구간 — `POC_TUNABLE`

내부 위험 점수는 `0~100`이며 플레이어에게 숫자를 직접 표시하지 않는다.

| 점수 | 표시 |
|---:|---|
| 0~9 | 매우 낮음 |
| 10~24 | 낮음 |
| 25~49 | 보통 |
| 50~74 | 높음 |
| 75~100 | 매우 높음 |

### 4.4 확인 규칙 — `POC_CONFIRMED`

- `높음` 이상: 명시 확인 1회
- 영구 파괴·몰수·장기 부상 가능: 결과 문구를 읽은 뒤 확인
- 같은 조건을 반복할 때는 세션 내 간소화 가능하나, 조건이나 보호 수단이 달라지면 다시 표시
- 정확한 성공률·신뢰 수치·밀수 적발 확률은 공개하지 않음

## 5. P4 — 저위험 연속 강화

### 5.1 해금과 범위 — `POC_CONFIRMED`

- 플레이어가 일반 강화를 수동으로 `15회` 판정한 뒤 해금
- POC 시나리오 런처에서는 즉시 해금 프리셋 제공
- 적용 가능 구간: `+1~+20`
- 위험 단계가 `매우 낮음` 또는 `낮음`인 시도만 포함
- 한 번에 최대 `10회` 요청
- 내부적으로 각 강화는 개별 판정·비용·이력·telemetry를 유지

### 5.2 자동 정지

다음 중 하나라도 발생하면 즉시 정지한다.

- 첫 실패
- 재료·골드·작업량 부족
- 목표 강화 단계 도달
- `+10`, `+20` 정밀강화 대기 진입
- 위험 단계가 `보통` 이상으로 상승
- 장비가 `DAMAGED`가 됨
- 보호석·특수 타격 등 수동 선택이 필요한 상태 진입

### 5.3 UI

시작 전 다음을 표시한다.

- 최대 시도 횟수
- 최대 소비 가능 골드·재료
- 정지 조건
- 도달 가능한 최고 단계

`고위험 연속 강화`와 정밀강화 자동 처리는 도입하지 않는다.

## 6. P5 — 기존 특수 타격을 이용한 실패 상한

### 6.1 원칙 — `POC_CONFIRMED`

- 새 실패 스택이나 별도 재화를 만들지 않는다.
- 기존 강화 특수 타격 충전값에 실패 기여를 포함한다.
- 충전 완료 후 다음 강화에서 선택형 `실패 완충 타격`을 사용할 수 있다.
- 성공률을 100%로 만들지 않는다.
- 사용 시 성공·실패와 무관하게 충전값을 모두 소비한다.

### 6.2 POC 충전값 — `POC_TUNABLE`

충전 최대치: `100`

| 결과 | 충전 기여 |
|---|---:|
| 저위험 실패 | +15 |
| 보통 위험 실패 | +25 |
| 높은 위험 실패 | +35 |
| 매우 높은 위험 실패 | +45 |
| 손상 복구 후 재강화 | +20 |
| 개인 최고 강화 갱신 | +10 |

- 성공만 반복해서 충전 완료할 수 없도록 성공 기여는 개인 최고 갱신 등 의미 있는 사건에 제한한다.
- 같은 저위험 단계 반복 실패의 세 번째부터 기여량을 절반으로 감쇠한다.

### 6.3 실패 완충 효과 — `POC_CONFIRMED`

자연 실패 결과가 발생한 뒤 최종 결과를 다음 상한으로 제한한다.

| 자연 결과 | 완충 후 최대 결과 |
|---|---|
| 영구 파괴 | `DAMAGED` |
| `DAMAGED` | 강화 `2단계 하락` |
| 3단계 이상 하락 | `1단계 하락` |
| 1~2단계 하락 | `1단계 하락` |
| 재료만 손실 | 변경 없음 |

보호석과 함께 사용한 경우 처리 순서:

1. 자연 실패 결과 결정
2. 보호석이 영구 파괴를 `DAMAGED`로 변환
3. 실패 완충 타격이 최종 결과를 최대 `2단계 하락`으로 제한

이는 강한 조합이지만 충전 완료 시에만 1회 사용할 수 있으며 성공률은 증가하지 않는다.

### 6.4 전문화 추가 효과 — `POC_TUNABLE`

- 안정 타격: 완충 사용 시 최대 하락 `1단계`
- 승부사의 망치: 완충을 사용하지 않고 성공하면 판매 가치 보너스용 기록 1회 생성
- 복구 단조: 완충 후 회복 가능 기록 기간 `+1일`
- 효율 제련: 완충 시 실패 재료 `30%` 반환

정확한 출시 효과는 POC 이후 조정한다.

## 7. P6 — 경제·성장 수치 조정

### 7.1 POC 시작 자원 — `POC_TUNABLE`

자연 진행 프로필:

- 시작 골드: `20,000`
- 일반 강화 재료: `240`
- 일반 촉매: `12`
- 보호석: `1`
- 회복석: `1`
- 강화 메인 포인트: `3`

시나리오 런처 프로필은 2.3의 풍부한 프리셋을 사용한다.

### 7.2 기본 제작비

대표 철검 1개:

- 골드 `500`
- 일반 재료 `20`
- 작업량 `3`

### 7.3 일반 강화 비용 밴드

| 목표 구간 | 1회 골드 | 1회 재료 |
|---|---:|---:|
| +1~+10 | 100 | 2 |
| +11~+20 | 250 | 3 |
| +21~+30 | 600 | 5 |
| +31~+40 | 1,200 | 8 |
| +41~+50 | 2,500 | 12 |
| +51~+60 | 5,000 | 18 |

촉매·보호석·정밀강화 재료는 별도다.

### 7.4 대표 공개시장가

제작 완성도 `평범한`, 정밀 요소 미적용 기준:

| 강화 단계 | 공개시장가 |
|---:|---:|
| +0 | 1,000 |
| +10 | 2,500 |
| +20 | 6,500 |
| +30 | 16,000 |
| +40 | 40,000 |
| +50 | 105,000 |
| +60 | 275,000 |

중간 단계는 인접 이정표 사이를 곡선 보간한다.

### 7.5 거래 채널 보정

- 방문 고객 적합 거래: 공개시장가 대비 `+10~25%`
- 군사 보급: 공개시장가 대비 `+15%`와 군사력·영향력
- 밀수: 공개시장가 대비 `+35%`, 적대 세력·적발 위험 증가
- 수집가: 역사 가치에 따라 `+20~80%`, 예산 상한 적용
- 전시: 직접 골드 없음

### 7.6 성장 이정표

POC 강화 메인 포인트 총 `8점`:

- 강화 숙련 단계 `2, 4, 6, 8, 10, 12, 14, 16`에서 각 1점
- 자연 진행 프로필은 3점부터 시작해 POC 중 나머지를 획득
- 런처 쇼케이스 프로필은 8점 보유
- +50 한계 돌파 비용 2점, +60 한계 돌파 비용 3점 유지

### 7.7 경제 안전 조건

- 일반 공개시장 판매만으로도 다음 강화 재도전이 가능해야 한다.
- 하나의 불운한 실패 연속으로 제작·강화 행동 전체가 잠기지 않아야 한다.
- 방문 고객·군사·밀수·수집가 보상은 코어 공개시장 수익을 대체하지 않는다.
- UI에 `다음 의미 있는 투자`와 부족 골드·재료를 표시한다.
- 지출 후 동일 구간 강화 `2회` 비용보다 적게 남는 경우 경고만 제공하고 차단하지 않는다.

## 8. 자동 검증 선행 조건

6개 항목 구현 뒤 사람 플레이 검증 전에 다음 자동 검증을 통과해야 한다.

- 12개 시나리오 결정적 기대 상태
- 연대기 요약과 원본 이벤트 일치
- 위험 카드와 실제 최악 결과 계약 일치
- 연속 강화 개별 비용·판정·정지 원자성
- 실패 완충 처리 순서와 보호석 조합
- 경제 fixture에서 코어 순환 및 소프트락 방지
- 저장·불러오기 후 시나리오·연대기·충전값 일치

자동 검증 통과는 재미·접근성·Android·성능 검증을 대체하지 않는다.

## 9. 후순위 사람 검증

다음은 6개 선행 항목과 자동 검증 후 진행한다.

- Android 실제 기기
- 안전 영역과 터치
