## 2. 역할 분리

- **보호석**만 무보호 파괴의 영구 소멸을 막을 수 있다.
- **실패 완충 타격**은 성공률을 올리지 않는다.
- 실패 완충 타격은 보호석 없이 파괴 판정이 나오면 장비를 살리지 못한다.
- 보호석과 실패 완충 타격을 함께 사용한 경우에만 보호 파괴의 대폭 단계 손실을 줄인다.
- 실패 완충 타격을 선택한 유효 시도가 시작되면 결과와 관계없이 충전값 전부를 소모한다.
- 보호석도 기존 규칙대로 유효 시도 시작 시 요구 수량 전부를 소모한다.

---

## 3. 최종 결과표

| 자연 결과 | 실패 완충만 사용 | 보호석만 사용 | 실패 완충 + 보호석 |
|---|---|---|---|
| 대성공 | 변경 없음 | 변경 없음 | 변경 없음 |
| 성공 | 변경 없음 | 변경 없음 | 변경 없음 |
| 유지 | 유지 | 유지 | 유지 |
| 하락 1 | **유지** | 유지 | 유지 |
| 하락 2 | **하락 1** | 유지 | 유지 |
| 파괴 | **즉시 영구 소멸** | 보호 파괴 | **보호 파괴 하락량 2단계 감소** |

실패 완충 타격은 무보호 도전의 파괴 안전장치가 아니다. 파괴 가능 구간에서 영구 소멸을 피하려면 보호석이 필요하다.

---

## 4. 보호 파괴 병용 공식

기본 보호 파괴 하락량:

```text
BASE_PROTECTED_BREAK_LOSS
= MAX(3, FLOOR(시도 직전 현재 강화 단계 ÷ 10))
```

실패 완충 타격 병용 하락량:

```text
BUFFERED_PROTECTED_BREAK_LOSS
= MAX(3, BASE_PROTECTED_BREAK_LOSS - 2)
```

최소 하락량은 3단계다. 따라서 낮은 구간에서는 완충 효과가 0~1단계에 그칠 수 있고, 고강화로 갈수록 정확히 2단계의 손실을 줄인다.

| 시도 직전 단계 | 기본 보호 파괴 | 완충 병용 | 최종 단계 |
|---:|---:|---:|---:|
| +51 | -5 | -3 | +48 |
| +60 | -6 | -4 | +56 |
| +80 | -8 | -6 | +74 |
| +99 | -9 | -7 | +92 |

보호 파괴 후 장비는 별도 `DAMAGED` 상태나 수리 없이 즉시 사용 가능하다는 기존 규칙을 유지한다.

---

## 5. 판정 순서

```text
1. 자연 결과 판정
2. 실패 완충 타격 활성 여부 확인
3. 자연 하락 1이면 유지로 완화
4. 자연 하락 2이면 하락 1로 완화
5. 자연 파괴는 이 단계에서 변경하지 않음
6. 보호석 활성 시 남은 하락 1·2를 유지로 변환
7. 보호석 활성 파괴를 보호 파괴로 변환
8. 실패 완충 타격도 활성인 보호 파괴는 기본 하락량에서 2단계 감소, 최소 3단계
9. 보호석 미사용 파괴는 즉시 영구 소멸
```

성공·대성공·유지에서도 선택한 실패 완충 충전값과 보호석은 반환하지 않는다.

---

## 6. 전문화 충돌 처리

기존 `안정 타격: 완충 사용 시 하락 2를 하락 1로 완화`는 새 기본 실패 완충 효과와 완전히 중복되므로 `SUPERSEDED`다.

- `안정 타격` 전문화 자체는 삭제하지 않는다.
- 대체 효과는 밸런스 수치가 아니라 빌드 정체성을 바꾸는 중요 기획이므로 `REVIEW_REQUIRED`로 남긴다.
- 대체 효과가 승인되기 전에는 안정 타격의 추가 보너스를 적용하지 않는다.
- 승부사의 망치와 효율 제련의 기존 POC 효과는 유지한다.

---

## 7. 검증 계약

POC와 후속 시뮬레이션은 최소 다음을 검증한다.

1. 무보호 + 완충 + 하락 1 → 유지
2. 무보호 + 완충 + 하락 2 → 하락 1
3. 무보호 + 완충 + 파괴 → 즉시 영구 소멸
4. 보호석 + 하락 1·2 → 유지
5. 보호석 + 파괴 → 기본 보호 파괴 하락
6. 보호석 + 완충 + 파괴 → 기본 하락량보다 2단계 적게 하락, 최소 3단계
7. 성공·실패와 관계없이 선택한 충전값과 보호석 소모
8. 보호 파괴 후 장비 즉시 사용 가능

보고 지표:

- 실패 완충으로 막은 하락 1 횟수
- 하락 2를 하락 1로 완화한 횟수
- 완충을 사용했지만 무보호 파괴로 소멸한 횟수
- 보호 파괴 손실 감소 총단계
- 보호석·충전값 동시 소비 횟수
