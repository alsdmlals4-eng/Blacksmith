## 네 고객 완주 진행 방식

네 고객 동일 깊이 세션은 **공통 단계 묶음 + 네 사건 병렬 진행** 구조를 사용한다.

수집가·모험가·검투사·병사의 고객별 선택과 완전한 결과 체인은 유지한다. 다만 같은 성격의 준비, 비교, 판매, 영업 종료와 결과 확인을 고객별로 네 번 반복하지 않고 단계별로 묶어 처리한다.

```text
[대장간]
네 장비 공통 준비

[방문 고객]
네 고객 동시 비교
→ 장비 네 개 배정·판매
→ 고객별 후속 준비 선택

[영업 종료]
네 사건을 같은 세계 진행에서 판정
→ 하나의 일관된 체크포인트 저장

[세계]
네 결과 요약 순차 확인
→ 필요한 결과만 상세 연대기 열기
```

이 구조는 네 고객을 결과 영상이나 설명 카드로 축소하는 자동 처리 방식이 아니다. 고객별로 최소 하나 이상의 실제 비가역 선택과 독립된 세계 결과를 유지하면서, 반복 이동과 대기 시간을 제거하는 세션 구조다.

## 세션 단계와 시간 예산

| 단계 | 목표 시간 | 완료 기준 |
|---|---:|---|
| 네 장비 공통 준비 | 6~7분 | 네 고객에게 판매 가능한 서로 다른 장비 준비 |
| 네 고객 비교·배정·판매 | 4~5분 | 요구·선호·야망·가격·후속 가치 비교 후 네 소유권 이전 |
| 네 고객 후속 준비 | 4~5분 | 고객별 실제 준비 선택 최소 1개 확정 |
| 영업 종료·병렬 세계 진행 | 1~2분 | 네 사건 결과 일괄 판정·무결성 검사·저장 |
| 네 결과·연대기 확인 | 4~5분 | 네 결과와 다음 행동 방향 확인 |
| 목표 합계 | 19~24분 | 네 고객 동일 깊이 세션 완료 |

시간 예산은 기획 목표이며 실제 합격은 추가 결정 16의 비유도 테스트 중앙값 15~25분 기준으로 판정한다. 실제 플레이테스트 전에는 시간 적합을 통과했다고 표현하지 않는다.

## 1단계: 네 장비 공통 준비

`[대장간]`에서 고객별 화면을 오가며 장비를 한 개씩 처음부터 제작하지 않는다. 하나의 작업대 맥락 안에서 네 후보 장비를 순차 준비한다.

필수 원칙:

- 네 장비는 서로 다른 고객 적합도와 후속 가치를 보여야 한다.
- 동일 장비를 여러 고객에게 중복 판매할 수 없다.
- 최소 한 장비에서는 일반 강화, 일반 정밀강화와 고위 정밀강화의 대표 감정 곡선을 충분히 경험한다.
- 나머지 장비도 단순 완제품 지급이 아니라 최소 하나 이상의 실제 비용·위험·보호 또는 진화 판단을 거친다.
- 각 비가역 행동은 기존 원자적 저장 계약을 그대로 사용한다.
- 장비 전환 시 마지막 장비의 확률·비용·위험 정보가 다음 장비에 잘못 남지 않는다.

권장 작업대 구조:

```text
장비 준비 목록
1. 검투사 후보 무기
2. 모험가 후보 탐험용 방어구
3. 수집가 후보 전시·의식용 장비
4. 병사 후보 군용 장비

각 장비 카드
→ 현재 강화 단계
→ 고객 적합 방향
→ 남은 필수 준비
→ 비용·위험
→ [작업대에서 준비]
```

장비 카드에서 작업대로 직접 이동하고 준비 완료 후 같은 목록 위치로 복귀한다. 네 장비의 준비 완료 여부를 한 화면에서 확인할 수 있어야 한다.

## 2단계: 네 고객 비교·배정·판매

`[방문 고객]`에서는 네 고객과 네 장비를 같은 비교 흐름에서 다룬다.

```text
네 고객 방문
→ 요구·선호·야망·기한 확인
→ 장비 후보 적합도 비교
→ 고객별 장비 배정
→ 가격·즉시 보상·후속 가치 최종 확인
→ 고객별 판매 확정
```

필수 원칙:

- 수집가·모험가·검투사·병사가 모두 실제 판매 후보로 표시된다.
- 네 고객의 요구, 선호와 야망은 같은 정보 구조로 비교한다.
- 장비를 한 고객에게 배정하면 다른 고객의 후보 목록에서 소유권 충돌을 명확히 표시한다.
- 판매는 고객별로 독립된 비가역 행동이며 각각 원자적으로 저장한다.
- 네 판매를 한 번의 전체 확인으로 묶어 취소 불가능하게 만들지 않는다.
- 판매 완료 후 고객, 장비, 가격, 즉시 보상과 소유권 이전 결과를 즉시 확인한다.
- 판매 도중 앱이 종료돼도 완료된 판매만 유지되고 미완료 판매는 이전 확정 상태로 복귀한다.

### 배정 충돌 처리

```text
장비 A를 검투사에게 판매 완료
→ 장비 A의 소유자는 검투사
→ 다른 고객에게 판매 불가
→ 다른 고객 비교 화면에는 `판매 완료: 검투사 소유` 표시
```

장비를 다른 고객에게 다시 판매하려면 기존 판매를 되돌리는 것이 아니라 별도 회수·재매입·소유권 이전 사건이 필요하다. 버티컬 슬라이스의 같은 세션에서는 판매 되돌리기를 제공하지 않는다.

## 3단계: 네 고객 후속 준비 묶음

네 판매 완료 후 고객별 후속 준비를 하나의 목록에서 순차 확정한다. 각 고객은 최소 하나의 실제 선택을 가진다.

| 고객 | 필수 후속 준비 선택 |
|---|---|
| 검투사 | 경기 배팅 또는 경기 전 지원 선택 |
| 모험가 | 수리·내구 보강·소모품·환경 보조재료 중 선택 |
| 수집가 | 감정 방식·전시 방식·기록 제공 등 유물화 방향 선택 |
| 병사 | 수리·보급·내구 지원·부대 배치 준비 중 선택 |

```text
후속 준비 목록
→ 고객별 남은 영업일
→ 비용
→ 예상 도움 방향
→ 확정 여부
→ [준비 선택]
```

원칙:

- 각 선택의 비용, 기한과 예상 영향 방향을 숨기지 않는다.
- 지원하지 않거나 최소 지원을 선택하는 유효 경로를 둘 수 있다.
- 선택하지 않았다는 이유만으로 자동 실패를 강제하지 않는다.
- 선택 결과와 비용은 고객별로 원자적으로 저장한다.
- 한 고객의 준비 선택이 다른 고객의 준비 상태를 덮어쓰지 않는다.
- 같은 지원을 재실행해 자원이 중복 소비되지 않는다.
- 네 고객 준비 완료 여부를 영업 종료 전에 한 화면에서 확인한다.

## 영업 종료 전 검증 화면

영업 종료 입력 전 네 고객 진행 상태를 요약한다.

| 상태 | 처리 |
|---|---|
| 판매 미완료 고객 존재 | 영업 종료 가능 여부와 미완료 결과를 명확히 안내 |
| 필수 준비 선택 미완료 | 해당 고객으로 직접 이동 가능 |
| 기한 있는 선택 보류 | 보류 시 발생 가능한 방향 표시 |
| 미확인 비가역 결과 존재 | 먼저 결과 확인 |
| 저장 오류·무결성 오류 | 영업 종료 차단 후 복구 안내 |

모든 세션에서 네 고객 완주가 필수이므로, 테스트용 대표 흐름에서는 네 고객 판매와 최소 후속 선택이 완료되기 전 영업 종료를 기본적으로 허용하지 않는다. 이 차단은 어떤 항목이 남았는지와 이동 버튼을 제공해야 하며, 단순 비활성 버튼만 표시하지 않는다.

## 4단계: 병렬 세계 진행과 원자적 체크포인트

영업 종료는 네 고객의 사건을 같은 세계 시간 단계에서 진행시키는 공통 경계다.

```text
영업 종료 확정
→ 네 고객 판매·지원·배팅·보급 상태 검증
→ 검투사 결과 판정
→ 모험가 결과 판정
→ 수집가 결과 판정
→ 병사 결과 판정
→ 장비·소유권·점유·관계·수식어·연대기 무결성 검사
→ 하나의 일관된 영업일 체크포인트 저장
→ 저장된 네 결과 표시
```

핵심 계약:

- 네 결과는 한 번의 세계 진행에서 각각 정확히 1회 판정한다.
- 결과 표시 순서가 판정이나 보상에 영향을 주지 않는다.
- 한 고객 결과만 적용된 상태로 다음 영업일에 진입하지 않는다.
- 일부 결과 저장 실패 시 다음 날을 표시하지 않고 현재 영업일 상태를 유지한다.
- 재시도 시 이미 확정된 판정을 중복 적용하거나 재추첨하지 않는다.
- 네 결과가 모두 정상 저장된 뒤에만 세계 결과 연출과 요약을 시작한다.
- 결과 화면 도중 종료해도 동일한 네 결과 묶음으로 복귀한다.

### 고객별 필수 결과 상태

- 검투사: 경기 승패, 배팅 정산, 장비 상태, 관계, 대표 수식어, 연대기
- 모험가: 귀환·손상 또는 분실·회수, 점유·위치, 관계, 수식어, 연대기
- 수집가: 감정·전시·유물화 또는 역사 가치, 소유권, 대표 수식어, 연대기
- 병사: 부대 사용·손상·공적, 소유권·점유, 관계, 대표 수식어, 연대기

## 5단계: 네 결과 요약과 상세 확인

`[세계]`에서는 네 고객 결과를 한꺼번에 긴 연출로 재생하지 않는다. 먼저 결과 요약 묶음을 제공하고, 고객별 핵심 결과를 순차 확인한다.

```text
영업일 결과 요약
→ 검투사 결과 카드
→ 모험가 결과 카드
→ 수집가 결과 카드
→ 병사 결과 카드
→ 전체 장비 연대기 변화 요약
→ 다음 행동 방향
```

각 결과 카드의 필수 정보:

- 고객 이름과 활동
- 대상 장비 이름·강화 단계
- 결과 방향
- 장비 상태 변화
- 관계·대표 수식어 변화
- 보상·손실
- 연대기 추가 내용
- 다음 방문·요청 또는 행동 방향
- `[상세 보기]`

### 요약과 상세의 경계

- 핵심 결과는 상세 화면을 열지 않아도 이해할 수 있어야 한다.
- 상세 화면은 전체 사건 설명, 과거 소유자 계보와 긴 연대기를 제공한다.
- 동일 결과를 요약과 상세에서 중복 적용하지 않는다.
- 결과 카드는 건너뛸 수 있어도 미확인 상태를 명확히 남긴다.
- 영구 파괴, 저장 복구와 소유권 충돌 같은 필수 상태는 일반 결과보다 먼저 정리한다.
- 접근성 화면 읽기 순서는 고객 → 장비 → 결과 → 변화 → 다음 행동 순서를 유지한다.

## 반복 시간 절감 규칙

다음 반복을 제거한다.

- 고객마다 대장간과 세계 탭을 처음부터 다시 탐색
- 네 번의 영업 종료
- 네 번의 세계 시간 진행 연출
- 고객마다 같은 판매 규칙 설명 반복
- 결과마다 동일한 장시간 도입 연출 반복
- 장비 연대기 전체 본문을 강제로 네 번 읽게 함

다음은 제거하지 않는다.

- 고객별 요구·선호·야망 비교
- 고객별 장비 배정과 판매 확정
- 고객별 최소 하나의 실제 후속 선택
- 고객별 독립 결과와 장비 운명
- 고객별 관계·수식어·연대기 변화
- 고객별 다음 행동 방향

## 실패·중단·복귀 처리

| 중단 시점 | 복귀 처리 |
|---|---|
| 장비 준비 확정 전 | 해당 행동 미실행, 이전 저장 상태 유지 |
| 고객 판매 저장 후 | 판매와 소유권 유지, 다음 미완료 고객부터 진행 |
| 후속 준비 저장 후 | 비용·준비 상태 유지, 재실행 금지 |
| 영업 종료 판정 전 | 세계 시간 미진행 |
| 네 결과 체크포인트 저장 후 | 동일 네 결과 요약부터 복귀 |
| 결과 카드 확인 도중 | 확인 위치 복원 가능, 결과 중복 적용 금지 |

한 고객의 오류 때문에 다른 고객의 이미 저장된 판매나 준비 선택을 임의로 롤백하지 않는다. 다만 영업 종료 후 네 결과 체크포인트는 전체 무결성을 만족해야 다음 날로 진행한다.

## UI·접근성 계약

- 네 장비와 네 고객의 준비 상태는 목록과 상태 아이콘으로 확인한다.
- 색상만으로 준비 완료·미완료·오류를 구분하지 않는다.
- 텍스트 확대 상태에서도 고객명, 기한, 비용, 위험과 완료 상태가 겹치지 않아야 한다.
- 결과 카드 순서를 화면 읽기로 탐색할 수 있어야 한다.
- 일반 결과 카드가 강화 입력이나 비가역 확인을 강제로 중단시키지 않는다.
- 모션 감소에서는 병렬 세계 진행의 전환·파티클을 축소하고 동일 결과 문구를 유지한다.
- 불씨 정령은 단계 전환을 보조할 수 있지만 네 고객 상태의 권위 있는 정보원은 아니다.

## 성능 계약

- 네 장비 목록과 네 고객 비교 화면에서 불필요한 장식 자산을 동시에 상주시켜 메모리를 누적하지 않는다.
- 결과 카드 자산은 필요한 순서에 맞춰 로드하고 사용 후 정리할 수 있다.
- 병렬 판정은 결과를 네 번 렌더링하는 의미가 아니며, 저장 무결성이 연출보다 우선한다.
- 저사양 기준 기기에서도 네 결과 요약과 상세 진입이 가능해야 한다.
- 성능 저하 시 배경·보조 파티클·전환 효과부터 축소하고 결과 문구·장비 상태·보상·기한은 유지한다.

## 플레이테스트 검증 항목

- 네 장비 준비가 목표 6~7분 안에 가능한지
- 장비 준비 목록에서 현재 해야 할 행동을 이해하는지
- 네 고객의 요구·선호·야망을 4~5분 안에 비교할 수 있는지
- 장비 배정 충돌과 판매 완료 소유권을 오해하지 않는지
- 네 후속 준비를 4~5분 안에 선택할 수 있는지
- 영업 종료 전 미완료 항목을 정확히 찾을 수 있는지
- 네 사건이 한 세계 진행에서 정확히 1회씩 판정되는지
- 결과 카드 네 개를 4~5분 안에 이해할 수 있는지
- 상세 연대기를 강제로 열지 않아도 다음 행동을 아는지
- 비유도 완료 세션 중앙값이 15~25분인지
- 검투사·모험가·수집가·병사 중 한 고객이 설명 카드 수준으로 축소되지 않았는지
- 앱 중단 후 동일 네 결과와 확인 위치로 복귀하는지
