## 결정 — 현재 검증 상한 +50, 최종 강화 상한은 후속 검증

사용자 승인:

- `권장안대로 진행`

### 확정 내용

1. 현재 기획·데모·행동 검증에서 실제 선택한 작품이 진행하는 강화 상한은 `+50`이다.
2. 정밀강화와 작품 정체성 이정표는 매 `+10` 단계마다 발생한다.
3. `+50`은 현재 검증 범위의 끝이며 장기 제품의 영구 최종 상한을 뜻하지 않는다.
4. 기존 문서의 `+100 제품 목표`는 확정 상한이 아니라 `Prototype 구현 사실 / DEFERRED TEST_TARGET`으로 재분류한다.
5. `+60`, `+70`, `+100` 등 후속 확장은 사람 플레이에서 강화 반복의 재미, 세션 길이, 성장 속도, 위험 피로도와 콘텐츠 생산 비용을 검증한 뒤 결정한다.
6. 최종 상한 확정 전에는 `+100`을 전제로 한 콘텐츠 수량, 경제 밸런스, 업적, 엔드게임과 UI 범위를 필수 요구사항으로 만들지 않는다.
7. 후속 검증에서 `+50` 이후의 반복이 새로운 판단 없이 수치만 늘린다면 상한을 늘리지 않는다.
8. 후속 구간이 새로운 재료·정밀 선택·위험·작품 생애 목표를 제공하고 장기 재미를 강화한다는 행동 증거가 있을 때만 확장한다.
9. 상한을 확장하더라도 프로젝트 코어 불변은 `매 +10 이정표`, `공개된 위험`, `멈춤·추가 도전 판단`, `작품 생애 환류`이며 특정 숫자 자체가 아니다.
10. 기존 Prototype에서 `+100`까지 동작하는 구현이 존재하더라도 이는 현재 구현 사실이며 최신 제품 기획의 확정 상한을 의미하지 않는다.

### 정본 우선순위

본 결정은 다음 과거 표현보다 우선한다.

- `BLACKSMITH_GAME_BIBLE.md`의 `정확한 +100은 현재 구현·제품 목표` 중 `제품 목표` 부분
- 과거 Roadmap·POC 문서의 `+100`을 장기 확정 목표처럼 해석할 수 있는 표현
- `+50`을 영구 최종 상한으로 해석하는 표현

정리 후 표준 문구:

> 현재 검증 상한은 `+50`이며, 정밀 이정표는 매 `+10`마다 발생한다. 장기 최종 강화 상한은 사람 플레이와 성장 속도 검증 이후 결정한다. 기존 `+100` 구현은 Prototype 사실이자 후속 테스트 후보이지 확정 제품 상한이 아니다.

### 검증 질문

최종 상한은 아래 행동 증거를 기준으로 후속 승인한다.

- 플레이어가 `+40→+50` 과정에서 반복이 아니라 새로운 판단을 경험하는가.
- `+50` 달성 후에도 같은 작품을 계속 강화하고 싶은 구체적 이유가 있는가.
- 추가 `+10` 구간마다 새로운 작품 정체성·위험·생애 목표가 생기는가.
- 목표 달성 시간이 지나치게 길어 작품 납품과 세계 환류를 미루게 하지 않는가.
- 높은 상한이 여러 작품 제작보다 한 작품 몰아주기를 압도하지 않는가.
- 장기 상한 확장이 콘텐츠 제작 비용에 비해 실제 재미를 늘리는가.
