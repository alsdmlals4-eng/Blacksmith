- `BS-HOF-20260802-02`의 `현재 상태`는 작품의 실시간 현재 상태를 뜻하지 않는다.
- 명예의 전당에 표시되는 변동 상태는 플레이어가 현실 일일 등록권을 사용해 제출했고 자격·개선 검증과 원자 저장에 성공한 `최고 자격 스냅샷`이다.
- 최초 입성 스냅샷은 역사 기록으로 영구 보존한다.
- 이후 갱신은 최초 입성 스냅샷 및 기존 최고 자격 스냅샷과 비교해 더 높은 기록일 때만 반영한다.

### 확정 내용

1. 명예의 전당은 작품별로 `최초 입성 스냅샷`과 `최고 자격 스냅샷`을 구분해 보관한다.
2. 최초 등록 시 두 스냅샷은 동일한 제출 상태로 생성된다.
3. 최초 입성 스냅샷은 작품이 어떤 상태로 처음 명예의 전당에 들어왔는지 보여주는 역사 기록이며 이후 갱신으로 덮어쓰지 않는다.
4. 최고 자격 스냅샷은 최초 입성 이후 성공한 갱신 후보 중 기존 기록보다 높은 상태만 반영한다.
5. 작품이 손상·대파·강화 하락·수식어 잠금 등으로 실제 게임 안에서 약화돼도 명예의 전당 기록은 자동으로 낮아지지 않는다.
6. 약화된 실제 상태는 자동·실시간 동기화하지 않는다.
7. 갱신 후보가 `BS-HOF-20260802-05`의 현재 등록 자격을 충족하지 못하면 갱신 요청을 성공시킬 수 없고 명예의 전당 기록도 변경되지 않는다.
8. 갱신 후보가 등록 자격은 충족하지만 기존 최고 자격 스냅샷보다 낮거나 같으면 `기록 개선 없음`으로 처리하고 최고 기록을 유지한다.
9. `기록 개선 없음`은 성공한 갱신이 아니므로 `BS-HOF-20260802-04`에 따라 현실 일일 등록권을 소모하지 않는다.
10. 갱신 후보가 현재 등록 자격을 충족하고 기존 최고 기록보다 높을 때만 스냅샷 저장과 현실 일일 사용 기록을 하나의 원자적 성공으로 커밋한다.
11. 최고 자격 스냅샷이 갱신돼도 최초 입성 스냅샷, 최초 입성 시각과 최초 입성 근거 연대기는 유지한다.
12. 작품의 손상·복원·계승·추가 사건은 일반 작품 생애와 연대기에 계속 기록되지만, 명예의 전당 최고 상태는 성공한 개선 갱신 전까지 바뀌지 않는다.
13. 작품이 복원·재강화되어 과거 최고 기록을 넘어선 경우 다음 KST 일일 등록권을 사용해 개선 갱신을 제출할 수 있다.
14. 명예의 전당 화면은 `최초 입성 기록`, `최고 기록`, `최고 기록 반영 시각`을 구분해 표시한다.
15. 실제 작품의 현재 상태와 최고 기록이 다를 수 있음을 숨기지 않으며, 최고 기록은 `마지막으로 검증·제출된 최고 상태`라고 명시한다.
