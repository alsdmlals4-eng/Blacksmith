## 모바일 강화 화면 구조

모바일 강화 화면은 **고정 강화 작업대 + 상황별 하단 패널** 구조를 사용한다.

반복 강화 중에는 현재 장비, 위험 정보, 비용과 강화 버튼의 위치를 유지한다. 상세 확률, 보호 비교, 정밀강화 결과, 고위 정밀강화 진화 후보와 고위험 최종 확인만 필요할 때 하단 패널로 확장한다.

```text
상단
- 현재 장비
- 현재 강화 단계와 목표 단계
- 장비 가치·주요 수식어

중앙
- 장비 외형
- 강화 연출
- 성공·실패·하락·파괴 결과 피드백

하단 고정 작업 영역
- 성공률 또는 확정 성공
- 총비용·소비 재료
- 최대 하락·영구 파괴 여부
- 보호 상태
- 강화 실행 버튼

상황별 하단 패널
- 전체 결과 확률
- 보호 전후 비교
- 정밀강화 결과 설명
- 고위 정밀강화 진화 후보 비교
- 고위험 최종 확인
```

## 고정 작업대 원칙

- 장비를 강화할 때마다 별도 전체 화면으로 반복 이동하지 않는다.
- 강화 결과가 나와도 작업대 맥락과 장비 선택은 유지한다.
- 성공률, 비용, 보호 상태와 강화 버튼은 반복 강화 중 계속 같은 작업 영역에 둔다.
- 저위험 강화는 패널을 열지 않고 즉시 판정한다.
- 위험 조건이 발생하면 작업대 위에 새 전체 화면을 덮지 않고 하단 패널을 연다.
- 패널을 닫으면 같은 장비와 강화 상태로 즉시 돌아온다.

## 하단 패널 종류

### 상세 확률 패널

- 성공, 유지, 단계별 하락, 영구 파괴의 정확한 확률을 표시한다.
- 숨겨진 실패 결과를 두지 않는다.

### 보호 비교 패널

- 보호 전후의 성공률, 비용, 단계 하락, 영구 파괴 여부를 나란히 비교한다.
- 보호는 영구 파괴만 방지한다는 점을 강조한다.

### 일반 정밀강화 패널

- 현재 시도가 10단위 진입 강화임을 표시한다.
- 성공 시 단계 상승과 정밀강화 결과가 동시에 적용됨을 보여준다.
- 실패 시 현재 강화 구간의 일반 위험이 적용됨을 보여준다.

### 고위 정밀강화 패널

- `+49 → +50` 확정 성공을 표시한다.
- 진화 후보 2~3개의 형태, 대표 특수 수식어, 적합도와 비용을 비교한다.
- 후보 선택 전에는 실행할 수 없다.
- 실패 확률 대신 높은 비용과 남은 운영 자원을 비교한다.

### 고위험 확인 패널

- 성공률 또는 확정 성공
- 총비용과 소비 재료
- 실패 시 최대 하락
- 영구 파괴 여부
- 보호 상태
- 실행 후 남는 운영 자금
- 영향을 받는 활성 약속·고객 지원 계획

추상적인 확인 문장만 표시하지 않고 실제 손실과 자원 영향을 보여준다.

## 화면 전환 원칙

- 강화 작업대는 세션의 주 화면이다.
- 재료 상점과 장비 선택은 작업대로 빠르게 복귀할 수 있는 짧은 보조 흐름으로 둔다.
- 세계 게시판, 구독 소식, 고객·사건 화면은 별도 주요 화면이지만 복귀 시 강화 작업대 상태를 보존한다.
- 하단 패널은 한 번에 하나만 연다.
- 패널 안에서 또 다른 전체 화면이나 다중 중첩 패널을 만들지 않는다.
- Android 세로형 화면에서 한 손 조작과 핵심 정보 가독성을 우선한다.

## 고위험 강화 최종 입력

강화 실행 입력은 위험의 비가역성에 따라 분리한다. 모든 위험 행동에 같은 확인 방식을 강제하지 않는다.

| 상황 | 기본 입력 |
|---|---|
| 저위험 일반 강화 | 즉시 실행 |
| 일반 정밀강화 | 정보 확인 후 확인 버튼 1회 |
| 보호 사용·해제 | 변경 내용 확인 후 확인 버튼 1회 |
| 운영 안전 자금 또는 활성 약속 자원 침범 | 영향 확인 후 확인 버튼 1회 |
| 비보호 영구 파괴 가능 강화 | 길게 누르기 |
| 특수재료를 소비하는 고위 정밀강화 | 길게 누르기 |
| 잠금 장비 강화 | 잠금 해제 후 길게 누르기 |

### 확인 버튼 대상

다음은 위험 정보와 선택 결과를 확인한 뒤 명시적 버튼 입력 한 번으로 실행한다.

- 일반 정밀강화
- 보호 사용 또는 보호 해제
- 운영 안전 자금 기준 아래로 내려가는 강화
- 활성 약속·고객 지원 계획에 필요한 자원을 침범하는 강화

이 경우에도 단순한 `진행하시겠습니까?` 문구만 사용하지 않는다. 단계 하락, 비용, 파괴 여부와 영향을 받는 약속을 실제 값으로 표시한다.

### 길게 누르기 대상

다음은 되돌릴 수 없는 장비·희귀 자원 손실을 포함하므로 길게 눌러 실행한다.

- 보호하지 않은 영구 파괴 가능 강화
- 특수재료와 고액 보조 재료를 소비하는 `+49 → +50` 고위 정밀강화
- 잠금 상태였던 장비를 잠금 해제한 직후 수행하는 고위험 강화

```text
위험 정보 확인
→ 실행 영역 길게 누르기
→ 진행도 표시
├─ 완료 전 손을 뗌: 취소, 자원 미소비
└─ 진행도 완료: 강화 1회 판정 또는 고위 정밀강화 확정 실행
```

- 누르고 있는 동안 진행도를 시각적으로 표시한다.
- 완료 전에 손을 떼면 즉시 취소하며 재료와 자금을 소비하지 않는다.
- 길게 누르기 완료 직후에만 자원 소비와 강화 판정을 확정한다.
- 고위 정밀강화에서는 진화 후보 선택이 완료되지 않으면 길게 누르기를 시작할 수 없다.

### 접근성 대체 입력

길게 누르기가 어려운 사용자는 접근성 설정에서 `2단계 확인 버튼`으로 대체할 수 있다.

```text
1단계: 위험·비용 확인
→ [다음]
2단계: 손실 요약 재확인
→ [강화 실행]
```

- 대체 입력은 길게 누르기와 동일한 위험 정보와 결과를 제공한다.
- 접근성 대체를 사용해도 성공률, 비용 또는 결과가 달라지지 않는다.
- 설정 변경은 플레이 도중 가능하며 특정 장비나 강화 결과에 불이익을 주지 않는다.
