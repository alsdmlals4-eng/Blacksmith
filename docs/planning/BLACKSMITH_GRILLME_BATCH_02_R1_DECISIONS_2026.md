```text
→ 수집가 방문의 제한 목록에 등장
  ├─ 구매
  │  → REACQUIRED
  │  → 기존 생애 유지
  └─ 보류
     → COLLECTOR_HELD 유지
     → 순환 대기
     → 관련 인물·지역·사건 맥락 또는 재등장 보장에 따라 다시 등장
```

### 보호 조건

- 한 번 구매하지 않았다는 이유만으로 작품을 영구 소실시키지 않는다.
- 모든 미구매 작품을 영구 고정 목록에 쌓아 수집가를 상시 상점으로 만들지 않는다.
- `지금 사지 않으면 영원히 잃는다`는 허위 긴급성과 과도한 FOMO를 만들지 않는다.
- 보류할 때마다 가격이 자동으로 상승하거나 재등장 확률이 악화되는 처벌 규칙을 기본값으로 두지 않는다.
- 명시적인 별도 생애 사건에 따른 파괴·분실과 단순 미구매를 같은 영구 소실로 취급하지 않는다.
- 관련 사건 가중치만 의존하여 오래된 작품이 사실상 영구 봉인되지 않게 한다.
- 수집가 목록을 확인하는 행동이 강화보다 우선하는 필수 순회·파밍 루프가 되지 않게 한다.

### 후속 상세화

- R3: `COLLECTOR_HELD`, 순환 대기, 제시 중, `REACQUIRED` 상태와 중복 방지 키
- R4: 수집가 방문 목록 구성, 맥락 태그 가중치, 미구매 작품 재큐잉 파이프라인
- R5: 재등장 보장 주기, 가격 유지·변동 규칙, 목록 독점과 FOMO 방지
- R6: 구매 전 생애 요약, 보유 중임을 알리는 추적 UI, 재등장 안내 강도
- R7: 미구매 후 영구 소실로 오해하지 않는지와 수집가 방문 부담 검증
