## `BS-DEMO-20260802-01` — 10강 정밀강화와 +50 데모 진행

- 승인 시각: `2026-08-02 17:21 KST`
- 상태: `CONFIRMED_BY_LATEST_USER_DIRECTION / APPROVED_SYSTEM_DIRECTION`
- 사용자 근거:
  - `우리 정밀강화 는 +10 마다 아냐?`
  - `+5 는 무슨 기준이야?`
  - `+50 까지는 데모에서 진행해도 좋을거같아.`

### 확정 내용

1. 정밀강화는 모든 10강 이정표에서 한 번 발생한다.
2. 데모의 정밀강화 이정표는 `+10`, `+20`, `+30`, `+40`, `+50`이다.
3. `+5`는 정밀강화 이정표가 아니다.
4. 과거 `+5 납품 / +10 도전` 자료의 `+5`는 납품 가능한 완성품으로 멈출지 +10에 도전할지 관찰하기 위한 사람 검증용 선택 지점이다.
5. 해당 과거 연구 지점을 R1 코어 규칙이나 정밀강화 기준으로 승격하지 않는다.
6. 데모에서는 준비된 `+49` 장비의 단일 타격만 보여주는 대신, 플레이어가 선택한 작품을 실제 데모 흐름 안에서 계속 강화하여 `+50`까지 진행할 수 있다.
7. `+10`마다 정밀강화 행동 1개를 선택하고 결과를 확정한 뒤 다음 강화 구간을 개방한다.
8. 각 이정표에서의 선택·성공·실패는 장비 이력과 데모 결과에 남는다.
9. 데모 자원량, 세션 길이, 강화 속도와 위험 곡선은 `RECOMMENDED_DEFAULT / TEST_VALUE`이며, +50 도달을 위해 정밀강화 이정표나 핵심 위험 판단을 생략하지 않는다.
10. 데모 +50 도달은 출시 본편의 자연 성장 속도를 확정하지 않는다.

### 정본 근거

### 보호 조건

- `+5`를 수식어 추가·등급 결정·정밀강화 이정표로 문서화하지 않는다.
- 데모가 +50에 도달하더라도 +10 단위 정밀강화 선택을 자동 처리하지 않는다.
- 데모 가속을 위해 무한 자원·무위험 성공만 제공하여 강화 판단을 제거하지 않는다.

- 특정 작품을 시스템적으로 `대표 장비`나 `보조 작품`으로 분류하지 않는다.

## `BS-LIFE-20260802-01` — 방문 고객 납품 이후에만 작품 생애 활성화

- 승인 시각: `2026-08-02 17:29 KST`
- 상태: `CONFIRMED_BY_LATEST_USER_DIRECTION / APPROVED_CORE_BOUNDARY`
- 사용자 근거:
  - `대표장비,보조 작품 같은 구분은 없어 그냥 강화만 계속 진행하면 돼.`
  - `[방문 고객]에게 납품을 진행한 경우에만 이후 해당 작품의 [생애]를 유지하면서 강화 코어를 지원하게 되는거야.`

### 확정 내용

1. 모든 작품은 동일한 기본 강화 대상이며 `대표 장비`, `보조 작품`, `자원 조달용 작품` 같은 시스템 등급을 부여하지 않는다.
2. 플레이어는 소유 중인 원하는 작품을 계속 강화할 수 있다.
3. 제작·강화 기록 자체는 작품의 내부 이력으로 보존할 수 있지만, 그것만으로 고객·세계와 연결된 `[생애]`가 활성화되지는 않는다.
4. 작품의 고객·세계 생애는 `[방문 고객]`에게 실제 납품이 완료된 시점에 시작한다.
5. 납품 이후에는 해당 작품의 소유자, 사용 목적, 사건 기여, 성공·실패, 손실·복원, 재방문, 계승과 후속 의뢰를 같은 UID에 연결해 유지한다.
6. 방문 고객의 재방문이나 후속 요청은 이미 납품된 작품의 상태·역사·필요를 다시 강화 코어로 환류시킨다.
7. 강화 코어를 지원하는 생애 환류는 `강화에 필요한 이유와 맥락`을 제공해야 하며, 강화보다 별도의 고객 관리·직원 경영·직접 전투가 우선하는 구조가 되어서는 안 된다.
8. 방문 고객에게 납품하지 않은 재고·시장 판매·소모성 작품까지 동일한 장기 생애 추적을 강제하지 않는다.
9. 세계 일정용 사건 연대기 세트는 실제 납품·사용·기여가 확인된 작품에만 별도 규칙으로 성립하며, 단순 보유나 강화만으로 생기지 않는다.
10. 고객 재방문 주기, 작품 반환 방식, 재강화 가능 조건과 보상은 `RECOMMENDED_DEFAULT / TEST_VALUE`로 남긴다.

### 핵심 흐름

```text
작품 제작
→ 원하는 만큼 강화
→ 방문 고객에게 납품
→ 작품 생애 활성화
→ 고객 사용·사건·결과 기록
→ 재방문·복원·추가 강화·후속 의뢰
→ 강화 코어로 동기 환류
```

### 보호 조건

- 작품을 사전에 `대표/보조` 계층으로 분류하지 않는다.
- 납품 전 모든 작품에 장기 고객·세계 시뮬레이션을 강제하지 않는다.
- 일반 시장 판매와 방문 고객 납품의 생애 계약을 같은 것으로 취급하지 않는다.
- 생애 시스템이 강화보다 더 긴 필수 대화·관리·직접 전투 루프로 확장되지 않게 한다.
- 고객 납품 이후에도 작품 UID·제작 완성도·정밀 등급·수식어·강화 이력·사건 연대기를 유지한다.
