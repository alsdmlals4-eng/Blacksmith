  - `+50 까지는 데모에서 진행해도 좋을거같아.`

### 확정 내용

1. 정밀강화는 모든 10강 이정표에서 한 번 발생한다.
2. 데모의 정밀강화 이정표는 `+10`, `+20`, `+30`, `+40`, `+50`이다.
3. `+5`는 정밀강화 이정표가 아니다.
4. 과거 `+5 납품 / +10 도전` 자료의 `+5`는 납품 가능한 완성품으로 멈출지 +10에 도전할지 관찰하기 위한 사람 검증용 선택 지점이다.
5. 해당 과거 연구 지점을 R1 코어 규칙이나 정밀강화 기준으로 승격하지 않는다.
6. 데모에서는 준비된 `+49` 장비의 단일 타격만 보여주는 대신, 플레이어가 사용하는 대표 장비를 실제 데모 흐름 안에서 `+50`까지 진행할 수 있다.
7. `+10`마다 정밀강화 행동 1개를 선택하고 결과를 확정한 뒤 다음 강화 구간을 개방한다.
8. 각 이정표에서의 선택·성공·실패는 장비 이력과 데모 결과에 남는다.
9. 데모 자원량, 세션 길이, 강화 속도와 위험 곡선은 `RECOMMENDED_DEFAULT / TEST_VALUE`이며, +50 도달을 위해 정밀강화 이정표나 핵심 위험 판단을 생략하지 않는다.
10. 데모 +50 도달은 출시 본편의 자연 성장 속도를 확정하지 않는다.
