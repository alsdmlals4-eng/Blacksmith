# 블랙스미스 결정 원장 추가 기록 13

> 상태: `PLANNING_IN_PROGRESS`
>
> 기준일: 2026-07-26
>
> 주제: 보호석의 하락·파괴 방지, 보호 파괴 단계 하락, 회복석·DAMAGED 수리 폐기

## 1. 사용자 승인

사용자는 다음 구조를 승인했다.

- 보호석은 자연 결과 `1단계 하락`, `2단계 하락`, `파괴`를 모두 방어한다.
- 하락 1·2는 보호석 사용 시 `유지`가 된다.
- 파괴를 보호석으로 막으면 장비는 소멸하지 않지만 강화 단계가 대폭 하락한다.
- 보호된 장비는 별도 DAMAGED 상태가 되지 않으며 수리 없이 즉시 사용 가능하다.
- 보호석이 없는 상태에서 파괴가 나오면 장비는 즉시 영구 소멸한다.
- 회복석 시스템은 제거한다.
- 보호석은 등급을 나누지 않고 목표 강화 단계가 높을수록 소모 개수를 늘린다.

상태: `POC_TUNABLE / APPROVED_CURRENT`

## 2. 보호석 요구량

보호석은 목표 강화 단계를 기준으로 유효한 시도 시작 시 전량 소모한다.

| 목표 강화 단계 | 보호석 |
|---:|---:|
| +1~+10 | 사용 불가 |
| +11~+20 | 1개 |
| +21~+29 | 2개 |
| +30~+39 | 3개 |
| +40~+49 | 4개 |
| +50~+59 | 6개 |
| +60~+69 | 8개 |
| +70~+79 | 10개 |
| +80~+89 | 12개 |
| +90~+99 | 15개 |
| +100 | 18개 |

- 보호석에는 등급이 없다.
- 시도가 시작되면 결과와 관계없이 반환하지 않는다.
- 취소 또는 자원 부족으로 시도가 시작되지 않으면 소모하지 않는다.
- 요구량이 부족하면 무보호 도전 또는 장비 보관을 선택한다.

## 3. 결과 변환

| 자연 결과 | 보호석 미사용 | 보호석 사용 |
|---|---|---|
| 대성공 | 대성공 | 대성공 |
| 성공 | 성공 | 성공 |
| 유지 | 유지 | 유지 |
| 하락 1 | 1단계 하락 | 유지 |
| 하락 2 | 2단계 하락 | 유지 |
| 파괴 | 즉시 영구 소멸 | 보호 파괴 + 단계 하락 |

보호석은 성공률을 높이지 않는다.

## 4. 보호 파괴 단계 하락

하락량은 시도 목표가 아니라 시도 직전 현재 강화 단계를 기준으로 계산한다.

```text
보호 파괴 하락량
= MAX(3, FLOOR(시도 직전 현재 강화 단계 ÷ 10))
```

| 시도 직전 현재 단계 | 하락량 |
|---:|---:|
| +29~+39 | -3 |
| +40~+49 | -4 |
| +50~+59 | -5 |
| +60~+69 | -6 |
| +70~+79 | -7 |
| +80~+89 | -8 |
| +90~+99 | -9 |

사용자 예시:

```text
현재 +51
→ 파괴 판정
→ 보호석으로 소멸 방지
→ -5
→ 사용 가능한 +46
```

```text
현재 +60
→ 파괴 판정
→ 보호석으로 소멸 방지
→ -6
→ 사용 가능한 +54
```

추가 경계 예시:

```text
현재 +99에서 +100 시도
→ 파괴 판정
→ 보호석으로 소멸 방지
→ -9
→ 사용 가능한 +90
```

## 5. 제거된 시스템

다음은 `SUPERSEDED`다.

- 보호석이 파괴만 DAMAGED로 변환하는 규칙
- 지속형 `DAMAGED` 장비 상태
- DAMAGED 장비 수리
- 회복석 아이템
- 회복 가능 기록 3일
- 장비당 최신 회복 기록 1개
- 보관 중 회복 기한 정지
- 회복석으로 사용 가능 상태 또는 강화 단계 복원
- 보호석 등급 구분
- `RECOVERY_WINDOW` POC 시나리오
- `DAMAGED`, `RECOVERED` 장비 타임라인 이벤트

## 6. POC 시나리오 대체

- `PROTECTION_DAMAGE` → `PROTECTION_BREAK`
- `RECOVERY_WINDOW` → `UNPROTECTED_DESTROY`

`PROTECTION_BREAK`는 보호석 사용 파괴가 정해진 단계 하락 후 즉시 사용 가능한 장비를 남기는지 검증한다.

`UNPROTECTED_DESTROY`는 보호석 미사용 파괴가 복구·수리·보관 경로 없이 즉시 장비를 삭제하는지 검증한다.

## 7. 실패 완충 타격 경계

보호석이 영구 파괴 방지의 전용 수단이 되도록 다음을 적용한다.

- 실패 완충 타격은 파괴 결과를 막지 않는다.
- 실패 완충 타격은 2단계 하락을 1단계 하락으로 완화할 수 있다.
- 보호석과 함께 사용하면 완충 적용 후 남은 하락을 보호석이 유지로 바꾼다.
- 파괴는 보호석이 있을 때만 보호 파괴로 바뀐다.

정식 출시용 세부 전문화 상호작용은 `REVIEW_REQUIRED`다.

## 8. 경제·검증 영향

후속 시뮬레이션은 다음을 별도로 측정한다.

- 목표 단계별 보호석 총소모량
- 보호로 막은 하락 1·2 횟수
- 보호 파괴 횟수와 누적 단계 손실
- 무보호 즉시 영구 소멸 횟수
- 보호석 부족으로 장비를 보관하는 빈도
- 다른 장비 제작·판매 후 보호석을 다시 확보하는 빈도
- 고강화 루프의 중앙값·75·90·95 분위 비용

회복석 비용, DAMAGED 수리 비용, 회복 시간은 더 이상 계산하지 않는다.
