## 1. 사용자 승인

사용자는 다음을 확정했다.

- 일반 강화 최종 결과는 `대성공 / 성공 / 유지 / 하락 1 / 하락 2 / 파괴` 여섯 종류다.
- 대성공은 `+2` 상승이다.
- 목표 `+49`, `+50`, `+100` 강화 시도에는 대성공을 적용하지 않는다.
- 하락 확률은 이전 저하락안보다 높게 배치한다.
- 성장으로 총성공률을 높이고 하락·파괴 위험을 줄인다.
- 보호석은 파괴를 `DAMAGED`로 전환한다.
- 회복석과 보관은 `DAMAGED` 이후 재도전을 가능하게 해 장기 루프를 유지한다.
- 일반 강화에서 자연 3단계 이상 하락은 사용하지 않는다.

상태: `POC_TUNABLE / APPROVED_CURRENT`

## 3. 대성공 배치

| 목표 구간 | 총성공 중 대성공 비중 |
|---:|---:|
| +1~+20 | 10% |
| +21~+40 | 7% |
| +41~+48 | 5% |
| +49~+50 | 0% |
| +51~+80 | 3% |
| +81~+99 | 2% |
| +100 | 0% |

대성공은 총성공률 안에서 분리되며 성공 확률을 추가 생성하지 않는다. 정밀강화·한계 돌파 이정표는 건너뛰지 않는다.

## 4. 성장과 위험 완화

- 성공 보정 숙련: 제작 60% + 해당 장비 분야 40%
- 위험 보정 숙련: 강화 60% + 해당 장비 분야 40%
- 최대 총성공률 상대 증가: 50%
- 최대 하락 1·2 상대 감소: 각각 15%
- 최대 파괴율 상대 감소: 10%
- 감소한 위험 확률은 전부 유지로 이동
- 공통 대장장이 등급은 적용 가능한 숙련 구간 상한을 해금

## 5. 보호·회복 장기 루프

```text
제작·판매
→ 보호석·회복석 확보
→ 고강화 도전
→ 하락 시 재강화
→ 보호된 파괴 시 DAMAGED
→ 회복석 사용 또는 보관
→ 재강화
```

- 보호석은 유효 시도 시작 시 전량 소모하며 성공률·하락률을 개선하지 않는다.
- 무보호 파괴는 영구 파괴다.
- 보호된 파괴는 `DAMAGED`다.
- POC 회복 기록은 3일, 장비당 최신 기록 1개, 기본 보관 슬롯 1개다.
- 보관 중 회복 기한이 정지된다.
- 회복석은 사용 가능 상태를 확정 복구한다.
- 정식 회복 비용과 DAMAGED 단계 손실량은 후속 결정이다.

## 6. 대체 상태

다음은 `SUPERSEDED`다.

- 일반 강화 자연 3단계 이상 하락
- +51~+60에서 2~4단계 하락을 기본으로 보는 구형 POC 표
- 실패 내부 하락률을 75~93%까지 올리는 안
- 대성공이 +49·+50 이정표를 건너뛰는 해석
- 숙련 감소분을 다른 위험 결과로 이전하는 해석
