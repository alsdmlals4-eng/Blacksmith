# 블랙스미스 결정 원장 추가 기록 15

> 상태: `PLANNING_IN_PROGRESS`
>
> 기준일: 2026-07-26
>
> 사용자 결정: 권장안 승인

---

## 1. 승인 결정

`안정 타격` 전문화의 대체 역할을 다음과 같이 확정한다.

- 실패 완충 타격 사용 후 충전값을 `20`으로 남긴다.
- 일반 빌드는 기존대로 완충 사용 후 충전값 `0`이 된다.
- 잔존 충전 적용 뒤 해당 시도의 결과 충전 기여를 더한다.
- 충전 최대치는 `100`, 완충 활성 요구량도 `100`을 유지한다.
- 잔존 충전 `20`만으로 즉시 재사용할 수 없다.

수치 `20`은 `POC_TUNABLE / APPROVED_CURRENT`다.

---

## 2. 기획 의도

안정 타격은 결과를 한 번 더 강하게 방어하는 전문화가 아니라, 실패 완충을 다시 준비하는 시간을 줄이는 안정형 빌드다.

역할 분리:

| 전문화 | 역할 |
|---|---|
| 안정 타격 | 실패 완충 재사용 주기 단축 |
| 승부사의 망치 | 완충 미사용 성공 가치 보상 |
| 효율 제련 | 실패 재료 손실 완화 |

이 구조는 안정 타격이 보호석·숙련·효율 제련의 역할을 흡수하는 것을 방지한다.

---

## 3. 유지되는 위험 계약

안정 타격은 다음을 바꾸지 않는다.

- 성공률과 대성공률
- 자연 하락 1·2 확률
- 자연 파괴 확률
- 무보호 파괴의 즉시 영구 소멸
- 보호석 요구량과 소비
- 보호 파괴의 기본·완충 병용 단계 손실
- 실패 재료 반환

보호석만 영구 소멸을 막을 수 있다는 기존 최신 규칙을 유지한다.

---

## 4. 처리 순서

```text
완충 사용 가능 충전 100 확인
→ 유효 시도 시작
→ 충전 소비
→ 안정 타격이면 충전 20 설정
→ 자연 결과 및 완충·보호석 처리
→ 결과 충전 기여 추가
→ 최대 100 제한
```

예시:

```text
안정 타격으로 완충 사용
→ 잔존 충전 20
→ 매우 높은 위험 실패 기여 +45
→ 종료 충전 65
```

---

## 5. 충돌 해결

### `SUPERSEDED`

- 안정 타격의 추가 효과로 `하락 2 → 하락 1`을 적용하는 규칙
- 안정 타격 대체 효과 `REVIEW_REQUIRED`
- 대체 효과 승인 전 안정 타격 추가 보너스 없음

기본 실패 완충 자체의 하락 완화 효과는 유지한다. 폐기되는 것은 동일 효과를 전문화가 다시 제공하던 중복 규칙이다.
