- Parent: `BS-CORE-20260820-01`
- 상태: `ACTIVE_PLANNING_SCOPE_GUARD`

## 현재 추가하지 않음

- 직원/생산라인 경영을 메인화
- 직접 전투·직접 탐험
- 고객 RPG 육성
- 확률을 숨겨 긴장감을 만드는 설계
- 광고/과금 기반 실패 완화
- 강화 실패 뒤 긴 재료 노가다 강제
- 매 강화마다 복잡한 안전/표준/강행 메뉴
- 작품 UID·역사를 일반 실패로 삭제
- 정밀제작을 강화보다 긴 기본 행동으로 만들기
- 고객/세계 결과를 강화와 무관한 별도 콘텐츠로 만들기

## 보존하지만 재검토 가능

- 5단계 제작 등급
- 예술성
- GRADE/CATALYST/CHRONICLE 구조
- 고객 4능력·적성
- 기존 +10/+20/+30/+40/+50 이정표
- R3 D01~D09 콘텐츠

위 항목은 강화의 긴장·결과·다음 강화 이유를 강화할 때 유지하고, 그렇지 못하면 축소/재설계한다.
