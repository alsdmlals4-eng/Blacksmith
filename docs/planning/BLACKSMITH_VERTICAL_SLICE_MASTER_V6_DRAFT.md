## 1. 기획 목표와 핵심 가설

### 1.1 플레이어 약속

플레이어는 반복 강화에서 **더 밀어붙일지 멈출지** 결정하고, 자신이 만든 고강화 장비가 특정 인물과 세계 사건에서 실제로 사용되는 결과를 되돌려 받는다.

### 1.2 핵심 감정

| 시간축 | 목표 감정 |
|---|---|
| 강화 순간 | 손실 긴장, 더 올리고 싶은 욕심 |
| 판매·인계 | 누구에게 맡길지 고민하는 책임감 |
| 세계 사건 | 내가 만든 장비를 믿는 두 번째 욕심 |
| 결과 환류 | 장비에 대한 애착, 제작자로서의 자부심 |

핵심 감정 흐름은 다음과 같다.

```text
강화 긴장·욕심
→ 고강화 장비 완성
→ 특정 인물에게 인계
→ 세계에서 실제 사용
→ 결과와 흔적이 귀환
→ 애착·자부심
→ 다음 강화와 새로운 장비 생애
```

### 1.3 핵심 가설

1. 한 단계씩 반복하는 강화와 중단 판단이 세션의 주된 긴장과 욕심을 만든다.
2. 즉시 판매가보다 구매자의 적합성과 미래 사건을 비교하게 만들면 장비 인계가 의미 있는 선택이 된다.
3. 장비의 실제 사용 장면, 결과 분석, 연대기와 수식어 심화가 장기 애착과 제작자 자부심을 만든다.
4. 세계 사건을 직접 조작하지 않아도 사전 지원·배팅·장비 선택만으로 충분한 개입감이 생긴다.
5. 승리뿐 아니라 패배도 장비의 새로운 전설과 후속 목표로 연결되면 무작위 결과가 서사를 끊지 않는다.

### 1.4 CORE POC 상태

```text
CORE_POC: SKIPPED_BY_USER_DECISION
CORE_POC_RESULT: NOT_AVAILABLE
CORE_HYPOTHESIS_VALIDATION: EMBEDDED_IN_VERTICAL_SLICE
```

CORE POC는 통과한 것이 아니다. 핵심 가설을 버티컬 슬라이스에 직접 포함했으므로, 슬라이스 실패 시 코어 가설부터 재작업할 위험이 남는다.

## 2. 핵심 플레이 루프와 세계 시간

### 2.1 순간 반복 루프

강화가 메인 콘텐츠다. 제작 준비와 재료 구매는 강화에 진입하기 위한 짧은 지원 과정으로 제한한다.

```text
장비·재료 준비
→ 한 단계 강화
→ 결과 확인
→ 보호 여부·비용·현재 가치 재평가
→ 계속 강화 또는 중단
→ 판매·인계
```

- `+0`부터 `+100`까지 한 단계씩 진행한다.
- 1회 강화 입력은 1회 판정이다.
- 강화 중 가장 중요한 선택은 계속 시도할지, 보호할지, 현재 상태에서 판매할지다.
- 채광, 장시간 생산, 복잡한 재료 가공은 버티컬 슬라이스에 포함하지 않는다.
- 재료는 짧은 상점 상호작용으로 구매한다.

### 2.2 운영일 구조

세계 시간은 실시간이 아니라 **영업일·운영 단계 기반**이다.

```text
영업 전 준비
→ 가게 오픈
→ 강화·거래·지원 준비
→ 영업 종료
→ 세계 시간 1단계 진행
→ 세계 게시판·구독 소식 갱신
→ 중요 사건 진입
```

- 강화·판매·정보 확인 중에는 시간이 자동 진행되지 않는다.
- 플레이어가 영업 종료를 선택할 때 세계가 한 단계 진행한다.
- 버티컬 슬라이스는 여러 영업일을 압축해 15~25분 안에 보여준다.

### 2.3 중요 사건과 마감

- 중요 사건은 남은 영업일로 마감 시간을 표시한다.
- 마감 전에는 사건 처리 순서와 지원 수준을 자유롭게 선택한다.
- 마감 후에는 플레이어 개입 없이 사건이 자동 진행된다.
- 결과는 사라지지 않고 세계 게시판, 구독 소식, 장비 연대기에 기록된다.
- 검투사 배팅은 경기 시작 전에 닫힌다.
- 모험·전투·출정 지원은 출발 전에 닫힌다.
- 장비 영구 파괴 가능성이 있는 재난급 사건은 별도의 최종 경고와 마감을 제공한다.

### 2.4 동시 사건 처리

중요 사건 개입 횟수와 일일 지원 작업 슬롯은 제한하지 않는다.

실질 제약은 다음뿐이다.

- 보유 자금
- 재료와 소모품
- 제공 가능한 장비
- 각 사건의 마감

## 3. 강화·정밀강화·고위 정밀강화

### 3.1 일반 강화

- 전체 게임의 표시 상한은 `+100`이다.
- 한 단계씩 강화한다.
- 강화 성공 확률, 비용, 하락 폭과 파괴 확률의 정확한 값은 플레이테스트 조정 대상이다.
- 구형 `기본 활성 한계 +40`, `+60 POC`, 강화 포인트 공유형 한계 돌파는 현재 새 기획에 자동 승계하지 않는다.

### 3.2 보호와 비보호

#### 비보호 강화

- 비용 효율이 높다.
- 실패 시 재료 소모와 단계 하락이 가능하다.
- 고강화 구간에서는 장비가 영구 파괴될 수 있다.

#### 보호 강화

- 추가 비용이 들고 비보호보다 총비용 효율이 낮다.
- 영구 파괴만 방지한다.
- 실패 시 재료와 보호 수단이 소모될 수 있다.
- 단계 하락은 여전히 발생할 수 있다.
- 성공 확률을 보장하거나 실패를 무효화하지 않는다.

보호 여부는 위험과 비용의 선택이지 정답 버튼이 아니다. 한 번의 실패로 전체 저장 진행이 사실상 종료되는 경제 구조는 허용하지 않는다.

### 3.3 정밀강화

모든 `+10` 이정표에서 `[정밀강화]`가 발생한다.

- 정밀강화는 장비의 수치·수식어 계열을 개선한다.
- `+50`에서 특수재료를 사용하지 않아도 일반 정밀강화를 수행하고 `+51` 이상으로 진행할 수 있다.
- `+60`~`+100`의 대장간 정밀강화는 기본 성능과 수치만 높인다.
- `+60` 이후에는 대장간에서 장비 분류를 다시 변신시키거나 대표 특수 수식어를 추가 심화하지 않는다.
- 장비 판매 후 세계 업적으로 발생하는 수식어 심화는 대장간 정밀강화와 별도 체계다.

### 3.4 고위 정밀강화

`[고위 정밀강화]`는 `+50` 정밀강화 시점에 `[특수재료]`를 촉매로 선택했을 때만 발생한다.

```text
현재 장비
+ 기존 수식어
+ 선택한 특수재료
→ 계보에 맞는 진화 후보 2~3개
→ 후보 정보 사전 공개
→ 플레이어가 하나 선택
→ 진화와 대표 특수 수식어 확정
```

보장 항목:

- 장비 진화 자체
- 진화 후 대표 특수 수식어
- 기존 장비·수식어 정체성의 보존 또는 승격
- 장비 유형·이름·외형 변화 가능
- 고객과 세계 사건 적합도 변화

변동 항목:

- 세부 등급
- 부가 수치
- 보조 효과
- 정확한 세계 사건 성과

희귀 특수재료를 사용했는데 아무 변화도 없는 결과는 허용하지 않는다.

### 3.5 특수재료 획득

특수재료는 단일 공용 포인트 보상이 아니다.

- 수집가: 수집가 거래망에서 구매·교환
- 모험가: 탐험 성과에 따라 확률적으로 획득 가능
- 제한된 고가 상점 재고
- 특정 고객·세계 사건의 고유 보상

모험가의 특수재료 보상 확률은 장비 강화도, 적합도, 수식어, 업적 규모, 생환 등에 영향을 받는다. 정확한 가중치는 미정이다.

## 4. 방문 고객과 판매 구조

### 4.1 일반 판매와 특정 인계

- 일반 장비는 즉시 자원 확보를 위해 일반 판매할 수 있다.
- 고가·고강화 장비는 `[방문 고객]`을 통해 특정 인물에게 판매·인계한다.
- 방문 고객은 서로 다른 이름, 성격, 직업과 야망을 가진다.
- 한 명의 반복용 익명 고객으로 통합하지 않는다.

### 4.2 고객 요구의 세 층

| 층 | 역할 |
|---|---|
| 필수 조건 | 판매 가능한 최소 자격 |
| 선호 조건 | 장비 적합도, 만족도, 관계와 후속 사건 |
| 야망 목표 | 더 높은 강화로 열리는 성취 상한과 추가 위험 |

고객이 먼저 방문하고 요구가 표시된다. 플레이어는 보유 장비 중 후보를 골라 지금 판매하거나 더 강화할 수 있다.

### 4.3 +50 진화 장비의 구매자 비교

대표 +50 고위 정밀강화 장비에는 적합한 개인 구매자 2명을 동시에 제시한다.

정확히 공개:

- 즉시 구매 가격
- 필수·선호 조건 충족 여부
- 공식 보상

정성적으로 공개:

- 장비 적합도 등급
- 야망과 위험 방향
- 예정된 대표 활동
- 미래 가치의 성격

공개하지 않음:

- 정확한 사건 성공률
- 확정 업적
- 확정 수식어 심화
- 장기 결과 보장

선택은 높은 즉시 가격과 더 좋은 적합성·미래 이야기 사이의 의도적 절충이어야 한다. 선택하지 않은 고객은 세계에서 사라지지 않으며 다른 장비 구매나 재방문이 가능하다.

## 5. 고객 4종과 세계 환류

네 고객 유형은 모두 핵심 세계 콘텐츠다. 보상 테마만 다른 결과 카드로 축소하지 않는다.

### 5.1 수집가

```text
방문·거래 제안
→ 수집품 또는 장비 거래
→ 수집가 네트워크 변화
→ 특수재료 구매·교환
→ 전시·재판매·소유권 이력
```

버티컬 슬라이스에서 특수재료 획득 경로를 직접 제공한다.

### 5.2 모험가

```text
장비 인계
→ 탐험·유적·괴물 사건 예고
→ 사전 지원
→ 탐험 결과
→ 발견·생환·부상·장비 상태
→ 특수재료 가능 보상과 재방문
```

### 5.3 검투사

```text
장비 인계
→ 경기 일정
→ 지원 약속
→ 상대·규칙·상태 분석
→ 배팅
→ 자동 경기 관전
→ 승패·부상·장비 기여
→ 재방문·수식어 심화
```

버티컬 슬라이스의 대표 심화 고객이다.

### 5.4 군인

```text
장비·보급 인계
→ 전투·방어·원정
→ 군사력·영향력 변화
→ 사상자·전선 안정·시장 변화
→ 국가·세력의 후속 사건
```

- `[군사력]`: 전투·방어·원정 성과, 사상자, 전선 안정, 이후 난도에 영향
- `[영향력]`: 세력 태도, 상점 재고와 거래 조건, 방문 고객, 사건 선택지에 영향

## 6. 세계 게시판·구독·전용 사건 화면

### 6.1 세계 게시판

구독 여부와 무관하게 공개되는 세계 정보다.

- 투기장 일정과 대진
- 전선과 국가 군사력·영향력
- 탐험·유적 사건
- 수집가 거래와 시장 변화

### 6.2 전용 사건 화면

중요 사건은 결과 카드만 보여주지 않고 대표 상호작용 화면을 가진다.

- 검투사 경기 관전
- 국가·전선 지도
- 탐험 결과
- 수집가 거래

### 6.3 구독 소식

판매 직후 구매자 카드에서 다음을 제안한다.

- `[구독한다]`
- `[지금은 구독하지 않는다]`

구독하지 않아도 인물과 사건은 계속 진행된다. 이후 고객 명부에서 언제든 변경할 수 있다.

구독 소식은 다음을 제공한다.

- 구체적인 인물 활동
- 장비 사용
- 감정과 관계 변화
- 부상·승진·업적
- 지원 요청과 마감
- 재방문

구독 인원 수는 제한하지 않는다. 대신 메인 화면과 긴급 알림 우선 노출을 위한 `[관심 인물]` 슬롯은 제한한다. 정확한 슬롯 수는 미정이다. 관심 인물에서 제거하거나 구독을 해제해도 관계, 장비 이력, 기존 소식은 삭제하지 않는다.

## 7. 지원·약속·관계

### 7.1 세계 사건의 자율성

- 전투, 탐험, 전쟁은 자동 진행된다.
- 플레이어는 직접 전투·이동·전술 조작을 하지 않는다.
- 중요한 사건 전에 수리, 보조 장비, 소모품, 보급, 교체 장비를 제공할 수 있다.
- 지원은 확률과 결과 범위를 바꾸지만 결과를 보장하지 않는다.

### 7.2 지원 강도

| 수준 | 구성 | 역할 |
|---|---|---|
| 미지원 | 추가 제공 없음 | 자원 보존, 기본 조건으로 진행 |
| 제한 지원 | 사건이 요구한 기본 물품 | 중간 수준의 결과 개선 |
| 전면 지원 | 기본 물품 + 우수 장비·희귀재료·소모품 | 더 높은 결과 상한과 희귀 업적 가능성 |

사건별 기본 요청품과 추가 투자를 결합한다. 지원은 생환·승리, 장비 손상·분실, 업적 등급, 수식어 심화, 군사력·영향력, 재방문 보상에 영향을 줄 수 있으나 보장하지 않는다.

### 7.3 지원품의 소유권

- 소모품과 군수품: 사용되면 소모
- 기존 장비 수리: 원소유자에게 복귀
- 임시 대여 장비: 생환·회수 시 대장간으로 귀환, 손상·분실·전리품화 가능
- 새로 증여한 장비: 인물·조직으로 소유권 이전, 별도 연대기 시작

### 7.4 관계 성장

숨겨진 지출형 호감도 파밍을 사용하지 않는다.

관계가 성장하는 사건:

- 상황에 맞는 장비 판매
- 플레이어 장비를 사용한 세계 업적
- 중요 지원
- 수리와 회수
- 계승 장비 제작
- 약속 이행

관계가 열 수 있는 콘텐츠:

- 개인 의뢰
- 조기 정보
- 전용 지원·세계 사건
- 인물 소개
- 상속·계승 사건
- 특수 거래와 보상

한 번의 미지원, 구독 해제, 비활동으로 관계가 하락하지 않는다.

### 7.5 명시적 약속

지원 요청이 자동 의무가 되지 않는다.

요청 화면에서 표시:

- 인물과 사건
- 요청 물품
- 마감
- 위험
- 관계상의 의미

플레이어는 명시적으로 수락하거나 거절한다.

- 거절: 직접적인 관계 손상 없음
- 수락: 추적되는 약속 생성
- 기한 안에 약속한 지원 제공: 결과가 패배여도 약속 이행
- 기한까지 제공하지 않음: 약속 파기

약속 책임은 플레이어가 통제 가능한 제공 행위에만 적용한다. 전투 승패나 생존을 보장하는 계약이 아니다.

### 7.6 신뢰 손상과 회복

약속 파기는 즉시 관계 단계를 삭제하지 않고 `[신뢰 손상]`을 만든다.

- 일부 관계 성장과 전용 콘텐츠가 일시 중단될 수 있다.
- 사과, 보상, 후속 의뢰·사건을 통해 회복한다.
- 돈만 내고 즉시 초기화할 수 없다.
- 반복 파기와 고의적 배신은 관계 단계 하락과 콘텐츠 폐쇄로 이어질 수 있다.
- 파기와 회복은 연대기에 영구 기록한다.

버티컬 슬라이스는 약속 수락과 이행을 직접 플레이한다. 고의 파기, 장기 신뢰 손상, 회복 퀘스트 전체 루프는 결과와 존재만 안내하고 직접 플레이하지 않는다.

## 8. 장비 소유권·연대기·파괴·계승

### 8.1 장비의 지속 정보

장비는 다음을 보존한다.

- 강화 단계
- 기본 성능
- 수식어
- +50 진화 유형
- 제작자
- 역대 소유자
- 사용 사건과 업적
- 손상·분실·회수·상속 기록
- 역사·거래 가치

### 8.2 세계 사건 이후 장비 운명

| 사건 결과 | 장비 상태 |
|---|---|
| 생환·성공 | 기존 소유자 유지 |
| 부상·패배 | 손상 또는 수리 요청 |
| 분실 | 회수·수색 사건 |
| 소유자 사망 | 유품 귀환, 동료 상속, 전리품 |
| 역사적 성취 | 보물·유물·전설 장비 |
| 수집가 거래 | 소유자 변경과 가치·이력 누적 |

### 8.3 세계의 영구 파괴

일반 세계 사건은 장비를 즉시 영구 삭제하지 않는다. 손상, 분실, 상속, 전리품, 유물화로 다음 이야기를 만든다.

영구 파괴는 사전 공지된 재난급 사건에서만 가능하다.

- 위험과 마감 사전 공개
- 영구 파괴 가능성 명시
- 지원과 장비 적합도로 위험 범위에 영향
- 파괴되어도 연대기, 제작자, 소유자, 파괴 장소·사건 기록 보존
- 파편, 유물, 추모와 계승 가능

대장간 강화 파괴와 세계 사건 파괴는 별도의 위험 경로다.

### 8.4 수식어의 세계 심화

`+50` 고위 정밀강화는 장비의 대표 특수 수식어를 만든다. 이후 수식어의 전설적 심화는 특정 소유자가 실제 세계 업적을 달성했을 때 발생한다.

```text
대장간
→ 성능과 정체성 완성

세계
→ 업적과 전설 완성
```

심화된 수식어는:

- 관련 세계 사건 성과에 영향
- 희귀 사건·업적 개방
- 역사·거래 가치 상승
- 양도·재판매·회수 후에도 유지
- 강화 단계 자체는 변경하지 않음

### 8.5 파괴된 전설과 계승 장비

파괴된 전설 장비를 원상 복원하지 않는다.

```text
원본 장비 파괴
→ 파편·유물 회수
→ 원본 장비 유형 + 회수 파편 + 실제 업적
→ 계보에 맞는 후보 2~3개
→ 플레이어 선택
→ 새로운 계승 장비
```

- 원본은 파괴 상태로 영구 기록
- 계승 장비는 혈통 수식어를 자동 획득
- 원본이 실제로 얻은 업적 중 하나를 계승 특성으로 선택
- 얻지 않은 업적이나 모든 능력을 상속할 수 없음
- 강화 단계와 기본 수치를 완전 복구하지 않음
- 원본과 후계의 연대기를 연결
- 동일 장비 유형으로 제한하지 않지만 무관한 장비로 자유 변환하지 않음

## 9. 검투사 대표 심화 루프

### 9.1 대표 고객

+50 고위 정밀강화 장비의 대표 심화 구매자는 이름과 성격을 가진 개인 검투사다. 정확한 이름, 외형, 상대, 경기 규칙은 미정이다.

```text
+50 고위 정밀강화
→ 구매자 2명 비교
→ 검투사에게 판매
→ 구독 선택
→ 경기 예고
→ 지원 약속 수락·이행
→ 경기 분석·배팅
→ 자동 경기 관전
→ 결과 분석
→ 검투사 재방문
→ 수식어·관계·연대기 심화
```

### 9.2 경기 전 정보

정확히 공개:

- 공식 배당률
- 배팅액
- 적중 예상 수익
- 경기 규칙과 환경
- 확인된 부상·피로·최근 전적

정성적으로 공개:

- 종합 전망: 우세 / 접전 / 열세
- 양측 강점과 위험 요인
- 장비 적합도
- 수식어 상성
- 제작자가 알 수 있는 장비 특성

공개하지 않음:

- 실제 승리 확률
- 확정 승패
- 확정 업적과 손상 결과

공식 배당은 시장 평가일 뿐 실제 승리 확률과 같지 않다. 플레이어는 자신이 만든 장비에 대한 정보로 시장보다 나은 판단을 시도한다.

### 9.3 배팅

- 배팅은 별도 화폐가 아니라 대장간 일반 자금을 사용한다.
- 빚과 마이너스 배팅은 불가하다.
- 확정 전 배팅액, 예상 적중액, 경기 후 잔여 자금을 표시한다.
- 진행 중인 약속에 필요한 자원을 침해할 경우 경고한다.
- 배팅 손실을 자동 복구하거나 저장 이전으로 되돌리지 않는다.
- 배팅 성공은 다음 고강화를 앞당기고, 손실은 강화·지원 계획을 지연시킨다.

### 9.4 경기 관전

전체 실시간 전투 시뮬레이션이 아니라 결정적 장면을 연결한 짧은 자동 경기다.

```text
경기 시작
→ 초반 우세 판단
→ 위기·부상 장면
→ 강화·수식어·지원품의 결정적 작동
→ 최종 승부
→ 결과 분석
```

- 경기 중 직접 조작 없음
- 시작 후 지원·배팅 변경 불가
- 장비가 작동한 순간을 시각적으로 명확히 표시
- 경기 후 강화, 적합도, 수식어, 상태와 지원이 결과에 끼친 영향을 설명
- 동일한 승패라도 부상, 장비 손상, 업적 등급은 달라질 수 있음

### 9.5 실제 승패와 완결 분기

승패는 장비, 지원, 상성, 검투사 상태와 실제 확률 판정으로 결정한다. 승리를 고정하지 않는다.

#### 승리 방향

- 경기 승리와 배팅 적중 가능
- 우승·챔피언 계열 업적
- 공격적·정복 계열 수식어 심화
- 상위 투기장 도전

#### 패배 방향

- 배팅 손실 가능
- 부상과 장비 손상 가능
- 장비가 생존이나 분투에 기여한 업적
- 생환·수호 계열 수식어 심화
- 수리 의뢰와 재도전

두 분기 모두 다음을 제공한다.

- 장비의 결정적 기여 장면
- 결과 분석
- 검투사 재방문
- 장비 연대기와 관계 변화
- 다음 야망 또는 후속 의뢰

### 9.6 슬라이스 마지막 장면

```text
경기 결과·배팅 정산
→ 세계 시간 진행
→ 검투사 재방문
→ 사용 흔적이 남은 장비 확인
→ 세계 업적으로 수식어 심화
→ 관계와 장비 연대기 갱신
→ 다음 야망·후속 의뢰 제시
```

마지막 화면은 제작 당시와 현재 장비, 결정적 사용 장면, 새 수식어, 소유자와 업적, 관계 변화, 세계 게시판 결과를 함께 보여준다.

## 10. 경제와 진행 불능 방지

### 10.1 공용 운영 자금

```text
대장간 일반 자금
├─ 재료 구매
├─ 강화·보호
├─ 고객 지원
└─ 검투사 배팅
```

자금 분리를 통해 위험을 무효화하지 않는다. 대신 한 번의 과욕이 저장 진행을 영구 종료시키지 않도록 최소 재기 경로를 둔다.

### 10.2 의뢰인 재료 지급형 재기 의뢰

자금과 판매 가능한 재고가 기준 아래로 내려가면 선불 비용 없는 기초 의뢰가 열린다.

```text
운영 자금 고갈
→ 의뢰인이 재료 제공
→ 기초 수리·가공·제작
→ 소액 보수
→ 기본 재료 구매
→ 정상 운영 복귀
```

- 플레이어 재료비 없음
- 강화 실패·영구 파괴 위험 없음
- 대장간 작업은 직접 수행
- 보상은 정상 운영 복귀 수준으로 제한
- 특수재료, 전설 수식어, 핵심 관계 보상 없음
- 정상 운영 가능 수준에 도달하면 닫힘
- 정확한 발동 기준과 보수는 미정

## 11. 버티컬 슬라이스 전체 진행표

### 11.1 목표 시간

- 목표 플레이 시간: 15~25분
- 시작 1분 안에 첫 강화
- 여러 운영일을 압축
- 준비된 장비 상태로 시스템 범위를 압축

### 11.2 대표 흐름

```text
1. 준비된 +0 장비로 +10까지 안전 학습
2. 상점에서 기본 재료 구매
3. 수집가 실제 거래로 특수재료 획득
4. 준비된 +49 고객 후보 장비 확인
5. +50 정밀강화에서 특수재료 사용
6. 고위 정밀강화 후보 2~3개 비교·선택
7. 적합 구매자 2명 비교
8. 개인 검투사에게 판매
9. 판매 직후 구독 선택
10. 운영일 종료와 세계 소식 갱신
11. 검투사의 지원 요청 확인
12. 약속을 명시적으로 수락하고 기한 안에 이행
13. 상대·상태·장비·공식 배당 분석
14. 일반 자금으로 배팅
15. 결정적 장면 중심 자동 경기 관전
16. 승리 또는 패배의 실제 결과와 장비 기여 분석
17. 모험가·군인·수집가의 대표 사건과 결과 환류 확인
18. 검투사 재방문
19. 수식어·관계·장비 연대기 심화
20. 다음 야망과 더 큰 세계 가능성을 제시하고 종료
```

### 11.3 네 고객의 깊이

- 검투사: 메인 심화 루프
- 수집가: 실제 거래와 특수재료 획득
- 모험가: 실제 탐험 지원·결과
- 군인: 실제 보급 판단과 군사력·영향력 결과

세 유형을 텍스트 티저나 단일 결과 카드로 대체하지 않는다. 다만 준비된 장비와 압축 사건을 사용해 시간을 통제한다.

### 11.4 약속 데모 범위

직접 플레이:

- 요청 확인
- 수락 또는 거절
- 수락 시 약속 추적
- 기한 안 지원 제공
- 이행 기록
- 관계·전용 소식·후속 사건 개방

안내만 제공:

- 고의 파기
- 장기 신뢰 손상
- 사과·보상·회복 전체 루프
- 반복 파기와 배신의 최종 페널티

## 12. 무작위 플레이테스트 운영

### 12.1 무작위성 원칙

사용자 결정에 따라 처음부터 모든 판정을 실제 확률로 진행한다.

- 고정 시드 기준 시나리오 없음
- 주요 결과 강제 없음
- 실패 후 원하는 결과가 나올 때까지 즉시 재판정하지 않음
- 세션마다 강화, 경기, 부상, 장비 상태와 경제 결과가 달라질 수 있음

### 12.2 누적 분기 커버리지

개별 세션 결과는 그대로 기록한다. 전체 표본에서 필수 분기가 확인될 때까지 신규 테스터 또는 신규 세션을 추가한다.

누적 확인 대상:

- 검투사 승리와 패배
- 배팅 성공과 손실
- 보호와 비보호 강화
- 단계 하락과 영구 파괴
- 미지원·제한 지원·전면 지원
- 장비 손상·수리·분실·회수
- 서로 다른 진화와 구매자 선택
- 고객 4종의 대표 세계 환류
- 자금 고갈과 재기 의뢰

### 12.3 필수 체험 체크포인트

핵심 경로에서 확인할 항목:

- 첫 1분 안 강화 시작
- 강화 지속·중단 판단
- +50 고위 정밀강화 후보 선택
- 구매자 2명 비교
- 판매 후 구독 판단
- 지원 약속 수락·이행
- 검투사 경기 분석·배팅·관전
- 장비 기여 확인
- 재방문에서 수식어와 연대기 확인
- 나머지 고객 3종의 대표 환류 확인

`개별 세션 필수`와 `누적 표본 필수`의 최종 구분은 감사 Finding `MUST_FIX-01`과 연결된다.

### 12.4 행동 지표

- 전체 완료 시간과 편차
- 강화 재시도·중단
- 보호 사용
- 구매자 선택 이유
- 지원 수준
- 배팅액과 잔여 운영 자금
- 게시판·구독·연대기 확인
- 결과 뒤 장비 상세 재확인
- 재기 의뢰 진입과 정상 운영 복귀

### 12.5 플레이어 질문

1. 강화 과정에서 더 시도하고 싶은 욕심과 손실 긴장을 느꼈는가?
2. 판매 가격 외에 장비를 누구에게 맡길지 고민했는가?
3. 경기 결과에서 직접 만든 장비의 기여를 이해했는가?
4. 패배해도 장비와 인물의 다음 이야기가 궁금한가?
5. 종료 시 해당 장비에 애착이나 제작자로서의 자부심을 느꼈는가?

## 13. 통과·차단·재작업 기준

### 13.1 핵심 차단 조건

다음 문제가 반복되면 평균 점수와 관계없이 통과할 수 없다.

- 첫 강화 진입이 늦거나 이해되지 않음
- 계속 강화할지 멈출지 고민하지 않음
- +50 진화 선택이 무의미함
- 구매자를 가격만 보고 선택함
- 검투사 경기에서 장비 기여를 이해하지 못함
- 패배가 단순 실패 화면으로 느껴짐
- 재방문 후 애착·자부심이 형성되지 않음
- 고객 4종 일부가 부가 보상 카드로만 인식됨
- 무작위 결과 때문에 핵심 흐름을 정상적으로 마칠 수 없음

### 13.2 통과 후보 조건

```text
핵심 차단 조건 없음
+ 필수 체험 확인
+ 누적 분기 커버리지 확보
+ 행동 지표가 목표 방향을 지지
+ 감정 응답이 핵심 가설을 지지
→ VERTICAL_SLICE_PASS_CANDIDATE
```

`통과 후보`는 다음을 의미하지 않는다.

- CORE POC 통과
- `기획 완료`
- `검수 완료`
- Production 승인

### 13.3 재작업

```text
차단 조건 발생
→ 관찰 증거로 원인 분류
→ 최소 영향 핵심 루프 수정
→ 앞뒤 연결 구간 회귀 검증
→ 전체 완전 무작위 테스트 재실행
```

- 수치만 바꿔 구조적 문제를 숨기지 않는다.
- 국소 문제 하나 때문에 전체 기획을 자동 폐기하지 않는다.
- 같은 문제가 반복되면 최초 원인 분석과 상위 구조를 재검토한다.

### 13.4 범위 변경 통제

현재 슬라이스 콘텐츠 범위는 잠근다. 새 기능·콘텐츠는 다음 조건을 모두 만족할 때만 추가한다.

1. 확인된 핵심 차단 조건을 직접 해결
2. 기존 요소 수정만으로 해결 불가
3. 15~25분 목표를 훼손하지 않음
4. 새 독립 시스템을 만들지 않음
5. 변경 후 전체 핵심 루프 재검증

그 외 아이디어는 정식 게임 백로그로 이동한다.

## 15. 통합 감사

### 15.1 기존 활성 문서와의 충돌

| 기존 표현 | 새 기획 판정 |
|---|---|
| 강화 중심 클리커라는 장르 고정 | `SUPERSEDED`: 강화가 메인 행동인 것은 유지하되 장르 명칭은 미확정 |
| 기본 활성 한계 +40와 포인트형 +50/+60 개방 | `SUPERSEDED / REVALIDATION_REQUIRED` |
| +60 통합 POC | `SUPERSEDED`: 15~25분 버티컬 슬라이스와 준비 상태 사용 |
| CORE POC 또는 통합 POC가 완료·통과했다는 표현 | `REJECT`: CORE POC 결과 없음 |
| 정밀 등급 1개·수식어 2칸·네 행동 고정 | `REFERENCE_ONLY`: 새 기획에서 세부 슬롯 구조 미확정 |
| 고객 소유 장비는 강화 파괴 시 자동 DAMAGED | `SUPERSEDED`: 대장간 강화의 보호/비보호 규칙 적용, 세계 사건 운명과 분리 |
| 회복석·3일 복구 창·보관으로 기한 정지 | `REJECT` |
| 실시간·오프라인 고객 준비 | `SUPERSEDED`: 운영일 단계 진행 |
| 활성 추적 고객 최대 3명 | `SUPERSEDED`: 구독 무제한 + 관심 인물 제한 |
| 밀수·국가·거래를 통합 POC 필수로 묶음 | `SUPERSEDED`: 수집가·모험가·검투사·군인 네 루프로 재구성 |
| 구형 확률·가격·보호 비용과 판매가 앵커 | `REFERENCE_ONLY / NOT_CURRENT` |

### 15.2 내부 정합성 확인

정합:

- `+60` 이후 대장간 수식어 심화 금지와 세계 업적 수식어 심화는 서로 다른 체계이므로 충돌하지 않는다.
- 세계 일반 사건의 장비 영구 파괴 금지와 대장간 비보호 강화 파괴는 별도 위험 경로이므로 충돌하지 않는다.
- 사건 개입 횟수 무제한과 자원·마감 제약은 함께 적용 가능하다.
- 실제 승패 판정과 승패 양쪽 완결 결말은 함께 적용 가능하다.
- 구독 무제한과 관심 인물 제한은 목적이 다르므로 충돌하지 않는다.

### 15.3 Finding

#### `MUST_FIX-01` — 완전 무작위성과 핵심 경로 중단

대표 +49 장비가 +50 시도에서 영구 파괴될 경우 고위 정밀강화, 구매자 선택, 검투사 판매와 이후 핵심 경로가 중단될 수 있다.

결정 필요:

- 세션 조기 종료를 실제 결과로 허용할지
- 파괴 후 대체 후보를 공급할지
- 핵심 경로 장비에 보호 선택을 강제하지 않으면서 복구 경로를 둘지
- 개별 세션 필수 체크포인트와 누적 표본 체크포인트를 어떻게 구분할지

#### `MUST_FIX-02` — v6 품질·플랫폼 계약 미정

다음 항목은 아직 사용자 승인 설계가 없다.

- UI·UX 정보 구조와 화면 전환
- 아트·애니메이션·사운드 Quality Bar
- 저장·복귀·오류·중단 복구
- 접근성 장벽과 대체 입력·정보
- 대표·최악 장면 성능 목표
- 두 번째 유사 콘텐츠 제작 가능성
- 마스코트 또는 상징 동반자의 역할
- Android·Google Play 테스트 패키지 경계

#### `MUST_FIX-03` — 검증 판정 임계값

핵심 차단 조건의 `반복 발생`, 최소 표본 수, 행동·감정 지표의 통과 경계가 미정이다. 정확한 밸런스 수치와 달리, 테스트 시작 전 판정 규칙은 최소한 정의되어야 한다.

#### `SHOULD_FIX-01` — 15~25분 범위 압축 위험

네 고객의 실제 상호작용, +50 진화, 약속, 배팅, 관전, 재방문을 모두 포함하므로 시간 초과 위험이 높다. 준비 상태와 짧은 대표 사건만으로 실제 완주 가능한지 프로토타입 동선 검증이 필요하다.

#### `SHOULD_FIX-02` — 데이터·저장 경계

소유권 이전, 구독, 약속, 장비 연대기, 수식어 심화, 분실·회수 상태가 저장과 복귀 시 어떻게 원자적으로 유지되는지 기획 계약이 필요하다.

#### `DEFER`

- `+51`~`+100` 정밀 수치 곡선
- 재난급 영구 파괴의 실제 확률과 전체 계승 제작
- 약속 반복 파기·배신·장기 회복 콘텐츠
- 고객별 장기 엔딩
- 정식 출시 경제와 관계 단계 수

### 15.4 현재 결론

```text
MASTER_INTEGRATION: COMPLETE_DRAFT
CONTRADICTION_AUDIT: COMPLETE_WITH_FINDINGS
VERTICAL_SLICE_PLANNING: IN_PROGRESS
READY_FOR_기획_완료: NO
IMPLEMENTATION: BLOCKED
```

다음 설계 우선순위는 `MUST_FIX-01`이다. 이 문제가 정리되어야 완전 무작위 테스트와 필수 슬라이스 흐름이 동시에 성립한다.
