## 1. 승인된 구조

목표 강화 단계 `+60~+100`에서 `완전 보호`를 선택할 수 있다.

- 일반 보호 요구량의 정확히 2배를 소비한다.
- 자연 하락 1·2를 유지로 바꾼다.
- 자연 파괴도 유지로 바꾼다.
- 성공률·대성공률·자연 파괴 확률은 변경하지 않는다.
- 유효한 시도 시작 시 보호석을 전량 소비하고 모든 결과에서 반환하지 않는다.

일반 보호와 무보호 도전은 삭제하지 않는다.

| 방식 | 파괴 결과 |
|---|---|
| 무보호 | 장비 즉시 영구 소멸 |
| 일반 보호 | 보호 파괴 + 기존 공식의 단계 하락 |
| 완전 보호 | 유지 |

## 3. 실패 완충 입력 처리

완전 보호와 실패 완충 타격은 동시에 결과 이득을 만들지 않는다.

- 완전 보호 선택 시 실패 완충 선택 자동 해제
- 자동 해제된 충전값 미소비
- 일반 보호와 실패 완충의 기존 병용 규칙 유지

이 규칙은 효과 없는 조합으로 자원을 소비하는 것을 막는 입력 안전장치다.

## 4. 위임된 POC 조정값

사용자는 다음 수치를 별도 승인 없이 권장안으로 배치하도록 위임했다.

- 보호석 구매 가격
- 보호석 반복 제작법과 보조 획득 묶음
- `+61~+100` 단계별 강화 골드·재료 비용
- `+61~+100` 공개시장 가격 앵커
- 시뮬레이션 기준 숙련과 보호석 그림자 가격

현재 권장값은 `docs/planning/BLACKSMITH_FULL_PROTECTION_ENDGAME_ECONOMY_2026.md`와 연결 JSON을 따른다. 이 값들은 `POC_TUNABLE / APPROVED_CURRENT`이며 구조를 바꾸지 않는 범위에서 POC 결과로 조정할 수 있다.

## 7. 별도 충돌 — 사용자 결정 필요

구형 통합 게임 기획에는 다음 예외가 남아 있다.

```text
고객 소유 장비가 강화 중 파괴 판정을 받으면 삭제하지 않고 DAMAGED로 전환
```

최신 일반 강화 규칙은 다음과 같다.

```text
보호석 미사용 파괴 → 장비 즉시 영구 소멸
지속형 DAMAGED 상태·수리·회복석 없음
```

고객 소유 장비에만 영구 소멸 예외를 둘지는 플레이어 책임감, 고객 관계, 역사 장비 보존 구조를 바꾸는 중요 기획이다. 이 기록에서는 어느 쪽도 임의 확정하지 않고 `REVIEW_REQUIRED_CUSTOMER_OWNED_EQUIPMENT_DESTROY_EXCEPTION`으로 유지한다.
