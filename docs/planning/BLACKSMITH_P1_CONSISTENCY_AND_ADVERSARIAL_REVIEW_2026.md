## 4. C-01 — 정밀강화 데이터 모델 충돌

### 기존 계약

기존 `BLACKSMITH_PRECISION_ENHANCEMENT_BASELINE.md`는 다음을 사용한다.

```text
제작 완성도 1축
+ 정밀 등급 1개
+ 수식어 슬롯 A·B 2개
```

### 사용자 승인 v9 계약

```text
제작 등급 1개
+ 계보 수식어 1개
+ 보조 수식어 최대 2개
+ +50 진화 형태
```

두 구조를 동시에 유지하면 다음 문제가 발생한다.

- 제작 등급과 정밀 등급의 차이를 모바일 카드에서 설명하기 어려움
- 계보·보조 수식어와 기존 A·B 슬롯이 중복됨
- 고객 적합도와 명작 전당 비교 정보가 과밀해짐
- 가치 보정이 같은 품질을 여러 번 계산할 위험

### 최종 판정

기존 `정밀 등급` 축을 폐기하고 제작 등급으로 통합한다.

기존 수식어 슬롯 A·B는 그대로 유지하지 않고 다음으로 전환한다.

```text
LINEAGE_SLOT: 1
SECONDARY_SLOT_COUNT: 2
PRECISION_GRADE_AXIS: REMOVED
```

제작 등급 명칭도 v9 결정으로 교체한다.

```text
미숙한 / 평범한 / 정교한 / 명품 / 완벽한
→
보통 / 양질 / 우수 / 명품 / 걸작
```

## 5. C-02 — 10단위 위험 이중 부과

### 문제

기존 기준선은 `+9→+10` 일반 강화 성공 후 정밀강화 행동을 별도로 선택하고, 해당 행동이 다시 실패할 수 있게 한다.

v9 마스터는 `+9→+10` 진입 시도 자체를 일반 정밀강화로 취급한다.

두 판정을 모두 적용하면 플레이어는 다음을 겪는다.

```text
10단위 진입 위험 감수
→ 성공
→ 다시 정체성 결과 실패 판정
```

이는 이정표 보상을 약화하고 위험 정보를 이중으로 읽게 만든다.

### 최종 판정

10단위 진입 성공 시 해당 이정표의 작품 정체성 결과는 별도 실패 없이 확정한다.

| 단계 | 성공 후 결과 |
|---:|---|
| +10 | 공개 후보 2~3개 중 계보 1개 선택 |
| +20 | 공개 후보 2~3개 중 보조 1개 선택 |
| +30 | 현재 계보 강화 또는 공개된 파생 방향 선택 |
| +40 | 공개 후보 2~3개 중 두 번째 보조 선택 |
| +50 | 진화 후보 2~3개 중 하나 선택, 계보를 대표 특수 형태로 승격 |

재료·촉매·특수재료의 역할:

- 후보 풀을 좁힘
- 특정 후보를 공개함
- 후보별 가치 방향을 바꿈
- 일반 강화 확률을 실제로 바꾸는 경우 최종 확률표에 반영

금지:

- 성공한 10단위 진입 뒤 정체성 결과가 빈 결과로 끝남
- 숨은 확률로 수식어 후보가 사라짐
- 같은 이정표에서 재료만 잃고 작품 변화가 전혀 없음

## 6. C-03 — 가치 계산 책임 중복

### 기존 표현

기존 경제 정본은 다음 순서를 사용한다.

```text
강화 단계 기준가
→ 제작 완성도
→ 정밀 등급·수식어
→ DAMAGED
→ 역사 가치
→ 거래 채널
```

### v9 최종 순서

```text
1. 강화 단계 기준가
2. 제작 등급 보정
3. 계보·보조 수식어의 일반 시장 보정
4. +50 진화 형태 보정
5. 장비 운명·연대기 보정
6. 고객 공개 적합 보정
7. 거래 채널 배율·고객 예산 상한
```

가드레일:

- 같은 수식어를 일반 시장 보정과 고객 적합 보정에 동일 이유로 두 번 계산하지 않는다.
- 일반 시장 보정은 보편적인 제작·희소 가치만 책임진다.
- 고객 적합 보정은 해당 고객의 공개 가치관 차이만 책임진다.
- `전투 흔적`은 보편 감액 상태가 아니다. 고객과 거래 채널에 따라 가치가 오르거나 내릴 수 있다.
- `DAMAGED` 상태와 반복 수리 가격은 사용하지 않는다.
- 파괴된 장비는 거래 가치가 없으며 아이템이 아닌 기록만 남는다.

### 경제 기준 유지

다음 기존 구조는 유지한다.

- +0~+4 평균 투자 회수 전
- +5 최초 평균 흑자
- +5 이후 대표 단계의 예상 순이익 증가
- +60~+100 완전 보호 구조는 본제작 미래 계약

다만 경제 문서의 `평범한`, `정밀 등급`, `DAMAGED` 표현은 기획 완료 후 v9 용어로 전파 수정해야 한다.

## 8. C-05 — +50 진화 정답 방지

세 후보는 총가치 예산을 유사하게 맞추되 결과 분포를 다르게 한다.

| 후보 | 전투 기여 | 관계·명성 | 시장·수집 가치 | 핵심 결과 |
|---|---|---|---|---|
| 성벽파쇄 | 높음 | 보통 | 보통 | 결정적 충격 |
| 용광의 심장 | 중상 | 보통 | 중상 | 연속 압박·화로 정체성 |
| 투기장의 맹세 | 보통 | 높음 | 높음 | 기록·소유자 관계 |

카시아는 세 후보 모두 구매할 수 있다.

- 성벽파쇄: 경기 장면의 직접 기여가 큼
- 용광의 심장: 경기 장면과 제작자 정체성이 균형
- 투기장의 맹세: 관계·명성·연대기 기여가 큼

어느 후보도 가격·승률·관계 모든 축에서 우월하면 안 된다.

## 9. C-06 — 배팅 범위 축소

Vertical Slice의 대표 후속 선택은 `경기 전 조율 지원`으로 고정한다.

배팅은 다음 상태로 내린다.

```text
OPTIONAL_VARIATION / NOT_REQUIRED_FOR_VERTICAL_SLICE_COMPLETION
```

이유:

- 강화·판매·세계 환류 검증에 필수적이지 않음
- 별도 배당·정산·경제·표시 검증을 요구함
- 첫 대표 흐름에서 대장장이보다 배팅 시스템이 주목받을 위험

배팅을 유지하더라도 내부 골드만 사용하며 실제 결제·현금성 재화와 연결하지 않는다.

## 10. C-07 — 파괴 장비와 명작 전당

장비 객체와 공개 기록을 분리한다.

```text
무보호 파괴
→ 장비 객체 영구 소멸
→ 사용·판매·재강화·복구 불가
→ 장비 연대기 종료 기록 유지
→ 기존 공개 등록이 있었다면 역사적 전시 기록으로만 유지 가능
```

역사적 전시 기록:

- `DESTROYED` 명시
- 현재 사용 가능 작품 랭킹 제외
- 등록 당시 정보와 파괴 연대기 보존
- 복구·복제·소유권 생성 권한 없음

## 11. C-08 — 수집가 범주 요청 유지

에르사 로엔의 실제 요청은 `방어구 범주`다.

`별철 의식 방패`는 두 번째 제작 파이프라인을 검증하기 위한 준비 작품 픽스처이며 고객이 특정 아이템 이름을 요구하는 계약이 아니다.

- 다른 판매 가능 방어구도 후보가 될 수 있음
- 낮은 적합도도 판매 가능
- 대표 픽스처는 제작 등급·계보·연대기 표현을 검증하기 위해 사용

## 12. C-09 — 첫 5분과 경제 속도

첫 5분 목표는 다음을 검증하는 UX 목표다.

```text
첫 제작 반응
→ 첫 강화
→ +5 완성 또는 +10 도전의 의미 이해
```

- Vertical Slice는 해당 흐름을 검증할 준비 자원과 조정된 초반 진행을 사용한다.
- 출시 경제의 실제 +5 도달 시간이 반드시 정확히 5분이어야 한다는 의미는 아니다.
- 단, 정식 첫 세션에서도 첫 강화는 60초 안에 제공하는 것을 목표로 한다.
- +5 최초 흑자 구조는 기존 경제 정본을 유지한다.
