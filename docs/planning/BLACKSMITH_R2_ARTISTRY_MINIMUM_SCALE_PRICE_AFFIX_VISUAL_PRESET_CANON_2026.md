# Blacksmith R2 예술성 최소 표시·가격·수식어·시각 프리셋 정본

- Decision ID: `BS-CRAFT-20260804-02`
- 상태: `USER_APPROVED / R2_BATCH_003_6_OF_10 / APPROVED_PENDING_MERGE`
- 단계: `R2_CORE_SESSION_META_LOOP`
- 제품 구현: `BLOCKED`
- 세분화 대상: `BS-CRAFT-20260804-01`

## 1. 목적

예술성 시스템을 기존 제작·강화의 보조 선택으로 유지하면서 플레이어가 결과를 예측하고 비교할 수 있는 최소 표시 규칙을 확정한다.

```text
재료·촉매 방향 확인
→ 실용형·예술형·혼합형 선택
→ 기존 제작·강화
→ 예술성·성능·수식어·가격·외형 결과
```

별도 예술 강화, 장식 미니게임, 다중 미학 능력치는 추가하지 않는다.

## 2. 예술성 표시 척도

작품 예술성은 플레이어에게 다음과 같이 표시한다.

```text
예술성: 정수 1~10
```

- 소수점은 표시하지 않는다.
- `1`은 예술성이 없는 작품이 아니라 기능 중심의 최소 미적 완성 상태다.
- `10`은 현재 기준선에서 가장 높은 예술 가치다.
- 작품 등급은 예술성의 기반과 상한에 영향을 줄 수 있지만 예술성을 자동 결정하지 않는다.
- 같은 등급에서도 보조재료·촉매·강화 결과·수식어에 따라 예술성이 달라진다.
- 강화 단계가 높다는 이유만으로 예술성이 자동 상승하지 않는다. 예술성 상승 효과가 있는 강화 결과와 수식어만 예술성에 반영한다.

정확한 내부 누적식과 재료별 증감치는 버전형 `BASELINE_TEST_PRESET`이 소유한다.

## 3. 재료·촉매 예상 효과 3단계

주재료·보조재료·촉매 설명에는 다음 네 항목을 제작 전에 표시한다.

```text
실전 성능: 낮음 / 보통 / 높음
예술성: 낮음 / 보통 / 높음
판매가: 낮음 / 보통 / 높음
강화 성향: 대표 효과·수식어 가족
```

- `낮음 / 보통 / 높음`은 정확한 수치가 아니라 방향 비교다.
- 색상·아이콘·화살표는 보조 표현으로만 사용할 수 있으며 텍스트 라벨을 대체하지 않는다.
- 최종 수식어를 확정적으로 예고하지 않는다.
- 반복 제작 결과는 사전 설명과 같은 방향을 보여야 한다.

예시:

```text
담금질 보조재료
실전 성능: 높음
예술성: 낮음
판매가: 보통
강화 성향: 방어·내구 / 취급·안정
```

```text
은사 상감 촉매
실전 성능: 낮음
예술성: 높음
판매가: 높음
강화 성향: 마감·세공 / 위신·희소
```

```text
균형형 희귀 촉매
실전 성능: 보통
예술성: 보통
판매가: 높음
강화 성향: 취급·안정 / 감정·가치
```

## 4. 가격 구조

가격은 다음 두 층으로 구성한다.

```text
기본 작품 가치
= 작품 등급 + 실전 성능

추가 가치
= 예술성 프리미엄
+ 희귀 보조재료·촉매 프리미엄
+ 작품 연대기·명성·감정 이력 프리미엄
```

최종 판매가는 기본 작품 가치와 추가 가치를 합산한다.

- 예술성은 가격을 올리지만 작품 등급과 실전 성능을 대체하지 않는다.
- 귀족·수집가·전시 의뢰는 예술성 프리미엄을 높게 평가할 수 있다.
- 검투사·모험가·군인 등 실용 수요 고객은 필요하지 않은 예술성 비용을 전부 지불하지 않을 수 있다.
- 고예술성 작품이 모든 고객·모든 상황에서 최고 수익이 되는 구조는 금지한다.
- 동일 비용으로 실전 성능·예술성·판매가를 모두 최고로 만드는 만능 조합은 금지한다.

정확한 가격 계수·고객별 평가 가중치·상한·체감 수익 곡선은 `BASELINE_TEST_PRESET`으로 남긴다.

## 5. 최소 강화 효과·수식어 가족

수식어 슬롯 수와 강화 입력 방식은 기존 계약을 유지한다. 작품 방향은 수식어 풀을 잠그지 않고 출현 가중치에 영향을 준다.

### 5.1 실용 계열 4가족

1. `OFFENSE_AND_PRECISION` — 공격력·관통·절단·정밀도
2. `DEFENSE_AND_DURABILITY` — 방어·내구·충격 저항·파손 대응
3. `HANDLING_AND_STABILITY` — 균형·경량·취급·안정성
4. `ENVIRONMENT_AND_SPECIALIZATION` — 환경 저항·대상 특화·도구 적합성

대표 표현 예시:

```text
예리함 / 견고함 / 균형 / 경량 / 충격 저항 / 환경 적응
```

### 5.2 예술·가치 계열 3가족

1. `FINISH_AND_CRAFTSMANSHIP` — 마감·세공·각인·상감·장인의 흔적
2. `PRESTIGE_AND_RARITY` — 위신·희소성·후원·가문·명품성
3. `APPRAISAL_AND_VALUE` — 감정 가치·전시 가치·수집 가치·가격 프리미엄

대표 표현 예시:

```text
명품 / 광휘 / 장인의 서명 / 희귀 상감 / 완벽한 마감 / 위신 / 감정 가치
```

### 5.3 성향 가중 규칙

- 실용형: 실용 계열 가중 `높음`, 예술 계열 가중 `낮음~보통`
- 예술형: 예술 계열 가중 `높음`, 실용 계열 가중 `낮음~보통`
- 혼합형: 양쪽 가중 `보통`
- 수식어 계열은 완전히 배타적이지 않다.
- 동일한 재료·촉매 조합에서 예고한 성향과 무관한 결과만 반복되는 것은 오류다.

정확한 출현 확률과 가중 배율은 `BASELINE_TEST_PRESET`이다.

## 6. 예술성 시각 4단계

예술성 수치에 따라 최소 네 단계의 시각 표현을 사용한다.

| 예술성 | 단계 | 표현 원칙 |
|---|---|---|
| `1~2` | `BASIC / 기본` | 재료 고유색과 기본 마감, 기능 판독 우선 |
| `3~5` | `REFINED / 정제` | 깨끗한 표면·정돈된 모서리·절제된 재료 강조 |
| `6~8` | `MASTERWORK / 명품` | 통제된 각인·상감·재료 대비·완성도 높은 표면 처리 |
| `9~10` | `MASTERPIECE / 걸작` | 작품 고유 세공·장인의 서명·절제된 촉매 연출·전시 이력 표식 |

- 예술성 단계는 무기·방어구의 원래 실루엣과 기능 판독성을 유지한다.
- 금색·보석·발광의 양만 늘려 단계를 구분하지 않는다.
- 강화 단계는 같은 예술성 단계 안에서 강도와 완성도를 보조할 수 있지만 예술성 단계 자체를 자동 승격하지 않는다.
- 작품 UID의 전시·수상·감정·계승 이력은 별도 작은 표식으로 추가할 수 있다.
- 모바일 세로 화면에서 작은 크기로도 단계 차이를 식별할 수 있어야 한다.

## 7. 등급·예술성·강화의 역할 구분

- 작품 등급: 출생 품질·제작 완성도·기본 가치의 기반
- 실전 성능: 전투·생존·환경·취급에서 실제 기능
- 예술성: 미적 완성·희소성·명품성·감정·전시 가치
- 강화 단계: 위험을 감수해 작품 성능과 결과를 성장시키는 핵심 진행
- 수식어: 강화 결과가 기능 또는 예술 가치로 구체화되는 차별점

고등급 작품은 예술성 잠재력이 높을 수 있지만 실용 재료와 기능 수식어를 선택하면 기능 중심 작품이 될 수 있다. 반대로 상대적으로 낮은 등급도 예술 지향 재료와 촉매를 사용하면 같은 등급의 일반 작품보다 높은 예술성을 가질 수 있다.

## 8. 적대적 보호 조건

- 예술성 이외의 미학·실용 신규 성장 수치 추가 금지
- 등급과 예술성을 동일 수치로 취급하는 구조 금지
- 강화 단계만으로 예술성·시각 단계가 자동 상승하는 구조 금지
- 제작 전 3단계 설명과 실제 결과 방향 불일치 금지
- 텍스트 없이 색상·화살표만으로 방향을 전달하는 UI 금지
- 예술형이 모든 고객에게 가장 비싼 만능 판매 해답이 되는 구조 금지
- 고예술성 가격 프리미엄이 강화 위험·실전 성능·재료 비용을 무의미하게 만드는 구조 금지
- 실용·예술 수식어 풀의 완전 분리로 혼합형을 제거하는 구조 금지
- 시각 단계가 실루엣·장비 종류·강화 상태 판독을 해치는 구조 금지
- 걸작 단계가 금색·보석·발광 과잉으로만 표현되는 구조 금지

## 9. 행동 검증 기준

플레이어가 다음을 설명할 수 있어야 한다.

1. 작품의 예술성 1~10과 시각 단계가 무엇인지
2. 재료·촉매가 실전 성능·예술성·가격 중 어디에 유리한지
3. 실용형·예술형·혼합형 중 무엇을 만들었고 무엇을 포기했는지
4. 강화 시 어떤 수식어 가족이 더 잘 붙을 것으로 예상했는지
5. 고예술성 작품을 어떤 고객·의뢰에 판매하는 것이 적합한지
6. 등급·강화 단계·예술성이 서로 다른 역할을 가진다는 점

행동 증거와 직후 중립적 회상 인터뷰가 충돌하면 통과를 보류하고 최소 수정 후 재검증한다.
