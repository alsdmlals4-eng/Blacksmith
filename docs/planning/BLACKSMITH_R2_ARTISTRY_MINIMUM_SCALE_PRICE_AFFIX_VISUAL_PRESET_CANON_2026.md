# [부분 대체됨] Blacksmith R2 예술성 표시·가격·시각 프리셋

- 원 Decision: `BS-CRAFT-20260804-02`
- 정제 Decision: `BS-CRAFT-20260805-01`
- 현재 대체 문서: `docs/planning/BLACKSMITH_R2_ARTISTRY_AS_NUMERIC_WEAPON_STAT_CANON_2026.md`
- 제품 구현: `BLOCKED`

## 현재 유지되는 계약

- 예술성은 정수 `1~10`, 소수점 없음
- 강화 단계만으로 자동 상승하지 않음
- 판매 가치와 귀족·후원자·수집가·전시·감정·증여·의식 수요에 기여 가능
- 실용 성능과 별도 축
- 고예술성이 모든 고객·상황의 최적해가 되어서는 안 됨
- 정확한 계수는 `BASELINE_TEST_PRESET`

## [대체됨] named tier 프리셋

다음 과거 임시 단계명은 현재 표시 계약이 아니다.

```text
BASIC 1~2
REFINED 3~5
MASTERWORK 6~8
MASTERPIECE 9~10
```

현재 정본은 다음과 같다.

```text
예술성 7/10
```

- 예술성 단계명 없음
- 제작 등급명 없음
- 무기·작품 상세의 다른 능력치와 함께 숫자로 표시
- 시각 변화가 필요해도 named tier를 사용자-facing 규칙으로 복원하지 않음

## 가격·수식어·시각 경계

- 예술성은 판매가에 기여할 수 있으나 모든 속성을 일괄 증폭하는 범용 품질 배율이 아니다.
- 예술성 관련 촉매·정밀강화 방식은 예술성 값이나 경향에 영향을 줄 수 있지만 `GRADE_AFFIX`를 변경하지 않는다.
- 실루엣과 기능 판독성을 보존한다.
- 금색·보석·광원만으로 높은 예술성을 표현하지 않는다.
- 색상만으로 수치 차이를 전달하지 않는다.

## 상태

이 문서는 가격·수요·시각 경계의 역사·보조 설명으로만 사용한다. 예술성의 현재 표시와 능력치 책임은 `BS-CRAFT-20260805-01`이 우선한다.
