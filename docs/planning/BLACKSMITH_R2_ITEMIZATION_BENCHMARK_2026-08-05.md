- 채택: 이름이 붙는 등급과 숫자형 능력치를 분리하는 정보 구조

- 수정 채택: 숫자 능력치는 성장 가능하게 두되, Blacksmith의 예술성은 전투 전체 품질 계수가 아니라 작품 가치·수요 축으로 사용
- 비채택: 예술성 숫자가 모든 속성을 일괄 증폭하는 범용 품질 배율
- 비채택: 외부 사례를 근거로 예술성에 임의의 고정 최대치를 설정

### Dwarf Fortress

- 이유: Blacksmith는 제작 등급·예술성·촉매·연대기의 원인을 각각 설명할 수 있어야 함

## Blacksmith 차별화

```text
제작 등급 5단계 = 출생 기술 완성도
예술성 0 이상의 정수 = 고정 설계 최대치 없는 원수치 작품 능력치
촉매 수식어 = 플레이어 정밀강화 선택의 흔적
연대기 수식어 = 실제 작품 생애
```

대표 표시:

```text
예술성 27
```

- 예술성 0은 미완성품이 아니라 미적 투자가 거의 없는 정상 기능품
- 제작 등급은 예술성 상한을 만들지 않음
- 기술적 자료형 한계는 콘텐츠 최대치가 아님
- 고정 최대치가 없어도 경제·수요 계산에는 기대 범위·선호 구간·점감 적용 가능

이 분리는 플레이어가 “왜 이 작품이 가치 있는가”를 하나의 총점으로 뭉개지 않고 설명하게 한다.

## 현업식 채택·수정·거절 판정

- Adopt: named grade와 raw numeric stat의 분리
- Adapt: 예술성 원수치는 계속 성장 가능하게 두되 경제·수요에는 점감과 콘텐츠 기대 범위를 적용 가능
- Reject: 예술성을 전투 전체 증폭 배율로 사용
- Reject: 희귀도·품질·예술성·연대기를 하나의 총점으로 합산
- Reject: 벤치마크에 존재한다는 이유만으로 고정 상한을 도입
- Differentiation: 같은 UID의 출생 등급·미적 투자·촉매 선택·실제 생애를 독립적으로 설명
- Remaining uncertainty: 초기 분포·가격 점감·고객 선호 구간·시각 변화·저장 자료형은 별도 승인

## 이후 벤치마킹 운영

질문·추천·새 시스템 확정 전 다음을 수행한다.

1. 비교할 현업 사례와 유사 게임을 찾는다.
2. 표면 기능이 아니라 플레이어 판단·정보 구조·제작 비용을 비교한다.
3. `채택 / 수정 채택 / 비채택 / 차별점 / 남은 불확실성`으로 기록한다.
4. 프로젝트 코어와 충돌하면 유명 사례라도 채택하지 않는다.
5. 출처와 확인 날짜를 정본 또는 PR 증거에 남긴다.
