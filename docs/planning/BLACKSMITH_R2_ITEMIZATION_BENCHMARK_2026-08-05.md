## 비교 대상

### Diablo IV

공식 아이템화 자료는 아이템 등급·아이템 위력·속성·담금질·명품화를 서로 다른 정보 축으로 다룬다. 최근 명품화 개편에서는 숫자형 품질 수치가 별도로 표시되고 속성 값에 영향을 준다.

- 채택: 이름이 붙는 등급과 숫자형 능력치를 분리하는 정보 구조
- 채택: 능력치를 상세 화면에서 직접 비교 가능하게 표시
- 비채택: 예술성 숫자가 모든 속성을 일괄 증폭하는 범용 품질 배율
- 이유: Blacksmith의 예술성은 작품 가치·수요 축이며 전투 최적해가 아니어야 함

참고:

### Dwarf Fortress

현재 Dwarf Fortress는 제작 품질과 재료·장식이 가치에 함께 영향을 주며, core quality와 total quality를 구분한다. 제작 품질은 무기 성능에도 영향을 줄 수 있다.

- 채택: 제작자의 기술적 완성도가 아이템 가치와 일부 기본 품질에 영향을 주는 방향
- 채택: 장식·세공 가치가 제작 품질 외에 별도 기여할 수 있다는 방향
- 비채택: 여러 품질 축을 하나의 total quality로 합쳐 사용자가 출처를 잃는 구조
- 이유: Blacksmith는 제작 등급·예술성·촉매·연대기의 원인을 각각 설명할 수 있어야 함

참고:

## Blacksmith 차별화

```text
제작 등급 5단계 = 출생 기술 완성도
예술성 1~10 = 이름 없는 숫자형 작품 능력치
촉매 수식어 = 플레이어 정밀강화 선택의 흔적
연대기 수식어 = 실제 작품 생애
```

이 분리는 플레이어가 “왜 이 작품이 가치 있는가”를 한 원인으로 뭉개지 않고 설명하게 한다.

## 현업식 채택·수정·거절 판정

- Adopt: named grade와 numeric stat의 분리
- Adapt: 품질 숫자를 전투 전체 증폭이 아니라 작품 가치·특정 수요에 사용
- Reject: 희귀도·품질·예술성·연대기를 하나의 총점으로 합산
- Differentiation: 같은 UID 작품이 고객·세계에서 겪은 생애를 별도 연대기로 유지
- Remaining uncertainty: 예술성의 가격 계수·초기 분포·시각 변화는 사람 플레이 전 테스트 프리셋

## 이후 벤치마킹 운영

질문·추천·새 시스템 확정 전 다음을 수행한다.

1. 비교할 현업 사례와 유사 게임을 찾는다.
2. 표면 기능이 아니라 플레이어 판단·정보 구조·제작 비용을 비교한다.
3. `채택 / 수정 채택 / 비채택 / 차별점 / 남은 불확실성`으로 기록한다.
4. 프로젝트 코어와 충돌하면 유명 사례라도 채택하지 않는다.
5. 출처와 확인 날짜를 정본 또는 PR 증거에 남긴다.
