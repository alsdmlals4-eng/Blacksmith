## 게임 전체 자동 저장 경계

게임 전체 저장은 **비가역 행동별 원자적 저장 + 영업일 체크포인트** 구조를 사용한다.

단순 화면 이동, 하단 패널 열기, 정보 조회는 진행 상태를 변경하는 저장 경계로 취급하지 않는다. 실제 자원·소유권·관계·세계 상태가 바뀌는 행동이 완료된 순간 해당 변경을 확정한다.

```text
비가역 행동 완료
→ 해당 변경을 원자적으로 저장

영업 종료 선택
→ 당일 전체 상태 체크포인트 저장
→ 세계 시간 1단계 진행
→ 사건·소식·관계·장비 운명 결과 저장
```

## 즉시 저장 대상

다음 행동은 완료된 순간 즉시 원자적으로 저장한다.

- 일반 강화·일반 정밀강화·고위 정밀강화
- 강화 재료·보호 수단·특수재료 구매
- 장비 일반 판매와 방문 고객 판매
- 장비 소유권 이전·대여·증여·회수
- 구독 상태와 관심 인물 우선순위 변경
- 약속 수락·거절·이행·기한 경과
- 지원 장비·수리·재료·소모품 제공
- 검투사 배팅 확정과 배당 정산
- 영업 종료 선택
- 세계 사건 결과와 장비 운명 적용
- 관계·신뢰·수식어 심화·연대기 변경
- 파괴 장비와 후계 장비 계보 기록

각 저장은 해당 행동에 연관된 비용, 자원, 대상 상태와 후속 기록을 분리하지 않고 하나의 상태 변경으로 확정한다.

## 영업일 체크포인트

영업 종료는 당일 운영과 세계 진행을 구분하는 명시적 체크포인트다.

```text
영업 전 준비
→ 가게 오픈
→ 강화·거래·지원·배팅 준비
→ 영업 종료 선택
→ 당일 전체 상태 체크포인트
→ 세계 시간 진행
→ 게시판·구독·사건 결과 갱신
→ 갱신 결과 저장
```

- 앱 종료만으로 영업일이 종료되거나 세계 시간이 진행되지 않는다.
- 영업 종료 입력 전까지 세계 사건 마감 일수는 자동 감소하지 않는다.
- 영업 종료 이후 발생한 세계 결과는 하나씩 누락되지 않도록 결과 묶음과 관련 상태를 함께 저장한다.
- 세계 결과 확인 연출은 저장 이후 재생한다.

## 저장 경계가 아닌 행동

다음 행동은 그 자체로 진행 저장을 요구하지 않는다.

- 화면 전환
- 강화 작업대 하단 패널 열기·닫기
- 상세 확률 확인
- 고객·장비·세계 게시판 정보 조회
- 장비 후보 간 비교
- 진화 후보를 보기만 하고 실행하지 않은 상태
- 배팅 금액을 입력했지만 확정하지 않은 상태
- 약속 내용을 열람했지만 수락·거절하지 않은 상태

다만 선택 장비, 마지막 작업대 위치와 같은 편의 상태는 진행 데이터와 분리된 UI 복귀 상태로 저장할 수 있다.

## 앱 종료·복귀 규칙

| 종료 시점 | 복귀 처리 |
|---|---|
| 비가역 행동 확정 전 | 행동 미실행, 자원 미소비, 이전 확정 상태 유지 |
| 비가역 행동 저장 완료 후 | 저장된 변경 유지, 재실행·재판정 없음 |
| 결과 연출·요약 도중 | 동일한 저장 결과를 다시 표시하고 중복 적용 금지 |
| 영업 종료 전 | 같은 영업일과 남은 마감 일수 유지 |
| 세계 결과 저장 후 | 미확인 결과 요약을 먼저 표시한 뒤 다음 운영 단계 진입 |

- 앱 종료나 강제 종료를 결과 재추첨·배팅 취소·약속 철회 수단으로 사용할 수 없다.
- 완료되지 않은 행동은 마지막 확정 상태로 복귀한다.
- 미확인 강화·거래·사건 결과가 있으면 일반 조작보다 먼저 결과 요약을 정리한다.
- 저장된 세계 결과를 다시 보여주더라도 보상·관계·연대기를 중복 적용하지 않는다.

## 설정 데이터 분리

다음 설정은 진행 상태와 분리해 변경 즉시 저장할 수 있다.

- 효과음·음량
- 진동
- 모션 감소
- 반복 연출 단축·건너뛰기
- 길게 누르기 대체 입력
- 기타 접근성 설정

설정 저장 실패가 강화·거래·세계 진행 상태를 롤백하거나 변경해서는 안 된다.

## 오류·무결성 경계

허용하지 않는 상태:

- 구매 비용만 소비되고 재료가 지급되지 않음
- 장비가 판매됐지만 자금·소유권·연대기가 일부만 변경됨
- 배팅 자금만 차감되고 배팅 기록이 없음
- 약속은 수락됐지만 기한·요구·대상 기록이 없음
- 세계 시간이 진행됐지만 사건 결과가 일부 누락됨
- 세계 결과 보상이 두 번 지급됨
- 앱 재시작으로 이미 확정된 선택을 취소하거나 다시 판정함

저장 기술, 파일 형식, 체크섬, 백업 슬롯과 오류 재시도 횟수는 구현 계획 단계에서 결정한다. 위 상태 무결성과 사용자 경험 계약은 유지한다.

## 검증 항목

- 재료 구매 직후 강제 종료 시 비용·재료가 함께 유지되는지 확인
- 장비 판매 직후 종료 시 자금·소유권·연대기가 함께 유지되는지 확인
- 약속 수락 직후 종료 시 요구·기한·대상이 유지되는지 확인
- 배팅 확정 직후 종료 시 동일 배팅이 유지되고 중복 차감되지 않는지 확인
- 영업 종료 직전 종료 시 세계 시간이 진행되지 않는지 확인
- 세계 진행 도중 종료 시 동일 결과로 복귀하고 보상이 중복되지 않는지 확인
- 미확인 결과가 복귀 후 먼저 표시되는지 확인
- 설정 변경과 진행 저장이 서로 롤백을 유발하지 않는지 확인

```text
GLOBAL_AUTOSAVE_MODEL: ATOMIC_IRREVERSIBLE_ACTIONS_PLUS_DAY_CHECKPOINT
IRREVERSIBLE_ACTION_SAVE: IMMEDIATE
DAY_CHECKPOINT: ON_EXPLICIT_SHOP_CLOSE
APP_EXIT_ADVANCES_WORLD_TIME: FORBIDDEN
SCREEN_NAVIGATION_AS_SAVE_BOUNDARY: FORBIDDEN
PENDING_RESULT_RECOVERY: REQUIRED
DUPLICATE_REWARD_OR_STATE_APPLICATION: FORBIDDEN
SETTINGS_SAVE: SEPARATE_FROM_PROGRESSION
EXACT_PERSISTENCE_TECHNOLOGY: IMPLEMENTATION_PLANNING_DECISION
```
