# 블랙스미스 성장 시스템 추가 결정 02 — 분야별 기술 돌파 상한과 10강 주기

> 상태: `PLANNING_IN_PROGRESS`
>
> 기준일: 2026-07-26
>
> 효력: 이 문서는 `BLACKSMITH_GROWTH_SYSTEM_PLANNING.md`와 `BLACKSMITH_GROWTH_SYSTEM_ADDENDUM_01.md`의 분야별 기술 돌파 상한 규칙을 보완한다. 충돌 시 이 문서의 최신 결정이 우선한다. 정확한 비용·요구 숙련·해금 효과 수치는 별도 승인 전까지 `PROPOSED_ONLY`다.

## 1. 확정 결정

분야별 기술 돌파의 최초 상한은 **`+40`**이며, 이후에는 **10강 단위**로 반복한다.

```text
+40 → 분야별 1차 기술 돌파 → +41 개방
+50 → 분야별 2차 기술 돌파 → +51 개방
+60 → 분야별 3차 기술 돌파 → +61 개방
+70 → 분야별 4차 기술 돌파 → +71 개방
...
```

따라서 `+40` 이후의 모든 10강 이정표는 `정밀강화 완료 → 분야별 기술 돌파 완료 → 다음 강화 단계 개방` 순서를 사용한다.

## 2. 공통 경계 처리

각 기술 돌파 상한 `+N0`에서는 다음 절차를 적용한다.

```text
+(N0-1) → +N0 강화 성공
→ 해당 +N0 정밀강화 완료
→ 해당 분야 기술 돌파 대기
→ 돌파 조건·비용 충족
→ 즉시 확정 돌파
→ +(N0+1) 강화 개방
```

- 최초 경계는 `+40`이다.
- 이후 경계는 `+50`, `+60`, `+70`처럼 10강 간격으로 반복한다.
- 정밀강화를 완료하기 전에는 같은 경계의 기술 돌파를 실행할 수 없다.
- 기술 돌파를 완료하기 전에는 다음 강화 단계 버튼이 비활성화된다.
- 차단 상태에서 강화 조작을 시도해도 골드·재료·촉매를 소비하지 않는다.
- 화면에는 부족한 분야 숙련, 공통 대장장이 등급, 선행 기술, 시설, 골드·일반 재료·연구 자원을 표시한다.
- 상한 장비는 돌파 전에도 정상적으로 사용·판매·납품·전시할 수 있다.
- 상한 장비를 기술 돌파 재료로 소비하지 않는다.

## 3. +40 최초 경계

```text
+39 → +40 강화 성공
→ +40 일반 정밀강화 완료
→ 해당 분야 1차 기술 돌파
→ +41 강화 개방
```

- `+40`에서는 고위 정밀강화를 사용할 수 없다.
- 고위 정밀강화는 기존 결정대로 `+50` 이후에만 가능하다.
- `+40` 돌파 완료 후 해당 장비의 `+40` 정밀강화를 다시 수행하지 않는다.

## 4. +50 이후 경계

`+50` 이후에는 정밀강화 선택과 분야별 기술 돌파가 같은 10강 경계에서 연속으로 발생할 수 있다.

```text
+49 → +50 강화 성공
→ 일반 정밀강화 또는 특수 재료를 사용한 고위 정밀강화 선택·결과 확정
→ 해당 분야 2차 기술 돌파
→ +51 강화 개방
```

- 정밀강화가 먼저다.
- 플레이어가 일반 정밀강화를 선택하면 해당 이정표의 고위 기회는 기존 규칙대로 소멸한다.
- 고위 정밀강화 성공·실패와 무관하게 해당 이정표의 정밀강화 결과가 확정되면 기술 돌파 단계로 이동한다.
- 고위 정밀강화 실패도 기술 돌파 자체를 실패시키거나 차단하지 않는다.
- 기술 돌파는 정밀강화 결과를 변경·재판정하지 않는다.
- 기술 돌파 완료 후 같은 이정표의 정밀강화를 반복하지 않는다.

같은 순서를 `+60`, `+70` 이후 경계에도 적용한다.

## 5. 계정·분야별 영구 해금

- 기술 돌파 단계는 무기·방어구·보조 장비·장신구 분야별로 독립한다.
- 돌파는 특정 장비가 아니라 계정의 해당 장비 분야에 영구 적용된다.
- 한 분야의 `+N0` 돌파를 완료하면 그 분야의 기존 `+N0` 장비와 이후 제작되는 모든 장비에서 `+(N0+1)` 이상 다음 구간이 개방된다.
- 다른 장비 분야에는 적용되지 않는다.
- 이미 완료한 하위 돌파와 정밀강화를 다시 요구하지 않는다.
- 상한 장비를 판매·납품해도 계정의 돌파 완료 상태는 유지된다.
- 돌파 자격은 특정 장비 보유가 아니라 분야 숙련·공통 등급·선행 기술·시설과 요구 자원으로 판정한다.

## 6. 정밀강화와 기술 돌파의 책임 분리

| 시스템 | 주기·시점 | 역할 |
|---|---|---|
| 일반 정밀강화 | 모든 10강 이정표 | 일반 수식어 획득·성장·진화 |
| 고위 정밀강화 | `+50` 이후 10강 이정표에서 특수 재료 사용 시 | 특수·초희귀 수식어 제작 경험 |
| 분야별 기술 돌파 | `+40`부터 모든 10강 이정표 | 해당 장비 분야의 다음 10강 구간과 분야 기술을 계정에 영구 개방 |

정밀강화는 장비 한 점의 수식어 결과를 결정하고, 기술 돌파는 계정의 장비 분야가 다음 강화 구간을 다룰 수 있는지를 결정한다.

## 7. 성장 속도 보호 원칙

돌파가 10강마다 반복되므로 다음 원칙을 적용한다.

- 돌파는 확률·실패·연구 대기시간 없이 조건 충족 시 즉시 완료한다.
- 매 돌파가 과도한 장기 재화 벽이 되지 않도록 비용 곡선을 별도 조정한다.
- 이전 돌파보다 요구량은 증가할 수 있으나, 강화 클릭 루프를 장기간 중단시키는 설계는 금지한다.
- 각 단계는 다음 강화 구간 외에도 해당 분야의 보조 기술 또는 메인 트리 접근 조건을 일부 해금할 수 있다.
- 정확한 단계별 숙련·등급·시설·비용·기술 해금은 `PROPOSED_ONLY`다.

## 8. 금지되는 구형 해석

- 최초 돌파를 `+50` 이상으로 미루지 않는다.
- `+40` 이후 돌파 간격을 `+80`, `+100`처럼 임의로 넓히지 않는다.
- `+40` 도달 즉시 정밀강화를 생략하고 돌파하지 않는다.
- `+50` 이후 기술 돌파가 고위 정밀강화를 대체하지 않는다.
- 분야 돌파에 이벤트 특수 재료를 요구하지 않는다.
- 분야 돌파는 확률·실패·이해도·보장선·연구 대기시간을 사용하지 않는다.
- 돌파 전 상위 강화를 불리한 확률로 우회할 수 없다.
- 상한 장비를 돌파 비용으로 파괴·소비하지 않는다.
