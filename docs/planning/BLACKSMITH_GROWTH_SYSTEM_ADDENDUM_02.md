# 블랙스미스 성장 시스템 추가 결정 02 — 최초 분야별 기술 돌파 상한

> 상태: `PLANNING_IN_PROGRESS`
>
> 기준일: 2026-07-26
>
> 효력: 이 문서는 `BLACKSMITH_GROWTH_SYSTEM_PLANNING.md`와 `BLACKSMITH_GROWTH_SYSTEM_ADDENDUM_01.md`의 분야별 기술 돌파 상한 규칙을 보완한다. 충돌 시 이 문서의 최신 결정이 우선한다. 후속 돌파 상한과 정확한 비용·요구 숙련·해금 효과 수치는 별도 승인 전까지 `PROPOSED_ONLY`다.

## 1. 확정 결정

분야별 기술 돌파는 모든 10강 정밀강화 이정표에서 발생하지 않고, 여러 정밀강화 구간을 묶은 대형 강화 경계에서만 요구한다.

최초 분야별 기술 돌파 상한은 **`+40`**으로 확정한다.

```text
+39 → +40 강화 성공
→ +40 일반 정밀강화 완료
→ 해당 분야 최초 기술 돌파 대기
→ 돌파 완료
→ +41 강화 개방
```

## 2. +40 경계 처리

- `+40`은 해당 분야의 최초 계정 기술 돌파 전 강화 상한이다.
- `+40` 도달 장비는 먼저 해당 이정표의 일반 정밀강화를 완료한다.
- `+40`에서는 고위 정밀강화를 사용할 수 없다. 고위 정밀강화는 기존 결정대로 `+50` 이후에만 가능하다.
- 정밀강화 완료 후에도 분야 기술 돌파 전에는 `+41` 강화 버튼이 비활성화된다.
- 차단 상태에서 강화 조작을 시도해도 골드·재료·촉매를 소비하지 않는다.
- 화면에는 부족한 분야 숙련, 공통 대장장이 등급, 선행 기술, 시설, 골드·일반 재료·연구 자원을 표시한다.
- 상한 장비는 돌파 전에도 정상적으로 사용·판매·납품·전시할 수 있다.
- 상한 장비를 기술 돌파 재료로 소비하지 않는다.

## 3. 계정·분야별 영구 해금

- 최초 기술 돌파는 무기·방어구·보조 장비·장신구 분야별로 독립한다.
- 돌파는 특정 장비가 아니라 계정의 해당 장비 분야에 영구 적용된다.
- 한 분야의 최초 기술 돌파를 완료하면 그 분야의 기존 `+40` 장비와 이후 제작되는 모든 장비에서 `+41` 이상 구간이 개방된다.
- 다른 장비 분야에는 적용되지 않는다.
- 돌파 완료 후 `+40` 정밀강화를 다시 수행하지 않는다.
- 돌파 이전에 판매·납품한 `+40` 장비 때문에 계정 돌파 자격이 사라지지 않는다. 돌파 자격은 장비 보유가 아니라 성장 조건과 자원으로 판정한다.

## 4. 정밀강화와 기술 돌파의 책임 분리

| 시스템 | 주기·시점 | 역할 |
|---|---|---|
| 일반 정밀강화 | 모든 10강 이정표 | 일반 수식어 획득·성장·진화, 다음 10강 구간 진입 관문 |
| 고위 정밀강화 | `+50` 이후 10강 이정표에서 특수 재료 사용 시 | 특수·초희귀 수식어 제작 경험 |
| 분야별 기술 돌파 | 여러 정밀강화 구간을 묶은 대형 경계 | 해당 장비 분야의 상위 강화 구간과 분야 기술을 계정에 영구 개방 |

기술 돌파는 정밀강화 결과를 대체하거나 재판정하지 않는다.

## 5. 후속 상한 상태

다음 항목은 아직 확정하지 않는다.

- 두 번째 기술 돌파 상한
- 이후 돌파 간격을 고정할지 점차 넓힐지
- 분야별 상한을 동일하게 적용할지 일부 차등화할지
- 각 돌파 단계의 정확한 숙련·등급·시설 요구치
- 골드·일반 재료·연구 자원 비용
- 각 단계에서 개방되는 분야 보조 기술과 메인 트리 접근 조건

후속 상한이 정해질 때까지 문서나 구현에서 `+80`, `+100` 등 특정 값을 확정값으로 사용하지 않는다.

## 6. 금지되는 구형 해석

- 모든 10강마다 분야 기술 돌파를 요구하지 않는다.
- `+40` 도달 즉시 정밀강화를 생략하고 돌파하지 않는다.
- 분야 돌파에 이벤트 특수 재료를 요구하지 않는다.
- 분야 돌파는 확률·실패·연구 대기시간을 사용하지 않는다.
- 돌파 전 상위 강화를 불리한 확률로 우회할 수 없다.
- `+40` 장비를 돌파 비용으로 파괴·소비하지 않는다.
