# [작업중 제안] Blacksmith 강화 DDD 재설계

- Parent Decision: `BS-CORE-20260820-01`
- 상태: `PROPOSED / USER_DECISION_REQUIRED_FOR_FAILURE_AND_RECOVERY_MODEL`
- 구현: `BLOCKED`

## 1. 설계 목표

강화는 Blacksmith의 메인 게임플레이다. 모든 보조 시스템은 다음 세 질문 중 하나를 강화해야 한다.

1. **강화하기 전:** 지금 멈출지 더 도전할지 고민되는가?
2. **강화 직후:** 결과를 즉시 강하게 이해하고 느끼는가?
3. **결과 이후:** 성공·실패가 다음 강화 행동과 작품 기억을 바꾸는가?

## 2. 세 가지 실질 대안

### A. 순수 위험 사다리

```text
강화 단계 상승
→ 성공률 하락 / 보상 상승
→ 실패 시 유지·손상·고위험 구간 파손
→ 플레이어는 멈춤 또는 계속 도전
```

장점:
- 가장 단순하고 긴장감이 직접적이다.
- 모바일 한 화면 UX에 적합하다.

문제:
- 연속 실패가 무의미하면 피로가 빠르게 누적된다.
- 높은 확률 의존도 때문에 '결국 운게임' 인상이 강해질 수 있다.

### B. 위험 사다리 + 공개된 실패 누적 회복

```text
강화 단계 상승
→ 성공률 하락 / 보상 상승
→ 실패 시 비용·손상 가능
→ 동시에 '단련 진전' 또는 다음 성공 보정 누적
→ 일정 실패 이후 확정 또는 강한 보정
```

장점:
- 실패해도 완전히 제자리라는 감각을 줄인다.
- 높은 단계의 긴장과 장기 실패 피로를 동시에 제어한다.
- 조정 가능한 데이터 경계가 명확하다.

문제:
- 누적치가 지나치게 크면 강화가 사실상 확정 진행바가 되어 긴장감이 죽는다.
- 누적치를 너무 자세히 숫자로 보여주면 UI가 계산기로 변할 수 있다.

### C. 플레이어 선택형 위험 모드

강화마다 다음과 같은 위험 프로필을 고른다.

```text
안정 강화
표준 강화
강행 강화
```

비용·성공률·보상·손상 위험을 서로 다르게 한다.

장점:
- 운 외에 플레이어 의사결정을 직접 늘린다.
- 강화 전 긴장과 표현력이 커진다.

문제:
- 한 옵션이 수학적으로 지배적이면 가짜 선택이 된다.
- 매 클릭마다 선택하면 리듬이 느려지고 인지부하가 커진다.
- 정밀강화와 책임이 겹칠 수 있다.

## 3. 현재 권장

**B를 기본 골격으로 채택하고 C의 핵심은 이정표/고위험 구간에만 제한적으로 흡수**하는 하이브리드가 현재 권장이다.

```text
일상 강화
→ 빠른 단일 시도
→ 성공 / 실패-유지 / 실패-손상
→ 실패에도 소량의 공개 누적 회복

특정 위험 구간 또는 정밀 이정표
→ 멈춤
→ 보호 수단 또는 고위험 도전 여부 선택
→ 강한 결과 연출
```

이렇게 하면 매번 메뉴를 고르는 마찰 없이 일반 강화는 빠르게 반복되고, 중요한 구간에서만 긴 의사결정이 발생한다.

## 4. DDD Reward Ladder

### Micro

한 번의 강화 시도:
- 짧은 anticipation
- 망치/불꽃/금속음
- 즉시 성공/실패 상태
- 능력/강화단계/손상/누적 회복의 명확한 변화

### Session

한 작품에서:
- 첫 위험 강화
- 강화 이정표
- 정밀 성장 방향
- '여기서 멈출까'라는 확보 순간

### Meta

작품을 내보낸 뒤:
- 고객/세계 결과
- 같은 UID의 손상·명성·Chronicle/기억
- 수리·복원·다음 강화 또는 후속 작품 제작 이유

## 5. 실패 결과 후보

기본 실패는 작품 삭제보다 긴장과 다음 행동을 만들어야 한다.

```text
FAIL_HOLD
- 강화 단계 유지
- 비용/작업량 소비
- 실패 누적 회복 증가

FAIL_DAMAGE
- 강화 단계 유지가 기본
- 작품 손상/균열 상태 발생
- 즉시 계속 강화 가능 여부 또는 수리 선택 발생
- UID/연대기 유지

CRITICAL_FAILURE
- 고위험 명시 구간에서만 후보
- 작품 사용 불가 수준 파손 또는 큰 복원 필요
- UID와 역사 자체는 보존
```

완전한 UID 삭제/역사 삭제는 기본 실패 계약에서 제외한다.

## 6. DDD 안전/품질 Gate

- 첫 강화들은 규칙 학습을 위해 높은 성공 체감을 제공한다.
- 높은 단계로 갈수록 보상·위험·연출이 동시에 커진다.
- 실패 연속은 다음 시도의 확률/회복 진전 또는 상태 변화 중 최소 하나를 남긴다.
- 보호 수단은 '무조건 누르는 세금'이 되지 않아야 한다.
- 고위험 단계에서 플레이어가 성공 가능성·비용·손실을 이해하지 못하면 실패다.
- 강화 버튼을 많이 누르게 하는 것 자체를 DDD로 간주하지 않는다.
- 실패 후 장시간 자원 파밍을 강제하지 않는다.
