# 블랙스미스 고객 소유 장비 파괴 규칙 — 2026

> 상태: `PLANNING_IN_PROGRESS`
>
> 기준일: 2026-07-26
>
> 구조 상태: `POC_CONFIRMED / APPROVED_CURRENT`
>
> 목적: 고객 소유 장비의 강화 파괴를 일반 장비와 다르게 처리하던 구형 예외를 폐기하고, 장비 교체가 가능한 고객 생애주기와 최신 강화 파괴 규칙을 일치시킨다.
>
> 기계 판독 데이터: `docs/planning/data/blacksmith_customer_equipment_destruction_2026.json`

---

## 1. 최신 결정

고객 소유 장비도 플레이어 소유 장비와 동일한 강화 파괴 규칙을 사용한다.

```text
보호 없음 + 파괴
→ 해당 장비 즉시 영구 소멸
→ DAMAGED·수리·회복 경로 없음
→ 고객은 유지
→ 후속으로 다른 장비 제작·제공 가능
```

고객 장비라는 이유만으로 파괴를 `DAMAGED`로 바꾸거나 장비를 복원하지 않는다.

---

## 2. 강화 선택

고객 소유 장비에도 다음 선택을 동일하게 제공한다.

| 선택 | 파괴 결과 |
|---|---|
| 무보호 | 장비 즉시 영구 소멸 |
| 일반 보호 | 보호 파괴와 단계 하락 |
| 완전 보호 | 유지 |

- 고객 소유 장비에 보호석 사용을 강제하지 않는다.
- 무보호 도전은 가능하며 일반 고위험 강화와 동일한 파괴 확률·최종 결과·경고를 표시한다.
- 보호석과 완전 보호의 요구량·소비 시점·효과는 각 강화 책임 원본을 따른다.
- 잠금은 판매·이전 실수를 막지만 강화 파괴를 방지하지 않는다.

---

## 3. 파괴 후 고객 처리

장비의 소멸과 고객의 생애주기는 분리한다.

- 파괴된 장비 객체는 인벤토리·고객 장비 슬롯·거래 대상에서 제거한다.
- 고객 자체, 관계, 조언 기록, 활동 기록은 삭제하지 않는다.
- 플레이어는 이후 신규 장비를 제작해 고객에게 제공할 수 있다.
- 새 장비는 새로운 장비 ID와 별도 강화·소유 이력을 가진다.
- 파괴된 장비는 복구 가능한 아이템으로 남지 않는다.

고객의 신뢰·대화 반응은 약속, 공개 방식, 후속 지원과 고객 성격을 따르는 별도 고객 규칙의 책임이다. 이 문서는 고정 신뢰 증감 수치를 추가하지 않는다.

---

## 4. 장비 연대기

장비 소멸 후에도 사건 설명을 위해 최소 기록은 보존한다.

```text
장비 상태: DESTROYED
종료 원인: UNPROTECTED_ENHANCEMENT_DESTROY
최종 소유자: 고객 ID
최종 강화 단계: 파괴 시도 직전 단계
```

- 연대기 기록은 아이템 복구 권한을 만들지 않는다.
- 파괴된 장비는 전시·판매·재강화할 수 없다.
- 고객에게 새 장비를 제공해도 기존 파괴 기록은 새 장비로 이전하지 않는다.

---

## 5. 폐기되는 구형 규칙

다음 내용은 `SUPERSEDED`다.

- 고객 소유 장비의 파괴를 자동으로 `DAMAGED`로 변환
- 고객 장비의 수식어·단계·소유권을 보존하는 복원 경로
- 고객 장비 전용 복원 흔적과 복원 비용
- 고객 장비에 대한 무보호 강화 금지
- 고객 장비는 반드시 보호석을 사용해야 한다는 해석

---

## 6. 검증 계약

POC와 후속 구현은 최소 다음을 확인한다.

1. 고객 소유 장비도 무보호 강화 선택 가능
2. 무보호 파괴 시 장비 객체 즉시 삭제
3. 삭제 후 DAMAGED·수리·회복 버튼 미노출
4. 고객과 고객 관계 데이터 유지
5. 다른 신규 장비를 고객에게 제공 가능
6. 신규 장비가 새 장비 ID와 이력을 가짐
7. 파괴된 장비의 연대기 종료 기록만 조회 가능
8. 일반 보호·완전 보호 결과는 일반 장비와 동일
9. 파괴 확률과 즉시 소멸 경고를 시도 전에 정확히 표시
10. 장비 잠금이 강화 파괴를 막지 않음

Godot 런타임 구현은 정확한 `기획 완료`와 `검수 완료` 이후 별도 계획과 PR로 진행한다.
