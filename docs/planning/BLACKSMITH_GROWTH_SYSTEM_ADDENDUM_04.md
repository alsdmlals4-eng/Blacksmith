# 블랙스미스 성장 시스템 추가 결정 04 — 강화 한계 돌파 트리

> 상태: `PLANNING_IN_PROGRESS`
>
> 기준일: 2026-07-26
>
> 효력: 이 문서는 `BLACKSMITH_GROWTH_SYSTEM_PLANNING.md`와 성장 시스템 추가 결정 01~03의 분야별 기술 돌파 관련 규칙을 대체·보완한다. 충돌 시 이 문서의 최신 결정이 우선한다. 정확한 포인트 지급량, 노드 비용, 숙련 조건, 최대 강화치는 별도 승인 전까지 `PROPOSED_ONLY`다.

## 1. 명칭과 시스템 위치

기존의 `분야별 기술 돌파`, `일반 돌파`, `주요 돌파` 명칭은 사용하지 않는다.

최신 명칭은 **`[강화 한계 돌파]`**다.

`[강화 한계 돌파]`는 장비 분야별 제작 기술이 아니라 **강화 성장축 내부의 별도 영구 스킬 트리**다.

강화 성장 화면은 다음 세 영역으로 구분한다.

1. `메인 전문화`
2. `보조 영구 강화`
3. `강화 한계 돌파`

`강화 한계 돌파`는 안정형·성능형·효율형 메인 빌드와 별개로 관리하며, 현재 빌드를 바꾸는 선택지가 아니라 계정의 최대 강화 구간을 영구 개방하는 진행 트리다.

## 2. 기본 구조

- 기본 강화 한계는 `+40`이다.
- `+40` 이후부터 10강 단위로 다음 강화 한계를 개방한다.
- 각 한계 돌파는 강화 트리의 순차 노드로 표현한다.
- 이전 한계 돌파 노드를 찍어야 다음 노드에 접근할 수 있다.
- 노드 투자에는 강화 성장축 전용 포인트인 `강화 포인트`를 사용한다.
- 투자한 한계 돌파 노드는 계정에 영구 적용된다.
- 한계 돌파 노드는 회수·초기화·재분배 대상이 아니다.
- 공통 보너스 포인트나 장비 분야 전용 포인트는 사용하지 않는다.

예시 구조:

```text
기본 한계 +40
→ [강화 한계 돌파 I] 투자: 최대 +50
→ [강화 한계 돌파 II] 투자: 최대 +60
→ [강화 한계 돌파 III] 투자: 최대 +70
→ [강화 한계 돌파 IV] 투자: 최대 +80
→ ...
```

## 3. 포인트 책임 분리

`강화 포인트`는 강화 숙련 이정표와 강화 관련 최초 기록·업적을 통해 얻는 방향으로 설계한다.

다만 포인트 풀은 목적에 따라 구분한다.

- 메인 전문화 포인트: 당일 강화 빌드 구성
- 보조 영구 강화 포인트: 작은 누적 성능·정보·편의
- 강화 한계 돌파 포인트 또는 지정 강화 포인트: 최대 강화 구간 영구 개방

동일한 강화 포인트 명칭을 사용하더라도 UI에서는 현재 사용 가능 범위와 예약·소모 위치를 명확히 표시한다.

정확히 하나의 공용 강화 포인트 풀을 세 트리가 공유할지, 한계 돌파 전용 포인트를 별도로 둘지는 아직 `UNRESOLVED`다.

## 4. 정밀강화와의 관계

- 정밀강화는 기존대로 모든 10강 이정표에서 발생한다.
- 한계에 도달한 장비는 해당 10강 정밀강화를 먼저 완료한다.
- 이후 필요한 `[강화 한계 돌파]` 노드가 투자되어 있어야 다음 단계 강화가 가능하다.
- `+40`에서는 일반 정밀강화 후 첫 한계 돌파가 필요하다.
- `+50` 이후에는 일반 또는 고위 정밀강화 결과를 먼저 확정한 뒤 다음 한계 돌파 조건을 확인한다.
- 고위 정밀강화 성공·실패는 한계 돌파 노드 투자 성공 여부와 무관하다.
- 한계 돌파는 확률·실패·연구 시간·연구 슬롯을 사용하지 않는다.

```text
+49 → +50 강화 성공
→ +50 정밀강화 결과 확정
→ [강화 한계 돌파 II] 투자 여부 확인
→ 투자 완료 시 +51 강화 개방
```

## 5. 상한 도달 장비 처리

필요한 한계 돌파 노드가 없는 경우:

- 다음 강화 버튼 비활성화
- 부족한 노드, 강화 포인트, 숙련 조건 표시
- 차단된 조작으로 골드·재료·촉매 미소모
- 장비는 정상적으로 사용·판매·납품·전시 가능
- 장비를 한계 돌파 재료로 소비하지 않음
- 이후 노드 투자 즉시 기존 상한 장비도 다음 구간 강화 가능

## 6. UI 원칙

`강화 한계 돌파`는 강화 성장 화면의 별도 탭 또는 명확히 분리된 세 번째 트리로 표시한다.

각 노드에는 다음을 표시한다.

- 현재 최대 강화치
- 투자 후 최대 강화치
- 필요 강화 포인트
- 선행 한계 돌파 노드
- 필요 강화 숙련·공통 대장장이 등급
- 투자 가능 여부와 부족 조건
- 영구 적용·회수 불가 경고

노드는 선형 또는 거의 선형인 순차 구조를 사용하며, 안정형·성능형·효율형처럼 분기 빌드 선택을 요구하지 않는다.

## 7. 폐기되는 구형 규칙

다음 규칙은 `REJECTED` 또는 `SUPERSEDED`다.

- `주요 돌파`와 `일반 돌파` 구분
- 돌파 단계마다 소형·대형 기술 보상 배치
- 장비 분야별 별도 돌파 트리
- 골드·일반 재료·연구 자원을 핵심 돌파 비용으로 사용하는 구조
- 돌파 성공·실패·이해도·보장선
- 돌파 연구 시간과 연구 슬롯
- 상한 장비를 돌파 재료로 소비
- 메인 전문화 노드 회수로 최대 강화치가 내려가는 구조

## 8. 현재 미결정

- 강화 한계 돌파가 메인·보조와 같은 강화 포인트 풀을 공유하는지
- 별도 `한계 돌파 포인트`를 사용하는지
- 노드 투자 가능 시점이 숙련 조건 충족 즉시인지, 해당 강화 한계 도달 후인지
- 각 노드의 포인트 비용 증가 방식
- 강화 한계의 최종 상한
- 한계 돌파 노드 투자 가능 시점을 영업 전 준비 단계로 제한할지 여부

모든 미결정 수치는 `PROPOSED_ONLY`다.
