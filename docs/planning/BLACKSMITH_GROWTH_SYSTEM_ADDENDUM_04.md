# 블랙스미스 성장 시스템 추가 결정 04 — 강화 한계 돌파 트리

> 상태: `PLANNING_IN_PROGRESS`
>
> 기준일: 2026-07-26
>
> 효력: 이 문서는 `BLACKSMITH_GROWTH_SYSTEM_PLANNING.md`와 성장 시스템 추가 결정 01~03의 기술 돌파 관련 규칙을 대체·보완한다. 충돌 시 이 문서의 최신 결정이 우선한다. 정확한 포인트 지급량, 노드 비용, 숙련 조건과 최종 강화 한계는 별도 승인 전까지 `PROPOSED_ONLY`다.

## 1. 명칭과 시스템 위치

기존의 `분야별 기술 돌파`, `일반 돌파`, `주요 돌파` 명칭은 사용하지 않는다.

최신 명칭은 **`[강화 한계 돌파]`**다.

`[강화 한계 돌파]`는 장비 분야별 제작 기술이나 별도 계정 영구 성장축이 아니라 **강화 성장축의 메인 빌드를 구성하는 별도 순차 스킬 트리**다.

강화 성장 화면은 다음 세 영역으로 구분한다.

1. `메인 전문화`: 안정형·성능형·효율형 분기
2. `강화 한계 돌파`: 고강화 작업을 위한 순차 한계 개방 트리
3. `보조 영구 강화`: 작은 누적 성능·정보·편의

고강화 작업 자체가 메인 빌드이므로 `강화 한계 돌파`는 메인 전문화와 동일한 제한 자원을 경쟁적으로 사용한다.

## 2. 기본 구조

- 기본 활성 강화 한계는 `+40`이다.
- `+40` 이후부터 10강 단위로 다음 활성 강화 한계를 개방한다.
- 각 한계 돌파는 순차 노드로 표현한다.
- 이전 한계 돌파 노드가 투자되어 있어야 다음 노드에 접근할 수 있다.
- 노드 투자에는 강화 메인 전문화와 동일한 `강화 메인 포인트`를 사용한다.
- 강화 메인 전용 포인트가 우선 사용되고, 기존 공통 보너스 포인트 규칙이 허용하는 범위에서 부족분을 보충할 수 있다.
- 한계 돌파 노드는 메인 빌드 노드이므로 영업 전 준비 단계에서 투자·회수할 수 있다.
- 가게를 연 뒤에는 다른 메인 전문화 노드와 함께 그날 동안 잠긴다.
- 장비 분야 전용 포인트와 보조 영구 강화 포인트는 사용하지 않는다.

예시 구조:

```text
기본 활성 한계 +40
→ [강화 한계 돌파 I] 투자: 활성 최대 +50
→ [강화 한계 돌파 II] 투자: 활성 최대 +60
→ [강화 한계 돌파 III] 투자: 활성 최대 +70
→ [강화 한계 돌파 IV] 투자: 활성 최대 +80
→ ...
```

## 3. 메인 빌드 경쟁

`강화 한계 돌파`에 사용한 포인트는 같은 날 안정형·성능형·효율형 분기에 사용할 수 없다.

따라서 강화 메인 빌드는 다음 선택을 포함한다.

- 낮은 강화 구간에서 안정·효율·성과 효과를 깊게 투자
- 일부 한계 돌파와 역할 분기를 혼합
- 높은 강화 한계를 확보하는 대신 역할 분기 깊이를 줄이는 고강화 빌드

메인 포인트 최종 상한으로 모든 역할 분기와 모든 한계 돌파 노드를 동시에 완성할 수 없도록 한다. 정확한 점유 비율은 `PROPOSED_ONLY`다.

## 4. 투자·회수와 활성 한계

- 투자와 회수는 영업 전 준비 단계에서만 가능하다.
- 개별 노드 회수, 연쇄 회수, 비용과 포인트 반환은 기존 메인 전문화 규칙을 따른다.
- 하위 한계 노드를 회수하면 이를 선행 조건으로 사용하는 상위 한계 노드도 함께 회수된다.
- 회수 미리보기에서 변경 전·후 활성 최대 강화치와 연쇄 회수 포인트를 표시한다.
- 영업 중 획득한 메인 포인트는 다음 준비 단계부터 사용할 수 있다.
- 저장·재접속, 같은 날 영업 종료·재개로 당일 잠금을 우회할 수 없다.

현재 장비의 강화 단계가 새 빌드의 활성 한계보다 높아져도 장비 단계는 하락하지 않는다.

- 해당 장비는 정상적으로 사용·판매·납품·전시할 수 있다.
- 현재 활성 한계보다 높은 장비는 추가 강화할 수 없다.
- 필요한 한계 돌파 노드를 다시 투자하면 추가 강화가 가능하다.
- 한계 노드 회수로 장비가 손상·파괴되거나 정밀강화 결과가 취소되지 않는다.

## 5. 정밀강화와의 관계

- 정밀강화는 기존대로 모든 10강 이정표에서 발생한다.
- 한계에 도달한 장비는 해당 10강 정밀강화를 먼저 완료한다.
- 이후 다음 단계에 필요한 `[강화 한계 돌파]` 노드가 현재 메인 빌드에 투자되어 있어야 다음 강화가 가능하다.
- `+40`에서는 일반 정밀강화 후 첫 한계 돌파 노드가 필요하다.
- `+50` 이후에는 일반 또는 고위 정밀강화 결과를 먼저 확정한 뒤 활성 한계를 확인한다.
- 고위 정밀강화 성공·실패와 한계 돌파 노드 상태는 독립이다.

```text
+49 → +50 강화 성공
→ +50 정밀강화 결과 확정
→ 현재 빌드의 [강화 한계 돌파 II] 확인
→ 투자되어 있으면 +51 강화 가능
```

## 6. 상한 도달 장비 처리

필요한 한계 돌파 노드가 현재 빌드에 없는 경우:

- 다음 강화 버튼 비활성화
- 부족한 노드, 강화 메인 포인트와 숙련 조건 표시
- 차단된 조작으로 골드·재료·촉매 미소모
- 장비는 정상적으로 사용·판매·납품·전시 가능
- 장비를 한계 돌파 재료로 소비하지 않음
- 다음 준비 단계에서 노드를 투자하면 기존 상한 장비도 추가 강화 가능

## 7. UI 원칙

`강화 한계 돌파`는 강화 성장 화면에서 메인 역할 분기와 시각적으로 분리된 별도 트리로 표시한다.

각 노드에는 다음을 표시한다.

- 현재 활성 최대 강화치
- 투자 후 활성 최대 강화치
- 필요 강화 메인 포인트와 포인트 출처
- 선행 한계 돌파 노드
- 필요 강화 숙련·공통 대장장이 등급
- 투자 가능 여부와 부족 조건
- 회수 시 낮아지는 활성 한계
- 영향을 받는 상위 노드와 반환 포인트
- 현재 영업 상태와 다음 변경 가능 시점

노드는 선형 또는 거의 선형인 순차 구조를 사용하며, 안정형·성능형·효율형처럼 별도 역할 분기를 만들지 않는다.

## 8. 폐기되는 구형 규칙

다음 규칙은 `REJECTED` 또는 `SUPERSEDED`다.

- `주요 돌파`와 `일반 돌파` 구분
- 돌파 단계마다 소형·대형 기술 보상 배치
- 장비 분야별 별도 돌파 트리
- 골드·일반 재료·연구 자원을 핵심 돌파 비용으로 사용하는 구조
- 한계 돌파 전용 포인트 풀
- 보조 영구 강화 포인트 사용
- 한계 돌파 노드의 영구·회수 불가 처리
- 계정에 영구 개방되어 메인 빌드와 경쟁하지 않는 구조
- 돌파 성공·실패·이해도·보장선
- 돌파 연구 시간과 연구 슬롯
- 상한 장비를 돌파 재료로 소비

## 9. 현재 미결정

- 각 한계 돌파 노드의 강화 메인 포인트 비용 곡선
- 노드별 강화 숙련·공통 등급 선행 조건
- 공통 보너스 포인트가 한계 돌파에 기여할 수 있는 정확한 상한
- 강화 메인 포인트 최종 상한에서 의도하는 한계 돌파·역할 분기 점유 비율
- 강화 한계의 최종 상한
- 개별 회수·전체 초기화 비용이 일반 메인 노드와 완전히 같은지 여부

모든 미결정 수치는 `PROPOSED_ONLY`다.
