## 1. 책임 분리

보조재료 슬롯은 사용하지 않는다.

```text
주재료 = 작품 기본 이름·기본 성능·재료 정체성
제작 등급 = 고정 등급 수식어
강화 방식 = 세부 능력치 조정 방향
촉매 = 촉매 수식어 씨앗·계보·변형 확률
작품 연대기 = 별도 연대기 수식어
```

세 수식어 슬롯의 최신 권위는 `BS-CRAFT-20260804-06`이다.

## 2. 제작과 강화 단계

### 최초 제작

```text
작품 종류 + 주재료 + 직접 단조
→ 기본 이름·기본 성능·제작 등급 확정
→ 등급 수식어 1개 생성
→ 촉매 수식어 EMPTY
→ 연대기 수식어 EMPTY
```

- 주재료가 작품 기본 이름과 기본 성능 범위를 결정한다.
- 제작 등급은 기존 `STANDARD / GOOD / PERFECT` 품질 계약을 사용한다.
- 등급 수식어는 동일 UID에서 고정된다.
- 최초 제작에 보조재료·촉매 슬롯은 없다.

### 일반 강화

```text
강화 입력
→ 한 번의 성공·실패·대파 결과
→ 멈춤 또는 추가 도전
```

- 일반 강화는 한 입력 한 결과를 유지한다.
- 매 일반 강화마다 방식과 촉매를 선택하지 않는다.
- 강화 단계는 촉매 수식어의 다음 성장 기회와 상한을 열지만 자동 성장시키지 않는다.
- 일반 강화는 등급 수식어와 연대기 수식어를 변경하지 않는다.

### 정밀강화

`+10/+20/+30/+40/+50` 정밀 이정표에서 다음을 선택한다.

1. 주재료 맥락과 호환 강화재
2. 강화 방식
3. 촉매 한 칸
4. 현재 촉매 수식어 계보와 예상 변화

정밀강화는 촉매 수식어만 생성·강화·분기·변형할 수 있다. 등급 수식어와 연대기 수식어를 직접 변경하지 않는다.

## 3. 주재료

주재료는 다음을 결정한다.

- 작품 기본 이름
- 공격·방어·내구·무게·취급 등 기본 성능 범위
- 기본 가치와 제작 난이도 방향
- 재료 고유색·질감·표면 특성
- 강화 방식과 촉매의 호환 범위

정밀강화에서 다른 재료를 사용해도 기존 작품 이름과 등급 수식어를 자동 변경하지 않는다. 새로운 혼합 재료 작품군은 별도 Decision과 명명 승인을 거친다.

## 4. 강화 방식 — 세부 수치 조정

| 방식 | 주요 방향 | 대표 대가 |
|---|---|---|
| 날 보강 | 공격력·정밀성 | 무게·취급·위험 |
| 충격 흡수 | 방어력·내구도 | 무게·공격성 |
| 경량화 | 무게 감소·취급성 | 내구·방어·최대 공격 |
| 균형 조정 | 취급성·안정성 | 공격·방어 최고점 |
| 예술 마감 | 예술성·가치 | 전투 성장 기회·비용 |
| 환경 처리 | 환경 대응·특화 | 범용 성능 최고점 |

- 각 방식은 주요 이점과 대가를 가진다.
- 작품 종류와 맞지 않는 방식은 표시하지 않는다.
- 성공한 결과는 선택한 방식의 능력치 방향을 반영한다.
- 정확한 증가·감소량은 `BASELINE_TEST_PRESET`이다.
- 강화 방식은 세 수식어 슬롯의 정확한 이름을 직접 결정하지 않는다.

## 5. 촉매 — 촉매 수식어 확률 구조

촉매는 `CATALYST_AFFIX` 한 슬롯에 다음을 설정한다.

- 후보 수식어 가족
- 계보별 가중 확률
- 빈 슬롯의 씨앗 성향
- 기존 계보의 강화·분기·변형 확률
- 결과 품질과 단계 범위
- 주재료·강화 방식과의 호환 반응

촉매는 다음을 확정하지 않는다.

- 정밀강화 성공
- 정확한 촉매 수식어 이름
- 최고 촉매 수식어 단계
- 기존 계보와 무관한 임의 변형
- 등급 수식어 또는 연대기 수식어의 생성·변경

정밀강화 한 번당 촉매 입력은 한 칸이다. 여러 이정표의 촉매 순서가 작품 UID에 누적되어 촉매 수식어의 조합 이력을 형성한다.

## 6. 촉매 역할군

1. `TEMPERING_SALT / 담금질 염` — 방어·내구·안정 계보
2. `HIGH_HEAT_QUENCH / 고열 담금질유` — 공격·정밀 계보, 위험 증가
3. `STABILIZING_OIL / 안정화유` — 안정·취급 계보와 실패 완화, 최고점 대가
4. `ANTI_CORROSION_AGENT / 방청 촉매` — 환경 대응·원정 계보
5. `FINE_POLISHING_POWDER / 정밀 연마분` — 마감·세공·감정 가치 계보
6. `HERALDIC_FIXATIVE / 문장 정착제` — 위신·가문·증여 계보
7. `STAR_RESIDUE / 별재 촉매` — 희귀·특화·혼합 변형 후보, 높은 비용·불안정

## 7. 세 수식어와 정밀강화 경계

- 등급 수식어: 제작 완료 시 생성, 동일 UID에서 고정
- 촉매 수식어: 정밀강화 촉매 이력으로 생성·성장·분기·변형
- 연대기 수식어: 고객·사건·사용·손상·복원·소유 이력으로 생성·진화

정밀강화 화면은 촉매 수식어 예상만 보여준다. 연대기 수식어 후보를 촉매 선택 보상처럼 제시하지 않는다.

## 8. 사전 표시

```text
주재료: 기본 성능·호환 상태
강화 방식: 능력치 증가·감소 방향
현재 촉매 수식어: 계보·단계
현재 촉매와 누적 촉매 이력
예상 씨앗·강화·분기·변형 가능성: 낮음 / 보통 / 높음
성공·실패·재료 소모 위험
```

- 텍스트 라벨은 필수다.
- 정확한 촉매 수식어 이름과 최종 수치는 확정적으로 공개하지 않는다.
- 후보로 제시하지 않은 무관한 계보가 성공 결과로 나오지 않는다.
- 실패·대파 가능성과 주요 손실을 실행 전에 표시한다.
