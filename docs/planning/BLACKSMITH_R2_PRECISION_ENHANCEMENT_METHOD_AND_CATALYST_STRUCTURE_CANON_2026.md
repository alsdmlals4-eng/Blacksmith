## 1. 결정 요약

보조재료 슬롯은 사용하지 않는다.

날 보강·충격 흡수·경량 합금·환경 처리·은사 상감·문장 각인처럼 별도 재료 슬롯으로 제안했던 방향성은 정밀강화 시 선택하는 `강화 방식`으로 전환한다.

정밀강화의 판단 구조는 다음 세 요소로 단순화한다.

```text
주재료 맥락 + 강화 방식 + 촉매·추가재료
→ 예상 능력치 방향·대가·위험 확인
→ 정밀강화 실행
→ 능력치 변화·수식어 추가 또는 성장·시각 변화
→ 멈춤 또는 다음 강화 판단
```

- 주재료는 작품의 기본 재료 정체성과 가능한 성능 범위를 제공한다.
- 강화 방식은 이번 정밀강화의 능력치 방향을 소유한다.
- 촉매·추가재료는 방향을 새로 정하지 않고 효과·위험·수식어·마감을 보정한다.

## 2. 제작과 강화 단계 분리

### 2.1 최초 제작

```text
작품 종류 선택
+ 주재료 선택
→ 수식어 없는 1차 완성품 생성
```

- 작품 기본 이름은 최초 주재료와 작품 종류에서 파생된다.
- 최초 제작에 보조재료 슬롯은 없다.
- 최초 제작만으로 일반 수식어를 부여하지 않는다.
- 작품 등급과 영구 출생 품질은 기존 직접 단조 결과가 소유한다.

### 2.2 일반 강화

일반 강화는 기존 핵심 재미를 유지한다.

```text
강화 입력
→ 한 번의 결과
→ 성공·실패·대파 결과 확인
→ 멈춤 또는 추가 도전
```

- 일반 강화는 한 입력 한 결과를 유지한다.
- 매 일반 강화마다 방식과 촉매를 고르게 하지 않는다.
- 일반 강화에 재료 조합 화면을 반복 삽입하지 않는다.

### 2.3 정밀강화

`+10/+20/+30/+40/+50` 정밀 이정표에서만 방향성 선택을 제공한다.

정밀강화 화면은 다음을 보여준다.

1. `주재료 맥락`
2. `강화 방식`
3. `촉매·추가재료`
4. 예상 능력치 방향
5. 명시적 대가와 위험
6. 예상 수식어 가족과 시각 변화 방향

## 3. 주재료 맥락

정밀강화에서 주재료는 작품의 원래 주재료와 호환 강화재를 뜻한다.

- 작품의 최초 주재료가 기본 성능 범위와 재료 정체성을 유지한다.
- 정밀강화에 필요한 주재료 소모량·품질·호환성은 후속 테스트 프리셋에서 정한다.
- 다른 재료를 촉매나 추가재료로 사용할 수는 있지만, 기존 작품의 기본 이름을 자동으로 바꾸지 않는다.
- 혼합 재료가 완전히 새로운 작품군이나 기본 명칭을 만든다면 별도 Decision과 명명 승인이 필요하다.

## 4. 강화 방식 — 능력치 방향성

강화 방식은 선택한 정밀강화에서 어떤 능력치를 우선할지 결정한다.

### 4.1 날 보강

- 주요 방향: `공격력 / 정밀성`
- 가능한 보조 효과: 날 내구·관통·절삭 적합성
- 대표 대가: 무게·취급·강화 위험 또는 방어 성능
- 적용 대상: 날이나 타격부를 가진 무기 중심

### 4.2 충격 흡수

- 주요 방향: `방어력 / 내구도`
- 가능한 보조 효과: 파손 저항·충격 분산
- 대표 대가: 무게 증가·공격성 또는 정밀성 감소
- 적용 대상: 방어구·방패·중량 무기·보호 장비

### 4.3 경량화

- 주요 방향: `무게 감소 / 취급성`
- 가능한 보조 효과: 속도·피로 효율·휴대성
- 대표 대가: 순수 내구·방어력·최대 공격력 감소 가능
- 적용 대상: 무기·방어구·도구 중 구조적으로 경량화 가능한 작품

### 4.4 균형 조정

- 주요 방향: `취급성 / 안정성`
- 가능한 보조 효과: 명중·반동 제어·장시간 사용 적합성
- 대표 대가: 공격·방어의 최고점이 낮아질 수 있음
- 적용 대상: 무기·도구·일부 방어 장비

### 4.5 예술 마감

- 주요 방향: `예술성 / 가치`
- 가능한 보조 효과: 마감·세공·위신·감정 가치·시각 단계
- 대표 대가: 직접 전투 성능 증가가 낮거나 비용·난이도가 높음
- 적용 대상: 전투품·의장품·가보·전시품을 포함한 금속 작품

### 4.6 환경 처리

- 주요 방향: `환경 대응 / 특화 성능`
- 가능한 보조 효과: 부식·열·냉기·습기·특정 위협 대응
- 대표 대가: 범용 공격·방어·예술 최고점 감소 가능
- 적용 대상: 고객 사건과 환경 요구가 명확한 작품

## 5. 강화 방식 공통 규칙

- 각 방식은 최소 하나의 주요 이점과 하나의 대가를 가진다.
- 성공한 정밀강화 결과는 선택한 방식의 주요 방향을 반드시 반영한다.
- 정확한 증가량·부작용·품질·수식어 결과는 고정하지 않으며 강화 결과와 테스트 프리셋이 결정한다.
- 방식은 작품 종류에 따라 적용 가능 여부와 효과가 달라진다.
- 날이 없는 방어구에 날 보강을 적용하는 식의 의미 없는 선택은 표시하지 않는다.
- 모든 작품에 항상 같은 방식이 최적인 구조를 금지한다.
- 선택한 방식이 성공 결과와 반대 방향으로 작동하는 숨은 함정을 금지한다.

## 6. 촉매·추가재료

촉매·추가재료는 강화 방식의 보조 변수다.

다음 중 일부를 조정할 수 있다.

- 주요 능력치 증가량
- 방식의 대가 완화 또는 강화
- 정밀강화 성공·실패·대파 위험 방향
- 수식어 가족의 등장·성장 가중치
- 예술성·마감·색·질감·입자 효과
- 특정 주재료와의 반응 또는 환경 특화

촉매는 다음을 할 수 없다.

- 강화 방식과 무관한 새로운 방향을 독립적으로 소유
- 성공·수식어·최고 결과를 확정
- 주재료의 기본 이름과 정체성을 자동 변경
- 같은 촉매 하나로 모든 방식의 대가를 제거

촉매 슬롯의 필수 여부·소비량·등급·재사용 가능성은 `BASELINE_TEST_PRESET`이다. 정밀강화 화면에는 슬롯을 제공하되 빈 슬롯 허용 여부는 정밀 단계와 레시피에 따라 테스트한다.

## 7. 초기 촉매 역할군

같은 촉매도 주재료와 강화 방식에 따라 효율과 대가가 달라질 수 있다.

## 8. 능력치와 수식어 관계

강화 방식은 직접 능력치 방향을 제공한다.

- 공격력
- 방어력
- 내구도
- 무게
- 취급성
- 안정성
- 환경 대응
- 예술성
- 작품 가치

수식어는 기존 규칙을 유지한다.

- 최초 완성품에는 일반 수식어가 없다.
- 일반 수식어 A·B는 정밀 이정표와 강화 결과에서 추가·성장한다.
- 활성 사건·연대기 수식어는 별도 한 개와 진화 이력을 유지한다.
- 강화 방식은 관련 수식어 가족의 가중치를 높인다.
- 촉매는 해당 가중치와 결과 품질을 보정하지만 특정 수식어를 확정하지 않는다.

예시:

```text
강철검 + 날 보강 + 고열 담금질유
→ 공격력·정밀성 방향
→ 무게·강화 위험 대가
→ 공격·정밀 수식어 가중
```

```text
강철 방패 + 충격 흡수 + 담금질 염
→ 방어력·내구도 방향
→ 무게 대가
→ 방어·내구 수식어 가중
```

```text
은합금 의장검 + 예술 마감 + 정밀 연마분
→ 예술성·가치 방향
→ 직접 전투 증가와 비용 효율 대가
→ 마감·세공·위신 수식어 가중
```

위 예시는 고정 레시피나 숨은 조합 정답이 아니다.

## 9. 사전 표시 계약

정밀강화 선택 전 다음을 텍스트로 표시한다.

```text
주재료: 작품의 기존 재료와 호환 상태
강화 방식: 주요 능력치 방향
촉매·추가재료: 추가 보정과 위험 변화
예상 변화: 낮음 / 보통 / 높음
대가: 감소·무게·비용·위험·범용성
수식어 성향: 관련 가족
```

- 색상·아이콘·화살표는 텍스트를 보조한다.
- 정확한 최종 수치와 수식어는 확정적으로 공개하지 않는다.
- 성공 시 표시한 주요 방향과 실제 결과가 일치해야 한다.
- 실패·대파 가능성과 주요 손실은 실행 전에 공개한다.
