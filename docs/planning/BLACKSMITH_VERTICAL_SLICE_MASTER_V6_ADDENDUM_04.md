## 강화 사운드·진동 문법

강화 피드백은 **공통 타격 문법 위에 결과·이정표·장비 레이어를 조합하는 계층형 구조**를 사용한다.

강화 단계마다 완전히 다른 효과를 제작하지 않는다. 플레이어가 반복 경험을 통해 성공, 실패, 단계 하락, 영구 파괴와 정밀강화 계열을 빠르게 구분할 수 있는 공통 문법을 먼저 만든다.

```text
기본 레이어
- 망치 충돌
- 금속 공명

결과 레이어
- 성공
- 실패·단계 유지
- 단계 하락
- 영구 파괴

이정표 레이어
- 일반 정밀강화
- 고위 정밀강화

장비 레이어
- 무기·방어구 등 재질과 형태 차이
```

## 사운드 레이어

### 기본 타격

- 모든 강화는 공통된 망치 충돌과 금속 공명을 기반으로 한다.
- 기본 타격은 반복 강화의 조작 반응을 담당한다.
- 장비별 재질 차이는 기본 결과 문법을 훼손하지 않는 범위에서 추가한다.

### 결과 구분

#### 저위험 성공

- 짧고 단단한 해결음을 사용한다.
- 반복 성공에서 과도하게 길거나 화려한 사운드를 사용하지 않는다.
- 다음 강화 입력을 방해하지 않는 길이를 유지한다.

#### 실패·단계 유지

- 성공과 분명히 구분되는 약한 미해결음을 사용한다.
- 무음이나 입력 누락처럼 들리지 않아야 한다.
- 재료가 소비됐다는 사실은 시각 정보와 함께 전달한다.

#### 단계 하락

- 실패음 이후 하강 방향이 느껴지는 별도 레이어를 사용한다.
- 하락 폭이 클수록 결과의 무게를 구분할 수 있지만, 정확한 하락 수치를 소리만으로 추측하게 만들 필요는 없다.
- 정확한 이전·현재 단계는 화면에 표시한다.

#### 영구 파괴

- 일반 실패와 혼동되지 않는 무겁고 명확한 파괴음을 사용한다.
- 파괴음만으로 손실 정보를 전달하지 않고 장비 이름, 강화 단계, 주요 수식어와 손실 요약을 화면에 함께 표시한다.
- 사운드를 끈 상태에서도 동일한 손실 정보를 제공한다.

### 이정표 구분

#### 일반 정밀강화

- 공통 타격과 결과음 위에 10단위 진입을 알리는 이정표 레이어를 추가한다.
- 일반 성공보다 길고 분명하지만 반복 템포를 과도하게 끊지 않는다.
- 실패한 정밀강화는 이정표 성공음을 재생하지 않는다.

#### 고위 정밀강화

- `+49 → +50` 확정 성공, 장비 진화와 대표 특수 수식어 공개를 단계적으로 구분하는 전용 사운드 전개를 사용한다.
- 일반 정밀강화와 동일한 단일 효과음으로 축소하지 않는다.
- 최초 연출은 완전 재생하고, 반복 시 단축해도 최종 진화 확정음은 유지한다.

### 장비 차이

- 무기, 방어구와 기타 장비의 재질·형태에 따라 충돌음과 공명음을 변형할 수 있다.
- 장비별 차이는 성공·실패·하락·파괴의 공통 결과 문법보다 우선하지 않는다.
- 모든 장비에 완전히 별개의 사운드 세트를 요구하지 않는다.

## 진동 문법

진동은 사운드와 같은 결과 계층을 사용하되, 진동만으로 정확한 확률·하락량·비용을 전달하지 않는다.

| 결과 | 진동 방향 |
|---|---|
| 저위험 성공 | 짧고 단단한 단발 |
| 실패·단계 유지 | 약한 단발 |
| 단계 하락 | 분리된 하강형 패턴 |
| 영구 파괴 | 무겁고 명확한 파괴 패턴 |
| 일반 정밀강화 성공 | 일반 성공보다 긴 이정표 패턴 |
| 고위 정밀강화 | 진화 공개 순서에 맞춘 단계형 패턴 |

- 진동 세기는 기기 차이를 고려해 지나치게 강한 기본값을 사용하지 않는다.
- 반복 강화에서 손 피로를 만들지 않도록 저위험 성공 진동은 짧게 유지한다.
- 영구 파괴와 고위 정밀강화는 일반 결과와 구분되지만 과도하게 긴 진동을 강제하지 않는다.
- 정확한 패턴 길이와 강도는 Android 실기기 플레이테스트에서 조정한다.

## 감각 정보의 중복 제공

중요한 결과는 특정 감각 하나에 의존하지 않는다.

- 사운드를 꺼도 시각·텍스트·숫자로 결과를 완전히 이해할 수 있어야 한다.
- 진동을 꺼도 결과와 위험 정보가 누락되지 않아야 한다.
- 모션 감소 설정에서도 성공·실패·하락·파괴·정밀강화·진화를 구분할 수 있어야 한다.
- 색상만으로 결과를 구분하지 않고 아이콘, 문구와 수치를 함께 사용한다.
- 화면을 보지 않아도 결과의 대략적 방향은 들을 수 있지만, 정확한 단계 변화와 비용은 화면에서 확인한다.

## 설정 분리

다음 설정은 서로 독립적으로 제공한다.

- 효과음 켜기·끄기
- 효과음 음량
- 진동 켜기·끄기
- 모션 감소
- 반복 강화 연출 단축·건너뛰기

한 설정을 변경했다고 다른 설정이 자동으로 강제 변경되지 않는다. 설정은 강화 확률, 비용, 판정 결과와 보상에 영향을 주지 않는다.

## 제작 범위 경계

- 강화 단계마다 개별 효과음을 제작하지 않는다.
- 모든 장비마다 완전히 별개의 결과 사운드 세트를 만들지 않는다.
- 기본·결과·이정표 레이어를 재조합해 두 번째 유사 장비와 결과를 확장할 수 있어야 한다.
- 장비별 개성보다 결과 판독 가능성과 공통 문법을 우선한다.

## 플레이테스트 조정 대상

- 기본 타격음 길이와 음량
- 반복 성공 사운드의 피로도
- 실패와 단계 유지의 구분 정도
- 단계 하락·영구 파괴의 무게 차이
- 일반 정밀강화와 고위 정밀강화의 사운드 격차
- 장비 재질 레이어의 수와 변형 폭
- 진동 패턴 길이와 강도
- 소형·중형 Android 기기의 실제 진동 차이

수치·자산 조정 시 다음 안전 경계를 지킨다.

- 결과를 소리나 진동 하나로만 전달하지 않는다.
- 반복 강화가 과도한 소음·진동 피로를 만들지 않는다.
- 영구 파괴가 일반 실패처럼 느껴지지 않아야 한다.
- 고위 정밀강화가 일반 정밀강화와 같은 무게로 느껴지지 않아야 한다.
- 무음·무진동·모션 감소 상태에서도 핵심 흐름을 완전히 진행할 수 있어야 한다.

```text
SOUND_AND_HAPTIC_LANGUAGE: LAYERED
BASE_LAYER: HAMMER_IMPACT_AND_METAL_RESONANCE
OUTCOME_LAYER: SUCCESS_FAILURE_DOWNGRADE_DESTRUCTION
MILESTONE_LAYER: PRECISION_AND_HIGH_PRECISION
EQUIPMENT_LAYER: MATERIAL_VARIATION_WITHIN_COMMON_GRAMMAR
SOUND_HAPTIC_DEPENDENCY_FOR_INFORMATION: FORBIDDEN
SOUND_AND_HAPTICS: INDEPENDENTLY_CONFIGURABLE
REDUCED_MOTION_AND_SILENT_PLAY: FULLY_SUPPORTED
EXACT_AUDIO_ASSETS_AND_HAPTIC_STRENGTH: PLAYTEST_TUNABLE
```
