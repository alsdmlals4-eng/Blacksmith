## 1. 목적

다음을 화면 단위로 고정한다.

1. 첫 실행 후 5분 안에 단조 손맛, 첫 강화, +5 완성·+10 도전의 의미를 이해하는 흐름
2. 장기 서버 기능인 명작 전당에서 `검증 랭킹`과 `레거시 전시`를 명확히 구분하는 흐름

첫 5분과 명작 전당은 같은 시점에 노출하지 않는다. 명작 전당은 +50 작품과 서버 기능이 해금된 이후의 장기 기능이다.

## 2. 첫 5분 성공 기준

초기 목표:

- 30초 안에 첫 망치 입력
- 60초 안에 첫 강화 화면 진입
- 첫 강화 중앙값 60초 이내
- 5분 전후에 +5 완성 또는 +10 도전의 차이 이해
- 확률·비용·최악 결과를 확인한 뒤 강화 실행
- 모닥의 안내 없이도 핵심 정보가 화면에 존재

+5 도달은 목표 시간이며 숨은 성공 보정으로 강제하지 않는다.

기존 초기 위험곡선과 다음 원칙을 사용한다.

- +1 기본 총성공률 100%
- +5 기본 총성공률 90%
- +29까지 파괴 결과 없음
- 유지 결과가 나왔을 때 재시도 가능한 초기 자원 제공
- 모든 실제 확률과 결과를 화면에 그대로 표시

## 3. 화면 흐름

```text
S00 복귀·미확인 결과 확인
→ S01 대장간 첫 화면
→ S02 단조 마무리
→ S03 제작 결과 공개
→ S04 강화 작업대
→ S05 강화 결과
→ S04~S05 반복
→ S06 +5 완성·+10 도전 결정
→ S07 다음 행동 안내
```

## 4. S00 — 복귀·미확인 결과 확인

첫 신규 실행에서는 건너뛴다.

기존 저장에 미확인 비가역 결과가 있을 때만 표시한다.

표시:

- 어떤 행동의 결과인지
- 장비 이름·이전/현재 단계
- 소비 자원
- 장비 상태
- 저장된 결과임을 알리는 문구

금지:

- 결과 재추첨
- 일반 대장간 화면을 먼저 조작
- 모닥 대사만으로 결과 처리

## 5. S01 — 대장간 첫 화면

### 사용자 목표

완성 직전 장비와 망치를 즉시 발견한다.

### 정보 위계

1. 중앙 장비
2. 타격 가능한 위치
3. 하단 망치 입력 영역
4. 최소 상태 표시
5. 모닥의 짧은 안내

### 최초 상태

- 장비: 완성 직전의 기본 철검
- 배경: 모루·화로·어두운 철과 숯
- 장식 메뉴: 축소 또는 잠금
- 고객·세계 탭: 존재는 표시하되 첫 타격 전 강조하지 않음

### 모닥

`불이 올랐어. 지금 쳐.`

### 입력

- 주요 타격 영역 최소 48dp
- 첫 입력을 작은 망치 아이콘 정확히 누르기로 제한하지 않음
- 타격 가능 영역을 한 번만 시각적으로 강조
- 색상 외에 윤곽·아이콘·짧은 문구 사용

## 6. S02 — 단조 마무리

### 목표 시간

0:00~0:30

### 입력·피드백

- 1~3회의 망치 입력
- 입력 즉시 금속 변형·불꽃·소리·진동 피드백
- 무음·무진동에서도 형태 변화와 진행 표시 유지
- 입력 속도에 따라 짧은 피버 피드백 가능

### 정보 제한

첫 단조에서 다음을 동시에 설명하지 않는다.

- 전체 제작 숙련
- 모든 재료 속성
- 고객 적합도
- 장비 연대기 전체
- +50 진화
- 명작 전당

### 완료

제작 결과를 원자적으로 저장한 뒤 S03으로 이동한다.

## 7. S03 — 제작 결과 공개

### 목표 시간

0:30~1:00

### 1차 공개

- 장비 이름
- 제작 등급
- 기본 가치
- 장비 범주·세부 종류
- 최초 연대기 한 줄

### 접힌 정보

- 상세 제작 재료
- 전체 수치
- 미래 수식어 슬롯
- 긴 연대기

### 다음 행동

`[강화해 보기]`

자동으로 강화하지 않는다.

### 제작 등급 설명

최초 한 번만 짧게 표시한다.

> 제작 등급은 이 작품이 처음 완성된 품질이며 강화 단계와 별개입니다.

## 8. S04 — 강화 작업대

### 목표 시간

1:00~3:00

### 정보 읽기 순서

```text
1. 현재 단계 → 목표 단계
2. 총성공률
3. 결과별 확률
4. 비용·재료
5. 최대 하락·파괴 여부
6. 보호 사용 가능 여부
7. 실행 버튼
```

### 초기 +1~+5 표시

- 파괴 없음 명시
- 하락 없음 구간이면 `단계 하락 없음` 표시
- 유지 가능성 표시
- 대성공과 성공 분리
- 확률표 합계 100.00%

### 행동

- `[강화]`
- `[전체 확률 보기]`
- `[비용 상세]`
- `[작품 정보]`

초기 저위험 구간에서는 길게 누르기를 요구하지 않는다.

### 화면 전환

- 강화 실행 후 추가 입력 잠금
- 판정·저장 완료 후 S05
- 저장 실패 시 성공 연출 금지

## 9. S05 — 강화 결과

### 표시

- 결과: 대성공·성공·유지
- 이전 단계 → 현재 단계
- 소비 자원
- 현재 작품 가치 변화
- 다음 강화 가능 여부

### 유지 결과

유지를 실패·오류처럼 표현하지 않는다.

```text
단계 유지
현재 작품은 안전합니다.
사용한 자원은 소비되었습니다.
```

선택:

- `[다시 시도]`
- `[작품을 완성]`
- `[작업대 나가기]`

+5 미만에서 완성 선택을 막지 않는다. 다만 +5가 첫 평균 흑자 지점이라는 정보는 가치 화면에서 공개한다.

### 반복

S04와 S05를 반복하되 다음을 지킨다.

- 결과 확인 후에만 재시도
- 빠른 연타 중복 판정 금지
- 반복 결과 연출 단축 가능
- 단계·비용·확률은 매 시도 갱신

## 10. S06 — +5 완성·+10 도전 결정

### 목표 시간

3:00~5:00 전후

### 진입

장비가 +5에 도달하면 한 번 표시한다.

### 비교 카드

#### 현재 작품 완성

- 현재 판매 기준가
- 예상 평균 흑자 여부
- 현재 제작 등급
- 현재 강화 단계
- 보관·일반 판매·고객 판매 가능

#### +10까지 도전

- +10에서 계보 수식어 후보 선택
- 추가 예상 비용
- 현재 구간 성공률·유지 위험
- +10까지 파괴 없음
- 더 높은 시장·고객·연대기 잠재력

### 버튼

- `[이 작품을 완성]`
- `[+10까지 도전]`
- `[자세히 보기]`

버튼을 좌우의 선악·추천 색으로 구분하지 않는다.

### 모닥

`여기서 완성해도 좋아.`

### 선택 저장

- 완성 선택: 작품 완성 상태 저장
- 도전 선택: 장비를 미완성으로 되돌리지 않고 다음 강화 구간 개방
- 선택만으로 추가 비용 소비 금지

## 11. S07 — 다음 행동 안내

### 완성 선택 후

우선순위:

1. 보관함에서 작품 확인
2. 일반 판매 설명
3. 방문 고객은 이후 흐름에서 소개

### 도전 선택 후

- 다음 목표 +10
- 계보 수식어 설명 한 줄
- 현재 필요한 예상 자원

### 금지

- 고객·세계·명작 전당을 한 번에 모두 튜토리얼
- 즉시 +49 테스트 픽스처로 강제 이동
- 완성 선택을 겁쟁이·낮은 보상으로 평가

Vertical Slice의 +49 대표작은 별도 다음 장면에서 이전 제작 이력이 있는 작품으로 소개한다.

## 12. 첫 5분 예외·복귀

### 앱 중단

- 단조 저장 전: 이전 상태 복귀
- 제작 저장 후: 같은 제작 결과 표시
- 강화 판정 저장 후: 같은 강화 결과 표시
- S06 선택 전: +5 결정 화면 재표시
- S06 선택 후: 저장된 선택 유지

### 자원 부족

초기 제공 자원은 +5 목표에서 유지 결과 1~2회를 재시도할 수 있어야 한다.

자원 부족 시:

- 부족 자원과 수량 표시
- 상점 전체 튜토리얼로 이탈시키지 않음
- Vertical Slice 테스트 픽스처에서 진행 불능이 되지 않도록 초기 자원 조정

## 13. 첫 5분 접근성

- 터치 대상 최소 48dp
- 텍스트 확대 시 단계·확률·비용·위험·버튼 유지
- 스크린 리더 순서가 시각 정보 위계와 일치
- 결과는 색상+아이콘+문구+숫자 사용
- 무음·무진동·모션 감소에서도 진행 가능
- 길게 누르기는 첫 5분 필수 입력이 아님
- 모닥이 포커스를 강제로 가져가지 않음

## 14. 첫 5분 관찰 지표

| 지표 | 목표 후보 |
|---|---|
| 첫 망치 입력 | 30초 이내 |
| 첫 강화 화면 진입 | 60초 이내 |
| 첫 강화 실행 중앙값 | 60초 이내 |
| +5·+10 차이 설명 | 6명 중 5명 이상 |
| 확률·비용·파괴 오해 | 차단 수준 오해 0건 |
| 잘못 누른 비가역 행동 | 0건 |
| 관찰자 개입 없는 첫 강화 | 6명 중 5명 이상 |

수치는 `PLANNING_CANDIDATE / TUNABLE`이다.

# 명작 전당 UX

## 15. 진입 조건

명작 전당은 다음 조건을 모두 만족할 때만 노출한다.

- 서버 기능이 실제 출시됨
- +50 이상 작품을 하나 이상 보유하거나 역사 기록으로 보유
- 네트워크 기능 설명을 확인

핵심 플레이와 첫 5분에는 노출하지 않는다.

오프라인 상태에서도 로컬 작품과 연대기를 볼 수 있으나 온라인 전당 목록은 연결 상태를 명확히 표시한다.

## 16. 최상위 구조

```text
[검증 랭킹]
[레거시 전시]
[내 작품]
```

### 검증 랭킹

서버 검증 흐름에 참여한 작품만 포함한다.

### 레거시 전시

서버 기능 출시 이전 오프라인 작품, 검증 불가능한 구버전 작품, 역사적 파괴 작품을 전시할 수 있다.

### 내 작품

등록 가능·등록 중·공개 중·등록 해제·역사 기록 상태를 관리한다.

## 17. 검증 상태 표시

색상만 사용하지 않는다.

| 상태 | 표시 |
|---|---|
| VERIFIED | 검증 아이콘 + `서버 검증 작품` |
| LEGACY | 기록 아이콘 + `레거시 전시` |
| DESTROYED_HISTORY | 파손 기록 아이콘 + `파괴된 역사적 작품` |
| PENDING | 처리 아이콘 + `등록 확인 중` |
| REJECTED | 경고 아이콘 + 구체적 등록 불가 이유 |
| DELISTED | 비공개 아이콘 + `공개 해제됨` |

`레거시`를 가짜·불법·열등한 작품처럼 표현하지 않는다. 검증 방식이 다르다는 뜻으로 설명한다.

## 18. 첫 진입 설명

두 문장 이내 기본 설명:

> 검증 랭킹은 서버에서 작품 기록을 확인한 +50 이상 작품을 비교합니다. 이전 오프라인 작품은 레거시 전시에서 기록과 외형을 공유할 수 있습니다.

세부 보기:

- 검증 랭킹에 필요한 데이터
- 레거시 전시가 순위에 포함되지 않는 이유
- 공개 정보와 비공개 정보
- 등록 해제·신고 방법

## 19. 작품 카드

### 공통 표시

1. 작품명
2. 강화 단계
3. 제작 등급
4. 계보·보조 수식어
5. 진화 형태
6. 현재 상태
7. 공개 제작자 별칭
8. 공개 연대기 요약
9. 검증·레거시 상태

### 금지

- 단일 종합 전투력 점수만 크게 표시
- 실명·계정 ID 기본 공개
- 검증과 레거시를 같은 순위 번호로 표시
- 파괴 작품을 현재 사용 가능한 작품처럼 표시

## 20. 검증 랭킹

기본 정렬:

```text
강화 단계
→ 제작 등급
→ 서버 검증 등록 시각
```

필터:

- 장비 범주·세부 종류
- 계보 수식어
- 제작 등급
- 진화 형태
- 시즌·역대

보상:

- 칭호
- 프로필·작품 프레임
- 전시 표식

게임 성능·강화 확률·경제 보상은 제공하지 않는다.

시즌 길이 12주는 후보값이며 서버 운영 기획 단계에서 재검증한다.

## 21. 레거시 전시

포함 가능:

- 서버 출시 이전에 제작된 오프라인 작품
- 이전 규칙 버전 작품
- 검증에 필요한 기록이 불완전한 작품
- 파괴 후 역사 기록만 남은 작품

표시:

- 작품이 생성된 게임 버전
- 검증 순위에 포함되지 않는 이유
- 공개 가능한 당시 기록
- 현재 사용 가능 여부

레거시 전시는 순위를 제공하지 않고 필터·감상·검색 중심으로 구성한다.

## 22. 등록 흐름

```text
내 작품 선택
→ 등록 자격 확인
→ 공개 정보 미리보기
→ 제작자 별칭 선택
→ 개인정보·신고 정책 확인
→ 등록 요청
→ 서버 검증
→ 검증 랭킹 또는 등록 불가 결과
```

### 자격 확인

- +50 이상
- 완성 상태
- 금지 이름 없음
- 서버가 요구하는 규칙 버전·검증 기록 보유

### 공개 정보

기본 공개:

- 작품 정보
- 공개 연대기 요약
- 자동 생성 별칭 또는 사용자가 승인한 별칭

비공개:

- 실명
- 로그인 식별자
- 로컬 저장 경로
- 전체 플레이 기록
- 내부 부정 탐지 데이터

## 23. 등록 실패

등록 실패가 로컬 작품에 영향을 주지 않는다.

실패 이유 예:

- 네트워크 오류
- 서버 점검
- 중복 요청
- 지원하지 않는 구버전
- 검증 기록 부족
- 이름 정책 위반

각 이유에 따라 재시도 가능 여부와 수정 방법을 표시한다.

`등록 실패`를 `작품이 무효·조작됨`으로 일괄 표현하지 않는다.

## 24. 공개 해제·신고

### 공개 해제

- 사용자가 언제든 실행 가능
- 공개 목록에서 제거
- 로컬 장비·연대기 유지
- 재등록 가능 여부 표시

### 신고

대상:

- 작품명
- 제작자 별칭
- 공개 연대기 문구

신고가 로컬 장비 삭제나 싱글플레이 제재로 자동 연결되지 않는다.

## 25. 파괴 작품

```text
무보호 파괴
→ 장비 객체 영구 소멸
→ 현재 검증 랭킹 제외
→ 기존 공개 기록은 DESTROYED_HISTORY로 전환 가능
→ 연대기와 등록 당시 정보만 보존
```

역사 기록에서 다음을 명확히 표시한다.

- 파괴됨
- 현재 사용 불가
- 최종 소유자
- 파괴 직전 강화 단계
- 종료 원인

복구·복제·새 소유권을 생성하지 않는다.

## 26. 접근성·오프라인

- 검증 상태를 색상만으로 구분하지 않음
- 필터·정렬 요소에 접근성 라벨 제공
- 긴 연대기는 펼치기 구조
- 오프라인에서는 마지막 캐시인지 현재 정보인지 표시
- 등록·삭제·신고 같은 네트워크 행동은 처리 상태와 결과를 명확히 표시
- 네트워크 실패로 로컬 작품 조작을 차단하지 않음

## 27. 검증 계약

1. 첫 5분 안에 명작 전당 노출 없음
2. 첫 강화 전 고객·세계 설명 강제 없음
3. 초기 +1~+5 실제 확률을 숨은 보정 없이 표시
4. 유지 결과 후 재시도 경로 제공
5. +5 완성과 +10 도전이 동등한 유효 선택으로 표시
6. 검증 랭킹과 레거시 전시를 다른 탭·상태로 구분
7. 레거시 작품에 순위 번호 미표시
8. 등록 실패가 로컬 장비 상태를 변경하지 않음
9. 공개 해제 후 로컬 기록 유지
10. 파괴 작품이 현재 사용 작품 랭킹에서 제거됨
11. 파괴 역사 기록이 복구 권한을 만들지 않음
