## 2. 생성 시점과 고정성

- 제작 등급은 최초 직접 단조 완료 판정에서 한 번만 결정한다.
- `전설`도 후천 승격이 아니라 최초 제작 판정에서만 극희귀하게 발생한다.
- 같은 작품 UID에서는 제작 등급과 등급 수식어가 영구 고정된다.
- 강화 성공·실패·단계 하락·대파·복원·감정·전시·명성·소유권·상속·연대기로 변경되지 않는다.
- 완전히 새로운 UID로 다시 제작한 경우에만 제작 등급을 새로 판정한다.
- 감정은 숨겨진 등급을 확인할 수는 있지만 등급을 높이거나 낮추지 않는다.

## 3. 네 단계의 역할

### 보통

- 설계된 기능과 안전 기준을 충족한다.
- 치명적 결함이 있는 실패품을 의미하지 않는다.
- 일상 장비와 반복 제작의 정상 기준선이다.

### 우수

- 마감 정밀도·구조 안정성·균형이 평균보다 좋다.
- 같은 작품 종류와 주재료의 보통 등급보다 기본 성능·가치가 높을 수 있다.
- 정확한 수치 차이는 `BASELINE_TEST_PRESET`이다.

### 걸작

- 제작자의 기술이 뚜렷하게 드러나는 희귀한 고완성도 결과다.
- 기술적 결함이 거의 없고, 동급 재료의 제작 결과 중 최고 수준에 속한다.
- 높은 제작 등급이지 예술성 최고 단계나 역사적 명성을 뜻하지 않는다.

### 전설

- 제작 순간에만 등장 가능한 극희귀 출생 등급이다.
- 시대 최고 수준의 기술적 완성도를 뜻하지만, 작품이 이미 유명하거나 역사적이라는 뜻은 아니다.
- `전설`이라는 이름만으로 촉매 수식어·연대기 수식어·예술성 최고치·최강 전투 성능을 자동 획득하지 않는다.
- 정확한 등장 확률과 영향 요인은 후속 밸런스 Gate의 `BASELINE_TEST_PRESET`이다.

## 4. 다른 작품 축과의 경계

```text
제작 등급 = 최초 제작의 기술적 완성도
예술성 = 외형·세공·조형·미적 가치
촉매 수식어 = 정밀강화 촉매 계보와 선택의 흔적
연대기 수식어 = 작품이 실제로 겪은 후천적 역사
```

따라서 다음 조합이 모두 가능하다.

```text
[전설] 강철 장검
→ 제작 완성도는 최고지만 촉매·연대기는 아직 없음

[보통] 찬란한 은합금 의장검 - 왕의 대관식을 함께한
→ 제작 완성도는 보통이지만 예술성과 연대기 가치는 높을 수 있음
```

## 5. 장비명 표시

등급 수식어는 장비명 맨 앞의 대괄호 슬롯을 사용한다.

```text
[등급 수식어] 촉매 수식어 기본 작품명 - 연대기 수식어
```

예시:

```text
[보통] 강철 장검
[우수] 균형 잡힌 강철 장검
[걸작] 예리한 강철 장검 - 투기장의 승자
[전설] 별빛을 머금은 운철 대검 - 심연에서 돌아온
```

기존 임시 예시 `[명품]`은 제작 등급 표시명으로 더 이상 사용하지 않는다.
