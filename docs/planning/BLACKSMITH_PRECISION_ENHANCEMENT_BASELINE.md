# 블랙스미스 정밀강화 기준선

> 상태: `PLANNING_IN_PROGRESS`
>
> 기준일: 2026-07-26
>
> 효력: 이 문서는 `BLACKSMITH_MASTER_GAME_DESIGN_PLANNING.md`의 10강 정밀강화 규칙과 관련 미결정 사항을 대체·보완한다. 충돌 시 이 문서가 우선한다.
>
> 범위: 정밀강화의 장비 데이터 구조, 10강 이정표 행동, 실패 처리, 고위 정밀강화와 POC 체험 기준.

## 1. 핵심 결정

모든 장비는 다음 정밀강화 요소를 가진다.

1. **등급 관련 요소 1개**
2. **수식어 관련 요소 2개**

정밀강화는 모든 10강 이정표에서 한 번 발생하며, 플레이어는 현재 장비 상태에 맞는 행동 하나를 선택한다.

```text
+9 → +10 강화 성공
→ 정밀강화 행동 1개 선택
→ 결과 확정
→ 해당 이정표 종료
→ 다음 강화 구간 개방
```

정밀강화 실패로 잃는 것은 **이번 시도에 투입한 강화 재료·보조재료·촉매·특수 재료**뿐이다.

정밀강화 실패는 다음을 잃거나 낮추지 않는다.

- 장비 강화 단계
- 제작 완성도
- 이미 결정된 장비 등급
- 기존 수식어
- 기존 수식어 단계
- 장비 이력·소유권·역사 기록
- 장비 내구·사용 가능 상태

일반 강화 실패의 단계 하락·손상·파괴 규칙과 정밀강화 실패는 별도 시스템이다.

---

## 2. 제작 완성도와 정밀 등급의 분리

기존 POC와 제작 시스템의 `제작 완성도`는 유지한다.

### 제작 완성도

- 제작 순간 확정한다.
- 재료, 시설, 제작 숙련, 분야 숙련, 제작법 친숙도의 영향을 받는다.
- 기본 성능, 기본 가치, 최초 등급 결정의 가중치에 영향을 준다.
- 일반 강화와 정밀강화로 직접 상승하지 않는다.
- 기존 5단계 데이터 구조를 재사용한다.

```text
미숙한 → 평범한 → 정교한 → 명품 → 완벽한
```

### 정밀 등급

- 장비의 정밀강화 `등급 관련 요소 1개`에 저장한다.
- 최초에는 `미결정` 상태일 수 있다.
- `[등급 결정]`으로 최초 등급을 확정한다.
- `[등급 강화]`로 이미 결정된 등급을 한 단계씩 높일 수 있다.
- 제작 완성도가 높을수록 최초 등급 결정의 좋은 결과 가중치가 높아진다.
- 제작 완성도와 정밀 등급은 UI에서 별도 항목으로 표시한다.

이 분리는 제작 결과의 고유성과 장기 강화 성장의 선택을 동시에 유지한다.

## 3. 장비당 정밀강화 구조

장비 데이터는 다음 세 개의 정밀강화 위치를 가진다.

| 위치 | 개수 | 가능한 행동 |
|---|---:|---|
| 정밀 등급 | 1 | 등급 결정, 등급 강화 |
| 수식어 슬롯 A | 1 | 수식어 추가, 수식어 강화 |
| 수식어 슬롯 B | 1 | 수식어 추가, 수식어 강화 |

총 수식어 슬롯은 **2개로 고정**한다.

- 세 번째 수식어 슬롯은 추가하지 않는다.
- 슬롯이 비어 있으면 `[수식어 추가]`를 선택할 수 있다.
- 슬롯이 채워져 있으면 해당 슬롯에 `[수식어 강화]`를 선택할 수 있다.
- POC 범위에서는 기존 수식어 교체·삭제·재각인을 제공하지 않는다.
- 수식어 교체 기능은 출시 후 별도 필요성이 검증되기 전까지 추가하지 않는다.

---

## 4. 정밀강화 행동 네 종류

### 4.1 `[등급 결정]`

조건:

- 정밀 등급이 아직 `미결정`인 장비

규칙:

- 행동 결과로 반드시 하나의 정밀 등급을 확정한다.
- 등급 결정은 빈 결과가 없는 가중 결과 판정이다.
- 낮은 등급 결과는 실패가 아니라 유효한 결과다.
- 제작 완성도, 사용 재료, 촉매, 제작·강화 숙련이 결과 가중치에 영향을 준다.
- 한 번 결정된 등급은 다시 `[등급 결정]`할 수 없다.

### 4.2 `[등급 강화]`

조건:

- 정밀 등급이 결정된 장비
- 현재 정밀 등급이 최고 단계 미만

규칙:

- 성공하면 정밀 등급이 정확히 한 단계 상승한다.
- 실패하면 정밀 등급은 유지되고 투입 재료만 소모한다.
- 한 번의 이정표에서 두 단계 이상 상승하지 않는다.
- 최고 등급에서는 선택할 수 없다.

### 4.3 `[수식어 추가]`

조건:

- 비어 있는 수식어 슬롯이 존재하는 장비

규칙:

- 대상 빈 슬롯 하나를 지정한다.
- 성공하면 재료·촉매 후보군에서 수식어 계보와 최초 단계를 결정한다.
- 실패하면 슬롯은 빈 상태로 유지되고 투입 재료만 소모한다.
- 성공한 수식어의 정체성과 계보는 장비에 영구 기록한다.

### 4.4 `[수식어 강화]`

조건:

- 하나 이상의 수식어 슬롯이 채워진 장비
- 대상 수식어가 최고 단계 미만

규칙:

- 강화할 수식어 슬롯 하나를 지정한다.
- 성공하면 같은 수식어 계보에서 한 단계 상승한다.
- 실패하면 수식어와 단계는 유지되고 투입 재료만 소모한다.
- 수식어 정체성을 다른 계보로 무작위 변경하지 않는다.

---

## 5. 이정표 소비와 다음 구간 개방

각 10강 이정표는 **정밀강화 결과 확정 1회**를 제공한다.

- 등급 결정의 결과가 확정되면 이정표가 종료된다.
- 등급 강화·수식어 추가·수식어 강화의 성공 또는 실패가 확정되면 이정표가 종료된다.
- 실패한 행동을 같은 이정표에서 다시 시도할 수 없다.
- 다음 시도는 다음 10강 이정표에서 가능하다.
- 결과가 실패여도 해당 이정표는 완료되며 다음 강화 구간이 열린다.
- 단, 현재 메인 빌드에 필요한 `[강화 한계 돌파]` 노드가 없으면 활성 한계에서 추가 강화가 차단된다.

이 규칙은 무한 재시도로 성공을 확정하는 문제를 막고, 각 10강 선택을 장비 성장 이력으로 남긴다.

---

## 6. 일반 정밀강화와 고위 정밀강화

### 일반 정밀강화

- 모든 10강 이정표에서 선택 가능하다.
- 일반 강화 재료, 보조재료, 촉매를 사용한다.
- 네 가지 행동 모두 수행할 수 있다.
- 일반 수식어 계보와 일반 등급 성장 범위를 사용한다.

### 고위 정밀강화

- `+50` 이후 10강 이정표에서 선택 가능하다.
- 일반 정밀강화 입력에 특수 재료를 추가한다.
- 네 가지 행동의 상위 결과 풀을 사용한다.
- 희귀·초희귀 수식어 계보 또는 고위 등급 강화 기회를 제공한다.
- 고위 정밀강화 실패 시 특수 재료를 포함한 투입 재료만 소모한다.
- 실패해도 장비 상태는 유지되고 이정표는 종료된다.
- 특수 재료 숙련은 기존 규칙대로 계정 도감에 누적한다.

일반 정밀강화를 선택하거나 고위 정밀강화 결과를 확정하면 같은 이정표의 다른 선택지는 소멸한다.

## 7. 재료 조합과 고정 조합

정밀강화 입력은 다음으로 구성한다.

1. 기본 강화 재료
2. 보조재료
3. 촉매
4. 고위 정밀강화 시 선택적 특수 재료

### 미등록 조합

- 후보 수식어 계열과 등급 방향을 가중 무작위로 결정한다.
- 속성·성질이 호환되면 후보군이 좁아진다.
- UI에는 예상 계열과 호환도 이유를 단계형으로 표시한다.

### 등록된 고정 조합

- 성공 시 결과 수식어의 정체성과 핵심 계보를 확정한다.
- 성공 자체는 보장하지 않는다.
- 성공한 수식어의 세부 강도는 `낮음 / 표준 / 높음`의 좁은 범위에서 결정한다.
- 수식어 강화 시에는 기존 계보를 유지하고 단계만 올린다.

POC의 대표 고위 조합은 기존 예시를 사용한다.

```text
[바람의 숨결]
+ [바람의 오브]
+ [폭풍군주의 핵]
= 성공 시 [폭풍왕의 가호를 받은] 계보
```

## 8. UI와 정보 표시

정밀강화 화면은 다음을 명확히 구분한다.

- 제작 완성도
- 정밀 등급과 다음 단계
- 수식어 슬롯 A·B
- 현재 선택 가능한 네 행동
- 대상 위치
- 예상 결과 계열
- 투입 재료
- 성공 시 변화
- 실패 시 `투입 재료만 소모, 장비 상태 유지`
- 해당 이정표가 결과 확정 후 종료된다는 경고
- 다음 활성 강화 한계와 필요한 `[강화 한계 돌파]` 노드

실패 결과 안내는 다음 형식을 사용한다.

```text
정밀강화 실패
- 소모: 철광석 3, 바람의 숨결 1, 촉매 1
- 유지: +50, 정밀 등급, 수식어 A·B, 장비 이력
- 이정표: 완료
```

색상만으로 성공·실패·슬롯 상태를 구분하지 않는다.

## 9. POC 확정 경로

통합 POC는 최대 `+60`까지 제공해 네 행동과 고위 정밀강화를 모두 체험할 수 있게 한다.

권장 안내 경로:

```text
+10: 등급 결정
+20: 수식어 추가 A
+30: 수식어 추가 B
+40: 등급 강화
+50: 고위 정밀강화로 수식어 강화 A
+60: 수식어 강화 B 또는 등급 강화
```

이 경로는 안내일 뿐 강제 순서는 아니다. 플레이어는 조건을 충족하는 다른 행동을 선택할 수 있다.

POC에는 다음 결과 fixture를 모두 제공한다.

- 등급 결정 결과
- 등급 강화 성공
- 수식어 추가 성공
- 수식어 추가 실패
- 수식어 강화 성공
- 고위 정밀강화 실패
- 등록 조합 성공

실패 fixture에서도 장비 상태는 유지되고 재료만 소모되는지 자동 검증한다.

## 10. 폐기·대체되는 규칙

다음 해석은 최신 기획에서 사용하지 않는다.

- 장비당 수식어 슬롯 수 미정
- 10강마다 수식어 슬롯이 계속 증가하는 구조
- 정밀강화 실패 시 강화 단계 하락
- 정밀강화 실패 시 기존 수식어 삭제·약화
- 정밀강화 실패 시 장비 손상·파괴
- 같은 이정표에서 재료만 있으면 성공할 때까지 반복하는 구조
- 고정 조합이 성공률까지 100% 보장하는 구조
- 제작 완성도와 정밀 등급을 같은 값으로 덮어쓰는 구조

## 11. 남은 밸런스 항목

다음은 구현 가능한 데이터 항목으로 정의하되, POC 플레이테스트 후 조정한다.

- 행동별 기본 성공률
- 제작 완성도의 등급 결정 가중치
- 일반·고위 정밀강화의 재료 비용
- 등급·수식어 단계별 성능 수치
- 특수 재료 숙련 획득량과 보정 상한
- 고정 조합의 세부 강도 범위

이 값들은 `POC_TUNABLE`이며 시스템 구조를 변경하지 않고 데이터로 조정해야 한다.
