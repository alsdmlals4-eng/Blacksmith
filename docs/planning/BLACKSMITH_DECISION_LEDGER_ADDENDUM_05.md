## 2. 최신 정밀강화 행동

```text
등급 관련 1개
├─ 등급 미결정: [등급 결정]
└─ 등급 결정됨: [등급 강화]

수식어 관련 2개
├─ 빈 슬롯: [수식어 추가]
└─ 채운 슬롯: [수식어 강화]
```

각 10강 이정표에서 가능한 행동 하나를 선택한다.

```text
행동 선택
→ 재료 투입
→ 성공 또는 실패 결과 확정
→ 이정표 소비
→ 장비 상태 저장
→ 다음 강화 구간 확인
```

실패 상태 불변 항목:

- 강화 단계
- 제작 완성도
- 정밀 등급
- 수식어 슬롯과 단계
- 장비 이력
- 사용 가능 상태

## 4. POC와 출시 밸런스의 상태 분리

### `POC_CONFIRMED`

- 구현·자동 검증·사람 검증에 사용할 정확한 POC 값
- 짧은 세션에서 시스템을 체험하기 위한 압축 값
- 출시 경제의 최종 수치로 재사용하지 않음

### `CONFIRMED_DIRECTION`

- 출시 구조와 책임 경계
- 예: 초기 출시 최대 강화 +100 방향, 10강 단위 한계 돌파
- 실제 비용·확률·보상 곡선은 데이터와 플레이테스트로 조정

### `POC_TUNABLE`

- 시스템 구조를 바꾸지 않고 데이터로 조정 가능한 값
- 행동별 성공률, 비용, 보상, 효과량, 경험량
- 조정 시 결정 원장을 수정할 필요는 없지만 변경 이유와 테스트 결과를 기록해야 함

## 5. POC 완료의 필수 체험 목록

다음 항목 중 하나라도 플레이 가능한 대표 경로가 없으면 통합 POC를 완료로 판정하지 않는다.

- 제작 완성도
- 일반 강화
- 정밀 등급 결정·강화
- 수식어 추가·강화
- 정밀강화 재료 손실 실패
- 고위 정밀강화와 특수 재료
- 강화 한계 돌파와 메인 빌드 포인트 경쟁
- 일반 강화 단계 하락·손상·파괴
- 보호석·회복석·보관
- 공개시장
- 고객 거래
- 고객 조언·자율성·신뢰·재방문
- 군사 보급
- 국가 사건
- 밀수와 적발
- 역사 장비·전시·수집가 흥정
- 장비 이력·뉴스·게임 날짜 종료

## 6. 폐기·대체 결정

다음 구형 해석은 `REJECTED` 또는 `SUPERSEDED`다.

- 정밀강화 수식어 슬롯 수를 계속 미정으로 유지
- 10강마다 수식어 슬롯 추가
- 정밀강화 실패 시 강화 단계 하락·장비 손상·파괴
- 정밀강화 실패 뒤 같은 이정표에서 성공할 때까지 재시도
- 수식어 추가가 기존 수식어를 무작위 교체
- 제작 완성도를 정밀강화로 직접 덮어쓰기
- 통합 POC를 기존 검투사 +10 경로만으로 완료 판정
- 자동 테스트 통과만으로 POC_ACCEPTED 선언
- 사람·Android·접근성·성능 검증 없이 Production 완료 선언

## 7. 구현 전 게이트

현재 상태는 계속 `PLANNING_IN_PROGRESS`다.

- 이 문서와 관련 POC 기준선은 구현 가능한 수준의 설계를 제공한다.
