## 1. 프로젝트 약속

> 한 명의 대장장이가 제한된 하루 작업량 안에서 작품을 만들고, 강화 위험 앞에서 멈출지 더 도전할지 선택하며, 작품이 고객과 세계에서 겪은 생애와 결과를 돌려받는 Android 세로형 제작 게임.

```text
강화의 즉각 판단
→ 작품에 제작자의 선택을 새김
→ 고객과 세계에 보냄
→ 같은 UID 작품의 생애 결과를 돌려받음
→ 다음 강화·복원·제작 이유가 생김
```

## 2. 작품 구조

```text
작품 UID
├─ 작품 종류·주재료·기본 작품명
├─ 제작 등급·GRADE_AFFIX
├─ 공격·방어·내구·조작성·예술성 등 능력치
├─ 강화 단계·방식 이력·촉매 이력
├─ CATALYST_AFFIX
├─ CHRONICLE_AFFIX
└─ 소유·사건·손상·복원·계승 기록
```

현재 수식어는 정확히 다음 세 슬롯이다.

```text
GRADE_AFFIX / CATALYST_AFFIX / CHRONICLE_AFFIX
```

일반 수식어 A·B 구조 재도입 금지. 보조재료 슬롯 재도입 금지.

## 3. 제작 등급

제작 등급은 최초 직접 단조의 기술적 완성도다.

```text
[보통] → [우수] → [명품] → [걸작] → [전설]
```

```text
CRAFT_NORMAL / CRAFT_SUPERIOR / CRAFT_FINE / CRAFT_MASTERWORK / CRAFT_LEGENDARY
```

- 최초 직접 단조 완료 시 한 번 확정
- 동일 UID에서 영구 고정
- 제작 후 승격·강등 없음
- `전설`은 최초 제작 판정에서만 극희귀하게 발생
- 강화·촉매·연대기·감정·명성·복원·상속으로 변경되지 않음
- `전설`은 예술성 10·촉매 수식어·연대기 수식어·모든 상황 최강을 보장하지 않음
- 정확한 확률·성능·가치 배율은 `BASELINE_TEST_PRESET`

과거 4단계 `[보통] → [우수] → [걸작] → [전설]`은 `[대체됨]`이다. 과거 `STANDARD / GOOD / PERFECT`는 `HISTORICAL_IMPLEMENTED_VALUE`이며 과거 3단계 구현 PASS를 현재 5단계 제품 구현 PASS로 해석 금지.

## 4. 예술성

```text
예술성 1~10
예술성 7/10
```

예술성은 이름이 붙는 등급이 아니라 무기·작품 능력치의 하나다.

- 정수 `1~10`, 소수점 없음
- 예술성 단계명 없음
- 무기 상세에서 다른 능력치와 함께 표시
- 조형·세공·표면 마감·장식 조화·감정 가치를 표현
- 판매 가치와 귀족·후원자·수집가·전시·감정·증여·의식 수요에 기여 가능
- 전투 성능을 기본적으로 올리지 않음
- 모든 속성을 일괄 증폭하는 품질 배율이 아님
- 강화 단계만으로 자동 상승하지 않음
- 제작 등급은 예술성을 자동 확정하지 않음

기존 임시 `BASIC / REFINED / MASTERWORK / MASTERPIECE` 시각 단계는 `[대체됨]`이다.

## 5. 강화와 촉매

일반 강화는 한 입력에 한 결과다.

정밀강화:

```text
+10 / +20 / +30 / +40 / +50
주재료 맥락 + 강화 방식 + 촉매 한 개
```

강화 방식은 세부 수치 방향을, 촉매는 촉매 수식어 후보 계보와 확률을 책임진다.

- 날 보강
- 충격 흡수
- 경량화
- 균형 조정
- 예술 마감
- 환경 처리

촉매 수식어는 `EMPTY → SEED → DEVELOPED → EVOLVED → MASTERED`로 성장할 수 있다. 무관한 계보로 무작위 교체하거나 같은 이정표를 무한 리롤하지 않는다.

## 6. 연대기와 장비명

```text
[등급 수식어] 촉매 수식어 기본 작품명 - 연대기 수식어
```

```text
[명품] 예리한 강철 장검 - 투기장의 승자
```

- 빈 촉매 수식어 생략
- 빈 연대기 수식어는 하이픈과 함께 생략
- 현재 연대기 하나만 이름에 표시
- 연대기 수식어를 누르면 UID 기반 읽기 전용 하단 상세 패널
- 형성 사건·주요 타임라인·진화 계보·소유·손상·복원 기록 표시
- 기록에 없는 사건과 미해결 미래 결과를 만들지 않음
