## 1. 프로젝트 약속

> 한 명의 대장장이가 제한된 하루 작업량 안에서 작품을 직접 만들고, 강화 위험 앞에서 멈출지 더 도전할지 선택하며, 그 작품이 고객과 세계에서 겪은 생애와 결과를 돌려받는 Android 세로형 제작 게임.

차별화:

> 장비를 대량 생산하는 게임이 아니라 작품의 출생·성장·소유·손상·복원·사건 기록을 만드는 대장장이 게임.

## 2. 핵심 재미

```text
강화의 즉각 판단
→ 작품에 제작자의 선택을 새김
→ 고객과 세계에 작품을 보냄
→ 같은 UID 작품의 생애 결과를 돌려받음
→ 다음 강화·복원·제작 이유가 생김
```

- **즉각 동력:** 강화 성공·실패, 멈춤·추가 도전
- **세션 의미:** 작품 선택, 고객 적합도, 일정 준비
- **장기 보상:** 작품 UID의 연대기, 재방문, 복원, 계승

## 6. 제작 책임

### 작품 종류

무기·방어구·금속 장신구·의장품 등 Blacksmith가 제작 가능한 금속 작품의 형태를 정한다.

### 주재료

- 기본 작품명
- 기본 성능 범위
- 재료 시각 정체성
- 기본 가치와 제작 난이도

희귀 주재료가 모든 상황의 만능 상위호환이 되어서는 안 된다.

### 제작 등급

- 직접 단조 완료 시 확정
- 현재 baseline ID: `STANDARD / GOOD / PERFECT`
- 정확한 한국어 표시명은 별도 콘텐츠·현지화 Gate
- 같은 작품 UID에서는 영구 고정
- 강화·촉매·사건·복원으로 변경되지 않음
- 기존 제작 등급 효과를 다시 더하는 중복 배율이 아님

## 7. 강화

### 일반 강화

- 한 입력에 한 결과
- 모든 단계에서 강화 방식·촉매 선택을 강제하지 않음
- 비용·확률·위험·소비 자원을 판정 전에 표시
- 정확한 수치는 버전형 테스트 프리셋

### 정밀강화

이정표:

```text
+10 / +20 / +30 / +40 / +50
```

입력:

```text
주재료 맥락 + 강화 방식 + 촉매 한 개
```

강화 방식:

1. 날 보강 — 공격력·정밀성
2. 충격 흡수 — 방어력·내구도
3. 경량화 — 무게 감소·취급성
4. 균형 조정 — 취급성·안정성
5. 예술 마감 — 예술성·가치
6. 환경 처리 — 환경 대응·특화

강화 방식은 세부 수치 방향을 책임지고, 촉매는 촉매 수식어의 후보 계보와 확률을 책임진다.

## 8. 세 수식어

현재 작품 수식어 슬롯은 정확히 세 개다.

```text
GRADE_AFFIX
CATALYST_AFFIX
CHRONICLE_AFFIX
```

과거 `일반 수식어 A·B + 사건 수식어` 구조는 `[대체됨]`이다.

### 등급 수식어

- 최초 제작 완료 시 즉시 생성
- 제작 등급만 반영
- 동일 UID에서 변경 불가
- 등급 성능을 중복 가산하지 않음

### 촉매 수식어

```text
EMPTY → SEED → DEVELOPED → EVOLVED → MASTERED
```

- 최초 제작 시 `EMPTY`
- 정밀강화 촉매의 현재·누적 이력으로 확률적 생성·성장·분기·변형
- 같은 계보 반복은 강화 가능성을 높임
- 호환 계보 전환은 분기 가능성을 높임
- 희귀 호환 이력은 혼합 변형 후보를 추가
- 무관한 수식어로 무작위 교체하지 않음
- 작품 연대기가 촉매 수식어를 직접 변경하지 않음

### 연대기 수식어

- 최초 제작 시 `EMPTY`
- 고객·사건·사용·손상·복원·전시·증여·상속 등 의미 있는 작품 기록으로 생성·진화
- 촉매와 제작 등급이 직접 생성·변경하지 않음
- 낮은 위험 반복 사건으로 무한 파밍하지 않음
- 현재 수식어와 과거 진화 계보를 UID에 보존

## 9. 장비명과 상세 표시

```text
[등급 수식어] 촉매 수식어 기본 작품명 - 연대기 수식어
```

예시:

```text
[명품] 예리한 강철 장검 - 투기장의 승자
```

이 예시의 정확한 한국어 등급 라벨은 임시 표현이다. 제작 등급과 예술성 시각 단계에 같은 `명품`이 중복되는 문제는 후속 Decision에서 분리한다.

- 빈 촉매 수식어는 생략
- 빈 연대기 수식어는 하이픈과 함께 생략
- 장비명에는 현재 연대기 수식어 하나만 표시
- 데이터는 세 독립 필드로 저장

연대기 수식어를 누르면 현재 장비 맥락을 유지하는 읽기 전용 하단 패널을 연다.

표시 항목:

- 현재 연대기 수식어와 요약
- 최초 형성 사건
- 주요 타임라인
- 수식어 진화 계보
- 현재 조건부 효과·위신·감정 가치
- 소유자·고객·결과
- 큰 손상·복원·상실·회수·증여·상속 기록

기록에 없는 사건이나 미해결 미래 결과를 만들지 않는다.

## 10. 예술성

- 새 작품 가치 수치는 `예술성` 하나
- 정수 `1~10`, 소수점 없음
- 실용성은 공격·방어·내구·무게·취급·안정성·환경 대응으로 표현
- 강화 단계만으로 예술성이 자동 상승하지 않음
- 예술 마감, 촉매 이력, 강화 결과, 예술성 계열 수식어가 영향을 줄 수 있음
- 고예술성 작품이 모든 고객에게 최고 수익을 보장하지 않음

현재 시각 프리셋:

```text
BASIC 1~2
REFINED 3~5
MASTERWORK 6~8
MASTERPIECE 9~10
```

정확한 한국어 시각 단계 명칭은 제작 등급 수식어와 겹치지 않게 별도 확정한다.

## 11. 고객

초기 방문 고객:

- 검투사
- 모험가
- 군인
- 귀족

귀족 수요에는 예술성·희소성·가문 위신·후원·선물·수집·의식·상속이 포함된다. 귀족 전용 신규 능력치는 만들지 않고 판단력을 주축으로 사용한다.

고객 능력:

```text
기량 / 체력 / 판단력
각 정수 1~10
```

사건 위험도도 정수 `1~10`이다. 판매 전후 예상 성공률은 약 10% 단위, `5~95%` 범위로 표시하며 정확한 보정치는 테스트 프리셋이다.

## 12. 개인 일정과 세계 일정

### 개인 일정

- 고객 방문과 판매·납품으로 활성화
- 고객 재방문 없이 하루 종료마다 최대 한 번 진행 판정
- 판매 당일 최종 결과까지 즉시 해결하지 않음
- 결과가 고객 상태, 작품 UID, 다음 제작·복원 판단을 남김

### 세계 일정

- 특정 날짜와 규모를 사전 예고
- 작품·도구·조언을 준비 기여로 누적
- 준비 체크포인트와 예정 날짜에서 판정
- 세계 변화와 고객·작품 후속 결과를 분리해 표시

과거 고정 `3일 결과 / 4일 재방문`은 한 개인 일정의 역사적 테스트 예시이며 모든 세계 일정의 상태 머신이 아니다.

## 15. 피로도와 날짜

- 피로도는 성공률 벌점이 아니라 제한된 하루의 작업 우선순위 자원
- 날짜는 플레이어가 하루를 끝낼 때 진행
- 고객·개인 일정·세계 일정 결과의 공통 시간축
- 빈 대기나 날짜 넘기기 반복이 최적해가 되어서는 안 됨

정확한 피로도 비용과 회복량은 테스트 프리셋이다.

## 16. 실패·손상·복원

R1 승인 기반:

- 일반 실패는 작품 UID와 역사를 자동 삭제하지 않음
- 손상·대파·잠금·복원은 작품 생애와 다음 행동을 만듦
- 동일 이정표 보상 중복 획득 금지
- 완전 파괴는 명시적이고 충분히 고지된 선택에서만 허용
- 과거 UID와 역사 기록은 보존

완전 파괴와 작품 애착의 감정적 정합성은 후속 사람 플레이 검증 대상이다.

## 17. 자동 작업 경계

자동 작업은 저위험 반복 제작·강화 편의만 제공한다. 다음 판단을 자동 통과하거나 최적화하지 않는다.

- 주재료 선택
- 제작 결과 평가
- 정밀강화 방식
- 촉매 선택
- 강화 위험과 멈춤 판단
- 고객 적합도와 작품 소유권
- 날짜 종료와 주요 일정 대응

## 18. 모바일·접근성 원칙

- Android portrait

- 한 화면에 중요한 판단 하나
