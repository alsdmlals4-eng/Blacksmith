
## 3. 제작 등급

제작 등급은 최초 직접 단조의 기술적 완성도다.

```text
[보통] → [우수] → [명품] → [걸작] → [전설]
```

```text
CRAFT_NORMAL / CRAFT_SUPERIOR / CRAFT_FINE / CRAFT_MASTERWORK / CRAFT_LEGENDARY
```

- 최초 직접 단조 완료 시 한 번 확정
- 동일 UID에서 영구 고정
- 제작 후 승격·강등 없음
- `전설`은 최초 제작 판정에서만 극희귀하게 발생
- 강화·촉매·연대기·감정·명성·복원·상속으로 변경되지 않음
- `전설`은 높은 예술성·촉매 수식어·연대기 수식어·모든 상황 최강을 보장하지 않음
- 정확한 확률·성능·가치 배율은 `BASELINE_TEST_PRESET`

과거 4단계는 `[대체됨]`이다. 과거 `STANDARD / GOOD / PERFECT`는 `HISTORICAL_IMPLEMENTED_VALUE`이며 과거 3단계 구현 PASS를 현재 5단계 제품 구현 PASS로 해석 금지.

## 4. 예술성

대표 원수치 표기: `예술성 27`.

```text
공격력  42
내구도  31
조작성  18
예술성  27
```

- `0` 이상의 정수, 소수점 없음
- 고정 설계 최대치 없음
- 분모·별점·백분율·예술성 단계명 없음
- 다른 능력치와 함께 원수치 표시
- 조형·세공·표면 마감·장식 조화·감정 가치를 표현
- 판매·감정 가치와 귀족·후원자·수집가·전시·증여·의식 수요에 기여 가능
- 전투 성능을 기본적으로 올리지 않음
- 모든 속성을 일괄 증폭하는 품질 배율이 아님
- 강화 단계만으로 자동 상승하지 않음
- 제작 등급이 예술성의 고정 상한을 만들지 않음
- 기술적 자료형 한계는 콘텐츠 최대치가 아님

`예술성 0`은 미적 투자가 거의 없는 정상 기능품이다. `[전설] / 예술성 3`과 `[보통] / 예술성 87`이 모두 가능하다.

고정 설계 최대치가 없더라도 경제와 고객 판정은 콘텐츠별 기대 범위·최소 요구치·선호 구간·점감 함수를 사용할 수 있다.

```text
NON_NEGATIVE_INTEGER_NO_FIXED_DESIGN_MAXIMUM
```

동일 Decision의 초기 bounded-stat 초안과 named-tier 프리셋은 `[대체됨]`이다.

## 5. 강화와 촉매

일반 강화는 한 입력에 한 결과다.

```text
+10 / +20 / +30 / +40 / +50
주재료 맥락 + 강화 방식 + 촉매 한 개
```

강화 방식은 세부 수치 방향을, 촉매는 촉매 수식어 후보 계보와 확률을 책임진다. 촉매 수식어는 `EMPTY → SEED → DEVELOPED → EVOLVED → MASTERED`로 성장할 수 있으며 무관한 계보로 무작위 교체하거나 같은 이정표를 무한 리롤하지 않는다.
