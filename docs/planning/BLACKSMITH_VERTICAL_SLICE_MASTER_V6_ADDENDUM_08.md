## 게임 전체 주요 화면 구조

게임 전체 정보 구조는 **대장간 홈 + 3개 고정 영역**을 사용한다.

하단 고정 내비게이션에서 `[대장간]`, `[방문 고객]`, `[세계]`를 언제든 구분하고 이동할 수 있게 한다. 강화는 게임의 주 행동이므로 `[대장간]`을 기본 홈으로 유지하되, 고객과 세계 활동을 강화 화면의 팝업으로 종속시키지는 않는다.

```text
[대장간]
- 강화 작업대
- 장비 선택·보관
- 강화 재료·보호 수단
- 수리·정비

[방문 고객]
- 방문 고객 목록·비교
- 판매 제안
- 약속
- 지원
- 관계·재방문

[세계]
- 세계 게시판
- 구독 소식
- 전용 사건 화면
- 검투사 경기·배팅
- 장비 연대기와 세계 결과 연결
```

## `[대장간]` 영역

`[대장간]`은 앱 시작과 일반 복귀의 기본 화면이며, 강화 작업대를 중심으로 구성한다.

- 마지막으로 선택한 유효 장비와 작업대 맥락을 복원한다.
- 강화 성공률, 비용, 위험, 보호 상태와 강화 입력을 핵심 작업 영역에 유지한다.
- 장비 목록, 재료 상점, 보호 수단과 수리는 작업대로 빠르게 복귀할 수 있는 보조 흐름으로 둔다.
- 고객·세계 화면에 다녀와도 선택 장비와 열려 있던 작업 맥락을 가능한 범위에서 보존한다.
- 파괴되거나 소유권이 이전된 장비는 복귀 시 선택 상태에 남기지 않는다.

`[대장간]`은 모든 기능을 담는 단일 허브가 아니다. 고객 관계, 세계 게시판과 사건 전문 정보는 각 고정 영역에서 처리한다.

## `[방문 고객]` 영역

`[방문 고객]`은 장비 판매와 인물 관계에 관한 결정을 담당한다.

주요 기능:

- 현재 방문한 고객과 남은 영업일 표시
- 고객별 요구 조건·선호·야망 비교
- 장비 적합도와 확정 판매가·즉시 보상 비교
- 장비 판매와 소유권 이전
- 약속 수락·거절·이행 상태
- 장비·재료·수리·소모품 지원
- 관계 변화, 재방문과 후속 요청
- 이미 판매한 장비가 어느 고객에게 있는지 확인

고객 비교 화면은 장비 강화를 대체하지 않는다. 판매 전 필요한 강화나 정비가 있으면 해당 장비를 선택한 상태로 `[대장간]`에 직접 이동할 수 있어야 한다.

```text
고객 제안 확인
→ 판매 후보 장비 선택
→ [대장간에서 준비]
→ 동일 장비가 선택된 작업대로 이동
→ 강화·수리 후
→ [방문 고객] 제안 맥락으로 복귀
```

## `[세계]` 영역

`[세계]`는 장비가 판매된 이후의 활동과 공개 세계 결과를 담당한다.

주요 기능:

- 전 세계 공개 소식을 보여주는 세계 게시판
- 구독한 인물과 관심 인물의 개인화 소식
- 사건 일정, 남은 영업일과 지원 가능 상태
- 전용 사건 화면
- 검투사 경기 일정·공식 배당·배팅
- 모험·수집·군사·검투 활동 결과
- 장비 손상·분실·회수·상속·전리품·유물화
- 대표 특수 수식어 심화와 장비 연대기
- 장비 현재 소유자와 과거 소유자 계보

게시판, 구독과 사건은 같은 `[세계]` 영역에 속하지만 단일 피드에서 모든 내용을 뒤섞지 않는다. 공개 소식, 개인 구독 소식과 직접 개입 가능한 사건은 하위 구분을 갖는다.

## 하단 고정 내비게이션

하단 내비게이션은 세 주요 영역을 지속적으로 구분한다.

| 탭 | 역할 | 대표 상태 표시 |
|---|---|---|
| `[대장간]` | 강화·장비·재료 | 강화 가능, 재료 부족, 수리 필요 |
| `[방문 고객]` | 판매·약속·관계 | 새 방문, 마감 임박, 약속 상태 |
| `[세계]` | 게시판·구독·사건 | 새 소식, 사건 마감, 경기 결과 |

원칙:

- 각 탭은 서로 다른 책임 영역을 가진다.
- 동일 기능을 여러 탭에 중복 배치하지 않는다.
- 하단 내비게이션을 가리는 지속 팝업이나 다중 모달 구조를 두지 않는다.
- 하단 패널이 필요한 경우 현재 영역 안에서 한 번에 하나만 연다.
- Android 세로형 화면과 한 손 조작을 기준으로 주요 탭을 배치한다.
- 정확한 탭 아이콘, 라벨 길이와 터치 영역은 UI 프로토타입에서 검증한다.

## 배지·기한 표시의 기본 원칙

각 영역에 처리할 일이 있을 때 배지 또는 기한 상태를 표시할 수 있다.

표시 후보:

- 새 방문 고객
- 고객 제안 마감 임박
- 활성 약속의 제공 기한
- 사건 지원 기한
- 검투사 경기 예정·결과
- 새 구독 소식
- 장비 손상·분실·회수 소식
- 미확인 강화·거래·세계 결과

단순한 읽지 않은 소식 수를 무제한 숫자로 쌓아 압박하지 않는다. 실제 행동 가능 여부와 기한이 있는 항목을 우선해 표시한다. 정확한 배지 우선순위와 묶음 규칙은 후속 정보 구조 결정에서 확정한다.

## 직접 이동과 복귀 맥락

중요 알림, 고객 제안과 세계 사건에서 관련 화면으로 직접 이동할 수 있다.

```text
알림 또는 장비 연대기 링크
→ 대상 고객·사건·장비 화면으로 직접 이동
→ 관련 행동 수행 또는 정보 확인
→ 뒤로 가기
→ 이전 영역과 작업 맥락으로 복귀
```

복귀 원칙:

- 직접 이동 전의 주요 영역을 기억한다.
- `[대장간]`에서 이동했다면 유효한 선택 장비와 작업대 상태를 복원한다.
- `[방문 고객]`에서 이동했다면 비교 중이던 고객과 장비 후보를 복원한다.
- `[세계]`에서 이동했다면 보던 게시판·구독·사건 위치를 복원한다.
- 대상 상태가 이미 변경됐거나 만료됐다면 사라진 화면을 복원하지 않고 변경 이유와 현재 유효한 상태를 표시한다.
- 복귀를 위해 동일 결과나 보상을 다시 적용하지 않는다.

## 다음 행동 안내

시스템은 현재 의미 있는 다음 행동을 안내할 수 있지만 강제 자동 이동하지 않는다.

예시:

- `강화 재료가 부족합니다 — 재료 보기`
- `고객 제안이 오늘 마감됩니다 — 제안 보기`
- `검투사 경기가 1영업일 남았습니다 — 경기 준비 보기`
- `판매한 장비의 새 연대기가 도착했습니다 — 결과 보기`

원칙:

- 안내를 닫거나 나중에 처리할 수 있다.
- 플레이어가 강화 중일 때 일반 소식이 작업대를 강제로 덮지 않는다.
- 영구 파괴, 저장 복구, 세계 시간 진행 결과처럼 반드시 확인해야 하는 상태만 일반 조작보다 먼저 정리한다.
- 안내 선택으로 이동한 뒤 이전 맥락으로 돌아갈 수 있어야 한다.

## 버티컬 슬라이스 적용 범위

15~25분 버티컬 슬라이스에서는 세 영역이 모두 실제 행동을 포함해야 한다.

```text
[대장간]
준비된 장비 강화·정밀강화·고위 정밀강화

[방문 고객]
네 고객 유형의 방문·비교·판매·약속·지원

[세계]
게시판·구독·검투 경기·장비 결과·재방문 연결
```

- 한 영역을 설명용 메뉴나 잠긴 티저로만 두지 않는다.
- 대표 흐름은 `[대장간] → [방문 고객] → [세계] → [방문 고객 재방문 또는 장비 연대기]`로 연결한다.
- 세 영역 간 이동이 슬라이스 플레이 시간의 과도한 비중을 차지하지 않아야 한다.
- 직접 이동과 복귀 맥락을 사용해 동일 장비·고객·사건을 다시 찾는 탐색 시간을 줄인다.

## 금지 구조

다음 구조는 사용하지 않는다.

- 고객·세계 기능을 모두 강화 작업대 팝업으로 넣는 단일 과밀 허브
- 강화·장비·재료·고객·약속·게시판·구독·사건을 각각 최상위 탭으로 나누는 과다 내비게이션
- 알림을 선택할 때마다 이전 작업대 상태를 잃는 구조
- 중요한 기한을 해당 영역에 들어가야만 알 수 있는 구조
- 다음 행동 안내가 플레이어 의사와 무관하게 화면을 강제 전환하는 구조
- 하단 내비게이션 위에 다중 모달·다중 하단 패널을 중첩하는 구조

## 검증 항목

- 앱 시작 시 `[대장간]` 작업대로 진입하는지 확인
- 세 탭의 책임이 플레이어에게 구분되는지 확인
- 고객 제안에서 대장간으로 이동 후 같은 장비·제안 맥락으로 돌아오는지 확인
- 세계 사건 직접 이동 후 이전 작업대 또는 피드 위치로 복귀하는지 확인
- 탭 배지로 새 방문·마감·세계 결과를 놓치지 않는지 확인
- 일반 알림이 강화 입력을 강제로 중단하지 않는지 확인
- 네 고객 유형과 세계 결과를 포함한 전체 슬라이스가 15~25분 안에서 탐색 과부하 없이 진행되는지 확인
- Android 세로형 화면에서 하단 탭과 핵심 행동이 한 손으로 조작 가능한지 확인

```text

DEFAULT_HOME: FORGE
TOP_LEVEL_DOMAIN_COUNT: THREE
TOP_LEVEL_DOMAINS: FORGE_CUSTOMERS_WORLD
CUSTOMER_AND_WORLD_AS_FORGE_POPUPS: FORBIDDEN
CONTEXTUAL_DEEP_LINK: REQUIRED
RETURN_CONTEXT_PRESERVATION: REQUIRED
FORCED_NAVIGATION_BY_NORMAL_NOTIFICATION: FORBIDDEN
BOTTOM_NAVIGATION_OCCLUDED_BY_STACKED_MODAL: FORBIDDEN
VERTICAL_SLICE_ALL_DOMAINS_FUNCTIONAL: REQUIRED
EXACT_BADGE_PRIORITY_AND_SUBNAV_LAYOUT: UNRESOLVED
```
