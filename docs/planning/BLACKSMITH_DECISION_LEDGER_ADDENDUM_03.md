# 블랙스미스 기획 결정 원장 추가 기록 03

> 상태: `PLANNING_IN_PROGRESS`
>
> 기준일: 2026-07-26
>
> 범위: 분야별 기술 돌파의 일반·주요 보상 구분

## 1. 결정 추적표

| 영역 | 결정 | 상태 | 최신 규칙 | 병합 조치 |
|---|---|---|---|---|
| 돌파 보상 | 모든 돌파에서 강한 신규 기술 제공 | `REJECTED` | 강한 신규 기능은 주요 돌파에 제한 | 기술 팽창 방지 |
| 돌파 보상 | 모든 돌파는 구간 개방만 제공 | `REJECTED` | 일반 돌파도 소규모 보조 효과·정보·편의를 제공 | 순수 재화 관문 방지 |
| 돌파 등급 | 일반·주요 구분 없음 | `SUPERSEDED` | 일반 돌파와 주요 돌파로 구분 | 성장 마디 차등화 |
| 일반 돌파 | 보상 없는 비용 관문 | `REJECTED` | 다음 구간 개방 + 소규모 분야 보조 보상 | 반복 돌파 체감 보장 |
| 주요 돌파 | 매 10강마다 발생 | `REJECTED` | 여러 일반 돌파 사이에 배치 | 강한 기능 과잉 방지 |
| 주요 돌파 간격 | 특정 값 확정 | `UNRESOLVED` | 최초 배치와 반복 간격 별도 결정 | 임의 확정 금지 |

## 2. 최신 책임 분리

### 모든 돌파

- 해당 분야의 다음 10강 구간 영구 개방
- 계정·장비 분야별 독립 적용
- 정밀강화 완료 후 즉시 확정 돌파

### 일반 돌파

- 정보·비교·편의
- 작은 조건부 안정·효율 보정
- 분야 보조 영구 강화 접근

### 주요 돌파

- 분야별 신규 기능
- 메인 전문 분야 상위 구간·핵심 노드 접근
- 강한 분야 보조 기술
- 새로운 제작·강화·복구 방식

## 3. 제약

- 분야 돌파가 제작·강화 공통 전문 분야의 고유 기능을 복제하지 않는다.
- 일반 돌파의 누적 보정에는 총합 상한과 체감 감소를 적용할 수 있다.
- 돌파 보상은 공개시장 고정 매입가를 직접 높이지 않는다.
- 돌파 보상만으로 강화 성공률 100%에 도달할 수 없다.
- 정확한 효과·비용·주요 돌파 배치는 `PROPOSED_ONLY`다.

- 이후 주요 돌파 간격
- 분야별 동일 배치 여부
- 각 일반 돌파 보상 풀
- 주요 돌파별 분야 고유 기능
