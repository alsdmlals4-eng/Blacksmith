## 대체된 구조

이 문서에서 제안했던 다음 구조는 더 이상 현재 정본이 아니다.

- `주재료 / 보조재료 / 촉매` 3개 재료 슬롯
- 날 보강재·충격 흡수재·경량 합금·환경 처리재·은사 상감재·문장 각인 금속의 보조재료 분류
- 보조재료를 포함한 대표 조합 8종
- 최초 제작 전에 세 재료 슬롯을 조합하는 흐름

사용자 승인 `BS-CRAFT-20260804-04`에 따라 보조재료 슬롯은 제거되었다. 날 보강·충격 흡수·경량화·균형 조정·예술 마감·환경 처리는 정밀강화에서 선택하는 `강화 방식`으로 이동했다.

현재 정밀강화 구조는 다음과 같다.

```text
주재료 맥락 + 강화 방식 + 촉매·추가재료
→ 능력치 방향·대가·위험 확인
→ 정밀강화 결과
```

## 유지되는 원칙

다음 원칙은 `BS-CRAFT-20260804-04`에서도 유지된다.

- 작품의 기본 이름과 재료 정체성은 최초 주재료에서 파생된다.
- 희귀 주재료는 모든 성능·예술성·가격의 만능 상위호환이 아니다.
- 최초 완성품에는 일반 수식어가 없다.
- 수식어는 정밀 이정표와 강화 결과에서 추가·성장한다.
- 촉매는 강화 결과와 수식어를 확정하지 않는다.
- 모든 강화 방식은 이점과 대가를 가진다.
- 정확한 수치·비용·확률은 `BASELINE_TEST_PRESET`이다.

이 문서는 설계 변화의 감사 기록으로만 보존하며 현재 게임 구조를 구현하거나 해석하는 근거로 사용하지 않는다.
