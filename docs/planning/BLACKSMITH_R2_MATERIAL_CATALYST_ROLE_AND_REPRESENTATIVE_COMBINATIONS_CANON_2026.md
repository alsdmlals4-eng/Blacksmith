- 제품 구현: `BLOCKED`

## 1. 목적

주재료·보조재료·촉매가 서로 다른 판단을 만들도록 역할을 분리하고, 플레이어가 제작 전에 실용형·예술형·혼합형의 방향을 읽을 수 있는 최소 대표 조합을 확정한다.

```text
주재료로 작품의 재료 정체성·기본 이름·기본 성능 범위 선택
→ 보조재료로 한 방향을 보정하고 대가를 선택
→ 촉매로 강화 과정·수식어·마감 성향을 조정
→ 수식어 없는 1차 완성품 제작
→ 기존 강화 이정표에서 수식어 획득·강화
→ 고객과 일정에 맞춰 판매·사용·연대기 환류
```

이 Gate는 재료별 정확한 수치·가격 계수·강화 확률·최종 인게임 명칭을 확정하지 않는다. 해당 값은 버전형 `BASELINE_TEST_PRESET`과 후속 콘텐츠 명명 Gate가 소유한다.

## 2. 상속하는 불변 규칙

초기 사용자 승인과 기존 R1~R2 정본에서 다음 규칙을 유지한다.

- 기본 작품의 이름과 기본 성능 정체성은 주재료에서 파생된다.
- 제작 직후 1차 완성품에는 수식어를 붙이지 않는다.
- 일반 수식어는 기존 강화 이정표와 강화 결과에서 추가·강화된다.
- 보조재료와 촉매는 제작 직후 가짜 수식어·접두사·접미사를 자동 부여하지 않는다.
- 숨은 조합은 허용하지만, 이번 대표 조합 8종은 숨은 레시피 전체 목록이 아니다.
- 작품 등급·예술성·강화 단계는 서로 다른 역할을 유지한다.

## 3. 재료 3계층 역할

### 3.1 주재료 — 작품 정체성과 기본 범위

주재료는 다음을 담당한다.

- 작품 기본 이름의 재료 표기
- 기본 공격·방어·내구·무게·취급·환경 대응 범위
- 기본 가치와 제작 난이도의 방향
- 재료 고유색·결·표면·반사 특성
- 실용·예술 잠재력의 출발점

주재료는 작품 등급이나 예술성을 자동 확정하지 않는다. 희귀 주재료도 낮은 제작 품질과 부적절한 보조재료·촉매를 사용하면 낮은 완성도를 가질 수 있다.

### 3.2 보조재료 — 방향 보정과 대가

보조재료는 주재료의 정체성을 유지하면서 한 가지 주 방향을 강화한다.

- 실전 성능 보정
- 예술성·표면 완성 보정
- 판매가·희소성 보정
- 환경·대상 적합성 보정
- 대표 수식어 가족의 출현 성향 보정

모든 보조재료는 `주요 이점 1개 + 대가 또는 비우선 영역 1개`를 가져야 한다. 주재료보다 더 큰 범위에서 작품의 이름·기본 성능·재료 정체성을 결정하지 않는다.

### 3.3 촉매 — 강화 과정과 결과 성향

촉매는 작품의 기본 재료가 아니라 제작·강화 과정의 반응과 마감 성향을 조절한다.

- 강화 안정성·위험 방향
- 강화 효과와 수식어 가족의 출현 가중치
- 예술성 상승 결과와 표면 마감 성향
- 환경·대상 특화 효과의 발현 성향
- 희귀 촉매의 제한된 시각 연출

촉매는 주재료의 기본 성능을 대체하거나 제작 즉시 확정 수식어를 부여하지 않는다. 정확한 소비량·강화 위험 증감·가중 확률은 `BASELINE_TEST_PRESET`이다.

## 4. 제작 전 표시 계약

각 선택지는 `BS-CRAFT-20260804-02`의 3단계 표시를 사용한다.

```text
실전 성능: 낮음 / 보통 / 높음
예술성: 낮음 / 보통 / 높음
판매가: 낮음 / 보통 / 높음
강화 성향: 대표 효과·수식어 가족
대가: 비용·무게·취급·안정성·범용성 중 한 가지
```

- 텍스트 라벨을 필수로 사용한다.
- 최종 수치와 수식어는 확정적으로 공개하지 않는다.
- 선택 세 가지를 합친 조합 요약에서도 가장 큰 이점과 대가를 함께 보여준다.
- `높음`이 세 항목에 동시에 반복되는 조합은 반드시 비용·제작 난이도·강화 불안정·낮은 범용성 중 명확한 대가를 가진다.

## 9. 이름과 수식어 경계

기본 이름은 다음 원칙을 따른다.

```text
주재료 이름 + 작품 종류
예: 철검 / 강철검 / 은합금 의장검 / 운철 도구
```

- 보조재료·촉매 이름을 자동 접두사·접미사로 붙이지 않는다.
- `예리한`, `견고한`, `명품`, `광휘` 같은 수식어는 강화 이정표와 강화 결과에서만 획득한다.
- 대표 조합명은 제작 화면의 레시피 요약 또는 분석용 명칭이며 작품의 영구 수식어가 아니다.
- 숨은 조합이 새로운 기본 작품군을 만들 경우 별도 Decision과 명명 규칙 승인이 필요하다.

## 10. 적대적 보호 조건

- 주재료·보조재료·촉매가 모두 같은 역할을 수행하는 중복 구조 금지
- 보조재료나 촉매가 주재료보다 작품 이름·기본 성능을 더 크게 결정하는 구조 금지
- 제작 직후 보조재료·촉매가 수식어를 직접 부여하는 구조 금지
- 희귀 주재료가 등급·예술성·실용성·가격을 모두 자동 최고로 만드는 구조 금지
- 상위 재료가 하위 재료의 완전한 상위호환이 되는 구조 금지
- 모든 고객과 일정에 하나의 최적 조합만 존재하는 구조 금지
- 희귀·고가 재료만 장기적으로 생존하고 철·강철 조합이 무의미해지는 구조 금지
- 촉매가 강화 선택과 결과를 확정해 위험·멈춤 판단을 제거하는 구조 금지
- 사전 표시와 반복 결과 방향이 불일치하는 구조 금지
- 대표 조합 8종을 전체 콘텐츠 수 또는 최종 재료 카탈로그로 오해하는 구조 금지
- 숨은 조합이 사전 단서 없이 무작위 정답 찾기가 되는 구조 금지

1. 주재료가 작품 이름과 기본 성능을 정하는 이유
2. 보조재료가 어떤 방향을 강화하고 무엇을 포기하게 하는지
3. 촉매가 기본 성능이 아니라 강화·수식어 성향에 영향을 주는 이유
4. 제작 직후 수식어가 없고 강화 이정표에서 수식어가 붙는다는 점
5. 같은 강철이라도 투기형·수호형·원정형이 다른 고객과 일정에 맞는 이유
6. 운철이 모든 상황에서 최적이 아닌 이유
7. 대표 조합의 실전 성능·예술성·가격·강화 성향과 대가

행동 증거와 직후 중립적 회상 인터뷰가 충돌하면 통과를 보류하고 최소 수정 후 재검증한다.
