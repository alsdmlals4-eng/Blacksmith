## 2. 공개 대상

일반 강화 시도 전에 다음 최종 결과 확률을 모두 공개한다.

```text
대성공 / 성공 / 유지 / 하락 1 / 하락 2 / 파괴 또는 보호 파괴
```

표시 확률에는 다음이 모두 반영되어야 한다.

- 현재 목표 강화 단계
- 제작 숙련과 장비 분야 숙련에 따른 성공 보정
- 강화 숙련과 장비 분야 숙련에 따른 위험 감소
- 대성공 비중과 비활성 목표 단계
- 보호석 선택 여부
- 실패 완충 타격 선택 여부
- 보호석과 실패 완충 타격의 병용 결과

촉매나 후속 전문화가 실제 결과 확률을 바꾸게 되는 경우에도 같은 최종 결과표에 반영한다.

## 3. 기본 표시 원칙

### 3.1 최종 결과표 우선

플레이어에게 가장 크게 보이는 표는 현재 선택 상태를 모두 반영한 **최종 결과표**다.

- 보호석을 선택하지 않았으면 `파괴` 확률과 `즉시 영구 소멸`을 표시한다.
- 보호석을 선택했으면 같은 확률 질량을 `보호 파괴`로 표시하고 예상 단계 하락량을 함께 표시한다.
- 실패 완충 타격만 선택했으면 하락 1 질량은 유지로, 하락 2 질량은 하락 1로 이동한 최종값을 표시한다.
- 보호석과 실패 완충 타격을 함께 선택했으면 하락 1·2의 최종 확률은 0이 되고, 파괴 질량은 완화된 단계 손실의 보호 파괴로 표시한다.

자연 결과표는 세부 정보에서 펼쳐볼 수 있지만 기본 판단 표를 대신하지 않는다.

### 3.2 표시 정밀도

- 내부 계산은 기존 책임 원본대로 확률 소수점 네 자리 이상을 유지한다.
- 플레이어 표시 단위는 `0.01%`다.
- 여섯 결과의 표시 합은 항상 `100.00%`여야 한다.
- 개별 값을 독립 반올림하지 않고 최대잔여 방식으로 0.01% 단위를 배분한다.
- 실제 확률이 0이 아니면 반올림으로 `0.00%`가 되지 않도록 최소 표시 단위 `0.01%`를 우선 배정하고 다른 항목에서 잔여를 조정한다.
- 계산 원본과 표시값이 다를 수 있으므로 자동 검증에서는 두 값을 별도로 보존한다.

## 4. 선택 변경 시 갱신

보호석 또는 실패 완충 타격을 켜거나 끄면 확인 버튼을 누르기 전에 결과표를 즉시 다시 계산한다.

갱신 대상:

- 결과별 확률
- 결과 명칭
- 장비 생존 여부
- 보호 파괴 예상 단계 하락량
- 보호석 요구량과 보유량
- 실패 완충 충전 소비
- 최악 결과 문구

확률 변화는 색상만으로 표현하지 않고 이전 값과 새 값을 숫자와 방향 기호로 함께 표시한다.

예시:

```text
하락 1 20.00% → 유지에 포함
하락 2 7.00% → 유지에 포함
파괴 8.80% → 보호 파괴 8.80% / 예상 -6
```

## 5. 보호 수단별 표시 계약

| 선택 상태 | 최종 확률표 처리 | 최악 결과 |
|---|---|---|
| 보호 없음·완충 없음 | 자연 6결과 | 파괴 시 즉시 영구 소멸 |
| 완충만 사용 | 하락 1→유지, 하락 2→하락 1 | 파괴 시 즉시 영구 소멸 |
| 보호석만 사용 | 하락 1·2→유지, 파괴→보호 파괴 | 대폭 단계 하락 후 즉시 사용 가능 |
| 보호석+완충 | 하락 1·2→유지, 파괴→완충된 보호 파괴 | 기본 보호 파괴보다 2단계 적게 하락, 최소 3단계 |

보호석이 파괴 확률 자체를 낮추는 것처럼 표현해서는 안 된다. 보호석은 파괴 결과의 **효과**를 바꾼다.

실패 완충 타격도 파괴 확률이나 성공률을 낮추거나 높이는 것처럼 표현해서는 안 된다.

## 6. 대성공 표시

- 대성공은 총성공률 내부의 분리 결과로 표시한다.
- 목표 `+49`, `+50`, `+100`에서는 `0.00%`와 비활성 사유를 표시한다.
- 대성공이 정밀강화·한계 돌파 이정표에서 멈추는 경우 예상 도착 단계를 표시한다.
- 대성공과 성공을 하나의 성공 확률로 합쳐 숨기지 않는다.

## 7. 다른 위험 시스템과의 경계

정확한 확률 공개는 일반 강화에만 적용한다.

다음 시스템은 기존처럼 정성적 위험 단계와 가능한 최악 결과를 표시한다.

- 밀수 적발
- 방문 고객·수집가 위험 흥정
- 국가 사건 선택
- 군사 보급의 세계 결과
- 정확한 내부 신뢰 수치

이들 시스템의 정확한 확률을 공개하려면 별도 중요 기획 승인이 필요하다.

## 8. 검증 계약

POC와 후속 자동 검증은 최소 다음을 확인한다.

1. 자연 상태 6결과 표시 합 `100.00%`
2. 숙련 변화 직후 최종 확률 갱신
3. 보호석 선택 시 하락 1·2가 유지에 합산
4. 보호석 선택 시 파괴 질량이 동일 확률의 보호 파괴로 명칭 변경
5. 완충만 선택 시 하락 1→유지, 하락 2→하락 1
6. 보호석+완충 시 보호 파괴 단계 손실 감소 표시
7. 무보호 파괴의 즉시 영구 소멸 문구
8. 목표 +49·+50·+100 대성공 0.00%와 사유 표시
9. 최대잔여 반올림 후 합계 100.00%
10. 밀수·흥정·국가 사건의 정확한 확률 비공개 유지
11. 색상 없이도 확률 변화와 최악 결과 식별 가능

보고 지표:

- 확률표 표시값과 내부값의 최대 오차
- 합계 100.00% 위반 횟수
- 보호 수단 변경 후 갱신 지연
- 최악 결과 오표기 횟수
- 플레이어가 보호석이 파괴 확률을 낮춘다고 오해한 비율
- 외부 테스트에서 시도 결과를 정확히 설명한 비율

Godot 런타임 구현은 정확한 `기획 완료`와 `검수 완료` 이후 별도 계획과 PR로 진행한다.
