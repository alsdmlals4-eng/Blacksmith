---

## 1. 승인 결정

일반 강화의 정확한 최종 결과 확률을 시도 전에 공개한다.

공개 결과:

```text
대성공 / 성공 / 유지 / 하락 1 / 하락 2 / 파괴 또는 보호 파괴
```

표시는 현재 목표 단계, 숙련, 보호석, 실패 완충 타격과 병용 효과를 모두 반영한다.

- 표시 단위: `0.01%`
- 표시 합계: 항상 `100.00%`
- 반올림: 최대잔여 방식
- 기본 표: 자연 결과가 아니라 현재 선택 상태의 최종 결과
- 자연 결과표: 세부 정보에서 별도 확인 가능

---

## 2. 보호 수단 표시

| 선택 | 표시 결과 |
|---|---|
| 보호 없음·완충 없음 | 자연 6결과, 파괴는 즉시 영구 소멸 |
| 완충만 | 하락 1→유지, 하락 2→하락 1, 파괴는 즉시 소멸 |
| 보호석만 | 하락 1·2→유지, 파괴→보호 파괴 |
| 보호석+완충 | 하락 1·2→유지, 파괴→손실이 2단계 줄어든 보호 파괴, 최소 3단계 |

보호석은 파괴 확률을 낮추지 않는다. 같은 파괴 확률 질량의 결과를 영구 소멸에서 보호 파괴로 바꾼다.

---

## 3. 대성공 공개

- 대성공과 성공을 합쳐 숨기지 않는다.
- 목표 `+49`, `+50`, `+100`에서는 대성공 `0.00%`와 비활성 사유를 표시한다.
- 이정표에서 멈추는 경우 예상 도착 단계를 표시한다.

---

## 4. 공개 범위 경계

정확한 확률 공개는 일반 강화에만 적용한다.

다음은 기존 정성적 위험 표시를 유지한다.

- 밀수 적발
- 방문 고객·수집가 위험 흥정
- 국가 사건
- 군사 보급의 세계 결과
- 내부 신뢰 수치

이 경계 변경은 별도 중요 기획 승인 사항이다.

## 5. 충돌 해결

### `SUPERSEDED_FOR_GENERAL_ENHANCEMENT`

- `정확한 성공률·신뢰 수치·밀수 적발 확률은 공개하지 않음`을 모든 시스템에 일괄 적용하는 해석
- `risk_preview.show_exact_probability: false`를 일반 강화에도 적용하는 해석
- 보호석 선택 후에도 자연 확률표만 보여주는 방식
- 대성공을 성공 확률 안에 합쳐 숨기는 방식

밀수·흥정·국가 사건의 정확한 확률 비공개는 유지한다.
