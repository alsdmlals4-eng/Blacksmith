> 주의: 아래의 `일반 돌파 / 주요 돌파` 구분은 폐기되었다. 이 문서는 의사결정 이력 확인 목적으로만 유지하며 구현·UI·밸런스 기준으로 사용하지 않는다. 최신 시스템 명칭과 구조는 `[강화 한계 돌파]` 별도 영구 스킬 트리다.

## 1. 폐기된 결정

분야별 기술 돌파를 `일반 돌파`와 `주요 돌파`로 구분하려던 방향이다.

모든 돌파가 다음 10강 구간을 계정·분야별로 영구 개방하고, 보상 크기로 두 종류를 구분하려 했다.

```text
정밀강화 완료
→ 해당 분야 기술 돌파
→ 다음 강화 단계 개방
```

## 2. 폐기된 일반 돌파 구상

일반 돌파에 다음 소규모 보상을 제공하려 했다.

- 해당 분야 위험·비용·결과 정보 개선
- 비교·필터·반복 작업 편의
- 작은 재료 손실 또는 복구 비용 완화
- 조건부 소규모 안정·효율 보정
- 분야별 보조 영구 강화 노드 접근 조건

## 3. 폐기된 주요 돌파 구상

주요 돌파에 다음 강한 보상을 제공하려 했다.

- 분야별 신규 기능 해금
- 메인 전문 분야 트리의 상위 구간 또는 핵심 노드 접근 조건
- 강한 분야 보조 기술
- 새로운 제작·강화·복구 방식
- 분야별 연출·도감·기록 확장

## 4. 폐기 사유

- `일반 / 주요` 명칭이 실제 돌파 절차가 다른 것처럼 오해하게 한다.
- 강화 한계 개방과 추가 기술 보상을 한 시스템에 결합해 책임이 불명확하다.
- 돌파마다 별도 보상 풀을 설계하면 장기적으로 기술과 규칙이 과도하게 팽창한다.
- 사용자가 원하는 구조는 강화 성장축에서 포인트를 투자하는 별도 한계 개방 트리다.

## 5. 최신 대체 규칙

- 명칭: `[강화 한계 돌파]`
- 위치: 강화 성장축 내부의 별도 영구 스킬 트리
- 기본 최대 강화: `+40`
- 이후 개방: `+50`, `+60`, `+70`처럼 10강 단위
- 비용: 강화 성장축 포인트
- 구조: 선행 노드를 요구하는 순차 트리
- 적용: 계정 전체에 영구 적용
- 회수: 불가
- 주요·일반 돌파 구분: 없음

세부 기준은 `BLACKSMITH_GROWTH_SYSTEM_ADDENDUM_04.md`를 따른다.
