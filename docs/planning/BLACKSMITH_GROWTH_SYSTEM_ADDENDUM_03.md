# 블랙스미스 성장 시스템 추가 결정 03 — 기술 돌파 보상 등급

> 상태: `PLANNING_IN_PROGRESS`
>
> 기준일: 2026-07-26
>
> 효력: 이 문서는 `BLACKSMITH_GROWTH_SYSTEM_PLANNING.md`와 기존 성장 시스템 추가 결정 문서의 분야별 기술 돌파 보상 규칙을 보완한다. 정확한 주요 돌파 배치, 효과 수치, 비용과 해금 노드는 별도 승인 전까지 `PROPOSED_ONLY`다.

## 1. 확정 결정

분야별 기술 돌파는 `일반 돌파`와 `주요 돌파`로 구분한다.

모든 돌파는 공통으로 다음 10강 구간을 계정·분야별로 영구 개방한다.

```text
정밀강화 완료
→ 해당 분야 기술 돌파
→ 다음 강화 단계 개방
```

## 2. 일반 돌파

일반 돌파는 강화 구간 개방에 더해 작고 명확한 분야 보조 보상을 제공한다.

허용되는 보상 범위:

- 해당 분야 위험·비용·결과 정보 개선
- 비교·필터·반복 작업 편의
- 작은 재료 손실 또는 복구 비용 완화
- 조건부로 작동하는 소규모 안정·효율 보정
- 분야별 보조 영구 강화 노드 접근 조건

일반 돌파는 새로운 강력한 전투·강화 규칙이나 메인 트리 최상위 기능을 매번 추가하지 않는다.

## 3. 주요 돌파

주요 돌파는 장기 성장의 큰 마디다.

가능한 보상 범위:

- 분야별 신규 기능 해금
- 메인 전문 분야 트리의 상위 구간 또는 핵심 노드 접근 조건
- 강한 분야 보조 기술
- 새로운 제작·강화·복구 방식
- 분야별 연출·도감·기록 확장

주요 돌파에서 해금되는 기능은 제작·강화 공통 전문 분야의 고유 기능을 그대로 복제하지 않는다.

## 4. 배치 원칙

- 돌파는 `+40`, `+50`, `+60`, `+70`처럼 10강 단위로 계속 발생한다.
- 모든 돌파가 다음 구간 개방을 담당한다.
- 여러 일반 돌파 사이에 주요 돌파를 배치한다.
- 주요 돌파가 아닌 단계도 보상 없이 재화만 소모하는 관문이 되지 않도록 소규모 보조 보상을 제공한다.
- 장기적으로 기술 수가 무한히 팽창하지 않도록 강한 신규 기능은 주요 돌파에만 제한한다.
- 일반 돌파와 주요 돌파의 비용·요구 조건은 단계가 오를수록 증가할 수 있으나 정확한 곡선은 `PROPOSED_ONLY`다.

## 5. 금지되는 해석

- 모든 돌파마다 새 강력한 고유 기능을 제공하지 않는다.
- 일반 돌파를 보상 없는 순수 재화 소모 관문으로 만들지 않는다.
- 돌파 보상이 메인 트리의 제한된 빌드 선택을 무력화하지 않는다.
- 분야 돌파 보상이 공개시장 고정 매입가를 직접 올리지 않는다.
- 돌파 단계가 강화 성공을 확정하거나 100%로 만들지 않는다.

## 6. 남은 미결정

- 최초 주요 돌파가 발생하는 강화 단계
- 주요 돌파의 반복 간격
- 분야별 주요 돌파 배치의 공통·차등 여부
- 일반 돌파의 보조 보상 풀
- 주요 돌파별 신규 기능과 트리 접근 조건
- 단계별 비용·숙련·공통 등급·시설 요구치
