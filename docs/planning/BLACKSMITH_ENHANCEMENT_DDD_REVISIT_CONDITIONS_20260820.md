# Blacksmith 강화 DDD 장기 재검토 조건

- Parent: `BS-CORE-20260820-01`

다음 증거가 나오면 현재 강화 중심 세부 구조를 다시 연다.

1. 플레이어가 항상 강화하고 거의 멈추지 않는다.
2. 플레이어가 안전 구간에서만 멈추고 위험 강화를 거의 시도하지 않는다.
3. 실패 뒤 '다음에는 될 것 같다'보다 '시간을 빼앗겼다'는 반응이 우세하다.
4. 실패 누적 회복이 긴장감을 제거한다.
5. 보호 수단이 항상 정답이라 사실상 추가 비용 세금이 된다.
6. 작품 손상 때문에 애착 있는 작품은 강화하지 않고 창고에만 보관한다.
7. 정밀제작 또는 고객 콘텐츠가 강화보다 더 핵심 재미로 평가된다.
8. 첫 세션에서 강화 선택 이유를 설명하지 못한다.
9. 강화 결과가 고객/세계 payoff와 인과적으로 연결되지 않는다.
10. 반복 강화가 모바일 작업 노동으로 인식된다.

위 조건은 실패가 아니라 재설계 트리거다. 실제 사람 플레이 전에는 모두 `UNVERIFIED`다.
