## 확정 내용

1. 방문 고객에게 주 제품과 함께 제공하는 `[추가물품 / 지원품]`은 기본적으로 별도 완성 작품이 아니라 기존 재고의 `[보조재료]`, `[촉매]`와 같은 자원 항목으로 구성한다.
2. 동일한 자원은 별도 `지원품 전용 복제품`을 만들지 않고 하나의 재고 수량을 공유한다.
3. 플레이어는 해당 자원을 다음 용도 중에서 선택해 사용한다.
   - 작품 제작의 보조재료
   - 작품 강화의 촉매 또는 보조 투입물
   - 방문 고객 사건에 제공하는 지원품
4. 지원품으로 제공하면 고객의 행동·목적·환경·예상 상황과 자원의 지원 태그가 맞을 때 사건 성공 가능성을 높이거나 실패·손상·대파의 심각도를 완화할 수 있다.
5. 모든 보조재료와 촉매를 모든 고객 사건에 사용할 수 있는 것은 아니다. 각 자원은 제작·강화 용도와 별도로 `지원 가능 상황 태그`를 가질 수 있다.
6. 고객 지원에 사용한 자원은 제작·강화에 다시 사용할 수 없도록 실제 재고에서 차감하며, 사건 결과에 따라 `소모`, `사용 후 잔존`, `미사용 반환`, `분실` 중 하나로 기록할 수 있다.
7. 플레이어의 핵심 선택은 같은 자원을 현재 작품의 제작·강화에 투자할지, 고객의 사건 성공과 작품 생애를 지원하기 위해 제공할지 결정하는 기회비용이다.
8. 지원 자원의 효과는 주문 작품의 강화 단계·수식어·정밀강화 효과, 고객 역량, 조언 준수 여부와 사건 변수에 함께 반영하며 자동 성공을 보장하지 않는다.
9. 사건 결과 화면은 어떤 보조재료·촉매가 제공됐고 실제로 사용됐는지, 어떤 결과에 기여했는지, 얼마가 소모·반환됐는지를 확인할 수 있어야 한다.
10. 보조재료·촉매 상태의 지원품은 개별 작품 UID, 독립 소유권, 장기 작품 생애 또는 사건 연대기 세트 구성원을 만들지 않는다.
11. 지원품의 사용 기록은 해당 방문 고객 사건과 주 작품의 생애에 `자원 기여 기록`으로 연결할 수 있지만, 자원 자체를 역사 작품으로 승격하지 않는다.
12. 별도의 완성된 무기·방어구·장신구·도구를 추가로 납품한다면 그것은 `[지원품]`이 아니라 `[추가 작품]`이다. 추가 작품은 실제 납품·사용·기여 시 각자의 UID와 작품 생애를 가진다.
13. 원재료나 촉매가 제작 과정을 거쳐 지속 사용 가능한 완성 작품이 된 경우에만 새 완성 작품의 UID와 생애 규칙을 적용한다. 원재료 단계의 이력으로 작품 UID를 미리 만들지 않는다.
14. 자원별 지원 적격 태그, 지원 제공 수량, 제작·강화 대비 기회비용, 소모·반환 확률, 성공 가중치와 피해 완화량은 `RECOMMENDED_DEFAULT / TEST_VALUE`다.

```text
보조재료·촉매 획득

→ 플레이어 용도 선택
  ├─ 제작에 투입
  │  → 완성 작품 생성
  │  → 완성 작품부터 UID·내부 이력 적용
  ├─ 강화에 투입
  │  → 강화 판정·보호·정밀강화 지원
  └─ 방문 고객 지원품으로 제공
     → 고객 사건에서 상황 태그와 함께 판정
     → 성공 가능성 증가 또는 실패·손상·대파 완화 가능
     → 소모·잔존·반환·분실 기록
     → 주 작품 생애의 자원 기여 기록으로 연결
```

## 용어 경계

### 지원품

- `[보조재료]`, `[촉매]` 등 공용 재고 자원
- 제작·강화·고객 지원 사이에서 사용처를 선택
- 기본적으로 수량형 자원이며 독립 UID·작품 생애 없음
- 사건 연대기 세트의 작품 구성원이 아님

### 추가 작품

- 완성된 무기·방어구·장신구·지속 사용 도구
- 주 제품 외에 추가로 납품될 수 있음
- 실제 납품 후 각자 UID와 작품 생애 활성화 가능
- 같은 사건에 실제 기여하면 사건 연대기 세트 후보가 될 수 있음

## 보호 조건

- 제작용, 강화용, 지원용으로 동일 자원을 서로 다른 재고에 복제하지 않는다.
- 지원에 제공한 자원의 비용을 무시하거나 사건 종료 후 무조건 되돌려주지 않는다.
- 모든 보조재료·촉매가 모든 상황에 동일 효과를 내는 범용 정답이 되지 않게 한다.
- 지원품을 제공하지 않으면 자동 실패하도록 기본 성공률을 인위적으로 낮추지 않는다.
- 희귀 촉매를 고객에게 제공하는 선택이 항상 제작·강화보다 우월하거나 항상 손해인 고정 답이 되지 않게 한다.
- 지원품을 무제한 중첩해 확정 성공, 손상 완전 제거 또는 완전 소실 면제를 만들지 않는다.
- 고객 사건 지원을 위해 별도 소비품 제작·파밍 루프가 강화 코어보다 커지지 않게 한다.
- 수량형 자원의 사용 로그를 작품 생애와 동일한 장기 연대기로 과잉 추적하지 않는다.
- 지원 자원을 제공했다는 이유만으로 사건 연대기 세트 구성원을 부풀리지 않는다.
- 완성된 추가 작품과 소모성 지원 자원의 UI·데이터·결과 표시를 혼동하지 않는다.
