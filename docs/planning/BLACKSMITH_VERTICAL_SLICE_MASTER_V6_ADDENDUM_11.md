## Android 성능 우선순위

버티컬 슬라이스는 **상황별 성능 목표 + 적응형 연출 품질**을 사용한다.

일반 UI와 반복 강화의 반응성은 60fps를 목표로 한다. 고위 정밀강화와 세계 결과처럼 순간 부하가 큰 전용 연출은 60fps를 우선 목표로 하되, 시각 효과를 단계적으로 축소한 상태에서 안정적인 30fps까지 허용한다.

```text
일반 UI·목록·탭 이동
→ 60fps 목표

저위험 반복 강화
→ 60fps 목표
→ 입력 지연과 결과 판독 우선

일반 정밀강화
→ 60fps 목표
→ 부하 시 파티클·후처리 자동 축소

고위 정밀강화·세계 결과
→ 60fps 목표
→ 일시적 30fps 허용
→ 안정적인 30fps 아래의 지속 저하 금지
```

## 상황별 성능 계약

| 상황 | 성능 목표 | 우선 보존 항목 |
|---|---|---|
| 일반 UI·목록·탭 이동 | 60fps 목표 | 터치 반응, 스크롤 판독성, 화면 전환 맥락 |
| 저위험 반복 강화 | 60fps 목표 | 입력 반응, 결과 숫자, 비용·위험 갱신 |
| 일반 정밀강화 | 60fps 목표 | 10단위 진입 인지, 성공·실패·하락 정보 |
| 고위 정밀강화 | 60fps 목표, 일시적 30fps 허용 | +50 도달, 진화 형태, 대표 특수 수식어 |
| 세계 결과·경기 연출 | 60fps 목표, 일시적 30fps 허용 | 사건 결과, 장비 상태, 관계·연대기 변화 |
| 저장·판정·복구 | 프레임과 독립 | 중복 입력 방지, 정확한 판정, 상태 무결성 |

프레임 유지보다 중요한 절대 우선순위는 다음과 같다.

1. 입력이 누락되거나 중복 적용되지 않을 것
2. 결과 판정이 정확히 1회만 수행될 것
3. 비용·장비·관계·세계 상태 저장이 누락되지 않을 것
4. 성공·실패·하락·파괴·진화 결과를 읽을 수 있을 것
5. 플레이어가 다음 행동 가능 여부를 오해하지 않을 것

## 적응형 연출 축소 순서

성능 부하가 감지되면 핵심 정보와 장비 상태를 유지하고 장식 효과부터 축소한다.

권장 축소 순서:

```text
1단계
→ 보조 파티클 수 감소
→ 화면 밖 파티클 제거

2단계
→ 화면 흔들림 강도·횟수 감소
→ 잔광·블룸·후처리 축소

3단계
→ 배경 장식 애니메이션 단순화
→ 비핵심 반사·그림자·변형 효과 축소

4단계
→ 연출 프레임을 안정적인 30fps로 제한
→ 핵심 장비 외형·결과 문구·아이콘·숫자는 유지
```

다음 항목은 자동 품질 조정으로 제거하거나 숨길 수 없다.

- 현재 장비와 강화 단계
- 성공률 또는 확정 성공 표시
- 비용·소비 재료
- 최대 단계 하락과 영구 파괴 여부
- 보호 적용 결과
- 성공·실패·하락·파괴 결과 문구
- 고위 정밀강화의 선택 진화 형태
- 대표 특수 수식어
- 고객·사건의 남은 영업일
- 저장 실패·복구 상태

## 입력·판정·저장 무결성

성능 저하는 게임 규칙 또는 상태 무결성에 영향을 주지 않는다.

- 프레임 저하 중 빠른 연속 탭을 여러 강화로 처리하지 않는다.
- 판정과 원자적 저장 완료 전 다음 비가역 입력을 잠근다.
- 연출 프레임이 끊겨도 판정을 다시 수행하지 않는다.
- 품질 자동 조정이 성공률·비용·하락·파괴 확률을 변경하지 않는다.
- 저장 완료 전 성공 연출을 먼저 보여주지 않는다.
- 연출 단축·건너뛰기와 성능 자동 조정은 서로 독립적으로 처리한다.
- 앱이 백그라운드로 이동해도 세계 시간이 자동 진행되지 않는다.

```text
프레임 부하 발생
→ 입력 상태 유지
→ 판정 1회 유지
→ 원자적 저장 완료
→ 현재 품질 단계에 맞춰 저장된 결과 표현
```

## 모션 감소와 저성능 모드

모션 감소는 접근성 설정이며, 저성능 자동 조정과 목적을 구분한다.

- 모션 감소: 화면 흔들림·섬광·급격한 확대·반복 파티클을 사용자 선택으로 줄임
- 적응형 품질: 기기 부하에 따라 장식 효과를 자동 축소
- 두 기능이 동시에 적용돼도 핵심 정보는 한 번만 명확하게 표시
- 모션 감소 사용자를 낮은 연출 등급이나 보상으로 취급하지 않음
- 저성능 기기에서도 무음·무진동·모션 감소 상태로 전체 슬라이스 진행 가능

## 로딩과 화면 전환 원칙

정확한 로딩 시간 수치는 기준 기기 결정 후 확정하지만 다음 사용자 경험 계약을 적용한다.

- `[대장간]`, `[방문 고객]`, `[세계]`의 주요 탭 전환은 작업 맥락을 잃지 않아야 한다.
- 장비·고객·사건의 핵심 텍스트 정보는 무거운 연출 자산보다 먼저 표시할 수 있다.
- 로딩 중 동일 행동을 반복 입력할 수 없게 한다.
- 저장·세계 결과 처리 중에는 현재 상태와 처리 중임을 표시한다.
- 장시간 정지 화면처럼 보이는 구간을 두지 않는다.
- 로딩 실패를 강화 실패·거래 실패·사건 실패로 위장하지 않는다.

## 메모리·장시간 세션 경계

15~25분 버티컬 슬라이스를 반복 플레이해도 누적 성능 저하가 없어야 한다.

검증 대상:

- 반복 강화 후 파티클·사운드·진동 객체가 누적되지 않는지
- 여러 장비를 전환해도 이전 장비 연출 자산이 계속 남지 않는지
- 고객 네 유형의 화면을 순회해도 메모리가 지속 증가하지 않는지
- 세계 게시판·구독·경기 결과를 반복 열어도 목록 성능이 저하되지 않는지
- 앱 백그라운드 복귀 후 입력·사운드·연출이 중복 실행되지 않는지
- 고위 정밀강화 이후 일반 작업대로 복귀했을 때 전용 자산이 적절히 정리되는지

정확한 메모리 상한은 기준 Android 기기와 콘텐츠 자산 크기 확정 후 정한다.

## 버티컬 슬라이스 성능 검증

버티컬 슬라이스에서 최소한 다음을 검증한다.

- 일반 UI와 목록 스크롤이 목표 반응성을 유지하는지
- 저위험 반복 강화가 프레임 대기 게임으로 변하지 않는지
- 일반 정밀강화의 결과를 성능 저하 중에도 오해하지 않는지
- 고위 정밀강화에서 30fps 허용 구간이 지속적인 심각 저하로 이어지지 않는지
- 자동 품질 축소 순서가 핵심 장비 외형과 결과 정보를 보존하는지
- 프레임 급락 중 연타로 강화·비용이 중복 적용되지 않는지
- 저장 완료 전후 앱 중단에서 동일 결과로 복귀하는지
- 15~25분 세션 반복 후 프레임·메모리·입력 반응이 악화되지 않는지
- 모션 감소·무음·무진동 상태에서도 동일 흐름을 완료할 수 있는지

## 미정 항목

다음 수치는 Android 플랫폼 범위와 기준 기기 결정 후 확정한다.

- 최소 지원 Android 버전
- 기준 저사양·중간·상위 기기
- 화면 해상도와 화면 비율 범위

- 초기 실행과 저장 복귀 로딩 목표
