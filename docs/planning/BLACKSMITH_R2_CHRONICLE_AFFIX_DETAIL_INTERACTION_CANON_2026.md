## 1. 결정 요약

장비명은 세 수식어 슬롯을 다음 형식으로 조합해 표시한다.

```text
[등급 수식어] 촉매 수식어 기본 작품명 - 연대기 수식어
```

대표 예시:

```text
[명품] 예리한 강철 장검 - 투기장의 승자
```

- `[명품]`: 등급 수식어
- `예리한`: 촉매 수식어
- `강철 장검`: 주재료와 작품 종류가 결정한 기본 작품명
- `투기장의 승자`: 연대기 수식어

데이터는 계속 `GRADE_AFFIX / CATALYST_AFFIX / CHRONICLE_AFFIX`의 독립 슬롯으로 저장한다. 이름 조합은 표시 규칙이며 슬롯의 생성 원인이나 성장 규칙을 합치지 않는다.

## 2. 빈 슬롯 이름 조합

아직 형성되지 않은 수식어는 장비명에서 자연스럽게 생략한다.

```text
[명품] 강철 장검
[명품] 예리한 강철 장검
[명품] 강철 장검 - 투기장의 승자
[명품] 예리한 강철 장검 - 투기장의 승자
```

- 등급 수식어는 제작 완료 후 항상 존재한다.
- 촉매 수식어가 `EMPTY`이면 촉매 수식어 부분을 생략한다.
- 연대기 수식어가 `EMPTY`이면 하이픈과 연대기 수식어 부분을 함께 생략한다.
- 과거 연대기 수식어를 장비명 뒤에 여러 개 나열하지 않는다. 장비명에는 현재 활성 연대기 수식어 하나만 표시한다.

## 3. 연대기 수식어 누르기

연대기 수식어가 존재할 때 장비명 뒤의 연대기 수식어 부분은 명확한 누르기 대상으로 동작한다.

```text
[명품] 예리한 강철 장검 - 투기장의 승자 ›
                         └ 연대기 상세 열기
```

- 누르기 대상은 연대기 텍스트 전체와 충분한 주변 여백을 포함한다.
- 색상만으로 누를 수 있음을 전달하지 않는다.
- 텍스트, 화살표·정보 표식 또는 동등한 비색상 단서를 함께 사용한다.
- 장비명 전체를 눌러 다른 화면으로 이동하는 동작과 충돌하지 않도록 연대기 수식어 대상 영역을 구분한다.
- 연대기 수식어가 없는 장비명에는 빈 하이픈이나 가짜 누르기 대상을 만들지 않는다.

## 4. 상세 표시 방식

연대기 수식어를 누르면 현재 장비 상세 맥락을 유지하는 `하단 상세 패널 / BOTTOM_SHEET`을 연다.

- 별도 인벤토리 페이지로 강제 이동하지 않는다.
- 닫기 또는 뒤로 가기 시 기존 장비 상세의 스크롤·선택 상태로 돌아간다.
- 패널은 읽기 전용 정보 화면이다.
- 패널을 여는 행위 자체가 연대기 생성·진화·보상 수령·확률 판정을 발생시키지 않는다.

## 5. 연대기 상세 정보 계약

하단 상세 패널은 다음 정보를 구분해 표시한다.

### 5.1 현재 연대기 수식어

- 현재 연대기 수식어 이름
- 수식어의 의미를 설명하는 짧은 요약
- 현재 연대기 단계 또는 상태가 존재한다면 해당 상태

### 5.2 최초 형성 기록

- 연대기 수식어가 처음 생성된 핵심 사건
- 사건 또는 일정 식별 정보
- 사건 당시 소유자·고객
- 사건 결과
- 사건 후 작품 상태 변화

### 5.3 주요 연대기 타임라인

시간 또는 사건 순서대로 중요한 기록만 표시한다.

- 주요 승리·패배·생존·구조
- 전쟁·원정·사냥·의례·전시·수상
- 큰 손상·상실·회수·복원
- 증여·상속·소유권 변화
- 연대기 수식어의 성장·분기·변형을 발생시킨 기록

일반적인 반복 사용, 의미 없는 이동, 동일한 낮은 위험 활동의 모든 로그를 그대로 나열하지 않는다.

### 5.4 수식어 진화 계보

연대기 수식어의 이름이 변했다면 이전 상태를 삭제하지 않고 계보로 표시한다.

```text
투기장의 생존자
→ 투기장의 승자
→ 왕관 없는 검투왕의 검
```

- 장비명에는 현재 수식어만 노출한다.
- 상세 패널에는 이전 수식어 이름과 변화 계기를 보존한다.
- 무관한 사건 하나로 기존 계보를 설명 없이 교체하지 않는다.

### 5.5 현재 효과와 가치

연대기 수식어가 현재 제공하는 내용이 있다면 서사 설명과 분리해 표시한다.

- 조건부 효과
- 적용 대상 콘텐츠
- 감정 가치·위신·역사성
- 현재 발동 조건 또는 제한

효과가 없는 순수 기록형 연대기 수식어라면 효과가 있는 것처럼 꾸미지 않고 `기록·위신 중심` 또는 동등한 상태로 표시한다.

## 6. 데이터 출처와 추적성

연대기 상세의 모든 항목은 해당 작품 UID의 기록에서 가져온다.

```text
ITEM_UID
→ CHRONICLE_RECORDS
→ CHRONICLE_AFFIX_HISTORY
→ CURRENT_CHRONICLE_AFFIX
```

- 수식어 형성·진화에 사용된 핵심 기록은 원본 사건·고객·소유·손상·복원 기록과 연결된다.
- 실제 기록에 없는 사건을 장식용 문장으로 만들어 사실처럼 표시하지 않는다.
- 해결되지 않은 미래 사건이나 숨은 결과를 미리 노출하지 않는다.
- 동일 사건을 여러 표현으로 중복 집계하지 않는다.

## 7. 촉매 수식어 상세와의 분리

연대기 상세 패널은 촉매 수식어의 생성 근거를 대신하지 않는다.

```text
예리한
→ 촉매·정밀강화·누적 촉매 이력

투기장의 승자
→ 고객·사건·사용·손상·복원·소유 연대기
```

- 연대기 상세에 촉매 조합을 연대기 생성 원인처럼 표시하지 않는다.
- 촉매 상세가 필요하면 별도 촉매 수식어 정보 진입점에서 제공한다.
- 연대기 패널을 열어도 촉매 수식어가 성장·변형되지 않는다.

## 8. 모바일 가독성과 접근성

- 연대기 수식어 텍스트가 길면 장비명 영역에서 한 줄 또는 제한된 줄 수로 줄이고 상세 패널에서 전체 이름을 보여준다.
- 누르기 영역은 텍스트 글자 크기에만 맞춘 작은 영역으로 제한하지 않는다.
- 색상·희귀도 광택·아이콘 하나만으로 상호작용 가능 여부를 전달하지 않는다.
- 패널 제목과 닫기 동작에는 텍스트 또는 접근 가능한 이름을 제공한다.
- 타임라인은 장식 아이콘 없이도 사건 순서와 결과를 이해할 수 있어야 한다.

정확한 터치 영역 크기, 글자 크기, 패널 높이와 애니메이션은 후속 UX 구현 프리셋에서 정한다.
