## 1. 현재 적용 범위

이 문서는 세 독립 수식어 중 `촉매 수식어 / CATALYST_AFFIX` 한 슬롯만 소유한다.

```text
등급 수식어 = 제작 등급에서 생성, 동일 UID에서 고정
촉매 수식어 = 촉매 이력에서 확률적으로 생성·성장·분기·변형
연대기 수식어 = 실제 작품 연대기에서 생성·진화
```

과거 `일반 수식어 A·B` 표현은 `BS-CRAFT-20260804-06`에 의해 대체되었다. 촉매 수식어는 한 슬롯이며 연대기 수식어와 등급 수식어를 생성·변경하지 않는다.

## 2. 촉매 수식어 책임

촉매는 다음을 설정한다.

1. 후보 수식어 가족
2. 후보 계보별 가중 확률
3. 최초 씨앗의 성향
4. 같은 계보 강화 확률
5. 호환 계보 분기·혼합 변형 확률
6. 결과 단계와 품질 범위
7. 주재료·강화 방식과의 호환성

촉매는 다음을 확정하지 않는다.

- 정밀강화 성공
- 정확한 수식어 이름
- 최고 수식어 단계
- 기존 계보와 무관한 임의 변형
- 등급 수식어 또는 연대기 수식어의 생성·변경

## 3. 생애주기

```text
EMPTY
→ SEED / 씨앗
→ DEVELOPED / 성장
→ EVOLVED / 진화
→ MASTERED / 완성
```

### 씨앗

- 최초 제작 시 촉매 수식어 슬롯은 `EMPTY`다.
- 첫 성공한 수식어 관련 정밀강화에서 현재 촉매가 후보 계보와 확률을 설정한다.
- 성공 시 후보 계보 중 하나가 확률적으로 `SEED`가 된다.

### 성장

- 강화 단계는 다음 정밀강화 기회와 성장 상한을 연다.
- 일반 강화만으로 촉매 수식어가 자동 상승하지 않는다.
- 실제 성장은 후속 정밀강화의 촉매 판정에서 발생한다.

### 진화·완성

```text
현재 촉매 수식어 계보
+ 현재 촉매
+ 누적 촉매 사용 순서
+ 주재료·강화 방식 호환성
+ 정밀강화 이정표 상한
→ 같은 계보 강화·호환 분기·혼합 변형·완성 후보
```

작품 연대기는 촉매 수식어의 계보·이름·단계를 직접 생성하거나 진화시키지 않는다. 연대기에서 파생되는 변화는 별도의 `CHRONICLE_AFFIX` 슬롯이 소유한다.

## 4. 촉매 조합

정밀강화 한 번당 촉매 입력은 한 칸이다.

```text
+10 촉매
+20 촉매
+30 촉매
+40 촉매
+50 촉매
= 작품 UID의 순서 있는 누적 촉매 이력
```

- 같은 촉매 계열 반복: 같은 계보 강화 가능성 상승
- 호환 촉매 전환: 계보 분기 가능성 상승
- 희귀 호환 이력: 혼합 변형 후보 추가
- 비호환 이력: 변형 가능성 감소 또는 비용·위험 증가 가능

동시 다중 촉매 슬롯은 기본 구조가 아니다. 필요한 경우 하나의 복합 촉매 아이템으로 별도 승인한다.

## 5. 초기 촉매 역할군

1. `TEMPERING_SALT / 담금질 염` — 방어·내구·안정 계보
2. `HIGH_HEAT_QUENCH / 고열 담금질유` — 공격·정밀·강한 결과 계보, 위험 증가
3. `STABILIZING_OIL / 안정화유` — 안정·취급 계보와 실패 완화, 최고점 대가
4. `ANTI_CORROSION_AGENT / 방청 촉매` — 환경 대응·원정 계보
5. `FINE_POLISHING_POWDER / 정밀 연마분` — 마감·세공·감정 가치 계보
6. `HERALDIC_FIXATIVE / 문장 정착제` — 위신·가문·증여 계보
7. `STAR_RESIDUE / 별재 촉매` — 희귀·특화·혼합 변형 후보, 높은 비용·불안정

정확한 후보 수·가중치·단계 확률은 `BASELINE_TEST_PRESET`이다.

## 6. 정밀 이정표 판정

### 빈 촉매 수식어 슬롯

- 촉매 계보 후보와 가능성을 표시한다.
- 성공 시 촉매 수식어 씨앗 하나를 생성한다.
- 실패 시 슬롯은 비어 있고 투입 재료만 소모한다.

### 기존 촉매 수식어 슬롯

- 동일 계보 강화
- 호환 계보 분기
- 호환 촉매 이력의 혼합 변형
- 변화 없음 또는 실패

기존 촉매 수식어를 무관한 계보로 교체하지 않는다. 실패 시 기존 촉매 수식어·계보·단계는 유지한다.

## 7. 사전 표시

```text
현재 촉매 수식어 계보·단계
현재 촉매
누적 촉매 이력
후보 수식어 가족
씨앗·강화·분기·변형 가능성: 낮음 / 보통 / 높음
성공·실패·재료 소모 위험
기존 계보 유지 여부
```

정확한 수식어 이름과 최종 단계는 확정적으로 공개하지 않는다. 후보로 표시하지 않은 무관한 계보가 성공 결과로 나오지 않는다.

## 8. 실패와 기록

- 실패 시 기존 강화 단계·등급 수식어·촉매 수식어·연대기 수식어·작품 기록은 유지한다.
- 이번 시도의 촉매와 투입 재료만 소모한다.
- 같은 이정표에서 무한 재시도하지 않는다.
- 모든 촉매 수식어 변화는 작품 UID의 촉매 이력과 진화 기록에 남긴다.

## 9. 적대적 보호 조건

- 촉매가 정확한 수식어·성공·최고 단계를 확정하는 구조 금지
- 촉매 수식어를 다시 A·B 두 슬롯으로 늘리는 구조 금지
- 연대기가 촉매 수식어를 직접 생성·성장·진화시키는 구조 금지
- 촉매가 연대기 수식어나 등급 수식어를 생성·교체하는 구조 금지
- 일반 강화마다 촉매를 선택하게 하는 구조 금지
- 정밀강화 한 번에 다중 촉매 슬롯을 두는 구조 금지
- 동일 이정표 무한 리롤 금지
- 기존 계보와 무관한 완전 무작위 교체 금지
- 촉매 하나가 모든 작품과 목적에서 최적이 되는 구조 금지

- 촉매 이력과 변형 미리보기
- 촉매 수식어 이름·효과·시각 콘텐츠
