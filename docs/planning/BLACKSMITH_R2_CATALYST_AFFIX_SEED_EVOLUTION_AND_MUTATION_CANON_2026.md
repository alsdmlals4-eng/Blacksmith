## 1. 결정 요약

정밀강화의 세 요소는 다음 책임을 가진다.

```text
주재료 = 작품 이름·기본 성능·재료 정체성
강화 방식 = 공격·방어·내구·무게·취급·예술성 등 세부 수치 방향
촉매 = 일반 수식어의 씨앗·계보·진화·변형 확률
```

촉매는 정확한 수식어와 성공을 확정하지 않는다. 촉매와 누적 촉매 이력은 `어떤 수식어 계열이 생기고, 기존 수식어가 어느 방향으로 성장·변형될 가능성이 높은가`를 결정한다.

일반 수식어 A·B는 촉매에서 시작한 계보를 가진다. 강화 단계와 작품 일대기는 그 계보를 강화·분기·완성한다. 별도의 활성 사건·일대기 수식어 한 칸은 기존 규칙대로 사건에서 발생하며 일반 수식어 A·B와 구분한다.

## 2. 핵심 흐름

```text
작품 종류 + 주재료
→ 기본 이름·기본 성능을 가진 수식어 없는 1차 완성품
→ 일반 강화로 강화 단계 상승
→ 정밀 이정표에서 강화 방식으로 세부 수치 방향 선택
→ 촉매로 수식어 후보 계보와 변형 확률 설정
→ 성공 시 수식어 씨앗 생성·강화·분기·변형 중 하나 발생
→ 다음 강화 단계와 작품 일대기로 성장 조건 축적
→ 이후 정밀 이정표의 촉매 이력과 일대기에 따라 진화·완성
```

일반 강화는 계속 한 입력 한 결과다. 수식어의 실제 생성·강화·변형 판정은 정밀 이정표에서만 처리해 일반 강화의 반복 흐름을 방해하지 않는다.

## 3. 주재료 책임

주재료는 다음을 결정한다.

- 작품 기본 이름
- 공격·방어·내구·무게·취급 등 기본 성능 범위
- 기본 가치와 제작 난이도 방향
- 재료 고유색·질감·표면·반사 특성
- 사용할 수 있는 강화 방식과 촉매 반응 범위

주재료는 일반 수식어를 직접 확정하지 않는다. 희귀 주재료도 모든 수식어 계보와 강화 방식에서 최고 효율을 보장하지 않는다.

## 4. 강화 방식 책임

강화 방식은 정밀강화에서 세부 수치 조정 방향을 소유한다.

- 날 보강: 공격력·정밀성
- 충격 흡수: 방어력·내구도
- 경량화: 무게 감소·취급성
- 균형 조정: 취급성·안정성
- 예술 마감: 예술성·가치
- 환경 처리: 환경 대응·특화 성능

강화 방식은 수식어의 정확한 이름이나 계보를 결정하지 않는다. 다만 방식과 맞지 않는 수식어 후보는 가중치가 낮아지거나 제외될 수 있다.

## 5. 촉매 책임 — 확정이 아닌 확률적 기본 설정

촉매는 일반 수식어 A·B에 다음을 제공한다.

1. 수식어 후보 가족
2. 후보 계보의 가중 확률
3. 최초 씨앗 수식어의 성향
4. 기존 수식어 강화·분기·변형 확률
5. 수식어 품질·단계 결과의 범위
6. 주재료·강화 방식·일대기와의 반응

촉매가 제공하는 것은 `결과 확정`이 아니라 `확률 분포와 계보 방향`이다.

예시:

```text
강철검 + 날 보강 + 고열 담금질유
→ 공격·정밀 수치 방향
→ 예리함·관통·강타 계보 확률 상승
→ 성공 시 후보 계보 중 하나의 씨앗 생성 또는 기존 계보 강화
```

```text
은합금 의장검 + 예술 마감 + 정밀 연마분
→ 예술성·가치 수치 방향
→ 마감·세공·감정 가치 계보 확률 상승
→ 성공 시 후보 계보 중 하나의 씨앗 생성 또는 기존 계보 진화
```

정확한 후보 수, 가중치, 단계별 확률은 `BASELINE_TEST_PRESET`이다.

## 6. 수식어 생애주기

일반 수식어 A·B는 다음 개념적 생애를 가진다.

```text
EMPTY
→ SEED / 씨앗
→ DEVELOPED / 성장
→ EVOLVED / 진화
→ MASTERED / 완성
```

이 단계명은 설계 계약이며 최종 UI 명칭과 정확한 단계 수는 후속 프리셋에서 조정할 수 있다.

### 6.1 씨앗

- 빈 일반 수식어 슬롯에서 첫 성공한 수식어 관련 정밀강화로 생성된다.
- 현재 촉매, 누적 촉매 이력, 주재료, 강화 방식이 후보 계보의 확률을 정한다.
- 정확한 수식어는 후보 계보 안에서 확률적으로 결정된다.

### 6.2 성장

- 강화 단계가 오를수록 수식어가 성장할 수 있는 상한과 다음 기회가 열린다.
- 일반 강화 단계만으로 즉시 수식어가 자동 상승하지 않는다.
- 실제 강화 판정은 다음 정밀 이정표의 수식어 관련 행동에서 발생한다.

### 6.3 진화

다음 요소가 함께 작동한다.

- 현재 수식어 계보
- 누적 촉매 이력
- 현재 정밀강화 촉매
- 강화 방식
- 작품 일대기의 관련 사건·사용 결과

같은 계보 촉매를 반복하면 기존 특성이 강화될 가능성이 높다. 인접 계보의 호환 촉매를 사용하면 분기 또는 혼합 변형이 가능하다. 관련 일대기 조건을 충족하면 사건 의미가 반영된 진화 후보가 추가된다.

### 6.4 완성

수식어 완성은 촉매 하나로 즉시 획득하는 결과가 아니다.

```text
초기 촉매가 계보 씨앗 설정
+ 강화 단계가 성장 기회와 상한 제공
+ 후속 촉매 이력이 강화·분기 방향 형성
+ 작품 일대기가 진화 조건과 의미 제공
→ 완성 수식어
```

완성 수식어도 작품의 모든 성능을 최고로 만들지 않는다. 기존 계보와 작품 생애를 압축해 보여주는 최종 성장 상태다.

## 7. 촉매 조합의 의미

기본 정밀강화는 `촉매 입력 한 칸`을 유지한다. 여러 촉매를 한 화면에 동시에 넣는 다중 슬롯은 기본 구조가 아니다.

`촉매 조합`은 다음을 뜻한다.

```text
+10에서 사용한 촉매
+20에서 사용한 촉매
+30에서 사용한 촉매
...
= 작품 UID에 누적된 촉매 이력
```

이 누적 순서와 반복·혼합 패턴이 후속 수식어 변형 확률에 영향을 준다.

- 같은 촉매 계열 반복: 기존 계보 강화 가능성 상승
- 인접·호환 촉매 전환: 분기 가능성 상승
- 희귀 호환 조합: 혼합 또는 특수 변형 후보 추가
- 비호환 조합: 변형 가능성 감소, 불안정·비용·실패 위험 증가 가능

동시 다중 촉매 레시피가 필요하면 하나의 `복합 촉매 아이템`으로 취급하고 별도 콘텐츠 Gate에서 승인한다.

## 8. 작품 일대기의 역할

작품 일대기는 수식어를 무에서 직접 생성하는 재료가 아니라 기존 계보의 성장·분기 조건이다.

관련 일대기 예시:

- 검투 경기 승리·패배
- 고객 생존·구조
- 장기 원정과 환경 극복
- 큰 손상과 복원
- 왕실 의례·전시·수상
- 가문 증여·상속
- 괴수·특수 위협 대응

일대기는 다음에 영향을 줄 수 있다.

- 진화 후보 추가
- 계보 이름·설명·시각 표현 변형
- 특정 효과의 강화 또는 조건부 발동
- 감정 가치·위신·역사성 증가

단순 반복 작업이나 같은 낮은 위험 사건의 무한 반복으로 일대기 진화를 파밍할 수 없도록 사건 중요도·고유성·반복 감쇠를 둔다. 정확한 판정은 `BASELINE_TEST_PRESET`이다.

## 9. 정밀 이정표 수식어 판정

수식어 관련 정밀강화에서 가능한 결과는 현재 슬롯 상태에 따라 달라진다.

### 빈 슬롯

- 촉매 계보 후보와 확률 표시
- 성공 시 씨앗 수식어 하나 생성
- 실패 시 슬롯은 비어 있고 투입 재료만 소모

### 기존 수식어 슬롯

- 동일 계보 강화
- 인접 계보 분기
- 호환 계보 혼합 변형
- 일대기 조건 진화
- 변화 없음 또는 실패

기존 수식어를 완전히 무관한 계보로 바꾸는 무작위 변형은 금지한다. 변형 가능성이 있을 때는 실행 전에 기존 계보 유지·분기·혼합 후보와 주요 위험을 표시한다.

## 10. 일반 수식어와 사건·일대기 수식어 분리

- 일반 수식어 A·B: 촉매에서 시작한 계보, 강화 단계와 일대기로 성장·진화
- 활성 사건·일대기 수식어 한 개: 실제 사건·사용·소유 이력에서 발생하고 별도 진화 기록 유지

작품 일대기는 일반 수식어 A·B의 진화 조건으로 사용될 수 있지만, 별도 사건·일대기 수식어 슬롯을 삭제하거나 대체하지 않는다.

## 11. 사전 표시 계약

수식어 관련 정밀강화 전 다음을 텍스트로 표시한다.

```text
현재 수식어 계보
현재 촉매와 누적 촉매 이력
후보 수식어 가족
씨앗·강화·분기·변형 가능성: 낮음 / 보통 / 높음
관련 작품 일대기 조건
성공·실패·재료 소모 위험
기존 계보 유지 여부
```

- 정확한 수식어 이름과 최종 단계는 확정적으로 공개하지 않는다.
- 색상·아이콘만으로 확률과 변형 방향을 전달하지 않는다.
- 성공 시 후보로 제시하지 않은 무관한 계보가 나타나지 않는다.
- 모든 변화는 작품 UID의 촉매 이력과 수식어 진화 기록에 남긴다.

## 12. 실패와 보호 규칙

기존 정밀강화 실패 계약을 유지한다.

- 실패 시 기존 강화 단계·등급·수식어·수식어 단계·작품 일대기는 유지
- 이번 시도의 촉매와 투입 재료만 소모
- 실패한 정밀 이정표는 완료되고 같은 이정표에서 무한 재시도 불가
- 실패가 기존 수식어를 무관한 계보로 강제 변형하거나 삭제하지 않음

## 13. 적대적 보호 조건

- 촉매가 정확한 수식어·성공·최고 단계까지 확정하는 구조 금지
- 촉매가 강화 방식의 세부 수치 역할까지 소유하는 역할 중복 금지
- 일반 강화마다 촉매를 선택하게 해 반복 흐름을 끊는 구조 금지
- 정밀강화 한 번에 다중 촉매 슬롯을 늘리는 조합 폭발 금지
- 동일 이정표 무한 재시도로 원하는 수식어를 확정하는 리롤 금지
- 기존 계보와 무관한 완전 무작위 변형 금지
- 사전 표시 없이 기존 수식어 계보를 삭제·교체하는 구조 금지
- 촉매 하나가 모든 주재료·강화 방식·고객 목적에서 최적인 구조 금지
- 낮은 위험 반복 사건으로 일대기 진화를 무한 파밍하는 구조 금지
- 강화 단계만으로 수식어가 자동 완성되는 구조 금지
- 일대기만으로 촉매 선택과 강화 이정표가 무의미해지는 구조 금지
- 일반 수식어 A·B와 별도 사건·일대기 수식어의 역할 혼합 금지

## 14. 후속 Gate

1. 촉매별 후보 수식어 가족과 확률 등급
2. 일반 수식어 계보와 분기·혼합 관계
3. 강화 이정표별 씨앗·성장·진화·완성 가능 범위
4. 일대기 조건의 중요도·반복 감쇠·진화 후보
5. 촉매 이력 UI와 변형 미리보기
6. 수식어 이름·효과·시각 변화 콘텐츠
7. exact 확률·비용·위험은 `BASELINE_TEST_PRESET`
