# 블랙스미스 기획 결정 원장 추가 기록 02

> 상태: `PLANNING_IN_PROGRESS`
>
> 기준일: 2026-07-26
>
> 범위: 분야별 기술 돌파 상한 배치와 최초 상한 `+40`

## 1. 결정 추적표

| 영역 | 결정 | 상태 | 최신 규칙 | 병합 조치 |
|---|---|---|---|---|
| 돌파 상한 배치 | 모든 10강마다 기술 돌파 | `REJECTED` | 여러 정밀강화 구간을 묶은 대형 경계에서만 요구 | 잦은 흐름 차단 방지 |
| 돌파 상한 배치 | 숙련과 무관한 임의 상한 | `REJECTED` | 강화 단계의 명확한 `+N0` 경계에서 정밀강화 후 정지 | 장비 단계와 성장 관계 유지 |
| 최초 기술 돌파 | 최초 상한 미정 | `SUPERSEDED` | 최초 분야별 기술 돌파 상한은 `+40` | 성장 문서에 확정값 기록 |
| +40 처리 | 정밀강화 없이 돌파 | `REJECTED` | `+40` 일반 정밀강화 완료 후 돌파 대기 | 정밀강화 책임 유지 |
| +40 처리 | 돌파 전 +41 우회 강화 | `REJECTED` | 돌파 전 +41 버튼 비활성화, 재화 미소모 | 상한 규칙 고정 |
| +40 장비 | 돌파 재료로 소비 | `REJECTED` | 사용·판매·납품·전시 가능, 돌파 비용으로 소비하지 않음 | 코어 판매 루프 보호 |
| 돌파 적용 범위 | 장비별 개별 해금 | `REJECTED` | 계정·장비 분야별 영구 해금 | 반복 병목 방지 |
| 돌파 완료 후 | +40 정밀강화 재수행 | `REJECTED` | 기존 정밀강화 결과 유지, 즉시 +41 구간 개방 | 중복 관문 금지 |
| 후속 상한 | +80 또는 +100 확정 | `UNRESOLVED` | 두 번째 이후 상한과 간격은 별도 결정 | 임의 수치 확정 금지 |

## 2. 최신 순서

```text
해당 분야 장비 +40 도달
→ +40 일반 정밀강화 완료
→ 분야별 최초 기술 돌파 조건·비용 확인
→ 즉시 확정 돌파
→ 해당 분야 전체에 +41 이상 구간 영구 개방
```

## 3. 교차 시스템 제약

- 고위 정밀강화는 `+50` 이후 규칙을 유지한다.
- `+40` 최초 돌파에는 특수 재료를 사용하지 않는다.
- 분야별 기술 돌파는 확률, 실패, 이해도, 보장선, 연구 시간, 연구 슬롯을 사용하지 않는다.
- 장비 보유 여부는 돌파 자격이 아니다. 분야 숙련·공통 등급·선행 기술·시설과 요구 자원이 자격을 결정한다.
- 다른 장비 분야의 돌파 상태는 공유하지 않는다.

## 4. 남은 미결정

- 두 번째 기술 돌파 상한
- 이후 고정 간격 또는 확장 간격
- 분야별 동일 상한 여부
- 돌파 단계 수
- 단계별 비용·숙련·등급·시설 조건
- 단계별 분야 기술 해금 내용

모든 미결정 수치는 `PROPOSED_ONLY`다.
