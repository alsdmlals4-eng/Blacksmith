# 블랙스미스 기획 결정 원장 추가 기록 02

> 상태: `PLANNING_IN_PROGRESS`
>
> 기준일: 2026-07-26
>
> 범위: 분야별 기술 돌파 최초 상한 `+40`과 이후 10강 주기

## 1. 결정 추적표

| 영역 | 결정 | 상태 | 최신 규칙 | 병합 조치 |
|---|---|---|---|---|
| 최초 기술 돌파 | 최초 상한 미정 | `SUPERSEDED` | 최초 분야별 기술 돌파 상한은 `+40` | 성장 문서에 확정값 기록 |
| 후속 돌파 간격 | 대형 경계마다 간헐적 돌파 | `SUPERSEDED` | `+40` 이후 `+50`, `+60`, `+70`처럼 10강마다 돌파 | 최신 주기 규칙으로 교체 |
| 후속 돌파 간격 | +80·+100 등 확장 간격 | `REJECTED` | 10강 고정 간격 | 임의 간격 확대 금지 |
| 경계 처리 | 정밀강화 없이 돌파 | `REJECTED` | 해당 +N0 정밀강화 완료 후 돌파 대기 | 정밀강화 책임 유지 |
| +50 이후 처리 | 기술 돌파가 고위 정밀강화 대체 | `REJECTED` | 일반·고위 정밀강화 결과 확정 후 기술 돌파 | 시스템 책임 분리 |
| 돌파 전 우회 | 불리한 확률로 다음 단계 강화 | `REJECTED` | 돌파 전 +(N0+1) 버튼 비활성화, 재화 미소모 | 상한 규칙 고정 |
| 상한 장비 | 돌파 재료로 소비 | `REJECTED` | 사용·판매·납품·전시 가능, 돌파 비용으로 소비하지 않음 | 코어 판매 루프 보호 |
| 돌파 적용 범위 | 장비별 개별 해금 | `REJECTED` | 계정·장비 분야·돌파 단계별 영구 해금 | 반복 병목 방지 |
| 돌파 완료 후 | 같은 정밀강화 재수행 | `REJECTED` | 기존 정밀강화 결과 유지, 다음 구간 즉시 개방 | 중복 관문 금지 |
| 돌파 방식 | 확률·실패·연구 대기 | `REJECTED` | 조건과 비용 충족 시 즉시 확정 완료 | 강화 흐름 장기 중단 방지 |

## 2. 최신 경계 순서

### 최초 경계

```text
해당 분야 장비 +40 도달
→ +40 일반 정밀강화 완료
→ 해당 분야 1차 기술 돌파
→ +41 강화 개방
```

### +50 이후 경계

```text
해당 분야 장비 +N0 도달
→ 일반 정밀강화 또는 +50 이후 고위 정밀강화 결과 확정
→ 해당 분야 다음 기술 돌파
→ +(N0+1) 강화 개방
```

적용 경계:

```text
+40, +50, +60, +70, +80, +90, +100, ...
```

## 3. 교차 시스템 제약

- `+40`에서는 일반 정밀강화만 가능하다.
- 고위 정밀강화는 `+50` 이후 규칙을 유지한다.
- `+50` 이후 고위 정밀강화의 성공·실패는 기술 돌파의 성공 여부와 무관하다.
- 정밀강화 결과가 먼저 확정되어야 같은 경계의 기술 돌파를 실행할 수 있다.
- 기술 돌파는 정밀강화 결과를 바꾸거나 다시 판정하지 않는다.
- 분야별 기술 돌파는 이벤트 특수 재료를 사용하지 않는다.
- 분야별 기술 돌파는 확률, 실패, 이해도, 보장선, 연구 시간, 연구 슬롯을 사용하지 않는다.
- 장비 보유 여부는 돌파 자격이 아니다. 분야 숙련·공통 등급·선행 기술·시설과 요구 자원이 자격을 결정한다.
- 다른 장비 분야의 돌파 상태는 공유하지 않는다.

## 4. 남은 미결정

- 분야별 돌파 단계의 정확한 비용 곡선
- 단계별 숙련·공통 등급·시설 조건
- 각 돌파 단계에서 개방되는 분야 보조 기술
- 메인 전문 분야 트리 접근 조건과의 연결
- 최고 강화 상한 존재 여부

모든 미결정 수치는 `PROPOSED_ONLY`다.
