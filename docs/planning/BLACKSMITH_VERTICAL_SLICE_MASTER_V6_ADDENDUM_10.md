## 접근성 지원 범위

버티컬 슬라이스는 **핵심 정보 접근성 계약 + 확장 가능한 구조**를 사용한다.

모든 접근성 기능을 완성형 제품 수준으로 선행 구현하지는 않지만, 강화·고객·세계 진행의 핵심 판단과 비가역 결과를 특정 색상, 사운드, 진동, 모션 또는 입력 방식 하나에만 의존하지 않도록 기획 단계에서 계약한다.

```text
시각 정보
→ 색상 + 아이콘 + 문구 + 숫자

입력
→ 기본 입력 + 접근성 대체 입력

감각 피드백
→ 사운드·진동·모션 각각 독립 설정

화면 읽기
→ 핵심 판단 순서와 상태를 의미 있게 제공
```

## 시각 정보 접근성

### 색상 의존 금지

성공·실패·단계 유지·단계 하락·영구 파괴·정밀강화·고위 정밀강화를 색상만으로 구분하지 않는다.

각 결과는 다음 정보 중 둘 이상을 결합한다.

- 결과 아이콘
- 명확한 결과 문구
- 이전 단계와 현재 단계 숫자
- 손실·소비 자원 요약
- 보호 적용 여부
- 장비 상태 변화
- 필요한 경우 전용 레이아웃 또는 연출 구조

예시:

```text
단계 하락
- 하락 아이콘
- `+47 → +45`
- `2단계 하락`
- 소비 재료 표시

영구 파괴
- 파괴 아이콘
- `장비가 영구 파괴되었습니다`
- 장비 이름·이전 강화 단계·주요 수식어
- 연대기 반영 여부
```

빨강·초록만으로 성공과 실패를 구분하거나, 색각 차이가 있는 사용자가 결과 방향을 오해하게 하는 구조를 사용하지 않는다.

### 텍스트 확대

버티컬 슬라이스에서는 최소한 다음 핵심 정보가 텍스트 확대 상태에서도 읽히고 조작 가능해야 한다.

- 현재 장비 이름과 강화 단계
- 목표 강화 단계
- 성공률 또는 확정 성공
- 총비용과 소비 재료
- 최대 단계 하락
- 영구 파괴 가능 여부
- 보호 사용 여부와 실제 효과
- 고객 요구·선호·야망
- 남은 영업일
- 약속·지원 기한
- 저장 복구와 비가역 결과 요약

확대 시 다음 상태를 허용하지 않는다.

- 강화 버튼이 화면 밖으로 밀려 조작할 수 없음
- 성공률·비용·파괴 위험이 겹쳐 읽을 수 없음
- 하단 고정 내비게이션 라벨이 잘려 영역을 구분할 수 없음
- 고객 비교에서 요구 조건 일부가 숨겨져 잘못 판매할 수 있음
- 남은 영업일이 생략되어 마감을 오해함

장식 문구, 세계관 서술과 긴 연대기 본문은 별도 스크롤 또는 펼치기 구조를 사용할 수 있다. 다만 핵심 판단 정보보다 장식 텍스트를 우선해 공간을 배분하지 않는다.

## 입력 접근성

### 길게 누르기 대체

비보호 영구 파괴 가능 강화와 고위 정밀강화의 기본 입력은 길게 누르기지만, 접근성 설정에서 `2단계 확인 버튼`으로 대체할 수 있다.

```text
1단계
→ 위험·비용·파괴 여부 확인
→ [다음]

2단계
→ 손실 요약 재확인
→ [강화 실행]
```

- 대체 입력은 기본 입력과 동일한 확률·비용·결과를 사용한다.
- 대체 입력 사용을 이유로 추가 비용이나 불이익을 부여하지 않는다.
- 설정 변경은 플레이 도중 가능하다.
- 길게 누르기와 대체 입력 모두 완료 전에는 자원을 소비하지 않는다.

### 한 손 조작

Android 세로형 화면에서 핵심 진행은 한 손 조작 경로를 유지한다.

- 강화 실행과 위험 확인은 하단 주요 조작 영역에서 접근 가능해야 한다.
- 하단 고정 내비게이션의 세 영역을 손가락 이동이 과도하지 않게 배치한다.
- 중요한 행동 버튼을 화면 모서리의 지나치게 작은 영역에 두지 않는다.
- 정보 열람을 위해 정밀한 드래그나 작은 아이콘 연속 선택을 요구하지 않는다.
- 장비·고객·사건 직접 이동 후 이전 맥락으로 돌아가는 경로를 명확히 제공한다.

정확한 터치 영역 수치는 UI 프로토타입과 Android 실기기 검증에서 결정한다.

### 중복 입력 방지

- 빠른 연속 탭이 여러 번의 강화 판정으로 처리되지 않아야 한다.
- 원자적 저장 완료 전 다음 비가역 행동 입력을 잠근다.
- 길게 누르기 진행 중 손을 떼면 취소하고 자원을 소비하지 않는다.
- 결과 연출 단축 설정이 중복 입력 허용으로 이어지지 않아야 한다.
- 화면 읽기 또는 대체 입력 사용 중 포커스 이동이 행동 확정으로 오인되지 않아야 한다.

### 시간 제한 입력 금지

핵심 진행과 비가역 선택에 짧은 시간 제한 입력을 사용하지 않는다.

금지 예시:

- 몇 초 안에 눌러야 강화 성공률이 유지되는 구조
- 제한 시간 안에 보호를 선택하지 않으면 비보호로 자동 실행되는 구조
- 고객 제안 화면 안에서 실시간 초읽기로 판매 선택을 강제하는 구조
- 화면 읽기 중 자동으로 다음 단계로 넘어가는 구조

게임 내 기한은 `남은 영업일`로 제공하며, 실제 조작 속도나 반응 시간으로 플레이어를 불리하게 만들지 않는다.

## 감각 대체와 설정 독립성

### 무음 플레이

사운드를 끈 상태에서도 다음을 완전히 이해할 수 있어야 한다.

- 강화 성공·실패·유지·하락·파괴
- 정밀강화와 고위 정밀강화
- 재료 소비와 비용
- 장비 진화와 대표 특수 수식어
- 고객 제안·약속·사건 기한
- 저장 복구와 오류 상태

효과음은 결과 인지와 타격감을 보조하지만 필수 정보를 독점하지 않는다.

### 무진동 플레이

진동을 끈 상태에서도 결과와 위험 정보가 누락되지 않아야 한다.

- 영구 파괴를 진동 패턴으로만 알리지 않는다.
- 단계 하락 폭을 진동으로만 구분하지 않는다.
- 길게 누르기 진행도는 시각적으로 확인할 수 있어야 한다.
- 진동 비활성화가 입력 완료 여부를 불명확하게 만들지 않아야 한다.

### 모션 감소

모션 감소 설정에서는 다음을 줄이거나 대체한다.

- 화면 흔들림
- 급격한 확대·축소
- 강한 섬광
- 반복 파티클
- 장시간 회전·진동 애니메이션

제거된 연출 정보는 다음으로 대체한다.

- 결과 문구
- 상태 아이콘
- 단계 변화 숫자
- 진행도 표시
- 장비 외형 전후 비교
- 결과 요약 패널

모션 감소 상태에서도 일반 성공, 단계 하락, 영구 파괴, 일반 정밀강화와 고위 정밀강화를 서로 구분할 수 있어야 한다.

### 설정 독립성

다음 설정은 서로 독립적으로 변경할 수 있다.

- 효과음 켜기·끄기
- 효과음 음량
- 진동 켜기·끄기
- 모션 감소
- 반복 연출 단축·건너뛰기
- 길게 누르기 대체 입력
- 텍스트 확대 단계

한 설정을 바꿨다고 다른 설정을 자동으로 강제 변경하지 않는다. 모든 접근성 설정은 강화 확률, 비용, 판정 결과, 고객 보상과 세계 결과에 영향을 주지 않는다.

## 핵심 화면 읽기 계약

버티컬 슬라이스에서는 최소한 핵심 판단 흐름에 의미 있는 읽기 순서와 대체 문구를 제공한다.

### `[대장간]`

권장 읽기 순서:

1. 현재 장비 이름과 장비 유형
2. 현재 강화 단계와 목표 단계
3. 성공률 또는 확정 성공
4. 총비용과 소비 재료
5. 실패 시 최대 단계 하락
6. 영구 파괴 가능 여부
7. 보호 사용 여부와 실제 효과
8. 강화 실행 또는 위험 확인 버튼

장식용 망치·불꽃·배경 오브젝트를 핵심 정보보다 먼저 반복해서 읽지 않는다.

### `[방문 고객]`

권장 읽기 순서:

1. 고객 이름과 유형
2. 남은 영업일
3. 요구 조건
4. 선호
5. 야망
6. 후보 장비와 적합도
7. 확정 판매가·즉시 보상
8. 약속·지원 관련 책임
9. 판매·거절·대장간에서 준비 행동

정확한 사건 확률은 숨겨도 되지만, 현재 공개하기로 한 요구·가격·적합도·위험 방향을 화면 읽기 사용자에게 누락하지 않는다.

### `[세계]`

권장 읽기 순서:

1. 소식 또는 사건 제목
2. 공개 소식·구독 소식·행동 가능한 사건 구분
3. 관련 인물과 장비
4. 남은 영업일 또는 결과 발생 시점
5. 현재 지원 상태
6. 공개된 위험 방향과 보상 정보
7. 지원·배팅·관전·연대기 확인 행동

### 비가역 결과와 복구

다음 정보는 화면 읽기에서도 생략하지 않는다.

- 파괴되거나 소유권이 이전된 장비 이름
- 이전 강화 단계와 결과 단계
- 소비된 주요 자원
- 영구 파괴·분실·상속·진화 여부
- 저장 오류 이유
- 마지막 정상 복구 영업일
- 복구 시 예상 진행 손실 범위
- 실행 또는 종료 선택

## 접근성으로 변경하지 않는 정보 경계

접근성은 정보 전달 방식과 입력 방식을 확장하지만, 게임 규칙을 바꾸는 난이도 보정으로 사용하지 않는다.

- 성공률을 높이지 않는다.
- 실패·하락·파괴 확률을 낮추지 않는다.
- 재료비·보호비·판매가를 변경하지 않는다.
- 세계 사건 결과를 유리하게 보정하지 않는다.
- 고객 요구·기한을 완화하지 않는다.
- 약속 실패 책임을 자동 면제하지 않는다.

접근성 기능과 별도의 난이도·편의 설정이 필요하면 후속 기획에서 다른 계약으로 다룬다.

## 버티컬 슬라이스 검증

15~25분 버티컬 슬라이스에서 다음을 실제 검증한다.

- 색상 없이 성공·실패·하락·파괴를 구분할 수 있는지
- 텍스트 확대 후 성공률·비용·파괴 위험·강화 버튼이 겹치지 않는지
- 길게 누르기 대체 입력으로 고위험 강화를 완료할 수 있는지
- 무음·무진동 상태에서 모든 강화 결과를 이해할 수 있는지
- 모션 감소 상태에서 정밀강화와 고위 정밀강화 결과를 구분할 수 있는지
- 빠른 연속 탭이 중복 강화로 처리되지 않는지
- 화면 읽기 순서가 장식보다 핵심 판단 정보를 우선하는지
- 고객 요구·선호·야망과 남은 영업일을 화면 읽기로 이해할 수 있는지
- 저장 복구 화면에서 오류 이유와 손실 범위를 파악할 수 있는지
- 접근성 설정 변경이 확률·비용·보상에 영향을 주지 않는지

정확한 글자 크기 단계, 최소 터치 영역 수치, 지원 화면 크기, 화면 읽기 기술 범위와 기기 매트릭스는 UI 프로토타입 및 Android 실기기 검증에서 확정한다.

COLOR_ONLY_COMMUNICATION: FORBIDDEN
CRITICAL_TEXT_SCALING: REQUIRED
CRITICAL_INFORMATION_CLIPPING_OR_OVERLAP: FORBIDDEN
