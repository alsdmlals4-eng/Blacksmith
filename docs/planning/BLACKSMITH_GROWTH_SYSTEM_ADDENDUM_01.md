# 블랙스미스 성장 시스템 추가 결정 01 — 기술 돌파 전 강화 상한

> 상태: `PLANNING_IN_PROGRESS`
>
> 기준일: 2026-07-26
>
> 효력: 이 문서는 `BLACKSMITH_GROWTH_SYSTEM_PLANNING.md`의 분야별 기술 돌파 규칙을 보완한다. 충돌 시 이 문서의 최신 결정이 우선한다. 정확한 강화 경계와 요구 수치는 `PROPOSED_ONLY`다.

## 1. 확정 결정

분야별 기술 돌파를 완료하지 않은 장비는 현재 계정에 개방된 해당 분야의 최고 강화 단계에서 정지한다.

- 미돌파 상태에서 불리한 확률로 상위 강화를 우회할 수 없다.
- 상한 장비를 돌파 재료로 소비하지 않는다.
- 상한에 도달한 장비는 정상적으로 사용·판매·납품·전시할 수 있다.
- 상위 강화 버튼은 비활성화하고 부족한 돌파 조건을 표시한다.
- 비활성화된 상위 강화 조작으로 골드·재료를 소비하지 않는다.
- 해당 분야 기술 돌파를 완료하면 기존 상한 장비도 즉시 다음 강화 구간에 진입할 수 있다.
- 돌파는 장비별이 아니라 계정·분야별 영구 해금이다.

## 2. 정밀강화 이정표와 상한의 관계

기술 돌파 상한이 10강 정밀강화 이정표와 겹치면 다음 순서를 사용한다.

```text
해당 강화 이정표 도달
→ 정밀강화 완료
→ 현재 분야 기술 상한에서 정지
→ 분야별 기술 돌파 완료
→ 다음 강화 구간 개방
```

- 정밀강화를 완료하지 않은 채 상한을 우회할 수 없다.
- 정밀강화 결과와 장비 이력은 돌파 전후 모두 유지한다.
- 돌파 완료 후 같은 이정표의 정밀강화를 다시 요구하지 않는다.

## 3. UI 원칙

상위 강화 버튼 비활성화 상태에서 다음 정보를 제공한다.

- 현재 적용 중인 분야 기술 단계
- 다음 돌파 단계의 선행 숙련·공통 등급·자원 조건
- 돌파 완료 시 개방되는 강화 구간
- 현재 장비가 돌파 후 즉시 강화 가능한 상태인지 여부

상한 도달은 실패나 손상 상태가 아니라 `기술 돌파 대기` 상태로 표현한다.

## 4. 폐기된 대안

- `REJECTED`: 미돌파 상태에서 성공률·손실을 불리하게 하여 상위 강화 허용
- `REJECTED`: 상한 장비 한 점을 소비하여 분야별 기술 돌파

## 5. 미결정

- 분야별 각 돌파 단계의 정확한 강화 상한
- 정밀강화 이정표와 돌파 상한을 배치하는 구체적인 수치표
- 상한 도달 알림과 돌파 화면 연결 방식

위 항목은 모두 `PROPOSED_ONLY`다.
