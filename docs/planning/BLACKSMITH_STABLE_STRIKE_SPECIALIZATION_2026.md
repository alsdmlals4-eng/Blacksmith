## 1. 적용 우선순위

이 문서는 다음 구형 규칙과 재검토 상태를 대체한다.

- `안정 타격: 실패 완충 사용 시 하락 2를 하락 1로 완화`
- `BLACKSMITH_FAILURE_BOUND_PROTECTION_INTERACTION_2026.md`의 안정 타격 대체 효과 `REVIEW_REQUIRED`

실패 완충의 결과 변환, 보호석의 영구 소멸 방지, 보호 파괴 하락량은 기존 최신 책임 원본을 유지한다.

---

## 2. 전문화 정체성

`안정 타격`은 한 번의 실패 결과를 더 강하게 지우는 전문화가 아니다.

- 실패 완충을 더 자주 사용할 수 있게 한다.
- 장기 강화에서 완충 사용 사이의 공백을 줄인다.
- 성공률·파괴율·보호석 요구량은 직접 바꾸지 않는다.
- 보호석을 대체하거나 무보호 파괴를 막지 않는다.
- 보호 파괴 단계 손실을 추가로 감소시키지 않는다.

즉, `안정 타격`은 결과 강도가 아니라 **완충 사용 주기의 안정성**을 제공한다.

---

## 3. 승인 효과

기본 실패 완충 충전 최대치는 `100`이다.

일반 빌드:

```text
실패 완충 타격 사용
→ 충전값 100 전부 소비
→ 시도 시작 충전값 0
```

`안정 타격` 전문화:

```text
실패 완충 타격 사용
→ 충전값 100 소비 처리
→ 안정 타격 잔존 충전 20 적용
→ 시도 시작 충전값 20
```

승인값:

| 항목 | 값 |
|---|---:|
| 충전 최대치 | 100 |
| 일반 완충 사용 후 충전값 | 0 |
| 안정 타격 완충 사용 후 충전값 | 20 |
| 즉시 재사용 가능 여부 | 불가 |

잔존 충전 `20`은 `POC_TUNABLE / APPROVED_CURRENT`다. 출시 밸런스에서는 시뮬레이션 결과에 따라 조정할 수 있다.

---

## 4. 처리 순서

```text
1. 실패 완충 타격 사용 가능 여부 확인: 충전값 100
2. 보호석과 기타 자원 유효성 확인
3. 유효한 강화 시도 시작
4. 실패 완충 충전값 소비
5. 안정 타격 전문화가 활성화되어 있으면 충전값을 20으로 설정
6. 자연 강화 결과 판정
7. 실패 완충·보호석 결과 변환 처리
8. 해당 시도의 결과에 따른 충전 기여를 추가
9. 최종 충전값을 100 이하로 제한
```

결과 충전 기여는 잔존 충전 적용 뒤 더한다.

예시:

```text
안정 타격 + 실패 완충 사용
→ 시도 시작 잔존 충전 20
→ 매우 높은 위험 실패로 충전 기여 +45
→ 시도 종료 충전값 65
```

성공·대성공·유지에서도 완충 타격을 선택했다면 잔존 충전은 20으로 적용되며, 완충 선택을 취소하지 않는 한 충전값은 반환되지 않는다.

---

## 5. 다른 전문화와 역할 분리

| 전문화 | 핵심 역할 |
|---|---|
| 안정 타격 | 실패 완충 재사용 주기 단축 |
| 승부사의 망치 | 완충을 쓰지 않은 성공의 가치 보상 |
| 효율 제련 | 실패 재료 손실 완화 |

`안정 타격`은 성공 보상이나 재료 환급을 제공하지 않는다. 다른 전문화의 경제 역할과 중복하지 않는다.

---

## 6. 금지되는 추가 효과

안정 타격은 다음 효과를 갖지 않는다.

- 성공률 증가
- 대성공률 증가
- 하락·파괴 자연 확률 감소
- 무보호 파괴 방지
- 보호석 소비 감소 또는 반환
- 보호 파괴 하락량 추가 감소
- 실패 재료 반환

이 제한은 안정형 빌드가 보호석·숙련·효율 제련의 책임을 흡수하지 않도록 한다.

---

## 7. 검증 계약

POC와 후속 시뮬레이션은 최소 다음을 검증한다.

1. 일반 빌드 완충 사용 후 충전값 0
2. 안정 타격 완충 사용 후 충전값 20
3. 결과 충전 기여가 잔존 충전 뒤 더해짐
4. 최종 충전값이 100을 넘지 않음
5. 잔존 충전 20만으로 완충을 즉시 재사용할 수 없음
6. 무보호 파괴는 안정 타격 여부와 관계없이 즉시 소멸
7. 보호석·보호 파괴 결과는 안정 타격으로 추가 강화되지 않음
8. 성공률과 자연 결과 확률이 변하지 않음

보고 지표:

- 목표 강화 도달까지 완충 사용 횟수
- 완충 사용 사이 평균·중앙값 시도 수
- 잔존 충전으로 단축된 재충전 시도 수
- 무보호 파괴 소멸 횟수
- 보호석 총소모량
- 안정 타격과 다른 전문화의 기대 비용 차이
