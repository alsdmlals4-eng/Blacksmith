# 블랙스미스 통합 체험 POC 완료 기준선

> 상태: `PLANNING_IN_PROGRESS`
>
> 기준일: 2026-07-26
>
> 목적: 지금까지 승인한 강화·장비·고객 생애주기·거래·국가 시스템을 최소한 한 번씩 실제로 조작하고 결과를 확인할 수 있는 통합 POC 범위를 정의한다.
>
> 구현 게이트: 사용자의 정확한 명령 `기획 완료` 전에는 구현 단계로 전환하지 않는다.

## 1. POC의 목표

통합 POC는 콘텐츠 양을 증명하는 빌드가 아니라 **모든 핵심 기획 아이디어의 상호작용을 체험하고 검증하는 세로 절단면**이다.

완료된 POC에서는 플레이어가 다음을 직접 경험할 수 있어야 한다.

- 장비 제작과 제작 완성도
- 일반 강화와 위험 상승
- 10강 단위 정밀강화
- 정밀 등급 1개와 수식어 2개
- 일반·고위 정밀강화
- `[강화 한계 돌파]`를 포함한 강화 메인 빌드
- 강화 실패, 단계 하락, 손상, 보호석, 회복석
- 공개시장 판매와 특수 거래
- 고객 조언·자율성·신뢰·재방문·부상·회복
- 군사 보급과 국가 사건
- 밀수와 적발 위험
- 역사 장비·전시·수집가
- 장비 이력과 세계 기록
- 게임 날짜 종료와 지연 결과 보고

POC에서 모든 시스템의 전체 콘텐츠 수를 구현할 필요는 없다. 각 시스템은 대표적인 성공 경로와 의미 있는 실패·대안 경로를 최소 한 번 제공한다.

---

## 2. 접근 방식

통합 POC는 두 가지 진입 방식을 제공한다.

### 2.1 연속 체험 경로

하나의 장비와 고객 관계를 따라 주요 시스템이 자연스럽게 연결되는 경로다.

```text
검투사 요청
→ 장비 제작
→ +10 정밀강화
→ 고객 납품 또는 계속 강화
→ 경기 준비와 조언
→ 날짜 종료
→ 지연 경기 결과
→ 장비 이력 생성
→ 고객 재방문
→ 장비 회수·추가 강화
→ +40 도달
→ 강화 메인 빌드에 [강화 한계 돌파] 투자
→ +50 고위 정밀강화
→ 국가·수집가·밀수 선택으로 장비의 다음 생애 결정
```

### 2.2 POC 쇼케이스 진입

사람 검증과 개발 검증을 위해 각 시스템의 대표 상태로 바로 진입할 수 있는 별도 메뉴다.

- 정밀강화 선택 직전
- 정밀강화 실패 fixture
- +40 한계 도달과 메인 빌드 변경
- 최고위험 강화와 보호석
- `DAMAGED` 장비와 회복석
- 고객 조언·경기 결과·재방문
- 군사 보급과 국가 사건 종료
- 밀수 적발
- 역사 장비 수집가 흥정

쇼케이스는 생산 진행을 대체하지 않으며 `POC/TEST` 표시를 항상 유지한다.

## 3. POC 강화 범위

### 3.1 최대 강화치

통합 POC의 최대 강화치는 `+60`으로 확정한다.

이 범위는 다음을 한 세션에서 검증하기 위한 값이다.

- `+10`, `+20`, `+30`, `+40`, `+50`, `+60` 정밀강화
- 기본 활성 한계 `+40`
- `[강화 한계 돌파 I]`로 `+50` 개방
- `[강화 한계 돌파 II]`로 `+60` 개방
- `+50`부터 고위 정밀강화

출시 초기 목표 최대 강화치는 `+100` 방향으로 승인한다.

- 출시 범위에는 `+50`부터 `+100`까지 10강 단위 한계 돌파 노드를 둔다.
- 정확한 출시 포인트 비용·성공률·재료 곡선은 POC 데이터와 사람 테스트 뒤 조정한다.
- POC의 `+60` 제한은 출시 최종 상한이 아니다.

### 3.2 POC 강화 메인 포인트

POC 쇼케이스 프로필은 강화 메인 포인트 `8`을 제공한다.

| 사용처 | POC 비용 |
|---|---:|
| 강화 한계 돌파 I: 활성 한계 +50 | 2 |
| 강화 한계 돌파 II: 활성 한계 +60 | 3 |
| 역할 분기 초급 노드 | 각 1 |
| 역할 분기 중급 노드 | 각 2 |

- 고강화 경로에 5점을 사용하면 역할 분기에 최대 3점을 사용할 수 있다.
- 낮은 한계 빌드는 한계 노드를 회수하고 안정·성능·효율 분기를 더 깊게 체험할 수 있다.
- 공통 보너스 포인트는 `[강화 한계 돌파]`에 POC 기준 최대 1점만 보충할 수 있다.
- 모든 변경은 영업 전 준비 단계에서만 가능하다.
- POC 수치는 `POC_CONFIRMED`이며 출시 밸런스 수치가 아니다.

### 3.3 메인 전문화 최소 노드

POC에는 강화 역할 분기별 최소 2개 노드를 제공한다.

#### 안정 분기

- 실패 시 단계 하락 폭 완화
- `[안정 타격]`: 제한적인 성공률 보정 또는 실패 결과 완화

#### 성능 분기

- 고위험 성공 시 가치·성과 보정
- `[승부사의 망치]`: 성공 보상을 높이되 실패 위험을 줄이지 않음

#### 효율 분기

- 일반 강화 재료 절감
- `[효율 제련]`: 특정 조건에서 촉매 효율 또는 연속 강화 편의 제공

복구 관련 강한 효과는 POC 보조 노드 또는 회복석 시스템에서 대표 체험을 제공한다. 역할 분기 수와 효과는 POC 이후 확장할 수 있다.

## 4. 일반 강화 실패 POC 단계표

정밀강화 실패와 달리 일반 강화 실패는 구간별 위험 결과를 가진다.

POC 단계표는 다음 체험을 보장하기 위한 데이터 기준이다.

| 강화 구간 | 대표 실패 결과 |
|---|---|
| +1~+10 | 재료 소모, 단계 유지 |
| +11~+20 | 재료 소모, 단계 유지 또는 1단계 하락 |
| +21~+30 | 1단계 하락 중심 |
| +31~+40 | 1~2단계 하락, 낮은 손상 가능성 |
| +41~+50 | 1~3단계 하락, 손상 가능성 |
| +51~+60 | 2~4단계 하락, 최고위험 판정에서 손상·파괴 가능성 |

구조적 규칙:

- 고객 소유·역사·고유 장비는 파괴 판정에서 `DAMAGED`로 전환한다.
- 일반 플레이어 장비는 최고위험 판정에서 영구 파괴될 수 있다.
- 보호석은 영구 파괴만 `DAMAGED`로 전환한다.
- 보호석은 성공률·단계 하락·손상 정도를 개선하지 않는다.
- 정밀강화 실패에는 이 단계표를 적용하지 않는다.

정확한 POC 확률은 데이터로 조정하며 자동 테스트용 결정적 fixture를 별도로 둔다.

## 5. 제작·재가공 POC 기준

- 기존 5단계 제작 완성도를 사용한다.
- 제작 완성도는 제작 순간 확정한다.
- 제작 완성도는 정밀 등급 결정 가중치와 기본 가치에 영향을 준다.
- 장비당 재가공은 `+10` 정밀강화 이전에 1회만 허용한다.
- `+10` 이후에는 POC에서 재가공할 수 없다.
- 재가공은 제작 완성도를 최대 한 단계 높일 수 있으며 실패 시 재료만 소모한다.
- 재가공으로 장비 강화 단계·정밀 등급·수식어를 변경하지 않는다.

이 규칙은 POC 데이터 모델을 단순하게 유지하면서 제작 성장과 강화 성장의 책임을 분리한다.

## 6. 보호·회복 POC 기준

POC에는 다음을 모두 직접 체험할 수 있는 fixture를 제공한다.

1. 보호석 없이 일반 장비 파괴
2. 보호석 사용 후 `DAMAGED` 전환
3. 고객 장비의 자동 `DAMAGED` 전환
4. 회복석으로 사용 가능 상태 복구
5. 회복 가능한 일부 강화 단계 복구
6. 회복 기한 만료
7. `[보관]`으로 기한 정지

POC 수치:

- 회복 가능 손실 기록 유지: 게임 날짜 3일
- 장비당 최신 회복 기록: 1개
- 기본 `[보관]` 슬롯: 1개
- 회복석은 사용 가능 상태를 확정 복구
- 강화 단계는 손실분의 절반을 올림 처리해 복구하되 실패 직전 단계를 넘지 않음
- 보호석은 강화 시도 결과와 관계없이 소모

출시 수치는 POC 경제 테스트 뒤 조정한다.

## 7. 정밀강화 POC 범위

정밀강화 세부 규칙은 `BLACKSMITH_PRECISION_ENHANCEMENT_BASELINE.md`를 따른다.

POC 장비는 다음 상태를 모두 체험할 수 있어야 한다.

- 제작 완성도와 정밀 등급의 별도 표시
- 정밀 등급 결정
- 정밀 등급 강화
- 수식어 슬롯 A 추가
- 수식어 슬롯 B 추가
- 수식어 강화
- 정밀강화 실패 시 재료만 손실
- +50 고위 정밀강화
- 미등록 조합과 등록 조합
- 특수 재료 숙련 상승

대표 특수 재료 계열은 바람 계열 하나로 제한한다.

- 보조재료: `바람의 숨결`
- 촉매: `바람의 오브`
- 특수 재료: `폭풍군주의 핵`
- 등록 결과 계보: `폭풍왕의 가호를 받은`

POC에는 최소 4개의 일반 수식어 계보와 1개의 초희귀 계보를 제공한다.

## 8. 고객 생애주기 POC 범위

### 8.1 대표 고객

POC에는 서로 다른 성격을 가진 고객 2명을 제공한다.

#### 검투사

- 성향: 공격적·명예 지향
- 주요 행동: 고위험 경기 도전
- 대표 결과: 승리, 결정적 승리, 부상
- 장비 이력: 경기·기록·재방문

#### 병사

- 성향: 임무·생존 지향
- 주요 행동: 군사 보급 장비 사용
- 대표 결과: 임무 성공, 철수, 부상
- 장비 이력: 부대·국가 사건 기여

### 8.2 필수 생애 흐름

두 고객 중 최소 한 명은 다음 전체 흐름을 통과한다.

```text
첫 방문
→ 장비 요청
→ 장비 제공
→ 선택적 추적
→ 활동 준비
→ 조언 요청
→ 고객의 자율적 선택
→ 게임 날짜 종료
→ 지연 결과
→ 신뢰·기록 변화
→ 부상 또는 성장
→ 재방문
→ 기존 장비 회수·교체·추가 강화 선택
```

POC에서 확인할 고객 원칙:

- 조언 미응답으로 활동이 멈추지 않음
- 신뢰가 높아도 조언을 반드시 따르지 않음
- 일반 실패로 신뢰가 자동 하락하지 않음
- 고객 사망·영구 삭제 없음
- 추적 해제로 신뢰·이력·성장이 삭제되지 않음

## 9. 거래·세계 시스템 POC 범위

각 시스템은 대표 콘텐츠 1개를 제공한다.

### 공개시장

- 즉시 고정 매입가 판매
- 강화·완성도·등급·수식어·손상 상태의 가격 근거 표시

### 방문 고객 거래

- 고객이 요구 분야와 예산을 제시
- 플레이어가 장비를 제안
- 적합도 등급과 이유 표시
- 수동 가격 입력 없음

### 군사 보급

- 장비 분야·수량·최소 조건·기한이 있는 계약 1개
- 납품이 군사력 구성에 반영

### 밀수

- 합법 거래보다 높은 보상
- 적대 세력 강화 또는 국가 위험 상승
- 적발 위험 등급과 원인 표시
- 적발 fixture에서 벌금·몰수 또는 합법 수익 감액 체험

### 수집가·전시

- 역사 장비 1개
- 전시대 1개
- 수집가 테마 요청 1개
- 자동 감정과 짧은 흥정
- 첫 흥정 안전, 두 번째 흥정 위험

### 국가 사건

- 게임 날짜 종료 시 판정하는 사건 1개
- 군사력 총량과 구성, 정책, 장비 기록을 입력으로 사용
- 결과가 뉴스·영향력·고객 활동에 반영

## 10. POC 콘텐츠 수량

| 콘텐츠 | 최소 수량 |
|---|---:|
| 장비 분류 | 4종 모두 데이터·UI 노출 |
| 실제 세로 경로 중심 장비 | 주 장비 1종 |
| 추가 대표 장비 | 방어구·보조 장비·장신구 각 1종 |
| 제작 완성도 | 5단계 |
| 정밀 등급 위치 | 1개 |
| 수식어 슬롯 | 2개 |
| 일반 수식어 계보 | 4개 이상 |
| 초희귀 수식어 계보 | 1개 |
| 고객 | 2명 |
| 군사 계약 | 1개 |
| 밀수 계약 | 1개 |
| 국가 사건 | 1개 |
| 역사 장비 사건 | 1개 |
| 수집가 | 1명 |
| 전시대 | 1개 |
| 고정 조합 | 일반 1개, 고위 1개 |

콘텐츠 수량이 적어도 데이터 구조는 확장 가능해야 한다.

## 11. POC 시간·경제 압축

POC는 시스템 체험을 위해 생산 진행보다 빠르게 구성한다.

- 연속 체험 목표 시간: 45~60분
- 개별 쇼케이스 모듈: 5~15분
- 강화 재료는 주요 경로를 한 번 완료할 수 있을 만큼 지급
- 실패 결과를 체험해도 전체 경로가 막히지 않도록 보충 지급
- POC 재화에는 `TEST` 표식을 사용하지 않지만 POC 프로필 자체를 명확히 표시
- 생산 경제 밸런스 판정에는 POC 쇼케이스 지급량을 사용하지 않음

모든 비용·확률·보상은 데이터 파일에서 조정 가능해야 한다.

## 12. 자동 검증 기준

통합 POC 구현 후 다음 자동 검증이 필요하다.

### 정밀강화

- 장비당 정밀 등급 1개·수식어 슬롯 2개 계약
- 네 행동의 조건 검증
- 실패 시 투입 재료만 감소
- 실패 시 장비 단계·등급·수식어·이력 불변
- 이정표 결과 확정 뒤 같은 이정표 재시도 불가
- +50 이전 고위 정밀강화 차단
- 고정 조합 성공 시 계보 일치

### 강화 한계 돌파

- 기본 활성 한계 +40
- +50·+60 노드 순차 선행 조건
- 메인 포인트 공유
- 영업 중 변경 차단
- 회수 뒤 고강화 장비 유지·추가 강화만 차단

### 생애주기

- 조언 미응답 기본 행동
- 결과 지연과 날짜 종료 판정
- 장비 이력 영구 유지
- 고객 재방문
- 일반 실패에서 신뢰 자동 하락 금지

### 세계 시스템

- 군사 보급의 국가 수치 반영
- 밀수의 적대 수치·위험 반영
- 역사 장비 전시 효과
- 수집가 거래 철회 시 소유권 유지

### 안전성

- 거래·강화·회복의 원자성
- 중복 입력·재시도 중복 보상 방지
- 저장·불러오기 뒤 당일 빌드 잠금 유지

## 13. 사람 검증 기준

외부 신규 플레이어 6명을 권장한다.

통합 POC `ACCEPT` 기준:

- 5명 이상이 자신이 강화한 대표 장비를 구분해 기억
- 4명 이상이 제작 완성도와 정밀 등급의 차이를 설명
- 4명 이상이 정밀 등급 1개·수식어 2개 구조를 설명
- 4명 이상이 정밀강화 실패와 일반 강화 실패의 차이를 설명
- 4명 이상이 `[강화 한계 돌파]` 때문에 역할 분기 투자를 포기한 이유를 설명
- 4명 이상이 고객 조언이 명령이 아니라 확률·성향에 영향을 준다고 이해
- 4명 이상이 고객 결과 보고 또는 재방문을 자발적으로 확인
- 4명 이상이 공개시장과 특수 거래의 차이를 설명
- 3명 이상이 국가·밀수 선택이 세계 수치에 미친 영향을 설명
- 주요 경로 완주율 70% 이상
- 날짜 넘기기만 반복하는 세션 20% 미만
- 치명적 진행 막힘 0건

Android 실제 기기, 안전 영역, 모션 감소, 색상 비의존 정보, 대표·최악 장면 성능도 별도로 검증한다.

## 14. 완료 판정

통합 POC는 다음 세 상태를 분리한다.

1. `IMPLEMENTATION_COMPLETE`
   - 코드·데이터·Scene 작성 완료
2. `AUTOMATION_VALIDATED`
   - 계약·단위·통합·E2E·Godot 검증 통과
3. `HUMAN_VALIDATED`
   - Android·접근성·성능·외부 플레이 기준 충족

세 상태가 모두 충족되어야 `POC_ACCEPTED`를 선언한다.

기존 Issue #34는 현재 장비 한 점 생애 POC의 사람·플랫폼 검증을 위해 계속 열어 둔다. 통합 POC 구현 작업은 `기획 완료`와 검수 완료 뒤 별도 구현 이슈로 분리한다.

## 15. POC 비목표

- 출시 전체 콘텐츠 양
- 최종 확률·가격·재료 곡선
- 모든 고객 직업과 국가 구현
- 최종 아트·연출·음향 품질
- 라이브 운영·과금·상점 최종 구조
- 무한 강화 또는 출시 후 확장 구간
- 생산용 자동화 전체 범위

POC는 **기획 아이디어가 실제 플레이에서 연결되고 이해되는지**를 검증한다.
