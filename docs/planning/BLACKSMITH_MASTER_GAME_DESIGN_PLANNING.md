> 상태: `PLANNING_IN_PROGRESS`
>
> 기준일: 2026-07-25
>
> 목적: 현재 대화에서 사용자가 승인한 게임 기획을 하나의 책임 원본 후보로 통합한다.
>
> 주의: 이 문서는 기획 확정본이 아니다. 사용자의 정확한 명령 `기획 완료` 전까지 검수 단계로 전환하지 않는다. 정확한 수치, 단계 수, 보정량, 재화량, 확률표는 별도 승인 전까지 `PROPOSED_ONLY`다.

## 1. 프로젝트 코어

블랙스미스의 메인 장르는 **강화 중심 클리커 게임**이다. 고객 생애주기와 국가 이벤트는 메인 경제를 대체하지 않고, 고강화 장비에 추가 목적과 보상을 제공하는 보조·유지 시스템이다.

### 1.1 핵심 플레이 루프

```text
장비 제작
→ 반복 강화
→ 계속 강화할지 판매할지 판단
→ 고강화 장비 판매
→ 골드·재료 즉시 획득
→ 시설·재료·숙련에 재투자
→ 더 높은 강화에 재도전
```

### 1.2 코어 우선순위

1. `PROJECT_CORE`: 제작, 반복 강화, 위험 감수, 중단/계속 판단, 고강화 판매, 재투자
2. `CORE_SUPPORT`: 클릭 피드백, 피버, 자동 단조, 재료·촉매, 수식어, 품질, 시설
3. `SECONDARY_RETENTION_LOOP`: 방문 고객, 추적 고객, 대화·조언, 성장·재방문
4. `IDLE_REWARD_LAYER`: 실시간 준비, 게임 날짜 종료 시 결과 판정, 묶음 뉴스·보상

### 1.3 금지되는 역전

- 고객 생애주기 보상이 메인 강화·판매 수익을 대체하지 않는다.
- 조언을 확인하지 않았다고 고객 활동이 정지하거나 보상이 삭제되지 않는다.
- 이벤트와 고객 팝업이 강화 클릭 흐름을 강제로 끊지 않는다.
- 높은 강화는 고객 성공 확률을 높일 수 있으나 결과를 보장하지 않는다.

## 2. 시간·뉴스·고객 생애주기

### 2.1 하이브리드 시간

- 고객 활동 준비는 실제 시간 기준으로 진행하며 오프라인도 포함한다.
- 주요 결과, 기록, 귀환은 플레이어가 게임 날짜를 종료할 때 판정한다.
- 조언 미응답은 기본 성격 행동으로 처리하며 불이익을 주지 않는다.

### 2.2 뉴스

일상 활동은 묶어서 전달한다. 다음 사건은 강조한다.

- 조언 요청
- 부상
- 신뢰 변화
- 고유 이정표
- 기록 달성
- 주요 사건 준비 완료
- 귀환
- 새 장비 요청

읽지 않은 뉴스는 고객 활동을 막지 않는다.

### 2.3 고객 추적

- 플레이어는 고객을 팬처럼 선택적으로 추적한다.
- 활성 추적 슬롯은 최대 3개 방향으로 확정했으나 정확한 수치는 밸런스 검증 전까지 `PROPOSED_ONLY`다.
- 추적 해제는 신뢰를 낮추지 않는다.
- 관계, 장비 이력, 성장, 기록은 유지한다.
- 추적 해제 시 신규 활성 뉴스·이벤트만 중단한다.
- 귀환한 고객은 다시 추적할 수 있다.
- 추적 고객은 예정 방문이 있으며 간헐적으로 깜짝 방문할 수 있다.

### 2.4 조언과 고객 자율성

- 조언은 짧은 대화 선택으로 제공한다.
- 누적 조언은 고객의 행동 성향에 영향을 준다.
- 고객은 고유 성격을 유지한다.
- 조언은 행동 확률을 바꾸며 결과를 직접 명령하거나 보장하지 않는다.
- 신뢰가 높으면 조언을 따를 확률이 오르지만 복종을 보장하지 않는다.

### 2.5 신뢰

신뢰 상승 원인:

- 상황에 맞는 고강화 장비 제공
- 적절한 선물
- 고객이 실제로 따른 조언이 인과적으로 도움이 된 경우
- 약속 이행
- 실패 뒤 합리적인 지원

신뢰 파밍 방지:

- 반복 선물 감쇠
- 무관한 고강화 장비는 신뢰 상승 근거가 되지 않음
- 같은 대화 반복 감쇠
- 무작위 성공을 조언 성과로 오인하지 않음

표시 방식:

- 정확한 신뢰 수치와 수락 확률은 숨김
- 신뢰 단계, 태도, 최근 변화 이유를 표시
- 조언을 수락하거나 거절한 이유를 설명

신뢰 단계 명칭과 정확한 구간은 `PROPOSED_ONLY`다.

### 2.6 고객 콘텐츠 모델

- 고객별 고유 이정표와 공통 절차형 이벤트 풀을 병행한다.
- 고객은 시작점, 목표, 갈등, 대표 기록, 장기 결말을 가진다.
- 공통 이벤트는 직업, 성격, 장비, 조언, 신뢰, 과거 기록에 따라 구성한다.
- 초기 고객 수, 이정표 수, 이벤트 수는 `PROPOSED_ONLY`다.

### 2.7 실패와 고위험 사건

일반 실패:

- 부상과 회복 지연
- 활동 지연
- 기록 연기
- 일시적 자신감 저하
- 교체·업그레이드 요청
- 보너스 감소
- 자동 신뢰 하락 없음

고위험 사건:

- 사전 예고
- 도전/준비/안전 선택 조언
- 고객은 성격과 신뢰에 따라 최종 결정
- 장기 부상, 일시 은퇴, 장비 손상·분실, 단계 하락 가능
- 기본 범위에서 고객 사망·영구 삭제 없음

## 3. 장비 모델

### 3.1 장비 분류

1. 주 장비
2. 방어구
3. 보조 장비
4. 장신구

모든 분류는 다음을 가진다.

- 강화 단계
- 수식어
- 소유·활동 이력
- 손상·복구 상태

공통 강화 문법:

- 1회 클릭 = 1회 판정
- 같은 단계·위험·10강 이정표 구조
- 분류별 효과, 수식어, 연출, 음향만 차별화
- 모든 슬롯의 최고 강화를 요구하지 않는다.

### 3.2 슬롯 개방

- 슬롯 개방은 고객이 아니라 플레이어 계정 성장에 귀속한다.
- 계정이 분류를 개방하면 기존·신규 고객 모두 사용할 수 있다.
- 계정 레벨과 핵심 행동 조건으로 개방 자격을 얻는다.
- 자격을 얻어도 즉시 강제하지 않고 짧은 입문 의뢰를 원하는 시점에 시작한다.
- 입문을 미뤄도 기존 게임은 계속된다.
- 입문 완료 시 분류가 전역 개방된다.
- 정확한 조건과 수치는 `PROPOSED_ONLY`다.

### 3.3 고객 장비 지원

귀환 고객에게 가능한 지원:

1. 다른 신규 주 장비 제작·제공
2. 기존 장비 회수 후 강화·업그레이드
3. 방어구나 다른 도구로 보강

고객 소유 장비가 강화 중 파괴 판정을 받으면 삭제하지 않고 `DAMAGED`로 전환한다.

- 이력, 소유권, 업적, 수식어 보존
- 복원, 교체, 기념 보존 선택
- 신뢰 반응은 공개 여부, 약속, 고객 성향, 후속 이행에 따라 결정

복원:

- 강화 단계 일부 하락
- 수식어와 이력 유지
- 영구적인 복원 흔적 생성
- 상황형 특성 또는 기록 가치로 활용
- 보편적인 상시 버프가 아님
- 의도적 반복 파밍·무한 중첩 금지
- 높은 비용과 새로운 강화 목표 형성

## 4. 인벤토리·잠금·보관

### 4.1 일반 인벤토리

- 하나의 일반 인벤토리
- 저장 수량 무제한
- 확장 비용 없음
- 고객 예약 전용 칸 없음
- 필터·정렬 지원
- 선택형 자동 판매 규칙 제공
- 고급 자동 조건은 성장에 따라 개방 가능

### 4.2 잠금

잠긴 장비는 다음에서 제외한다.

- 개별·일괄·자동 판매
- 고객 실수 전달
- 자동 폐기·재료화
- 군사 보급
- 밀수

잠금은 플레이어가 직접 해제한다. 잠금은 강화 파괴를 막지 않는다.

### 4.3 회복 대기 보관

`[보관]`은 회복 가능 손실의 기간을 동결하는 별도 시설 기능이다.

- 보관 중 회복 기한 정지
- 강화·판매·납품·밀수·증여·분해·고객 제안 불가
- 보관 슬롯 수 제한
- 슬롯 부족 시 `[잠금]` 상태로만 유지 가능
- 잠금 상태에서는 회복 기한이 계속 감소
- 보관 해제 후 다음 게임 날짜부터 기한 감소 재개
- 보관·출고 자체는 즉시이며 추가 비용 없음

보관소 확장:

- 제작·강화 성장 조건 충족
- 골드·재료 투입
- 일정 게임 날짜 경과
- 슬롯 증가
- 골드만으로 성장 조건을 건너뛸 수 없음
- 최대 슬롯 제한
- 일반 인벤토리·역사 전시대와 별도 시설
- 정확한 슬롯 수와 비용은 `PROPOSED_ONLY`

## 5. 판매 채널

### 5.1 채널 분류

1. `OPEN_MARKET_SALE`
2. `VISITOR_CUSTOMER_TRANSACTION`
3. `MILITARY_SUPPLY_CONTRACT`

적대국 공급은 중개인을 통한 특수 비밀 거래인 `SMUGGLING_CONTRACT`다.

### 5.2 공개 시장

- 고정 즉시 매입가
- 날짜별 시장 가격 변동 없음
- 강화, 품질, 수식어, 상태로 가격 산정
- 개별·일괄·자동 판매
- 메인 클리커 경제의 핵심 현금화 수단

### 5.3 방문 고객 거래

고객은 특정 아이템이 아니라 장비 분류를 요청한다.

- 플레이어가 제안 장비 선택
- 적합도가 높을수록 보상 증가
- 고객 예산은 지위·직책으로 제한
- 예산은 예상 범위와 `지불 가능 / 부담 / 지불 불가`로 표시
- 최종 거래에서 정확한 자금 공개

예산 초과 시:

1. 다른 장비 제안
2. 고객 최대 자금만 받기
3. 선물하기

수동 가격 입력은 없다.

적합도 판정:

- 슬롯·분류 일치
- 기존 장비 대비 개선
- 다음 활동 적합성
- 수식어·성격 일치
- 약점·부상 보완
- 강화 단계
- 신뢰

높은 강화는 심각한 부적합을 덮지 못한다. 정확한 점수와 확률은 숨기고 다음 등급과 구체적인 장단점을 표시한다.

- 매우 적합
- 적합
- 다소 도움
- 불확실
- 부적합

### 5.4 방문 대기와 약속

- 고객은 실제 시간이 아닌 게임 날짜 기준으로 넉넉히 기다린다.
- 떠나도 자동 불이익 없음
- 성장 후 재방문 가능
- 추적·중요 고객은 더 오래 기다림
- 남은 날짜와 상태 표시

제작 약속:

- 요청 열람만으로 약속되지 않음
- 플레이어가 명시적으로 수락
- 약속 대상은 정확한 아이템·강화치가 아니라 장비 분류
- 약속 시 대기 기간 연장
- 이행하면 신뢰·만족 상승
- 불이행은 작은 신뢰 하락
- 취소 가능, 늦은 취소일수록 불리

약속 이행 조건:

- 요청 분류 일치
- 고객이 장비를 수락
- 적합도 `다소 도움` 이상
- 정상 판매, 최대 예산 지원, 선물 모두 가능

동시 약속 슬롯은 계정 성장에 따라 증가하며 시작 1, 후반 2~3 방향은 `PROPOSED_ONLY`다.

### 5.5 방문 예산과 추가 장비

- 방문당 핵심 분류 요청 1개
- 선택적인 추가 제안 가능
- 핵심 요청만으로 정상 거래·약속 완료
- 방문 전체가 하나의 총예산 공유
- 판매할 때마다 남은 자금 갱신
- 추가 장비 때문에 예산이 인위적으로 증가하지 않음

### 5.6 교체·트레이드인

기존 장비 처리:

1. 고객이 예비품·기념품으로 보유
2. 대장간으로 반환해 강화·복원
3. 트레이드인
4. 역사·손상 장비를 기념품으로 보존

성격·이력에 따라 일부 선택을 거부할 수 있다.

트레이드인:

```text
고객 지불액 = 신규 장비 가격 - 기존 장비 트레이드인 가치
```

- 고객 예산은 실제 지불액만 감소
- 기존 장비 소유권은 플레이어에게 이전
- 기존 장비 가치가 신규 가격보다 높아도 현금 지급 없음
- 트레이드인 가치는 시장가 × 기본 비율 × 상태 보정
- 감정적 이력은 기본 현금가를 과도하게 높이지 않음
- 반환 장비는 이전 소유자·활동 이력 유지

## 6. 군사 보급·국가 시스템

### 6.1 군사 보급

계약 요소:

- 장비 분류 또는 세부 종류
- 수량
- 최소 품질·강화
- 마감일
- 완료 보너스

서로 다른 아이템도 규격을 충족하면 납품 가능하다.

부분 납품:

- 언제든 묶음 제출
- 각 아이템 대금 즉시 지급
- 수량 누적
- 목표 달성 시에만 완료 보너스
- 실패해도 이미 받은 대금 회수 없음

기본 제외:

- 잠금 장비
- 고객 소유 장비
- 손상 장비

자동 판매 장비를 계약에 예약할 수 있다. 규격 초과 가치는 체감하며 최고급 장비는 시장·고객 거래가 더 유리할 수 있다.

### 6.2 국가 군사력

- 대표 총점은 공개
- 내부적으로 무기, 방어구, 보조 장비, 장신구·특수 장비 구성을 추적
- 총점은 전반적 대비태세
- 구성은 특정 손실·선택지·결과에 영향
- 구성은 단계와 이유 중심으로 표시
- 자연 감소 없음
- 전쟁, 대형 사냥, 재난 등에서 소비
- 오프라인 자동 소모 없음

### 6.3 국가 사건

성공 확률 요소:

- 군사력
- 사건 등급
- 보급 구성
- 플레이어 지원 정책
- 상황 변수

- 군사력은 성공 확률을 높이지만 보장하지 않음
- 주요 사건은 여러 게임 날짜 전에 예고
- 위협, 부족 품목, 긴급 계약 표시
- 게임 날짜 종료 시 결과 판정
- 소형 사건은 제한적인 기습 가능
- 강화 흐름을 팝업으로 방해하지 않음

지원 정책은 군대 전술이 아니라 제한된 지원 방향이다.

- 공격
- 방어·생존
- 정찰·환경 대응

선택하지 않으면 국가 기본 정책 적용. 관련 고객만 선택적으로 영향을 받고 무관한 고객은 뉴스 반응만 한다. 고객 자동 사망·영구 삭제 없음.

### 6.4 국가 영향력

- 사건 등급과 결과 품질로 영향력 변화
- 군사력은 실전 대비태세
- 영향력은 국제적 위상
- 하나의 공개 영향력 수치와 맥락별 평판 태그 사용
- 자연 감소 없음

영향력 개방:

- 상위 계약
- 외국 사절
- 재료·제작법
- 외교·사건
- 고위 방문객

### 6.5 외국 개방

본국 우선. 외국은 본국 영향력과 사건으로 순차 개방한다.

1. 뉴스 언급
2. 연락·사절·상인
3. 무역
4. 관계
5. 심화 군사 보급·사건

개방된 국가만 활성 상태를 가진다.

## 7. 밀수·중개인

### 7.1 적대국 공급

- 높은 금전 보상
- 성공 납품 장비는 적대국 군사력 상승
- 발각 시 본국 평판·감시·영향력 악화
- 상시 메뉴가 아니라 조건부 비밀 제안

### 7.2 발각 구조

- 플레이어가 배송 묶음 구성
- 수량, 가치, 군사 민감도가 높을수록 위험 증가
- 묶음별 독립 판정
- 성공 시 즉시 지급 및 대상국 군사력 상승
- 반복 배송으로 감시 누적
- 중단하면 이전 성공 수익 유지
- 정확한 확률은 숨기고 위험 등급·이유 표시
- 잠금 장비 제외

### 7.3 단계적 처벌

초기:

- 화물 몰수
- 대금 없음
- 의심 태그
- 임시 검사

반복:

- 영향력 하락
- 공식 군사 계약 악화
- 감시·수사 태그

중대·전시:

- 큰 영향력 하락
- 일부 계약 중단
- 심각한 평판·수사

코어 강화·공개 시장 루프는 봉쇄하지 않는다. 관련 합법 거래와 상류 고객이 영향을 받을 수 있다. 기존 신뢰 고객은 변호·해명 기회를 제공할 수 있다.

### 7.4 합법 매출 압류

처벌 중 다음 합법 화폐 거래에서 일정 비율을 차감한다.

- 공개 시장
- 방문 고객 지불
- 본국·동맹 군사 보급
- 합법 외국 무역

비화폐 보상과 밀수 수익은 제외한다.

- 차감률은 현재 처벌 단계 기준
- 기간은 처벌 단계와 반복 발각으로 증가
- 차감률 중첩 없음
- 기간은 상한 내 누적
- 재발각 시 더 낮은 단계로 덮어쓰지 않음
- 합법 국가 기여는 남은 기간만 줄이며 즉시 해제 불가
- 최소 의무 기간 존재
- 평판·감시 회복과 압류 기간은 별도

### 7.5 중개인

중개인은 판매 채널이 아니라 방문 고객 직업이다.

- 적대국 접촉, 전쟁, 외국 상인·범죄자, 명성·영향력, 태그·사건으로 비밀 접촉 가능
- 첫 접촉은 자발적으로 수락
- 이후 주기적 방문
- 감시가 높으면 빈도 감소 또는 잠적

중개인 차이:

- 대상국
- 전문 분야
- 보상
- 운송량
- 은폐력
- 방문 빈도
- 신뢰성

중개인과의 개인 신뢰와 네트워크 노출은 별도 상태로 관리한다.

## 8. 고객 직업·정체성

가능 직업:

- 모험가
- 검투사
- 군인
- 중개인
- 수집가
- 용병
- 상인
- 귀족·관료
- 경비
- 장인·기술자
- 주민

초기 직업 수는 `PROPOSED_ONLY`다.

정체성 구성:

- 주 직업 1개
- 배경 태그 복수
- 상태 태그 복수
- 선택적 소속

주 직업은 주요 활동·장비·이벤트 풀을 결정한다. 배경·상태·소속은 예산, 대화, 특수 사건, 국가 연결을 수정한다.

주 직업은 주요 생애 이정표에서만 변경한다.

- 은퇴
- 추방
- 승진
- 전향

변경 전 예고하며 관계, 장비 이력, 추적, 신뢰, 기록은 유지한다. 이전 직업은 배경 태그가 된다.

전직 후 장비:

- 적합 장비는 계속 장착
- 부적합 장비는 고객이 소유·보관하지만 활성 보너스 없음
- 다음 방문에서 교체, 개조, 반환, 기념 보존 선택
- 오래된 장비 때문에 활동 자체가 봉쇄되지 않음

## 9. 역사 장비·전시·수집가

### 9.1 역사 장비

다음 조건으로 역사 장비가 될 수 있다.

- 주요 고객 이정표
- 국가 사건 참여
- 희귀 기록
- 유명 소유자
- 손상 후 복원
- 특별 평판·사건

보호:

- 자동 판매 제외
- 일괄 판매 제외
- 군사 보급 제외
- 밀수 제외
- 자동 분해 제외
- 개별 처분 시 이력 요약과 별도 확인

기본 공개 시장가는 이력만으로 자동 상승하지 않는다. 수집가, 귀족, 중개인, 이전 소유자, 관련 조직이 상황형 특별 제안을 할 수 있다.

### 9.2 전시

전시는 직접 골드를 생산하지 않고 대장간 명성을 높인다.

- 고위 방문객
- 특별 의뢰
- 군사 계약
- 수집가
- 사건

대장간 명성은 국가 영향력과 별도다.

전시 장비 상세에는 다음 생애 기록을 표시한다.

- 제작·강화
- 소유자
- 직업·상태 변화
- 활동·국가 사건
- 성공·실패
- 손상·복원 흔적
- 대화·약속

전시 구조:

- 모든 역사 장비를 보는 무제한 아카이브
- 명성 효과를 주는 제한된 활성 전시대
- 활성 전시대는 대장간 성장으로 개방
- 자유롭게 교체 가능

명성 성숙:

- 전시 즉시 초기 명성
- 게임 날짜에 따라 항목별 상한까지 추가 명성
- 무한 수동 명성 없음
- 완전히 알려진 뒤에도 관련 방문·계약·사건 유인
- 새 역사 발생 시 제한적 추가 성숙
- 유사 이력은 감쇠

전시 장비 판매:

- 수집가 특별 제안 가능
- 실물 전시와 유인 효과 종료 경고
- 판매 확인 시 자동 전시 해제
- 대체 전시 선택 기회
- 이미 획득한 영구 명성 유지
- 아카이브 기록 유지, 현 소유자는 수집가로 변경
- 잠금은 별도로 해제해야 함

### 9.3 수집가

수집가는 방문 고객 주 직업이다.

평가 요소:

- 강화
- 희귀 수식어
- 복원 흔적
- 유명 이전 소유자
- 국가 사건 참여
- 기록 희소성
- 의미 있는 상태·손상

유형:

- 일반
- 역사
- 전쟁 유물
- 검투사 장비
- 복원 장비
- 외국 무기
- 저주·기묘한 수식어

요청 규칙:

- 일반 방문은 특정 아이템이 아니라 수집 주제를 요청
- 예: 전쟁 이력 무기, 복원 장비, 검투사 기록 장비, 희귀 수식어 방어구
- 특정 장비 지목은 지식 경로가 있을 때만 가능
  - 활성 전시
  - 알려진 소문
  - 과거 감정·공개
  - 공개 국가·역사 사건
  - 연락망 정보
- 비공개 인벤토리를 마법처럼 알 수 없음

### 9.4 수집가 감정과 흥정

최초 자동 감정 요소:

- 일반 시장가
- 수집가 전문 분야 일치
- 역사 사건 중요도
- 기록 희소성
- 이전 소유자 명성
- 손상·복원 이력
- 현재 예산

가격과 이유를 함께 표시한다.

흥정:

- 선택형 짧은 미니게임
- 수동 가격 슬라이더 없음
- 장비가 실제로 가진 근거만 사용
- 기본 2회, 특별 거래 최대 3회 방향은 `PROPOSED_ONLY`
- 첫 흥정은 안전
  - 실패: 최초 가격 유지
  - 성공: 가격 상승
- 두 번째 이후는 위험
  - 성공: 추가 상승
  - 실패: 가격 하락 또는 거래 철회
- 각 단계에서 현재 제안 수락 가능
- 장비 소유권과 역사 기록은 거래 철회 시 유지

성공 판정:

- 실제 장비 근거
- 수집가 관심사와의 일치
- 선택한 설득 근거
- 대장간 명성
- 해당 수집가 신뢰
- 플레이어 화술

화술만으로 부적합 장비나 예산 상한을 무시할 수 없다.

## 10. 플레이어 화술 성장

### 10.1 성장 구조

- 공통 화술 단계
- 제한적인 전문화 선택
- 제한적 재훈련

경험 획득:

- 수집가 흥정
- 고객 장비 설명
- 선물·후원 의도 전달
- 약속 이행·실패 해명
- 중개인 계약
- 밀수 조사
- 귀족·군인·상인 등 특수 응대

성공뿐 아니라 의미 있는 실패도 일부 경험을 준다. 반복 쉬운 대화는 감쇠한다. 골드만으로 단계를 구매할 수 없다. 경험 조건 뒤 대장간 훈련으로 단계가 오른다.

### 10.2 전문화

- 상인의 감각: 수집가·일반 거래
- 신뢰의 언변: 고객 추천·선물·약속
- 은밀한 교섭: 중개인·밀수·조사
- 궁정 예법: 귀족·군대·국가 계약

전문화는 공통 화술을 대체하지 않고 특정 상황에 소폭 우위를 준다.

### 10.3 재훈련

- 평상시 선택 유지
- 비용과 게임 날짜 사용
- 진행 중 흥정·조사·국가 사건 중 변경 불가
- 초기 1회 무료 또는 저비용 방향
- 공통 화술 단계와 경험 유지
- 전문화만 재선택
- 반복 재훈련 비용 증가 또는 재사용 대기시간
- 정확한 수치는 `PROPOSED_ONLY`

## 11. 제작 성장

### 11.1 구조

- 공통 제작 단계
- 선택형 공정 전문화
- 장비 분야 숙련
- 대표 제작법 친숙도
- 제한적 재훈련

공통 제작 단계:

- 제작 품질 하한 개선
- 결과 편차 완화
- 소재 손실 감소
- 복원·개조·희귀 가공 개방
- 상위 제작법과 입문 의뢰 조건

### 11.2 공정 전문화

- 정밀 제작
- 대량 생산
- 복원 기술
- 특수 가공

전문화하지 않은 공정도 계속 사용할 수 있다. 전문화는 독점 권한이 아니라 우위다.

### 11.3 장비 숙련

분야 숙련:

- 무기
- 방어구
- 보조 장비
- 장신구

대표 제작법 친숙도:

- 장검, 창, 활, 중갑 등 세부 제작법
- 사용 경험으로 자연 성장
- 신규 제작법 사용을 막지 않음
- 전문화 재훈련 시 유지
- 작은 안정성과 반복 편의 제공
- 단순 반복 경험 감쇠

숙련 효과:

- 낮은 품질 결과 감소
- 품질 편차 완화
- 연속 제작 편의
- 대량 생산 소재 손실 감소
- 적합 수식어 후보 정보 개선
- 해당 장비 강화 성공률 보정

강화 성공률 보정 범위:

- 공통 제작 단계: 모든 장비에 작은 보정
- 분야 숙련: 일치 분야에 주요 보정
- 제작법 친숙도: 일치 세부 종류에 작은 추가 보정
- 합산 상한
- 고강화에서 효율 감쇠
- 100% 보장 불가

### 11.4 품질과 재가공

- 제작 품질은 제작 시 확정
- 일반 강화는 품질을 올리지 않음
- 제한적인 재가공으로 품질 개선 가능
- 재가공에 소재, 골드, 게임 시간 필요
- 고강화 장비 재가공은 강화 하락 또는 위험 가능
- 장비별 재가공 횟수 또는 총 개선량 상한
- 역사·소유·수식어·복원 기록 보존
- 제작 숙련과 정밀 제작 전문화가 안정성 보정

## 12. 강화 성장

### 12.1 강화 숙련

실제 강화 시도로 공통 강화 숙련 경험을 얻는다.

경험:

- 성공
- 실패·단계 하락
- 고위험 구간 최초 진입
- 개인 최고 단계 갱신
- 손상 복구 후 재강화
- 촉매·특수 소재 활용
- 실패 후 복구 성공

저단계 반복은 감쇠한다.

공통 강화 숙련의 역할:

- 조작 편의
- 위험 정보 표시
- 실패 피해·소모·복구 보정
- 재료·촉매 기능 개방
- 성공률 직접 보정은 주 역할이 아님

역할 분리:

- 제작 숙련: 성공률 보정
- 강화 숙련: 실패 피해, 소모, 복구, 조작 편의
- `안정 타격` 주 전문화만 제한적인 성공률 추가 보정

### 12.2 강화 전문화

주 전문화 1개 + 보조 기술 1~2개 방향.

주 전문화:

- 안정 타격
- 승부사의 망치
- 복구 단조
- 효율 제련

재훈련 시 주 전문화와 보조 기술을 다시 선택하되 공통 강화 숙련·경험·제작 숙련은 유지한다.

### 12.3 특수 타격

각 주 전문화는 다음을 가진다.

1. 상시 패시브
2. 상황 발생형 1회 특수 타격

- 별도 미니게임·화면 전환 없음
- 강화 버튼 주변에 준비 상태 표시
- 사용하지 않고 일반 강화 가능
- 무한 축적 금지
- 확정 성공이 아니라 위험·피해·보상 구조 변형

빠른 충전 조건:

- 안정 타격: 일반 강화 누적, 위험 구간 진입
- 승부사의 망치: 연속 성공, 고위험 도전
- 복구 단조: 실패, 하락, 손상
- 효율 제련: 촉매·희귀 소재 사용, 연속 강화

모든 의미 있는 강화는 보장 게이지에도 기여한다.

귀속:

- 기본 충전은 계정 공용
- 강한 효과는 대상 장비 최근 기여도 요구
- 기여도 부족 시 차단보다 효과 약화

장비 기여도:

- 최근 직접 강화
- 강화 위험도 가중
- 높은 단계, 낮은 성공률, 촉매 사용, 손상 복구에 추가 가중
- 안전 구간 반복 감쇠
- 장기간 미사용 시 점진 감소
- `낮음 / 충분 / 완전` 표시
- 정확한 내부 수치 숨김

## 13. 강화 실패·보호석·회복석

### 13.1 최고위험 실패

- 일반 플레이어 소유 장비는 명시된 최고위험 구간에서 영구 파괴 가능
- 파괴 시 일부 소재·파편 회수 가능
- 고객 소유, 역사, 고유 장비는 `DAMAGED`로 전환
- 보호 대상은 큰 강화 하락, 복구 비용, 복원 흔적을 대가로 가짐
- 위험은 시도 전에 명확히 표시

### 13.2 보호석

- 상점에서 골드로 상시 구매
- 강화 전에 사용
- 일반 장비의 영구 파괴만 방지
- 파괴 판정을 `DAMAGED`로 전환
- 성공률, 강화 하락, 손상 정도, 복구 비용을 개선하지 않음
- 성공해도 장착한 보호석은 소모
- 목표 강화 단계가 높을수록 더 많은 수량 필요
- 고객·역사·고유 장비는 원래 삭제되지 않으므로 추가 보호 효과 없음

### 13.3 회복석

- 상점에서 골드로 상시 구매
- 실패 후 사용
- `DAMAGED → 사용 가능` 복구는 요구 수량 충족 시 확정
- 강화 하락은 일부 단계만 확정 회복
- 전부 되돌리지 않음
- 하나의 실패에서 발생한 손실만 복구 대상
- 실패 이전 단계 이상으로 복구 불가
- 고강화일수록 필요 수량 증가
- 복구 단조 전문화가 수량·비용·기간·상한을 보정
- 복원 흔적과 이력 유지

### 13.4 회복 가능 손실 기록

- 강화 하락 시 장비에 최신 `회복 가능 손실` 기록 1개 생성
- 일정 게임 날짜 동안 회복석으로 일부 단계 회복 가능
- 다시 강화하면 기존 기록은 소멸하거나 새 결과로 교체
- 만료 뒤 정상 강화로만 복구
- 남은 기간과 회복 가능 단계 표시
- `[잠금]`: 기한 계속 감소
- `[보관]`: 기한 정지

## 14. 고강화 특수 재료와 분야별 돌파

이 절의 분야별 돌파는 15절의 10강 정밀강화와 별도 개념으로 유지한다. 두 시스템이 같은 재료를 공유하는지, 돌파 기준 단계가 정밀강화 이정표와 동일한지는 아직 `UNRESOLVED`다.

### 14.1 획득

고강화용 특수 재료는 다음에서 얻는다.

- 고객 주요 이정표
- 국가 위기·전쟁·대형 토벌
- 고등급 군사 보급
- 특별 수집가 의뢰
- 외국 사절·희귀 상인
- 중개인 고위험 계약
- 역사 장비 사건
- 기록적인 강화 달성

보호석·회복석과 달리 일반 상점 상시 구매 대상이 아니다.

### 14.2 분야별 기술 돌파

- 무기·방어구·보조 장비·장신구별 독립 돌파
- 최초 돌파 시 이벤트 특수 재료 소비
- 성공하면 해당 분야의 구간 기술을 계정에 영구 해금
- 이후 같은 분야 장비는 필수 특수 재료 없이 해당 구간 도전 가능
- 개별 장비에 특수 재료를 추가 사용하면 선택형 보정 가능
- 제작법 친숙도는 준비에 작은 이점

돌파 실패:

- 일반 촉매·골드 소모
- 핵심 재료 일부를 파편·잔재로 반환
- 분야별 `돌파 이해도` 누적
- 다음 성공률 상승 또는 요구 재료 감소
- 일정 실패 뒤 보장선
- 성공 시 이해도 소모 및 영구 해금

장비 손실:

- 일반 고강화 실패 규칙 적용
- 보호석은 영구 파괴만 `DAMAGED`로 전환
- 고객·역사·고유 장비는 삭제되지 않음
- 단계 하락이 돌파 입장 기준 아래로 내려가지 않음
- 회복석 사용 가능

정확한 돌파 단계, 재료량, 반환율, 보장선은 `PROPOSED_ONLY`다.

## 15. 10강 이정표 정밀강화

### 15.1 필수 관문

모든 10강 이정표에서 정밀강화를 완료해야 다음 강화 구간으로 진입한다.

```text
+49 → +50 성공
→ 정밀강화 대기
→ 정밀강화 결과 확정
→ +51 강화 개방
```

- +10, +20, +30 등 모든 10강에 적용
- 정밀강화 보류 중 해당 장비의 다음 강화 불가
- 다른 장비·제작·판매는 가능
- 이정표당 결과 확정 1회

### 15.2 일반 정밀강화

- 모든 10강 이정표에서 가능
- 일반 강화 재료, 보조재료, 촉매 사용
- 특수 재료를 사용하지 않음
- 수식어의 획득·강화·일반 계보 진화
- +50 이후에도 계속 선택 가능

### 15.3 고위 정밀강화

- +50 이후 10강 이정표에서 선택 가능
- 일반 정밀강화 대신 특수 재료를 추가 선택
- 초희귀 수식어 계보로 진화할 기회
- 특수 재료가 없어도 일반 정밀강화를 선택할 수 있음
- 일반 정밀강화를 확정하면 같은 이정표의 고위 기회는 소멸
- 고위 정밀강화 실패도 해당 이정표를 소모하며 다음 구간은 개방
- 정확한 시작점은 +50 방향으로 확정했으나 최종 수치표는 `PROPOSED_ONLY`

### 15.4 재료 조합 판정

정밀강화 입력:

1. 보조재료
2. 촉매
3. 고위 정밀강화에서 선택적 특수 재료

결과 규칙:

- 각 보조재료는 여러 수식어 가능성을 가짐
- 각 촉매도 여러 수식어 가능성을 가짐
- 일반 조합은 두 후보군과 가중치에서 무작위 결정
- 속성·성질이 유사하면 후보군이 좁아지고 관련 결과 확률 상승
- 등록된 특정 조합은 수식어 명칭과 핵심 계보를 확정
- 성공 여부와 세부 수치는 별도 판정

확정 조합 예:

```text
보조재료 [바람의 숨결]
+ 촉매 [바람의 오브]
= 수식어 [바람의 가호가 깃든]
```

고위 확정 조합 예:

```text
[바람의 숨결]
+ [바람의 오브]
+ [폭풍군주의 핵]
= 초희귀 수식어 [폭풍왕의 가호를 받은]
```

고정 조합은 `무엇이 나오는가`를 확정하지만 정밀강화 성공 자체는 보장하지 않는다.

### 15.5 조합식 발견

- 처음에는 재료 속성과 가능 계열만 공개
- 고객, 수집가, 국가 사건, 제작 문헌에서 조합 단서 획득
- 단서는 한쪽 재료 또는 예상 계열을 알려줌
- 직접 조합에 성공하거나 완전한 제작법을 획득하면 대장장이 도감에 영구 등록
- 등록 후 확정 결과와 필요 재료를 표시
- 특수 재료가 포함된 고위 조합은 사용 전 최소한 호환 여부를 경고

### 15.6 특수 재료 숙련

- 실제 고위 정밀강화에서 사용한 경우에만 증가
- 특수 재료별 독립
- 계정 단위 `[대장장이 도감]`에 저장
- 장비에는 실패 흔적·보정 스택을 남기지 않음
- 같은 특수 재료를 다음에 사용할 때 정밀강화 성공률 보정
- 다른 재료에는 적용되지 않음
- 장비 판매·파괴·교체, 전문화 재훈련 뒤에도 유지
- 보정 상한 존재
- 숙련만으로 100% 보장 불가
- 사용 시 기본 숙련, 실패 시 추가 분석 숙련 방향
- 일반 정밀강화는 특수 재료 숙련을 주지 않음

## 17. 상태 분류

### 17.1 `CONFIRMED`

- 강화 중심 클리커가 메인 코어
- 생애주기·국가 이벤트는 보조 보상·유지 층
- 4개 장비 분류
- 무제한 일반 인벤토리와 잠금
- 공개시장·방문고객·군사보급·밀수 채널 구분
- 고객 자율성·신뢰·추적·직업 변화
- 역사 장비·전시·수집가
- 화술, 제작, 강화 성장 구조
- 보호석·회복석
- 제한 슬롯 보관소
- 10강마다 정밀강화 필수
- +50 이후 일반/고위 정밀강화 선택
- 재료·촉매 조합 기반 무작위 및 고정 조합
- 단서 제공 후 도감 영구 등록
- 특수 재료 숙련을 장비가 아닌 도감에 저장

### 17.2 `LATEST_OVERRIDE`

- 생애주기 중심 코어 → 강화·판매 중심 코어
- 수집가 가격 자동 감정만 → 자동 감정 + 선택형 흥정
- 화술 스탯 없음 → 공통 화술 단계와 전문화 추가
- 제작 숙련은 강화 성공률에 영향 없음 → 일치 장비 강화 성공률 보정
- 보호석이 손실 완화 가능 → 영구 파괴만 방지
- 정밀강화 후보 3개 제시 → 보조재료·촉매 조합의 가중 무작위 및 고정식
- 고강화 특정 단계에서만 정밀강화 → 모든 10강에 일반 정밀강화, +50 이후 선택형 고위 정밀강화
- 실패 흔적을 장비에 저장 → 특수 재료 숙련을 대장장이 도감에 저장

### 17.3 `PROPOSED_ONLY`

- 모든 정확한 확률, 수량, 비용, 기간, 상한
- 강화 안전·하락·파괴 구간의 정확한 단계표
- +50 이후 고위 정밀강화 단계표
- 고객 수, 이벤트 수, 신뢰 단계 이름
- 전문화 선택 횟수, 보조 기술 수
- 추적·약속·보관 슬롯 수
- 특수 재료 목록과 개별 수식어 수치
- 돌파 실패 보장 횟수

### 17.4 `UNRESOLVED`

- 분야별 기술 돌파와 10강 정밀강화가 같은 특수 재료 풀을 공유하는지
- 분야별 기술 돌파 기준 단계와 정밀강화 이정표의 관계
- 고위 정밀강화 실패 시 강화 단계 하락·손상 규칙의 정확한 범위
- 일반 정밀강화 실패가 가능한지, 가능하다면 실패 결과
- 정밀강화로 신규 수식어 슬롯을 추가하는지 기존 수식어를 교체·진화시키는지
- 장비당 수식어 슬롯 수와 10강 이정표별 성장 규칙

## 18. 문서 병합 정책

이 문서를 기존 기획 문서에 반영할 때 다음 순서를 사용한다.

1. 강화·판매 중심 프로젝트 코어로 기존 코어 문구 교체
2. 생애주기는 보조 시스템으로 이동
3. 장비·강화·정밀강화 책임 원본을 최신 결정으로 정합화
4. 기존 `BROKEN_OR_LOST` 중심 상태를 `DAMAGED`와 영구 파괴 예외 규칙으로 구분
5. 오래된 정확 적합도·예상 결과 선공개 규칙을 등급·장단점 표시로 교체
6. `CONFIRMED`, `PROPOSED_ONLY`, `UNRESOLVED`를 섞지 않음
7. 기존 구현 상태는 검증 없이 `PASS`로 변경하지 않음
8. `PLANNING_IN_PROGRESS` 상태 유지
