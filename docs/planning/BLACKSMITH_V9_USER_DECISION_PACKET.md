## 결정 1 — 제작 등급

### 질문

단조 결과로 고정되는 제작 등급을 몇 단계로 사용할 것인가?

### 추천안

```text
보통
→ 양질
→ 우수
→ 명품
→ 걸작
```

### 이유

- 기존 PoC의 영구 완성도 5단계 구조와 연결하기 쉽다.
- `전설`을 제작 등급에 사용하지 않아 +50 진화·세계 연대기·명작 전당의 희소성과 충돌하지 않는다.
- 낮은 등급을 모욕적인 `조악`으로 부르지 않아 첫 제작의 만족을 훼손하지 않는다.

### 판정

`RECOMMENDED: 5_TIERS`

## 결정 2 — 수식어 슬롯 구조

### 질문

장비 정체성을 몇 개의 수식어 축으로 표현할 것인가?

### 추천안

```text
계보 수식어 1개
+ 보조 수식어 최대 2개
```

### 이유

- 계보 수식어는 장비의 한 문장 정체성을 만든다.
- 보조 수식어 두 개는 비교·조합의 다양성을 제공한다.
- 모바일 카드에서 세 개를 넘기면 정보 밀도와 기억 부담이 급격히 커진다.
- +50 대표 특수 수식어는 새 슬롯을 추가하지 않고 계보 수식어를 승격한다.

### 제외안

- 수식어 무제한 누적
- +10마다 새 슬롯 추가
- 계보·대표·특수·보조를 모두 별도 슬롯으로 분리

### 판정

`RECOMMENDED: ONE_LINEAGE_PLUS_TWO_SECONDARY`

## 결정 3 — +10 단위 이정표

### 질문

수식어와 진화를 어떤 강화 이정표에 배치할 것인가?

### 추천안

| 단계 | 결과 |
|---:|---|
| +10 | 계보 수식어 획득 |
| +20 | 보조 수식어 1개 획득 |
| +30 | 계보 수식어 강화 또는 방향 선택 |
| +40 | 보조 수식어 2개째 획득 |
| +50 | 진화 + 계보 수식어의 대표 특수 형태 승격 |
| +60 이상 | 신규 슬롯 없이 기존 수식어 심화 |

### 이유

- 10단위마다 같은 보상을 반복하지 않는다.
- +50을 장비 정체성이 완성되는 명확한 장기 목표로 만든다.
- +60 이상에서 슬롯을 계속 늘리지 않아 UI·밸런스·서버 비교가 폭발하지 않는다.

### 판정

`RECOMMENDED: IDENTITY_COMPLETES_AT_PLUS_50`

## 결정 4 — 방문 고객의 적합 신호

### 질문

범주만 맞으면 판매 가능한 구조에서 고객별 선택 의미를 어떻게 만들 것인가?

### 추천안

```text
거래 자격
= 범주 일치 여부만 판정

적합 신호
= 등급·계보·수식어·연대기와 고객 가치관의 일치
```

적합 신호는 다음에 영향을 준다.

- 공개 매입 가격
- 관계 변화 방향
- 후속 세계 사건의 유리·불리 방향
- 고객 반응과 장비 연대기 문구

### 필수 원칙

- 낮은 적합도여도 판매 가능
- 숨은 실패 조건 없음
- `왜 이 고객이 이 장비를 높게 평가하는지` 공개
- 자동 추천·자동 선택 없음

### 판정

`RECOMMENDED: ELIGIBILITY_AND_FIT_SEPARATED`

## 결정 5 — 장비 운명 상태

### 질문

내구도 시스템을 사용하지 않으면서 세계에서 사용된 흔적을 어떻게 남길 것인가?

### 추천안

```text
정상
전투 흔적
분실
회수
영구 파괴
```

### 전투 흔적 정의

- 내구도 수치 아님
- 장비 사용 불가 상태 아님
- 반복 수리 비용 없음
- 외형·가치·수식어 설명·연대기에 영향을 주는 서사 상태

### 이유

장비가 세계에서 사용됐다는 흔적은 남기되, 모바일 운영을 반복 수리 관리 게임으로 바꾸지 않는다.

### 판정

`RECOMMENDED: NARRATIVE_FATE_WITHOUT_DURABILITY`

## 결정 6 — 두 번째 콘텐츠 세트

### 질문

검투사 대표 루프와 다른 제작 기반을 증명할 두 번째 고객은 누구인가?

### 추천안: 수집가

```text
방어구 또는 의식 장비 범주 요청
→ 제작 등급·희소성·계보·연대기 적합 신호 비교
→ 제품 직접 선택·판매
→ 짧은 감정·전시 결과
→ 가치·연대기 갱신
```

### 수집가를 추천하는 이유

- 검투사의 성능·경기와 다른 가치 축을 검증한다.
- 제작 등급·수식어·장비 연대기 UI를 직접 시험한다.
- 상인은 일반 판매와 높은 현금 가격 역할이 겹칠 가능성이 크다.
- 모험가는 분실·회수·세계 사건 범위가 커져 Vertical Slice 제작량이 증가한다.

### 적용 방식

- 대표 15~25분 세션에는 검투사만 완주한다.
- 수집가는 별도 결정론적 제작 파이프라인 증명 시나리오로 완주한다.

### 판정

`RECOMMENDED: COLLECTOR_AS_SECOND_PIPELINE_SET`
