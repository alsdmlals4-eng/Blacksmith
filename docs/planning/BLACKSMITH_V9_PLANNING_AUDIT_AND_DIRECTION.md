## 3. 복원된 프로젝트 코어

### 3.1 추천 코어 문장

> **망치질로 장비를 만들고, 더 강하게 만들수록 커지는 위험 앞에서 멈출지 도전할지 선택하며, 완성한 작품이 다른 인물과 세계에 남기는 흔적을 확인하는 모바일 대장간 게임.**

### 3.2 플레이어 약속

1. 제작 과정은 짧고 직접적인 손맛을 제공한다.
2. 강화는 결과를 숨기는 도박이 아니라 위험·비용·보호 효과를 이해한 선택이다.
3. 장비는 판매 즉시 사라지는 숫자가 아니라 이름·등급·수식어·소유자·사건을 가진 작품이다.
4. 멈춘 선택과 도전한 선택 모두 다음 플레이로 연결된다.
5. 높은 강화 작품은 장기적으로 다른 플레이어의 작품과 비교 가능한 명작이 된다.

### 3.3 감정 곡선

```text
만드는 손맛
→ 조금 더 올리고 싶은 욕심
→ 잃을 수 있다는 긴장
→ 멈춤 또는 도전의 책임감
→ 작품 완성의 자부심
→ 누구에게 넘길지 고민
→ 세계에서 쓰이는 장면 확인
→ 장비를 기억하고 다음 작품을 만들 동기
```

### 3.4 코어와 지원 시스템 구분

| 분류 | 내용 |
|---|---|
| 프로젝트 코어 | 단조 손맛, 강화 위험 선택, 작품 완성 시점, 장비 정체성 |
| 코어 지원 | 보관함, 일반 판매, 방문 고객, 장비 연대기, 원자적 저장 |
| Vertical Slice 지원 | 검투사 후속 활동, 불씨 정령, 모바일 작업대, 접근성·성능 계약 |
| 본제작 확장 | 다수 고객 유형, 세계 사건, 장기 관계, +51~+100, 계승 장비 |
| 미래 온라인 | +50 이상 명작 랭킹·비교, 서버 검증, 시즌·전당 |
| 제외 또는 재검토 | 네 고객 동시 완주, 내구도 수치, 고객 전용 장비, 필수 로그인 |

## 4. 현재 기획의 강점

### 4.1 강화 정보의 공정성

- 성공률·비용·최대 하락·영구 파괴·보호 효과를 실행 전에 공개한다.
- 일반 정밀강화는 `+9→+10` 같은 이정표 진입 시도 자체다.
- `+49→+50` 특수재료 고위 정밀강화는 성공 여부가 아니라 진화 후보와 높은 비용을 선택하는 확정 성공 이정표다.
- 결과를 한 번 판정한 뒤 비용·재료·장비 상태·연대기를 원자적으로 저장하고 연출한다.

### 4.2 모바일 UX의 책임 경계

- 고정 강화 작업대와 상황별 하단 패널을 사용한다.
- 저위험 반복 강화는 빠르게, 파괴·진화 같은 비가역 결과는 충분히 무겁게 표현한다.
- 길게 누르기가 어려운 사용자를 위한 2단계 확인 대체 입력이 있다.
- 색상·사운드·진동·모션 하나에 핵심 정보를 독점시키지 않는다.

### 4.3 장비를 작품으로 만드는 구조

- 장비 식별자, 제작자, 현재·과거 소유자, 강화·수식어, 사건, 파괴 기록을 연결한다.
- 판매는 장비 삭제가 아니라 소유권 이전이다.
- 세계 결과와 재방문이 같은 장비 ID에 누적된다.
- 앱 종료로 결과를 재추첨하거나 손실을 되돌릴 수 없다.

### 4.4 범위 축소 방향

Addendum 21 이후 다음 과도한 구조가 폐기됐다.

- 매 세션 고객 네 명 동시 방문
- 고객 네 명 모두에게 반드시 판매
- 네 개의 완제품 자동 준비
- 네 고객 세계 결과를 한 세션에 모두 완주

현행 방향은 일반 영업과 방문 고객 이벤트를 분리하고, 방문 요청을 최대 2개로 제한하며, 영업일 시작에 최대 1개만 발생시키는 구조다.

### `P0-02` 최신 15~25분 플레이 순서 부재

기존 대표 흐름은 네 고객을 모두 완주하도록 설계됐으나 폐기됐다. Addendum 21 이후의 일반 영업·방문 요청 구조를 반영한 최신 Vertical Slice 순서가 없다.

**권장 대표 흐름:**

```text
0~2분
불씨 정령과 작업대 진입
→ 짧은 단조 마무리로 새 장비 완성
→ 1분 안에 첫 강화

2~6분
새 장비 +0→+5 저위험 강화
→ 성공·유지·하락 정보 학습
→ +5에서 지금 완성할지 계속 도전할지 비교

6~10분
오래 벼려 온 준비 장비 +49 확인
→ 일반 정밀강화 위험과 특수재료 고위 정밀강화 비교
→ 진화 후보 선택
→ +50 확정 진화와 대표 특수 수식어 획득

10~14분
무기 범주를 요청한 이름 있는 검투사 방문
→ 새 +5 장비, +50 대표작, 다른 이력 장비 비교
→ 가격·공개 적합 신호·후속 활동 방향 확인
→ 플레이어가 판매 작품 직접 선택

14~17분
선택한 장비 판매·소유권 이전
→ 선택적 지원 또는 배팅 1개 결정
→ 명시적 영업 종료

17~22분
짧은 자동 경기의 결정적 장면
→ 장비 등급·강화·수식어가 기여한 원인 표시
→ 승리 또는 패배 결과 확정

22~25분
검투사 결과·장비 연대기·관계 변화 확인
→ 판매하지 않은 장비의 다음 가능성도 보존
→ 다음 작품과 +50 명작 목표 제시
```

이 구조는 `오늘 만든 장비`와 `오래 벼려 온 대표작`의 두 시간축을 사용한다. 준비 +49 장비는 신규 캠페인 기본 지급이 아니라 Vertical Slice 테스트 픽스처다.

### `P0-03` 장비 등급·수식어·진화 데이터 모델 미확정

등급과 수식어가 고객 비교, 장비 연대기, +50 진화, 향후 서버 랭킹 모두에 필요하지만 현재 슬롯·성장 관계가 하나로 확정되지 않았다.

**추천 후보 모델:**

| 축 | 책임 |
|---|---|
| 제작 등급 1개 | 단조 완성도를 나타내는 영구 품질 축 |
| 강화 단계 | `+0~+100`, 위험·시장 가치·이정표 축 |
| 계보 수식어 1개 | 장비가 어떤 방향으로 성장했는지 보여주는 대표 정체성 |
| 보조 수식어 최대 2개 | 세부 성능·사용 맥락의 차이 |
| +50 진화 | 외형·이름·계보 수식어를 특수 형태로 승격 |
| 장비 연대기 | 제작·소유·판매·세계 사건·파괴 기록 |

**추천 이정표 배치:**

- `+10`: 계보 수식어 최초 획득
- `+20`: 보조 수식어 1개 획득
- `+30`: 계보 수식어 강화 또는 방향 선택
- `+40`: 보조 수식어 2개째 획득
- `+50`: 진화 + 대표 특수 수식어 승격
- `+60 이상`: 신규 슬롯을 계속 늘리지 않고 기존 정체성의 심화 중심

이 배치는 사용자 승인 전 확정하지 않는다. 다만 데이터 축 자체는 기획 완료 전에 고정해야 한다.

### `P0-04` 장비 범주 요청이 선택을 지나치게 얕게 만듦

Addendum 28은 방문 고객이 `무기` 또는 `방어구` 범주만 요구하고, 강화·등급·수식어는 거래 자격을 막지 않도록 단순화했다. 숨은 실패 조건을 제거한 점은 좋지만, 모든 무기가 동일하게 판매 가능하면 고객 선택이 가격 배수 비교로 축소될 수 있다.

**권장 보완: 자격과 적합 신호를 분리한다.**

```text
거래 자격
= 요청 범주 일치 + 판매 가능 상태

공개 적합 신호
= 고객 가치관과 장비 등급·수식어·역사 방향의 일치

결과
= 모든 자격 제품 판매 가능
+ 적합 신호에 따라 공개 가격·관계·후속 사건 방향 차이
```

- 적합 신호는 판매를 막지 않는다.
- 숨은 조건을 사용하지 않는다.
- `추천`이 아니라 `이 고객은 파쇄 수식어를 높게 평가함`처럼 이유를 공개한다.
- 낮은 적합 장비를 파는 것도 자금 확보·재고 정리·작품 보존 같은 유효 선택이 된다.

### `P0-05` 내구도·손상·수리 계약 충돌

Addendum 28은 내구도 수치와 내구도 상태 시스템을 금지한다. 그러나 기존 문서와 모험가·군인 후속 사건에는 손상·수리·내구 보강이 남아 있다.

**권장안:**

- 수치형 내구도: 사용하지 않음
- 반복 유지보수 수리 루프: 사용하지 않음
- 서사적 운명 상태: 제한적으로 허용
  - `정상`
  - `전투 흔적`
  - `분실`
  - `회수`
  - `영구 파괴`
- `전투 흔적`은 장비 사용 불가·수리 비용 반복을 만들지 않고 외형·연대기·가치에만 영향을 준다.

모험가의 `손상·수리` 증명 세트는 `흔적·분실·회수` 중심으로 다시 작성한다.

### `P0-06` +5/+10 일상 루프와 +50 대표작의 관계 미정

Sheet는 +5 납품/+10 도전을 대표 Demo로 삼고, PR #61은 +50 진화를 핵심 장면으로 올렸다. 둘을 경쟁하는 두 정본으로 두면 안 된다.

**권장 구조: 두 개의 시간 지평**

| 지평 | 역할 |
|---|---|
| 일상 루프 | +5에서 완성·판매 또는 +10까지 도전, 짧은 모바일 세션 |
| 장기 작품 루프 | 여러 영업일에 걸쳐 +50 이상 대표작 완성·진화·세계 기록·명작 비교 |

+5/+10은 반복 가능한 일상 판단이고, +50은 장기 목표와 세일즈 포인트다. Vertical Slice는 준비 장비를 사용해 두 지평의 연결을 한 번에 보여준다.

### `P0-07` 플레이테스트 계약이 폐기된 네 고객 구조에 종속됨

최소 6명 비유도 테스트, 결정론적 기능 검증, 회귀 Gate 자체는 유지 가치가 있다. 그러나 현재 테스트 항목은 네 고객 동시 판매·모험가 손상·검투사 배팅을 한 흐름에 묶고 있다.

**권장 최신 Gate:**

1. 결정론적 기능 검증
   - 단조·강화·+5 선택
   - +49→+50 진화
   - 방문 요청·제품 선택·판매
   - 영업 종료·검투사 결과·연대기
   - 저장·복귀·접근성·성능
2. 최소 6명 비유도 대표 흐름
3. 별도 데이터 기반 두 번째 콘텐츠 세트 검증
   - 같은 시스템으로 상인 또는 수집가 요청·판매·짧은 결과를 재현
   - 대표 15~25분 세션에 억지로 동시 삽입하지 않음
4. 수정 후 원조건·앞뒤 소비자 회귀

## 6. P1 Finding — 기획 완성도를 위해 보완

### `P1-01` 일반 판매와 방문 상인의 차별성

상인이 일반 판매보다 높은 현금을 주는 방문 고객이라면 일반 판매가 열등한 버튼이 될 수 있다.

권장 차이:

- 일반 판매: 즉시·항상 가능·낮은 변동·세계 후속 없음
- 방문 상인: 2영업일 기한·범주 요청·높은 매입 가능·발생 빈도 제한
- 상인 거래는 항상 최고가가 아니라 특정 장비 가치 방향에 강함
- 일반 판매는 현금 흐름 안전망으로 유지

### `P1-02` 방문 고객 발생 규칙의 과도한 조기 상세화

40% 발생, 2회 미발생 보정, 최대 2개 요청, 우선순위 3등급은 상태 무결성에는 좋지만 아직 핵심 재미가 검증되지 않은 단계에 비해 세밀하다.

- 구조는 유지 가능
- `40%`, 반복 억제 배율, 고객별 가중치는 `POC_TUNABLE`
- Vertical Slice 대표 고객은 무작위가 아니라 확정 트리거 사용

### `P1-03` 세계 시스템이 강화 코어를 압도할 위험

고객, 약속, 지원, 배팅, 세계 게시판, 구독, 관계, 군사력, 영향력, 계승을 동시에 전면화하면 플레이어가 대장장이보다 세계 관리자처럼 느낄 수 있다.

Vertical Slice에서는 다음만 직접 완주한다.

- 이름 있는 검투사 1명
- 지원 또는 배팅 중 핵심 선택 1개
- 결정적 장면 중심 결과 1개
- 장비 연대기 갱신 1개

나머지 고객·세계 축은 별도 데이터 세트 또는 본제작 범위로 둔다.

### `P1-04` 튜토리얼과 첫 5분 계약 부족

첫 실행에 필요한 최소 안내를 명시한다.

```text
첫 30초: 장비와 망치 입력
1분 이내: 첫 강화
3분 이내: 성공·실패·비용 읽기
5분 이내: +5 완성/도전 선택
```

불씨 정령은 안내를 보조하지만 수치·위험 정보의 권위 원본이 아니다.

### `P1-05` 브랜드·아트 첫인상 미정

**권장 첫인상:**

- 중앙: 플레이어가 만든 장비
- 하단: 망치·강화의 직접 입력
- 배경: 어두운 철과 숯, 따뜻한 화로 빛
- 포인트: 불씨 주황, 고강화 금속광, 위험은 별도 아이콘·문구
- 상징: 비성장형 불씨 정령

스토어 세일즈 문장 후보:

> **내가 만든 장비가 누군가의 전설이 된다.**

세 가지 대표 스크린샷 축:

1. 망치질과 피버의 손맛
2. 위험을 읽고 멈춤·도전을 선택하는 강화
3. 장비의 소유자·수식어·세계 기록과 명작 비교

### `P1-06` 장기 경쟁이 장비 애착을 훼손할 위험

순수 단일 점수 랭킹은 최적 수치 장비만 남기고 다양한 작품 정체성을 약화할 수 있다.

서버 기능의 사용자 노출명은 **`명작 전당`**을 우선 검토한다.

- 강화 단계 순위
- 제작 등급 필터
- 계보·특수 수식어 필터
- 장비 종류 필터
- 시즌 명작과 역대 명작 분리
- 게임 플레이 보상 없는 명예·감상 중심

## 7. 미래 서버 랭킹 기획 계약

상태: `FUTURE_SERVER_PLANNING / NOT_IMPLEMENTED`

### 7.1 사용자 가치

+50 이상 작품을 다른 플레이어의 작품과 비교하며 다음을 확인한다.

- 얼마나 멀리 강화했는가
- 어떤 제작 등급으로 완성됐는가
- 어떤 계보와 수식어 조합을 만들었는가
- 누가 제작했고 어떤 사건을 거쳤는가

### 7.2 등록 조건

- 강화 단계 `+50` 이상
- 완성된 작품 상태
- 사용자의 명시적 공개 동의
- 지원되는 게임 버전·밸런스 시즌·Schema
- 서버 무결성 검증 통과

### 7.3 공개 정보

- 공개 작품 ID
- 장비 이름·종류
- 강화 단계
- 제작 등급
- 계보·대표 특수 수식어
- 보조 수식어
- 진화 형태
- 공개 가능한 연대기 요약
- 시즌·게임 버전
- 익명 또는 사용자가 선택한 공개 제작자명

기기 식별자, 로컬 저장 전체, 구매 정보, 비공개 계정 ID는 공개하지 않는다.

### 7.4 운영 원칙

- 싱글플레이·저장·강화는 오프라인 우선
- 등록 실패가 로컬 작품을 훼손하지 않음
- 업로드는 선택적이며 재시도·취소 가능
- 동일 작품 중복 등록은 idempotency로 방지
- 클라이언트가 제출한 점수·등급을 그대로 신뢰하지 않음
- 밸런스가 다른 시즌을 하나의 순위에 무비판적으로 혼합하지 않음
- 랭킹 보상이 강화 확률·경제·전투 성능에 영향을 주지 않음
- 판매 후에도 동일 작품 ID의 공개 기록을 유지할 수 있으나 현재 소유자 공개는 별도 동의 대상
