
## 2. 복원된 프로젝트 코어

> **망치질로 장비를 만들고, 커지는 위험 앞에서 멈출지 도전할지 선택하며, 완성한 작품이 사람과 세계에 남기는 흔적을 확인하는 모바일 대장간 게임.**

감정 곡선:

```text
만드는 손맛
→ 더 올리고 싶은 욕심
→ 잃을 수 있다는 긴장
→ 멈춤 또는 도전의 책임감
→ 작품 완성의 자부심
→ 누구에게 넘길지 고민
→ 세계에서 쓰이는 장면 확인
→ 다음 작품을 만들 동기
```

## 3. 유지할 강점

### 강화 공정성

- 성공률·비용·최대 하락·파괴·보호 효과를 실행 전에 공개
- 정밀강화는 10단위 진입 시도 자체
- +49→+50 특수재료 고위 정밀강화는 진화 선택과 높은 비용을 중심으로 한 확정 성공
- 판정 1회 후 비용·장비·연대기를 원자적으로 저장하고 연출

### 모바일 UX

- 고정 강화 작업대 + 상황별 하단 패널
- 저위험 반복 강화는 빠르게, 파괴·진화는 무겁게 표현
- 길게 누르기 대체 입력 제공
- 색상·사운드·진동·모션 하나에 정보를 독점시키지 않음

### 작품 생애주기

- 장비 ID, 제작자, 소유자, 강화, 수식어, 사건, 파괴 기록 연결
- 판매는 삭제가 아니라 소유권 이전
- 세계 결과가 동일 장비 ID와 연대기에 누적
- 앱 종료로 결과 재추첨·손실 되돌리기 금지

## 4. 확인된 주요 충돌

| 충돌 | 최신 판정 |
|---|---|
| 네 고객 동시 완주 vs 일반 영업·방문 요청 분리 | 네 고객 동시 완주 폐기 |
| 개별 장비 종류 요청 vs 장비 범주 요청 | 범주 요청 채택 |
| 고객 범주만 맞으면 선택이 얕아지는 문제 | 거래 자격과 공개 적합 신호 분리 |
| 손상·수리·내구 보강 vs 내구도 부재 | 수치 내구도 폐기, 비수치 운명 상태 채택 |
| Sheet의 +5/+10 vs PR 후반 +50 중심 | 일상 +5/+10과 장기 +50의 두 시간 지평으로 통합 |
| 상인 또는 수집가 두 번째 세트 | 수집가 확정 |
| 온라인 랭킹 명칭·목적 | 명작 전당 확정 |

## 5. 사용자 승인으로 해결된 P0

2026-07-31 사용자 승인을 기준으로 다음을 확정했다.

### P0-01 제작 등급

```text
보통 → 양질 → 우수 → 명품 → 걸작
```

### P0-02 수식어 모델

```text
계보 수식어 1개 + 보조 수식어 최대 2개
```

### P0-03 강화 이정표

- +10: 계보 수식어
- +20: 보조 수식어 1개
- +30: 계보 강화·방향 선택
- +40: 보조 수식어 2개째
- +50: 진화와 대표 특수 형태 승격
- +60 이상: 신규 슬롯 없이 기존 정체성 심화

### P0-04 고객 선택 의미

```text
거래 자격 = 요청 범주 일치
공개 적합 신호 = 등급·수식어·연대기와 고객 가치관의 일치
```

낮은 적합도여도 판매 가능하며 숨은 조건과 자동 추천을 사용하지 않는다.

### P0-05 장비 운명

수치형 내구도와 반복 수리 루프는 사용하지 않는다.

```text
정상 / 전투 흔적 / 분실 / 회수 / 영구 파괴
```

### P0-06 두 번째 콘텐츠 세트

수집가를 별도 결정론적 제작 파이프라인 증명 시나리오로 사용한다.

### P0-07 미래 온라인

사용자 노출명을 `명작 전당`으로 확정한다. 현재는 기획만 하며 구현하지 않는다.

### P0-08 작업 원칙

새 시스템·핵심 규칙·콘텐츠 구조·주요 UX 흐름은 반드시 벤치마킹 후 설계한다. 매 작업마다 전체 조사를 반복하지는 않으며 최근의 관련 조사 결과를 재사용할 수 있다.

## 6. 최신 15~25분 대표 흐름

| 시간 | 흐름 |
|---:|---|
| 0~2분 | 단조 마무리, 첫 강화 |
| 2~6분 | 새 장비 +0→+5, 완성·도전 판단 |
| 6~10분 | 준비 +49 대표작의 +50 진화 |
| 10~14분 | 검투사 요청과 작품 비교 |
| 14~17분 | 제품 직접 선택·판매·지원 또는 배팅 |
| 17~22분 | 자동 경기의 결정적 장면과 결과 |
| 22~25분 | 관계·장비 연대기·다음 목표 |

새 +5 장비와 준비된 +49 대표작의 두 시간축을 사용한다. 준비 장비는 신규 캠페인 기본 지급이 아니라 테스트 픽스처다.

## 7. P1 벤치마킹 결과

P1 상세 설계에 앞서 다음 사례를 비교했다.

- Potion Craft: 직접 도구 조작과 고객 판매
- Anvil Saga: 고객·관계·결정의 세계 결과
- Shop Titans: 모바일 제작·판매·영웅 환류와 온라인 시장
- While the Iron's Hot: 제작 과정과 세계 문제 연결
- Blacksmith Master: 전체 생산 체인의 범위
- Weapon Shop Fantasy: 장비 속성·스킬·모험 확장
- Android 공식 접근성·리더보드 가이드

채택:

- 짧은 직접 제작 입력
- 고객 선택의 공개 이유
- 판매 장비의 세계 결과·연대기 환류
- 여러 작품 정체성 축을 함께 비교

제외:

- 직원·시설·자원 생산 제국
- 길드·오픈마켓·필수 로그인
- 탐험·전투·자동전투
- 무제한 수식어·스킬 조합
- 단일 종합 점수 랭킹

상세 근거와 출처는 `BLACKSMITH_P1_CONTENT_UX_BENCHMARK_AND_DESIGN_2026.md`에서 관리한다.

## 8. P1 추천 기본안

### 콘텐츠

- 불씨 정령: `모닥`
- 대표 검투사: `카시아 벨란`
- +50 진화 후보: `성벽파쇄`, `용광의 심장`, `투기장의 맹세`
- 계보 수식어 6종: 예리·파쇄·수호·기민·잔화·명예
- 보조 수식어 10종
- 수집가: `에르사 로엔`
- 대표 수집 작품: `별철 의식 방패`

### UX

- 첫 30초 안에 망치 입력
- 첫 60초 안에 첫 강화
- 5분 안에 +5 완성 또는 +10 도전 판단
- 주요 터치 대상 최소 48dp
- 장비 카드: 이름 → 제작 등급·강화 → 계보 → 보조 → 소유자·운명 상태
- 고객 비교: 요청·기한 → 가치 방향 → 적합 이유 → 가격 → 후속 방향

### 명작 전당

- +50 이상 선택 등록
- 강화 단계·제작 등급·수식어·진화·연대기 표시
- 시즌 전당과 역대 전당 분리
- 성능 보상 없음
- 공개 등록 해제·신고 지원
- 서버 기능 출시 전 오프라인 작품은 레거시 전시 가능, 검증 랭킹 제외
- 숫자 점수만 제공하는 플랫폼 리더보드는 보조 수단이며 작품 메타데이터 정본에는 별도 서버 필요

## 9. Google Sheet 드리프트

현재 Sheet에는 다음 문제가 남아 있다.

- 고객 4종과 네 고객 상호작용을 현행 Demo 조건으로 기록
- +5/+10만 대표 흐름으로 기록하고 장기 +50 연결 미반영
- 최신 고객 범주 요청·최대 2개 요청·수집가 두 번째 세트 미반영
- `+`로 시작하는 텍스트가 수식으로 처리되어 여러 `#ERROR!` 발생
- 이전 Base 운영 버전 정보 잔존

Sheet는 사용자 `기획 완료` 후 마스터 기획에 맞춰 동기화한다.

## 10. 남은 정합성 확인

1. P1 추천 고유명·콘텐츠가 프로젝트 톤과 충돌하지 않는지
2. 초기 수식어 6+10개가 과도하거나 의미 중복인지
3. +50 진화 후보가 특정 계보를 정답으로 만들지 않는지
4. 카시아 경기 결과가 전투 시스템으로 확장되지 않는지
5. 수집가 세트가 공통 데이터 구조만으로 가능한지
6. 첫 5분과 15~25분 시간 예산이 함께 성립하는지
7. 명작 전당 레거시·검증 작품 분리가 사용자에게 오해를 만들지 않는지
8. 기존 강화·경제·보호 정본과 신규 콘텐츠가 충돌하지 않는지
