## 2. 프로젝트 코어

> **망치질로 장비를 만들고, 커지는 위험 앞에서 멈출지 도전할지 선택하며, 완성한 작품이 사람과 세계에 남기는 흔적을 확인하는 모바일 대장간 게임.**

감정 곡선:

```text
만드는 손맛
→ 더 올리고 싶은 욕심
→ 잃을 수 있다는 긴장
→ 멈춤 또는 도전의 책임감
→ 작품 완성의 자부심
→ 누구에게 넘길지 고민
→ 세계에서 쓰이는 장면 확인
→ 다음 작품을 만들 동기
```

## 3. 사용자 승인 결정

- 제작 등급: 보통 → 양질 → 우수 → 명품 → 걸작
- 장비 정체성: 계보 1개 + 보조 최대 2개
- +50: 진화와 대표 특수 형태 완성
- 고객: 범주 거래 자격 + 공개 적합 신호
- 수치형 내구도·반복 수리: 없음
- 운명 상태: 정상·전투 흔적·분실·회수·영구 파괴
- 두 번째 콘텐츠 세트: 수집가
- 미래 온라인 명칭: 명작 전당
- 새 시스템·핵심 규칙·콘텐츠 구조·주요 UX 흐름: 벤치마킹 선행 필수

## 4. 벤치마킹 판정

### 채택

- 제작 과정 자체의 직접 입력
- 고객 선택의 공개 이유
- 판매 장비의 세계 결과·연대기 환류
- 단일 전투력보다 여러 작품 정체성 축 비교

### Blacksmith 맞춤 변형

- 긴 제작 공정 → 30~90초 첫 반응·강화 진입
- 다수 고객·파벌 → 카시아 대표 흐름 + 에르사 별도 증명 세트
- 영웅 모험 → 결정적 장면 + 장비 기여 원인 + 연대기
- 온라인 시장 → 미래 명작 전당, 오프라인 코어 유지

### 제외

- 직원·시설·자원 생산 제국
- 길드·오픈마켓·필수 로그인
- 실시간 탐험·전투·자동전투
- 무제한 수식어·스킬
- 단일 종합 점수 랭킹

## 5. 정합성 검토에서 해결된 P0

### P0-01 정밀 등급 충돌

구형 구조:

```text
제작 완성도
+ 정밀 등급 1개
+ 수식어 A·B 2개
```

v9 구조:

```text
제작 등급
+ 계보 1개
+ 보조 2개
+ +50 진화
```

판정:

```text
PRECISION_GRADE_AXIS: SUPERSEDED
LEGACY_AFFIX_SLOT_A_B: SUPERSEDED
```

### P0-02 위험 이중 부과

구형 정밀강화는 10단위 진입 성공 후 별도 행동 실패를 추가했다.

v9는 10단위 진입 성공 시 정체성 결과를 보장 선택으로 확정한다.

```text
+10 성공
→ 계보 후보 선택
→ 별도 실패 없음
```

### P0-03 가치 계산 중복

최종 순서:

```text
강화 단계
→ 제작 등급
→ 일반 시장 수식어 보정
→ +50 진화
→ 운명·연대기
→ 고객 적합
→ 거래 채널·예산 상한
```

같은 요소를 일반 시장과 고객 적합에 같은 이유로 중복 계산하지 않는다.

## 6. P1 정합화 결과

### 수정 수식어

계보 ID:

- 정밀
- 파쇄
- 수호
- 기민
- 잔화
- 명예

보조:

- 균형 잡힌
- 경량화된
- 중량화된
- 견고한
- 충격을 흘리는
- 손에 맞춘
- 울림 있는
- 흔적을 새긴
- 의식 각인의
- 현장형

`정교한·흠없는`은 제작 등급과, `열을 품은`은 잔화 계보와 의미가 겹쳐 제거했다.

### +50 정답 방지

- 성벽파쇄: 경기 직접 기여 중심
- 용광의 심장: 경기·제작 정체성 균형
- 투기장의 맹세: 관계·명성·수집 가치 중심

세 후보의 총가치 예산을 유사하게 유지하고 어느 후보도 가격·승률·관계 전부에서 우월하지 않게 한다.

### 배팅 범위

대표 Vertical Slice는 `경기 전 조율 지원`을 사용한다.

배팅은 선택적 변형이며 대표 흐름·합격 기준에서 제외한다.

### 파괴 작품 공개 기록

```text
장비 객체: 영구 소멸
장비 연대기: 종료 기록 유지
명작 전당: DESTROYED 역사적 전시 가능
현재 사용 작품 랭킹: 제외
```

## 7. 최신 대표 흐름

| 시간 | 흐름 |
|---:|---|
| 0~2분 | 단조 마무리·첫 강화 |
| 2~6분 | 새 장비 +0→+5, 완성·도전 판단 |
| 6~10분 | 준비 +49 대표작의 +50 진화 |
| 10~14분 | 카시아 요청과 작품 비교 |
| 14~17분 | 작품 선택·판매·경기 전 조율·영업 종료 |
| 17~22분 | 결정적 경기 장면과 장비 기여 원인 |
| 22~25분 | 관계·연대기·다음 목표 |

수집가 에르사 세트는 대표 세션과 분리된 데이터 재사용 검증 시나리오다.

## 8. 경제·보호 유지 판정

유지:

- 일반 강화 최종 6결과 확률 공개
- 표시 단위 0.01%, 합계 100.00%
- 보호는 파괴 확률이 아니라 결과 효과 변환
- +0~+4 평균 투자 회수 전
- +5 최초 평균 흑자
- +5 이후 대표 단계 예상 순이익 증가
- +60~+100 완전 보호는 본제작 미래 구조

기획 완료 후 용어 전파 수정:

- `평범한` 기준 → `보통` 기준
- `정밀 등급` 제거
- `DAMAGED` 제거
- +60 이상 신규 슬롯 없음 명시
