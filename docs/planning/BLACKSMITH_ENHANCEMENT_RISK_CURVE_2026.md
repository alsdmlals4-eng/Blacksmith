## 1. 적용 범위

- 정식 최대 강화 단계는 `+100`이다.
- 통합 POC 대표 목표는 `+60`을 유지한다.
- 일반 강화의 최종 자연 결과는 다음 여섯 종류만 사용한다.

```text
대성공 / 성공 / 유지 / 1단계 하락 / 2단계 하락 / 파괴
```

- 일반 강화에서 한 번에 3단계 이상 하락하는 구형 규칙은 `SUPERSEDED`다.
- 정밀강화 실패는 이 표를 사용하지 않고 투입 재료만 잃는다.

## 3. 숙련 성장

### 3.1 성공 숙련

```text
성공 보정 숙련도
= 제작 숙련 × 60%
+ 해당 장비 분야 숙련 × 40%
```

```text
최종 총성공률
= MIN(단계별 상한,
      기본 총성공률 × (1 + 숙련 상대 보정률))
```

| 실제 적용 숙련도 | 기본 성공률 상대 증가 |
|---:|---:|
| 0% | 0% |
| 20% | 5% |
| 40% | 12% |
| 60% | 22% |
| 80% | 35% |
| 100% | 50% |

- +1~+5 상한 100%
- +6~+20 상한 95%
- +21~+100은 계산값을 사용하되 절대 100%를 넘지 않는다.

### 3.2 위험 숙련

```text
위험 감소 숙련도
= 강화 숙련 × 60%
+ 해당 장비 분야 숙련 × 40%
```

최대 숙련 기준:

- 1단계 하락 확률 15% 상대 감소
- 2단계 하락 확률 15% 상대 감소
- 파괴율 10% 상대 감소
- 감소한 위험 확률은 모두 `유지`로 이전

공통 대장장이 등급은 직접 확률을 크게 더하지 않고 적용 가능한 숙련 보정 구간의 상한을 해금한다.

## 4. 대성공

- 대성공은 총성공률 안에서 분리하며 추가 성공 확률을 생성하지 않는다.
- 대성공 결과는 현재 강화 단계에서 `+2` 상승이다.
- `+10` 단위 정밀강화·한계 돌파 이정표는 건너뛰지 않는다.
- 목표 `+49`, `+50`, `+100` 강화 시도에서는 대성공을 적용하지 않는다.

| 목표 구간 | 총성공 중 대성공 비중 |
|---:|---:|
| +1~+20 | 10% |
| +21~+40 | 7% |
| +41~+48 | 5% |
| +49~+50 | 0% |
| +51~+80 | 3% |
| +81~+99 | 2% |
| +100 | 0% |

## 7. 보호석·회복석 장기 루프

### 보호석

- 보호석은 성공률과 하락률을 개선하지 않는다.
- 유효한 강화 시도 시작 시 요구량 전부를 소모한다.
- 성공·대성공·유지·하락·파괴 전환 여부와 관계없이 소모한다.
- 보호석 미사용 파괴는 영구 파괴다.
- 보호석 사용 파괴는 같은 확률의 `DAMAGED`로 변환한다.
- 보호석이 부족해도 무보호 도전 또는 장비 보관을 선택할 수 있다.

### 회복석과 보관

POC 구조 기준:

- 회복 가능 기록 유지 기간: 게임 날짜 3일
- 장비당 최신 회복 기록 1개
- 기본 보관 슬롯 1개
- 보관 중 회복 기한 정지
- 회복석은 `DAMAGED` 장비의 사용 가능 상태를 확정 복구
- 회복 가능한 강화 손실은 손실분의 절반을 올림 처리해 복구하되 실패 직전 단계를 넘지 않음

정식 출시용 회복 비용, 회복석 요구량, DAMAGED 단계 손실량은 후속 결정이다.

### 장기 순환

```text
제작·판매
→ 보호석·회복석 확보
→ 고강화 도전
→ 성공·대성공 또는 유지
→ 하락 시 재강화
→ DAMAGED 시 회복석 사용 또는 보관
→ 자금 부족 시 다른 장비 제작·판매
→ 다시 고강화 도전
```

보호석은 영구 종료를 복구 가능한 중단으로 바꾸고, 회복석은 그 중단을 다시 강화 루프로 연결한다.

## 9. 판정 순서

```text
1. 숙련 적용 최종 총성공률 계산
2. 성공 영역에서 대성공 비중 분리
3. 대성공 또는 성공 판정
4. 실패 영역의 기본 파괴 질량 계산
5. 파괴 숙련 감소분을 유지로 분리
6. 남은 파괴 판정
7. 비파괴 실패에서 하락 1·2 판정
8. 하락 숙련 감소분을 유지로 분리
9. 나머지를 유지로 판정
10. 보호석 사용 시 파괴를 DAMAGED로 변환
```

- 모든 최종 결과 확률의 합은 정확히 1이어야 한다.
- 하락 1과 하락 2는 상호 배타적이다.
- +0 이하로 내려가지 않는다.

## 10. 폐기·후속 결정

### `SUPERSEDED`

- 최대 숙련 성공률 `+10%p` 고정 가산
- +60을 정식 최종 강화로 보는 가정
- 일반 강화의 3단계 이상 하락 결과
- 하락률을 실패 내부 75~93%까지 높이는 과도한 안
- 숙련으로 줄어든 파괴·하락 확률을 다른 위험 결과에 재분배하는 해석

### `REVIEW_REQUIRED`

1. +30~+100 보호석 요구량과 가격
2. DAMAGED 발생 시 강화 단계 손실량
3. 회복석 요구량·가격·회복 시간
4. +61~+100 강화 비용과 판매 가격
5. 실패 완충 타격을 새 최대 하락 2단계 구조에 맞게 단순화

## 11. 검증 계약

후속 시뮬레이션은 평균만 사용하지 않고 중앙값·75·90·95 분위와 다음을 보고한다.

- 목표 단계 도달 시도 횟수
- 대성공 횟수와 이정표 정지
- 하락 1·2 발생 횟수
- 무보호 영구 파괴 횟수
- 보호 사용 DAMAGED 횟수
- 보호석·회복석 소모량
- 복구 비용과 보관 빈도
- 공개시장 판매 후 재도전 가능 여부
- 한 번의 불운으로 제작·강화 전체가 잠기는 소프트락 여부

Godot 런타임 구현은 정확한 `기획 완료`와 `검수 완료` 이후 별도 계획과 PR로 진행한다.
