## 1. 적용 범위와 상한

- 정식 설계의 최대 강화 단계는 **+100**이다.
- 통합 POC의 대표 체험 목표는 기존대로 **+60**을 유지한다.
- +60은 최종 강화가 아니라 후반 진입 이정표다.
- 기존에 +60을 최종 단계로 가정해 배치한 최종 성공률·파괴율·하락률·보호석 요구량은 그대로 사용하지 않는다.
- +61~+100의 파괴·하락·보호석·복구·가격 수치는 후속 승인 전까지 `REVIEW_REQUIRED`다.

## 2. 외부 벤치마크에서 채택한 방향

세부 근거는 `BLACKSMITH_ENHANCEMENT_VALUE_BENCHMARK_2026.md`를 따른다.

- Black Desert Godr-Ayed는 대표 구간에서 약 9.90%에서 3.15%까지 성공률이 낮아진다.
- Black Desert Preonne은 25%에서 최종 7.5%까지 낮아지고 실패 시 단계 하락과 보장선이 존재한다.
- MapleStory Star Force는 고강화에서 성공률 감소, 단계 하락, 파괴 방지 추가 비용을 결합한다.

블랙스미스는 위 수치를 그대로 복제하지 않는다. +1부터 +100까지 순차 강화하고, 장비 생애·보관·보호석·DAMAGED 복구를 함께 사용하므로 다음 원칙만 적응한다.

1. 초반은 학습과 성장 흐름을 끊지 않는다.
2. +30부터 파괴 위험이 시작된다.
3. +70 이후는 한 자릿수에 접근하는 고위험 후반부로 설계한다.
4. +100은 기본 5%로 두어 최종 도전의 희소성을 유지한다.
5. 숙련 보정은 퍼센트포인트 고정 가산이 아니라 기본 성공률 비례 배율로 적용한다.

## 4. 숙련 성공률 보정

기존의 `최대 +10%p` 고정 가산안은 `SUPERSEDED`다.

### 4.1 계산식

```text
최종 성공률
= MIN(단계별 성공률 상한,
      기본 성공률 × (1 + 숙련 상대 보정률))
```

`숙련 +50%`는 기본 성공률에 1.5배를 적용한다는 뜻이다.

예시:

```text
기본 성공률 20%
× 최대 숙련 배율 1.5
= 최종 성공률 30%
```

기본 성공률 5%인 +100은 최대 숙련에서도 7.5%다.

### 4.2 숙련 성장 구간

| 실제 적용 숙련도 | 기본 성공률 상대 증가 |
|---:|---:|
| 0% | 0% |
| 20% | 5% |
| 40% | 12% |
| 60% | 22% |
| 80% | 35% |
| 100% | 50% |

- 구간 사이는 선형 보간한다.
- 초반에는 보정이 완만하고, 높은 숙련에서 성장 가치가 커진다.

### 4.3 단계별 상한

| 목표 구간 | 최종 성공률 상한 |
|---|---:|
| +1~+5 | 100% |
| +6~+20 | 95% |
| +21~+100 | 계산 결과 사용, 절대 100% 초과 금지 |

### 4.4 최대 숙련 예시

## 5. 숙련 출처와 공통 등급 제한

### 성공률용 관련 숙련

```text
성공 보정 숙련도
= 제작 숙련 × 60%
+ 해당 장비 분야 숙련 × 40%
```

### 위험 감소용 관련 숙련

```text
위험 감소 숙련도
= 강화 숙련 × 60%
+ 해당 장비 분야 숙련 × 40%
```

### 공통 대장장이 등급

공통 대장장이 등급은 큰 직접 확률 보너스를 제공하지 않는다. 대신 적용 가능한 숙련 보정 구간의 상한을 해금한다.

```text
실제 적용 숙련도
= MIN(관련 숙련 종합값,
      공통 대장장이 등급이 허용한 최대 구간)
```

이 구조는 공통 등급의 콘텐츠 해금 역할, 제작 숙련의 성공률 역할, 강화 숙련의 실패 손실 완화 역할, 장비 분야 숙련의 분야별 경험을 동시에 유지한다.

## 6. 실패 위험 숙련 보정

최대 숙련 기준:

| 항목 | 최대 효과 | 계산 방식 |
|---|---:|---|
| 단계 하락 발생률 | 15% 감소 | 상대 감소 |
| 파괴율 | 10% 감소 | 상대 감소 |

예를 들어 파괴율 25%에 최대 보정을 적용하면:

```text
25% × 0.90 = 22.5%
```

감소한 하락·파괴 확률은 다른 위험 결과로 이동하지 않고 모두 `유지`로 이전한다.

---

## 7. 결과 판정 순서

일반 강화의 최종 판정 순서는 다음과 같다.

```text
1. 최종 성공률 계산 및 성공 판정
2. 실패한 경우 실패 내부 파괴 판정
3. 파괴되지 않은 실패의 단계 하락 판정
4. 나머지는 유지
```

숙련 효과는 다음처럼 작동한다.

- 성공률 상대 증가분은 전체 실패 확률을 줄인다.
- 파괴율 감소분은 `유지`로 이동한다.
- 하락률 감소분은 `유지`로 이동한다.
- 보호석은 성공률을 높이지 않는다.
- 보호석 사용 시 최종 파괴 결과만 `DAMAGED`로 변환한다.

정밀강화 실패는 이 판정표를 사용하지 않는다. 정밀강화는 기존 기준대로 투입 재료만 잃고 장비 상태를 유지한다.

## 8. 함께 유지되는 승인 규칙

- 영구 파괴는 목표 +30부터 발생한다.
- +30 이상에서도 무보호 강화는 허용한다.
- 무보호 시 파괴 결과는 영구 소멸이다.
- 보호석 사용을 켜고 유효한 강화 시도가 시작되면 결과와 관계없이 요구량 전부를 소모한다.
- 보호석 사용 시 파괴 결과는 `DAMAGED`로 변환한다.
- 보호석은 성공률이나 일반 단계 하락을 직접 개선하지 않는다.
- 보호석이 부족하면 무보호 도전 또는 장비 보관을 선택할 수 있다.
- 고강화 장비를 보관하고 다른 제작·판매 활동으로 보호석 자금을 마련하는 흐름을 지원한다.

## 9. 폐기·재검토 상태

### `SUPERSEDED`

- 최대 숙련 성공률 `+10%p` 고정 가산
- +60을 정식 최종 강화로 보는 가정
- +60에 최종 단계용 파괴율·하락률·보호석 수치를 집중한 배치

### `REVIEW_REQUIRED`

1. +30~+100 실패 내부 파괴율 곡선
2. +61~+100 단계 하락 발생률
3. +61~+100 최대 하락 단계
4. +60~+100 보호석 요구량 재배치
5. DAMAGED 복구 비용·시간·회복석 곡선
6. +61~+100 강화 비용과 판매 가격

## 10. 검증 계약

이 곡선은 데이터 승인값이며 런타임 구현 완료 증거가 아니다.

후속 시뮬레이션은 평균만 사용하지 않고 다음을 보고해야 한다.

- 목표 단계 도달 시도 횟수의 중앙값·75·90·95 분위
- 누적 골드와 재료 비용
- 단계 하락 횟수와 복구 구간
- 무보호 영구 파괴 횟수
- 보호 사용 시 DAMAGED 발생 횟수
- 보호석 총소모량
- 복구 비용
- 보호석 부족으로 장비를 보관하고 자금을 다시 마련하는 빈도

성공률·파괴율·하락률·보호석 가격·판매 가격을 한 번에 모두 조정하지 않는다. 각 결정 후 입력 스냅샷과 가드레일을 고정하고 순차 검증한다.

Godot 런타임 구현은 정확한 `기획 완료`와 `검수 완료` 이후 별도 계획과 PR로 진행한다.
