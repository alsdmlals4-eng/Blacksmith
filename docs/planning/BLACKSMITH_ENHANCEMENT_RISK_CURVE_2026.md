## 1. 적용 범위

- 정식 최대 강화 단계는 `+100`이다.
- 통합 POC 대표 목표는 `+60`을 유지한다.
- 일반 강화의 자연 결과는 다음 여섯 종류만 사용한다.

```text
대성공 / 성공 / 유지 / 1단계 하락 / 2단계 하락 / 파괴
```

- 일반 강화에서 한 번에 3단계 이상 하락하는 구형 규칙은 `SUPERSEDED`다.
- 정밀강화 실패는 이 표를 사용하지 않고 투입 재료만 잃는다.
- 보호석은 자연 결과가 정해진 뒤 하락·파괴 결과를 변환한다.

## 3. 숙련 성장

### 3.1 성공 숙련

```text
성공 보정 숙련도
= 제작 숙련 × 60%
+ 해당 장비 분야 숙련 × 40%
```

```text
최종 총성공률
= MIN(단계별 상한,
      기본 총성공률 × (1 + 숙련 상대 보정률))
```

| 실제 적용 숙련도 | 기본 성공률 상대 증가 |
|---:|---:|
| 0% | 0% |
| 20% | 5% |
| 40% | 12% |
| 60% | 22% |
| 80% | 35% |
| 100% | 50% |

- +1~+5 상한 100%
- +6~+20 상한 95%
- +21~+100은 계산값을 사용하되 절대 100%를 넘지 않는다.

### 3.2 위험 숙련

```text
위험 감소 숙련도
= 강화 숙련 × 60%
+ 해당 장비 분야 숙련 × 40%
```

최대 숙련 기준:

- 1단계 하락 확률 15% 상대 감소
- 2단계 하락 확률 15% 상대 감소
- 파괴율 10% 상대 감소
- 감소한 위험 확률은 모두 `유지`로 이전

공통 대장장이 등급은 직접 확률을 크게 더하지 않고 적용 가능한 숙련 보정 구간의 상한을 해금한다.

## 4. 대성공

- 대성공은 총성공률 안에서 분리하며 추가 성공 확률을 생성하지 않는다.
- 대성공 결과는 현재 강화 단계에서 `+2` 상승이다.
- `+10` 단위 정밀강화·한계 돌파 이정표는 건너뛰지 않는다.
- 목표 `+49`, `+50`, `+100` 강화 시도에서는 대성공을 적용하지 않는다.

| 목표 구간 | 총성공 중 대성공 비중 |

| +1~+20 | 10% |
| +21~+40 | 7% |
| +41~+48 | 5% |
| +49~+50 | 0% |
| +51~+80 | 3% |
| +81~+99 | 2% |
| +100 | 0% |

## 7. 보호석

### 7.1 역할

보호석은 성공률을 올리지 않는다. 자연 결과가 하락 또는 파괴일 때만 최종 결과를 다음처럼 바꾼다.

| 자연 결과 | 보호석 사용 최종 결과 |
|---|---|
| 1단계 하락 | 유지 |
| 2단계 하락 | 유지 |
| 파괴 | 보호 파괴 + 대폭 단계 하락 |
| 대성공·성공·유지 | 변경 없음 |

- 보호석 미사용 상태에서 파괴가 나오면 장비는 즉시 영구 소멸한다.
- 보호석 사용 상태에서 파괴가 나오면 장비는 소멸하지 않는다.
- 보호된 장비는 별도 `DAMAGED` 상태가 되지 않으며 즉시 사용 가능하다.
- DAMAGED 수리, 회복석, 회복 기록, 회복 기한은 존재하지 않는다.
- 보호석이 부족하면 무보호 도전 또는 장비 보관을 선택할 수 있다.

### 7.2 단계별 요구량

보호석은 등급이 없는 단일 아이템이다. 아래 수량은 목표 강화 단계를 기준으로 유효한 시도 시작 시 전량 소모한다.

| 목표 강화 단계 | 보호석 소모 |
|---:|---:|
| +1~+10 | 사용 불가 |
| +11~+20 | 1개 |
| +21~+29 | 2개 |
| +30~+39 | 3개 |
| +40~+49 | 4개 |
| +50~+59 | 6개 |
| +60~+69 | 8개 |
| +70~+79 | 10개 |
| +80~+89 | 12개 |
| +90~+99 | 15개 |
| +100 | 18개 |

소비 규칙:

- 시도 버튼을 누르기 전 보호석 사용 여부를 선택한다.
- 유효한 강화 시도가 시작되면 요구량 전부를 즉시 소모한다.
- 대성공·성공·유지·하락 방지·파괴 방지 여부와 관계없이 반환하지 않는다.
- 취소하거나 자원 부족으로 시도가 시작되지 않으면 소모하지 않는다.

### 7.3 보호 파괴 단계 하락

파괴를 보호석으로 막았을 때 하락량은 **시도 직전 현재 강화 단계**를 기준으로 계산한다.

```text
보호 파괴 하락량
= MAX(3, FLOOR(시도 직전 현재 강화 단계 ÷ 10))
```

| 시도 직전 현재 단계 | 보호 파괴 하락량 |
|---:|---:|
| +29~+39 | -3 |
| +40~+49 | -4 |
| +50~+59 | -5 |
| +60~+69 | -6 |
| +70~+79 | -7 |
| +80~+89 | -8 |
| +90~+99 | -9 |

예시:

```text
현재 +51에서 강화 시도
→ 파괴 판정
→ 보호석이 소멸을 방지
→ 5단계 하락
→ 사용 가능한 +46 장비로 즉시 전환
```

```text
현재 +60에서 강화 시도
→ 파괴 판정
→ 보호석이 소멸을 방지
→ 6단계 하락
→ 사용 가능한 +54 장비로 즉시 전환
```

```text
현재 +99에서 +100 시도
→ 파괴 판정
→ 보호석이 소멸을 방지
→ 9단계 하락
→ 사용 가능한 +90 장비로 즉시 전환
```

## 9. 판정 순서

```text
1. 숙련 적용 최종 총성공률 계산
2. 성공 영역에서 대성공 비중 분리
3. 대성공 또는 성공 판정
4. 실패 영역의 기본 파괴 질량 계산
5. 파괴 숙련 감소분을 유지로 분리
6. 남은 파괴 판정
7. 비파괴 실패에서 하락 1·2 판정
8. 하락 숙련 감소분을 유지로 분리
9. 나머지를 유지로 판정
10. 보호석 사용 시 하락 1·2를 유지로 변환
11. 보호석 사용 시 파괴를 보호 파괴로 변환하고 단계 하락 적용
12. 보호석 미사용 파괴는 장비 즉시 영구 소멸
```

- 모든 자연 결과 확률의 합은 정확히 1이어야 한다.
- 하락 1과 하락 2는 상호 배타적이다.
- 보호 파괴 하락 후 +0 이하로 내려가지 않는다.
- 위험·결과 사전 카드에는 보호석 요구량, 무보호 즉시 소멸, 보호 파괴 예상 하락량을 시도 전에 표시한다.

## 10. 장기 순환

```text
제작·판매
→ 보호석 확보
→ 고강화 도전
→ 일반 하락은 보호 유지
→ 보호 파괴 시 대폭 단계 하락
→ 낮아진 단계부터 재강화
→ 보호석 부족 시 장비 보관
→ 다른 장비 제작·판매로 자금 확보
→ 다시 고강화 도전
```

- 보호석은 영구 소멸을 막지만 강화 진행을 보존하지는 않는다.
- 회복석이나 수리 단계가 없으므로 파괴 방지 후 즉시 재강화 루프로 복귀한다.
- 무보호 도전은 영구 소멸 위험을 감수하는 선택으로 유지한다.

## 11. 폐기·후속 결정

### `SUPERSEDED`

- 최대 숙련 성공률 `+10%p` 고정 가산
- +60을 정식 최종 강화로 보는 가정
- 일반 강화의 3단계 이상 자연 하락
- 하락률을 실패 내부 75~93%까지 높이는 과도한 안
- 숙련으로 줄어든 파괴·하락 확률을 다른 위험 결과에 재분배하는 해석
- 보호석이 파괴만 `DAMAGED`로 바꾸는 규칙
- 지속형 `DAMAGED` 상태와 DAMAGED 수리
- 회복석, 회복 기록 3일, 회복 기한, 단계 복원
- 보호석 등급 분리

### `REVIEW_REQUIRED`

1. 보호석 가격·제작·획득 곡선
2. +61~+100 강화 비용과 판매 가격
3. 실패 완충 타격과 보호 파괴의 최종 상호작용

## 12. 검증 계약

후속 시뮬레이션은 평균만 사용하지 않고 중앙값·75·90·95 분위와 다음을 보고한다.

- 목표 단계 도달 시도 횟수
- 대성공 횟수와 이정표 정지
- 자연 하락 1·2 발생 횟수
- 보호로 막은 하락 1·2 횟수
- 무보호 즉시 영구 소멸 횟수
- 보호 파괴 횟수와 누적 단계 손실
- 보호석 총소모량
- 장비 보관 후 자금 마련 빈도
- 공개시장 판매 후 재도전 가능 여부
- 한 번의 불운으로 제작·강화 전체가 잠기는 소프트락 여부

Godot 런타임 구현은 정확한 `기획 완료`와 `검수 완료` 이후 별도 계획과 PR로 진행한다.
