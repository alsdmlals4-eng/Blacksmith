## 1. 사용자 승인

사용자는 `+30~+100` 파괴율의 **최종 위험 이전형 권장안**을 승인했다.

이 결정은 다음 방향을 확정한다.

- 파괴 가능 시작 단계는 목표 `+30`
- 최대 강화 단계는 `+100`
- 기존에 `+60` 최종 단계에 배치했던 실패 내부 파괴율 25%는 폐기
- 최종 실패 내부 파괴율 25%는 `+100`으로 이동
- +30부터 +100까지 위험을 단계적으로 가속
- 보호석 미사용 파괴 결과는 영구 소멸
- 보호석 사용 파괴 결과는 `DAMAGED`

상태: `POC_TUNABLE / APPROVED_CURRENT`

## 3. 숙련 보정

위험 감소용 숙련은 기존 승인대로 다음 합성값을 사용한다.

```text
위험 감소 숙련도
= 강화 숙련 × 60%
+ 해당 장비 분야 숙련 × 40%
```

공통 대장장이 등급은 적용 가능한 숙련 구간의 상한을 해금한다.

최대 위험 숙련 시 파괴율은 기본 파괴율에서 10% 상대 감소한다.

```text
최종 실패 내부 파괴율
= 기본 실패 내부 파괴율 × 0.90
```

감소한 파괴 확률은 단계 하락 판정으로 이동하지 않고 `유지`로 직접 이전한다.

```text
시도당 파괴 결과 확률
= (1 - 최종 성공률) × 최종 실패 내부 파괴율
```

보호석이 없으면 위 결과는 영구 파괴다. 보호석 사용 상태에서는 `DAMAGED`로 변환된다.
