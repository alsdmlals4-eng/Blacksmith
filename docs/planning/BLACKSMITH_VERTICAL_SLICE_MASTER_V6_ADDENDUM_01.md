## 10단위 진입 강화의 정의

`[정밀강화]`는 10단위 강화 단계에 도달한 뒤 별도로 실행하는 후속 행동이 아니다. 다음 단계로 진입시키는 **강화 시도 자체**가 정밀강화다.

```text
+9 → +10   = [정밀강화]
+19 → +20  = [정밀강화]
+29 → +30  = [정밀강화]
+39 → +40  = [정밀강화]
+49 → +50  = [정밀강화] 또는 [고위 정밀강화]
+59 → +60  = [정밀강화]
...
+89 → +90  = [정밀강화]
+99 → +100 = [정밀강화]
```

- 일반 강화는 10단위 이정표 사이의 단계 상승 시도다.
- 정밀강화는 `현재 단계의 끝자리가 9인 상태`에서 다음 10단위로 진입하는 강화 시도다.
- 성공하면 강화 단계가 해당 10단위로 상승하고 정밀강화 결과가 함께 적용된다.
- 정확한 비용·확률·실패 결과별 수치는 플레이테스트 조정 대상이다.

## 일반 정밀강화 실패 규칙

특수재료를 사용하지 않는 `[정밀강화]`는 확률 판정이며, **해당 강화 구간의 일반 강화 위험 규칙을 그대로 적용**한다.

```text
정밀강화 시도
├─ 성공
│  → 다음 10단위 단계 도달
│  → 정밀강화 결과 적용
└─ 실패
   → 해당 구간의 일반 실패 결과 적용
```

실패 시 가능한 결과:

- 강화 재료 소모
- 단계 유지
- 단계 하락
- 고강화 구간의 장비 영구 파괴
- 보호 강화 선택 시 영구 파괴 방지

규칙 경계:

- 정밀강화라는 이유만으로 성공률이 보장되지 않는다.
- 정밀강화라는 이유만으로 영구 파괴가 면제되지 않는다.
- 보호 강화는 일반 강화와 동일하게 영구 파괴만 방지하며, 성공률·재료 소모·단계 하락은 보장하지 않는다.
- 실패한 정밀강화에서는 다음 10단위 단계와 정밀강화 결과를 획득하지 못한다.
- 실패 후 현재 단계가 다시 끝자리 `9`가 되면 정밀강화를 재시도할 수 있다.
- 정확한 성공 확률, 비용, 단계 하락 폭과 파괴 확률은 플레이테스트 조정 대상이다.

이 규칙은 `+9 → +10`, `+19 → +20`, `+29 → +30` 등 모든 일반 정밀강화에 적용한다. 단, 특수재료를 사용하는 `+49 → +50` 고위 정밀강화는 아래의 확정 성공 예외를 적용한다.

## +49 → +50 고위 정밀강화

`+49` 장비에서 `[특수재료]`를 촉매로 선택하면 `+49 → +50` 강화 시도 자체가 `[고위 정밀강화]`가 된다. `+50`에 먼저 도달한 뒤 별도의 고위 정밀강화를 실행하는 구조가 아니다.

```text
+49 장비
+ 기존 수식어
+ 선택한 특수재료
+ 고위 정밀강화용 보조 재료
→ 계보에 맞는 진화 후보 2~3개 공개
→ 플레이어가 후보 하나 선택
→ [고위 정밀강화] 확정 성공
→ 장비 +50 도달
→ 선택한 형태로 진화
→ 대표 특수 수식어 획득
```

### 보장

- `+49 → +50` 단계 상승이 확정된다.
- 실패, 단계 유지, 단계 하락, 장비 파괴가 발생하지 않는다.
- 무변화 또는 특수재료만 소실되는 결과가 없다.
- 선택한 후보로의 장비 진화가 확정된다.
- 대표 특수 수식어 획득이 확정된다.
- 기존 장비와 수식어의 정체성은 보존되거나 승격된다.

### 변동 가능

- 세부 등급
- 부가 수치
- 보조 효과
- 이후 세계 사건의 실제 성과

### 비용 원칙

확정 성공의 대가는 높은 재료비다.

- 일반 정밀강화보다 명확히 비싸다.
- 다음 강화, 고객 지원, 배팅 계획에 영향을 줄 정도의 경제적 결정을 요구한다.
- 투입한 특수재료와 고위 정밀강화용 보조 재료는 성공 시 소비한다.
- 정확한 재료 종류, 요구 수량과 가격은 플레이테스트 조정 대상이다.
- 희귀 촉매를 반복적으로 부담 없이 사용할 수 있는 가격 구조는 허용하지 않는다.

고위 정밀강화의 긴장은 성공 여부가 아니라 **어떤 진화를 선택할지, 높은 비용을 지금 감당할지**에서 발생한다.

## 특수재료를 사용하지 않는 +49 → +50

특수재료를 사용하지 않으면 `+49 → +50`은 일반 `[정밀강화]`로 처리한다.

- 장비 진화와 대표 특수 수식어는 발생하지 않는다.
- 성공하면 일반 정밀강화 결과를 받고 +51 이상으로 계속 강화할 수 있다.
- 실패하면 +40대 일반 강화 구간의 실패 위험을 그대로 적용한다.
- 정확한 성공·실패 수치와 비용은 플레이테스트 조정 대상이다.

## 강화 전 위험 정보 표시

강화 화면은 **핵심 위험 상시 표시 + 전체 결과 확률 상세 펼치기** 구조를 사용한다.

### 기본 화면 상시 표시

플레이어가 강화 여부를 판단하는 데 필요한 다음 정보를 항상 노출한다.

- 현재 단계와 목표 단계
- 성공률
- 이번 시도의 총재료비와 소비 재료
- 실패 시 최대 단계 하락
- 영구 파괴 가능 여부
- 보호 사용 여부와 보호 비용
- 보호 사용으로 실제로 달라지는 항목
- 성공 후 예상 장비 가치 또는 가치 방향

기본 화면은 반복 강화의 속도를 해치지 않도록 전체 실패 분포를 모두 펼쳐 놓지 않는다.

### 상세 확률 보기

플레이어가 상세 보기를 열면 현재 강화 시도의 전체 결과 분포를 정확히 확인할 수 있다.

예시 항목:

- 성공
- 단계 유지
- 1단계 하락
- 2단계 이상 하락
- 영구 파괴

결과 종류가 세분화되는 경우 각 결과의 정확한 확률을 개별 표시한다. 숨겨진 실패 결과를 두지 않는다.

### 보호 전후 비교

보호 선택 화면은 다음 차이를 직접 비교한다.

| 항목 | 비보호 | 보호 |
|---|---|---|
| 성공률 | 동일 | 동일 |
| 일반 강화 재료 | 동일한 기본 요구 | 동일한 기본 요구 |
| 추가 보호 비용 | 없음 | 있음 |
| 단계 하락 | 가능 | 가능 |
| 영구 파괴 | 가능 | 방지 |
| 총비용 효율 | 상대적으로 높음 | 상대적으로 낮음 |

- 보호는 성공률을 높이지 않는다.
- 보호는 실패를 성공으로 바꾸지 않는다.
- 보호는 재료 소모와 단계 하락을 막지 않는다.
- 보호는 영구 파괴만 방지한다.

### 강화 종류별 강조

#### 일반 강화

성공률, 비용, 최대 하락과 파괴 가능 여부를 기본 규칙에 따라 표시한다.

#### 일반 정밀강화

`10단위 진입 시도`임을 명확히 표시하고, 성공 시 정밀강화 결과가 함께 적용된다는 점과 실패 시 해당 구간의 일반 위험이 적용된다는 점을 강조한다.

#### 고위 정밀강화

다음을 상시 강조한다.

- `확정 성공`
- `+49 → +50 도달 보장`
- `실패·하락·파괴 없음`
- `고액 특수재료 소비`
- `진화 후보 선택 필요`

고위 정밀강화에는 실패 확률 상세가 존재하지 않는다. 대신 후보별 진화 결과, 대표 특수 수식어, 비용과 남은 운영 자원을 비교하게 한다.

```text
RISK_DISCLOSURE_DEFAULT: CORE_RISK_ALWAYS_VISIBLE
RISK_DISCLOSURE_DETAIL: EXACT_OUTCOME_DISTRIBUTION_ON_EXPAND
PROTECTION_COMPARISON: DIRECT_SIDE_BY_SIDE
HIDDEN_FAILURE_OUTCOME: FORBIDDEN
HIGH_PRECISION_DISPLAY: GUARANTEED_SUCCESS_AND_HIGH_COST
EXACT_UI_LAYOUT: UNRESOLVED
```

## 감사 영향

기존 `MUST_FIX-01`은 다음 오해를 전제로 했다.

```text
+49 → +50 일반 강화
→ 성공 후 별도 고위 정밀강화
```

이 구조는 폐기한다. 특수재료를 선택한 대표 경로에서는 `+49 → +50` 시도 자체가 확정 성공하는 고위 정밀강화이므로, 대표 장비가 진입 전에 파괴되어 핵심 경로가 중단되는 문제는 해소된다.

```text
MILESTONE_ENHANCEMENT_DEFINITION: TRANSITION_ATTEMPT_ITSELF
NORMAL_PRECISION_RESULT: PROBABILISTIC
NORMAL_PRECISION_FAILURE_RULE: SAME_AS_CURRENT_ENHANCEMENT_BAND
NORMAL_PRECISION_DESTRUCTION_EXEMPTION: NONE
HIGH_PRECISION_TRIGGER: +49_TO_+50_WITH_SPECIAL_MATERIAL
HIGH_PRECISION_RESULT: GUARANTEED_SUCCESS
HIGH_PRECISION_COST_DIRECTION: HIGH_MATERIAL_COST
EXACT_COST_AND_PROBABILITY: PLAYTEST_TUNABLE
MUST_FIX_01: RESOLVED_BY_RULE_CLARIFICATION
```
