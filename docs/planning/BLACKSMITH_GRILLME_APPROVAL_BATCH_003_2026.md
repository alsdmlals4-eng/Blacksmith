## 최종 승인 결정

### 1. `BS-LIFE-20260802-10` — 수집가와 외부 작품의 출처 경계

- 수집가는 플레이어가 직접 제작하고 방문 고객에게 납품해 생애가 활성화된 뒤 처분 경로를 거친 작품만 취급한다.
- 외부 작품은 수집가 재고·순환·재매입·`COLLECTOR_HELD`·`REACQUIRED` 상태에 들어가지 않는다.
- 외부 작품은 명예의 전당에 전시될 수 있으나 구매·복제·플레이어 UID 편입으로 연결되지 않는다.

### 2. `BS-HOF-20260802-01` — 플레이어·외부 작품 공동 전시

- 플레이어 작품과 외부 세계 작품 모두 명예의 전당에 진입할 수 있다.
- 두 출처는 같은 아카이브에서 열람되지만 직접 수치 경쟁하지 않는다.
- 명예의 전당 등록은 판매·소유권 이전·수집가 진입·재고 제거를 발생시키지 않는다.

### 3. `BS-HOF-20260802-02` — 최초 입성 스냅샷과 명시적 갱신

- 최초 입성 스냅샷은 영구 보존한다.
- 실제 작품 상태는 자동·실시간으로 명예의 전당에 동기화하지 않는다.
- 신규 등록과 기존 작품 갱신은 하나의 현실 일일 행동 한도를 공유한다.

### 4. `BS-HOF-20260802-03` — KST 자정 초기화

- 현실 일일 등록권은 모든 지역에서 `Asia/Seoul / UTC+09:00` 기준 매일 `00:00 KST`에 초기화한다.
- 정확히 24시간을 기다리는 쿨다운이 아니다.
- 게임 내 날짜, 기기 시계, 계정 지역과 재접속으로 우회할 수 없다.

### 5. `BS-HOF-20260802-04` — 성공한 원자 저장만 횟수 소모

- 자격 검증·스냅샷 저장·성공 시각·KST 사용 기록이 하나의 원자적 작업으로 모두 성공했을 때만 일일 횟수를 소모한다.
- 취소·자격 미달·유효성 실패·저장 실패·롤백은 횟수를 소모하지 않는다.
- 저장은 성공했지만 응답만 유실된 재시도는 멱등하게 기존 성공 결과를 반환하며 중복 등록·추가 소모를 만들지 않는다.

### 6. `BS-HOF-20260802-05` — 등록 자격식

```text
+50 이상
AND
(
  특수 재료 기반 특수 수식어
  OR
  정식 세트 아이템
)
AND
특수 연대기
```

- 단순 고강화·희귀 재료·세트 명칭만으로는 등록할 수 없다.
- 외부 작품은 강화·희소성·특수 연대기라는 동일한 의미 축을 보존하는 동등 증거 기준을 사용한다.

### 7. `BS-HOF-20260802-06` — 개별 UID 등록과 세트 연결 전시

- 등록 단위는 개별 작품 UID다.
- 세트 자격은 희소성 분기만 통과시키며 다른 구성품을 자동 등록하지 않는다.
- 등록 작품은 자기 상태로 `+50 이상`이고 자기 UID가 실제 기여한 특수 연대기를 가져야 한다.
- 세트 묶음 페이지는 공동 역사·구성 관계를 보여주는 조회 화면이며 별도 항목·중복 집계를 만들지 않는다.

### 8. `BS-HOF-20260802-07` — 특수 연대기 인정

다음 중 하나로 인정한다.

1. 해당 UID가 핵심 기여한 결정적 단일 이정표 사건
2. 같은 UID의 납품·사용·성과 또는 실패·손상·복원·재출전·계승 등이 인과적으로 연결된 생애 서사

- 성공뿐 아니라 의미 있는 실패·희생·대파·복원·계승·재도전도 인정할 수 있다.
- 단순 횟수, 소유 기간, 강화량, 재료 가치, 사건 현장 존재, 반복 템플릿 파밍과 화려한 자동 문구는 인정 근거가 아니다.
- 두 인정 경로를 모두 충족해도 자동으로 이중 자격·이중 보상을 만들지 않는다.

### 9. `BS-HOF-20260802-08` — 작품별 최고 자격 스냅샷 유지

- 작품별로 `최초 입성 스냅샷`과 `최고 자격 스냅샷`을 분리 보관한다.
- 손상·강화 하락·수식어 잠금은 전당 기록을 자동 하향하지 않는다.
- 갱신 후보가 현재 자격을 충족하고 기존 최고보다 높은 경우에만 최고 자격 스냅샷을 갱신한다.
- 자격 미달·낮거나 같은 제출은 `기록 개선 없음`으로 처리하며 기록과 일일 횟수를 변경하지 않는다.
- `더 높다`는 같은 작품의 제출 이력 비교이며 작품 간 경쟁 순위가 아니다.

### 10. `BS-HOF-20260802-09` — 비경쟁 작품 아카이브

- 명예의 전당은 작품 간 등수·점수·티어·상위 퍼센트·승패를 제공하지 않는다.
- 플레이어 작품 순위, 외부 작품 순위, 통합 순위를 모두 만들지 않는다.
- 시즌·상위권·경쟁 보상을 제공하지 않는다.
- 검색·필터·최근 등록·테마 전시·연결 작품 탐색은 감상과 탐색을 위한 큐레이션이며 공식 서열이 아니다.
- 조회수·좋아요·추천 수·등록 작품 수를 경쟁 점수, 등록 자격, 전투·경제 보너스로 사용하지 않는다.
- 유료 결제·광고·희귀 재화로 등록 횟수, 노출 우선권과 전시 순서를 구매하지 않는다.
- 기본 명예의 전당을 경쟁 시스템으로 바꾸려면 별도 사용자 승인 Decision ID가 필요하다.
