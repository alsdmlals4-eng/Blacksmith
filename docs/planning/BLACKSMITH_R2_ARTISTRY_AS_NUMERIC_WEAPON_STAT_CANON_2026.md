## 결정

예술성은 제작 등급이나 별도 희귀도 단계가 아니라 **무기·작품 능력치의 하나**다.

```text
field: artistry
conceptual type: non-negative integer
minimum: 0
fixed design maximum: none
named tiers: none
```

대표 원수치 표기: `예술성 27`.

```text
공격력  42
내구도  31
조작성  18
예술성  27
```

- `0` 이상의 정수
- 소수점 없음
- 고정 설계 최대치 없음
- 분모·별점·백분율 표기 없음
- 예술성 단계명 없음
- 희귀도명 없음
- 다른 무기 능력치와 같은 영역에 원수치 표시
- 기술적 자료형 한계는 콘텐츠 최대치가 아님

## 예술성 0

`예술성 0`은 미완성품이나 사용 불가가 아니다. 기능과 안전 기준은 충족하지만 장식·세공·미적 의도가 거의 없는 순수 기능품이다.

## 책임

예술성은 조형 완성도, 표면 마감과 세공, 장식 구성과 조화, 작품으로서의 인상, 감정·전시·수집 가치에 기여하는 미적 완성을 표현한다.

영향 가능 범위:

- 판매 가치와 감정 가치
- 귀족·후원자·수집가 선호
- 전시·증여·의식·기념품 수요
- 예술성 최소 요구치·선호 구간이 있는 고객과 일정 판정

## 다른 축과의 경계

```text
제작 등급 = 최초 단조의 기술적 완성도
예술성 = 누적 가능한 미적·작품 능력치
촉매 수식어 = 정밀강화 선택과 촉매 계보
연대기 수식어 = 실제 작품 생애
```

```text
[전설] 운철 전투도끼 / 예술성 3
[보통] 은제 의장검 / 예술성 87
```

- 제작 등급은 예술성의 고정 상한을 만들지 않음
- `[전설]`이 높은 예술성을 보장하지 않음
- `[보통]`도 높은 예술성을 가질 수 있음
- 예술성은 네 번째 수식어 슬롯이 아님

## 생성과 변화

현재 승인된 원천:

- 최초 제작 결과
- `ARTISTIC_FINISH` 정밀강화 방식
- 예술성 관련 촉매·수식어 효과
- 세공·마감 콘텐츠
- 손상·복원 과정의 미적 상태 변화

강화 레벨만으로 자동 증가하지 않으며 동일 행동 반복으로 무한 효율을 얻지 않는다. 구체적인 증감값·비용·성공률은 `BASELINE_TEST_PRESET / USER_PLAYTEST_REQUIRED`다.

## 경제·수요 경계

- 화면에는 원수치를 그대로 표시
- 판매·감정·고객 선호 계산에는 콘텐츠별 기대 범위와 점감 함수 사용 가능
- 고객과 일정은 최소 요구치·선호 구간·다른 능력치 조합 사용 가능
- 높은 예술성이 모든 고객과 상황의 최적해가 되지 않게 함
- 정확한 점감 함수와 기대 범위는 별도 승인

## 전투 경계

예술성은 전투 성능을 기본적으로 올리지 않는다.

금지:

- 공격력·방어력·내구도·조작성의 범용 증가
- 모든 수식어 수치의 일괄 증폭
- 예술성을 종합 전투력으로 자동 환산
- 높은 예술성만으로 모든 장비 선택 지배

## 대체된 계약

동일 Decision의 초기 bounded-stat 초안과 named-tier 프리셋은 `[대체됨]`이며 정확한 옛 문자열과 모델 ID는 Legacy Registry에만 역사 증거로 보존한다.

```text
NON_NEGATIVE_INTEGER_NO_FIXED_DESIGN_MAXIMUM
```

## 미확정

- 콘텐츠 단계별 기대 예술성 범위
- 가격·감정 가치의 점감 함수
- 고객별 최소 요구치와 선호 구간
- 손상·복원에 따른 증감
- 저장 자료형과 overflow 보호
- 시각 변화의 정확한 매핑

## 적대적 보호 조건

- 예술성 고정 설계 최대치 재도입 금지
- 분모·별점·백분율 표기 금지
- 예술성 0을 미완성·사용 불가와 동일시 금지
- 제작 등급이 예술성 상한을 결정하게 하지 않음
- 예술성을 범용 전투력·수식어 배율로 변환 금지
- 기술적 자료형 한계를 콘텐츠 최대치로 노출하지 않음
- 구체적 점감·분포를 사용자 승인 없이 제품값으로 고정하지 않음
- 제품 구현은 계속 `BLOCKED`
