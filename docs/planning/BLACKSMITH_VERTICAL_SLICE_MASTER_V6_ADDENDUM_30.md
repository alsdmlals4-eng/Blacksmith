## 결정 84 — 고객별 매입 배수와 후속 보상 채널 분리

`[방문 고객]` 거래 가격은 모든 고객에게 동일한 고정 배수를 적용하지 않는다.

각 고객 유형은 데이터로 정의된 **고객별 매입 배수**를 사용하며, 거래 전에 해당 배수와 확정 금액을 공개한다.

```text
일반 판매 기준 가치
× 방문 고객별 매입 배수
= 방문 고객 즉시 매입 가격
```

고객별 세계 후속 결과는 즉시 매입 가격과 별도 채널로 처리한다.

```text
즉시 확정
→ 고객별 매입 가격

후속 세계 결과 가능성
→ 특수재료
→ 명성
→ 세계 군사력
→ 영향력
→ 고객별 장비 연대기
```

후속 결과의 `가능성`은 거래 즉시 무조건 지급되는 보상을 의미하지 않는다.

## 고객 명칭 및 유형 정정

### `병사` → `군인`

기존 문서의 고객 유형 `병사`는 최신 사용자 표현에 따라 **`군인`**으로 사용자 노출 명칭을 변경한다.

```text
PLAYER_FACING_CUSTOMER_TERM: 군인
LEGACY_CUSTOMER_TERM: 병사
```

기존 `병사`의 부대 배치·임무·보급·세계 결과 방향은 `군인`에게 승계한다.

### `상인` 고객 유형 추가

`상인`은 일반 판매의 이름 없는 구매자와 구분되는 **방문 고객 유형**으로 추가한다.

- 일반 판매: 고객 식별·관계·세계 후속 활동이 없는 기본 현금화 경로
- 방문 상인: 장비 범주를 요청하고 고객별 매입 배수로 거래하는 이름 있는 또는 유형화된 방문 고객
- 상인도 기본 2영업일 기한, 최대 2개 활성 요청, 범주 요청, 직접 제품 선택 규칙을 사용한다.
- 상인은 고객 전용 장비를 요구하지 않는다.

따라서 현재 방문 고객 유형의 기본 집합은 다음과 같다.

```text
모험가
검투사
수집가
상인
군인
```

이 집합은 콘텐츠 확장이 불가능한 폐쇄 enum으로 하드코딩하지 않는다.

## 즉시 거래 가격 계약

방문 고객 즉시 거래 가격은 다음 구조를 사용한다.

```text
방문 고객 즉시 매입 가격
= 일반 판매 기준 가치 × customer_purchase_multiplier
```

### 일반 판매 기준 가치

일반 판매와 방문 고객 거래는 동일한 장비 기본 가치 계산을 공유한다.

장비 기본 가치에 반영 가능한 요소:

- 장비 세부 종류
- 강화 단계
- 정밀강화·고위 정밀강화 결과
- 진화 여부
- 대표·보조 수식어
- 역사 가치와 장비 연대기
- 제작자 또는 과거 소유 이력 중 경제 가치로 명시된 항목

내구도는 존재하지 않으므로 가격 계산 입력에 포함하지 않는다.

### 고객별 배수

각 고객 유형은 `customer_purchase_multiplier` 데이터를 가진다.

- 고객별로 서로 다른 배수 사용 가능
- 같은 고객 유형 내에서도 중요 고객·관계 단계·콘텐츠 데이터에 따라 변형 가능
- 정확한 적용 배수는 거래 전에 공개
- 거래 확정 뒤 배수를 재추첨하지 않음
- 앱 재실행으로 배수가 바뀌지 않음
- 고객 이름 코드 분기로 가격을 계산하지 않고 데이터로 계산

정확한 배수 수치는 후속 밸런스 결정에서 확정한다.

## 고객별 가치 방향

| 고객 유형 | 즉시 거래 가치 방향 | 거래 이후 가능한 후속 결과 |
|---|---|---|
| 모험가 | 고객별 매입 배수 적용 | 원정 결과에 따라 특수재료를 가져올 가능성 |
| 검투사 | 고객별 매입 배수 적용 | 대회 우승 또는 성과에 따라 명성 추가 가능성 |
| 수집가 | 일반 판매보다 높은 매입 배수 방향 | 전시·감정·역사 가치·장비 연대기 후속 가능 |
| 상인 | 일반 판매보다 높은 매입 배수 방향 | 현금 중심 거래 및 향후 상업 콘텐츠 연결 가능 |
| 군인 | 고객별 매입 배수 적용 | 장비 운용 결과에 따라 세계 군사력·영향력 변화 가능성 |

이 표의 후속 결과는 방향 계약이다. 정확한 확률·수량·상한·발생 조건은 후속 결정에서 확정한다.

## 모험가 — 특수재료 회수 가능성

모험가에게 장비를 판매하면 거래 완료 후 `[세계]`에서 원정 활동으로 연결될 수 있다.

```text
모험가에게 장비 판매
→ 장비 소유권 이전
→ 원정 또는 탐험 활동
→ 활동 결과 판정
→ 특수재료 획득 가능
```

원칙:

- 특수재료는 거래 즉시 확정 지급하지 않는다.
- 실제 후속 원정 결과가 발생했을 때만 획득 가능하다.
- 특수재료 획득 가능성은 거래 전에 방향 수준으로 공개한다.
- 정확한 획득 여부·종류·수량은 결과 판정 전 확정 보상처럼 표시하지 않는다.
- 결과 판정은 활동당 정확히 한 번 수행하고 저장 후 연출한다.
- 앱 재실행으로 특수재료 결과를 재추첨하지 않는다.
- 모험가 전용 장비나 특수재료 반환을 보장하는 장비 플래그를 만들지 않는다.

## 검투사 — 대회 우승과 명성 가능성

검투사에게 장비를 판매하면 거래 완료 후 경기·대회 활동으로 연결될 수 있다.

```text
검투사에게 장비 판매
→ 경기 또는 대회 참가
→ 경기 결과 판정
→ 우승·성과 발생 가능
→ 명성 추가 가능
```

원칙:

- 명성은 장비 판매 즉시 자동 지급하지 않는다.
- 대회 우승 또는 명시된 경기 성과가 발생할 때 추가될 수 있다.
- 거래 화면은 `우승 시 명성 획득 가능` 같은 방향을 공개한다.
- 정확한 우승 결과를 거래 전에 확정적으로 예고하지 않는다.
- 명성 변화와 경기 결과·장비 연대기를 하나의 일관된 결과로 저장한다.
- 우승하지 못해도 판매 거래와 이미 지급된 매입 가격을 취소하지 않는다.

## 수집가 — 높은 매입 가치

수집가는 일반 판매보다 높은 가격으로 장비를 매입하는 방향을 가진다.

```text
일반 판매 기준 가치
× 수집가 매입 배수
= 수집가 거래 가격
```

원칙:

- 수집가의 높은 매입 가치는 거래 전에 확정 금액으로 공개한다.
- 장비 범주만 맞으면 낮은 강화 장비도 거래 후보가 된다.
- 특정 역사 가치·진화·수식어를 숨은 거래 조건으로 요구하지 않는다.
- 역사 가치가 가격 산식에 반영된다면 제품별 가격 차이로 명시한다.
- 거래 후 전시·감정·연대기 후속이 발생할 수 있으나 높은 매입 가격과 중복되지 않는 별도 결과로 관리한다.

## 상인 — 높은 현금 매입 가치

상인은 일반 판매보다 높은 매입 가격을 제공하는 방문 고객 유형이다.

```text
일반 판매 기준 가치
× 상인 매입 배수
= 상인 거래 가격
```

원칙:

- 일반 판매와 달리 요청 범주·2영업일 기한·고객별 배수를 가진다.
- 즉시 현금 가치가 주요 차별점이다.
- 상인이 제품을 되팔거나 시장에 유통하는 상세 세계 시스템은 현재 결정만으로 확정하지 않는다.
- 상인에게 판매한 제품도 기존 장비 ID와 거래 연대기를 유지한다.
- 일반 판매와 방문 상인 거래를 같은 기능으로 합치지 않는다.

## 군인 — 세계 군사력·영향력 가능성

군인에게 장비를 판매하면 부대 배치·임무·군사 활동으로 연결될 수 있다.

```text
군인에게 장비 판매
→ 부대 또는 임무에 장비 투입
→ 세계 결과 판정
→ 세계 군사력 변화 가능
→ 영향력 변화 가능
```

원칙:

- 군사력·영향력은 판매 즉시 무조건 증가하지 않는다.
- 실제 임무·배치·성과 결과에 따라 변화할 수 있다.
- 거래 전에 가능한 후속 방향을 공개하되 정확한 결과를 보장하지 않는다.
- 군사력과 영향력은 서로 다른 세계 상태로 저장할 수 있다.
- 동일 결과를 여러 번 적용하지 않는다.
- 군사력·영향력 결과가 다른 활성 방문 고객 요청의 기한이나 배수를 변경하지 않는다.
- `군인 전용 장비`는 만들지 않는다.

## 확정 보상과 가능성 보상의 표시 분리

거래 화면은 즉시 확정되는 항목과 향후 가능성이 있는 항목을 명확히 구분한다.

### 즉시 확정 영역

- 일반 판매 기준 가치
- 고객별 매입 배수
- 최종 즉시 매입 가격
- 거래 즉시 지급되는 확정 자원
- 관계·약속의 즉시 확정 변화가 있다면 해당 변화

### 후속 가능성 영역

- 모험가의 특수재료 회수 가능성
- 검투사의 우승·명성 가능성
- 수집가의 전시·감정 후속
- 상인의 향후 상업 콘텐츠 가능성
- 군인의 군사력·영향력 변화 가능성

다음 표현은 금지한다.

- 확률 결과를 확정 보상처럼 합산 표시
- 우승하지 않았는데 명성을 선지급
- 원정 전 특수재료를 선지급
- 임무 전 군사력·영향력을 선적용
- 후속 결과 실패 시 이미 확정된 판매 가격 회수
- 고객별 배수를 거래 확정 후 숨은 판정으로 변경

## 제품 선택 화면 영향

추가 결정 29의 직접 선택 구조를 유지한다.

제품별 비교에는 다음을 추가한다.

- 일반 판매 기준 가치
- 해당 고객의 매입 배수
- 방문 고객 최종 매입 가격
- 일반 판매 대비 증감액 또는 증감률
- 확정 즉시 보상
- 후속 가능성의 종류

```text
무기 요청 — 모험가

장검 A
일반 판매 가치: 1,000
모험가 배수: M_A
즉시 매입 가격: 1,000 × M_A
후속 가능성: 원정 후 특수재료

도끼 B
일반 판매 가치: 1,500
모험가 배수: M_A
즉시 매입 가격: 1,500 × M_A
후속 가능성: 원정 후 특수재료
```

정확한 수치가 확정되기 전에는 플레이어용 UI 예시에서 임의 배수를 확정값처럼 사용하지 않는다.

## 저장·원자성 계약

방문 고객 거래 확정 시 다음을 하나의 원자적 결과로 저장한다.

- 선택 제품 식별자
- 일반 판매 기준 가치
- 적용 고객 유형 또는 고객 식별자
- 적용 매입 배수와 데이터 버전
- 최종 즉시 매입 가격
- 지급 자원
- 제품의 보관함 제외
- 고객에게 소유권 이전
- 방문 고객 요청 완료
- 관계·약속 상태
- 생성된 후속 세계 활동 식별자
- 가능한 후속 보상 채널
- 장비 연대기 거래 기록

후속 세계 활동 결과는 해당 활동이 실제로 판정될 때 별도 원자적 결과로 저장한다.

```text
거래 확정
→ 매입 가격·소유권·후속 활동 생성 저장

이후 세계 활동
→ 결과 정확히 1회 판정
→ 특수재료·명성·군사력·영향력 등 결과 저장
→ 연출
```

## 기존 결정과의 관계

### 유지

- 일반 판매 기준 가치와 방문 고객 보너스를 분리하는 추가 결정 29 이후의 가격 방향
- 방문 고객은 장비 범주만 요청
- 범주 내 제품은 플레이어가 직접 선택
- 고객 전용 장비 없음
- 내구도 없음
- 기본 2영업일 요청 기한
- 동시 활성 요청 최대 2개
- 영업일 시작 시 방문 판정
- 일반 요청 40% + 미발생 보정
- 중요 고객 데이터 기반 우선순위

### 정정·확장

- 모든 방문 고객이 동일 배수를 사용한다는 해석: 금지
- 고객별 매입 배수: 필수
- `병사` 사용자 노출 명칭: `군인`으로 변경
- 방문 고객 유형: `상인` 추가
- 후속 결과: 고객별 특수재료·명성·군사력·영향력 채널로 분리

## 현재 기획 상태 영향

해결된 항목:

- 방문 고객 가격의 기본 산식
- 고객별 매입 배수 구조
- 모험가·검투사·수집가·상인·군인의 가치 방향
- 즉시 확정 보상과 후속 가능성의 분리
- `병사` → `군인` 명칭 정정
- `상인` 방문 고객 유형 추가

미정 항목:

- 같은 고객 유형 내 관계 단계별 배수 변화
- 모험가 특수재료 결과 확률·종류·수량
- 검투사 우승·명성 결과 확률·수치
