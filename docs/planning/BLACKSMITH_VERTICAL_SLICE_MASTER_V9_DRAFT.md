## 1. 문서 권한

이 문서는 Blacksmith의 Vertical Slice 기획을 Base v9.3 기준으로 통합하기 위한 사용자 검토용 초안이다.

- PR #61의 v6 Draft와 Addendum 01~30은 요구사항 이력과 비교 근거다.
- 이 문서에 통합되지 않은 과거 내용은 자동으로 현행 권한을 갖지 않는다.
- 사용자 `기획 완료` 전에는 제품 구현을 시작하지 않는다.
- 사용자 `검수 완료` 전에는 Codex Goal과 구현 Issue를 승인하지 않는다.

## 2. 제품 정의

### 한 문장

> 망치질로 장비를 만들고, 더 강하게 만들수록 커지는 위험 앞에서 멈출지 도전할지 선택하며, 완성한 작품이 사람과 세계에 남기는 흔적을 확인하는 Android 세로형 모바일 대장간 게임.

### 핵심 판매 문장

> **내가 만든 장비가 누군가의 전설이 된다.**

### 핵심 경험

1. 손으로 만든다는 짧고 선명한 제작 감각
2. 위험을 알고 선택하는 공정한 강화
3. 내가 멈춘 지점이 작품의 완성으로 인정되는 감정
4. 등급·수식어·진화로 구분되는 장비 정체성
5. 판매 후에도 같은 장비가 세계와 관계에 남는 경험

## 3. 플랫폼과 제품 경계

- Primary platform: Android 모바일
- Orientation: 세로형
- Engine: Godot 4.7.1 / GDScript
- 핵심 플레이: 오프라인 가능
- 필수 로그인·계정·서버 판정: 없음
- Vertical Slice 설치 산출물: 내부 테스트용 Android 패키지
- PC, iOS, 웹, 태블릿 전용 레이아웃: Vertical Slice 합격 범위 제외

## 4. 게임의 시간 지평

### 4.1 일상 작품 루프

짧은 모바일 플레이의 반복 단위다.

```text
재료 선택
→ 단조·피버
→ 장비 완성
→ +0~+5 강화
→ 지금 완성·판매 또는 +10 도전
→ 보관·일반 판매·방문 고객 거래
→ 다음 작품 재투자
```

- +5는 첫 안정적 완성·판매 판단 지점이다.
- +10은 첫 정밀강화 이정표와 장비 계보의 시작이다.
- 멈춤은 실패가 아니며 자금·관계·보관 전략에 따라 유효하다.

### 4.2 장기 명작 루프

여러 영업일에 걸쳐 한 작품을 성장시키는 장기 목표다.

```text
일상 작품 중 하나를 보존
→ +10 단위 정밀강화 반복
→ 계보·보조 수식어 형성
→ +49 도달
→ 일반 위험 강화 또는 특수재료 고위 정밀강화 선택
→ +50 진화
→ 판매·세계 사건·연대기
→ +50 이상 명작 비교의 후보
```

+50은 Vertical Slice의 세일즈 포인트이지만 신규 캠페인 첫날 도달 속도를 의미하지 않는다.

## 5. 단조

### 역할

단조는 제작 과정의 손맛과 장비의 최초 정체성을 만든다.

### 기본 흐름

- 재료·제작 종류 선택
- 망치 타격
- 열 또는 진행 상태 확인
- 피버 진입
- 완성 결과 확인
- 제작 등급과 초기 작품 정보 확정

### 품질 원칙

- 빠른 연속 입력은 불이익보다 피버·속도감으로 보상한다.
- 첫 의미 있는 제작 보상은 1~2분 안에 제공한다.
- 제작 실패가 긴 재시작 반복을 만들지 않는다.
- 단조의 제작 등급은 강화 단계와 분리된 영구 작품 정보다.

## 6. 장비 정체성 모델

### 6.1 기계 판독 축

| 필드 | 의미 | 상태 |
|---|---|---|
| 장비 ID | 장비 생애를 연결하는 불변 식별자 | 확정 방향 |
| 장비 이름 | 플레이어가 기억하는 작품명 | 확정 방향 |
| 장비 범주 | 무기·방어구 등 방문 요청 자격 | 확정 방향 |
| 세부 종류 | 장검·도끼·방패 등 실제 형태 | 확정 방향 |
| 제작 등급 | 단조 완성도와 기본 가치 | 확정 필요 |
| 강화 단계 | +0~+100 성장·위험 축 | 확정 방향 |
| 계보 수식어 | 장비 성장 방향의 대표 정체성 | 확정 필요 |
| 보조 수식어 | 세부 성능·사용 맥락 | 확정 필요 |
| 진화 형태 | +50 고위 정밀강화 결과 | 확정 방향 |
| 제작자·소유자 | 현재·과거 소유 관계 | 확정 방향 |
| 연대기 | 제작·강화·판매·사건·파괴 기록 | 확정 방향 |

### 6.2 수식어 슬롯 추천안

- 제작 등급: 1개
- 계보 수식어: 1개
- 보조 수식어: 최대 2개
- +50 대표 특수 수식어: 계보 수식어의 승격 형태

### 6.3 정밀강화 이정표 추천안

| 이정표 | 추천 역할 |
|---:|---|
| +10 | 계보 수식어 최초 획득 |
| +20 | 보조 수식어 1개 획득 |
| +30 | 계보 수식어 강화 또는 방향 선택 |
| +40 | 보조 수식어 2개째 획득 |
| +50 | 진화 + 대표 특수 수식어 승격 |
| +60 이상 | 신규 슬롯보다 기존 정체성 심화 중심 |

정확한 등급명·수식어 풀·수치·승격 규칙은 사용자 승인 대기다.

## 7. 강화

### 7.1 일반 강화

- 10단위 이정표 사이의 단계 상승 시도다.
- 결과 확률은 0.01% 단위까지 공개하고 합계는 100.00%여야 한다.
- 실행 전 현재 단계, 목표 단계, 총비용, 성공률, 최대 하락, 영구 파괴, 보호 효과를 표시한다.
- 판정 결과 예시는 성공, 대성공, 유지, 하락, 파괴이며 정확한 결과 집합은 최신 강화 정본과 정합화한다.

### 7.2 일반 정밀강화

`+9→+10`, `+19→+20`처럼 10단위로 진입하는 시도 자체다.

- 성공 시 단계 상승과 정밀 결과를 동시에 적용한다.
- 실패 시 해당 구간의 일반 강화 위험을 적용한다.
- 정밀강화라는 이유로 파괴를 면제하거나 성공을 보장하지 않는다.

### 7.3 +49→+50 고위 정밀강화

특수재료를 사용하면 확정 성공하는 진화 선택이다.

```text
+49 장비
+ 기존 계보·보조 수식어
+ 특수재료
+ 고위 정밀강화 비용
→ 진화 후보 2~3개 공개
→ 후보 선택
→ +50 확정
→ 외형·이름·대표 특수 수식어 승격
```

긴장은 실패 확률보다 다음에서 발생한다.

- 희귀 재료와 높은 비용을 지금 사용할지
- 어떤 계보를 대표 형태로 승격할지
- 장비를 보존할지 고객에게 판매할지

특수재료를 사용하지 않으면 +49→+50은 일반 정밀강화 위험을 사용한다.

### 7.4 보호·완충

- 보호는 성공률을 숨겨 올리지 않는다.
- 보호 사용 전후 결과 차이를 나란히 공개한다.
- 보호·완충의 현재 main 정본과 PR #61 표현을 별도 정합화해야 한다.
- 완전 보호와 +60 이상 경제는 Vertical Slice 직접 구현 범위가 아니다.

## 8. 강화 화면

### 고정 작업대

```text
상단
- 장비 이름·등급·단계·수식어

중앙
- 장비 외형
- 망치·강화 결과 연출

하단 고정
- 성공률 또는 확정 성공
- 총비용·재료
- 최대 하락·파괴
- 보호 상태
- 강화 버튼

상황별 하단 패널
- 전체 확률표
- 보호 비교
- 정밀강화 설명
- 진화 후보
- 비가역 최종 확인
```

### 입력

- 저위험 강화: 즉시 실행
- 일반 정밀강화: 정보 확인 후 1회 확인
- 비보호 파괴 가능 강화: 길게 누르기
- 고위 정밀강화: 후보 선택 후 길게 누르기
- 접근성 대체: 동일 정보의 2단계 확인 버튼

## 9. 보관함과 판매

### 보관함

- 작업 중 제품과 완제품을 지속 보유한다.
- 세션마다 자동 초기화하지 않는다.
- 고객 수에 맞춰 완제품을 자동 생성하지 않는다.
- 테스트 픽스처는 일반 신규 캠페인 규칙과 명확히 구분한다.

### 일반 판매

- 언제든 사용할 수 있는 기본 현금화 경로다.
- 이름 있는 고객·관계·세계 후속 활동을 만들지 않는다.
- 방문 고객보다 빠르고 예측 가능하지만 보상 잠재력은 낮다.

## 10. 방문 고객

### 10.1 기본 구조

- 방문 고객은 별도 요청 이벤트다.
- 동시에 최대 2개 요청이 활성화된다.
- 일반 요청은 영업일 시작에 최대 1개만 발생한다.
- 기본 기한은 요청 당일을 포함한 2영업일이다.
- 앱 종료·실시간 경과는 기한을 줄이지 않는다.

### 10.2 요청 자격

방문 고객은 장비 범주를 요청한다.

```text
요청 범주 일치
+ 제작 완료
+ 판매 가능
+ 플레이어 보관함 소유
→ 거래 후보
```

낮은 강화, 수식어 부재, 낮은 등급은 후보 자격을 막지 않는다.

### 10.3 공개 적합 신호

거래 자격과 별도로 고객이 중요하게 보는 가치 방향을 공개한다.

예시:

- 검투사: 성능, 명성, 공격 계보
- 모험가: 생존, 환경 대응, 회수 이력
- 수집가: 제작 등급, 희소성, 역사 가치
- 상인: 시장성, 회전 가치, 거래 이력
- 군인: 표준성, 신뢰성, 공적 기록

적합 신호는 판매를 막지 않으며 다음에만 영향을 준다.

- 공개 거래 가격
- 관계 변화
- 후속 세계 사건 방향
- 장비 연대기의 결과 문구

### 10.4 제품 직접 선택

- 기본 선택 없음
- 최고가·최고 강화 자동 선택 없음
- 플레이어가 제품을 눌러 예상 거래 결과를 비교
- 최종 확인 전에는 예약·소유권 이전 없음
- 판매 확정 시 보상·소유권·연대기·요청 완료를 원자적으로 저장

## 11. 주요 고객 콘텐츠 계층

### Vertical Slice 대표 고객: 검투사

- 요청 범주: 무기
- 가치 방향: 성능·명성·대표 수식어
- 후속 선택: 배팅 또는 경기 전 지원 중 1개
- 세계 결과: 짧은 자동 경기의 결정적 장면
- 결과: 승패·관계·명성·장비 연대기

### 제작 파이프라인 증명: 상인 또는 수집가

대표 15~25분 세션과 분리된 결정론적 시나리오에서 같은 요청·제품 선택·판매·저장 구조를 재사용한다.

### 본제작 후순위

- 모험가 원정
- 군인 임무
- 수집가 장기 유물화
- 상인 장기 시장 콘텐츠
- 고객별 장기 약속·재방문

## 12. 장비 운명 상태

### 사용하지 않음

- 내구도 수치
- 내구도 퍼센트
- 반복 수리 관리
- 고객 요청의 내구 조건

### 제한적으로 사용

- 정상
- 전투 흔적
- 분실
- 회수
- 영구 파괴

`전투 흔적`은 반복 수리 비용을 만드는 운영 시스템이 아니라 외형·가치·연대기에 남는 서사 상태다.

## 13. Vertical Slice 대표 플레이

### 목표 시간: 15~25분

| 구간 | 목표 시간 | 핵심 증명 |
|---|---:|---|
| 단조 마무리·첫 강화 | 0~2분 | 손맛과 즉시 피드백 |
| 새 장비 +0→+5 | 2~6분 | 위험 정보와 완성 판단 |
| 준비 대표작 +49→+50 | 6~10분 | 진화 선택과 장기 목표 |
| 검투사 요청·제품 비교 | 10~14분 | 작품 보존·판매 고민 |
| 판매·지원/배팅·영업 종료 | 14~17분 | 비가역 선택과 원자적 저장 |
| 경기 결과 | 17~22분 | 장비가 세계에 미친 원인 |
| 연대기·다음 목표 | 22~25분 | 애착·회상·재플레이 동기 |

### 필수 분기

플레이어는 다음 중 하나를 고를 수 있다.

- 새 +5 장비를 판매하고 +50 대표작을 보존
- +50 대표작을 판매해 높은 세계 영향과 서사를 선택
- 다른 보관함 장비를 판매하고 두 장비를 모두 보존

어느 선택도 정답으로 표시하지 않는다. 테스트는 선택 이유와 결과 회상을 관찰한다.

## 14. 불씨 정령

- 비성장형 상징 동반자
- 첫 강화·정밀강화·+50 진화·주요 결과의 짧은 안내
- 강화 확률·정답·결과 예측을 제공하지 않음
- 핵심 UI를 가리지 않음
- 성장·재화·능력 보정 없음
- 색상·소리·모션에만 정보를 의존하지 않음

정확한 이름·말투·외형은 아트·카피 결정 대기다.

## 15. 정보 구조

### 하단 3개 영역

- `[대장간]`: 단조, 강화, 보관함, 일반 판매
- `[방문 고객]`: 활성 요청, 제품 비교, 거래, 관계
- `[세계]`: 판매 후 활동, 결과, 장비 연대기

### 알림 우선순위

1. 미확인 결과·저장 복구
2. 기한 있는 요청·행동
3. 일반 세계 소식

원시 미확인 숫자를 압박형 배지로 누적하지 않는다.

## 16. 저장·복귀

- 비가역 행동별 즉시 원자적 저장
- 명시적 영업 종료 시 세계 체크포인트
- 앱 종료만으로 세계 시간 진행 금지
- 한 강화 시도당 판정 1회
- 저장된 결과를 연출하며 연출이 판정을 만들지 않음
- 단일 활성 캠페인 + 시스템 복구 스냅샷
- 복구 스냅샷은 손상·마이그레이션용이며 나쁜 결과 되돌리기에 사용하지 않음
- 설정 저장은 진행 저장과 분리

## 17. 접근성·성능

### 접근성

- 색상만으로 결과 구분 금지
- 무음·무진동·모션 감소에서도 전체 진행 가능
- 텍스트 확대 시 성공률·비용·파괴·버튼 유지
- 길게 누르기 대체 입력
- 짧은 실시간 반응 제한 없음
- 세로형 한 손 핵심 조작

### 성능

- 일반 UI·반복 강화: 60fps 목표
- 고위 정밀강화·세계 결과: 60fps 목표, 일시적 안정 30fps 허용
- 성능 저하 시 장식 효과부터 축소
- 핵심 숫자·문구·장비 외형·결과는 제거 금지
- 프레임 저하가 입력·판정·저장 무결성에 영향 금지
