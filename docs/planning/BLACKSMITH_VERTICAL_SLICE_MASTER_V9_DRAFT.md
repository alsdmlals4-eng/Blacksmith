## 1. 문서 권한

이 문서는 Blacksmith Vertical Slice의 현행 통합 기획 초안이다.

권한 순서:

```text
사용자 최신 결정
→ 본 마스터 v9
→ 사용자 결정 기록
→ P1 정합성·적대적 검토
→ 벤치마킹 설계
→ 기존 main 기획 정본
→ PR #61 v6 Draft·Addendum 요구사항 이력
```

- 이 문서에 통합되지 않은 과거 내용은 현행 권한을 갖지 않는다.
- 사용자 `기획 완료` 전에는 제품 구현과 Google Sheet 동기화를 시작하지 않는다.
- 사용자 `검수 완료` 전에는 Codex Goal과 구현 Issue를 승인하지 않는다.
- 새 시스템·핵심 규칙·콘텐츠 구조·주요 UX 흐름은 벤치마킹을 먼저 수행한다.

## 2. 제품 정의

> **망치질로 장비를 만들고, 커지는 위험 앞에서 멈출지 도전할지 선택하며, 완성한 작품이 사람과 세계에 남기는 흔적을 확인하는 Android 세로형 모바일 대장간 게임.**

핵심 판매 문장:

> **내가 만든 장비가 누군가의 전설이 된다.**

핵심 경험:

1. 짧고 직접적인 단조 손맛
2. 위험·비용·보호 효과를 알고 선택하는 공정한 강화
3. 멈춘 지점도 작품의 완성으로 인정되는 감정
4. 제작 등급·수식어·진화로 구분되는 장비 정체성
5. 판매 후에도 같은 장비가 세계와 관계에 남는 경험

감정 곡선:

```text
만드는 손맛
→ 더 올리고 싶은 욕심
→ 잃을 수 있다는 긴장
→ 멈춤 또는 도전의 책임감
→ 작품 완성의 자부심
→ 누구에게 넘길지 고민
→ 세계에서 쓰이는 장면 확인
→ 다음 작품을 만들 동기
```

## 3. 플랫폼 경계

- Primary: Android 스마트폰
- 화면 방향: 세로형
- Engine: Godot 4.7.1 / GDScript
- 핵심 플레이: 오프라인 완료 가능
- 필수 로그인·계정·서버 판정: 없음
- 저장: 단일 활성 캠페인 자동 저장
- Vertical Slice 산출물: 내부 테스트용 설치 패키지
- PC·iOS·웹·태블릿 전용 대응: 합격 범위 제외

매 작업마다 대규모 조사를 반복하지 않으며 최근의 관련 조사 결과를 재사용할 수 있다.

## 5. 두 시간 지평

### 5.1 일상 작품 루프

```text
단조
→ 장비 완성
→ +0~+5 강화
→ 지금 완성·판매 또는 +10 도전
→ 보관·일반 판매·방문 고객 거래
→ 다음 작품 재투자
```

- +5는 첫 안정적 완성·평균 흑자 판단 지점이다.
- +10은 첫 계보 수식어를 획득하는 장비 정체성 이정표다.
- 낮은 단계에서 멈추는 선택도 실패가 아니다.

### 5.2 장기 명작 루프

```text
일상 작품 중 하나를 보존
→ +10 단위 이정표 성장
→ 계보·보조 수식어 형성
→ +49 도달
→ 일반 위험 정밀강화 또는 특수재료 고위 정밀강화
→ +50 진화
→ 판매·세계 사건·연대기
→ 명작 전당 후보
```

+50은 장비 정체성이 한 차례 완성되는 장기 목표다.

## 6. 단조와 제작 등급

단조는 제작 손맛과 최초 작품 정체성을 만든다.

```text
장비 종류·재료 선택
→ 망치 타격
→ 열·진행 확인
→ 피버
→ 완성
→ 제작 등급과 최초 연대기 확정
```

확정 제작 등급:

```text
보통
→ 양질
→ 우수
→ 명품
→ 걸작
```

원칙:

- 제작 등급은 강화 단계와 분리된 영구 정보다.
- 낮은 등급도 정상적으로 강화·판매·보관할 수 있다.
- `전설`은 제작 등급명으로 사용하지 않는다.
- 구형 `미숙한·평범한·정교한·명품·완벽한` 명칭을 대체한다.
- 정확한 등급별 배율과 발생 분포는 플레이테스트 조정 대상이다.

## 7. 장비 정체성 모델

### 7.1 필수 데이터 축

- 장비 ID
- 장비 이름
- 장비 범주와 세부 종류
- 제작 등급
- 강화 단계
- 계보 수식어 1개
- 보조 수식어 최대 2개
- +50 진화 형태
- 제작자·현재 소유자·과거 소유자
- 운명 상태
- 장비 연대기

### 7.2 폐기되는 구형 축

```text
PRECISION_GRADE_AXIS: REMOVED
LEGACY_AFFIX_SLOT_A_B: SUPERSEDED
```

구형 `정밀 등급 1개 + 수식어 슬롯 A·B 2개`를 동시에 유지하지 않는다.

### 7.3 계보 수식어 6종

계보 ID는 공통으로 사용하고 장비 범주에 따라 표시명을 다르게 쓸 수 있다.

| 계보 ID | 무기 표시 예 | 방어구 표시 예 | 정체성 |
|---|---|---|---|
| 정밀 | 예리 | 정합 | 정확성·약점·마감 |
| 파쇄 | 파쇄 | 충격 저항 | 중량·충격·장갑 대응 |
| 수호 | 수호 | 수호 | 보호·안정 |
| 기민 | 기민 | 경량 | 빠른 대응·조작성 |
| 잔화 | 잔화 | 열막 | 화로·열·지속 압박 |
| 명예 | 명예 | 의식 | 기록·상징·소유자 관계 |

### 7.4 보조 수식어 10종

| 수식어 | 역할 |
|---|---|
| 균형 잡힌 | 무게 중심·조작성 |
| 경량화된 | 휴대성·빠른 대응 |
| 중량화된 | 충격·존재감 |
| 견고한 | 충돌 뒤 형태 유지 |
| 충격을 흘리는 | 방어·완화 방향 |
| 손에 맞춘 | 특정 소유자·사용자 적합 |
| 울림 있는 | 공명·상징·관중 반응 |
| 흔적을 새긴 | 사건·소유·연대기 상호작용 |
| 의식 각인의 | 전시·명예·의식 가치 |
| 현장형 | 실용·일반 고객·군용 가치 |

배타·검증:

- `경량화된`과 `중량화된` 동시 적용 금지
- 계보와 같은 의미의 보조 수식어 동시 후보 금지
- 장비 범주에 적용 불가능한 수식어 후보 제외
- 수식어 이름만으로 숨은 종합 등급을 만들지 않음

## 8. 10단위 장비 정체성 이정표

10단위 진입 성공 시 정체성 결과를 별도 실패 없이 확정한다.

| 단계 | 성공 후 결과 |
|---:|---|
| +10 | 공개 후보 2~3개 중 계보 수식어 1개 선택 |
| +20 | 공개 후보 2~3개 중 보조 수식어 1개 선택 |
| +30 | 현재 계보 강화 또는 공개 파생 방향 선택 |
| +40 | 공개 후보 2~3개 중 두 번째 보조 수식어 선택 |
| +50 | 진화 후보 2~3개 중 하나 선택, 계보를 대표 특수 형태로 승격 |
| +60 이상 | 신규 슬롯 없이 기존 계보·보조·진화 정체성 심화 |

금지:

- 10단위 진입 성공 후 별도 정밀강화 실패 판정
- 성공했지만 빈 결과로 이정표 종료
- 숨은 확률로 후보 소멸
- 같은 이정표 무한 재시도

재료·촉매·특수재료는 후보 풀을 좁히거나 특정 후보를 공개한다. 일반 강화 확률을 실제로 바꾸는 경우에는 최종 확률표에 반영한다.

## 9. 강화 계약

### 9.1 일반 강화

- 10단위 사이의 단계 상승 시도다.
- 최종 결과 확률을 0.01% 단위까지 공개한다.
- 표시 결과 합계는 100.00%다.
- 실행 전 단계·비용·성공률·최대 하락·파괴·보호 효과를 표시한다.
- 보호·완충 선택이 바뀌면 결과표를 즉시 갱신한다.

### 9.2 일반 정밀강화

`+9→+10`, `+19→+20`처럼 10단위로 진입하는 강화 시도 자체다.

- 실패는 해당 구간의 일반 강화 위험을 사용한다.
- 성공하면 단계 상승과 이정표 선택을 하나의 결과로 확정한다.
- 성공 후 추가 실패 판정을 실행하지 않는다.

### 9.3 +49→+50 고위 정밀강화

```text
+49 장비
+ 기존 계보·보조 수식어
+ 특수재료와 비용
→ 진화 후보 2~3개 공개
→ 플레이어 선택
→ +50 확정
→ 외형·이름·계보 수식어 승격
```

- 특수재료 경로는 +50 성공을 보장한다.
- 특수재료를 사용하지 않는 경로는 일반 정밀강화 위험을 따른다.
- 긴장은 재료·비용·진화 방향·판매 여부에서 발생한다.

### 9.4 보호·완충

- 보호는 자연 파괴 확률 자체를 낮추지 않고 결과 효과를 바꾼다.
- 일반 보호: 하락 결과 유지 변환, 파괴는 보호 파괴·단계 하락
- 완전 보호: +60~+100 미래 구간에서 자연 실패 결과를 유지로 변환
- 완전 보호·+60~+100 경제는 Vertical Slice 직접 범위가 아니다.

### 9.5 판정·저장·연출

```text
최종 입력
→ 결과 정확히 1회 판정
→ 비용·재료·장비·연대기 원자적 저장
→ 저장된 결과 연출
→ 작업대 갱신
```

연출은 결과를 생성하거나 재추첨하지 않는다.

## 10. 가치·경제 계약

기존 구조 유지:

- +0~+4 평균 투자 회수 전
- +5 최초 평균 흑자
- +5 이후 대표 단계의 예상 순이익 증가
- +60~+100 완전 보호·고강화 경제는 본제작 미래 계약

최종 거래 가치 계산 순서:

```text
1. 강화 단계 기준가
2. 제작 등급 보정
3. 계보·보조 수식어의 일반 시장 보정
4. +50 진화 형태 보정
5. 장비 운명·연대기 보정
6. 고객 공개 적합 보정
7. 거래 채널 배율·고객 예산 상한
```

가드레일:

- 같은 요소를 두 단계에서 같은 이유로 중복 계산하지 않는다.
- 일반 시장 보정은 보편적 제작·희소 가치를 책임진다.
- 고객 적합 보정은 해당 고객의 공개 가치관만 책임진다.
- `전투 흔적`은 보편 감액 상태가 아니다.
- `DAMAGED`와 반복 수리 가격을 사용하지 않는다.
- 파괴된 장비는 거래 가치가 없으며 기록만 남는다.

## 11. 모바일 작업대

고정 작업대:

- 상단: 장비 이름·제작 등급·강화 단계·계보
- 중앙: 장비 외형·망치 입력·결과 연출
- 하단: 성공률·비용·최대 하락·파괴·보호·강화 버튼
- 상황별 패널: 전체 확률, 보호 비교, 이정표 후보, 진화 후보, 비가역 확인

입력:

- 저위험 강화: 즉시 실행
- 일반 정밀강화: 정보 확인 후 실행
- 파괴 가능 강화: 길게 누르기
- 고위 정밀강화: 후보 선택 후 길게 누르기
- 접근성 대체: 동일 정보의 2단계 확인 버튼
- 주요 터치 대상: 최소 48dp

## 12. 보관함·판매 채널

### 보관함

- 작업 중 제품과 완제품을 캠페인 동안 지속 보유한다.
- 영업일마다 자동 초기화하지 않는다.
- 고객 수에 맞춰 제품을 자동 생성하지 않는다.
- Vertical Slice 준비 장비는 이전 제작 이력을 가진 테스트 픽스처다.

### 일반 판매

- 언제든 가능한 기본 현금화 경로
- 가격 변동이 작고 즉시 처리
- 관계·세계 사건 없음
- 재기 경제의 안전망

### 방문 상인

- 제한적으로 발생하는 2영업일 범주 요청
- 시장성·회전 가치·거래 이력을 공개 적합 신호로 사용
- 일반 판매보다 높은 가격 가능성이 있지만 항상 최고가를 보장하지 않음
- 장기 관계·전용 세계 사건 없음

### 이름 있는 고객

- 작품의 다음 삶, 관계, 세계 사건, 연대기를 제공
- 단순 현금화보다 장기 결과를 선택하는 채널

## 13. 방문 고객 계약

기본 구조:

- 동시에 최대 2개 요청 활성
- 영업일 시작에 신규 요청 최대 1개
- 기본 기한 2영업일
- 앱 종료와 실제 시간 경과로 기한 감소 금지
- 대표 고객은 확정 트리거 사용

거래 자격:

```text
요청 범주 일치
+ 제작 완료
+ 판매 가능
+ 플레이어 보유
→ 거래 후보
```

공개 적합 신호:

```text
제작 등급·계보·보조 수식어·진화·연대기
↔ 고객 가치관
```

적합 신호 영향:

- 공개 매입 가격
- 관계 변화
- 후속 세계 사건 방향
- 고객 반응
- 장비 연대기 문구

필수 원칙:

- 낮은 적합도여도 판매 가능
- 숨은 실패 조건 금지
- 평가 이유 공개
- 자동 추천·자동 선택 금지
- 최종 확인 전 예약·소유권 이전 없음

## 14. 대표 콘텐츠

### 14.1 불씨 정령 모닥

- 비성장형 상징 동반자
- 검은 숯 껍질, 주황빛 핵, 짧은 불꽃
- 첫 강화·이정표·+50 진화·주요 결과의 짧은 안내
- 한 번에 한 문장, 아기 말투·밈·과장 금지
- 확률·정답·결과 예측 금지
- 성장·재화·능력 보정 없음
- 핵심 UI 가림 금지

대표 대사:

- 첫 망치: `불이 올랐어. 지금 쳐.`
- 첫 강화: `비용과 위험을 먼저 봐.`
- +5: `여기서 완성해도 좋아.`
- +50: `어떤 작품으로 남길래?`
- 영구 파괴: `이 작품의 기록은 남길게.`

### 14.2 대표 검투사 카시아 벨란

- 역할: 상위 투기장 진출을 노리는 중견 검투사
- 요청 범주: 무기
- 가치 방향: 성능·명성·계보·경기 이력
- 핵심 욕망: 자신의 이름과 함께 기억될 무기
- 대표 후속 선택: 경기 전 조율 지원
- 결과: 결정적 경기 장면, 장비 기여 원인, 승패, 관계, 명성, 연대기

경기 표현:

```text
경기 시작 요약
→ 결정적 장면 1개
→ 장비 기여 원인 1~2개
→ 승패
→ 관계·명성·연대기
```

패배 시에도 장비 기여와 패배 원인을 분리한다.

배팅:

```text
OPTIONAL_VARIATION / NOT_REQUIRED_FOR_VERTICAL_SLICE_COMPLETION
```

- 내부 골드만 사용
- 실제 결제·현금성 재화와 연결 금지
- 대표 흐름과 합격 기준에서는 제외

### 14.3 수집가 에르사 로엔

- 역할: 이동 전시회를 운영하는 수집가 겸 감정인
- 실제 요청: 방어구 범주
- 가치 방향: 제작 등급·희소성·계보·연대기
- 대표 픽스처: 별철 의식 방패

```text
제품 직접 선택·판매
→ 짧은 감정 장면
→ 제작 기술 또는 사건 기록 중심 전시 선택
→ 전시 결과
→ 가치·관계·연대기 갱신
```

`별철 의식 방패`는 검증용 준비 작품이며 특정 아이템 이름을 요구하는 고객 계약이 아니다. 다른 방어구도 거래 후보가 될 수 있다.

## 15. +50 대표 진화 후보

대표 무기 픽스처 임시명: `오래 벼린 검`

| 후보 | 방향 | 주요 가치 |
|---|---|---|
| 성벽파쇄 | 파쇄·중량·결정적 충격 | 경기 직접 기여 |
| 용광의 심장 | 잔화·연속 압박·화로 정체성 | 경기·제작자 정체성 균형 |
| 투기장의 맹세 | 명예·안정·기록 | 관계·명성·수집 가치 |

정답 방지:

- 세 후보의 총가치 예산을 유사하게 유지
- 전투·관계·시장·연대기 분포만 다르게 구성
- 어느 후보도 가격·승률·관계 모든 축에서 우월하지 않음
- 카시아는 세 후보 모두 구매 가능
- 정확한 효과 수치는 후속 밸런스 대상

## 16. 장비 운명·파괴

사용하지 않음:

- 내구도 수치·퍼센트
- 반복 수리 관리
- 고객 요청의 내구 조건
- `DAMAGED` 상태

허용 상태:

```text
정상
전투 흔적
분실
회수
영구 파괴
```

`전투 흔적`은 사용 불가나 반복 수리 비용을 만들지 않고 외형·가치·설명·연대기에 영향을 주는 서사 상태다.

무보호 파괴:

```text
장비 객체 영구 소멸
→ 사용·판매·재강화·복구 불가
→ 고객·관계 데이터 유지
→ 장비 연대기 종료 기록 유지
```

## 17. 대표 Vertical Slice

목표 시간: 15~25분

| 구간 | 시간 | 핵심 증명 |
|---|---:|---|
| 단조 마무리·첫 강화 | 0~2분 | 손맛과 즉시 피드백 |
| 새 장비 +0→+5 | 2~6분 | 위험 정보와 완성 판단 |
| 준비 대표작 +49→+50 | 6~10분 | 진화 선택과 장기 목표 |
| 카시아 요청·제품 비교 | 10~14분 | 작품 보존·판매 고민 |
| 판매·경기 전 조율·영업 종료 | 14~17분 | 비가역 선택과 저장 |
| 경기 결과 | 17~22분 | 장비의 세계 기여 원인 |
| 연대기·다음 목표 | 22~25분 | 애착·회상·재플레이 동기 |

필수 판매 선택:

- 새 +5 장비를 판매하고 +50 대표작 보존
- +50 대표작을 판매해 높은 세계 영향 선택
- 다른 보관함 장비를 판매하고 두 작품 보존

어느 선택도 정답으로 표시하지 않는다.

## 18. 첫 5분 UX

```text
0~30초: 망치 입력과 즉시 반응
30~60초: 제작 등급 확인과 강화 진입
1~3분: 단계·성공률·비용·위험 순서 학습
3~5분: +5 완성 또는 +10 도전 비교
```

첫 강화 정보 순서:

1. 현재·목표 단계
2. 성공률
3. 비용
4. 최대 하락·파괴 여부
5. 보호 효과
6. 실행 버튼

+5 판단 버튼:

- `[이 작품을 완성]`
- `[+10까지 도전]`
- `[자세히 보기]`

금지:

- 연속 모달
- 긴 세계관 설명
- 정답 버튼 강조
- 첫 5분 안의 고객·세계·서버 설명
- 모닥 대사로 확률·비용 대체

첫 5분은 Vertical Slice UX 목표다. 출시 경제의 +5 도달 시간이 반드시 정확히 5분이어야 한다는 의미는 아니다. 정식 첫 세션의 첫 강화는 60초 이내를 목표로 한다.

## 19. 정보 위계

### 장비 카드

```text
장비 이름
```

```text
→ 예상 관계·후속 방향
→ 최종 판매 확인
```

### 장비 연대기

- 최근 사건 우선
- 결과 원인과 결과를 한 묶음으로 표시
- 오래된 기록은 접힌 타임라인
- 파괴된 작품 기록도 삭제하지 않음

## 20. 저장·접근성·성능

### 저장

- 비가역 행동별 원자적 저장
- 명시적 영업 종료 시 세계 체크포인트
- 앱 종료만으로 시간 진행 금지
- 한 강화 시도당 판정 1회
- 단일 활성 캠페인 + 시스템 복구 스냅샷
- 복구 스냅샷으로 나쁜 결과 되돌리기 금지

### 접근성

- 색상만으로 결과 구분 금지
- 무음·무진동·모션 감소에서도 진행 가능
- 텍스트 확대 시 핵심 정보와 버튼 유지
- 길게 누르기 대체 입력
- 터치 대상 최소 48dp
- 기능 아이콘에 고유 접근성 설명

### 기준 기기군 후보

| 기기군 | 계획 후보 | 목표 |
|---|---|---|
| 저사양 | Android 11+, RAM 4GB, 720×1600급 | 전체 흐름 완료, 안정 30fps 하한 |
| 중간 | Android 13+, RAM 6GB, 1080×2400급 | 일반 UI·반복 강화 60fps |
| 상위 | Android 15+, RAM 8GB+, 고주사율 | 최대 연출 품질 |

정확한 모델·버전·메모리는 실제 확보 가능한 물리 기기 기준으로 구현 계획에서 확정한다.

### 성능

- 일반 UI·반복 강화 60fps 목표
- 고부하 연출 60fps 목표, 일시적 안정 30fps 허용
- 부하 시 장식 효과부터 축소
- 프레임 저하가 입력·판정·저장에 영향 금지

## 21. 플레이테스트 Gate

### Gate 1 — 결정론적 기능 검증

- 단조·첫 강화·+5 판단
- +49→+50 진화
- 카시아 요청·판매·조율·경기·연대기
- 저장·복귀·접근성·기기 성능

### Gate 2 — 최소 6명 비유도 테스트

초기 합격 후보:

- 최소 5명이 개입 없이 첫 강화 완료
- 첫 강화 중앙값 60초 이내
- 최소 5명이 +5 완성과 +10 도전 차이를 설명
- 6명 모두 판매가 삭제가 아닌 소유권 이전임을 이해
- 잘못 누른 비가역 행동 0건
- 최소 5명이 경기 후 장비 기여 원인 1개 이상 회상

### Gate 3 — 수집가 세트

같은 시스템·데이터·저장 구조로 요청·선택·판매·전시 결과를 완주한다.

### Gate 4 — 양방향 회귀

대표 검투사 흐름과 수집가 세트를 모두 재검증한다.

수치 합격선은 `PLANNING_CANDIDATE / TUNABLE`이다.

## 22. 미래 명작 전당

> 상태: `FUTURE_SERVER_PLANNING / NOT_IMPLEMENTED`

등록 자격:

- +50 이상 완성 작품
- 사용자 명시 동의
- 서버 검증 통과

비교 정보:

- 작품명
- 강화 단계
- 제작 등급
- 계보·보조 수식어
- 진화 형태
- 공개 연대기 요약
- 시즌·게임 버전

정책 후보:

- 기본 정렬: 강화 단계 → 제작 등급 → 서버 검증 등록 시각
- 필터: 장비·계보·등급·진화·시즌·역대
- 시즌 후보: 12주
- 공개 제작자명: 기본 비공개 또는 자동 생성 별칭
- 공개 등록 해제와 작품명·별칭 신고 지원
- 게임 성능 보상 없음
- 단일 종합 점수 금지

검증 경계:

- 플랫폼 숫자 리더보드는 보조 수단으로만 사용
- 작품 등급·수식어·진화·연대기 정본에는 별도 서버 레코드 필요
- 서버 검증 흐름에 참여한 작품만 검증 랭킹 등록
- 서버 이전 오프라인 작품은 레거시 전시 가능, 검증 순위 제외
- 등록 실패가 로컬 작품에 영향 없음

파괴 작품:

```text
장비 객체: 영구 소멸
공개 기록: DESTROYED 역사적 전시 가능
현재 사용 작품 랭킹: 제외
복구·복제·소유권 생성: 금지
```
