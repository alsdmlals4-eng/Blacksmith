## 2. 제품 정의

> **망치질로 장비를 만들고, 커지는 위험 앞에서 멈출지 도전할지 선택하며, 완성한 작품이 사람과 세계에 남기는 흔적을 확인하는 Android 세로형 모바일 대장간 게임.**

핵심 판매 문장:

> **내가 만든 장비가 누군가의 전설이 된다.**

핵심 경험:

1. 짧고 직접적인 단조 손맛
2. 위험·비용·보호 효과를 알고 선택하는 공정한 강화
3. 멈춘 지점도 작품의 완성으로 인정되는 감정
4. 제작 등급·수식어·진화로 구분되는 장비 정체성
5. 판매 후에도 같은 장비가 세계와 관계에 남는 경험

## 4. 두 시간 지평

### 4.1 일상 작품 루프

```text
단조
→ 장비 완성
→ +0~+5 강화
→ 지금 완성·판매 또는 +10 도전
→ 보관·일반 판매·방문 고객 거래
→ 다음 작품 재투자
```

- +5는 첫 안정적 완성 판단 지점이다.
- +10은 첫 정밀강화와 계보 수식어 획득 지점이다.
- 낮은 단계에서 멈추는 선택도 실패가 아니다.

### 4.2 장기 명작 루프

```text
일상 작품 중 하나를 보존
→ +10 단위 정밀강화
→ 계보·보조 수식어 형성
→ +49 도달
→ 일반 위험 정밀강화 또는 특수재료 고위 정밀강화
→ +50 진화
→ 판매·세계 사건·연대기
→ 명작 전당 후보
```

+50은 장비 정체성이 한 차례 완성되는 장기 목표다.

## 5. 단조와 제작 등급

단조는 제작 손맛과 최초 작품 정체성을 만든다.

```text
장비 종류·재료 선택
→ 망치 타격
→ 열·진행 확인
→ 피버
→ 완성
→ 제작 등급과 최초 연대기 확정
```

확정 제작 등급:

```text
보통
→ 양질
→ 우수
→ 명품
→ 걸작
```

원칙:

- 제작 등급은 강화 단계와 분리된 영구 정보다.
- 낮은 등급도 정상적으로 강화·판매·보관할 수 있다.
- `전설`은 제작 등급명으로 사용하지 않는다.
- 정확한 등급별 배율과 발생 분포는 플레이테스트 조정 대상이다.

## 6. 장비 정체성 모델

필수 축:

- 장비 ID
- 장비 이름
- 장비 범주와 세부 종류
- 제작 등급
- 강화 단계
- 계보 수식어
- 보조 수식어
- +50 진화 형태
- 제작자·현재 소유자·과거 소유자
- 운명 상태
- 장비 연대기

확정 수식어 구조:

```text
계보 수식어 1개
+ 보조 수식어 최대 2개
```

+50 대표 특수 수식어는 새 슬롯이 아니라 계보 수식어의 승격 형태다.

확정 이정표:

| 강화 단계 | 작품 정체성 결과 |
|---:|---|
| +10 | 계보 수식어 최초 획득 |
| +20 | 보조 수식어 1개 획득 |
| +30 | 계보 수식어 강화 또는 방향 선택 |
| +40 | 보조 수식어 2개째 획득 |
| +50 | 진화 + 계보 수식어의 대표 특수 형태 승격 |
| +60 이상 | 신규 슬롯 없이 기존 수식어 심화 |

## 7. 강화 계약

### 일반 강화

- 10단위 사이의 단계 상승 시도다.
- 최종 결과 확률을 0.01% 단위까지 공개하고 합계 100.00%를 유지한다.
- 실행 전 단계·비용·성공률·최대 하락·파괴·보호 효과를 표시한다.

### 일반 정밀강화

`+9→+10`, `+19→+20`처럼 10단위 진입 시도 자체다.

- 성공 시 단계와 이정표 결과를 함께 적용한다.
- 실패 시 해당 구간의 일반 위험을 적용한다.
- 정밀강화라는 이유로 성공이나 파괴 면제를 보장하지 않는다.

### +49→+50 고위 정밀강화

```text
+49 장비
+ 기존 수식어
+ 특수재료와 비용
→ 진화 후보 2~3개 공개
→ 플레이어 선택
→ +50 확정
→ 외형·이름·계보 수식어 승격
```

긴장은 실패 확률보다 재료·비용·진화 방향·판매 여부에서 발생한다.

### 판정·저장·연출

```text
최종 입력
→ 결과 정확히 1회 판정
→ 비용·재료·장비·연대기 원자적 저장
→ 저장된 결과 연출
→ 작업대 갱신
```

연출은 결과를 생성하거나 재추첨하지 않는다.

## 8. 모바일 강화 화면

고정 작업대:

- 상단: 장비 이름·등급·단계·수식어
- 중앙: 장비 외형과 강화 연출
- 하단: 성공률·비용·최대 하락·파괴·보호·강화 버튼
- 상황별 패널: 전체 확률, 보호 비교, 정밀강화, 진화 후보, 비가역 확인

입력:

- 저위험 강화: 즉시 실행
- 일반 정밀강화: 정보 확인 후 실행
- 파괴 가능 강화: 길게 누르기
- 고위 정밀강화: 후보 선택 후 길게 누르기
- 접근성 대체: 동일 정보의 2단계 확인 버튼

## 9. 보관함과 판매

### 보관함

- 작업 중 제품과 완제품을 캠페인 동안 지속 보유한다.
- 영업일마다 자동 초기화하지 않는다.
- 고객 수에 맞춰 제품을 자동 생성하지 않는다.
- 테스트 준비 장비는 이전 제작 이력을 가진 픽스처다.

### 일반 판매

- 언제든 가능한 기본 현금화 경로다.
- 이름 있는 고객·관계·세계 후속을 만들지 않는다.
- 빠르고 예측 가능하지만 보상 잠재력은 낮다.

### 판매 저장

제품 제외, 장비 ID 유지, 소유권 이전, 보상, 연대기, 요청 완료를 하나의 결과로 저장한다.

## 10. 방문 고객

기본 구조:

- 일반 판매와 분리된 요청 이벤트
- 동시에 최대 2개 활성
- 영업일 시작에 신규 요청 최대 1개
- 기본 기한 2영업일
- 앱 종료와 실제 시간 경과로 기한 감소 금지
- 대표 고객은 확정 트리거 사용

거래 자격:

```text
요청 범주 일치
+ 제작 완료
+ 판매 가능
+ 플레이어 보유
→ 거래 후보
```

낮은 강화·낮은 등급·수식어 부재는 자격을 막지 않는다.

공개 적합 신호:

```text
제작 등급·계보·보조 수식어·연대기
↔ 고객 가치관
```

적합 신호는 공개 가격, 관계, 후속 사건 방향, 고객 반응, 연대기 문구에 영향을 준다.

필수 원칙:

- 낮은 적합도여도 판매 가능
- 숨은 실패 조건 금지
- 평가 이유 공개
- 자동 추천·자동 선택 금지
- 최종 확인 전 예약·소유권 이전 없음

## 11. 콘텐츠 계층

### 대표 고객: 검투사

- 요청 범주: 무기
- 가치 방향: 성능·명성·계보·경기 이력
- 후속 선택: 배팅 또는 경기 전 지원 중 1개
- 결과: 짧은 자동 경기, 승패, 관계, 명성, 장비 연대기

### 두 번째 제작 기반 증명: 수집가

```text
방어구 또는 의식 장비 요청
→ 제작 등급·희소성·계보·연대기 비교
→ 제품 직접 선택·판매
→ 짧은 감정·전시 결과
→ 가치·관계·연대기 갱신
```

- 대표 15~25분 세션과 분리한다.
- 검투사와 같은 요청·선택·판매·소유권·저장 구조를 재사용한다.
- 수집가 전용 핵심 엔진이나 별도 저장 구조를 만들지 않는다.

본제작 후순위:

- 모험가 장기 원정
- 군인 임무·세계 영향력
- 수집가 장기 유물화
- 상인 장기 시장 콘텐츠
- 고객별 장기 약속·재방문

## 12. 장비 운명 상태

사용하지 않음:

- 내구도 수치·퍼센트
- 반복 수리 관리
- 고객 요청의 내구 조건
- 유지보수 실패로 장비 사용 차단

허용 상태:

```text
정상
전투 흔적
분실
회수
영구 파괴
```

`전투 흔적`은 사용 불가나 반복 수리 비용을 만들지 않고 외형·가치·설명·연대기에 영향을 주는 서사 상태다.

## 13. 대표 Vertical Slice

목표 시간: 15~25분

| 구간 | 시간 | 핵심 증명 |
|---|---:|---|
| 단조 마무리·첫 강화 | 0~2분 | 손맛과 즉시 피드백 |
| 새 장비 +0→+5 | 2~6분 | 위험 정보와 완성 판단 |
| 준비 대표작 +49→+50 | 6~10분 | 진화 선택과 장기 목표 |
| 검투사 요청·제품 비교 | 10~14분 | 작품 보존·판매 고민 |
| 판매·지원/배팅·영업 종료 | 14~17분 | 비가역 선택과 저장 |
| 경기 결과 | 17~22분 | 장비의 세계 기여 원인 |
| 연대기·다음 목표 | 22~25분 | 애착·회상·재플레이 동기 |

필수 판매 선택:

- 새 +5 장비를 판매하고 +50 대표작 보존
- +50 대표작을 판매해 높은 세계 영향 선택
- 다른 보관함 장비를 판매하고 두 작품 보존

어느 선택도 정답으로 표시하지 않는다.

- 확률·정답·결과 예측 제공 금지
- 성장·재화·능력 보정 없음
- 핵심 UI 가림 금지

이름·말투·외형은 다음 기획 단계에서 확정한다.

## 15. 정보 구조와 첫 5분

하단 3영역:

- `[대장간]`: 단조, 강화, 보관함, 일반 판매
- `[방문 고객]`: 활성 요청, 제품 비교, 거래, 관계
- `[세계]`: 판매 후 활동, 결과, 장비 연대기

알림 우선순위:

1. 미확인 비가역 결과·복구
2. 기한 있는 요청·행동
3. 일반 세계 소식

첫 5분 계약:

```text
30초: 장비와 망치 입력 이해
1분: 첫 강화
3분: 성공·실패·비용·보호 이해
5분: +5 완성 또는 +10 도전 판단
```

## 16. 저장·접근성·성능

저장:

- 비가역 행동별 원자적 저장
- 명시적 영업 종료 시 세계 체크포인트
- 앱 종료만으로 시간 진행 금지
- 단일 활성 캠페인 + 시스템 복구 스냅샷
- 복구 스냅샷으로 나쁜 결과 되돌리기 금지

접근성:

- 색상만으로 결과 구분 금지
- 무음·무진동·모션 감소에서도 진행 가능
- 텍스트 확대 시 핵심 정보와 버튼 유지
- 길게 누르기 대체 입력
- 짧은 실시간 반응 제한 없음

성능:

- 일반 UI·반복 강화 60fps 목표
- 고부하 연출 60fps 목표, 일시적 안정 30fps 허용
- 부하 시 장식 효과부터 축소
- 프레임 저하가 입력·판정·저장에 영향 금지

## 17. 아트·사운드

시각:

- 어두운 철·숯 배경
- 따뜻한 화로·불씨 주황

- 고강화는 금속광·형태 변화·각인으로 표현
- 위험은 아이콘·문구·숫자를 함께 사용

사운드·진동:

- 무음·무진동에서도 정보 완전성 유지

## 18. 플레이테스트 Gate

### Gate 1 — 결정론적 기능 검증

### Gate 2 — 최소 6명 비유도 테스트
