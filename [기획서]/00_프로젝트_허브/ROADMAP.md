## R2 — Core·Session·Meta Loop

상태: `PLANNING_ACTIVE / CHECKPOINT_003_CANON`.

### 병합 완료 범위

- 고객 능력·위험도 정수 `1~10`
- 약 10% 단위 예상 성공률, `5~95%`
- 개인 일정·세계 일정 분리
- 주요 일정 고정·오늘 중요 소식·묶음 요약·일정 장부
- 검투사·모험가·군인·귀족과 콘텐츠 가족
- 예술성 정수 `1~10`
- 보조재료 제거
- 일반 강화 한 입력 한 결과
- 정밀강화 방식과 촉매 책임 분리
- 등급·촉매·연대기 세 수식어
- 장비명 조합과 연대기 하단 상세 패널

### 현재 코어 흐름

```text
작품 종류 + 주재료 + 직접 단조
→ 제작 등급·등급 수식어
→ 일반 강화와 멈춤·추가 도전
→ 정밀강화 방식·촉매 선택
→ 촉매 수식어 성장
→ 고객·세계에 작품 전달
→ 연대기 수식어와 UID 생애 결과
→ 다음 강화·복원·제작 판단
```

### 다음 승인 후보 — `0/10`

1. 제작 등급 수식어와 예술성 시각 단계의 한국어 명칭 분리
2. 연대기 수식어의 효과 책임 경계
3. 작품 판매·증여·복원·상속 소유권 상태 머신
4. 모바일 장비명 줄바꿈·축약·스크린리더 읽기 순서
5. 첫 작품의 촉매·연대기 정체성 보상 시점
6. 완전 파괴와 작품 애착의 검증 계약
7. PR #81 분야별 자산 선별 이관 순서

### R2 적대적 질문

- 세 수식어가 실제 다음 판단을 만드는가, 단순 설명 장식에 그치는가
- 성공률 공개가 수치 최적화만 강제하지 않는가
- 일정 알림이 강화 리듬을 과도하게 끊지 않는가
- 첫 작품의 정체성 보상이 너무 늦지 않는가
- 예술성·제작 등급·세 수식어의 UI 위계가 명확한가
