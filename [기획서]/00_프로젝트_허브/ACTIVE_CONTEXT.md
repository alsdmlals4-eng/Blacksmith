## 정밀강화 예상 효과 계약

각 정밀강화 선택지와 최종 조합 요약은 다음을 표시한다.

```text
주재료: 작품의 기존 재료와 호환 상태
강화 방식: 주요 능력치 방향
촉매·추가재료: 추가 보정과 위험 변화
예상 변화: 낮음 / 보통 / 높음
대가: 성능 감소·무게·비용·위험·범용성
수식어 성향: 관련 효과 가족
```

- 텍스트 라벨은 필수다.
- 색상·아이콘·화살표는 보조 표현이며 텍스트를 대체하지 않는다.
- 정확한 최종 수치와 수식어를 확정적으로 공개하지 않는다.
- 성공한 결과는 선택한 강화 방식의 주요 방향을 반영해야 한다.
- 실패·대파 가능성과 주요 손실은 실행 전에 공개한다.
- 여러 항목이 모두 `높음`이면 비용·난이도·불안정·낮은 범용성 중 명확한 대가를 가진다.

## 예술성·가치와 실용 제작 선택

작품에는 새 가치 수치로 `예술성` 하나만 추가한다.

- 별도 `실용성` 수치는 추가하지 않는다.
- 실용성은 공격·방어·내구·무게·취급·안정성·환경 대응·작품 적합성으로 표현한다.
- 예술성은 별도 장식 미니게임이 아니라 기존 정밀강화의 예술 마감과 강화 결과 안에서 성장한다.
- 실용형은 기능·전투·생존·내구를 우선한다.
- 예술형은 예술성·희소가치·명품성·판매가를 우선한다.
- 혼합형은 양쪽을 결합하지만 동일 비용의 만능 최적해가 아니다.

## 예술성 최소 프리셋

### 표시

- 예술성: 정수 `1~10`
- 소수점 없음
- 등급은 예술성 기반과 잠재력에 영향을 주지만 자동 결정하지 않음
- 강화 단계만 높다는 이유로 예술성이 자동 상승하지 않음

### 가격

```text
기본 작품 가치 = 작품 등급 + 실전 성능
추가 가치 = 예술성 + 희귀 촉매·추가재료 + 작품 연대기·명성·감정 이력
```

고객 수요가 최종 제안을 조정한다. 귀족·수집가·전시는 높은 예술성 프리미엄을 평가할 수 있고, 실용 고객은 불필요한 예술 비용을 전부 지불하지 않을 수 있다.

### 수식어 가족

- 실용: 공격·정밀 / 방어·내구 / 취급·안정 / 환경·특화
- 예술: 마감·세공 / 위신·희소 / 감정·가치
- 수식어 풀은 완전히 배타적이지 않음

### 시각 4단계

| 예술성 | 단계 |
|---|---|
| `1~2` | 기본 |
| `3~5` | 정제 |
| `6~8` | 명품 |
| `9~10` | 걸작 |

금색·보석·발광의 양만 늘리지 않고 재료 질감·마감·각인·상감·장인 표식으로 차이를 만든다. 원래 실루엣과 기능 판독성을 유지한다.

## 정밀강화 구조

### 최초 제작

```text
작품 종류 + 주재료
→ 수식어 없는 1차 완성품
```

- 주재료는 기본 이름·성능 범위·가치·재료 시각 정체성을 결정한다.
- 초기 기준선은 `철 / 강철 / 은합금 / 운철`이다.
- 희귀 주재료도 능력치·예술성·가격을 자동 최고로 만들지 않는다.
- 보조재료 슬롯 없음.

### 일반 강화

- 일반 강화는 한 입력 한 결과다.
- 일반 강화마다 방식·촉매를 선택하지 않는다.
- 결과 확인과 멈춤·추가 도전 판단을 방해하는 조합 화면을 삽입하지 않는다.

### 정밀강화

정밀강화에서 선택하는 세 요소:

1. 주재료 맥락 — 기존 작품 재료와 호환 강화재
2. 강화 방식 — 능력치 방향성
3. 촉매·추가재료 — 증가량·대가·위험·수식어·마감 보정

강화 방식 6종:

- 날 보강: 공격력·정밀성
- 충격 흡수: 방어력·내구도
- 경량화: 무게 감소·취급성
- 균형 조정: 취급성·안정성
- 예술 마감: 예술성·가치
- 환경 처리: 환경 대응·특화 성능

각 방식은 주요 이점과 대가를 가진다. 작품 종류와 맞지 않는 방식은 표시하지 않는다. 성공한 결과는 선택 방향을 반영하지만 정확한 증가량·부작용·수식어는 변동 가능하다.

촉매 후보:

- 담금질 염
- 고열 담금질유
- 안정화유
- 방청 촉매
- 정밀 연마분
- 문장 정착제
- 별재 촉매

촉매는 강화 방향을 독립적으로 소유하거나 성공·수식어를 확정하지 않는다.

## 이름과 수식어 경계

```text
최초 주재료 이름 + 작품 종류
예: 철검 / 강철검 / 은합금 의장검 / 운철 도구
```

- 정밀강화 재료와 촉매가 기존 작품의 기본 이름을 자동 변경하지 않는다.
- 제작 직후 1차 완성품에는 수식어가 없다.
- `예리한`, `견고한`, `명품`, `광휘` 같은 수식어는 정밀 이정표와 강화 결과에서만 획득한다.
- 새로운 혼합 재료 작품군이 필요하면 별도 Decision과 명명 승인을 거친다.

## 자동 단조

자동 단조는 저위험 반복 제작을 줄이는 편의 기능이다. 주재료 선택·정밀 강화 방식·고객 적합성·강화 위험·멈춤 여부 같은 중요 판단을 자동 통과하거나 최적화하지 않는다.

## 고객 방문 흐름

```text
방문 고객 등장
→ 고객 유형·목적·사건 위험도·예정 시점 파악
```

대화는 판매 판단에 필요한 최소 정보만 제공하며 장문의 필수 퀘스트 설명이 아니다.

## 판매 전 정보 공개 계약

- 사건 위험도: 정수 `1~10`
- 고객 능력: `기량 / 체력 / 판단력` 각 정수 `1~10`
- 예상 성공률: 약 10% 단위, `5~95%`
- 장비 선택 전후 성공률 갱신
- 별도의 숨은 변수 경고 없음

## 세계일정 진행 계약

개인 일정:

- 방문과 판매·납품으로 활성화
- 고객 재방문 없이 하루 종료마다 최대 한 번 진행
- 판매 당일 최종 결과까지 즉시 해결하지 않음

세계 일정:

- 특정 날짜와 규모 사전 예고
- 관련 고객들의 판매·조언을 준비 기여로 누적
- 준비 체크포인트와 예정 날짜에서 판정
- 세계 변화와 고객별 후속 결과·재방문 분리

개인 일정과 세계 일정에 동일한 고정 날짜 상태 머신을 강제하지 않는다.

활동 이름과 보상만 다르고 고객 동기·작품 결과·후속 제작 판단이 같으면 별도 콘텐츠가 아니다.

## 방문고객과 초기 콘텐츠 가족

초기 방문고객: `검투사 / 모험가 / 군인 / 귀족`

개인 일정: 경쟁·라이벌 / 탐사·개척 / 보호·책임 / 사냥·위협 대응 / 예술·위신·후원

세계 일정: 대경기 시즌 / 대규모 유적 원정 / 왕국 위기 / 왕실 의례·명품 박람회

## 고객 능력과 성공 예측

- 기량 1~10
- 체력 1~10
- 판단력 1~10
- 역할·경력
- 특기 최대 2개
- 약점 최대 1개
- 짧은 성향·목표

일정은 `주 능력 1개 + 보조 능력 최대 1개 + 관련 특기·약점`을 사용한다. 귀족 전용 신규 능력치는 추가하지 않는다.

- 작품·도구 변경 후 예상 성공률 방향을 이해한다.
- 개인 일정과 특정 날짜 세계 일정을 구분한다.
- 일정 결과를 보고 복원·재강화·대체품·특화 신작 목표를 정한다.
- 보조재료 슬롯이 없다는 점을 설명한다.
- 최초 제작의 주재료와 정밀강화의 주재료 맥락을 구분한다.
- 일반 강화와 정밀강화의 선택 밀도 차이를 설명한다.
- 날 보강·충격 흡수·경량화·예술 마감이 재료가 아니라 강화 방식임을 설명한다.
- 강화 방식이 능력치 방향을 정하고 촉매가 결과를 보정하는 차이를 설명한다.

- 작품 종류에 맞지 않는 강화 방식이 노출되지 않아야 함을 이해한다.
- 촉매가 성공·수식어를 확정하지 않는 이유를 설명한다.
- 제작 직후 수식어가 없고 정밀 이정표에서 수식어가 붙는다는 점을 설명한다.

- 등급·강화 단계·예술성이 서로 다른 역할임을 설명한다.
- 고예술성 작품이 모든 고객에게 최적이 아님을 이해한다.
- 전투뿐 아니라 전시·감정·증여·상속도 작품 생애로 인식한다.
