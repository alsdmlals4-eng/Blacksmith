## 연대기 수식어 상세 열람

연대기 수식어가 존재하면 장비명 뒤의 해당 부분을 누를 수 있다.

```text
[명품] 예리한 강철 장검 - 투기장의 승자 ›
                         └ 연대기 상세
```

누르면 현재 장비 상세 맥락을 유지하는 읽기 전용 하단 패널을 연다.

- 현재 연대기 수식어와 요약
- 최초 형성 사건
- 형성·변화에 영향을 준 주요 타임라인
- 과거 수식어에서 현재 수식어까지의 진화 계보
- 현재 조건부 효과·위신·감정 가치
- 소유자·고객·결과와 손상·복원·상속 기록

모든 내용은 해당 작품 UID의 실제 기록에 근거한다. 일반 반복 로그는 제외한다. 열람 자체는 판정·보상·수식어 변화를 발생시키지 않는다. 색상만으로 누르기 가능 여부를 전달하지 않는다.
