## 제작·정밀강화 책임

### 주재료

- 작품 기본 이름 결정
- 공격·방어·내구·무게·취급 등 기본 성능 범위 결정
- 기본 가치·제작 난이도·재료 시각 정체성 결정
- 초기 기준선: `철 / 강철 / 은합금 / 운철`
- 희귀 주재료도 모든 상황의 만능 상위호환이 아님

### 제작 등급

- 직접 단조 결과로 `STANDARD / GOOD / PERFECT` 결정
- 제작 완료 시 등급 수식어 한 개 생성
- 동일 UID에서 강화·촉매·연대기·손상·복원으로 변경되지 않음
- 기존 제작 등급 성능·가치 효과를 설명하며 별도 중복 배율을 추가하지 않음

### 강화 방식

- 정밀강화의 세부 수치 조정 방향 소유
- 날 보강: 공격력·정밀성
- 충격 흡수: 방어력·내구도
- 경량화: 무게 감소·취급성
- 균형 조정: 취급성·안정성
- 예술 마감: 예술성·가치
- 환경 처리: 환경 대응·특화 성능
- 모든 방식은 주요 이점과 대가를 가짐
- 작품 종류와 맞지 않는 방식은 표시하지 않음

### 촉매

- 정확한 촉매 수식어가 아니라 후보 가족과 계보별 확률을 설정
- 빈 촉매 수식어 슬롯의 씨앗 성향 설정
- 기존 촉매 계보의 강화·분기·혼합 변형 확률 설정
- 정밀강화 한 번당 촉매 한 칸
- 여러 이정표의 촉매 사용 순서가 `누적 촉매 조합 이력`을 형성
- 강화 성공·정확한 촉매 수식어 이름·최고 단계를 보장하지 않음
- 등급 수식어와 연대기 수식어를 생성·변경하지 않음

### 작품 연대기

- 검투·전쟁·원정·사냥·구조·의례·전시·손상·복원·증여·상속 기록이 연대기 수식어를 생성·진화시킴
- 촉매 수식어를 직접 생성·성장·진화시키지 않음
- 제작 등급 수식어를 변경하지 않음
- 낮은 위험 반복 사건만으로 무한 성장하지 않음

## 세 수식어 슬롯

### 1. 등급 수식어 / GRADE_AFFIX

- 생성 원인: 제작 등급
- 최초 제작 상태: 즉시 생성
- 변경: 동일 UID에서 불가
- 역할: 출생 품질과 고정 등급 정체성 표시
- 금지: 제작 등급 효과의 중복 가산

### 2. 촉매 수식어 / CATALYST_AFFIX

```text
EMPTY
→ SEED / 씨앗
→ DEVELOPED / 성장
→ EVOLVED / 진화
→ MASTERED / 완성
```

- 최초 제작 상태: `EMPTY`
- 생성·변경 원인: 현재 촉매와 누적 촉매 이력
- 강화 단계: 다음 성장 기회와 상한만 개방
- 같은 촉매 계열 반복: 같은 계보 강화 가능성 상승
- 호환 촉매 전환: 계보 분기 가능성 상승
- 무관 계보 완전 무작위 교체 금지
- 작품 연대기는 촉매 수식어에 직접 영향 없음

### 3. 연대기 수식어 / CHRONICLE_AFFIX

- 최초 제작 상태: `EMPTY`
- 생성·변경 원인: 실제 작품 사용·사건·손상·복원·소유 이력
- 의미 있는 기록이 누적될 때 생성·성장·분기·변형
- 촉매와 제작 등급은 연대기 수식어의 이름·계보·진화를 직접 결정하지 않음
- 모든 변화는 작품 UID의 연대기 기록에 연결

기존 `일반 수식어 A·B` 구조는 현재 정본이 아니다. 현재 구조는 정확히 `등급 1 + 촉매 1 + 연대기 1`이다.

## 최초 제작 결과

```text
작품 종류 + 주재료 + 직접 단조
→ 기본 작품명·기본 성능·제작 등급
→ 등급 수식어 1개
→ 촉매 수식어 미형성
→ 연대기 수식어 미형성
```

따라서 `수식어 없는 1차 완성품`은 더 이상 정확한 표현이 아니다. 최초 제작품은 촉매·연대기 수식어만 비어 있다.

```text

```

- 텍스트 라벨 필수
- 정확한 촉매 수식어 이름과 최종 단계는 확정 공개하지 않음
- 후보로 제시하지 않은 무관한 계보가 성공 결과로 나오지 않음
- 실패 시 세 수식어·강화 단계·작품 기록은 유지
- 같은 이정표에서 무한 재시도 불가
- 정밀강화 화면에서 연대기 수식어를 촉매 보상처럼 제시하지 않음
