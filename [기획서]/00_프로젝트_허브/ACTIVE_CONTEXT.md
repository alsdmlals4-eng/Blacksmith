## 제작 전 재료·촉매 예상 효과 계약

각 선택지와 최종 조합 요약은 다음을 표시한다.

```text
실전 성능: 낮음 / 보통 / 높음
예술성: 낮음 / 보통 / 높음
판매가: 낮음 / 보통 / 높음
강화 성향: 대표 효과·수식어 가족
대가: 비용·무게·취급·안정성·범용성 중 한 가지
```

- 텍스트 라벨은 필수다.
- 색상·아이콘·화살표는 보조 표현이며 텍스트를 대체하지 않는다.
- 정확한 완성 수치와 최종 수식어를 확정적으로 공개하지 않는다.
- 반복 결과는 사전 설명과 같은 방향을 보여야 한다.
- 세 항목이 모두 `높음`이면 비용·난이도·불안정·낮은 범용성 중 명확한 대가를 가진다.

## 예술성·가치와 실용 제작 선택

작품에는 새 가치 수치로 `예술성` 하나만 추가한다.

- 별도 `실용성` 수치는 추가하지 않는다.
- 실용성은 공격·방어·내구·취급·안정성·환경 대응·작품 적합성으로 표현한다.
- 예술성은 별도 강화 버튼이나 장식 미니게임이 아니라 기존 강화 결과 안에서 성장한다.
- 실용형은 기능·전투·생존·내구를 우선한다.
- 예술형은 예술성·희소가치·명품성·판매가를 우선한다.
- 혼합형은 양쪽을 결합하지만 동일 비용의 만능 최적해가 아니다.

## 예술성 최소 프리셋

### 표시

- 예술성: 정수 `1~10`
- 소수점 없음
- 등급은 예술성 기반과 잠재력에 영향을 주지만 자동 결정하지 않음
- 강화 단계만 높다는 이유로 예술성이 자동 상승하지 않음

### 가격

```text
기본 작품 가치 = 작품 등급 + 실전 성능
추가 가치 = 예술성 + 희귀 보조재료·촉매 + 작품 연대기·명성·감정 이력
```

고객 수요가 최종 제안을 조정한다. 귀족·수집가·전시는 높은 예술성 프리미엄을 평가할 수 있고, 실용 고객은 불필요한 예술 비용을 전부 지불하지 않을 수 있다.

### 수식어 가족

- 실용: 공격·정밀 / 방어·내구 / 취급·안정 / 환경·특화
- 예술: 마감·세공 / 위신·희소 / 감정·가치
- 수식어 풀은 완전히 배타적이지 않음

### 시각 4단계

| 예술성 | 단계 |
|---|---|
| `1~2` | 기본 |
| `3~5` | 정제 |
| `6~8` | 명품 |
| `9~10` | 걸작 |

금색·보석·발광의 양만 늘리지 않고 재료 질감·마감·각인·상감·장인 표식으로 차이를 만든다. 원래 실루엣과 기능 판독성을 유지한다.

## 재료 3계층 역할

### 주재료

- 작품 기본 이름의 재료 표기
- 기본 성능 범위와 기본 가치 방향
- 제작 난이도·재료 고유색·결·반사 특성
- 실용·예술 잠재력의 출발점

초기 역할군은 `철 / 강철 / 은합금 / 운철`이다. 희귀 주재료도 등급·예술성·실용성·가격을 자동 최고로 만들지 않는다.

### 보조재료

주재료 정체성을 유지하면서 한 방향을 강화하고 하나의 대가를 만든다.

- 날 보강재
- 충격 흡수재
- 경량 합금
- 환경 처리재
- 은사·상감재
- 문장·각인 금속

### 촉매

기본 재료가 아니라 강화 과정의 반응과 결과 성향을 조절한다.

- 담금질 염
- 고열 담금질유
- 안정화유
- 방청 촉매
- 정밀 연마분
- 문장 정착제
- 별재 촉매

촉매는 강화 안정성·위험·강화 효과·수식어 가중·마감 성향에 영향을 주지만 결과를 확정하지 않는다.

- 숨은 조합이 새 기본 작품군을 만들면 별도 Decision과 명명 승인이 필요하다.

## 행동 증거

- 플레이어가 고객 능력과 사건 위험도를 비교한다.
- 작품·도구 변경 후 예상 성공률 방향을 이해한다.
- 개인 일정과 특정 날짜 세계 일정을 구분한다.
- 일정 결과를 보고 복원·재강화·대체품·특화 신작 목표를 정한다.
- 재료·촉매의 실용·예술·가격 방향과 대가를 설명한다.
- 주재료가 이름과 기본 성능을 정하고 보조재료가 방향을 보정하는 차이를 설명한다.
- 촉매가 강화·수식어 성향에 영향을 주지만 결과를 확정하지 않는 이유를 설명한다.
- 제작 직후 수식어가 없고 강화 이정표에서 수식어가 붙는다는 점을 설명한다.
