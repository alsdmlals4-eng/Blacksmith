## 제작·정밀강화 책임

### 주재료

- 작품 기본 이름 결정
- 공격·방어·내구·무게·취급 등 기본 성능 범위 결정
- 기본 가치·제작 난이도·재료 시각 정체성 결정
- 초기 기준선: `철 / 강철 / 은합금 / 운철`
- 희귀 주재료도 모든 상황의 만능 상위호환이 아님

### 강화 방식

- 정밀강화의 세부 수치 조정 방향 소유
- 날 보강: 공격력·정밀성
- 충격 흡수: 방어력·내구도
- 경량화: 무게 감소·취급성
- 균형 조정: 취급성·안정성
- 예술 마감: 예술성·가치
- 환경 처리: 환경 대응·특화 성능
- 모든 방식은 주요 이점과 대가를 가짐
- 작품 종류와 맞지 않는 방식은 표시하지 않음

### 촉매

- 정확한 수식어가 아니라 후보 가족과 계보별 확률을 설정
- 빈 수식어 슬롯의 씨앗 성향 설정
- 기존 계보의 강화·분기·혼합 변형 확률 설정
- 정밀강화 한 번당 촉매 한 칸
- 여러 이정표의 촉매 사용 순서가 `누적 촉매 조합 이력`을 형성
- 강화 성공·정확한 수식어 이름·최고 단계를 보장하지 않음

## 수식어 생애주기

```text
EMPTY
→ SEED / 씨앗
→ DEVELOPED / 성장
→ EVOLVED / 진화
→ MASTERED / 완성
```

- 초기 촉매가 수식어 씨앗과 계보 확률을 설정한다.
- 강화 단계는 성장 기회와 상한을 연다.
- 일반 강화 단계만으로 수식어가 자동 성장하지 않는다.
- 실제 생성·강화·변형은 정밀 이정표에서 판정한다.
- 같은 촉매 계열 반복은 기존 계보 강화 가능성을 높인다.
- 호환 촉매 전환은 계보 분기 가능성을 높인다.
- 작품 일대기는 특수 진화 후보·이름·설명·시각·조건부 효과를 추가한다.
- 기존 계보와 무관한 완전 무작위 교체는 금지한다.
- 모든 변화는 작품 UID의 촉매 이력과 수식어 진화 기록에 남긴다.

## 일반 수식어와 사건 수식어

- 일반 수식어 A·B: 촉매 씨앗에서 시작해 강화 단계와 일대기로 성장
- 활성 사건·일대기 수식어 한 칸: 실제 사건·사용·소유 이력에서 발생
- 작품 일대기는 일반 수식어의 진화 조건이 될 수 있지만 사건 수식어를 대체하지 않음

- 실패 시 기존 수식어·계보·강화 단계·일대기는 유지
- 같은 이정표에서 무한 재시도 불가
